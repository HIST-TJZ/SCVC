## 3. 涡旋变形 = 非平凡联络

### 3.1 物理波函数

在涡旋背景中, 费米子零模波函数被局域化:
```

其中R_a(z) = 从z到不动点p_a的Fubini-Study测地距离,

```

```

展宽ξ_a反比于费米子质量: ξ_a = σ_Koide · (m_τ/m_a)^{1/3}。

### 3.2 变形后的内积

```
G̃_{ab} = ⟨ψ̃_a|ψ̃_b⟩ 
        = (3/π³) ∫_{S⁵} z̄_a z_b · Φ(R_a)Φ(R_b) dμ
```

a≠b时, 被积函数z̄_a z_b不再在整个S⁵上积分——Φ的乘积打破了对称性。
两个Φ峰重叠的区域贡献非零内积:
```
G̃_{ab} ≈ exp(-d(p_a,p_b)²/2(ξ_a²+ξ_b²))
```

其中d(p_a,p_b) = π (Fubini-Study距离)。

### 3.3 变形Berry联络

```

```

沿连接p_a到p_b的测地线γ(t):
```
Ã_t^{ab} = i∫ ψ̄_a(z) ψ_b(z) · Φ(R_a)Φ(R_b) · ∂_t[log Φ(R_b)] dμ

这给出了非零联络。关键部分:
