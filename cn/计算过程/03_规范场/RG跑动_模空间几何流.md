## 标准QFT图像

alpha_s^(-1)(mu) = alpha_s^(-1)(M_KK) + (beta_0/(2*pi)) * ln(M_KK/mu)
beta_0 = 11 - 2*N_f/3 = 7 (SU(3), N_f=6)

这是RGE数值积分 — 看似纯计算。

## SCVC几何图像

### 16*pi = CP^2纤维体积

在GKM局域化中, 规范耦合的平方反比 = toric簇上的等变积分:
alpha_s^(-1) = (volume of CP^2 fiber at scale mu)

在M_KK: 所有KK模式活跃 -> 纤维体积最大 -> alpha_s^(-1)最小
在M_Z: 仅零模 -> 纤维体积缩小 -> alpha_s^(-1)增大

### beta函数系数的几何意义

11 = dim(SU(3)) = 8 (伴随表示) + 3?
   = 来自规范玻色子圈图的群论因子
   = SU(3)的Casimir: C_A = 3, 圈图系数 = 11/3 * C_A?

2*N_f/3 = 来自费米子圈图的群论因子
   = N_f * C_F * (something)
   = 6 * (4/3) * (1/2) = 4 -> 2*N_f/3 = 4

这些都是群表示论 — 在SCVC中是CP^2的等变K理论 — 纯几何!

### 几何流方程

RG跑动 = CP^2上纤维体积随能量尺度的单参数形变:
d(alpha_s^(-1))/d(ln mu) = -beta_0/(2*pi)
                        = -7/(2*pi)
                        = -(11 - 2*N_f/3)/(2*pi)

这对应于CP^2上某种 等变体积的Ricci流。
