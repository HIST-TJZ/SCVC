## 1. CP²上BPS涡旋的场方程

### 1.1 几何设定

底流形: CP² = SU(3)/U(2), Fubini-Study度规:
```
ds²_FS = g_{ij} dz^i dz̄^j
g_{ij} = (1+|z|²)δ_{ij} - z̄_i z_j / (1+|z|²)²
```

Kähler形式: ω = i g_{ij} dz^i ∧ dz̄^j, dω = 0。

Ricci曲率: R_{ij} = 3 g_{ij} (CP²是Kähler-Einstein, 常数正曲率)。

### 1.2 规范场+标量场系统

SCVC涡旋 = CP²上的U(1)规范场A_μ + 复标量场φ(旋量BEC序参量):

```
L = -¼F_{μν}F^{μν} + |D_μφ|² - V(|φ|)
```

其中D_μ = ∂_μ - iA_μ, V(|φ|) = λ(|φ|² - v²)²/4。

### 1.3 BPS极限

当λ = 1 (临界耦合, 即BPS极限)时, 二阶场方程化为一阶BPS方程:

```
F_{12} = ±½(|φ|² - v²)   (BPS方程1: 磁通量=标量场偏离)
D̄φ = 0                   (BPS方程2: 全纯性条件)
```

在CP²上, D̄φ = 0意味着φ是某线丛的全纯截面。

### 1.4 涡旋ansatz

轴对称涡旋(绕CP²中某不动点):
```
φ(z) = v · f(R) · e^{inθ}  (n ∈ Z, 涡旋绕数)
A_θ = n · a(R)              (仅角向分量)
```

其中R是到不动点的Fubini-Study测地距离, θ是角坐标。

剖面函数f(R)满足的ODE:
```
f'' + (cot R + 2cot 2R)f' - (n²(1-a)²/sin²R + 2cos²R)f
    = λv²(f²-1)f
```

以及在CP²几何下的磁通方程:
```
a'' + (cot R - 2tan R)a' = f²(1-a)/g²
```
