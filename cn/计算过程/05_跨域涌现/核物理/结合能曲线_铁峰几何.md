## 1. 结合能曲线的极值条件

液滴模型每核子结合能:
```
B/A = a_v - a_s/A^{1/3} - a_c·Z(Z-1)/A^{4/3} - a_a·(N-Z)²/A² + δ/A
```

对于稳定核素, β稳定谷给出N≈Z+(a_c/2a_a)A^{2/3}Z/(...)。在A处固定Z使B最大化。

对Z求导(固定A, 沿β稳定谷):
```
∂(B/A)/∂Z = 0 → Z_opt
```

### 1.1 β稳定条件

```
∂B/∂Z|_{A} = 0 → a_c·(2Z-1)/A^{1/3} - 4a_a·(N-Z)/A = 0

N-Z = (a_c/4a_a) · A^{2/3} · (2Z-1)/A^{1/3}
     ≈ (a_c/2a_a) · A^{2/3}  (当Z≫1)
```

加上A = Z + N:
```
A = 2Z + (a_c/2a_a) A^{2/3}
```

对于A∼50-60: A^{2/3}∼14-15, a_c/2a_a = 0.711/(2×23.7) = 0.0150。

```
A ≈ 2Z + 0.015 × 15 = 2Z + 0.225
Z ≈ (A - 0.225)/2
```

对A=56: Z≈27.9 → Z≈26 (Fe-56的Z=26, 轻微偏离因为壳效应)。

## 3. 为什么是铁(Z=26)?

### 3.1 几何根源

铁峰的存在 = 三个效应的竞争:
1. **表面项**(∼A^{-1/3}): 随A增大而减弱 → 有利大核
2. **Coulomb项**(∼Z²/A^{4/3}): 随Z增大而增强 → 不利大核
3. **对称项**(∼(N-Z)²/A²): 中子过剩代价 → 不利大核

三项的平衡点由SCVC几何系数决定:

## 4. Fe-56 vs Ni-62

### 4.1 为什么不是Ni-62?

Ni-62 (Z=28, N=34) **每核子结合能最高** (8.795 MeV vs Fe-56的8.790 MeV)。
但Fe-56的**每核子质量最低**——因为中子比质子重。

m_n - m_p - m_e ≈ 0.78 MeV。Ni-62有更多中子→虽然结合更紧但总质量更大。

### 4.2 SCVC的几何解释

Fe-56 (Z=26, N=30) vs Ni-62 (Z=28, N=34):
- Fe-56: Z更小 → Coulomb能更小 → 即使每核子结合少0.005 MeV, 总质量仍更小
- 这是因为m_n > m_p, 而Ni-62多了4个中子 → 质量增加4×0.78=3.12 MeV, 远超结合能优势(62×0.005=0.31 MeV)

**所以铁是最低质量的核, 镍是最高结合能的核。**
