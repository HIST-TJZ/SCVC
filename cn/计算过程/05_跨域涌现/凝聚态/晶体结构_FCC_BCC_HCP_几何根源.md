## 1. SCVC原子图像

### 1.1 原子 = 核涡旋环 + 电子涡旋环

在SCVC中:
- 原子核 = 核子涡旋环的紧密团簇
- 电子壳层 = 电子涡旋环的分层排列
- 原子间力 = 涡旋环间的Ampère力 + Pauli拓扑排斥

### 1.2 涡旋环的几何形状

涡旋环不是完美球形——它有各向异性:
```
环平面方向: Ampère力最强(环的"赤道面")
环轴方向: Ampère力最弱(环的"极轴")
```

这直接导致了晶体结构的选择:
- **各向同性环**(稀有气体、贵金属) → 密堆积 → FCC/HCP
- **各向异性环**(碱金属、过渡金属) → 方向性堆积 → BCC/其他

## 2. FCC: 各向同性涡旋环的最密堆积

### 2.1 几何最优性

在3D空间中, 等球的最高配位数=12 (FCC和HCP), 堆积分数=π/√18≈74%。

SCVC推导: 原子间Ampère力 F_A ∝ (κ₁κ₂)/r²。结合能∝配位数。

FCC的近邻壳层:
```
第1壳层: 12个近邻 (距离d)
第2壳层: 6个近邻 (距离√2 d)
第3壳层: 24个近邻 (距离√3 d)
```

总结合能(成对叠加):
```
E_FCC = -½ · [12·V(d) + 6·V(√2 d) + 24·V(√3 d) + ...]
```

V(r) = Ampère势 = -C·κ²/r (涡旋环平行时)。

### 2.2 为什么是FCC而不是HCP?

FCC和HCP都有12近邻和74%堆积分数。区别在次近邻:
- FCC: 第2壳层6个(距离√2 d), 第3壳层24个(√3 d)
- HCP: 第2壳层6个(距离√2 d), 第3壳层2个(c/a理想时)

FCC的远程堆积略优于HCP → 对于完美各向同性的涡旋环, FCC是最优的。

**实验**: Cu, Ag, Au, Al, Ni, Pt... 都是FCC ✅

### 2.3 SCVC预测: 哪些元素取FCC?

条件: Z_eff适中(5-11), 涡旋环接近球形, 无强方向键。

```
FCC金属: Cu(Z=29, Z_eff~7.9), Ag(47,~7.6), Au(79,~10.9)
           Al(13,~4.1), Ni(28,~8.9), Pt(78,~12.0)
```

规律: Z_eff在4-12范围, 电子涡旋环足够"球形"→FCC。

## 3. BCC: 各向异性涡旋环的堆积

### 3.1 BCC的结构优势

BCC配位数只有8(比FCC少), 但:
- 第1壳层8个(d) + 第2壳层6个(2/√3 d≈1.155d)
- 第2壳层非常近!

对于各向异性涡旋环:
- 环的"赤道面"方向Ampère力强, 但只有4个近邻在此方向
- 环的"极轴"方向Ampère力弱
- BCC的8+6结构更好地利用了各向异性

### 3.2 碱金属→BCC: 大而软的涡旋环

碱金属(Li, Na, K, Rb, Cs): 最外层只有一个电子→涡旋环"松散"→各向异性强。

Z_eff很小(~1.3-2.5)→涡旋环半径大→原子间距离大→环的各向异性显著。

BCC允许环在8个方向上最大化Ampère重叠, 同时6个次近邻填补空隙。

**实验**: 所有碱金属都是BCC ✅

### 3.3 过渡金属→BCC: d电子的方向键

Fe, W, Cr等BCC过渡金属: d电子涡旋环有强烈的角向依赖性。

Fe (Z=26): [Ar]3d⁶4s², d壳层半满→球对称? 不, 每个d轨道有特定的角向分布。
在晶体场中, d轨道分裂为t₂g和e_g→方向键→BCC更灵活。

W (Z=74): 5d⁴6s², 高Z→强自旋-轨道耦合→涡旋环各向异性强→BCC。

**实验**: Fe(α), W, Cr, Mo, V, Nb, Ta都是BCC ✅

### 3.4 SCVC预测规则

```
涡旋环各向异性参数 η = (r_max - r_min) / r_avg

η < 0.05 → FCC (近球形环, 贵金属)
0.05 < η < 0.15 → BCC/FCC边界
η > 0.15 → BCC (高各向异性, 碱金属/高Z过渡金属)
```

Z_eff与η的关系: 低Z_eff(碱金属)→大原子半径→涡旋环自由度高→η大→BCC。

## 4. HCP: 方向键的六角堆积

### 4.1 HCP的独特性

HCP与FCC有相同配位数(12)和堆积分数(74%), 但层堆叠方式不同:
- FCC: ABCABC... (三层重复)
- HCP: ABABAB... (两层重复)

为什么某些金属选HCP? 方向键!

### 4.2 方向键的几何

HCP在一个方向(z轴)上有独特的对称性。对于有方向键的涡旋环:
- 环的赤道面在x-y平面→Ampère力在x-y平面最强→六角密排
- z方向→AB堆叠→允许环的极轴方向有更多自由度

过渡金属(d电子): d轨道有方向性→涡旋环各向异性→HCP(部分填充d壳层)。

**实验**: Mg, Zn, Cd, Ti, Zr, Co... 都是HCP ✅

### 4.3 c/a比率的几何

理想HCP的c/a = √(8/3) ≈ 1.633。实际金属的c/a偏离:
- Zn: 1.856 (偏离+13.7%) — d¹⁰满壳, 环被拉长
- Mg: 1.624 (偏离−0.6%) — 接近理想
- Ti: 1.588 (偏离−2.8%) — d²部分填充

c/a偏离 = 涡旋环各向异性的直接度量!
