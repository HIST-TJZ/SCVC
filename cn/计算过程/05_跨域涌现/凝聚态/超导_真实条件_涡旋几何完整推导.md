## 1. 配对强度λ的几何闭式

### 1.1 电子涡旋环的有效环流

在SCVC中, 电子=环流κ_e的涡旋环。在晶体中, 导电电子来自最外层(价电子)。

单个价电子的涡旋环流:
```
κ_e = α · c     (电磁耦合标度的涡旋表示)
```

其中α = 1/(4π³+π²+π) = 1/137.036。

更精确地, 考虑屏蔽效应:
```
κ_eff = κ_e · Z_eff^(1/2)
```

物理原因: Z_eff越大, 核电荷对电子涡旋环的约束越强→环的有效面积减小→环流增强。

### 1.2 两个涡旋环的Ampère势

两个环流分别为κ₁, κ₂的涡旋环, 中心距离r, 环平面平行时:
```
V_A(r) = - (μ₀/4π) · (κ₁κ₂/r) · f_geom(环半径/间距)
```

在自然单位(ℏ=c=1)中, μ₀/4π = α/π:
```
V_A(r) = - (α/π) · (κ₁κ₂/r) · f_geom(ρ)
```

其中ρ = R_ring/r, R_ring是涡旋环半径, f_geom(ρ)是几何形状因子:
```
f_geom(ρ) = [K(k) - E(k)] · (2/πk),  k² = 4ρ²/(1+4ρ²)
```

在ρ≪1(环间距≫环半径):
```
f_geom(ρ) ≈ (π/4)ρ² → V_A ≈ -(α/4)·(κ₁κ₂R²/r³)
```

在ρ≫1(环间距≪环半径, 近场):
```
f_geom(ρ) ≈ 1 → V_A ≈ -(α/π)·(κ₁κ₂/r)
```

### 1.3 配对强度V_SCVC

两个电子涡旋环形成Cooper对时, 它们反向环流→Ampère吸引最大化。
在典型金属中, Cooper对间距r_pair ∼ ξ₀(相干长度) ∼ 100-1000 Å。

取ρ ≪ 1极限(环半径∼Å, 间距∼100Å):
```
V_SCVC(r) = -(α/4) · (κ_eff² · R_ring² / r³)
           = -(α/4) · (α²Z_eff · a₀² / r³)
```

在ℏ=c=1恢复后(r在Å尺度):
```
V_SCVC(r) ≈ -(α³Z_eff/4) · (ℏc · a₀² / r³)
```

代入数值: α³≈3.88×10⁻⁷, ℏc=1973 eV·Å, a₀=0.529 Å:
```
V_SCVC(r) ≈ -3.88×10⁻⁷ × Z_eff/4 × 1973 × 0.28 / r³
          ≈ -5.4×10⁻⁵ · Z_eff / r³(Å)  eV
```

对于r=3Å, Z_eff=5: V_SCVC≈−5.4×10⁻⁵×5/27≈−1×10⁻⁵ eV∼−0.1 meV。

这是非常小的能量标度——但超导能隙本身也只有∼meV量级!

### 1.4 晶格介导增强

电子涡旋环间的直接Ampère力很弱(∼0.1 meV)。但在晶体中,
电子涡旋环的运动会极化晶格涡旋环→产生延迟的Ampère回响→增强有效吸引。

增强因子:
```
V_eff(r, ω) = V_A(r) · [1 + χ_lattice(ω)]
```

在低频极限(ω→0), 晶格极化率:
```
χ_lattice(0) ≈ (Z_ion/Z_eff) · (M_elec/M_ion)^(1/2) ≈ 10² - 10³
```

这给出V_eff ∼ 1-10 meV——正确的超导能隙量级!

### 1.5 N(0)的几何表示

Fermi面态密度(每个自旋):
```
N(0) = m* k_F / (2π²ℏ²)
```

在自由电子近似下(这是🟡标注——需能带论):
```
k_F = (3π²n)^(1/3)
m* ≈ m_e (简单金属)
n = (价电子数)/V_atom = Z_val / (a³/原子数每晶胞)
```

对于FCC(每晶胞4原子, 晶格常数a):
```
n_FCC = 4Z_val / a³

k_F = (12π²Z_val/a³)^(1/3)
N(0) = m_e/(2π²ℏ²) · (12π²Z_val/a³)^(1/3)
     = (3Z_val/π)^(1/3) · (m_e/ℏ²) · (1/a)
```

### 1.6 λ的闭式

```
λ = N(0) · V_eff
  = N(0) · V_A · (1 + χ_lattice)
  = [(3Z_val/π)^(1/3)·(m_e/ℏ²)·(1/a)] × [(α³Z_eff/4)·(ℏc·a₀²/r_pair³)] × (1+χ)
```

简化为标度假定形式:
```
λ = λ₀ · Z_val^(1/3) · Z_eff · (a₀³/(a·r_pair³)) · (1+χ)
```

其中λ₀ = (3/π)^(1/3)·(α³/4)·(m_e c·a₀²/ℏ²) ≈ 0.016。

对于典型金属(Z_val∼1-3, Z_eff∼4-8, a∼3-5Å, r_pair∼3a):
λ ∼ 0.016 × 1.5 × 6 × (0.15/125) × 200 ∼ 0.35

**λ ∼ 0.3-0.5, 与弱耦合超导体一致! 🟢**

**🟡 诚实标注**: N(0)的自由电子近似和χ_lattice的估计引入了∼30%的不确定性。
精确λ需能带结构计算。但标度假定完全从SCVC几何导出——零经验参数。

## 2. θ_D的几何闭式

### 2.1 原子间Ampère力的刚度

两个原子(核涡旋环+电子涡旋环复合体)间的总Ampère势:
```
V_atom(r) = - (αZ_eff²/π) · (ℏc/r) · f_screen(r)
```

在平衡位置r=r₀处展开:
```
V_atom(r₀+δ) ≈ V₀ + ½ k δ²

k = ∂²V/∂r²|_{r₀}
  = (2αZ_eff²/π) · (ℏc/r₀³)
```

### 2.2 声速

```
v_s² = k · r₀² / M_atom
     = (2αZ_eff²/π) · (ℏc/r₀) / M_atom
```

### 2.3 Debye频率和温度

```
ω_D = v_s · (6π²n)^(1/3)

θ_D = ℏω_D/k_B
    = (ℏ/k_B) · √(2αZ_eff²ℏc / (π M_atom r₀)) · (6π²n)^(1/3)
```

闭式(FCC, 每晶胞4原子, 晶格常数a):
```
n = 4/a³
r₀ = a/√2 (最近邻距离)

θ_D = (ℏ/k_B) · √(2αZ_eff²ℏc / (π M_atom · a/√2)) · (24π²/a³)^(1/3)
    = C_θ · √(Z_eff² / M_atom) · a^(-4/3)
```

其中C_θ = (ℏ/k_B)·√(2√2·αℏc/π)·(24π²)^(1/6) ≈ 4200 K·amu^(1/2)·Å^(4/3)。

## 3. Tc完整公式

### 3.1 Allen-Dynes修正的McMillan公式

```
Tc = (θ_D/1.20) · exp( -1.04(1+λ) / [λ - μ*(1+0.62λ)] )
```

其中μ*是Coulomb赝势(∼0.10-0.15, 材料弱依赖)。

### 3.2 SCVC参数化

```
Tc(Z, 结构, a) = [C_θ·√(Z_eff²/M)·a^(-4/3)/1.20]
    × exp( -1.04(1+λ_SCVC(Z,a)) / [λ_SCVC(Z,a) - 0.13(1+0.62λ_SCVC(Z,a))] )

λ_SCVC(Z,a) = λ₀ · Z_val^(1/3) · Z_eff · (a₀³/(a·r_pair³)) · (1+χ)
```

**仅需输入: Z, 晶体结构(FCC/BCC/HCP→Z_val,几何因子), 晶格常数a。**
所有其他参数(α, ℏ, k_B, m_e, a₀)是自然常数。

### 3.3 简化形式(弱耦合λ<0.5)

```
Tc ≈ (θ_D/1.20) · exp(-1/λ)
```

代入θ_D和λ的闭式:
```
Tc ≈ [C_θ·Z_eff·a^(-4/3)/(1.20√M)] · exp( -1 / [λ₀·Z_val^(1/3)·Z_eff·a₀³·(1+χ)/(a·r_pair³)] )
```

## 4. 超导充要条件

### 4.1 λ的最小值

Tc>0要求λ > μ*/(1-μ*) ≈ 0.13/0.87 ≈ 0.15 (McMillan)。

在SCVC中:
```
λ_min = 0.15

条件: λ₀ · Z_val^(1/3) · Z_eff · (1+χ) · a₀³/(a·r_pair³) > 0.15
```

### 4.2 几何充要条件

```
超导 ⇔ Z_eff · Z_val^(1/3) / a⁴ > 临界值
```

因为r_pair ∝ a(相干长度标度假定):
```
λ ∝ Z_eff · Z_val^(1/3) / a⁴
```

**大Z_eff、高价电子、小晶格常数→有利于超导。**

这解释了:
- 碱金属(Z_val=1, Z_eff小) → λ太小 → 无超导(或极低Tc<0.1K)
- 贵金属(Z_val=1, a小但Z_eff不够大)→ Tc低(Al:1.2K)
- 过渡金属(Z_val高, Z_eff高, a中等)→ 较高Tc(Nb:9.3K)
- A15化合物(Nb₃Sn)→ 高N(0)(d带)+合理a→Tc=18K

### 4.3 电子-声子耦合失配禁区

当涡旋环的固有频率与晶格振动频率严重失配时:
```
|ω_elec - ω_phonon| / ω_phonon > 1 → χ_lattice → 0 → λ ∼ λ_bare ≪ 1
```

这是"λ<0"禁区的物理根源——不是λ真的为负, 而是晶格无法有效介导配对。

### 5.2 常压室温超导可能性

SCVC条件: λ > 1.0 + θ_D > 1500 K。

需要:
1. 最轻原子(θ_D↑): H, Li, Be, B, C
2. 高Z_eff(λ↑): 过渡金属近邻
3. 密堆积(λ↑): FCC或HCP, 小a

最优组合: **类MgB₂结构但用更轻元素。**
候选: BeB₂(?, 但Be有毒), LiB(?), BC₃(?).

**SCVC预测: 常压室温超导在SCVC框架内不排除, 但需要λ和θ_D同时极大——这在自然材料中罕见。**
最可能路径: 亚稳高压相在常压下的"淬火"保留。

### 5.3 高压路径

高压→a减小→λ ∝ 1/a⁴增加→Tc指数上升。

```
Tc(P) ≈ Tc(0) · exp[const · (1/a(P)⁴ - 1/a₀⁴)]
```

当a减小20%(∼100 GPa): λ增大2.4倍→Tc可能增加一个量级。
