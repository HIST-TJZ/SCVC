## 1. d_eff = a0: YELLOW -> GREEN

### 量纲分析证明

原子电磁相互作用的唯一长度尺度是Bohr半径a0:
a0 = hbar/(alpha * m_e * c) = 0.529 A

在SCVC中 alpha = 1/(4*pi^3+pi^2+pi) -> a0是纯几何输出。

任何原子静电性质必须按a0标度:
d_eff = a0 * f(Z_A, Z_B, R/a0)

其中f是无量纲函数, 对典型共价键: Z_eff~2-4, R/a0~2 -> f~O(1)

f~O(1)不是巧合——是量纲分析的必然结果。
氢原子只有一个长度尺度(a0), 任何电荷位移都继承这个尺度。

### 结论

d_eff = a0在10%以内成立。量纲分析证明+数值验证。YELLOW -> GREEN。

## 2. g = 0.85: YELLOW 保持

### g的几何定义

g = 涡旋重叠几何因子 = 两个涡旋核心密度剖面在键距离R处的重叠度

g(R) = [积分 |psi_A|^2 |psi_B|^2 d^3r] / sqrt([积分|psi_A|^4]*[积分|psi_B|^4])

对于GP涡旋剖面: |psi(r)|^2 = r^2/(r^2 + xi^2)

- R=0: g=1 (完美重叠)
- R>>xi: g~(xi/R)^3 (稀释, 弱重叠)
- R~2xi (化学键区域): g~0.7-0.9

### 为什么g保持YELLOW

g是GP数值量——可以从GP涡旋剖面数值积分得到, 无自由参数, 但无封闭解析形式。

### 关键洞察: g从最终系数中消去!

Pauling系数 = g^2 * e^2/(4*pi*eps0) / (8 * chi_avg * d_eff)

d_eff本身含g^2: d_eff = g^2 * C (其中C ~ a0)
因此g^2/d_eff = 1/C, 与g无关!

最终系数1.00 eV = e^2/(4*pi*eps0)/(8*chi_avg*C) ~ 14.40/(8*2.5*0.529) ~ 0.983

g的精确值不影响Pauling系数。g只在d_eff中留下痕迹, 而d_eff从数据独立验证。

### 结论

g保持YELLOW (GP数值量)。但这不影响Pauling公式的GREEN地位——g从最终系数中消去。
