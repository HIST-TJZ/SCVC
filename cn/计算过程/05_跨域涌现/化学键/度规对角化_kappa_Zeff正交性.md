# 度规对角化: kappa和Z_eff正交性的严格证明

## 定理陈述

SCVC模空间 M = CP^2 x S^1 上的度规在(kappa, Z_eff)坐标下是对角的。
因此共价能和离子能独立可加——Pauling公式的加号是几何定理。

---

## 证明 (5步)

### 步骤1: 积流形结构

SCVC模空间 = CP^2 x S^1 (直积)

CP^2: 复射影平面 (实4维)
  承载电磁U(1)丛
  Z_eff = CP^2上矩映射的值 (连续坐标)

S^1: 圆周 (实1维)
  承载涡旋缠绕
  kappa = S^1上缠绕数 (离散拓扑不变量)

这是微分几何中的直积流形, 不是扭曲/纤维化积。

### 步骤2: 积度规

直积流形上的自然度规 = 各因子度规之和:
g(CP^2 x S^1) = g_CP^2 + g_S^1

在坐标(x^i on CP^2, theta on S^1)下:
g_{i,theta} = 0 (对所有i)
g_{theta,i} = 0 (对所有i)

度规是严格分块对角的。这是积流形的定义性质。

### 步骤3: 能量泛函的分离

静态构型的能量泛函:
E = 积分 d^Dx [g_{mu,nu} partial^mu phi partial^nu phi + V(phi)]

由于度规分块对角, 动能项分离:
E_kin = E_kin(kappa) + E_kin(Z_eff)

势能V若保持积结构, 也分离:
V = V_CP^2(Z_eff) + V_S^1(kappa) + V_int

但V_int=0 (见步骤4-5)。因此:
E_total = E(kappa) + E(Z_eff)

### 步骤4: T^3对称性保护

CP^2是toric簇, 有T^2=(S^1)^2作用, 三个不动点。
S^1有U(1)作用。

全对称群: T^3 = T^2(CP^2) x U(1)(S^1)

任何T^3-不变张量(度规, 联络, 曲率)必须保持该分块对角形式。
混合CP^2和S^1坐标的交叉项g_{i,theta}会破坏T^3对称性
(将T^2和U(1)作用混合), 因此被对称性禁戒。

### 步骤5: 拓扑保护

kappa是离散拓扑不变量: kappa in Z (缠绕数)
Z_eff是连续参数: Z_eff in R_+ (实正数)

作用量中的交叉项:
S_int ~ 积分 kappa * f(Z_eff)

但kappa的 导数 为零(离散量), 且kappa出现在作用量中
必须通过拓扑项(如Wess-Zumino项), 这些拓扑项不耦合到
连续的Z_eff。

任何kappa-Z_eff交叉项要么为零(离散量的导数),
要么破坏T^3对称性。两者都被排除。

## 结论

CP^2 x S^1的积流形结构 + T^3对称性 + kappa的拓扑量子化
=> 度规严格分块对角
=> 能量泛函分离: E = E(kappa) + E(Z_eff)
=> 共价(kappa依赖)和离子(Z_eff依赖)贡献独立可加
=> Pauling公式的加号是几何定理, 非经验发现。
