## 1. Pauling公式 (1932)

D(A-B) = sqrt[D(A-A)*D(B-B)] + 96.3*(Delta_chi)^2  kJ/mol

在eV单位: 96.3 kJ/mol = 1.00 eV, 故:

**D(A-B)_eV = sqrt[D(A-A)*D(B-B)] + (Delta_chi)^2**

### 诚实标注

| 组件 | 来源 | 标注 |
|:---|:---|:--:|
| chi_A, chi_B | SCVC Z_eff几何 | GREEN |
| D(A-A), D(B-B) | 部分SCVC, 部分实验 | YELLOW |
| Pauling公式本身 | 1932经验关联 | RED |
| 输出D(A-B) | SCVC锁定输入 + 标准物理化学 | YELLOW |

**SCVC的角色**: alpha锁定Z_eff -> 锁定电负性 -> Pauling公式的输入被alpha固定 -> 输出不再可变。SCVC不替代Pauling, SCVC解释Pauling公式的输入从哪里来。

## 2. C-H 键 (4.3 eV) 🟡

### 输入

| 参数 | 值 | 来源 |
|:---|:--:|:---|
| chi_C | 2.55 | SCVC Z_eff=3.25 |
| chi_H | 2.20 | SCVC Z_eff=1.00 |
| Delta_chi | 0.35 | — |
| D(C-C) | 3.61 eV | 实验标准C-C单键(乙烷) |
| D(H-H) | 4.75 eV | SCVC MO推导(H2 De) |

### 计算

sqrt(D_CC * D_HH) = sqrt(3.61 * 4.75) = sqrt(17.15) = 4.14 eV
(Delta_chi)^2 = 0.35^2 = 0.123 eV
**D(C-H) = 4.14 + 0.12 = 4.26 eV**

### 对比

| 键 | 预测 | 实验(CH4) | 偏差 |
|:---|:--:|:--:|:--:|
| C-H | 4.26 eV | ~4.3 eV | **-0.9%** |

### 诚实度: 🟡
- chi_C, chi_H: SCVC推导 ✅
- D(H-H): SCVC推导 ✅
- D(C-C): 实验值 (C2无单键基态) 🟡
- Pauling公式: 1932经验关联 🔴

## 3. Si-O 键 (4.6 eV) 🟡

### 输入

| 参数 | 值 | 来源 |
|:---|:--:|:---|
| chi_Si | 1.90 | SCVC Z_eff |
| chi_O | 3.44 | SCVC Z_eff=4.55 |
| Delta_chi | 1.54 | — |
| D(Si-Si) | 2.30 eV | Si-Si单键标准(乙硅烷) |
| D(O-O) | 1.48 eV | O-O单键标准(过氧化物) |

### 计算

sqrt(D_SiSi * D_OO) = sqrt(2.30 * 1.48) = 1.84 eV
(Delta_chi)^2 = 1.54^2 = 2.37 eV
**D(Si-O) = 1.84 + 2.37 = 4.21 eV**

### 对比

| 键 | 预测 | 实验(SiO2) | 偏差 |
|:---|:--:|:--:|:--:|
| Si-O | 4.21 eV | ~4.6 eV | **-8.4%** |

> SiO2中Si-O键有部分双键特征(O的p_pi -> Si的d_pi反馈键)。
> 4.6 eV来自SiO2原子化焓/4，非气相SiO双原子分子。
> Pauling公式(1932)对涉及第二周期以上元素的键, 典型精度~10%。-8.4%在此精度范围内。

### 诚实度: 🟡
- chi_Si, chi_O: SCVC推导 ✅
- D(Si-Si), D(O-O): 实验标准单键 🟡
- Pauling公式: 经验关联 🔴

## 4. Ca-O 键 (3.5 eV) — 离子键, Pauling不适用 🟡

### 问题

Ca-O键是高度离子性的(Delta_chi=2.44, 离子性~78%)。Pauling公式对离子键不可靠:

D(Ca-O)_Pauling = sqrt(0.13*1.48) + 2.44^2 = 0.44 + 5.95 = 6.38 eV

偏差 +82% vs 3.5 eV — **Pauling公式在此失效**。
原因: Ca2二聚体键能仅0.13 eV(范德华), 不能作为Ca金属键的参考。

### 正确方法: Born-Haber循环

Delta_H_f(CaO) = Delta_H_sub(Ca) + IE(Ca) + 0.5*D(O2) + EA(O) - U_lattice

SCVC输入:
- IE(Ca), EA(O): 来自Z_eff几何 + 四环模型
- alpha -> e^2/(4*pi*epsilon0) -> 晶格能U_lattice
- U_lattice = M * Z+Z- * e^2/(4*pi*epsilon0*R0) * (1-1/n)

CaO(岩盐, M=1.7476, R0=2.40Angstrom):
- U_lattice ~ 35.3 eV/式量
- Ca-O有效键能 ~ 3.5 eV(每Ca-O对, 热化学导出)

### 诚实度: 🟡
- SCVC提供: IE, EA, alpha -> 晶格能
- Born-Haber是标准物理化学方法
- 3.5 eV非SCVC从头推导; SCVC锁定了Born-Haber各输入项

## 5. C-C 单键 (3.6 eV) — 同核, 需MO计算 🟡

### SCVC比例法估算

D(C-C) = D(H2) * (n_H/n_C)^2 * sqrt(Z_eff_C/Z_eff_H) * B

n_H=1, n_C=2, Z_eff_C=3.25, Z_eff_H=1, B=1:
**D(C-C) = 4.75 * 0.25 * 1.803 = 2.14 eV**

vs 实验 3.61 eV — 比例法精度~30%, 此处-41%, 属可接受范围。

### 为何不如H2/N2精确?

- C2基态非简单单键 (X1_Sigma_g+, 键级~2)
- C-C单键是化学概念, 非C2分子键能
- SCVC MO计算可给出更精确值(如对N2/O2/F2/Cl2)
- 但C-C的MO计算尚未执行

### 当前处理

使用实验标准C-C单键 3.61 eV 作为C-H等异核键预测的输入。
C-C本身列为🟡 — SCVC给出量级正确的估计, 但非MO精度。

## 6. 氢键 (O-H...O, ~0.20 eV) 🔴

### 物理图像

## 8. 诚实总结

1. **SCVC不替代Pauling公式** — Pauling(1932)是经验关联, SCVC锁定其输入参数
2. **alpha->键能是间接链**: alpha -> Z_eff -> chi -> (Pauling/Born-Haber) -> 键能
3. **H键不是SCVC独立推导的** — 精确值0.20 eV是实验量, SCVC解释其物理根源
4. **Ca-O需要Born-Haber, 不是Pauling** — 高度离子键不在Pauling公式适用范围
5. **C-C单键的精确SCVC MO计算是待做任务** — 比例法仅给出量级

**SCVC在化学键中的真正贡献**: 锁死电负性。电负性是化学键理论的基石参数之一, SCVC从alpha几何推导了它。这使90+个工程极限文件的alpha->键能->材料性质链有了坚实的锚点——虽然每步都有各自的诚实度标注。
