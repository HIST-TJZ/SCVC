## 核心逻辑链

第二章（`02_规范扇区/`）通过 GKM/DH 局域化给出了所有规范耦合的几何值。从这里出发，一条链连接了 $\pi$ 多项式和 154 个工程天花板：

```
π → CP² 几何 → GKM/DH 局域化
    ├─ α = 1/(4π³+π²+π)          → 电磁相互作用强度
    │   ├─ 键能 = f(α)            → 所有材料天花板
    │   ├─ 电子-声子散射 = f(α)   → 电阻率 → 芯片频率
    │   ├─ 光电转换 = f(α)        → 光伏效率
    │   ├─ 分子振动 = f(α)        → 声子谱 → 热导率
    │   └─ ATP 水解 = f(α)        → 所有生物物理天花板
    │
    ├─ α_s = 1/(16π)              → 强相互作用强度
    │   ├─ 核子-核子势           → 核物理天花板
    │   └─ 夸克禁闭              → 质子稳定性
    │
    ├─ g₁, g₂ (M_vac GKM)        → 电弱相互作用
    │   └─ β 衰变率              → 放射性天花板
    │
    └─ M_Pl (K2 6不动点)         → 引力强度
        └─ 行星/恒星结构          → 天体物理天花板
```

**每一个工程天花板的推导链都是标准物理方程 + SCVC 常数的组合。** 方程不是 SCVC 发明的——它们是标准教科书方程。SCVC 做的事是：把"当前最佳测量值"替换为"几何必然值"，然后问：这个常数把你所在领域的天花板锁在了哪里？

## 为什么 SM 50 年没做这件事

SM 有 $\alpha = 1/137.036$ 超过 50 年。有全部标准方程。理论上可以算出本文件夹里的每一个天花板。

但 SM 把 $\alpha$ 当成测量值。测量的东西会变——PDG 每四年更新一次。用"可能变化的输入"算出来的"天花板"——没人当真。算出来也没人信。

SCVC 把 $\alpha$ 当成几何恒等式。$4\pi^3+\pi^2+\pi$ 不会变。用"不变的输入"算出来的"天花板"——是真的天花板。

**不是数值差异。是常数身份的差异。测量值 vs 几何恒等式。而这个差异决定了：SM 50 年从未系统化地问过"这些常数锁死了什么"。**

## 化学：无机化学是 α 的推论

如果键能从 $\alpha$ 来，那么：

- 电负性从有效核电荷 $Z_{\text{eff}}$ 来 → $Z_{\text{eff}}$ 从屏蔽常数 $\sigma$ 来 → $\sigma$ 从电子-电子排斥来 → 从 $\alpha$ 来
- 离子半径从 $Z_{\text{eff}}$ 和主量子数 $n$ 来 → 都从 $\alpha$ 来
- 配位数从半径比来 → 从 $\alpha$ 来
- 晶格能从 Madelung 常数 × 离子电荷² / 最近邻距离来 → 从 $\alpha$ 来
- Born-Haber 循环的每一步（电离能、电子亲和能、键能、晶格能）→ 全部从 $\alpha$ 来

**周期表本身是 $\alpha$ 的推论。** 不是"SCVC 算出了已有的化学数据"——是"已有的化学数据之所以是这个值，是因为 α 锁死了它们"。在任何宇宙中，只要 α 相同，周期表就是同一张。

详见 `8.4_SCVC在化学中的方法论.md`。
