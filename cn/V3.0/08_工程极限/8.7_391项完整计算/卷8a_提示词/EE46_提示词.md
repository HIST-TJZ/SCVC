# SCVC工程极限：爆轰/爆炸 — 最大爆速+最大爆炸威力

**任务**：从SCVC键能出发，推导炸药和爆轰的物理上限。

**工程问题：**

### §1. 爆速上限（Chapman-Jouguet）
- 爆速 D = √(2(γ²−1)Q)，Q为爆炸热（kJ/g），γ为产物绝热指数
- Q由化学键重组决定：断键吸热+成键放热→净能量
- N≡N（9.8 eV）是最强的产物键→最大Q来自生成N₂的炸药
- HMX/RDX ~9-10 km/s → 是否已接近化学炸药天花板？
- 理论最大爆速：金属氢？聚合氮（全N≡N网络）？
- **化学炸药的最大爆速？Octaazacubane（N₈）的理论爆速？**

### §2. 最大能量密度
- 最理想的爆炸反应：所有产物都是N₂（每分子 ~9.8 eV）
- 理论最大 Q_max ∝ (生成N₂的能量 − 反应物键能)/分子量
- 金属氢：H₂ → 2H → H₂（金属→分子）→ 能量 ~1 eV/H原子
- **最大爆炸能量密度（kJ/g）vs 已实现的最大值？**

### §3. 核爆 vs 化爆的物理鸿沟
- 化爆最大 ~10 kJ/g（理论）
- 核裂变 ~8×10⁷ kJ/g（²³⁵U）
- 核聚变 ~3×10⁸ kJ/g（D-T）
- 反物质 ~9×10¹⁰ kJ/g（E=mc²）
- 这四层阶梯之间没有"中间态"——α和α_s之间的鸿沟就是原因
- **为什么不存在"中等威力"的爆炸？（化学键能 vs 核结合能差了7个量级）**
