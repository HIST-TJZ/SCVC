# SCVC工程极限 E153：大气压生命极限

**问题**: 深海鱼（1100atm）vs 喜马拉雅跳蛛（0.3atm）——生命的气压范围是锁死的吗？

**任务**: 从SCVC常数推导碳基生命的大气压生存区间。

## §1. 物理链
- 低压极限：水在体温下沸腾 → 37°C水的饱和蒸气压~0.06atm → 绝对下限
- 高压极限：蛋白质变性 → 压力使水分子进入蛋白质内部→破坏疏水核心
- 疏水相互作用由水的H键网络决定 → 从α推导
- 脂双层在高压下由液晶→凝胶相变→膜失去功能
- 气体溶解度为Henry定律 → O₂/N₂在高压下中毒

## §2. 请计算
- 碳基生命的气压绝对下限（水沸腾+气体交换）
- 碳基生命的气压绝对上限（蛋白质变性+膜相变+N₂麻醉）
- 深海鱼(~1100atm)在SCVC区间的什么位置？
- 不同的溶剂（非水基生命）→区间如何移动？
