# SCVC工程物理 E116: 权力的物理学——一个社会能承受多少不平等？

**问题**: Dunbar150锁死了扁平组织的上限。超过150人必须用等级制压缩信息。但等级制会产生不平等。最大可持续不平等是多少？

**任务**: 从SCVC推导社会组织的物理极限。

---

## §1. 为什么等级制是必然的

Dunbar150: 你可以直接管理×150个人(记住每人的历史)
超过150: 你无法追踪所有人→需要中间层

等级制 = Dunbar150的递归应用:
- 每层管理者可以直接管理~150人/单元
- N人的组织需要 log₁₅₀(N)层

## §2. 不平等的信息论定义

权力 = 信息不对称:
- 上层知道下层的信息
- 下层不知道上层的信息
- 信息差 = 权力

最大可持续信息差 = f(口语带宽, 记忆衰减, 博弈均衡)

## §3. 请计算

1. 最大组织层数: log₁₅₀(8e9)≈4.5层(全人类)
2. 信息流通量每层衰减率(39bits/s的缓冲)
3. 最大可持续不平等比 = f(层数, 信息衰减, 博弈均衡)
4. 为什么历史上所有极端不平等社会都崩溃了？(信息差超过博弈均衡)
5. AI社会的组织结构：无Dunbar限制→完全扁平是否可能？
