# SCVC工程极限 E142：最大冰雹尺寸

**问题**: 记录冰雹~1kg(直径~20cm)。有上限吗？

**任务**: 从SCVC常数推导冰雹最大尺寸的物理天花板。

## §1. 物理链
- 冰雹增长 = 过冷水滴碰撞+冻结→需要强上升气流托住
- 上升气流上限 = 大气不稳定能量(CAPE)→从水汽凝结潜热（H键能）推导
- 冰雹终端速度 ∝ √(直径)→当终端速度>上升气流速度→掉落
- 最大尺寸 = 碰撞效率×过冷水含量×上升气流持续时间
- 还有冰雹在上升/下降循环中的融化损失

## §2. 请计算
- 地球大气最大CAPE→最大上升气流速度
- 对应能托住的最大冰球直径
- 与记录~20cm对比
- 超级单体的物理极限
