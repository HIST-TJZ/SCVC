# SCVC工程极限 E134：永磁体磁场上限——剩磁的绝对天花板

**问题**: NdFeB的1.4T是否已接近物理极限？室温永磁体还能更强吗？

**任务**: 从SCVC常数推导永磁体剩磁和磁能积的绝对上限。

---

## §1. 永磁体的SCVC物理链

### 1.1 每一步都是α锁死的
- 电子磁矩 μ_B = eℏ/(2m_e) → ℏ和m_e都从SCVC来
- 各向异性场 H_A → 晶体场分裂 → 由配位离子的静电势决定 → 由α（电磁耦合）决定
- 交换耦合 J → 自旋-自旋相互作用 → 由α和泡利不相容决定
- 居里温度 T_C ∝ J/k_B → 决定室温下剩磁的保持率

### 1.2 剩磁上限
- 理论最大剩磁 B_r = μ_0 × M_s（饱和磁化强度）
- M_s = n × μ_B × 每个磁性离子的玻尔磁子数
- n = 晶体结构中的磁性离子密度
- 这个密度由离子半径（α→屏蔽→原子大小）决定

## §2. 请计算

### 2.1 最大可能饱和磁化强度
- 搜索周期表中自旋最高的离子（Fe³⁺=5μ_B, Gd³⁺=7μ_B, Dy³⁺=10μ_B...）
- 最高自旋×最高堆积密度 → 最大M_s
- 堆积密度从SCVC离子半径推导

### 2.2 室温保持率
- 居里温度/室温比 → 室温剩磁占饱和磁化的比例
- 高自旋通常意味着大磁矩但也可能低T_C
- 最优折中在哪里？

### 2.3 最大磁能积(BH)_max
- (BH)_max ≤ B_r²/(4μ_0)（理论极限）
- 代入最优B_r → 绝对天花板
- NdFeB当前~474 kJ/m³，还有多少空间？

### 2.4 不用稀土的永磁上限
- 稀土(钕、钐、镝)的高自旋来自4f电子
- 3d金属(铁、钴)最高自旋只有~2.2μ_B/原子
- 无稀土磁体是否被物理锁死在远低于NdFeB的水平？
