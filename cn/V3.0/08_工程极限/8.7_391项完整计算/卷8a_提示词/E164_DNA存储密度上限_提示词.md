# SCVC工程极限 E164：DNA数字存储密度上限

**问题**: 理论~455 EB/克（1EB=10⁹GB）。实际做到~200MB/克。差距10⁹倍→已经是非常正面的结果。

**任务**: 从SCVC常数确认/修正DNA存储密度的理论极限。

## 物理链
- 每bp信息量=2bits，bp间距=0.34nm，分子量~650 Da
- → 理论密度 = 2bits/(650×1.66×10⁻²⁴g) = 1.85×10²¹ bits/g = 215 EB/g
- 但考虑冗余（纠错码、引物、索引）→ 有效密度降
- 碱基对的H键能→决定了复制保真度→决定了纠错冗余需求
- 最小冗余从信息论+物理错误率（~10⁻⁹/碱基）推导
