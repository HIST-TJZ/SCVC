# SCVC工程极限：医学成像 — 分辨率+剂量+安全边界

**任务**：从SCVC的α（离子化）、k_B T（热噪声）和ℏ（量子噪声）出发，推导医学成像的物理极限。

**工程问题：**

### §1. X射线/CT
- 空间分辨率：由X射线源尺寸+探测器像素+散射决定
- 剂量极限：每mSv的癌症风险 ~5%/Sv → 诊断CT ~1-10 mSv
- 对比度分辨率：由光子统计（散粒噪声 √N）决定
- **给定安全剂量下的最小可分辨病灶尺寸？**
- 光子计数CT能否突破传统CT的剂量效率？

### §2. MRI
- 空间分辨率：~mm，受限于梯度强度+采集时间
- SNR ∝ B₀^(7/4)（近似）→ 更高场更强信号
- 人体极限：B₀ ~ 7-11T（组织介电效应+神经刺激）
- **MRI的终极空间分辨率？能否到10 μm级？**
- 超极化技术能否突破热平衡极化极限？

### §3. 超声
- 分辨率 ~λ = c/f → 高频超声穿透浅，低频分辨率差
- 频率上限 ~50-100 MHz（组织衰减 ~1 dB/cm/MHz）
- **超声的最小可分辨结构？能否替代光学显微镜？**

### §4. 光学成像（OCT/荧光/光声）
- OCT分辨率 ~10 μm，深度 ~2-3 mm（散射限制）
- 光声：分辨率 ~50 μm，深度 ~cm（声学检测+光学激发）
- **光学体内成像的深度×分辨率乘积上限？**

### §5. 工程结论
- 早期癌症检测的物理极限——最小可检出肿瘤直径？
- 无创活体显微镜是否可能？
