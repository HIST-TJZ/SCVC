# SCVC工程极限 E157：飞机最快速度——大气层内飞行的物理天花板

**问题**: SR-71 ~Mach 3.3, X-15 ~Mach 6.7, 高超音速武器~Mach 20。大气层内飞行的绝对速度上限在哪？不是一个墙，是一层一层撞上去的。

**任务**: 从SCVC常数推导大气层内飞行的多级速度天花板，区分战斗机和客机的实际限制。

---

## §1. 五层天花板（速度从低到高）

### 第一层：螺旋桨极限（~Mach 0.7）
- 桨尖速度接近Mach 1→激波→效率崩塌
- 不是引擎不够强，是空气动力学锁死
- 这与SCVC的关联：声速从α（空气比热比γ→分子自由度）推导

### 第二层：涡轮叶片熔化极限（~Mach 3-4）
- 涡轮进气温度 ∝ 驻点温度 ∝ M²
- 叶片材料耐温上限 → 从金属键能（α）推导
- 冷却技术（气膜冷却）可以推高，但有物理极限
- 这是SR-71撞到的墙（进气温度~400°C，钛合金极限）
- 客机撞这里更早（涡扇~Mach 0.85，因为效率不是推力）

### 第三层：冲压发动机极限（~Mach 5-6）
- 超过涡轮极限→必须用冲压/超燃冲压
- 燃烧室内驻点温度→空气开始解离（N₂→2N，需要9.8eV）
- 解离吸收热量但不产生推力→"解离墙"
- N≡N键能从α_s（强核）决定 → SCVC可精确给出解离温度

### 第四层：热结构极限（~Mach 8-12）
- 机身表面温度 ∝ M² → 辐射平衡温度
- 材料熔点从键能（α）来
- 钛合金~1668°C, 陶瓷~3000°C+
- 主动冷却的理论上限
- X-15撞到~Mach 6.7时机身温度~650°C

### 第五层：空气液化/等离子体墙（~Mach 20-25）
- 驻点温度>5000K → N₂,O₂完全解离→等离子体
- 等离子体不产生气动升力→飞行器坠落
- 通信黑障（等离子体屏蔽无线电）
- 这是大气层内飞行的绝对天花板

## §2. 客机 vs 战斗机的不同天花板

### 客机（经济性限制）
- 额外约束：燃油效率 → 最优巡航在Mach 0.85（跨音速阻力最低点附近）
- 协和式Mach 2已证明技术上可行但经济上失败
- 声爆限制 → 陆地上空超音速商业飞行被禁
- 客机的实际天花板 = 物理限制 ∩ 经济限制 ∩ 法规限制

### 战斗机（推力+热管理）
- 不需要经济性 → 只需要"能飞到"
- 撞的是涡轮叶片熔化+热结构
- 五代机（F-22超巡~Mach 1.8）→ 不开加力的超音速巡航
- 六代机目标~Mach 3+（需要变循环发动机+更好的热管理）
