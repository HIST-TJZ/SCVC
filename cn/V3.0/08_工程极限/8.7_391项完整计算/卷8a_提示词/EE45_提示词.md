# SCVC工程极限：量子网络 — 纠缠分发距离+全球量子互联网

**任务**：从SCVC光纤损耗（Rayleigh散射由α决定的极化率导出）和量子中继器级联出发，推导全球量子网络的天花板。

**工程问题：**

### §1. 光纤损耗的SCVC起源
- Rayleigh散射 ∝ n⁸ p²/(λ⁴)，p为光弹系数，n为折射率
- n由极化率（α决定）导出 → 损耗由α锁死
- 硅光纤在1550 nm的理论最小损耗 ~0.14 dB/km
- 当前最佳 ~0.15-0.16 dB/km（已接近SCVC极限！）
- **光纤损耗的最后提升空间？~10%**

### §2. 无中继纠缠分发
- 量子信号不可放大（no-cloning定理）→ 损耗直接限制距离
- 光子到达概率 = 10^(−αL/10)，α ~0.15 dB/km → 每10 km损失~30%
- 在500 km处→10⁻⁷·⁵ → 基本不可能
- 卫星纠缠分发（自由空间）：无光纤损耗，但衍射+大气衰减
- **无中继量子通信的最大距离？地基 vs 星基？**

### §3. 量子中继器
- 纠缠交换 + 纠缠纯化 + 量子存储
- 存储寿命 τ_mem 限制了中继间隔 → 间隔 ~cτ_mem/2
- 当前τ_mem ~ms-min → 间距 ~100-10⁴ km
- 超导qubit T₂ → s级（E8）→ 间距 ~10⁵ km（理论上地球任意两点）
- **实现全球量子网络需要几个中继站？**
- **量子存储T₂达到秒级后——中继器是否不再需要？**

### §4. 量子密钥分发（QKD）速率
- 单光子源 → 每脉冲1个光子 → 光纤损耗后 → 探测器效率
- 密钥率 R ≤ f_source × η_channel × η_detector
- 100 km光纤 → 10⁻⁷·⁵ → 每10⁷个脉冲才1个安全bit
- **实用QKD距离/速率trade-off？城域网 vs 骨干网？**

### §5. 工程结论
- "全球量子互联网"——哪个部分物理允许哪个部分物理禁止？
- 量子中继器是"10年可解决"还是"永远不可能"？（SCVC答案：秒级T₂后→可能）
- 经典互联网不会被量子互联网取代——只有安全关键的通信才用量子
