**工程问题：**

### §1. 嗅觉极限
- 单个气味分子与嗅觉受体的结合能：E_bind ~0.3-1 eV

- K_d = exp(−E_bind/k_B T) → 结合能越强检测限越低
- 最强非共价结合 ~1-3 eV → K_d可到fM-pM
- 人鼻对硫醇检测 ~ppb → 受体已接近单分子灵敏度？
- **SCVC锁死的最小可嗅浓度（分子数/升）？狗的嗅觉为何比人灵敏几个量级——是受体更多还是结合更强？**

### §2. 化学战剂/爆炸物探测

- 单分子荧光检测→已实现单分子灵敏度
- 选择性 vs 灵敏度的trade-off（弱结合→低选择性，强结合→不可逆）
- **给定目标分子的结合能——最小可探测浓度的SCVC公式？**

- 需要可逆 → 结合能必须在1-3 eV → 限制了检测限
