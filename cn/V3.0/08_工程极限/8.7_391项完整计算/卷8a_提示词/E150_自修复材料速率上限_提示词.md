# SCVC工程极限 E150：自修复材料速率上限

**问题**: 自修复材料能修多快？有物理天花板吗？

**任务**: 从SCVC常数推导材料自修复速度的绝对上限。

## §1. 物理链
- 微胶囊型：胶囊破裂→单体毛细扩散至裂纹→聚合
- 扩散时间 ∝ 距离²/D → D从α（溶剂-单体相互作用）推导
- 聚合速率 ∝ 单体碰撞频率 × exp(-E_a/k_B T) → E_a=活化能从键能来
- 血管网络型：修复剂由泵送→流速上限 = 泊肃叶定律+黏度（α）
- 生物自修复（骨骼/肝脏）→由细胞分裂周期~24h锁死
- 非生物材料可以更快→因为不需要细胞分裂

- 聚合反应速率上限
