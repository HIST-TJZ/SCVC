# SCVC工程极限：最强酸+最强碱+最强氧化剂/还原剂

**任务**：从SCVC键能和质子亲和力出发，推导化学酸碱强度和氧化还原电位的理论上限。

**工程问题：**

### §1. 最强酸
- 酸强度由质子亲和力（PA）决定：HA → H⁺ + A⁻
- PA由H-A键能决定：键越弱→酸越强
- 最弱H键：H和惰性气体/重卤素 → H-I键能 ~3.0 eV
- 超强酸：SbF₅ + HF → H₂F⁺SbF₆⁻（Hammett酸度H₀ ~-28）
- 碳硼烷酸（carborane acid）：H(CHB₁₁Cl₁₁) → 史上最强孤立酸
- **SCVC锁死的最大酸度（最低H₀值）？H⁺能否完全"裸"——没有共轭碱的稳定化？**

### §2. 最强碱
- 碱强度由质子亲和力决定：B + H⁺ → BH⁺，PA越大→碱越强
- 最大PA由B-H键能+电离能决定
- 烷基锂（BuLi）→ PA ~400 kcal/mol → ~17 eV
- **最大质子亲和力？能否超过N≡N键能9.8 eV对应的值？**

### §3. 最强氧化剂/还原剂
- 氧化剂：电子亲和力EA最大（卤素 ~3-4 eV）+ 高电负性
- 还原剂：电离能最小（碱金属 ~4-5 eV）+ 低电负性
- 电化学窗口受限于溶剂（水 ~1.23 V，非水 ~6-8 V）
- **非水溶剂中的最大氧化还原电位？由什么锁死？**

### §4. 工程结论
- 电池电解液的"不可还原"溶剂设计方向
- 工业催化中的超强酸/超强碱应用天花板
- 是否存在"溶解一切的酸"？（SCVC答案：不能，受限于特定键能）
