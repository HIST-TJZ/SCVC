# SCVC工程极限：无线能量传输 — 近场耦合效率×距离上限

**任务**：从SCVC锁定的介电常数（α→极化率）和磁导率出发，推导无线能量传输的物理极限。

**工程问题：**

### §1. 感应式（近场）耦合
- 效率 η = k²Q₁Q₂/(1+√(1+k²Q₁Q₂))²，k为耦合系数，Q为品质因数
- k²由线圈几何和间距决定 → 最大k²受限于线圈尺寸比和距离
- 线圈Q值：导体损耗∝1/σ（金属电导率由α决定自由电子密度）+ 辐射损耗
- **给定线圈半径r——最大有效充电距离？效率>90%的距离/半径比？**
- 手机无线充 ~5-10 mm → 能否推到 ~1 m（房间级无线供电）？

### §2. 谐振式（MR-WPT）
- 利用相同谐振频率的两个LC回路 → 距离可以到线圈直径的几倍
- 谐振Q值上限由辐射损耗和欧姆损耗决定
- 辐射损耗 ∝ (r/λ)³——频率越高辐射越强
- **最优频率？最大距离比？效率>80%时的 d/r_max？**

### §3. 远场（微波/激光传能）
- Friis传输公式：P_r/P_t = G_t G_r (λ/4πd)²
- 天线增益G ∝ 面积/λ² → 衍射限制
- 大气衰减窗口（~2-10 GHz，~35-94 GHz，~红外/可见光）
- **1 km 距离传 1 kW 的最小发射天线尺寸？**
