# SCVC工程极限：光学/光子学 — 激光损伤阈值 + 非线性极限

**任务**：从SCVC锁定的键能和电子结构出发，推导光学材料的基本极限。

**工程问题：**

### §1. 激光损伤阈值（LIDT）
- 多光子电离 → 电子从价带到导带 → 雪崩电离 → 损伤
- 电离阈值由带隙决定（SCVC最大带隙 ~10-15 eV）
- 脉宽依赖性：fs脉冲（多光子主导）vs ns脉冲（热积累）
- **从SCVC推导的理论最大LIDT（J/cm²和W/cm²）？**
- 能否实现"永不损坏的镜片"？

### §2. 非线性光学极限
- 二阶非线性 χ⁽²⁾：非中心对称晶体 → 最大二阶极化率
- 三阶非线性 χ⁽³⁾：所有材料 → n₂的最大值
- 光克尔效应、自聚焦、超连续谱产生的极限
- **SCVC是否限制了非线性效率？能否实现单光子级别的全光开关？**

### §3. 折射率范围
- 可见光波段：n ≈ 1.3（冰晶石）到 ~4（Ge, Te）
- 折射率由极化率决定 → 原子序数越大极化率越大
- 但原子不能太大（否则可见光被吸收）→ 实际范围
- **SCVC锁死的可见光折射率范围？能否有 n>5 的透明材料？**

### §4. 工程结论

- "完美透镜"（n→∞, 无吸收）— 是否被SCVC禁止？
- 全光计算（光子代替电子）的物理可行性？
