# SCVC工程极限：碳捕获 — 直接空气捕获(DAC)的能量下限

**任务**：与E10海水淡化同一逻辑——反混合的最小热力学功。从SCVC锁定的k_B T和CO₂浓度出发。

**工程问题：**

### §1. 热力学最小功
- CO₂浓度：大气 ~420 ppm → 分压 ~42 Pa
- 反混合自由能：W_min = k_B T × [浓度项 + 混合熵]
- 详细计算：ΔG = RT ln(p₀/p_CO₂) → 分离1 mol CO₂的最小功
- 大气420 ppm → W_min ≈ 20 kJ/mol CO₂ ≈ 0.13 kWh/kg CO₂
- **捕获1吨CO₂的理论最小能耗？**（约 130 kWh）

### §2. 吸收/吸附法的额外能耗
- 化学吸收（胺）：溶液再生需要加热→水蒸发潜热 ~0.42 eV/分子
- 胺-CO₂结合能 ~0.5-1.0 eV → 脱附需要更高温度
- 实际能耗 ~150-300 kWh/tCO₂（当前）vs 理论 ~130 kWh
- **接近理论极限的剩余空间？~2×**

### §3. 膜分离
- CO₂/N₂分离因子由膜选择性决定
- 选择性由溶解度和扩散率差异决定 → 上限由分子尺寸和极性决定
- CO₂分子动力学直径 ~3.3 Å vs N₂ ~3.64 Å → Robeson上限
- **膜法的最小能耗？能否低于吸收法？**

### §4. 直接电化学捕获
- CO₂ + e⁻ → CO₂⁻（活化为草酸盐/甲酸盐）
- 氧化还原电位 ~-1.9 V vs SHE
- 电子+离子+CO₂三者在电极处汇聚的效率
