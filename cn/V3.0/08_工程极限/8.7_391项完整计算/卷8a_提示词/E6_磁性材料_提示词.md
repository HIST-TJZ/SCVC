# SCVC工程极限：磁性材料上限 + 自旋电子学

**任务**：从SCVC的涡旋环自旋图像出发，推导磁性材料的基本极限。

**SCVC已有输入：**
- 电子涡旋环 = 费米子，环量 = h/m_e
- Magnus力、Biot-Savart涡旋相互作用
- Pauli排斥 = 拓扑排斥（同向涡旋环不能重叠）
- 自旋-轨道耦合（从α推导）

**工程问题：**

### §1. 最大磁化强度
- 每个原子磁矩 μ ∼ μ_B = eℏ/2m_e
- 饱和磁化强度 M_s = n × μ_B（n为磁性原子密度）
- Fe ~2.2 T, NdFeB ~1.4 T → 接近上限？
- **理论最大M_s（从原子密度和μ_B）？能否超过3 T？**

### §2. 最高居里温度
- T_c由交换耦合J决定（海森堡模型）
- 交换耦合J从轨道重叠和库仑积分推导
- 轨道重叠由SCVC键能/键长给定量级
- **T_c的理论上限？是否有室温以上的铁磁/反铁磁未被发现？**

### §3. 自旋电子学
- 自旋极化电流、自旋Hall效应
- 自旋-轨道耦合强度从α推导
- 自旋弛豫时间、自旋扩散长度
- **室温自旋电子学的可行性？最大自旋扩散长度？**
