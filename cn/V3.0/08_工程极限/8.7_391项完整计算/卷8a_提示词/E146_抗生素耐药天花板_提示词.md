# SCVC工程极限 E146：抗生素耐药天花板

**问题**: 超级细菌能同时对多少种抗生素耐药？演化极限在哪？

**任务**: 从SCVC常数推导细菌耐药性的物理/演化上限。

## §1. 物理链
- 每种耐药基因有适应度成本→在没有抗生素时, 耐药菌生长慢
- 同时携带N个耐药基因→总成本 ∝ N → 生长率降
- 基因组的物理大小上限→能塞多少耐药基因
- 水平基因转移速率（接合/转化/转导）→由分子扩散（α决定）
- 突变率~10⁻⁹/代 → 从DNA聚合酶保真度（α→H键识别能）推导
