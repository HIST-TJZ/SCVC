# SCVC工程极限 E154：显示像素密度上限

**问题**: 手机屏幕已到~500 ppi。继续堆像素还有意义吗？衍射极限在哪？

**任务**: 从SCVC常数推导显示设备像素密度的绝对天花板。

## §1. 物理链
- 衍射极限：一个像素的角尺寸 ≥ 1.22λ/D（瞳孔直径~3mm）
- 绿光λ=550nm → 最小可分辨角 ~0.5弧分
- 给定视距→最大有用像素密度
- 手机视距~30cm → 最大有用ppi
- VR视距~5cm → 更高ppi但仍然有衍射上限
- 超过此上限→相邻像素在视网膜上重叠→浪费
