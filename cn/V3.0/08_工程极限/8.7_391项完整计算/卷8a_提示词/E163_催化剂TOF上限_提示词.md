# SCVC工程极限 E163：催化剂转换频率(TOF)上限

**问题**: 酶~10⁶/s，工业催化剂~10²-10⁴/s。天花板如果在10⁸-10⁹→空间巨大→正面。

**任务**: 从SCVC常数推导催化TOF的绝对上限。

## 物理链
- Arrhenius指前因子：k_B T/h ≈ 6×10¹²/s → 理论最大（过渡态理论）
- 但受限于扩散：底物必须先扩散到活性位点
- 扩散控制极限（水溶液）：~10⁹ M⁻¹s⁻¹ → 从α→溶剂黏度→扩散系数
- 多相催化还需考虑：吸附/脱附 → 从α→表面键能
- 产物的脱附可能是速率限制步

## 请计算
- 均相催化（溶液）的TOF天花板
- 多相催化（固体表面）的TOF天花板
- 酶(10⁶)、工业催化剂(10²-10⁴)在区间的什么位置？
- 如果天花板在10⁸-10⁹→工业催化还有10⁴-10⁶倍的提升空间→极大正面
