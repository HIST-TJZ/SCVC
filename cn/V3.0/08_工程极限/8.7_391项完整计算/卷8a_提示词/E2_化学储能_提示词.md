# SCVC工程极限：化学储能密度上限（电池/燃料/超级电容）

**任务**：从SCVC锁定的α和m_e出发，推导化学键储能密度的理论上限，回答"电池能做到多密"。

**SCVC已有输入：**
- α = 1/(4π³+π²+π) → 化学键能、键长全由电磁耦合决定
- m_e = 0.511 MeV → 电子轨道半径、价电子能量
- 已有化学键推导（共价键、离子键、金属键能量和键长）

**工程问题：**

### §1. 理论储能密度上限
- 最强化学键（C≡C, N≡N, 离子键）每键 ~ 8-10 eV
- 最轻原子（Li, Be, B, C）→ 每质量键数最多
- 质量/体积密度上限
- **计算出 Wh/kg 和 Wh/L 的理论最大值**
- 当前锂电 ~300 Wh/kg，汽油 ~12000 Wh/kg（但燃烧不可逆）
- 可逆电化学储能的理论上限是多少？

### §2. 电压上限
- 电化学窗口由HOMO/LUMO gap决定
- HOMO/LUMO gap由α和原子轨道能量决定
- **最大电解液稳定窗口是多少伏？**
- 当前锂电 ~4.2V → 理论上限？

### §3. 功率密度上限
- 离子迁移率 → 由晶格振动频率（∼ω_D）和跳跃势垒决定
- 电解质离子电导率上限
- **最大充放电倍率（C-rate）？能否实现1分钟充满？**

### §4. 工程结论
- 锂电还有多少提升空间？
- 哪些化学体系接近SCVC允许的理论极限？
- 哪些方向根本不可能？（例如"能量密度超过汽油的可逆电池"）
