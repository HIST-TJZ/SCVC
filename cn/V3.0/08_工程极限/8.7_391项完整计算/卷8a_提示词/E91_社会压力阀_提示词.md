## §1. 纯繁殖社会的物理崩溃——假设所有 150 人都是异性恋繁殖对

### 1.1 社交竞争爆炸
- 150 人 → ~75 对繁殖对。但不是随机配对——择偶竞争产生 O(n²) 的社交压力
- 每对夫妻需要维护婚姻关系（高带宽）+ 亲子关系 + 与其他对的关系
- 如果所有成年人都处于"择偶竞争"状态 → **所有关系都被性竞争污染**
- 性嫉妒：每对中每个成员需要监控配偶 + 防御竞争者 → 带宽需求爆炸

### 1.2 社交带宽的 SCVC 计算
- Dunbar 150 人的关系维护：~39 bits/s 口语 ÷ 每日社交时间
- 如果每个关系都是"高紧张度"（含性竞争维度）→ 带宽需求至少翻倍
- 39 bits/s 不够维护 150 个高紧张度关系 → 要么减少人数，要么降低紧张度
- **但减少人数到 ~75 会低于群体生存所需的最小多样性**

### 1.3 后代照顾的资源约束
- 人类后代发育期极长（~15 年）→ 需要大量非父母照顾（alloparenting）
- 如果所有成年人都在繁殖 → 谁来当 alloparent？
- 祖父母？——但祖父母人数受限于世代重叠。叔姨？——如果他们也都在繁殖
- **纯繁殖社会缺少"劳动力冗余"来照顾漫长的后代发育**

### 1.4 社会学习的信息瓶颈
- 文化传递需要非繁殖个体的时间投入
- 如果每个成年人都在照顾自己的后代 → 跨家庭的知识传递断裂
- 39 bits/s 的带宽限制决定了"知识传递"和"个人繁殖成功"之间存在 trade-off

## §2. 非繁殖角色的功能——物理压力阀

### 2.1 减少社交竞争维度
- 同性恋个体退出择偶竞争 → 社交关系从"竞争+合作"降维为"纯合作"
- 每增加一个非繁殖个体 → 减少的社交竞争对数是 O(n_breeding² → (n_breeding-1)²)
- 降低社交热度的效率是超线性的

### 2.2 提供 alloparenting 劳动力
- 非繁殖个体可以投入照顾 nieces/nephews（包容性适应度）
- 在狩猎采集社会，alloparenting 是儿童存活的核心决定因子
- **这个劳动力的 ATP 预算是从"不需要维护自己的繁殖关系"里省出来的**

### 2.3 社会凝聚力和冲突调解
- 非繁殖个体处于社交网络的"中立节点"——不受性竞争影响 → 最适合调解冲突
- 祭司、巫师、长老——很多传统社会中的调解者角色来自非繁殖/非典型性别个体

### 2.4 知识保存和传递
- 当大量成年人投入繁殖时，文化复杂性下降
- 非繁殖个体可以担负"记忆保存"的功能——和 E84（2 bits/s）的长期记忆写入互补

## §3. 最优占比的 SCVC 正向推导

### 3.1 关键参数
- 社交压力函数：S(n_breeding) ∝ (n_breeding)² / (n_total × bandwidth)
- 后代存活函数：P(n_offspring) ∝ n_alloparents / n_offspring
- 总适应度 = P × (1 − S/S_crit) —— 存在最优值

### 3.2 推导要求
- 使用 Dunbar 150、39 bits/s、每日社交时间 ~4-6 小时
- 估计每种关系类型的带宽需求（配偶：~5 bits/s，亲子：~3 bits/s，普通社交：~0.5 bits/s）
- 计算纯繁殖（75 对）的总关系带宽需求 → 是否超过 39？
- 计算使总带宽回到 39 以内的最优非繁殖占比
- 与观测值对比：人类同性恋比例 ~3-10%（文化变幅很大但始终存在）

### 3.3 预测
- 如果比例太低（<1%）→ 社交过热 → 群体分裂或内战
- 如果比例太高（>20%）→ 繁殖不足 → 人口下降
- **最优区间：~5-15%。** 这和人类学、历史学的观测大致吻合

## §4. 为什么这个比例在不同文化/时代变化但永不归零？

- 纯异性恋社会在物理上是不稳定的——任何小扰动都会产生非繁殖个体
- 一旦产生 → 这些个体的存在降低了社交紧张 → 被群体选择保留
- 即使某个文化压制同性恋 → 非繁殖角色会以其他形式出现（独身祭司、未婚姑妈、同性社交圈）
- **SCVC 预言：非繁殖角色在所有人类社会中的占比 > 0%。这不是文化——是物理。**
