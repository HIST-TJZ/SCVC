# SCVC医学 E181：血脑屏障——药物穿透的物理地图

**问题**: 98%的小分子和100%的大分子被BBB阻挡。SCVC能给出"什么能穿过"的物理法则吗？

**任务**: 从SCVC常数推导血脑屏障通透性的物理边界→CNS药物设计地图。

## §1. 物理链
- 被动扩散：需要分子量<400-500Da + 亲脂性(logP 2-5) + <8个H键供体/受体
- H键供体数限制→每个H键增加去溶剂化成本~0.2eV（从α来）
- 如果分子形成太多H键→去溶剂化能>热运动→无法通过
- 外排泵(P-gp)：识别亲脂性底物→主动泵出→从底物结合能（α）推导
- 受体介导转胞吞：大分子的另一条路→受体结合从α推导

- BBB被动扩散的精确物理阈值（分子量、logP、H键供体上限）
- 当前的"CNS药物规则"（Lipinski/BBB规则）是否接近物理极限？
- 大分子（抗体、酶替代疗法）穿过BBB的转胞吞天花板
- 超声/微泡暂时打开BBB→从紧密连接键能推导安全窗口
