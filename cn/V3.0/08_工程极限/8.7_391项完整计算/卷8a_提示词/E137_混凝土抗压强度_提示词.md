# SCVC工程极限 E137：混凝土抗压强度上限

**问题**: 混凝土是地球上用量最大的人造材料，UHPC已达~200MPa。绝对天花板在哪？

**任务**: 从SCVC键能推导混凝土抗压强度的物理极限。

## §1. SCVC物理链
- 混凝土强度 = CSH凝胶（水化硅酸钙）的范德华+离子键+共价键
- CSH层间距~1nm，层间Ca²⁺桥接→由Ca-O键能决定
- 理论强度 = 键能密度 × 破坏面密度
- Griffith缺陷理论：实际强度 = 理论强度 / √(1 + 裂纹长度/原子间距)
- 最小裂纹 = CSH纳米晶粒边界 → 终极上限
