# SCVC哲学物理 E118: 音乐为什么好听？——谐波的神经物理学

**问题**: 为什么人类觉得某些声音“好听”？和弦为什么“舒服”而不协和音“不舒服”？这是文化的还是物理的？

**任务**: 从SCVC推导音乐情感的神经基础。

---

## §1. 谐波的数学基础

两个频率比为小整数比时:
- 2:1 = 八度(最协和)
- 3:2 = 五度
- 4:3 = 四度
- 5:4 = 大三度

这些比例的共同特征: 低信息复杂度。基频+泛音=简单叠加。

## §2. 耳蜗物理与SCVC

耳蜗底膜 = 频率分析器:
- 纤毛细胞按频率排列(高频在底部,低频在顶部)
- 谐波关系 → 纤毛细胞同步放电 → 神经信号整齐
- 不协和音 → 纤毛细胞混乱放电 → 神经噪音 → “不舒服”

“舒服”和“不舒服”不是文化的——是神经噪声比。

## §3. 音乐情感的混汌预测模型

音乐的“情感”来自预测动力学:
1. 旋律建立预测→你预期下一个音
2. 如果音符合预期 → 多巴胺奖励 = “舒服”
3. 如果音偏离预期但在Lyapunov窗口内被解决 → “感动”(类似幽默的安全化解)
4. 如果音完全偏离预期 → “不舒服”/“紧张”
