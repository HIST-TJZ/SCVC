## 任务2：临床试验设计

### 2.1 分三阶段

```
Phase Ib（剂量探索，12-18个月）:
  设计: 3+3或BOIN设计
  入组: 30-50例晚期/转移性（已穷尽标准治疗）
  目标: 找到四药联合的最大耐受低剂量
  关键: 不是找"最大耐受剂量"——是找"最小有效四联剂量"
        传统PhI是往上找→我们是往下找→更快更安全

Phase II（随机对照，18-24个月）:
  设计: 开放标签，随机1:1
  入组: 200-400例早期高风险术后
  分组: 标准辅助治疗 vs 标准+四联低剂量
  终点: 2年无病生存率（DFS）
  关键: 选择DFS而非OS→缩短随访时间

Phase III（确认性，如果PhII正面）:
  设计: 双盲，随机1:1
  入组: 1000-2000例
  但: PhII如果效果显著→可申请加速批准→跳过PhIII
```

### 2.2 加速策略

```
如何在2-3年而不是8-10年出结果？

策略A: 生物标志物替代终点
  → 不以"生存"为终点（需要5-10年随访）
  → 以"ctDNA清除率"为终点（6-12个月可测）
  → ctDNA从阳性→阴性 = 分子学完全缓解
  → FDA/EMA已开始接受ctDNA作为替代终点（部分癌种）

策略B: 篮子试验
  → 不限于单一癌种
  → 入组多个癌种的早期术后患者
  → 共同特征: 高风险复发 + ctDNA可检测
  → 样本量需求降低（共享对照组）

策略C: 平台试验
  → 利用已有的大型辅助治疗平台（如I-SPY）
  → 加入四联臂 → 已有基础设施 → 快

策略D: 真实世界证据
  → 低剂量=低毒性→可在社区医院进行
  → 不需要大型学术中心→入组更快
```

## 任务3：资金与推动力

### 3.1 药企为什么不愿意做

```
低剂量 = 低利润
  → CDK4/6i标准剂量: ~$10,000/月 × 2年 = $240,000/患者
  → 低剂量: ~$1,000/月 → $24,000/患者
  → 药企收入减少90%
  
四种药分属不同公司:
  → Pfizer (Palbociclib), AstraZeneca (Olaparib), Roche (贝伐珠单抗), Merck/BMS (检查点抑制剂)
  → 没有一家公司拥有全部四种 → 需要跨公司合作
  → 跨公司合作 = 专利/利润分配纠纷 → 没人牵头
  
但:
  标准剂量 → 副作用 → 30-50%患者无法完成全程
  低剂量 → 几乎无副作用 → 100%完成 → 总体市场扩大
  → 净收入可能持平甚至增加
```
