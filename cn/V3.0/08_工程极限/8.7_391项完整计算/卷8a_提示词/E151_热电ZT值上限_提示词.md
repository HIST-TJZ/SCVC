## §1. 物理链
- ZT = S²σT/κ（无量纲）
- S（塞贝克系数）= 每个载流子的熵 → 从载流子浓度和有效质量推导（m_e锁死）
- σ（电导率）= ne²τ/m* → τ由散射机制决定（α→电子-声子耦合）
- κ（热导率）= κ_e + κ_lattice
- κ_e通过Wiedemann-Franz：κ_e = LσT（L=洛伦兹数 = π²k_B²/(3e²)）
- κ_lattice下限 = 声子最小平均自由程 = 原子间距（E57已算）
- σ和S互锁：增加σ → S↓（Mott公式）
