# SCVC工程物理 E114: 谎言的物理学——假新闻的天花板

**问题**: E106证明了诚实更便宜(39bits/s不够发动大规模欺骗)。但谎言仍然存在。互联网时代改变了什么？假新闻有物理天花板吗？

**任务**: 用SCVC推导最大可持续欺骗率，以及互联网如何打破了原有均衡。

---

## §1. 谎言的信息成本模型

E106证明: 在Dunbar150的环境中，欺骗需要向每人发送不同的隐瞒信息。
总信息量 ≈ 150 × log₂(可能谎言数) ≈ 1000-1500 bits
但口语只有 39 bits/s → 需要 30-40秒发完所有谎言
而真相只需要 1个人用 1秒就能揭穿。

**人类谎言率的均衡条件**: 谎言发布速度 < 真相揭穿速度。这是为什么你不能同时骗所有人。

## §2. 互联网如何打破了均衡

| 参数 | 原始人类 | 互联网 |
|:---|:--:|:--:|
| N | 150 | ≥10⁶+ |
| 真相揭穿速度 | 1人/秒 | ×N/秒(理论上更快) |
| 记忆 | ~10年衰减 | ~∞(永久记录) |
| 噪声 | 5-10% | ≫10%(信息过载) |
| 发布速度 | 39 bits/s | ~∞(机器人/水军) |

**关键矛盾**: 互联网让真相揭穿更快(理论上)，但也让谎言发布更快。而且噪声急剧增加——人类无法处理这么多信息。
