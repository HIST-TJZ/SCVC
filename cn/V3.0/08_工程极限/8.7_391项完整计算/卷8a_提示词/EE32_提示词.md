# SCVC工程极限：配位化学 — 最高配位数+最密堆积

**任务**：从SCVC离子半径（从α和屏蔽推导）和Pauli排斥出发，推导配位数的理论上限和配位几何的极限。

**工程问题：**

### §1. 最高配位数
- 配位数由半径比r_cation/r_anion决定（Pauling规则）
- 半径比 > 1.0 → CN=12（立方最密堆积/fcc→立方八面体）
- Cs⁺(r=1.67 Å) / F⁻(r=1.33 Å) = 1.26 → CN=8（实际CsF为岩盐型CN=6，不匹配说明Pauling规则有修正）
- 最大离子半径：Cs⁺→Fr⁺（放射性），最小：F⁻
- **SCVC锁死的最大稳定配位数？能否有CN>12？**
- 间隙原子的配位数（氢在金属中CN可达12）→ 是否已触顶

### §2. 配位几何极限
- CN=12：立方八面体（fcc）或反立方八面体（hcp）
- 更高配位数需要更长键长→键能下降→不稳定
- 金属有机框架（MOF）中的高配位节点：Zr₆簇 CN=12
- **能否通过多中心键实现有效配位数>12？**

### §3. 最密堆积密度
- 等径球最密堆积：π/(3√2) ≈ 74.05%（fcc/hcp）
- 非等径球可以更高（小原子填八面体/四面体空隙）
- 最大密度由Pauli排斥（同向涡旋环不能重叠）锁死
- **非等径球堆积的最大理论密度？能否逼近100%？**
