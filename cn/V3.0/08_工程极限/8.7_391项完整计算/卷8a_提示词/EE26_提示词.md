# SCVC工程极限：脑机接口 — 神经信息传输率的天花板

**任务**：从SCVC的k_B T和离子通道物理出发，推导大脑↔机器的信息传输率上限。

**工程问题：**

### §1. 神经元放电速率上限
- 动作电位持续时间 ~1 ms → 原则上 ~1000 Hz
- 不应期 ~1-2 ms（Na⁺通道失活恢复）→ 实际上限 ~500 Hz
- Na⁺通道动力学由膜蛋白构象变化决定 → 势垒由氢键 ~0.1-0.3 eV
- Arrhenius速率 ∝ exp(-E_a/k_B T)，300K时k_B T = 0.026 eV
- **SCVC锁死的神经元最大放电频率？能否超过1000 Hz？**

### §2. 轴突信息传输率
- 轴突带宽由膜电容 + 离子通道密度 + 传导速度决定
- 膜电容：~1 μF/cm²（脂双层厚度 ~5 nm，介电常数 ~2-3）
- 传导速度：有髓轴突 ~100 m/s（郎飞结间距优化）
- Shannon信息率：C = B log₂(1+SNR)
- **单根轴突的最大信息率（bits/s）？视神经/听神经的实际 vs 理论？**

### §3. 脑机接口电极极限
- Utah阵列：~100电极，每电极记录~1-3个神经元
- 电极密度受限于组织损伤和瘢痕形成
- 电极尺寸下限由热噪声（Johnson噪声：√(4k_B TRΔf)）和阻抗决定
- **皮层电极的最大空间分辨率（电极数/mm²）？**
- **单电极能否实现"读心"级别的信息提取？**

### §4. 非侵入式接口
- EEG、fMRI、MEG、fNIRS — 各自的空间/时间分辨率
- EEG受颅骨低通滤波限制：高频信号(~>100 Hz)严重衰减
- 颅骨电导率 ~0.01 S/m → 空间分辨率 ~cm级
