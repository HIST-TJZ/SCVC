### 1.2 SCVC锁定机制

```
k = 2π/λ = 2πf/c
c 由 ℏc = 197.3 MeV·fm 锁定 → c 从 α 推导
→ 给定频率 f, 波长 λ = c/f 是固定的
→ ka = 2πa/λ = 2πa·f/c 是固定的
→ 天线的最小 Q 由几何 (a) 和物理 (c) 联合锁定

这就是"不可能三角"的来源:
  小尺寸 (a↓) × 高增益 (G↑) × 宽频带 (BW↑)
  → 三个量在SCVC下不可能同时优化
```

## §4 工程结论

### 4.1 5G/6G 毫米波手机天线

```
手机物理尺寸 ~15×7 cm

频率        λ      D_max(dBi)  阵列规模   实用增益
28 GHz    10.7 mm    24 dBi    16单元     12-16 dBi
60 GHz     5.0 mm    37 dBi    64单元     18-22 dBi
140 GHz    2.1 mm    45 dBi   256单元     24-28 dBi

"不可能三角"在毫米波被"打破"的方式:
  → λ变小 → 同一物理口径在电尺寸上变大 → ka增大
  → 口径方向性随 1/λ² 增长 → 手机在140GHz的D_max可达~45 dBi
  → 但: 波束极窄 (140GHz时 ~1°) → 需要快速波束扫描
  → 新瓶颈: 波束管理算法 + 功耗 + 信道相干时间
```

### 4.2 射电天文的最大灵敏度

```
CMB噪声地板: T_sys ≥ 2.725 K → 不可逾越
现有最大口径 (FAST 500m): A_e~2×10⁵ m² → S_min ~ μJy级
未来 SKA (~1 km²): S_min ~ 0.01 μJy → 毫央级

真正的灵敏度瓶颈 (按出现顺序):
  1. CMB (2.725 K) — 物理硬上限, 不可逾越
  2. 银河同步辐射 — 低于~1 GHz主导
  3. 大气辐射 — 高于~20 GHz主导
  4. 源混淆 (confusion) — 任何波段的终极限制
     → 再大的天线也分不开视线重叠的源
     → 干涉阵 (VLBI) 缓解: 角分辨率 ∝ λ/基线长
```

```
SCVC的冷静结论:
  天线效率不可能通过"新材料"或"新设计"突破Chu-Harrington
  → Q ≥ 1/(ka)³ 是 Maxwell方程的几何推论
  → 唯一"破解": 提高频率 (λ↓, a/λ↑, ka↑)
  → 这就是为什么毫米波/太赫兹是芯片天线的未来
```

### 4.4 核心洞察

1. **Chu-Harrington是SCVC硬墙**: Q ≥ 1/(ka)³ 来自 Maxwell + c(α), 不可谈判。电小天线窄带 — 永远如此。

2. **方向性受衍射限**: D_max = 4πA/λ² → 想高增益? 要么大天线, 要么短波长。超方向性可行但Q爆炸 → 无实用价值。

3. **灵敏度受CMB限**: T_sys ≥ 2.725 K 来自 Λ₄^(1/4) = 2.4×10⁻³ eV → 这是"宇宙给射电天文学的终极噪声预算"。

4. **毫米波是天线工程师的救赎**: λ变小 → 同一物理尺寸的 ka 增大 → 摆脱"电小"诅咒 → 增益和带宽同时改善 → 但波束管理成本爆炸。

5. **芯片天线: 频率越高越容易**: 60 GHz 片上天线已商用, 300 GHz 轻松, 1 THz 可行。SCVC没有设定"芯片天线不可行"的墙, 只设定了"任何频率下不能小于 ~λ/20" 的墙。
