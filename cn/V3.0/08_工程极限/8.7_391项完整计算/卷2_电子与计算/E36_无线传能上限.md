## §1. 感应式（近场）耦合

### 1.1 耦合效率的基本物理

两线圈之间的无线能量传输效率由耦合系数k和品质因数Q决定：

```
效率：η = k²Q₁Q₂ / (1 + √(1 + k²Q₁Q₂))²

对于相同线圈(Q₁=Q₂=Q)：
```

| 目标效率 η | 所需 k²Q² | 含义 |
|-----------|----------|------|
| 50% | ≥ 8 | 基本可用 |
| 75% | ≥ 48 | 良好 |
| 85% | ≥ 151 | 优秀 |
| **90%** | **≥ 360** | 商用标准 |
| 95% | ≥ 1,520 | 高端 |
| 99% | ≥ 39,600 | 近乎完美 |

### 1.2 耦合系数k与距离的衰减律

对于两个同轴圆环线圈（半径r，间距d），耦合系数在远距离下（d ≫ r）有：

```
k ≈ (π/2) × r³/(d³ × [ln(8r/a)-2])
```

**k随d⁻³衰减**——这是近场耦合距离受限的根本原因。近场能量储存在线圈周围的磁场中，磁场强度以1/d³衰减（偶极场），而不是远场辐射的1/d衰减。

### 1.3 品质因数Q的SCVC限制

```
Q = ωL/R_total

R_total = R_ohmic + R_rad

R_ohmic ∝ √ω  （趋肤效应：电流限于表面深度 δ=√(2/ωμ₀σ)）
R_rad   ∝ ω⁴  （小环天线辐射电阻：∝ (r/λ)⁴）

→ Q_ohmic ∝ √ω  （频率↑→Q↑）
→ Q_rad   ∝ 1/ω³ （频率↑→Q↓）
```

**SCVC约束**：导体电导率σ由自由电子密度和散射率决定，散射率由α设定（电子-声子耦合λ_max~3）。即使在最佳导体（铜、银）中，室温下的σ也被声子散射锁定在~6×10⁷ S/m。

| 频率 | 波长 | Q_ohmic (Cu) | Q_rad | Q_total | 主导损耗 |
|------|------|-------------|-------|---------|---------|
| 0.1 MHz | 3 km | 672 | ~10¹¹ | **672** | 欧姆 |
| 1 MHz | 300 m | 2,130 | ~10⁹ | **2,130** | 欧姆 |
| **10 MHz** | **30 m** | **6,730** | **~9×10⁵** | **~6,680** | **最优平衡** |
| 100 MHz | 3 m | 21,300 | ~900 | **~860** | **辐射** |

**最优频率**：~10 MHz（r ~ 0.3m线圈的最优工作点）。低于此频率，欧姆损耗主导且Q低。高于此频率，辐射损耗飙升。

### 1.4 最大有效距离

| 配置 | 线圈半径r | Q | d/r (η=90%) | d/r (η=80%) | d_max (η=80%) |
|------|----------|---|------------|------------|-------------|
| 手机Qi充电 | 2 cm | 100 | 1.4 | 1.8 | **3.6 cm** |
| 笔记本充电垫 | 5 cm | 200 | 1.7 | 2.2 | **11 cm** |
| 房间级谐振 | 30 cm | 2,000 | 3.3 | 4.2 | **1.3 m** |

**关键结论**：d/r_max ≈ 5-7 是近场耦合的SCVC物理天花板。即使使用超导线圈（Q→∞），耦合系数k的d⁻³衰减律也意味着效率永远无法在远大于线圈尺寸的距离上保持。

## §2. 谐振式磁耦合（MR-WPT）

### 2.1 谐振增强原理

当发射和接收线圈调到相同谐振频率时，无功功率在线圈之间来回振荡，减少了电源需要提供的无功电流。这等效于提高了系统的有效Q值。

```
谐振耦合的本质：两个LC谐振回路通过互感M交换能量
→ 能量交换速率 ∝ k·ω₀
→ 损耗速率 ∝ ω₀/Q
→ 效率取决于 kQ（不是k²Q）
```

实际上，谐振耦合并不能改变k²Q²的效率公式，但允许在更低的k值下工作（因为谐振使阻抗匹配更容易）。

### 2.2 最优频率的SCVC推导

最优频率由Q_total的最大值决定。考虑欧姆损耗和辐射损耗的竞争：

```
Q_total = (1/Q_ohmic + 1/Q_rad)⁻¹

Q_ohmic ∝ √ω · σ·a/√(μ₀)   （a为导线半径）
Q_rad   ∝ c³/(ω³·r³)        （r为线圈半径）

令 ∂Q/∂ω = 0：
ω_opt ∝ (c³/(r³ · √(σ·a/√μ₀)))^(2/7)
```

对于r=0.3m, a=3mm的铜线圈：ω_opt ≈ 2π × 12 MHz → **f_opt ≈ 12 MHz**。

### 2.3 多线圈中继扩展

单跳耦合的d/r上限为~5-7，但可以插入中继线圈（passive repeater）形成"磁波导"：

```
发射线圈 → 中继1 → 中继2 → ... → 接收线圈
每跳距离：d_hop/r ≈ 2-3（保持高效率）
N跳总距离：d_total/r ≈ N × 2-3

3个中继：d_total/r ≈ 9（r=0.3m → 2.7m覆盖）
```

韩国KAIST的偶极线圈阵列（2014）：6个中继线圈覆盖~5m距离，效率~50%。这是谐振耦合扩展距离的主要工程路线。

## §3. 远场（微波/激光）传输

### 3.1 Friis传输方程

```
P_r/P_t = G_t · G_r · (λ/(4πd))²

其中G_t, G_r为天线增益，G = 4πA_eff/λ²

代入：A_eff = G·λ²/(4π)

→ 关键标度律：A_required = √η × d × λ
（对于相同收发天线，效率η）
```

**物理直觉**：所需天线面积正比于距离×波长。越远需要越大天线，越高频率（越短波长）可以用越小天线。

### 3.2 1 km传1 kW的工程参数

| 频率 | 波长λ | 天线面积(η=50%) | 天线直径 | 增益 |
|------|-------|---------------|---------|------|
| 1 GHz (L-band) | 30 cm | **212 m²** | 16.4 m | 45 dBi |
| 2.45 GHz (ISM) | 12 cm | 86.5 m² | 10.5 m | 49 dBi |
| 5.8 GHz (ISM) | 5.2 cm | **36.5 m²** | 6.8 m | 52 dBi |
| 10 GHz (X-band) | 3.0 cm | 21.2 m² | 5.2 m | 55 dBi |
| 35 GHz (Ka-band) | 8.6 mm | 6.1 m² | 2.8 m | 60 dBi |
| 94 GHz (W-band) | 3.2 mm | 2.3 m² | 1.7 m | 64 dBi |
| 可见光 (绿) | 500 nm | **φ=2.3 cm** | 2.3 cm | 102 dBi |

**可见光的诱惑与陷阱**：仅需2.3 cm孔径！但大气衰减在雨中可达30 dB/km——99.9%损耗。微波在2-10 GHz和35-94 GHz有大气窗口，衰减<0.2 dB/km。

### 3.3 太空太阳能电站→地面

GEO轨道（36,000 km）传能到地面：

```
标度律：A = √η × d × λ

2.45 GHz：A_tx = A_rx ≈ 3.1 km²（直径2.0 km）
5.8 GHz： A_tx = A_rx ≈ 1.3 km²（直径1.3 km）
35 GHz：  A_tx = A_rx ≈ 0.22 km²（直径530 m）
```

**实际约束**：
- 发射天线在GEO上展开km²级相控阵——质量数万吨，远超现有发射能力
- 地面整流天线（rectenna）可以用轻质网面——经济上可行
- 功率密度安全：100-200 W/m²（约阳光的10-20%）→ 1 GW接收需5-10 km²
- **大气击穿（电离）阈值**：~1 MW/m²（远高于实际功率密度，但波束中心需注意）

### 3.4 衍射的SCVC硬极限

远场波束的发散角由衍射设定：

```
θ ≈ λ/D    （半功率波束宽度）

距离d处的波束直径：w ≈ d·λ/D
```

对于GEO上的1 km发射天线，5.8 GHz：
- θ ≈ 0.052/1000 = 5.2×10⁻⁵ rad ≈ 0.003°
- 地面波束直径 ≈ 3.6×10⁷ × 5.2×10⁻⁵ ≈ **1.9 km**

比天线本身大不了多少——这就是高增益天线的作用。但衍射极限意味着**永远有波束扩散**，无法将全部能量聚焦到一个比λ/D倍距离更小的点上。这是麦克斯韦方程的几何约束，SCVC中的α和ℏ未对此添加新限制。

## §4. 工程结论

### 4.1 "房间级无线供电"的物理可行性

```
线圈半径r=0.5m, Q=2000（6.78 MHz铜线圈，可实现）：
  d_max(η=80%) ≈ 2.0 m
  → 一个线圈覆盖4m×4m房间需要放在房间中央
  → 或使用4个中继线圈（每墙一个）→ 效率~50-60%

线圈半径r=1.0m（嵌入天花板/地板）：
  d_max(η=80%) ≈ 4.0 m
  → 单个线圈覆盖整个大房间
  → 成本：1m直径线圈 + 6.78 MHz射频功放

SCVC判断：房间级无线供电在物理上完全可行。
不是物理禁止的——是成本和EMF安全标准限制的。
```

### 4.2 EMF安全：真正的瓶颈

```
ICNIRP 2020 公众暴露限值（6.78 MHz近场）：
  电场：E < 83 V/m
  SAR：< 2 W/kg（头部/躯干）

100 W 发射，天线增益~1，2m距离：
  E ≈ √(30·P·G)/d ≈ √3000/2 ≈ 27 V/m ✅ OK

1 kW 发射，2m距离：
  E ≈ √30000/2 ≈ 87 V/m ⚠️ 超限！

→ 房间级无线供电的功率上限 ≈ 300-500 W
  （在不触发安全限值的前提下）
→ 足够为灯具+小型电子设备供电
→ 不够为空调/电磁炉等大功率设备供电
```

### 4.3 无人机空中充电

```

无人机线圈 r=0.1m（小）

不对称耦合（发射线圈远大于接收线圈）：
  k ∝ √(r_tx³ × r_rx³)/d³
  → d_max(η=50%) ≈ 8-15 m（取决于精确对准）
  
实用极限：
  着陆垫充电：d=0 → η>90%（已商用）
  悬停充电：d=1-3m → η≈50-70%（需要对准+稳定悬停）
  飞行中充电：d>5m → η<30%（效率太低）
  
→ 无人机"空中充电网"需要密集的发射线圈阵列（间距~10-20m）
```
