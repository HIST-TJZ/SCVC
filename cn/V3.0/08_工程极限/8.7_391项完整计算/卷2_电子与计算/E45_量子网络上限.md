## §1. 光纤损耗的SCVC起源

### 1.1 二氧化硅光纤的损耗构成（1550 nm）

| 损耗机制 | 理论最小值 (dB/km) | SCVC起源 |
|----------|-------------------|----------|
| **Rayleigh散射** | **~0.12** | 密度/浓度涨落 → 极化率涨落 → α |
| 红外吸收尾 | ~0.015 | Si-O键振动泛频 → 键能（3.6-8.7 eV, SCVC） |
| 紫外吸收尾 | ~0.005 | 电子带间跃迁尾 → 带隙（~9 eV, SCVC） |
| 波导缺陷 | ~0.003 | 制造不完美（非SCVC） |
| **总计** | **~0.14** | |

当前最纯硅芯光纤（Corning, Sumitomo）已达 **0.142-0.15 dB/km** → **距SCVC理论极限仅 1-7%。**

### 1.2 Rayleigh散射的SCVC推导链

```
Rayleigh散射截面: σ_R ∝ (n²-1)² / λ⁴

折射率: n²-1 ∝ N × α_pol (Clausius-Mossotti)

极化率: α_pol ∝ a₀³ ∝ 1/α³  (a₀ = ℏ/αm_ec = Bohr半径)

→ Rayleigh散射 ∝ α_pol² ∝ 1/α⁶
```

**这意味着光纤损耗对精细结构常数α极度敏感。** 如果α差1%，Rayleigh散射差~6%；如果α差10%，Rayleigh散射差~80%。SCVC以2.22 ppm精度锁定α → Rayleigh损耗被严格锁定。

**SCVC判据：光纤损耗的最后提升空间约5-10%，之后到达物理天花板。** 对传输距离的影响（在固定可容忍损耗下）：

```
ΔL_max ≈ (4.34/α_att) × ln(α_att_old/α_att_new)
       ≈ (4.34/0.15) × ln(0.15/0.14) ≈ 2 km
```

降低0.01 dB/km仅增加~2 km传输距离 → **继续降低光纤损耗的边际收益已极小。**

### 1.3 各距离传输率

以0.15 dB/km（优质光纤）为例：

| 距离 (km) | 损耗 (dB) | 透过率 | 直观类比 |
|-----------|----------|--------|----------|
| 10 | 1.5 | **71%** | 几乎透明 |
| 50 | 7.5 | **18%** | 城市内QKD可行 |
| 100 | 15 | **3.2%** | 城域网可用 |
| 200 | 30 | **0.1%** | 需要TF-QKD或中继 |
| 300 | 45 | 3×10⁻⁵ | 无中继探测极难 |
| 400 | 60 | 10⁻⁶ | 黑暗计数与信号相当 |
| 500 | 75 | 3×10⁻⁸ | 无中继基本不可能 |

## §2. 无中继纠缠分发

### 2.1 光纤直连的物理极限

量子信号不可放大（no-cloning定理）→ 每个光子到达概率 = 光纤透过率。

以1 GHz脉冲源、平均光子数μ=0.1、超导纳米线探测器（SNSPD, η=85%, 暗计数~10 Hz）为例：

| 距离 | 信号速率 (光子/s) | 暗计数比 | QBER_dark | 能否QKD？ |
|------|-------------------|----------|-----------|-----------|
| 50 km | 1.4×10⁷ | 10⁻⁶ | ~0% | ✅ 高密钥率 |
| 100 km | 2.5×10⁶ | 4×10⁻⁶ | ~0% | ✅ 良好 |
| 200 km | 8.0×10⁴ | 1.3×10⁻⁴ | ~0.01% | ✅ 可用 |
| 300 km | 2.5×10³ | 4×10⁻³ | ~0.4% | ⚠️ 勉强 |
| 400 km | 80 | 0.13 | **~11%** | ❌ 基本不行 |
| 500 km | 2.5 | 4 | — | ❌ 不可能 |

300 km处：信号~2500光子/秒，暗计数~10/s，QBER~0.4% → **勉强可行但密钥率极低。**

400 km处：QBER已达~11%（BB84安全阈值）→ 无中继QKD到此为止。

**Twin-field QKD突破：** 使用中间测量站（非全量子中继器），密钥率 ∝ √η 而非 η：

```
BB84在400 km:  R ∝ 10⁻⁶
TF-QKD在400 km: R ∝ 10⁻³ → 1000倍提升！
TF-QKD在500 km: R ∝ 3×10⁻⁴
```

TF-QKD的无中继记录：**509 km**（2020年）。这已接近光纤无中继的SCVC天花板——再远，即使TF-QKD也无法产生有意义的密钥率。

### 2.2 卫星纠缠分发（自由空间）

**自由空间 vs 光纤的根本差异：**

```
光纤500 km: 损耗 ~75 dB  → 传输率 3×10⁻⁸
自由空间500 km: 损耗 ~15 dB → 传输率 3% → 好10⁶倍！
```

**卫星链路的损耗预算（500 km LEO）：**

| 损耗项 | 效率 | 备注 |
|--------|------|------|
| 衍射扩展（30 cm→1 m接收） | 8.4% | 由ℏ决定衍射极限 |
| 大气透过率（好波长） | 75% | 由分子吸收（SCVC能级） |
| 指向跟踪 | 90% | 工程问题 |
| 接收光学 | 70% | 工程问题 |
| 探测器效率 | 85% | SNSPD |
| **总效率** | **~3%** | **等效15 dB损耗** |

对比500 km光纤（75 dB）→ 卫星链路好 **60 dB (= 10⁶ 倍传输率)。**

**已实现：** 墨子号卫星（Micius）已验证1200 km纠缠分发。SCVC允许更远（仅受衍射和大气约束）。

## §3. 量子中继器

### 3.1 中继器原理

量子中继器通过**纠缠交换 + 纠缠纯化**克服no-cloning限制：

```
[节点A] --纠缠--> [中继1] --纠缠--> [中继2] --纠缠--> [节点B]
                         ↓ 纠缠交换
                    [A ~~~~ B 直接纠缠]
```

最大中继间距由量子存储寿命决定：

```
L_max = v_fiber × τ_mem / 2

v_fiber = c / 1.468 ≈ 2.04×10⁸ m/s (光纤中光速)
```

| 量子存储 T₂ | 最大间距 (km) | 地球周长覆盖需要节点数 |
|------------|-------------|---------------------|
| 1 ms | **102** | ~392 |
| 10 ms | **1,021** | ~39 |
| 100 ms | **10,211** | ~4 |
| 1 s | **102,108** | **1** (地球全覆盖) |
| 10 s | 10⁶ | 0（完全不需要中继） |
| ~~核自旋~~ | ~~小时级~~ | 0（理论极限远超需求） |

### 3.2 SCVC对量子存储T₂的约束

从SCVC速查表：

```
电子-声子耦合: λ = 0.5-2
德拜频率: ℏω_D = 0.3-0.5 eV → ~3500-5800 K

自旋-晶格弛豫: T₁ ∝ coth(ℏω_D/2k_B T) / (λ² × ω_D)
```

在低温（T ≪ θ_D）下，声子瓶颈效应使T₁指数增长：
```
T₁ ~ exp(ℏω_D / k_B T) × (prefactor)
```

在T = 10 mK, ℏω_D = 0.4 eV (≡ 4640 K):
```
T₁ ~ exp(4640/0.01) / (4 × 7.6×10¹⁴) ≈ 天文数字
```

**SCVC核心发现：核自旋的T₂在充分低温下可以接近无限长（>小时），SCVC不设硬天花板。** 唯一的限制是宇宙射线电离（非SCVC约束）和残留顺磁杂质（工程问题）。

### 3.3 中继器级联的指数代价

即使T₂足够长，中继器链的密钥率随级数N指数衰减：

```
R(N) ∝ p₀ × (p_success)^N

p_success: 每段纠缠分发+交换+纯化的综合成功率
典型 p_success ~ 0.3-0.8（取决于光子损耗和门保真度）
```

| 级数 N | R/R₀ (p=0.5) | R/R₀ (p=0.7) | 实用性 |
|--------|-------------|-------------|--------|
| 1 | 0.5 | 0.7 | ✅ |
| 4 | 0.06 | 0.24 | ✅ |
| 8 | 0.004 | 0.058 | ⚠️ |
| 10 | 0.001 | 0.028 | ⚠️ |
| 20 | 10⁻⁶ | 8×10⁻⁴ | ❌ |

**关键：秒级T₂使级数N降为1-4（而非40+），这是中继器从"不可能"到"可能"的转折点。**

### 3.4 无需中继器的极限条件

当 T₂ > 2×L_earth / v_fiber ≈ 2×4×10⁷/2×10⁸ ≈ 0.4 s 时，**全球任意两点之间可以实现无中继的memory-assisted直接纠缠分发。** SCVC允许这一条件。

```
方案: Alice持有纠缠光子对的一半，将另一半通过光纤发送给Bob
     Bob收到后存储在他的量子存储中
     Alice和Bob各自测量 → 获得纠缠

需要: Bob收到光子时Alice的存储仍保持相干
     → T₂ > L/v_fiber ≈ 200 ms (地球半周长)
```

核自旋T₂可达秒级 → **物理上全球无中继纠缠分发是SCVC允许的。**

## §4. 量子密钥分发（QKD）速率

### 4.1 BB84 decoy-state QKD

以1 GHz时钟、μ=0.5平均光子数、SNSPD探测器为例：

| 距离 | 透过率 | 原始密钥率 | **安全密钥率** | 可用性 |
|------|--------|-----------|-------------|--------|
| 10 km | 71% | 150 Mbps | **64 Mbps** | ✅ 骨干加密 |
| 25 km | 42% | 90 Mbps | **38 Mbps** | ✅ 骨干加密 |
| 50 km | 18% | 38 Mbps | **16 Mbps** | ✅ 城域骨干 |
| 100 km | 3.2% | 6.7 Mbps | **2.9 Mbps** | ✅ 城域接入 |
| 150 km | 0.6% | 1.2 Mbps | **508 kbps** | ⚠️ 窄带 |
| 200 km | 0.1% | 210 kbps | **90 kbps** | ⚠️ 仅密钥交换 |
| 300 km | 3×10⁻⁵ | 6.7 kbps | **2.9 kbps** | ❌ 太慢 |
| 400 km | 10⁻⁶ | 210 bps | **90 bps** | ❌ 无用 |

> 安全密钥率 = 原始率 × 筛选(1/2) × decoy开销(1/2) × 纠错+隐私放大(~0.85)

### 4.2 Twin-field QKD的提升

TF-QKD的密钥率 ∝ √η（而非η），在长距离上优势巨大：

| 距离 | BB84安全速率 | TF-QKD安全速率 | 提升 |
|------|-------------|---------------|------|
| 200 km | 90 kbps | **~3 Mbps** | 30× |
| 300 km | 2.9 kbps | **~500 kbps** | 170× |
| 400 km | 90 bps | **~90 kbps** | 1000× |
| 500 km | 3 bps | **~16 kbps** | 5000× |

**SCVC判据：** TF-QKD将无中继光纤QKD从~200 km（实用）推到~500 km（极限）。进一步延伸必须中继器或卫星。

### 4.3 QKD vs 经典通信 —— 量子不会取代经典

| 特性 | 量子网络 | 经典光纤网络 |
|------|---------|-------------|
| 带宽 | kbps-Mbps | Tbps |
| 距离(无中继) | ~100-500 km | ~100 km（之后放大） |
| 可放大？ | ❌ (no-cloning) | ✅ (EDFA) |
| 用途 | **安全密钥分发** | 一切 |
| 成本 | 极高（单光子探测+低温） | 极低 |

**QKD的核心价值是安全，不是速度。** 100 kbps的密钥足以用一次一密（OTP）加密语音通话或生成AES-256会话密钥。QKD是经典加密的补充（对抗量子计算攻击），而非经典互联网的替代品。

## §5. 工程结论：全球量子互联网

### 5.1 五层架构及SCVC判断

| 层级 | 技术 | 距离 | SCVC允许？ | 现状 |
|------|------|------|-----------|------|
| **城域QKD** | 光纤直连 | <100 km | ✅ | **已商用** |
| **城际QKD** | TF-QKD / 可信中继 | 100-500 km | ✅ | **已部署**（京沪干线2000+ km） |
| **洲际QKD** | 卫星QKD | 500-5000 km | ✅ | **已演示**（Micius） |
| **全球纠缠网** | 量子中继器 | 100-40,000 km | ✅ | 🔬 实验室阶段 |
| **量子互联网** | 分布式量子计算 | 任意 | ✅ | 🔮 数十年后 |

### 5.2 "哪个部分物理允许，哪个部分物理禁止？"

**✅ SCVC明确允许：**
- 光纤QKD城域网（损耗可容忍）→ **已商用**
- 卫星QKD全球密钥分发（自由空间优势）→ **已演示**
- 量子中继器（T₂ > 100 ms后，N<10级）→ **实验推进中**
- 全球无中继memory-assisted纠缠（核自旋T₂ > 秒）→ **物理允许**

**⚠️ SCVC不禁止但工程极难：**
- 千公里级无中继QKD（需探测器噪声降10³×）→ **收益递减**
- N>20的中继器链（指数衰减的密钥率）→ **不实用**

**❌ SCVC禁止（或等效禁止）：**
- 量子信号放大（no-cloning定理，来自量子力学，非SCVC特有）→ **绝对禁止**
- 光纤损耗降到0（Rayleigh散射∝1/α⁶，α>0→损耗>0）→ **绝对禁止**

### 5.3 量子中继器："10年可解决"还是"永远不可能"？

**SCVC答案：可能，且10-20年内可解决。**

核自旋存储已达秒级T₂（NV中心、稀土掺杂晶体）。SCVC给出T₂的物理上限极高（低温下声子瓶颈指数抑制弛豫），唯一的物理障碍是λ>0（自旋-声子耦合永远存在）→ 这意味着T₂永远有限——但上限可达**小时到天级**，远超一切实际需求。

关键障碍在工程：
- 纠缠纯化的保真度 → 需要>99%双量子门
- 光子-存储接口效率 → 需要>90%的光子-自旋映射
- 多路复用 → 并行化抵消指数衰减

### 5.4 终极量子网络的SCVC天花板

| 参数 | SCVC极限 | 决定因子 | 当前水平 |
|------|---------|----------|----------|
| 光纤最小损耗 | **~0.14 dB/km** | Rayleigh ∝ 1/α⁶ | 0.142 |
| 无中继QKD最大距离 | **~500-600 km** | 暗计数 vs 信号 | 509 km (TF-QKD) |
| 卫星纠缠最远距离 | **~10,000 km** | 衍射(ℏ)+大气 | 1,200 km |
| 量子中继间距高 | **~10⁵ km** (T₂=1s) | T₂ (λ, ℏω_D) | ~100 km |
| QKD最大密钥率(100km) | **~10 Mbps** | η, 探测器 | ~Mbps |
| 核自旋T₂上限 | **~小时-天** | λ→声子瓶颈 | ~小时 |

### 5.5 经典互联网不会被量子互联网取代

量子网络的独特价值：**物理定律保证的安全性**——基于no-cloning和测量塌缩，而非数学困难。对安全关键通信（金融、军事、政务）不可替代。对99%的日常互联网流量（视频、网页、邮件），经典网络已经足够且效率高10⁶倍。

**量子+经典混合网络是SCVC允许的最优架构：量子层传密钥，经典层传数据。**
