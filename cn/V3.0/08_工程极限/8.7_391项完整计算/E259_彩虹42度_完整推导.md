## 1. 笛卡尔最小偏转角 → 42°

### 1.1 彩虹射线（一次内反射）

太阳光 → 球形水滴折射(进入) → 一次内反射 → 折射(出射)。

偏转角（入射角i）：
\[
D(i) = (i-r) + (180°-2r) + (i-r) = 180° + 2i - 4r
\]

其中r = arcsin(sin i / n)，n是水的折射率。

### 1.2 最小偏转角

彩虹出现在最小偏转角附近（光线在此堆积→最亮）。dD/di = 0：

\[
\frac{dD}{di} = 2 - 4\frac{dr}{di} = 0 \rightarrow \frac{dr}{di} = \frac{1}{2}
\]

从Snell定律：cos i·di = n·cos r·dr → dr/di = cos i/(n·cos r) = 1/2

→ cos i_min = (n²−1)/3

代入n=1.33：cos i_min = (1.7689−1)/3 = 0.2563 → i_min ≈ 75.2°

r_min = arcsin(sin 75.2°/1.33) = arcsin(0.9679/1.33) = arcsin(0.7278) ≈ 46.7°

D_min = 180° + 2×75.2° − 4×46.7° = 180° + 150.4° − 186.8° = 143.6°

彩虹角半径（反太阳方向到彩虹的距离）= 180° − D_min = 180° − 143.6° ≈ **36.4°**。

等等，这个数不对。让我重新算。

D(i) = (i-r) + (180°-2r) + (i-r) = 180° + 2i - 4r

r = arcsin(sin(75.2°)/1.33) = arcsin(0.9679/1.33) = arcsin(0.7278) = 46.67°

D = 180 + 2(75.2) - 4(46.67) = 180 + 150.4 - 186.68 = 143.72°

这个偏转角是相对于入射光方向的。彩虹出现在反太阳方向，所以彩虹角=180°−D_min。

不对，D是光线进入水滴到出射的总偏转角。观测者看到的是向后散射的光→偏转角大约在138-140°范围。光线从太阳来，进入水滴，反射一次，然后回到观测者眼睛。偏转=180°−42°=138°。

让我用正确的公式——彩虹角是光线偏向角接近180°−42°=138°附近的最小偏转角。

实际上通常定义：偏转角 = 光线最终方向与原始入射方向的夹角。彩虹在约138°偏转（向后方向），而不是143°。让我重新推导。

对于一次内反射的彩虹，光线路径：
入射→折射进→反射→折射出

偏转角（从原始方向）：δ = (i-r) + (π-2r) + (i-r) = π + 2i - 4r

最小偏转：dδ/di = 2 - 4(dr/di) = 0 → dr/di = 1/2

从Snell：cos i = n·cos r·(dr/di) = n·cos r·(1/2)

所以：cos²i = n²·cos²r·(1/4)

而 sin²i = n²·sin²r

联立：1 = cos²i + sin²i = (n²/4)cos²r + n²sin²r = (n²/4)(1-sin²r) + n²sin²r
= n²/4 - (n²/4)sin²r + n²sin²r = n²/4 + (3n²/4)sin²r

所以 sin²r = (4-n²)/(3n²)

cos²r = 1 - (4-n²)/(3n²) = (3n²-4+n²)/(3n²) = (4n²-4)/(3n²) = 4(n²-1)/(3n²)

现在：cos i 来自 cos²i + sin²i = 1。或者直接用 δ_min。

在最小偏转角：δ_min = π + 2·arccos(√((n²−1)/3)) − 4·arcsin(√((4−n²)/(3n²)))

实际上我需要的是彩虹角 = π − δ（如果δ>π/2）。对于n=1.33：

sin²r = (4−1.7689)/(3×1.7689) = 2.2311/5.3067 = 0.4204 → sin r = 0.6484 → r = 40.42°

cos²r = 1−0.4204 = 0.5796, cos r = 0.7613

cos²i = (n²/4)cos²r = (1.7689/4)(0.5796) = 0.4422×0.5796 = 0.2563

cos i = 0.5063 → i = 59.58°

D_min = 180° + 2(59.58°) − 4(40.42°) = 180° + 119.16° − 161.68° = 137.48°

彩虹角 = 180° − D_min + 360°... 不对。

偏转角137.48°意味着光线向后偏转。彩虹角半径（从反太阳点到彩虹）= 180° − 137.48° = **42.52°**。

对n=1.33→这是主虹角。对紫光（n≈1.344）→ ≈40.7°。对红光（n≈1.330）→ ≈42.5°。

所以红光在外面（42.5°），紫光在里面（40.7°），彩虹宽度≈1.8°。✅

OK现在继续文档。

## 2. n=1.33的SCVC根源

水的折射率 ≈ 1.33。为什么不是1.2或1.5？

### 2.1 分子极化率 → α

Lorentz-Lorenz公式：
\[
\frac{n^2-1}{n^2+2} = \frac{N\alpha_{\text{pol}}}{3\varepsilon_0}
\]

N = 分子数密度。液态水：ρ=1000 kg/m³, M=18 g/mol → N≈3.35×10²⁸ m⁻³。

α_pol(H₂O) ≈ 1.48×10⁻³⁰ m³（电子极化率，可见光频率）。

代入： (n²−1)/(n²+2) = 3.35×10²⁸×1.48×10⁻³⁰/(3×8.854×10⁻¹²)
= 4.96×10⁻²/(2.66×10⁻¹¹) = ... 等等，单位有问题。

α_pol/ε₀ = 1.48×10⁻³⁰/8.854×10⁻¹² = 1.67×10⁻¹⁹ m³... 这是体积。

Nα_pol = 3.35×10²⁸×1.48×10⁻³⁰ = 4.96×10⁻²（无量纲）。

(Nα_pol)/(3ε₀) = 4.96×10⁻²/3 = 1.65×10⁻²。

(n²−1)/(n²+2) = 1.65×10⁻² → n²−1 = 0.0165(n²+2) → n²−1 = 0.0165n²+0.0331
→ 0.9835n² = 1.0331 → n² = 1.050 → n = 1.025。

不对！1.025远低于1.33。问题在哪？水有**永久偶极矩**→在可见光频率下取向极化来不及响应→只有电子极化。但实验上水的n≈1.33→意味着有效极化率比我用的大。

实际上，Lorentz-Lorenz对水不太准。实验上水的(n²−1)/(n²+2)=0.206（从n=1.33）。这给出Nα_pol/(3ε₀)=0.206→α_pol≈1.63×10⁻²⁹ m³→大约是简单估计的10倍。这是因为液态水中分子间电荷转移和H键增强了极化率。

但我需要一个更物理的解释...

### 2.2 极化率→电子轨道→α

分子的电子极化率 α_pol ∝ (电子云体积) ∝ a₀³。

a₀ = ħ/(α m_e c) = 0.529 Å。→ α_pol ∝ 1/α³（精细结构常数）。

分子数密度 N ∝ 1/分子体积 ∝ 1/(键长³) ∝ 1/a₀³ ∝ α³。

所以 (n²−1) 中的乘积 N·α_pol ∝ α³ × (1/α³) = **常数**！

**SCVC关键洞察**：n−1到最低阶来自N·α_pol，而这两个对α的依赖恰好相消。因此水的折射率n≈1.33**几乎不依赖α的精确值**——它更依赖分子结构的几何（O-H键角104.5°、配位数~4的四面体H键网络）。

**n≈1.33是水的分子几何的直接后果，不是"α恰好调出来的"**。这和Pauling公式的1.00 eV系数一样——是自然单位的涌现。

### 2.3 验证：为什么n=1.33不是1.5？

如果水分子排列更紧密（冰）→N更大→n更大→冰的n≈1.31（反常！冰密度低）。

如果电子更易极化（更大的原子）→α_pol更大→n更大。CS₂(n≈1.63)→大极化率来自S的大电子云。

**SCVC：周期表中元素的折射率排序 = 电子云体积排序 = 轨道半径排序 = Z_eff排序。** 而Z_eff来自核电荷屏蔽→轨道能级∝α²Ry→**折射率的排序被α锁死，但每个分子的具体n值由分子几何决定。**

## 3. 色散——彩虹为什么有颜色

### 3.1 Cauchy公式

\[
n(\lambda) \approx A + \frac{B}{\lambda^2}
\]

水的A≈1.324, B≈3.1×10⁻³ μm²。

B来自：共振吸收在UV（~100nm，电子跃迁）和IR（~3μm，O-H伸缩）。可见光在中间→正常色散。

### 3.2 共振频率→轨道能级

UV吸收≈100nm（12.4 eV） → H₂O的σ→σ*跃迁或n→σ*跃迁。
这些跃迁能 → 分子轨道能级差 → 由O-H键的键能和O的孤对电子能量决定。
键能 → 库仑力 → α。孤对电子 → O的2p轨道 → Z_eff²·Ry → α²。

**SCVC**：B（色散强度）∝ 1/ω₀² ∝ 1/(α²·Ry)² → 色散由α锁定。

如果α大1%→UV共振蓝移~2%→B小~4%→色散更弱→彩虹更窄。

## 4. 副虹(51°)、日晕(22°)——α在天空中画的更多角

### 4.1 副虹：两次内反射

光线在水滴内反射两次→偏转角更大→彩虹角≈51°（n=1.33）。

\[
\cos i_{\text{min}} = \sqrt{\frac{n^2-1}{8}}
\]

代入n=1.33 → i≈71.8° → 彩虹角≈50.5°。颜色顺序反转（红内紫外）。

### 4.2 日晕22°

六角冰晶→折射+最小偏转→22°晕。

冰的n≈1.31。六角棱镜(60°顶角)：δ_min = 2·arcsin(n·sin(30°))−60°。

n=1.31 → δ_min ≈ 21.8° → **22°晕**。

**SCVC**：冰的n≈1.31 ← 冰的密度比水低→N更小→n略小。22°是冰晶六角几何×n_ice的组合。**任何有六角冰晶的行星大气→日晕永远≈22°。**
