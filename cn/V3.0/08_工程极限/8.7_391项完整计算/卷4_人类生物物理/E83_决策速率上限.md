## §1 每个决策的物理成本 — ATP 链条

### 1.1 底层：突触传递

一次突触传递的 ATP 预算(从 SCVC 化学键能正向推导):

`
动作电位到达突触前终扣
  → 电压门控Ca²⁺通道开放
  → ~100-200 Ca²⁺内流
  → 突触小泡融合, 释放 ~5000 神经递质分子
  → Ca²⁺由Ca²⁺-ATP酶泵出: 每Ca²⁺ ~1 ATP → ~150 ATP
  → 小泡回收(内吞+重填): ~10⁴ ATP/小泡

单次突触事件: ~1.5×10⁴ ATP
`

**SCVC 锁死: Ca²⁺泵出能量来自 ATP 0.55 eV, Ca²⁺梯度是电化学势差 ~200 mV × 2e ≈ 0.4 eV, 泵效率 ~70% → 恰好在 k_B T 标度上可逆。**

### 1.2 中层：动作电位

从 E28 的 Na⁺/K⁺-ATP 酶:

`
皮层局部回路神经元 (短轴突 ~0.5 mm):
  Na⁺内流/AP: ~10⁶-10⁷ 个
  Na⁺/K⁺-ATP酶: 3Na⁺/2K⁺/ATP
  ATP/AP: ~3×10⁵ (短轴突)

皮层锥体神经元 (长投射 ~5 cm):
  ATP/AP: ~3×10⁶
`

### 1.3 顶层：一个"决策"的皮层微环路

`
一个皮层"决策" = 吸引子网络从一个稳态跳到另一个稳态

涉及:
  → 10³-10⁵ 个突触同时参与竞争
  → 10²-10³ 个神经元改变发放率
  → 持续性活动维持决策结果 (~100-500 ms)

ATP 增量:
  简单检测(~10³突触): ~10⁷-10⁸ ATP
  选择判断(~10⁴突触): ~10⁸-10⁹ ATP
  复杂评估(~10⁵突触): ~10⁹-10¹⁰ ATP
  创造性判断(~10⁶突触): ~10¹⁰-10¹¹ ATP
`

### 1.4 大脑 ATP 预算验证

`

## §2 真实瓶颈 — 皮层时间常数 τ_m

### 2.1 从 α 到决策延迟

从 E82 的 SCVC 推导:

`
α
├─→ C-C 键长 1.54 Å → 脂双层疏水核心 5.5 nm
│   → C_m ≈ 0.4 μF/cm²
│
├─→ 蛋白质力常数 k ~10³ N/m → 离子通道构象动力学
│   → R_m ≈ 50,000 Ω·cm²
│
└─→ τ_m = R_m × C_m ≈ 20 ms (皮层锥体神经元)
`

**吸引子网络收敛:**

`
单次突触事件: AMPA 2-5 ms / NMDA 10-50 ms
突触整合: ~20 ms (EPSP/IPSP 求和)
侧抑制竞争: ~30-80 ms (皮层柱内动力学)
全网络吸引子收敛: 5-10 × τ_m = 100-200 ms
`

**SCVC 锁死: 任何皮层决策至少需要 ~100 ms 的收敛时间。这是 τ_m 的直接推论。**

### 2.2 决策层级 — 从 τ_m 推导

| 决策类型 | 涉及回路 | 最小收敛 | 理性上限 | 实测 |
|:---|:---|:---:|:---:|:---:|
| **脊髓反射** | 单突触/双突触 | 20-50 ms | 20-50/s | 膝跳 ~30 ms |
| **简单检测** | 感觉→运动 | 100-150 ms | **7-10/s** | 起跑反应 ~120 ms |
| **二择一** | 前额→运动 | 150-250 ms | **4-7/s** | 按键选择 ~200 ms |
| **N 择一 (Hick)** | 前额整合 | 200-500 ms | **2-5/s** | RT ∝ log₂(N) |
| **复杂评估** | 广泛皮层 | 500-2000 ms | **0.5-2/s** | 象棋 ~1-2 步/s |
| **创造性判断** | 默认+突显 | 2-10 s | **0.1-0.5/s** | 洞察 ~0.1/s |

### 2.3 速度-精度权衡的 SCVC 根源

`
决策信息量 = 速度 × 精度的乘积 ≈ 常数

RT (反应时) = a + b × log₂(N_options)    (Hick 定律)
  a ≈ 100-150 ms (感觉运动地板, τ_m 锁死)
  b ≈ 100-200 ms/bit (每比特处理时间, τ_m 锁死)

信息率 = log₂(N) / RT ≈ 1/b ≈ 5-10 bits/s/决策任务
→ 接近 E82 的 ~39 bits/s 但略低(单一任务 vs 多任务语言)
`

## §3 SCVC 决策带宽统一公式

### 3.1 三种"决策"的不同天花板

`
类型 A: 自动/无意识决策
  回路: 小脑+基底节, 非皮层
  时间: 50-100 ms
  速率: ~10-20/s
  实例: 网球回球, F1 换挡, 走路
  SCVC: 受限于小脑苔状纤维传导+浦肯野细胞 ~100 Hz

  回路: 前额-运动皮层

  实例: 交易员下单, 电竞瞄准, 飞行员检查单

  回路: 前额-颞叶-顶叶广泛网络
  时间: 1-10 s

  实例: 象棋走法, 投资策略, 科学假设

### 3.3 为什么不是 39/s？

`
E82 给出 39 bits/s 语言信息率
E83 给出 3-7 决策/s

差异来源:
  语言: 高冗余, 高可预测性, 每个词含 ~5-8 bits
  决策: 低冗余, 每个决策是离散选择 (含 ~1-5 bits)

统一: 总比特率 ≈ 39 bits/s (E82)
        → 简单决策 (1 bit/决策): ~39 决策/s (理论)
        → 选择决策 (3 bits): ~13 决策/s
        → 复杂决策 (10 bits): ~4 决策/s
        → 创造性 (40 bits): ~1 决策/s
        
实测: 所有人类皮层认知任务的信息率收敛到 ~30-50 bits/s
`

## §4 工程结论

### 4.1 三重墙

`
SCVC 决策天花板由三堵物理墙同时锁死:

墙 1: τ_m ≈ 20 ms → 皮层吸引子收敛 ≥ 100 ms
        → 任何有意识决策不可能快于 ~10/s

墙 2: 39 bits/s → 总认知带宽
        → 决策数 × 每决策信息 ≤ 39

墙 3: ATP 预算 (虽非瓶颈但设上限)
        → 持续高速决策会耗尽可用能量
        → 精神疲劳 = 腺苷累积 → A1 受体 → 前额叶抑制
`

### 4.2 可证伪预言

1. **任何人类在任何任务中的有意识决策速率不可能持续超过 ~10/s** —— τ_m 锁死
2. **Hick 定律的斜率 b ≈ 100-200 ms/bit 对所有人类恒定** —— τ_m 是物理常数
3. **速度-精度乘积 ≤ ~39 bits/s 对所有认知任务成立**
4. **AI 不受此限** —— 硅的 τ 比生物膜快 ~10⁶×
5. **脑机接口绕不过 τ_m** —— 皮层神经元膜电容是物理常数，除非换神经元
