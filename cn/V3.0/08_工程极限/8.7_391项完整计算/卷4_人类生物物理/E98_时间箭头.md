## §3 为什么我们记得过去却不记得未来？

`
记忆 = 大脑中低熵的突触权重模式(E84)

过去 → 现在:
  → 过去的事件(低熵) → 在我们的脑中留下痕迹
  → 痕迹 = 神经元放电 → LTP → 突触权重改变
  → 这是熵增过程(信息写入 = 局部熵减, 伴随全局熵增)

  → \"未来的记忆\" = 未发生的事件在我们脑中留下痕迹
  → 这要求: 突触权重\"提前\"改变以匹配未来的输入
  → 这等价于: 从高熵态自发涨落出低熵的记忆
  → 概率: exp(−记忆的比特数) ≈ exp(−10¹⁵)
  → 永不发生

你记得过去不记得未来——
  不是因为时间\"流动\"
  是因为记忆形成是熵增过程,
  而宇宙从低熵走向高熵。
`
