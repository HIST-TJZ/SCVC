# 第一部分：蓝天为什么是蓝色

## 1. Rayleigh散射 → λ⁻⁴

散射截面（偶极辐射，粒子<<波长）：
\[
\sigma_R = \frac{8\pi^3}{3}\frac{(n^2-1)^2}{N^2\lambda^4}
\]

蓝光450nm vs 红光700nm：σ_蓝/σ_红=(700/450)⁴=**5.86**。

## 2. n−1 → 分子极化率 → α

(n²−1)∝N·α_pol。N₂极化率≈1.74×10⁻³⁰ m³→来自N≡N三键的电子云→分子轨道→束缚能∝α²·Ry。

**关键**：N∝1/分子体积∝1/a₀³∝α³。α_pol∝电子轨道体积∝a₀³∝1/α³。→**(n²−1)中的α因子相消**。和彩虹42°同构。✅

## 3. 为什么是蓝色不是紫色

- Rayleigh σ∝λ⁻⁴→紫光(400nm)>蓝光(450nm)→1.6×
- 太阳Planck谱：400nm≈0.6×450nm的强度
- 人眼V(λ)：400nm≈0.004×450nm的灵敏度
- 组合：蓝光(470nm)峰值→**纯蓝**。✅

## 4. 日落红色

地平线→大气质量~40×天顶。τ_蓝≈20→衰减e⁻²⁰≈2×10⁻⁹。τ_红=20×(450/700)⁴≈3.5→仍有3%到达→日落红色。

## 5. 火星天空反向——验证

火星大气薄(6mbar)→Rayleigh弱。尘埃Mie散射主导→白天橙红，**日落蓝色**。好奇号拍摄验证✅。

# 第二部分：恒星质量窗口 [0.08, 300] M_⊙

## 6. 下限：氢点火

p-p链需要T_c>3×10⁶ K（Gamow穿透库仑势垒）：
\[
\text{Gamow} \propto \exp\left(-\sqrt{\frac{E_G}{E_{\text{cm}}}}\right)
\]

E_G=2m_r(πα)²≈247 keV（两质子）。T_c=3×10⁶ K→E_cm≈0.4 keV→Gamow≈1.5×10⁻¹¹。

太阳核心功率密度仅276 W/m³→需要巨大体积→M>0.08 M_⊙。

**α敏感性**：α大1%→E_G大2%→Gamow因子小~25%→M_min更大→更少的恒星。

## 7. 上限：爱丁顿极限

L_Edd=4πGMc/κ。κ∝α²（Thomson散射）。L∝M^3.5。→M_max∝1/α²。

R136a1~265 M_⊙→已近天花板。

## 8. 恒星质量窗口 = α的指纹

```
[0.08, 300] M_⊙ = α定义的氢燃烧范围
  ├─ M_min ← Gamow ∝ exp(−1/α)
  └─ M_max ← κ ∝ α²
```
