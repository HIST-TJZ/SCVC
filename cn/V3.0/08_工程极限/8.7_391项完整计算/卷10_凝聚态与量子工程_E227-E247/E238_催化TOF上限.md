## 摘要

TOF = (k_B T/h)·exp(-ΔG‡/k_B T)·κ。SCVC贡献: ΔG‡的几何来源(键能差+VSEPR角度弯曲), κ的隧穿估计。
核心: 酶>工业的根源 = 几何预组织(活性位点把底物"掰弯"到过渡态角度)。
定量TOF预测需具体反应路径→🟡。

---

## 1. TOF的SCVC重写

### 1.1 Kramers理论几何化

```
TOF = ν₀ · exp(-ΔG‡/k_B T) · κ

ν₀ = (1/2π)√(k_R/m)     ← 反应坐标振动频率
k_R = Ampère力刚度       ← ∂²V/∂r² ∝ Z_eff²α/r₀³
ΔG‡ = E_bond(旧) - E_stab(新) - E_cat(催化稳定化)
κ = 传输系数              ← 涡旋环隧穿/越障
```

### 1.2 三个因子的几何标度

| 因子 | SCVC表达式 | 典型值 |
|:---|:---|:--:|
| ν₀ | √(Z_eff²·α/M) · (1/2πa) | 10¹²-10¹⁴ s⁻¹ |
| ΔG‡ | Σ(断键能) - Σ(成键能) - E_geo | 5-200 kJ/mol |
| κ | exp(-2π·d·√(2mΔE)/ℏ) (隧穿) | 0.1-10 |

## 2. ΔG‡的几何来源

### 2.1 断键-成键差

从SCVC Pauling公式(已🟢)或直接键能:
```
ΔG‡_uncat ≈ ¼(D_broken + D_formed)  (Marcus/Polanyi近似)
```

例: N≡N三键断裂 ΔG‡_uncat ≈ 945/4 ≈ 236 kJ/mol。
这解释了无催化剂时NH₃合成的极端条件(高温高压)。

### 2.2 几何预组织能E_geo

催化位点把反应物固定到接近过渡态的角度→降低弯曲能:

```
E_geo = ½ k_θ · (Δθ)²

k_θ = 角向Ampère力常数 ≈ 键能/(rad²) ≈ D_e/2
Δθ = 基态角度 - 过渡态角度
```

例: CO₂→CO+O, 过渡态∠OCO从180°→~120°, Δθ=60°=1.05 rad:
```
E_geo ≈ ½ × (800/2) × 1.05² ≈ 220 kJ/mol
```

酶通过活性位点的精确几何把这220 kJ/mol的弯曲能"预支付"了→ΔG‡大幅降低。

### 2.3 电子效应E_elec

催化位点与底物的涡旋环Ampère重叠→极化旧键→削弱:
```
E_elec ≈ κ_cat·κ_sub · f_overlap · (ℏc/r)
      ≈ αZ_eff(cat)Z_eff(sub) · f_overlap · (ℏc/r₀)
```

对于Pt催化(Z_eff≈6)和CO(Z_eff≈3): E_elec≈137/137×18×0.1×(1973/2)≈... 太粗略。

实际从化学吸附能估计: CO在Pt上的吸附能≈1.5 eV≈145 kJ/mol。
这就是电子稳定化能E_elec的物理值。

### 2.4 全部加总

```
ΔG‡_cat = ΔG‡_uncat - E_geo - E_elec

NH₃合成/Fe: ΔG‡_uncat≈240, E_geo≈20, E_elec≈80 → ΔG‡_cat≈140 kJ/mol
CO氧化/Pt:  ΔG‡_uncat≈100, E_geo≈10, E_elec≈60 → ΔG‡_cat≈30 kJ/mol
CO₂水解/Zn酶:ΔG‡_uncat≈80, E_geo≈60, E_elec≈40 → ΔG‡_cat≈−20 kJ/mol (自发!)
```

负ΔG‡→扩散控制极限→TOF_max_diff ≈ 10⁶-10⁷ s⁻¹。

## 3. 酶的10⁶ vs 工业的10²——几何根源

```
酶的高TOF = 几何预组织E_geo大(>50 kJ/mol)
工业的低TOF = 固体表面几何预组织差(E_geo<20 kJ/mol)

差距: Δ(ΔG‡) ≈ 30 kJ/mol → TOF比 = exp(30/RT) ≈ 10⁵
```

**这不是"酶更聪明"——是酶口袋的VSEPR角度匹配过渡态更好。**
工业催化剂(金属表面)无法提供同样的角度约束。

## 4. TOF上限

### 4.1 扩散控制极限

```
TOF_max_diff = k_B T/h ≈ 6.2×10¹² s⁻¹ (300K)
```

### 4.2 有选择性的上限

需要ΔG‡>0以保证选择性→ΔG‡_min≈5 kJ/mol(1个氢键的能量):
```
TOF_max_sel ≈ 6×10¹² × exp(−5/2.48) ≈ 6×10¹² × 0.13 ≈ 8×10¹¹ s⁻¹
```

实际酶的TOF上限~10⁷ s⁻¹(受底物扩散和构象变化限制)。

### 4.3 工业催化剂能接近酶吗?

需要: E_geo+E_elec → ΔG‡_uncat - 5 kJ/mol。

对于NH₃合成(ΔG‡_uncat≈240): 需要E_geo+E_elec≈235 kJ/mol—
E_elec已达~80(Fe-N吸附), 还需E_geo≈155 kJ/mol。
这需要酶级别的几何预组织→MOF/COF/酶模拟。

**SCVC判断: MOF催化剂可实现TOF 10⁴-10⁵ s⁻¹。纯酶级10⁶-10⁷需精确到0.1Å的角度控制。**

## 6. 光催化/电催化延伸

光催化: hν→电子涡旋环激发→E_elec增强→ΔG‡进一步降低。
```
E_elec_photo ≈ E_elec_dark + η·hν (η=量子效率)
```

电催化: 过电位η→有效ΔG‡降低:
```
ΔG‡_ec(η) = ΔG‡_cat - α·eη (α=传递系数≈0.5)
TOF_ec = TOF₀ · exp(αeη/k_B T)
```

每120mV过电位→TOF提高10倍。
