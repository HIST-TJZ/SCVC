# 一、中间态从哪来——为什么它们存在

## 1.1 根源：组合爆炸

任意N输入M输出的函数→真值表2^N行。N=32→4G行→物理上不可能直接存储→必须分解为多级门→每级输出=下一级输入→**中间态**。

## 1.2 中间态的物理代价

```
创造中间态:  电容充电 → ~5×10⁻¹⁸ J (已算E265)
擦除中间态:  Landauer → kT ln 2 ≈ 3×10⁻²¹ J
```

**看似擦除更便宜？不。** 中间态被创造+擦除→两个步骤都得付。一个FP32 FMA(~5pJ)中，~95%是中间态的创造/擦除循环，仅~5%是"真正需要的逻辑结果"。

## 1.3 SCVC量化

| 操作 | 总能耗 | 中间态擦除占比 | "净逻辑"能耗 |
|:---|:---|:---|:---|
| INT加法 | ~0.1 pJ | ~90% | ~0.01 pJ |
| FP32 FMA | ~5 pJ | ~95% | ~0.25 pJ |
| FP64除法 | ~100 pJ | ~99% (迭代10步) | ~1 pJ |
| sin/cos (CORDIC) | ~1000 pJ | ~99.9% (多步迭代) | ~1 pJ |

**结论**：当前计算的能耗几乎全是中间态的代价。消除中间态擦除→能耗降10-1000×。

# 二、直通计算的本质

## 2.1 定义

**直通计算** = 输入→信号路由→输出，**零中间态擦除**。

不是"没有中间态"（信号传播必然经过多个物理节点），而是"中间态不被擦除"——每个中间结果保留在它自己的寄存器/线路上，消费它的下一级只是读取，不擦除。

## 2.2 信息守恒视角

```
传统计算: 输入 → [中间1] → [擦除] → [中间2] → [擦除] → 输出
           创造    消灭      创造    消灭
           熵增↑              熵增↑

直通计算: 输入 → 中间1 → 中间2 → ... → 输出
           保留    保留          保留
           零熵增（可逆极限）
```

# 三、四条路线

## 路线1：FPGA/LUT路线（小函数直通）

| 参数 | 值 | SCVC |
|:---|:---|:---|
| K-LUT | K=6→64bit表→寄存器级 | 零中间态 |
| 单LUT延迟 | ~0.1ns | RCl |
| 单LUT能耗 | ~0.1pJ | 电容充电 |
| 互联延迟 | 1cm=70ps | 光速墙🟢 |
| 互联能耗 | ~1pJ/cm | 线电容 |

**瓶颈**：互联压倒LUT。10×10cm FPGA上，跨芯片=700ps→已超单LUT延迟→多级LUT级联的总延迟被光速锁死。

## 路线2：ASIC硬连线（纯组合逻辑）

直接综合为门级组合逻辑——零寄存器、零擦除。

N=32任意函数→几千门→可行。最大N受限于：
- 门扇入(~4-5)
- 线延迟(~1ps/μm)
- 关键路径深度log₂N

**能耗**：仅门电容充电→~0.01 pJ/门×几千门→~几十pJ→比FP32 FMA(~5pJ)的GPU路径（多级流水线+寄存器+擦除）**省10-100×**。

## 路线3：CAM/关联存储器路线（硬件查表）

CAM=输入匹配→并行比较所有条目→输出。N输入→2^N条目→O(2^N)能耗。

| N | 条目数 | 能耗 | 判定 |
|:---|:---|:---|:---|
| 8 | 256 | ~10 pJ | ✅ L1级 |
| 12 | 4096 | ~100 pJ | 🟡 L2级 |
| 16 | 65536 | ~1000 pJ | 🔴 开始吃亏 |
| 20 | 1M | ~10⁴ pJ | ❌ |

**SCVC**：CAM直通在N<12时优于ALU。这正是FPGA LUT的工作原理——K=6→64条目→完美。

## 路线4：光子/模拟路线（终极直通）

一个透镜做傅里叶变换：光场进入→衍射→焦平面=频谱。**零中间态、零焦耳热。**

| | 电子 | 光子 |
|:---|:---|:---|
| 信号载体 | 电荷(e⁻) | 光子(γ) |
| 焦耳热 | 有(I²R) | **零** |
| 能耗地板 | 电容~5×10⁻¹⁸ J | 散粒噪声~1.4×10⁻¹⁷ J |
| 互联延迟 | RC+光速 | **仅光速** |
| 傅里叶变换 | O(N log N)门 | **1个透镜** |

**SCVC**：光子散粒噪声地板~88eV/bit≈1.4×10⁻¹⁷ J——比电子(~5×10⁻¹⁸ J)高~3×。但光子在长距离互联上碾压电子（零焦耳热+仅光速延迟）。

# 四、实例：直通加法器

## 4.1 进位传递=不可避免的中间态

8bit加法→进位从bit0传到bit7→8级依赖→8个中间态→全部被擦除。

## 4.2 进位选择加法器=消除中间态

```
传统: A₀+B₀ → c₁ → A₁+B₁+c₁ → c₂ → ... → 8级传播

直通: 预计算每4bit块的"进位=0/1两种情况"
      → 2×16=32条目→64B→寄存器级
      → 高位块根据实际进位→多路选择
      → 3级(2×4bit查表+1次MUX)→零进位传播
```

**结果**：8bit加法=3级→~0.3ns, ~0.3pJ。业界已经这样做了——Carry-Select Adder。原理正是"消除中间态传播"。

# 五、可逆计算——终极理论

## 5.1 Bennett 1973

可逆逻辑门（Fredkin, Toffoli）：输入数=输出数→信息守恒→**零Landauer代价**。垃圾输出保留或逆向计算清除。

## 5.2 空间/时间换能量

| 策略 | 代价 | 收益 |
|:---|:---|:---|
| 保留所有中间态 | O(N)存储 | 零擦除能耗 |
| 逆向计算清除 | O(2N)时间 | 零擦除+零存储 |
| 混合(检查点) | O(√N)存储, O(N√N)时间 | 最优trade-off |

## 5.3 为什么还没商用

Landauer擦除(~3×10⁻²¹ J)远小于电容充电(~5×10⁻¹⁸ J)。**当前瓶颈不是擦除——是创造中间态（电容充电）。** 消除擦除只省了0.1%的能耗。必须先解决电容充电问题→3D堆叠缩短线长→降低C→才能让可逆计算变得有意义。
