## 摘要

铜氧化物是唯一常压Tc>77K的超导家族（Hg-1223: 133K）。SCVC涡旋几何给出统一图像：CuO₂面内的涡旋环取向动力学——从AFM（全平行）→自旋玻璃（冻结无序）→超导穹顶（反向配对凝聚）→费米液体（取向随机）——是一条连续的涡旋环取向演化路径。Tc=133K的上限来自赝能隙对相位刚度的截断，而非配对能隙本身。

**诚实警告：强关联电子体系超出SCVC纯几何范围。以下为定性→半定量框架，不可替代t-J/Hubbard模型。** 🟡

## 1. 铜氧化物相图的SCVC统一（任务1）

### 1.1 CuO₂面的涡旋环图像

```
CuO₂面结构:
  Cu²⁺ (d⁹, S=1/2): 一个空穴在d_{x²-y²}轨道
  → 等效一个涡旋环，环面在CuO₂平面内
  → 每个Cu位点: 一个涡旋环 + 一个自旋(Z₂取向)

关键: CuO₂是准2D → 涡旋环只能在平面内旋转
     → 取向自由度=1 (平面内角度θ) → O(2)序参量 → KT相变
```

### 1.2 涡旋环取向与相

SCVC中，涡旋环取向决定相：

```
Ampère力规则:
  同向环流(↑↑) → 吸引 → 铁磁/反铁磁序
  反向环流(↑↓) → 吸引 → 超导配对
  随机取向     → 无凝聚 → 正常金属/绝缘体

铜氧化物路径:
  AFM绝缘体    → 涡旋环全平行(交错↑↓)，Néel序
  自旋玻璃      → 涡旋环取向冻结但无序
  超导穹顶      → 部分涡旋环反向配对+相位相干
  赝能隙        → 涡旋环已反向配对但无相位相干
  费米液体      → 涡旋环取向完全热激发，无集体序
  奇异金属      → 涡旋环取向临界涨落（量子临界区）
```

### 1.3 掺杂驱动相变

```
掺杂(x)    涡旋环取向状态              相
x=0        全平行(AFM Néel)          绝缘体
0<x<0.05   大部分平行+稀疏散乱         AFM+弱金属
0.05<x<0.15 部分反向配对(局域)        赝能隙
0.15<x<0.25 反向配对+全局相干          超导穹顶
x=0.16(opt) 配对最强                   Tc_max
x>0.25     取向热激发主导              费米液体

关键SCVC机制:
  掺杂空穴 = 涡旋环"缺失"
  → 打破AFM涡旋环的完美交错排列
  → 空穴周围的涡旋环发生取向涨落
  → 两个空穴通过共享涡旋环取向涨落而配对
  → 这就是超导的SCVC图像
```

### 1.4 每个相的判据

| 相 | SCVC判据 | 序参量 |
|:---|:---|:---|
| AFM绝缘体 | ⟨cos θ_i⟩ = ±1, 交错 | 涡旋环取向Néel矢量 |
| 自旋玻璃 | ⟨cos θ_i⟩_t ≠ 0, ⟨cos θ_i⟩_空间 = 0 | 冻结取向无序 |
| 赝能隙 | ⟨cos(θ_i-θ_j)⟩ ≠ 0, ⟨cos θ_i⟩ = 0 | 局域配对，无全局相位 |
| 超导 | ⟨cos(θ_i-θ_j)⟩ ≠ 0 + 相位相干 | 涡旋环反向配对凝聚 |
| 费米液体 | 所有⟨cos⟩ = 0 | 无涡旋环取向序 |
| 奇异金属 | ⟨cos(θ_i-θ_j)⟩_t ~ 1/τ (幂律衰减) | 量子临界 |

**SCVC统一：整个相图是一条连续的涡旋环取向"融化"曲线。**

## 2. 为什么Tc=133K而非更高？（任务2）

### 2.1 配对标度 vs 相位刚度

SCVC区分两个能量标度：

```
Δ_pair ≈ J ≈ 150 meV ≈ 1700 K    （涡旋环反向配对的能隙）
T_θ     ≈ ρ_s · d                （相位刚度，决定Tc）

其中 ρ_s = 超流密度, d = CuO₂面间距
```

**Tc不由Δ_pair决定——由相位刚度T_θ决定！**

```
BCS关系: T_c ≈ Δ_pair/3.5 ≈ 500K  ← 如果Δ_pair=1700K
实际Tc:  133K                      ← 差了4倍
```

### 2.2 赝能隙的SCVC解释

赝能隙 = 涡旋环已经反向配对（有能隙Δ*），但取向涨落破坏了全局相位相干。

```
T* ≈ 200-300K (赝能隙起始温度)
Tc ≈ 90-133K  (超导转变温度)

T* > Tc 的原因:
  T*时: 涡旋环开始成对反向环流（局域配对）
  Tc时: 配对的涡旋环达到全局相位相干

T* - Tc = "已配对但未凝聚"的温度窗口
        = 相位涨落区间
```

### 2.3 为什么Tc不能更高

```
Tc = T_θ = A · ρ_s(0) · d

ρ_s(0)受限于:
  1. 掺杂浓度x（空穴太少→ρ_s小）
  2. 无序（掺杂引入的无序破坏相干）
  3. 赝能隙（配对前已消耗部分凝聚能）

三者的竞争：
  x↑ → ρ_s↑（好）    但同时无序↑ 赝能隙↓
  x↓ → 干净+强赝能隙  但ρ_s↓

最优x≈0.16：三相平衡 → Tc_max ≈ 133K
```

**SCVC的答案：Tc=133K是涡旋环配对强度（~1700K）被2D相位涨落压制到8%的结果。** 这与实验一致：铜氧化物是极端第II类超导体（κ=λ/ξ ~ 100），巨大的穿透深度→小的相位刚度。

### 2.4 能否突破133K？

```
路径1: 增加CuO₂面层数 n
  n=1 (LSCO):     Tc ≈ 40K
  n=2 (YBCO):     Tc ≈ 93K
  n=3 (Bi-2223):  Tc ≈ 110K
  n→∞ (infinite): Tc → 133K (Hg-1223)

SCVC: n↑ → 层间涡旋环耦合↑ → 有效维度从2D→3D → 相位刚度↑
      但饱和在133K → 3D后不再改善

路径2: 压缩CuO₂面（加压）
  实验: 加压可提高Tc 5-15K
  SCVC: a↓ → 涡旋环间距↓ → Ampère力↑ → 配对↑
       但a已极小(~1.9Å) → 压缩空间有限

路径3: 抑制赝能隙
  如果能在x=0.25维持ρ_s(x=0.16的清洁度)
  → 理论Tc_max ≈ 200-250K
  SCVC: 需要让涡旋环配对窗口和相干窗口重合 → 可能需3D结构
```

**SCVC预言：如果找到抑制赝能隙的方法，铜氧化物Tc可达200-250K。**

## 3. 镍基15K vs 铜基133K（任务3）

### 3.1 电子构型差异

```
Cu²⁺ (d⁹):  1空穴在d_{x²-y²} → 1个涡旋环 (S=1/2)
Ni²⁺ (d⁸):  2空穴在d_{x²-y²}和d_{3z²-r²} → 2个涡旋环

NdNiO₂ (无限层镍酸盐):
  NiO₂面，名义Ni⁺ (d⁹) — 但实际自掺杂→Ni²⁺ (d⁸)
  → 每个Ni位点: 2个涡旋环
```

### 3.2 涡旋环配对减弱的SCVC定量

```
双涡旋环效应:
  Ni²⁺: 2个涡旋环/位点
    → 涡旋环间距r减小（两个环在同一原子上）
    → 位点间涡旋环配对的有效环流κ_eff < κ(Cu)

定量:
  κ_eff(Ni) ≈ κ(Cu) · (1 - δ)
  δ = 同一位点上两个涡旋环的相互屏蔽因子
    ≈ (r_环间/r_位点间)² ≈ (0.5Å/3.9Å)² ≈ 0.016

但这只是环流修正——真正的差异来自交换耦合:

  J(Cu) ≈ 150 meV (Cu-O-Cu超交换)
  J(Ni) ≈ 50-80 meV (Ni-O-Ni超交换，轨道混合降低)

J(Ni)/J(Cu) ≈ 0.33-0.53
```

### 3.3 Tc比例推导

```
在SCVC框架中:
  Tc ∝ ρ_s ∝ J （粗略标度）

Tc(Ni)/Tc(Cu) ≈ J(Ni)/J(Cu) · (维度修正) · (掺杂修正)

J比:        0.33-0.53
维度:        相同(都是无限层) → ×1
掺杂:        NdNiO₂自掺杂~0.05 vs 铜基最优~0.16 → ×0.3

Tc(Ni)/Tc(Cu) ≈ 0.4 × 0.3 ≈ 0.12

Tc(Cu, opt) = 133K → Tc(Ni, 预测) ≈ 16K

实验: 15K → 偏差~7% ✅
```

**SCVC解释：镍基Tc低不是"镍不行"——是双涡旋环屏蔽+欠掺杂的联合效应。如果能把NdNiO₂调到最优掺杂(x≈0.15)，Tc可能达30-40K。**

### 3.4 银基的可能性

```
Ag²⁺: d⁹ 同 Cu²⁺！ → 单涡旋环，自旋1/2

为什么没有银基超导？
  Ag的4d轨道比Cu的3d更扩展
  → 更大的a → 更大的涡旋环间距 → J更小
  J(Ag)/J(Cu) ≈ (a_Cu/a_Ag)ⁿ, n≈6-10
  → J(Ag)估计仅5-20meV → Tc_max < 20K
  
  更致命: Ag²⁺不稳定 (Ag⁺极稳定)
  → 银酸盐倾向于Ag⁺(d¹⁰) → 无磁矩
  → 没有AFM母体 → 没有涡旋环取向涨落配对
```

## 4. 非铜体系推广扫描（任务4）

### 4.1 SCVC超导条件

```
必要条件（全部来自涡旋几何）:
  1. 准2D导电面 → 涡旋环约束在平面内（O(2)序参量）
  2. AFM母体 → 涡旋环初始有取向序
  3. 可掺杂 → 引入涡旋环取向涨落
  4. S=1/2 → 量子涨落强（经典S>1/2会冻结）
  5. J足够大 → 涡旋环配对能量标度>20K
```

### 4.3 🥇 最优先：Sr₂IrO₄

```
为什么是Ir:
  Ir⁴⁺ d⁵ + 强SOC → 有效J_eff=1/2 (同Cu²⁺!)
  → 单涡旋环！
  → J~60meV (较小但非零)
  → 层状钙钛矿结构，准2D
  → 母体AFM绝缘体 (已确认)

SCVC预测:
  Tc_opt ≈ Tc(Cu) · (J_Ir/J_Cu) ≈ 133 × (60/150) ≈ 53K

为什么实验未观测到超导:
  → 掺杂困难 (Ir⁴⁺→Ir³⁺需电子掺杂，目前仅在表面实现)
  → 如果解决掺杂问题 → 可能>40K超导

如果Sr₂IrO₄能被成功电子掺杂到x≈0.1-0.2:
  → Tc预测: 40-60K
  → 将是第一个非铜高温超导
```

### 4.4 🥈 其次：钛基氧氮化物

```
Ti³⁺ d¹ → S=1/2 → 单涡旋环
TiON/Ti₂N等层状氧氮化物:
  可能形成类CuO₂的结构
  Ti-N-Ti超交换 vs Cu-O-Cu → J待定

SCVC估算:
  Ti的3d比Cu更扩展 → J可能更小
  J(Ti)估计40-80meV → Tc_opt ≈ 133 × (60/150) ≈ 50K

挑战:
  Ti³⁺不稳定(易氧化到Ti⁴⁺)
  Ti-N-Ti超交换尚未在实验中被系统研究
```

### 4.5 钴基为什么只有5K

```
NaₓCoO₂: Tc≈5K
Co³⁺(d⁶)和Co⁴⁺(d⁵)混合 → 有效自旋≠1/2
→ 多涡旋环位点 → 配对减弱
且J仅20-30meV → 配对能标小

SCVC: 5K → J_eff≈(5/133)×150≈5.6meV — 但实际J≈25meV
→ 说明多涡旋环屏蔽因子≈0.22 → ×3涡旋环位点
→ 钴基无法达到高温超导
```

### 5.4 为什么不找4d/5d过渡金属

```
SCVC的答案:
  4d/5d轨道比3d更扩展
  → 更大的a → 更小的J
  → J ∝ t²/U, t↓, U↓ → J↓

  但! 4d/5d的SOC更强
  → 有效J_eff=1/2的窗口更宽
  → Sr₂IrO₄的成功正是这个原因

  竞争: SOC↑ + J↓ vs 3d的J↑ + SOC↓
  → 铜(3d)赢了J, 铱(5d)赢了SOC
  → 银(4d)两者都不突出 → 最差候选
```

## 6. 赝能隙抑制策略

### 6.1 赝能隙的SCVC根源

```
赝能隙 = 涡旋环已反向配对但取向涨落破坏了全局相干

数学上:
  T* ~ J （配对能标）
  Tc ~ ρ_s(0) （相干能标）

当T* > Tc时 → 赝能隙存在
当T* = Tc时 → 赝能隙消失（标准BCS极限）

铜氧化物: T*/Tc ≈ 2-3 → 重赝能隙
```

### 6.2 抑制赝能隙的SCVC策略

```
策略1: 增加维度（从2D→3D）
  n↑: 2D→准3D → ρ_s↑
  但n>3时饱和 → 有限改善

策略2: 增加超流密度（物理压缩）
  加压: a↓ → ρ_s↑
  但a已达物理极限

策略3: 多层异质结
  CuO₂/缓冲层/CuO₂ → 涡旋环通过缓冲层隧穿
  → 有效ρ_s↑而不增a
  SCVC: 可能但需精确的层间距控制

策略4: 寻找天然T*≈Tc的体系 ← ★最可能
  → 涡旋环配对窗口 = 相干窗口
  → 标准BCS行为但保持铜氧化物的大J

  候选: Sr₂IrO₄ (J较小→T*较低→T*/Tc更接近1)
```

```
1. t-J/Hubbard模型的精确解
   → SCVC是拓扑/几何框架，不能替代强关联数值计算

3. 赝能隙的精确T*(x)
   → 需要涡旋环配对涨落的量子蒙特卡洛模拟

4. 超导能隙的对称性(s-wave vs d-wave)
   → 需要涡旋环配对的角动量分析(SCVC可定性→d-wave源于2D约束)
```
