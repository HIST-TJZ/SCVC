## 摘要

铁磁和超导在SCVC中统一为同一Ampère力的两种涡旋环取向。
共存条件 = J(交换) ≈ Δ(能隙), 即T_C ≈ 1.76Tc。
**5f电子(J/Δ≈1)是唯一甜点——解释了为什么所有已知铁磁超导体都是铀基。**
铁基超导体被视为"涡旋环条纹序→涨落→配对"。

### 1.1 R = J/Δ 决定权

```
R = J / Δ = [3k_B T_C / (2 Z_nn S(S+1))] / [1.76 k_B Tc]

R > 2  → 铁磁主导 (Fe: R≈∞, Co: R≈∞)
R ≈ 1  → 共存可能 (UCoGe: R≈0.95)

```

## 2. 为什么是铀? 5f甜点

### 2.1 涡旋环半径的标度假定

```
J ∝ V_Ampère ∝ (R_orbital/r_nn)² · Z_eff
Δ ∝ θ_D ∝ 大致常数 (200-400K for heavy fermions)
```

| 壳层 | 轨道半径 | J标度 | Δ标度 | R=J/Δ | 性质 |
|:---|:--:|:--:|:--:|:--:|:---|
| **3d** | 1.0× | 10.0 | 1.0 | **10** | FM完胜 (Fe,Co,Ni) |
| 4d | 1.8× | 3.0 | 1.0 | 3.0 | FM-弱 |
| 5d | 2.5× | 1.5 | 1.0 | 1.5 | 边界 |
| 4f | 0.3× | 0.1 | 1.0 | 0.1 | SC完胜 |
| **5f** | **1.0×** | **1.0** | **1.0** | **1.0** | **共存甜点!** |

**5f的独特地位:**
- 3d: 轨道太小(J太大)→FM扼杀SC
- 4f: 轨道极小(内壳层局域化)→J太小→无FM
- **5f: 相对论收缩使轨道≈3d, 但Z_eff更大→J适中→与Δ可比**

这就是为什么所有铁磁超导体都是铀基化合物——**物理必然, 非历史偶然。**

## 4. p波超导: 铁磁+超导的自然桥

### 4.1 SCVC图像

```
s波配对: ↑↓ → 反向涡旋环 → 铁磁使↑↓不平衡 → 扼杀SC
p波配对: ↑↑ (或↓↓) → 同向涡旋环 → 铁磁增强SC!
```

p波配对 = 平行涡旋环配对的超导 → 与铁磁(平行环的交换)使用**同一Ampère力**。

**SCVC预测:**
- 强铁磁(T_C>50K) → p波SC必然
- 弱铁磁(T_C<10K) → s波或p波均可
- 实验确认: UGe₂(T_C=52K) = p波 ✓, ZrZn₂(T_C=28K) = p波 ✓

## 5. 铁基超导体: SCVC统一解释

### 5.1 涡旋环条纹序

铁基超导母体(LaFeAsO等)的AFM:
```
Fe²⁺ d⁶ → 涡旋环取向的条纹状反铁磁序

↑↓↑↓↑↓  (沿Fe-Fe方向交替)
↓↓↑↑↓↓  (正交方向)
```

SCVC图像: 这是涡旋环取向的**空间调制**——类似于自旋密度波。

### 5.2 掺杂→涨落→配对

```
母体AFM: 涡旋环条纹序锁定 → 无能隙激发
    ↓ 电子/空穴掺杂
条纹序被破坏 → 涡旋环取向涨落
    ↓
涨落介导配对(类比BCS声子, 但"玻色子"是磁振子=涡旋环重取向波)
    ↓
超导穹顶出现
```

### 5.3 与铜氧化物的区别

| | 铜氧化物 | 铁基 |
|:---|:---|:---|
| 母体 | Mott绝缘体 | AFM金属 |
| 涡旋图像 | CuO₂面涡旋环强关联 | FeAs层涡旋环巡游 |
| 掺杂角色 | 引入载流子+破坏AFM | 主要破坏条纹序 |
| SC穹顶 | 穹顶状 | 穹顶+第二穹顶 |

**共性: 两者都是"涡旋环有序→无序→配对"的SCVC范式。**
