## 摘要

激子凝聚 = 电子-空穴涡旋环对的反向环流Bose凝聚(与超导同机制)。
量子自旋液体 = 几何阻挫晶格上涡旋环自旋的无序基态。

# 第一部分: 激子凝聚

## 1. SCVC激子图像

### 1.1 激子 = 固体中的"氢原子"

```
电子涡旋环(负环流) + 空穴涡旋环(正环流)
        ↓ Ampère吸引
    激子 = 涡旋环对束缚态
```

这与Rydberg激子(电子-空穴对)的图像一致, 但SCVC用涡旋环Ampère力替代了Coulomb力作为束缚机制。

### 1.2 激子结合能

```
E_bind = (μ/ε²) · Ry*

μ = m_e m_h/(m_e+m_h): 约化有效质量
ε: 介电常数(屏蔽)
Ry* = 13.6 eV · (μ/m_e) / ε²: 有效Rydberg
```

SCVC贡献: ε来自晶格极化(涡旋环重排的Ampère响应), μ来自能带结构(涡旋环惯性)。

### 1.3 激子Bose凝聚条件

```
Tc_BEC ≈ 3.31 ℏ² n_exciton^(2/3) / (m_exciton k_B)

n_exciton > n_Mott: 激子波函数开始重叠
   nMott⁻¹ ≈ (4π/3) a_exciton³
   a_exciton = ε · a₀ / (μ/m_e): 激子Bohr半径
```

**激子凝聚 ⇔ n_exciton · a_exciton³ > 0.24 (Mott判据)。**

## 2. 材料条件

### 2.1 需要什么?

1. **小ε**: 弱屏蔽→大E_bind→激子在室温稳定
2. **小μ**: 小有效质量→大a_exciton→低Mott密度
3. **直接带隙**: 光激发直接产生激子
4. **长寿命**: 激子复合慢→积累到临界密度

## 3. 与超导的关系

```
激子凝聚 ↔ 超导 (粒子-空穴对称)

超导: e⁻+e⁻ → Cooper对 → BCS凝聚
激子: e⁻+h⁺ → 激子 → BEC凝聚

共同SCVC机制: 涡旋环反向环流Ampère吸引
```

**激子凝聚 = 绝缘体中的"超导" (带电中性→无Meissner效应, 但有超流)。**

# 第二部分: 量子自旋液体

## 4. SCVC自旋图像

### 4.1 自旋 = 涡旋环的环流方向

在SCVC中, 电子自旋 = 电子涡旋环的环流方向:
- ↑ = 顺时针环流
- ↓ = 逆时针环流

两个相邻涡旋环平行环流 → Ampère排斥(↑↑)
两个相邻涡旋环反向环流 → Ampère吸引(↑↓)

磁有序 = 涡旋环环流的空间有序排列。
量子自旋液体 = 涡旋环环流在T=0仍无序(量子涨落>>Ampère有序化)。

### 4.2 几何阻挫

三角晶格: 三个自旋无法同时满足↑↓吸引→阻挫。
```
    ↑
   / \
  ↓───↓   两个↓吸引, 但第三个与↑的排布无法最优
```

SCVC: 三角形涡旋环阵列→Ampère力无法同时满足所有对的偏好→基态简并→自旋液体。

### 4.3 阻挫参数

```
f = |θ_CW|/T_N

θ_CW: Curie-Weiss温度(衡量Ampère力强度)
T_N: Neel温度(实际有序化温度)

f >> 1 → 强阻挫 → 自旋液体候选
f ~ 1 → 弱阻挫 → 常规磁有序
```

## 6. 自旋液体的涡旋环特征

### 6.1 分数激发

QSL的激发不是普通磁子(ΔS=1), 而是**自旋子**(ΔS=1/2):

SCVC: 涡旋环环流"分裂"→半个涡旋环翻转→携带半整数自旋。

这对应Kitaev模型中Majorana费米子的物理。

### 6.2 拓扑序

QSL基态有非平凡拓扑→基态简并依赖于空间拓扑(如环面→4重简并)。

SCVC: 涡旋环环流在非平凡空间中的缠绕数贡献拓扑简并。

### 6.3 量子临界

阻挫f从1→∞的变化→量子相变(磁有序→QSL)。

SCVC相边界: f_crit ≈ 5-10 (与晶格维度和自旋值有关)。

## 7. SCVC的统一视角

```
阻挫晶格 + 强量子涨落 → 自旋液体
    ↕ (粒子-空穴对称?)
掺杂载流子 → 高温超导? (共振价键理论: Anderson 1987)
```

SCVC: 自旋液体和高温超导共享涡旋环阻挫几何。
掺杂→涡旋环浓度足够高→反向环流配对→超导。
这与铜氧化物超导体的相图一致(QSL母体+掺杂→超导)。
