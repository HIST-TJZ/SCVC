## 2. 合成路线优化

### 2.1 Z=119: 48Ca + ²⁵⁴Es

```
反应: 48Ca + 254Es → 302-119* → 298-119 + 4n

入射能量: ~227 MeV (库仑势垒212 MeV × 1.07)
激发能: ~227 + Q_fus ≈ 227 - 175 = 52 MeV
蒸发中子: 4n (激发能 ~52 MeV, 每中子 ~12 MeV)

产物: 298-119, 预期T1/2(α) ∼ 10⁻³-10⁻¹ s
截面估计: ~0.1-1 pb (外推自Z=118的~0.5 pb)
```

### 2.2 Z=120: 48Ca + ²⁵⁷Fm

```
反应: 48Ca + 257Fm → 305-120* → 301-120 + 4n

入射能量: ~228 MeV
截面估计: ~0.05-0.5 pb
困难: 257Fm靶半衰期仅100.5天, 需在线生产
```

### 2.3 冷聚变可行性

对Z=119: 需要入射离子Z>35 (Br, Kr, Rb...)
库仑势垒>350 MeV → 激发能>100 MeV → 多中子蒸发 → 产物截面极低。

**结论: 冷聚变对Z≥119不可行。热聚变是唯一路径。**

## 4. 经济嬗变

### 4.1 贵金属: 不可行

```
Au成本: ~$30,000/g(加速器嬗变) vs $70/g(市场)
能量需求: ~30 MeV/原子 × 3×10²¹ 原子/g = 1.4×10¹⁰ J/g
         = 4,000 kWh/g → $400/g(仅电费)
         含加速器摊销 → $30,000/g

结论: 4个数量级的经济差距。物理可行, 经济荒谬。
```
