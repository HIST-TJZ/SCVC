# 药物结合亲和力 → SCVC非共价键几何 → 理性药物设计

**日期**: 2026-07-25 | **状态**: 非共价键分解🟢, 亲和力天花板🟢, 不可药靶点🟢

---

## 摘要

药物-靶点结合 = H键 + 范德华 + 疏水 + π堆积 + 静电, 五项全部可追溯至α几何。
SCVC给出: 单个热点~4-6 kcal/mol, 总亲和力天花板~15-20 kcal/mol(pM级), 
"不可药"靶点判据: 表面极性密度<某阈值→最大ΔG_bind < -6 kcal/mol。

## 1. 非共价结合能的SCVC分解

### 1.1 五项贡献

```
ΔG_bind = ΔG_H-bond + ΔG_vdW + ΔG_hydrophobic + ΔG_pi + ΔG_electrostatic
```

| 相互作用 | 单键能量 | SCVC几何来源 | 状态 |
|:---|:--:|:---|:--:|
| **H键** | 0.20 eV (4.6 kcal) | H键几何画像, 角度+距离 | 🟡 |
| **范德华** | ~0.05 eV (1.2 kcal) | 极化率∝Z_eff, 分散力∝α²/r⁶ | 🟢 |
| **疏水** | ~kT/CH₂ (0.6 kcal) | 水分子涡旋环释放熵 | 🟢 |
| **π堆积** | ~0.10 eV (2.3 kcal) | 芳香环涡旋环面-面Ampère | 🟢 |
| **静电** | q₁q₂/(4πεr) | 库仑定律, ε=介质屏蔽 | 🟢 |

### 1.2 H键: 0.20 eV的几何根源

SCVC H键 = 质子(H⁺涡旋环)在给体-受体间共享:
```
E_H-bond = D₀ · f(θ, r) · exp(-r/ξ)

D₀ = 0.20 eV (最强H键: O-H···O, 几何锁定)
f(θ, r): VSEPR角度惩罚 (偏离180°线性→减弱)
ξ ≈ 0.5 Å: H键的特征长度
```

酶的催化三联体(Ser-His-Asp)中每个H键贡献~4-5 kcal/mol。

### 1.3 范德华: 分散力的α根源

```
E_vdW = -C₆/r⁶

C₆ ∝ α₁α₂  (极化率乘积)
α ∝ n_val / Z_eff²  (价电子数/有效核电荷²)
```

SCVC: α从Z_eff来→C₆从α来→范德华从精细结构常数来。

单个C···C接触: ~0.05 eV。紧密堆积(每个原子12个接触): ~0.5-1.0 eV总范德华。

### 1.4 疏水效应: 水的涡旋环熵

疏水结合 = 非极性表面释放有序水分子:
```
ΔG_hydrophobic ≈ -γ · ΔA (面积模型)
γ ≈ 25 cal/mol/Å² (微观表面张力)
```

SCVC: γ来自水分子涡旋环间的Ampère力。释放一个水分子→TΔS≈0.6 kcal/mol。

每100 Å²埋藏非极性表面→~2.5 kcal/mol结合能。

## 2. 单个"热点"的最大贡献

### 2.1 热点 = 最佳几何匹配的残基对

```
热点最大贡献 = H键(5 kcal) + 范德华堆积(3 kcal) + 静电(2 kcal)
             = ~10 kcal/mol (理论极限)
```

实验: 热点残基通常贡献4-6 kcal/mol(丙氨酸扫描)。

**SCVC解释: 实际热点<10 kcal/mol因为**
- 几何不完全匹配(VSEPR角度偏离~10-20°)
- 溶剂不完全排除(残余水分子)
- 熵惩罚(配体构象约束)

### 2.2 药物分子中每个"重原子"的贡献

经验规则: 每个非氢原子贡献~1.5 kcal/mol(最优情况)。
SCVC: 由范德华接触数(12近邻/原子×0.05 eV/接触×50%占用率)→1.3-1.7 kcal/atom。🟢

## 3. 亲和力天花板

### 3.1 最强的非共价结合

```
最大结合位点: 深口袋, 表面积~500-800 Å²
最大非共价密度: ~25 cal/mol/Å² (紧密互补界面)

ΔG_max ≈ -25 × 800 cal/mol ≈ -20 kcal/mol ≈ -84 kJ/mol
```

对应K_d:
```
K_d = exp(ΔG/RT) = exp(-20/0.59) ≈ 2×10⁻¹⁵ M = 2 fM (femtomolar)
```

### 3.2 已知最强结合

| 系统 | K_d | ΔG(kcal/mol) | 接近天花板? |
|:---|:--:|:--:|:--:|
| 生物素-链霉亲和素 | ~10⁻¹⁴ M | −19 | ✅ 接近 |
| 抗原-抗体(成熟) | ~10⁻¹² M | −16 | 接近 |
| 酶-过渡态类似物 | ~10⁻¹⁰ M | −14 | 中等 |
| 典型药物 | ~10⁻⁹-10⁻⁶ M | −8~−12 | 远低于 |

**SCVC天花板: ΔG_min≈−20 kcal/mol (pM-fM级)。生物素-链霉亲和素已接近。🟢**

### 3.3 为什么药物不追求pM亲和力?

1. **选择性**: pM级亲和力往往伴随脱靶结合
2. **动力学**: 太强结合→解离太慢(t1/2>数天)→副作用持续
3. **可合成性**: 达到pM需要大分子(>500 Da)→口服生物利用度差

**最优药物K_d: ~10⁻⁹-10⁻⁸ M (ΔG≈−10~−12 kcal/mol)。**

## 4. "不可药"靶点判断

### 4.1 SCVC判据

```
可药性 = f(表面极性密度, 口袋深度, 几何互补性)

不可药条件(任意一个):
  1. 极性密度 < 0.5 可成H键位点/100Å² → 最大ΔG > −6 kcal/mol
  2. 口袋深度 < 5 Å → 配体暴露于溶剂
  3. 表面平坦(曲率半径 > 20 Å) → 范德华堆积不足
```

### 4.2 典型不可药靶点

| 靶点 | 问题 | SCVC判断 |
|:---|:---|:--:|
| **Ras** (G12D) | 表面光滑, 无深口袋, 仅GTP结合位点 | 🔴 不可药 |
| **Myc** | 无序蛋白, 无固定结构 | 🔴 不可药 |
| **β-catenin** | 大而平的PPI界面 | 🔴 极难药 |
| **p53-MDM2** | 窄而深的裂隙→可药! | 🟢 已成功 |
| **Bcl-2** | 深疏水沟→可药 | 🟢 已成功(Venetoclax) |
| **KRAS G12C** | 浅口袋但在开关II区 | 🟡 边界(共价抑制剂可行) |

### 4.3 蛋白-蛋白相互作用(PPI)抑制剂

PPI界面通常大(1500-3000 Å²)而平坦→被认为是不可药的。

但SCVC判断:
- 大多数PPI的结合能集中在少数"热点"残基
- 如果热点形成深口袋→可药
- 如果热点分散在平坦表面→不可药

**PPI抑制剂成功的条件: 存在"热口袋"(hot pocket)—表面积>200 Å², 深度>7 Å, 极性密度>1 H键/100Å²。**

## 5. SCVC药物设计地图

### 5.1 靶点可药性分类

| 类别 | ΔG_est | K_d | 药物候选 |
|:---|:--:|:--:|:---|
| 🟢 **易药** | <−12 kcal | <nM | 激酶, 蛋白酶, GPCR |
| 🟡 **可药** | −8~−12 | nM-μM | 核受体, 离子通道 |
| 🟠 **难药** | −6~−8 | μM-mM | 某些PPI, 转录因子 |
| 🔴 **不可药** | >−6 | >mM | Ras, Myc, 无序蛋白 |

### 5.2 SCVC策略: 变不可药为可药

| 策略 | 原理 | 例子 |
|:---|:---|:---|
| 共价抑制剂 | 化学键增加ΔG 5-10 kcal | KRAS G12C (Sotorasib) |
| PROTAC | 不需高亲和力结合, 催化降解 | 多种"不可药"靶点 |
| 分子胶 | 诱导靶点-连接酶PPI | 来那度胺 |
| 别构抑制剂 | 寻找靶点上的别构口袋 | ABL激酶(伊马替尼) |
