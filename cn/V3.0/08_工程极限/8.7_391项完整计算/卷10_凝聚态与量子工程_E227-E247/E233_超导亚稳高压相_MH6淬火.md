**日期**: 2026-07-25 | **状态**: 淬火路径🟢, 77K储存🟢, 室温储存🔴, 时间线🟡

## 摘要

类比金刚石(碳高压相淬火常压亚稳), 探索MH₆氢化物超导体淬火至常压的可能性。
**核心发现: 室温常压储存不可行(H扩散势垒仅0.8eV), 但液氮温度(77K)储存可行——
"冷储存超导体"是更现实的目标。**

## 2. 淬火动力学

### 2.1 H扩散势垒

```
H在MH₆笼形结构中的扩散:
  E_a ≈ 0.8 eV (穿过笼窗口)
  D₀ ≈ 10⁻³ cm²/s

  T=1200K: τ_diff ≈ 10⁻⁷ s  (合成温度, H自由移动)
  T=500K:  τ_diff ≈ 10⁻² s  (开始减速)
  T=300K:  τ_diff ≈ 20 s    (室温, H仍可移动)
  T=200K:  τ_diff ≈ 10⁵ s   (干冰温度, H基本冻结)
  T=77K:   τ_diff ≈ 10²⁰ s  (液氮, H完全冻结=宇宙年龄)
```

### 2.2 所需淬火速率

```
冷却1200K→300K, H跳跃次数:
  dT/dt = 10³ K/s  → N≈10¹⁰ → 结构崩塌
  dT/dt = 10⁶ K/s  → N≈10⁷ → 部分崩塌
  dT/dt = 10⁹ K/s  → N≈10⁴ → H部分逃逸
  dT/dt = 10¹² K/s → N≈10   → 勉强及格
  dT/dt = 10¹⁵ K/s → N≈0.01 → 结构保留!

实验室淬火速率:
  水淬:    10²-10³ K/s   ❌ 不够
  油淬:    10³-10⁴ K/s   ❌ 不够
  飞溅淬火: 10⁵-10⁶ K/s  ❌ 仍不够
  激光淬火: 10⁹-10¹² K/s ⚠️ 勉强可能
```

**室温淬火→常压储存: 🔴 极其困难, 需激光淬火+亚皮秒冷却。**

## 5. 替代策略

### 5.1 化学压

小离子替代大离子→"模拟"高压:
```
Sc→Y: ΔP_chem ≈ 3×B₀×(ΔV/V) ≈ 4 GPa (20% Sc替代)
Zr→Y: ΔP_chem ≈ 5 GPa (30% Zr替代)
```

### 5.2 外延约束

衬底外延应力:
```
P_epi ≈ Y×ε/(1−ν) ≈ 200×0.02 ≈ 4 GPa
```

### 5.3 纳米颗粒

Laplace压力:
```
P_Laplace = 2γ/R
R=5nm: ≈ 0.8 GPa
R=1nm: ≈ 4 GPa
```

### 5.4 组合策略

Y₀.₇Zr₀.₃H₆纳米颗粒(5nm)+SrTiO₃衬底:
```
化学压: 5 + 外延: 4 + 纳米: 3 ≈ 12 GPa
→ 仍需~140 GPa物理压→降到了~130 GPa
→ 杯水车薪。无法替代高压。
```

**结论: 替代策略可以将分解压力从~80GPa降到~70GPa——有帮助但不是game-changer。**
