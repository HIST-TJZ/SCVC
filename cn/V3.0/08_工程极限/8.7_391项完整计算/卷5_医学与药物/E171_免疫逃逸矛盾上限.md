1. 双重监视系统 — 进化的两面夹击
==============================================================

1.1 T 细胞: "看到异常肽就杀"
--------------------------------------------------------------
    CD8⁺ T 细胞通过 TCR 识别 MHC-I 呈递的肽段:
    · 正常肽: TCR 结合弱 → 不激活
    · 突变肽 (新抗原): TCR 结合强 → 激活 → 杀伤

    灵敏度: 仅需 1-10 个特异性 pMHC/细胞即可激活!
    → T 细胞是极其灵敏的"异常检测器"

1.2 NK 细胞: "没看到 MHC 就杀"
--------------------------------------------------------------
    NK 细胞的杀伤抑制性受体 (KIR, CD94/NKG2A) 结合 MHC-I:
    · MHC-I 正常 → 抑制信号 → 不杀伤
    · MHC-I ↓ → 抑制解除 → "missing self" → 杀伤

    阈值: MHC-I ~20-50% → 去抑制临界


2. 癌症的免疫逃逸窗口
==============================================================

2.1 双重束缚
--------------------------------------------------------------
    ┌───────────────────────────────────────────────────────┐
    │                                                       │
    │   高 MHC-I ──── T 细胞识别 ──── 被 T 细胞杀             │
    │       ↑                                               │
    │       │  免疫逃逸窗口?                                  │
    │       ↓                                               │
    │   低 MHC-I ──── NK "missing self" ──── 被 NK 杀          │
    │                                                       │
    │   两头都是死! 中间的窗口在哪里?                           │
    └───────────────────────────────────────────────────────┘

2.2 逃逸策略: 选择性等位基因丢失
--------------------------------------------------------------
    T 细胞需要识别"特定 MHC 等位基因 + 特定肽段":
    → 只需要降低那个"呈递新抗原的等位基因"

    NK 细胞监控"总 MHC-I 水平":
    → 保留部分 MHC-I 等位基因 → 维持 NK 抑制

    人类有 6 个 MHC-I 等位基因 (每个亲本各 3 个):

    丢失 1-2 个 → 67-83% MHC-I 保留 → NK 抑制 ≥ 20% 阈值 ✓
    → T 细胞无法识别已丢失的等位基因 → T 逃逸 ✓
    → 双重逃逸成立!

    ⚫ 逃逸窗口宽度: 丢失 1-3/6 等位基因 → 50-83%
      足够维持 NK 抑制, 同时逃避 T 细胞识别丢失的等位基因。
      这个窗口是真实存在的 — 大多数肿瘤正是这样逃逸的!

2.3 但这个窗口有内建矛盾
--------------------------------------------------------------
    窗口成立的条件:
    (a) 癌症恰好丢失"呈递新抗原的"等位基因 → 但新抗原是随机产生的
        → 癌症不知道哪个 MHC 等位基因会呈递哪个新抗原
        → 只能通过"尝试错误": 丢失不同等位基因的子克隆被选择

    (b) 剩余 MHC-I 足够抑制 NK → 但 NK 的 KIR 也分亚型
        → 不同 KIR 识别不同的 HLA 等位基因
        → 丢失特定 HLA → 特定的 KIR 不再被抑制

    ⚫ 逃逸需要"恰好"→ 需要多次试错 → 需要时间 → 需要突变!
      这就是为什么免疫逃逸不是即刻发生的 —
      它本身是一个进化过程, 受 E168-E169 的时间约束限制!


3. PD-1/CTLA-4 — 第二层逃逸 + 治疗突破口
==============================================================

3.1 检查点: T 细胞的"刹车"
--------------------------------------------------------------
    肿瘤即使保留了 MHC-I 和呈递新抗原, 仍可通过检查点逃逸:
    · 肿瘤表达 PD-L1 → 结合 T 细胞 PD-1 → T 细胞耗竭
    · CTLA-4: 在淋巴结中竞争 B7 → 抑制 T 细胞启动

    ⚫ 检查点抑制剂 (抗 PD-1, 抗 CTLA-4) 释放 T 细胞的"刹车"。

3.2 但检查点抑制剂不是万能的
--------------------------------------------------------------
    如果肿瘤已经丢失 MHC-I 等位基因:
    → 即使 T 细胞被检查点抑制剂"唤醒",
      也无法识别肿瘤 (因为没有呈递新抗原的 MHC!)
    → 这就是检查点治疗的耐药机制

    ⚫ 逃逸双层结构:
      层 1 (MHC 丢失) → 检查点抑制剂无效
      层 2 (检查点上调) → 检查点抑制剂有效

      患者的肿瘤可能部分细胞在层 1, 部分在层 2 →
      单用检查点抑制剂 → 层 2 被杀, 层 1 存活 → 复发!


4. 突破: 闭合逃逸窗口
==============================================================

4.1 双管齐下 — 同时攻击 T 和 NK 轴
--------------------------------------------------------------
    ┌────────────────────────────────────────────────────────┐
    │                                                        │
    │   策略 A: 恢复 MHC-I 表达                                │
    │   · 表观遗传药物 (HDAC 抑制剂, DNMT 抑制剂)               │
    │   · IFN-γ 信号通路激活 → MHC-I 上调                       │
    │   · → 让所有等位基因重新表达 → T 细胞可"看到"新抗原       │
    │                                                        │
    │   策略 B: 增强 NK 细胞杀伤                                │
    │   · NK 细胞 engager (双特异性抗体)                        │
    │   · 阻断 NK 抑制性受体 (抗 KIR, 抗 NKG2A)                │
    │   · → 让 NK 细胞攻击"低 MHC-I"的癌细胞                    │
    │                                                        │
    │   策略 C: 检查点抑制剂 (抗 PD-1/PD-L1 + 抗 CTLA-4)        │
    │   · 释放 T 细胞"刹车"                                     │
    │                                                        │
    │   ⚫ A + B + C 同时使用:                                    │
    │     · 高 MHC-I 癌细胞 → 被 T 细胞识别 (策略 A+C)          │
    │     · 低 MHC-I 癌细胞 → 被 NK 细胞杀伤 (策略 B)           │
    │     · PD-L1+ → 检查点被阻断 (策略 C)                       │
    │     · → 无处可逃! 窗口完全闭合!                             │
    └────────────────────────────────────────────────────────┘

4.2 三重联合的 SCVC 基础
--------------------------------------------------------------
    ⚫ 癌细胞面临的"不可能三角":
    
    癌细胞同时需要:
    (a) 低特异性 pMHC → 逃避 T 细胞 (MHC 等位基因丢失)
    (b) 高总 MHC-I → 抑制 NK 细胞
    (c) 持续生长 → 积累更多突变和免疫逃逸能力

    → (a)+(b) 要求精细调控特定的 MHC 等位基因 → 容错空间极窄
    → (c) 需要时间 (E169: 突变积累 ~数年)
    → 在免疫系统两面夹击下, 这个"三选二"窗口是可被压缩到消失的!

    ⚫ SCVC 给出的物理判断:
    MHC-I 介导的免疫逃逸窗口客观存在 (选择性等位基因丢失),
    但它的宽度是有限的 — 不是因为免疫系统完美,
    而是因为 T+NK 双重监视 + 突变时间的组合约束
    使癌症必须通过"试错-选择"来逃避, 而非"一次搞定"。

    如果我们同时施压三轴 → 窗口闭合 → 癌症无处可逃。

E171 结论
====================================================================

  ⚫ 逃逸窗口存在: 选择性丢失 1-3/6 MHC-I 等位基因
  ⚫ 但窗口需"试错-选择"→ 需要时间+突变 (E168-E169 约束)
  ⚫ 单用检查点抑制剂 → 层 1 耐药 (MHC 丢失)
  ⚫ 三重联合 (MHC 恢复 + NK 激活 + 检查点阻断) → 窗口闭合
  ⚫ SCVC: 免疫逃逸的物理极限 → 联合治疗是物理必然, 非偶然策略
