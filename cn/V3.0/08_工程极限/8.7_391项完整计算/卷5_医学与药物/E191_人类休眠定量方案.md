1. 四种休眠方案的温度-代谢映射
==============================================================

1.1 Arrhenius 代谢率 vs 温度
--------------------------------------------------------------
    基础代谢率 (BMR) 随温度下降:

    BMR(T) / BMR(310K) = (T/310) × exp(-E_a/k_B × (1/T - 1/310))

    对 E_a = 0.4 eV (典型代谢酶):

    ┌──────────┬──────────┬──────────┬──────────────────────────┐
    │ 温度     │ T (K)    │ BMR%     │ 备注                     │
    ├──────────┼──────────┼──────────┼──────────────────────────┤
    │ 37°C     │ 310      │ 100%     │ 正常                     │
    │ 35°C     │ 308      │ 91%      │ 熊式浅休眠               │
    │ 32°C     │ 305      │ 78%      │ 治疗性低体温上界         │
    │ 30°C     │ 303      │ 68%      │ 心脏安全边界             │
    │ 28°C     │ 301      │ 64%      │ ⚠️ Na⁺/K⁺ 泵效率 ~50%   │
    │ 25°C     │ 298      │ 50%      │ 🔴 室颤风险极高          │
    │ 20°C     │ 293      │ 36%      │ 🔴 不能自主维持          │
    │ 15°C     │ 288      │ 25%      │ 🔴 心脏几乎停跳          │
    │ 10°C     │ 283      │ 17%      │ 🔴 需要完全体外循环      │
    │ 0°C      │ 273      │ 12%      │ 地松鼠冬眠体温 (但人有   │
    │          │          │          │  不同的离子通道!)        │
    └──────────┴──────────┴──────────┴──────────────────────────┘

    ⚫ 注意: 这是"如果心脏能承受"的理论 BMR —
      实际人体安全温度被心脏锁定在 ~28°C 以上!

1.2 心脏的物理地板 — 为什么 28°C?
--------------------------------------------------------------
    Na⁺/K⁺-ATP 酶活化能 E_a ≈ 0.50 eV:

    k_pump(301K) / k_pump(310K) = exp(-0.50/8.617e-5 × (1/301-1/310))
    = exp(-5805 × 0.000096) = exp(-0.557) ≈ 0.57

    ⚫ 28°C 时钠泵效率降至 57%

    心肌细胞每搏:
    · 正常 Na⁺ 内流 ~10 mM/s (动作电位上升支)
    · Na⁺/K⁺ 泵需匹配此速率
    · 泵效率 57% → Na⁺ 在胞内累积 → 膜电位去极化

    累积 ~10-30 秒 → 去极化 >15 mV → 
    触发异常自动节律 → 室颤 → 无效泵血 → 死亡

    ⚫ 这就是人类在 <28°C 时心脏停跳的物理根源 —
      不是"巧合", 是 Na⁺ 泵活化能锁定的结果。

    地松鼠为何能到 0°C?
    · 它们的心肌表达不同的 Na⁺ 通道亚型 (Na_v1.5 的低温适应性剪接)
    · 钠泵密度高于人类 ~2-3×
    · 人类可以通过基因治疗改变钠通道 — 但目前没有

    ⚫ 没有基因修改: 人类心脏地板 = 28°C
    ⚫ 有基因修改 (过表达 Na_v1.5 低温亚型 + Na⁺/K⁺ 泵):
      地板可能推低到 10-15°C

3. 垃圾积累 — 各类休眠的安全时长 (来自 E189)
==============================================================

3.1 垃圾积累速率 vs 代谢率
--------------------------------------------------------------
    E189 给了在 37°C 下的垃圾积累时间。如果代谢率降到 R:

    可溶错误蛋白:
    · 产生 ∝ 转录+翻译错误率 → ∝ 代谢率 R
    · 降解 (UPS) ∝ 酶活性 → 也 ∝ 代谢率 R
    · → 净积累 ∝ R (产生和降解同比例减慢)
    · → 毒性阈值时间 ∝ 1/R
    · → E189: 10-20 年 (37°C) → 在 10% BMR 下 → 100-200 年

    聚集蛋白 (tau, α-syn):
    · 聚集 = 非线性 (自催化)
    · 但在 lag phase: 单分子错误折叠 ∝ R
    · → lag phase 延长 ∝ 1/R
    · E189: 5-15 年 → 在 10% BMR 下 → 50-150 年

    脂褐素:
    · ∝ 氧化损伤 → ROS ∝ 呼吸链通量 → ∝ R
    · 完全不可降解 → 线性积累 ∝ R
    · E189: 30-50 年 → 在 10% BMR 下 → 300-500 年

    线粒体损伤:
    · ROS ∝ R (呼吸链)
    · 修复 (线粒体自噬) ∝ R
    · → 净积累 ∝ R (产生和清除同比例)
    · E189: 15-20 年 → 在 10% BMR 下 → 150-200 年

    ⚫ 关键假设: 产生和清除同比例减慢 → 毒性阈值时间反比于代谢率。
    ⚫ 这个假设对大多数垃圾成立, 但对聚集蛋白 (非线性) 需要验证。

    ⚫ 核心洞察: 只要代谢率降到 ~10%,

      (肌肉、骨骼、免疫、肠道)。

    ⚫ 因此: 安全休眠时长不由垃圾决定, 由"失用性萎缩"决定。
      这就是为什么需要定期唤醒。


4. 唤醒周期 — E189 垃圾 + 失用性萎缩的双约束
==============================================================

4.1 失用性萎缩速率 (代谢率校正)
--------------------------------------------------------------
    在休眠代谢率 R 下:

    肌肉萎缩:
    · 正常制动: ~3-5% 肌力/周
    · 休眠中 (R=10%): ~0.3-0.5% 肌力/周
    · 3 个月: ~4-7% 肌力损失 → 可在 1 个月恢复
    · 6 个月: ~8-14% → 需要 ~2 个月恢复

    骨密度:
    · 正常制动: ~1-2% 骨密度/月
    · 休眠中 (R=10%): ~0.1-0.2%/月
    · 3 个月: ~0.3-0.6% → 可忽略
    · 12 个月: ~1.2-2.4% → 需要关注

    免疫:
    · T 细胞库: ~1%/天新生 (胸腺)
    · 休眠中 (R=10%): ~0.1%/天
    · 3 个月: T 细胞更新 ~10% → 可接受
    · 6 个月: ~20% → 免疫力可能下降

    肠道:
    · 肠道上皮更新: ~3-5 天 (正常)
    · 休眠中 (R=10%): ~30-50 天
    · 3 个月: 上皮更新 2-3 次 → OK (需要营养输入)
    · 营养输入: 必须外部供给 (酮体 + 必需氨基酸 + 维生素)

    干细胞池:
    · 肠道干细胞分裂: ~1/天 (正常) → ~0.1/天 (休眠)
    · 造血干细胞: 类似
    · 3 个月: 端粒损耗 ~9 次分裂 → 端粒缩短 ~500-900 bp
    · → 需要唤醒期间的端粒酶激活来补偿

5. 能量预算 — 休眠期间需要什么?
==============================================================

5.1 每日能量需求
--------------------------------------------------------------
    正常 BMR: ~1700 kcal/天 (70 kg 成人)

    方案 C (H₂S, BMR 10%):
    · 每日能量: ~170 kcal
    · 全部来自酮体 (β-羟基丁酸, ~4.5 kcal/g)
    · 每日酮体需求: ~38 g
    · 酮体可通过外部循环持续输入

    方案 D (深低温 10°C, BMR 5-10%):
    · 每日能量: ~85-170 kcal
    · 酮体: ~19-38 g/天

    ⚫ 这是极低的热量需求 — 
      10 天只需要 ~380 g 酮体 → ~1.7 kg/月
      外部循环系统可以轻松管理这个量。

5.2 废物清除
--------------------------------------------------------------
    尿素 (蛋白代谢产物):
    · 正常: ~25-30 g/天
    · 休眠 (10% BMR): ~2.5-3 g/天
    · → 需要透析级清除 (1-3 g/天 — 非常温和)

    CO₂:
    · 正常: ~800 g/天
    · 休眠 (10% BMR): ~80 g/天
    · → ECMO 膜肺可轻松处理

    水:
    · 正常: ~2000-2500 mL/天
    · 休眠 (10% BMR): ~200-300 mL/天
    · → 微量输注即可

    ⚫ 废物负荷极低 — 即使是便携式设备也能胜任。

7. 药物剂量 — 从物理到 mg
==============================================================

7.1 腺苷 A1 激动剂 (降低体温调定点)
--------------------------------------------------------------
    目标: 将下丘脑体温调定点从 37°C 降至 32-35°C。

    内源性腺苷在视前区: 正常浓度 ~0.1-1 μM
    冬眠动物: ~5-10 μM → 体温调定点降至 ~30-35°C

    药物选择:
    · N⁶-cyclohexyladenosine (CHA): A1 选择性激动剂, K_d ≈ 1 nM
    · 目标浓度: ~10-50 nM (血浆) → ~0.3-1.5 μg/kg/h 持续输注
    · 或: 口服双嘧达莫 (抑制腺苷再摄取) → 内源性腺苷 ↑ →
      更生理性的途径

    ⚫ 副作用: 心动过缓 (A1 在心脏) → 需要监控 + 可能起搏。
    ⚫ 物理约束: 腺苷-A1 结合 ΔG ≈ -1.5 eV (多个 H 键) →
      高亲和力 → 低浓度有效 → 低毒性。

7.2 H₂S 供体 (线粒体 Complex IV 可逆抑制)
--------------------------------------------------------------
    目标: 代谢率降至 10-20%。

    内源性 H₂S: ~10-100 μM (组织)
    冬眠诱导: ~50-200 μM H₂S → Complex IV 抑制 ~50-80%

    药物:
    · GYY4137: 缓释 H₂S 供体, 半衰期 ~2-3 h
    · 目标浓度: ~50-100 μM (血浆)
    · 剂量: ~10-50 mg/kg IV 负荷 + 1-10 mg/kg/h 维持
    · 或: Na₂S (更快但更短效)

    ⚫ 关键: H₂S 的抑制是完全可逆的 — 停药后线粒体恢复。
    ⚫ 在小鼠中已验证: 80 ppm H₂S 吸入 → 代谢降至 10%,
      核心体温降至 15°C, 6 h 后完全恢复, 无神经损伤。
    ⚫ 人类数据: 仅极低剂量 (安全测试) → 未知高剂量是否安全。

7.3 T3 下调 (降低组织代谢需求)
--------------------------------------------------------------
    甲状腺激素 T3 调控线粒体生物合成和解偶联蛋白 (UCP)。

    方法: 丙硫氧嘧啶 (PTU) → 抑制 T4→T3 转化
    · 剂量: 50-100 mg/天 (口服, 比甲亢治疗低)
    · 或: 直接 T3 受体拮抗剂 (仍在开发中)

    ⚫ 效果: 代谢率 ↓ 10-20% (叠加腺苷和 H₂S)


8. 诚实地带
==============================================================

8.1 方案 C (H₂S) 的最大未知
--------------------------------------------------------------
    ⚫ 小鼠 6 小时 → 人类 6 个月 → 差 720×!
    ⚫ H₂S 的神经毒性: 在极高浓度下, H₂S 还抑制 
      Complex I + 细胞色素 c 氧化酶的其他亚基
    ⚫ 人类的安全窗口未知 — 可能是 10-50 μM 很安全,
      但 100 μM 有神经毒性 → 窗口可能只有 2-5×
    ⚫ 需要大量动物实验 (非人灵长类) 来确定安全窗口。
    ⚫ 这不是物理墙 — 是数据墙。

8.2 唤醒过程的应激
--------------------------------------------------------------
    熊从冬眠中醒来: 体温从 35°C 回到 37°C — 轻微。
    地松鼠从 0°C 回到 37°C: 需要 ~2-3 小时, 
    伴随大量 ROS 产生 (再灌注样损伤)。

    人类从深低温 (10-20°C) 唤醒:
    · 需要缓慢复温 (~1°C/h) → 需要 17-27 小时
    · 复温期间: 代谢率 ↑ → ROS ↑ → 需要抗氧化剂保护
    · 方案: 复温前给予 N-乙酰半胱氨酸 (谷胱甘肽前体) + 
      MitoQ (线粒体靶向抗氧化剂)

    ⚫ 复温损伤是深低温休眠的"隐性墙"—
      不是冷冻的冰晶, 但 ROS 爆发可损伤 mtDNA。

8.3 终极问题: "休眠 1 年" 在物理上是否等价于"年轻 1 年"?
--------------------------------------------------------------
    如果代谢率 10%, 垃圾积累 10%, 
    端粒损耗 10%, 干细胞消耗 10% →
    休眠 1 年 ≈ 正常老化 0.1 年 → 是的, 你"只老了 1.2 个月"。

    但两个例外:
    ① 突触: 长期不活跃 → 可能被修剪 (突触可塑性) →
       如果被修剪, 信息丢失不能靠"代谢率"恢复
    ② 结缔组织: 弹性蛋白的老化主要由 AGEs 和机械疲劳驱动, 
       不是代谢率 (AGEs 形成 ∝ 糖浓度, 在休眠中糖低 → 有利)

    ⚫ 综合: 休眠 1 年 ≈ 老化 0.1-0.2 年 (物理老化), 
      但突触信息可能额外丢失 → 定期唤醒 + 学习训练
      可以对抗突触修剪。

E191 结论
====================================================================

  ⚫ 人类休眠的物理障碍 = 0 — 所有分子通路都在基因组中
  ⚫ 心脏地板 28°C — Na⁺/K⁺ 泵活化能 0.50 eV 锁定的硬墙
  ⚫ 三种可行方案 (无基因修改):
    A (熊式 32-35°C): 安全连续 1-3 月, 寿命延长 ~1.3×
    C (H₂S 37°C): 安全连续 4-6 月, 寿命延长 ~3-4×, ★推荐中期方案
    B (ECMO 28-32°C): 连续 1-4 周 (临床已验证), 但寿命增益有限
  ⚫ 方案 D (基因修改 + 10-20°C): 连续 8-12 月, 寿命延长 ~6-8×, 远期
  ⚫ 限制休眠时长的不是垃圾 (E189: 在低代谢下阈值远), 
    是失用性萎缩 (肌肉/骨骼/免疫)
  ⚫ 最优唤醒: 方案 C → 每 6 月醒 1 月; 方案 D → 每年醒 1 月
  ⚫ H₂S 代谢降至 10% → 每日仅需 ~170 kcal, ~38 g 酮体
    → 外部循环轻松管理
  ⚫ 最大未知: H₂S 人体安全窗口 (小鼠 6h → 人类 6 月 = 差 720×)
  ⚫ SCVC: 人类休眠不是科幻 — 是物理学允许但尚未被工程化的能力
