## §9.13 四线并行实验方案 — 从今天到三重验证

> **目标**: 在3-4个月内完成小鼠RCT + 犬类自发肿瘤 + 斑马鱼预实验 + 人类首例off-label，四线数据交叉验证。
> **设计原则**: 每条线独立可发表，四线汇聚时形成压倒性证据。
> **预算**: ~$82,000（传统PhI的1/250）
> **时间**: 3-4个月到全部数据（传统PhI的1/12）

### 9.13.1 剂量换算基础

```
人类低剂量(§5基准):
  Palbociclib:  25mg/day  (标准125mg的1/5)
  Olaparib:     50mg bid   (标准300mg的1/6)
  Bevacizumab:  2.5mg/kg q3w (标准15mg/kg的1/6)
  Pembrolizumab: 100mg q3w (标准200mg的1/2)

种间换算 (基于体表面积Km因子):
  Human Km = 37
  Mouse Km = 3   →  Human→Mouse: ×(37/3) = ×12.3 (mg/kg)
  Dog Km = 20    →  Human→Dog:  ×(37/20) = ×1.85 (mg/kg)
  Zebrafish: 溶于水中，按μg/mL计算

换算后小鼠剂量(mg/kg):
  Palbociclib:  25mg/60kg×12.3 ≈ 5 mg/kg/day PO
  Olaparib:     50mg/60kg×12.3 ≈ 10 mg/kg/day PO
  Bevacizumab:  2.5×12.3 ≈ 30 mg/kg q3d IP (小鼠半衰期更短)
  Pembrolizumab: 100mg/60kg×12.3 ≈ 20 mg/kg q3d IP

换算后犬剂量(mg/kg):
  Palbociclib:  25mg/60kg×1.85 ≈ 0.8 mg/kg/day PO
  Olaparib:     50mg/60kg×1.85 ≈ 1.5 mg/kg/day PO
  Bevacizumab:  2.5×1.85 ≈ 5 mg/kg q3w IV
  Pembrolizumab: 100mg/60kg×1.85 ≈ 3 mg/kg q3w IV
```

### 9.13.2 第一条线: 小鼠同系模型RCT (4-5周)

```
动物: BALB/c雌鼠, 6-8周龄, n=50 (确保每组n=10分析)
肿瘤: 4T1小鼠乳腺癌 (免疫健全+自发转移+可摸到)
终点: 肿瘤体积 + 肺转移结节 + CD8+浸润 + 体重(毒性)

分组 (5组×10只):
  ┌─────────────────────────────────────────────────────────┐
  │ G1: 生理盐水对照 (PO+IP, qd)                             │
  │ G2: Palbociclib单药标准 (25mg/kg PO qd)                  │
  │ G3: Palbociclib+Olaparib双药低剂量 (5+10mg/kg PO qd)    │
  │ G4: 四联低剂量 (Palbo5+Ola10+Bev30+Pembro20)            │
  │ G5: 四联标准剂量 (Palbo25+Ola50+Bev150+Pembro100)        │
  │     → G5用于验证"低剂量是否真的更低毒性"                  │
  └─────────────────────────────────────────────────────────┘

时间线:
  Day -7: 订购小鼠+适应
  Day 0: 4T1细胞接种(1×10^5/乳腺脂肪垫, 每只100μL)
  Day 7: 成瘤确认(50-100mm³可触) → 随机分组 → 开始给药
  Day 14: 中期测量(肿瘤体积+体重)
  Day 21: 第三次测量
  Day 28: 终末牺牲 → 肿瘤称重 + 肺结节计数 + 流式(CD8+/Treg比) + H&E

预期结果 (基于E172理论):
  G1: 肿瘤>1000mm³ (终点强制牺牲)
  G2: 肿瘤~600-800mm³ (单药部分抑制)
  G3: 肿瘤~300-500mm³ (双药协同)
  G4: 肿瘤<200mm³ 或完全消退 (四墙同时收紧)
  G5: 肿瘤<200mm³ 但体重显著下降(毒性)
  
  → 如果G4≈G5(抗肿瘤) 但G4体重>G5(低毒性)
  → 证明核心假说: 低剂量多靶点=强效+安全

关键指标:
  肿瘤抑制率(TGI) = (1 - Gx肿瘤体积/G1体积) × 100%
  G4 TGI预期: >80%
  毒性比 = G5体重下降/G4体重下降 → 预期>2×
  CD8+/Treg比: G4预期>G1(3×以上) → 免疫墙激活

药物配制与给药:
  Palbociclib/Olaparib: 溶于0.5%甲基纤维素钠 → PO灌胃 0.1mL/10g
  Bevacizumab/Pembrolizumab: PBS稀释 → IP注射 0.1mL/10g
  G4每天的灌胃顺序: Palbo+Ola混合灌胃(Bev+Pembro隔天IP)
```

### 9.13.3 第二条线: 犬类自发肿瘤病例系列 (4-8周)

```
动物: 大型犬(金毛寻回犬/罗威纳/大丹犬为首选)
     确诊骨肉瘤(四肢)或血管肉瘤
     标准治疗已失败或主人拒绝截肢/化疗
入组: n=10 (此为"病例系列", 无对照组; 历史对照)
合作: 1-2家兽医肿瘤转诊中心

入组标准:
  ① 组织学确诊恶性肿瘤
  ② 可测量的肿瘤(≥2cm, 触诊或影像)
  ③ 预期生存≥4周(确保完成治疗周期)
  ④ 主人签署知情同意
  ⑤ 无严重的肝肾功能不全

排除:
  ① 已使用过检查点抑制剂(犬类罕见)
  ② 脑转移(BBB穿透未知)
  ③ 怀孕/哺乳

方案:
  周期: 每3周一次, 共2个周期(6周), 然后评估
  低剂量方案(按体重):
    Palbociclib:  0.8 mg/kg PO qd (用人类25mg胶囊拆分或调药)
    Olaparib:     1.5 mg/kg PO bid
    Bevacizumab:  5 mg/kg IV q3w
    Pembrolizumab: 3 mg/kg IV q3w
  联合用药: 全部同时开始(Day 0)

终点(6周主要评估):
  主要: 肿瘤体积变化(RECIST适配犬类) → 目标CR+PR>50%
  次要: 
    - 疼痛评分(犬类疼痛量表, 主人+兽医双盲评分)
    - 生活质量(QoL评分, 主人评估)
    - 不良事件(VCOG-CTCAE犬类毒性标准)
    - ctDNA(犬类已有商业化检测)
    - 6周无进展生存

时间线:
  Week -2: 联系兽医肿瘤中心+签订合作协议
  Week -1: 筛选+入组(目标是2周内入组10只)
  Week 0: 第一轮治疗开始
  Week 3: 中期评估 + 第二周期
  Week 6: 主要终点评估
  Week 8: 数据整理+统计分析

预期:
  犬骨肉瘤的历史中位生存: 3-6个月(不截肢)
  如果四联有效:
    疼痛减轻 → Week 2-3明显
    肿瘤缩小 → Week 6可测量
    如果>50%犬只显示客观反应 → 强信号
    如果1-2只完全缓解 → 爆发性传播材料

传播力评估:
  "科学家用四联低剂量治愈了大丹犬的晚期骨肉瘤"
  → 动物新闻 + 科技媒体 + 人类癌症患者的注意
  → 狗主人 = 传播节点(社交媒体)
  → 兽医社区 = 专业背书
```

### 9.13.4 第三条线: 斑马鱼异种移植快速预筛 (2-4周)

```
动物: 成年斑马鱼(AB品系), n=60
肿瘤: 荧光标记人乳腺癌细胞(MDA-MB-231-GFP或MCF7-RFP)
     移植至卵黄囊周围
温度: 斑马鱼维持33°C(匹配哺乳动物代谢) vs 28°C(正常)

分组(3组×20只):
  G1: DMSO对照(0.1%水溶液)
  G2: Palbociclib+Olaparib+Bevacizumab三药(无免疫成分)
       → 浓度: Palbo 2μM + Ola 5μM + Bev 50μg/mL 水溶
       → 此线无法测试检查点抑制剂(斑马鱼无适应性免疫)
  G3: 高浓度三药(×5浓度, 毒性对照)

终点: 7天+14天
  荧光面积变化(共聚焦显微镜)
  血管新生抑制(Bevacizumab效应→血管密度)
  凋亡(TUNEL染色)
  鱼存活率(毒性)

时间线:
  Day -3: 斑马鱼适应
  Day 0: 肿瘤细胞移植(显微注射)
  Day 1: 确认移植物存活(荧光)
  Day 2: 开始给药(每天换水+药物)
  Day 7: 第一次成像
  Day 14: 终末成像+组织学

预期:
  G1: 肿瘤荧光面积增大3-5倍
  G2: 肿瘤荧光面积稳定或缩小>30%
  
优势: 2-4周出数据, 极低成本, 透明→实时观察
劣势: 免疫墙缺失→无法测四联完整效果

此线的定位: 快速预实验+补充数据(证明三药已有协同)
           不是主证据线(主证据是小鼠+狗)
```

## §9.14 诚实: 这个方案的风险和弱点

```
1. 协调复杂性 [E]
   四线并行需要一个人全职管理
   → 找CRO + 找兽医 + 找医生 + 管数据
   → 需要项目管理和科学素养兼备的人
   → 目前只是一个方案——需要执行者

2. 小鼠模型可能失败 [E, 概率~20-30%]
   4T1是极其恶性的模型
   → 如果四联对4T1无效 → ≠对人类无效
   → 但负面数据会阻碍人类尝试的决心
   → 缓解: 同时用两种小鼠模型(4T1+EMT6)分散风险

3. 犬类入组速度不确定 [C]
   "2周内入组10只符合条件的狗"可能过于乐观
   → 需要多个兽医中心同时筛选
   → 主人知情同意可能构成障碍
   → 缓解: 提前联系3-5家中心, 预筛选

4. 人类医生愿意度 [C]
   即使off-label合法, 多数医生仍不愿意
   → 因为"没人做过"= 担心医疗诉讼
   → 即使低毒性, 如果出事→ 解释成本高
   → 缓解: 先有动物数据 → 增加医生信心
         或者: 找学术型医生 → 以"研究者发起试验"(IIT)形式

5. 最大的隐藏风险 [E]
   如果四联确实有效且三线数据都在4个月内出来
   → 药企会怎么做?
   → 答: 囤积药物 + 涨价 + 阻止off-label
   → CDK4/6i和PARPi专利还有10-15年
   → 药企有动机压制低剂量数据(因为破坏高剂量市场)
   → 缓解: 数据先公开(preprint) → 公众知情 → 药企涨价=PR灾难

6. 物理底层风险 [C]
   E172的理论是否正确?
   → "四墙同时收紧"在人体中是否成立?
   → 药物的实际分布、代谢、半衰期是否如预期?
   → 药代动力学(PK)在低剂量下的非线性效应?
   → 缓解: 这正是实验要验证的——不是风险是无法验证,
     而是"验证结果可能为负"
     如果为负 → 知道"这个方向不对" = 也是进展
```
