1. 问题的物理本质
==============================================================

1.1 自身免疫 = 同一物理机制的阈值偏移
--------------------------------------------------------------
    E171 分析了 T+NK 如何攻击癌细胞 (免疫逃逸)。
    自身免疫病是同一机制的反面: 免疫系统错误攻击自身。

    ┌──────────────────────────────────────────────────────────┐
    │                                                          │
    │  T 细胞的生命周期 — 两次筛选:                              │
    │                                                          │
    │  胸腺中 (中枢耐受):                                       │
    │  · 阳性选择: TCR 微弱结合自身肽-MHC → 存活               │
    │    阈值 E_pos ≈ 0.5-1.0 eV → "有用但不危险"             │
    │  · 阴性选择: TCR 强结合自身肽-MHC → 凋亡                 │
    │    阈值 E_neg ≈ 1.5-2.0 eV → "太危险, 删除"             │
    │                                                          │
    │  外周中 (外周耐受):                                       │
    │  · 激活阈值 E_act ≈ 1.0-1.5 eV + 共刺激信号              │
    │  · 无共刺激 → 不应答 (anergy) → "看到但不攻击"           │
    │                                                          │
    │  ⚫ 自身免疫病的物理根源:                                  │
    │    灰色地带 ΔE_gray = E_neg − E_pos ≈ 0.5-1.0 eV        │
    │    在这个灰色地带的 T 细胞逃过了阴性选择,                  │
    │    但仍可能在特定条件下被激活 → 攻击自身组织。             │
    └──────────────────────────────────────────────────────────┘


2. TCR-肽-MHC 结合能的 SCVC 定量
==============================================================

2.1 结合界面的物理组成
--------------------------------------------------------------
    TCR 接触的肽残基 (通常 P4-P8, 即 5 个残基):

    每个残基的侧链贡献:
    · 大疏水残基 (F, W, Y, L, I): ΔG ≈ 0.3-0.5 eV/残基 (疏水+vdW)
    · 带电残基 (K, R, D, E): ΔG ≈ 0.2-0.4 eV/残基 (盐桥+H键)
    · 极性残基 (N, Q, S, T): ΔG ≈ 0.1-0.2 eV/残基 (H键)
    · 小残基 (A, G, V, P): ΔG ≈ 0.05-0.1 eV/残基 (仅vdW)

    总 TCR-肽界面结合能: E_interface ≈ 1.0-2.5 eV

2.2 自身肽 vs 外来肽 — 物理上有什么区别?
--------------------------------------------------------------
    ┌──────────────────────────────────────────────────────────┐
    │ ⚫ 物理上, 自身肽和外来肽没有本质区别!                     │
    │                                                          │
    │ 都是 9 个氨基酸, 都由相同的 20 种氨基酸组成。              │
    │ 免疫系统无法"看"肽的来源 — 只能"感觉"结合能。              │
    │                                                          │
    │ 胸腺选择的逻辑是:                                         │
    │ "凡是能在此处 (胸腺) 呈递且结合能 > 阈值的 → 删除"       │
    │                                                          │
    │ 问题:                                                     │
    │ 1. 不是所有自身肽都在胸腺中呈递 (组织特异性抗原)          │
    │ 2. 呈递的自身肽可能结合能恰好低于阴性选择阈值              │
    │ 3. 感染后, 病原体肽可能在结构上"模拟"自身肽                │
    │    → 分子模拟 (molecular mimicry)                        │
    └──────────────────────────────────────────────────────────┘

2.3 分子模拟的物理条件
--------------------------------------------------------------
    设一种自身肽 S 结合 TCR 的能量为 E_S ≈ 1.3 eV
    (低于阴性选择阈值 E_neg=1.5 eV → T 细胞存活)

    设一种病原体肽 P 结合同一 TCR 的能量为 E_P ≈ 1.8 eV
    (高于 E_neg → 但病原体肽不在胸腺中出现!)

    感染时: T 细胞被 P 强烈激活 → 清除感染
    感染后: T 细胞遇到 S → E_S=1.3 eV > E_act → 激活 → 攻击自身组织

    ⚫ 分子模拟需要: E_S > E_act 且 E_S < E_neg
    ⚫ 窗口宽度: ΔE_window = E_neg − E_act ≈ 0.3-0.5 eV
    ⚫ 这是 ~2-3 个 H 键的差异 — 足够容纳"类似但不同"的肽


3. 各自身免疫病的物理可逆性分析
==============================================================

3.1 1型糖尿病 (T1D) — 靶向胰岛β细胞
--------------------------------------------------------------
    自身抗原: 胰岛素, GAD65, IA-2, ZnT8
    MHC 关联: HLA-DQ8 (DQB1*0302), HLA-DQ2

    ⚫ 物理特征:
    · 自身肽(胰岛素 B9-23)直接结合 MHC-II 强 → TCR 识别
    · 胰腺 β 细胞不在胸腺中呈递 → 对应的 T 细胞未删除
    · 外周调节性 T 细胞 (Treg) 不足 → 失控

    阈值校正的可能性:
    ┌──────────────────────────────────────────────────────────┐
    │ 策略 1: 抗原特异性耐受诱导                                │
    │ · 口服胰岛素 → 肝脏呈递 → 诱导 Treg                      │
    │ · 物理基础: 低剂量 + 无共刺激 → 不应答 (anergy)          │
    │ · 难度: 需要 Treg 占优势 → TCR 亲和力低 (~0.5-1 eV)     │
    │ · ⚫ SCVC: 物理上可能, 但需在β细胞大量死亡前(窗口窄)     │
    │                                                          │
    │ 策略 2: 竞争肽 (altered peptide ligand, APL)             │
    │ · 设计与自身肽竞争但结合能较低的肽类似物                   │
    │ · ΔG_APL 控制在 0.5-1.0 eV → 结合但不激活                 │
    │ · ⚫ SCVC: 设计窗口狭窄 (~0.2-0.3 eV/残基) → 困难        │
    │                                                          │
    │ ⚫ 最可能校正? ★★★☆☆ (中度可能, 但窗口期是瓶颈)          │
    └──────────────────────────────────────────────────────────┘

3.2 类风湿关节炎 (RA) — 靶向关节滑膜
--------------------------------------------------------------
    自身抗原: 瓜氨酸化蛋白 (citrullinated vimentin, fibrinogen等)
    MHC 关联: HLA-DR4 (shared epitope: DRB1*0401, *0404等)

    ⚫ 物理特征:
    · 瓜氨酸化 = 精氨酸 → 瓜氨酸 (PAD 酶催化) → 电荷变化
    · 精氨酸 (Arg, +1 电荷) → 瓜氨酸 (Cit, 0 电荷)
    · MHC-II 的 P4 口袋专门结合带正电残基 (shared epitope 特征)
    · → 瓜氨酸化后 → 肽-MHC 结合增强 → TCR 识别增强
    · 瓜氨酸化在炎症环境中增加 → 正反馈循环

    阈值校正的可能性:
    ┌──────────────────────────────────────────────────────────┐
    │ ⚫ RA 的物理特殊性:                                       │
    │   瓜氨酸化是翻译后修饰 → 不可逆 (共价键!)                 │
    │   → "校正抗原"不可能 → 必须校正 T 细胞或阻断效应         │
    │                                                          │
    │ 策略: PAD 酶抑制剂 (阻断瓜氨酸化)                         │
    │ · 阻止新自身抗原产生 → 打破正反馈                         │
    │ · ⚫ SCVC: 物理上可能, 已在临床试验中                     │
    │                                                          │
    │ ⚫ 最可能校正? ★★★★☆ (靶向上游修饰而非下游免疫)         │
    └──────────────────────────────────────────────────────────┘

3.3 多发性硬化 (MS) — 靶向髓鞘
--------------------------------------------------------------
    自身抗原: MBP (髓鞘碱性蛋白), PLP, MOG
    MHC 关联: HLA-DR15 (DRB1*1501)

    ⚫ 物理特征:
    · MBP 是高度碱性的膜蛋白 → 带大量正电荷
    · MHC-II 结合广泛 → 多个 T 细胞克隆可识别
    · 分子模拟: EBV 的 EBNA1 与 MBP 有序列相似
    · 中枢神经系统的免疫特权 → T 细胞不易进入
    · 但一旦进入 → 血脑屏障受损 → 更多进入 → 正反馈

    阈值校正的可能性:
    ┌──────────────────────────────────────────────────────────┐
    │ ⚫ MS 的挑战: 自身抗原是结构蛋白 (MBP/PLP/MOG)            │
    │   → 不能"清除抗原" → 必须让免疫系统"忽略"它              │
    │                                                          │
    │ 策略 1: 抗原特异性免疫疗法                                 │
    │ · 经皮递送 MBP 肽 → 诱导肝脏耐受 → Treg 扩增            │
    │ · ⚫ SCVC: 物理挑战 — MBP 肽与多种 MHC 结合              │
    │   → 需要覆盖多种 HLA 类型 → 个性化                       │
    │                                                          │
    │ 策略 2: 抗 CD20 (ocrelizumab) → 清除 B 细胞              │
    │ · 阻断抗原呈递和自身抗体产生                               │
    │ · ⚫ SCVC: 非特异性免疫抑制, 非"阈值校正"                 │
    │                                                          │
    │ ⚫ 最可能校正? ★★☆☆☆ (抗原复杂, 中枢位置不可达)         │
    └──────────────────────────────────────────────────────────┘


4. 阈值校正的物理策略
==============================================================

4.1 移动阈值 vs 移动抗原 vs 清除细胞
--------------------------------------------------------------
    ┌──────────────────────────────────────────────────────────┐
    │                                                          │
    │ 方向 1: 上调阴性选择等效阈值 (使其变严)                   │
    │ · CTLA-4-Ig (阿巴西普): 阻断共刺激 → 提高激活阈值        │
    │ · ⚫ SCVC: 提高 E_act 从 1.0 eV → 1.3 eV              │
    │   → 灰色地带自身肽 (E≈1.0-1.3 eV) 不再激活              │
    │   → 但对外来肽的免疫也减弱 → 感染风险 ↑                  │
    │ · 已在 RA 中获批 → 部分验证了"阈值校正"策略              │
    │                                                          │
    │ 方向 2: 删除交叉反应 T 细胞                                │
    │ · CAR-Treg 工程: 靶向特定自身肽-MHC 复合物               │
    │ · ⚫ SCVC: 需要 Treg 的 TCR 结合自身肽在 ~0.5-1.0 eV    │
    │   → 足够结合但不触发效应功能 → 物理窗口窄但存在           │
    │ · 在 T1D 和 MS 的早期临床试验中                           │
    │                                                          │
    │ 方向 3: 稳定自身肽-MHC 结合 (改变 TCR 看到的"图景")      │
    │ · 小分子"肽编辑": 改变肽在 MHC 槽中的构象                 │
    │ · ⚫ SCVC: 肽-MHC 结合能 ~1-2 eV → 小分子难以竞争        │
    │   → 最多 ~0.5-0.8 eV 的小分子 → 不足以取代肽             │
    │   → 物理上不太可行                                       │
    │                                                          │
    │ 方向 4: 检查点调控的反向应用                               │
    │ · PD-1 激动剂 (非拮抗剂!) → 增强 T 细胞"刹车"            │
    │ · ⚫ SCVC: 提高外周耐受 → 关闭灰色地带窗口               │
    │   → 副作用: 可能容忍癌细胞 (E171 的反面)                 │
    │   → 需要局部递送 (仅作用于自身免疫靶组织)                │
    └──────────────────────────────────────────────────────────┘

5. 感染后自身免疫的物理窗口
==============================================================

5.1 Guillain-Barré 综合征 (GBS) — 分子模拟的经典案例
--------------------------------------------------------------
    空肠弯曲菌 (C. jejuni) 的脂多糖 (LOS) 模拟神经节苷脂 (GM1):
    · 两者的糖链结构几乎相同 (差异 < 2 Å)
    · 免疫系统产生的抗 LOS 抗体同时结合 GM1 → 攻击周围神经
    · → 上行性麻痹

    ⚫ SCVC 键能分析:
    抗体-LOS 结合能 ΔG_LOS ≈ 1.5-2.5 eV (高亲和力)
    抗体-GM1 交叉结合能 ΔG_GM1 ≈ 1.2-1.8 eV (略低但足够)

    ΔG_GM1/ΔG_LOS ≈ 0.7-0.8 → 交叉反应的概率由
    Boltzmann 权重决定: exp(-ΔΔG/k_B T)

    ΔΔG ≈ 0.3-0.7 eV → exp(-0.5/0.026) ≈ 4×10⁻⁹ →
    在 10⁷ B 细胞库中 → 必然有一些交叉反应的克隆。

    ⚫ 这解释了为什么 GBS 是"罕见但必然"的:
      分子模拟的概率 ≈ 10⁻⁶-10⁻⁸ → 在 10⁹ 人的大样本中
      必然出现。它不是"倒霉" — 它是免疫系统工作原理的物理必然。

E177 结论
====================================================================

  ⚫ TCR 灰色地带 ΔE ≈ 0.3-0.5 eV — 由 α 设定的物理常数
  ⚫ 胸腺筛选不是完美的 → 部分自身反应性 T 细胞必然存活
  ⚫ 分子模拟: 感染后自身免疫是物理必然 (概率 ~10⁻⁶-10⁻⁸)
  ⚫ 单抗原+可牺牲组织 → 可校正 (MG → 胸腺切除)
  ⚫ 多抗原+关键组织 → 难校正, 只能管理 (MS, SLE)
  ⚫ CTLA-4-Ig 已证明"阈值校正"在临床上可行
  ⚫ 抗原特异性耐受是物理上最优雅的方向 — 精准且无毒
