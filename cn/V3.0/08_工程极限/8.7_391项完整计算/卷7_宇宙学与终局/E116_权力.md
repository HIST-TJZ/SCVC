# SCVC工程物理 E116：权力的物理学——一个社会能承受多少不平等？

## §1 为什么等级制是必然的

`
Dunbar 150: 你可以直接管理 ≤150 人。
超过150: 你必须用中间层。

等级制 = Dunbar的递归应用:
  1层:  直接管理 150 人 → 最大组织 150
  2层:  150个中层 × 150人/层 → 最大组织 22,500
  3层:  150² × 150 → 最大组织 3,375,000
  N层:  150^N

全人类 (~8×10⁹) 需要的层数:
  log₁₅₀(8×10⁹) ≈ log(8×10⁹)/log(150) ≈ 9.9/2.18 ≈ **4.5层**

任何超过150人的组织必须有等级。
等级 = Dunbar的数学必然, 不是"选择"。
`

---

## §2 不平等的信息论定义

`
权力 = 信息不对称:
  上层知道下层的信息。
  下层不知道上层的信息。
  信息差 = 权力。

每层信息衰减:
  39bits/s的口语带宽在层级间传递 → 每层有损失。
  如果每层损失 ~10-20%:
    4层后的信息保真度: (0.85)⁴ ≈ 52%
    
  底层收到的"上级意图" → 只有原始信息的一半。
  上层收到的"底层情况" → 也被压缩了一半。

信息不对称随层级指数增长:
  ΔI_layer = I_top - I_bottom = I₀ × (1 - (1-ε)^N)
  
  N=4.5层, ε≈0.15:
  ΔI ≈ I₀ × 0.52
  
  上层和底层的信息差距 ≈ 52%的总信息量。
  这就是不平等的物理量。
`

## §3 最大可持续不平等

`
博弈论约束:
  E108: 恶意行为占15-20%。其中大部分是"噪声误判+报复循环"。
  
  不平等增加 → 信息差增大 → 底层更容易"误判"上层意图
  → 误判增加 → 报复增加 → 合作率下降
  
  临界点: 当信息差导致了合作率跌破 ~50%:
    → 博弈均衡崩溃 → 组织解体 → 革命/崩溃

最大可持续层级 (= 最大不平等):
  N_max ≈ log(组织规模) / log(150)
  但受限于: 信息衰减不能使底层合作率 < 50%
  
  这意味着存在一个"信任预算":
    信任预算 ≈ (85% - 50%) / (每层信息衰减导致的信任损失)
    每层损失 ≈ 5-8%
    最大可承受 ≈ (35%)/(6.5%) ≈ 5-6 层
    
  → 全人类的5-6层是最大可持续层级。
  → 超过此 → 底层无法信任上层 → 博弈崩溃。

历史上所有极端不平等社会都崩溃了:
  不是因为"道德"。
  是因为信息差超过了博弈均衡的容限。
`

## §4 AI社会: 无Dunbar = 完全扁平？

`
AI没有Dunbar限制。
AI可以一次性追踪所有其他AI。
不需要中间层 → 不需要等级制 → 理论上可以完全扁平。

但:
  AI的"权力"不是信息不对称 → 是带宽不对称 (E105)。
  一个AI可以被赋予比其他AI更多的带宽。
  → 新型不平等: 不是"信息差", 是"计算速度差"。

SCVC不能预测AI社会的政治结构。
只能说:
  人类的等级制是Dunbar的必然。
  AI不需要等级制。但可能产生新的不平等形式。
`

---

## §5 结论

等级制 = Dunbar的数学必然。
权力 = 信息差。
最大层级 ≈ 5-6层 (在博弈论约束下)。

不等式:
  信息差不能大到让底层合作率 < 50%。
  超过 → 博弈崩溃 → 革命。
  这就是所有极端不平等社会最终瓦解的物理原因。
