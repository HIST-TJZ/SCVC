## §1 为什么均衡不是100%善意

### 1.1 E106已证明合作是纳什均衡——但均衡里有噪声

`
E106的结论: 在重复囚徒困境中, 合作是以牙还牙(TFT)的纳什均衡。

但这不意味着100%合作。
任何真实系统中, 总有五个因子在制造"非合作":

因子1: 噪声 — 你误判了别人("他背叛我了?" → 其实没有 → 你报复 → 对方报复 → 合作崩坏)
因子2: 新入者 — 新人没有声誉历史, 必须被"测试"
因子3: 探索 — 在静态环境中, 偶尔尝试背叛是检测"环境是否变了"的理性策略
因子4: 有限记忆 — 过去的背叛最终被遗忘, 给背叛者"重新开始"的机会
因子5: 网络结构 — 你不是和所有人博弈, 你只在Dunbar-150网络中和部分人博弈

这五个因子, 每一个都可以用SCVC常数参数量化。
`

## §2 SCVC参数化的囚徒困境模型

### 2.1 基础收益矩阵

`
标准囚徒困境 (T>R>P>S):

              对方合作        对方背叛
  你合作       R, R          S, T
  你背叛       T, S          P, P

典型值: T=5, R=3, P=1, S=0

SCVC如何看待这些值?

R (双方合作价值):
  两个人在Dunbar网络中合作 → 共享信息
  信息交换率: 39 bits/s (口语)
  典型有效交互: ~数分钟/天 × 365天/年 → ~10⁵-10⁶ bits/人/年
  R = 合作的信息价值 = 互信息增量
  
T (背叛诱惑):
  单方背叛 → 获取对方合作的全部信息, 但不付出自己的
  信息不对称收益 → T ≈ R + (对方独有信息价值)
  对方独有信息 ≈ R (假设信息大致对等)
  → T/R ≈ 2 (在一锤子买卖中)
  → 但在重复博弈中, T的有效值被未来报复折现

T/R ≈ 2 (原始值), 但在重复博弈中 ≈ 1 + 1/(1+δ+δ²+...) 

SCVC不能从第一原理精确推导T/R。
T/R取决于"合作的制度结构"——法律、合同、声誉系统。
但SCVC可以给下界: 
  在Dunbar-150社会中, 单次背叛最多骗150人
  但每次欺骗的信息上限 ≈ 39 bits/s × 持续时长
  → T_max / R ≈ (150 × max_deception) / (daily_cooperation_per_pair)
  → 大约在 1.1 - 3.0 的范围
`

### 2.2 噪声率——从τ_m推导

`
因子1: 噪声 = 你在有限带宽下误判"他是否背叛了我"

人类的社交判断:
  需要证据: 语调、表情、上下文、历史记忆
  需要信息量: ~50-200 bits/判断
  可用带宽: 
    意识 ~100-200 bits/s (E92)
    口语 ~39 bits/s (E82)
    视觉→意识 ~20-40 bits/s (显意识视觉)
    
  每次决策窗口 ~200ms → 可用 ~8 bits (口语) + ~8 bits (视觉意识) ≈ 16 bits
  但需要 50-200 bits → 不够
  
  现实中: 你不在200ms内做社交判断
  你积累证据: 典型交互 ~数分钟 → 总可用 ~10³ bits
  → 足够做一次合理的社交判断

  但因时间压力或注意分散导致的误判:
  假设50%的社交判断在证据不足(信息<50 bits)时做出
  此时误判概率 → 高
  
  保守估计:
  每日社交判断 ~5-10次 (与Dunbar网络中的人交互)
  其中 ~10-20% 在证据不足时做出
  证据不足时误判率 ~30-50%
  
  总体噪声率 p_noise ≈ 0.10 × 0.40 ≈ **4-8%**

SCVC噪声率: p_noise ≈ 5-10% (来自带宽约束)
  含义: 每20次合作/背叛判断中, 有1-2次是错的。
`

### 2.3 新入者率——从Dunbar推导

`
因子2: 新入者 = 你的Dunbar网络中每年加入的新面孔

Dunbar 150: 稳定的社会关系数
关系更替率: 每年 ~5-10人 (换工作、搬家、新朋友)
新入者比例 r_new ≈ 5-10/150 ≈ **3-7%/年**

新入者策略:
  无历史记录 → 必须被"测试"
  测试方式: 初始合作, 观察反应
  如果新人背叛 → TFT报复
  如果新人合作 → 纳入合作网络

新入者的"初始背叛"概率取决于社会制度质量:
  高信任社会: 新入者初始合作率 > 90%
  低信任社会: 新入者初始合作率 < 50%
  
SCVC不能预测社会制度质量 → 这是大不确定因素。
`

### 2.4 记忆衰减——从E84推导

`
因子4: 记忆衰减 = 背叛信息随时间丢失

记忆写入率: ~2 bits/s (E84)
记住"这个人背叛过我"需要: ~10-20 bits (身份+事件+情感标签)
写入时间: 10-20 bits / 2 bits/s ≈ 5-10 秒

但记忆不是永久存储:
  海马体→皮层巩固: 需要数天到数周
  长期记忆半衰期: ~5-15 年 (社会记忆)
  
  10年后: 背叛记忆剩余 ~50-25%
  20年后: 背叛记忆剩余 ~25-6%
  
  这意味着: 背叛者在~10-20年后可以"重新开始"

记忆衰减参数 τ_mem ≈ **8-12 年** (半衰期)
  含义: 背叛者被"原谅"(其实就是被遗忘)的时间 ≈ 10-20年
`

## §3 均衡计算——SCVC版Axelrod演化模拟

### 3.1 模拟参数汇总

`
| 参数 | SCVC值 | 物理来源 |
|:---|:--:|:---|
| N (网络大小) | 150 | Dunbar (E85) |
| T/R (背叛诱惑比) | ~1.5-2.5 | 信息不对称 (待精确化) |
| p_noise (误判率) | 5-10% | 带宽约束 (τ_m→5/s) |
| r_new (新入者率) | 3-7%/年 | Dunbar 150 更替 |
| τ_mem (记忆半衰期) | 8-12年 | 记忆写入 2bits/s (E84) |
| 更新速率 | 5/s | τ_m≈20ms |
| 收益折现 δ (继续概率) | ~0.99/天 | 关系稳定性 |

关键: δ > (T-R)/(T-P) 是TFT均衡的条件。
δ ≈ 0.99/天 > 0.5 (当T=5,R=3,P=1) → 条件满足。
`

### 3.2 三大策略类型

`
在重复囚徒困境 + 噪声 + 新入者 + 记忆衰减的环境中:

类型G ("善良"): 始终合作 (ALL-C)
  在任何条件下都合作
  容易被ALL-D剥削
  在无噪声环境中会被淘汰
  但在噪声明环境中 → 偶尔被TFT误认为背叛者 → 被报复 → 也存活

类型S ("策略性"): 以牙还牙 (TFT)
  先合作, 然后复制对方上一轮
  在噪声环境中: 一次误判 → 一轮相互背叛 → 恢复合作
  这是纳什均衡策略

类型E ("恶意"): 始终背叛 (ALL-D)
  永远背叛
  在TFT主导的人群中被快速孤立
  只能在网络边缘生存(新入者、陌生人)

在纯TFT人群中: 
  ALL-C ≈ TFT (ALL-C在和TFT对弈时表现完全相同)
  ALL-D ≈ 被淘汰
  → 难以区分ALL-C和TFT

在有噪声的人群中:
  ALL-C 偶尔因为误判被TFT惩罚 → 比TFT稍差
  ALL-D 利用新入者和记忆衰减 → 以低比例存活
  
均衡分布:
  TFT 主导: 85-93%
  ALL-C: 5-10%
  ALL-D: 2-5%
`

### 3.3 合作率计算

`
合作行为占比 (包括TFT的合作回合和ALL-C的全部回合):

C% = (TFT的合作回合 + ALL-C的全部回合) / 总回合数

TFT的合作回合:
  在TFT vs TFT中: (1 - p_noise × 平均报复链长)
  噪声导致的一次误判 → 2轮相互背叛(你背叛+我报复) → 回到合作
  平均报复链长 ≈ 2
  → TFT vs TFT合作率 ≈ 1 - 2×p_noise
  
  在TFT vs ALL-D中: 0% (ALL-D永远背叛, TFT以背叛回报)
  在TFT vs ALL-C中: 100% (ALL-C永远合作, TFT也合作)

总合作率:
  C% ≈ f_TFT² × (1-2p_noise) + f_TFT × f_ALL-C × 1 + f_ALL-C × f_TFT × 1 + f_ALL-C² × 1
     ≈ f_TFT² × (1-2p_noise) + 2×f_TFT×f_ALL-C + f_ALL-C²

代入 p_noise ≈ 0.075:
  如果 f_TFT=0.88, f_ALL-C=0.08, f_ALL-D=0.04:
  C% ≈ 0.88²×0.85 + 2×0.88×0.08 + 0.08²
     ≈ 0.658 + 0.141 + 0.006
     ≈ **80.5%**

如果 p_noise ≈ 0.05:
  C% ≈ 0.88²×0.90 + 0.141 + 0.006 ≈ 0.697 + 0.141 + 0.006 ≈ **84.4%**

SCVC人类合作率: **80-85%**
恶意行为占比: **15-20%**

这个数字匹配日常经验:
  → 大多数交互 (4/5) 是合作的
  → 大约 1/5 的交互涉及欺骗、背叛或误判导致的冲突
  → 但"恶意个体"占比只有 2-5% (持续背叛者)
  → 其余 15-20% 的"非合作"来自噪声、误判和新入者试探
`

人类不是"坏"。

## §5 "善意个体"占比 vs "善意行为"占比

`
一个关键区分:

善意个体 G%: 始终或几乎始终采用合作策略的个体比例
善意行为 C%: 所有交互中合作行为的比例

这两个数字不同。

善意个体: 
  TFT ≈ 85-93% (合作但有条件)
  ALL-C ≈ 5-10% (无条件合作)
  合计"善意个体" ≈ 90-98%

恶意个体:
  ALL-D ≈ 2-5% (始终背叛)
  其余"偶尔背叛"的策略 ≈ 3-8%

但善意行为只有 80-85%。
为什么?

因为善意个体(TFT)之间也会因噪声而偶发背叛:
  一次误判 → 报复 → 反报复 → 1-2轮"非合作"
  这些"非合作"不是来自恶意个体 → 来自噪声

所以:
  98%的人不是坏人。
  但只有85%的行为是合作行为。
  15%的"非合作"中:
    → ~10-12% 来自噪声(好人的误判)
    → ~3-5% 来自真正恶意个体的背叛
    → ~2-3% 来自新入者试探
`
