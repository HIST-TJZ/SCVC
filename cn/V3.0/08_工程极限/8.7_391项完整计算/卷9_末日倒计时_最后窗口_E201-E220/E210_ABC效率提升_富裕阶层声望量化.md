## 1. ABC效率提升——四大浪费回收

## 2. 声望量化——注意力经济学（含决策者溢价）

> **重要修正 (v2)**：原始版本用"教师薪资 $1.67/人时"定价所有注意力，
> 严重低估了C层决策者查询的价值。以下分两层定价。

### 2.1 核心模型

```
声望 = 注意力在时间上的积分 * 注意力质量权重

  注意力(A) = 年查询次数 * 每次注意秒数 * 质量权重(Q)
  
  两层定价:
    普通查询 (99%):  V_ordinary = $1.67/人时 (教师薪资模型)
    决策者查询 (1%): V_elite = $X/人时 (按"影响政策价值"折算)
    
  声望(R) = Sum [A_ordinary(t) * V_ordinary + A_elite(t) * V_elite]
            from t = 投资年 to t = 文明终结年
```

### 2.2 决策者注意力溢价——关键计算

```
旧世界游说参考:
  游说公司 $1000万 ≈ 影响1个美国议员1年
  1个议员1年工作时间 ≈ 2000小时
  → 游说注意力价值 ≈ $1000万 / 2000h = $5000/人时
  
  但: 游说是有偏见的信息 (只给议员看你想让他看的)
  ABC中: B层提供完整上下文 → 决策者注意力的质量更高
  → ABC决策者注意力效率 ≈ 游说注意力的2-3x (无信息偏差)
  
  保守取: V_elite = $5000/人时 (与游说等价)
  中值: V_elite = $10000/人时 (B层提升效率)
  
  取保守: $5000/人时

对比:
  普通注意力: $1.67/人时
  决策者注意力: $5000/人时
  → 溢价倍数: ~3000x

加权注意力价值:
  V_weighted = 0.99 * $1.67 + 0.01 * $5000
             = $1.65 + $50.00
             = $51.65/人时

  → 加入1%决策者查询后，加权注意力价值从 $1.67 → $51.65
  → 提升约 31倍
```

## 3. 反向博弈论——为什么合作是唯一理性选择

### 3.1 博弈矩阵（修正后的数字）

```
选择A：合作（投资ABC项目换声望）
  - 金钱: 归零 (货币重置) 但本来也要归零 (零利率 → 购买力逐渐消失)
  - 声望: +R(T) (等效价值取决于T和决策者%)
    T=1,000年: R ≈ 0.02-0.1 * 投资额
    T=10,000年: R ≈ 0.2-0.8 * 投资额
    T=1Myr:     R ≈ 0.25-1.5 * 投资额
  - 安全: B层正面记录 → 不被排斥 → 自由移动
  - 永生资格: OK (被文明历史永久记录)
  - 子孙: 优秀者获得声望乘数 (见3.5)

选择B：抵抗（隐藏财富/对抗ABC）
  - 金钱: 短期保留部分 → p_detect≈95% → 最终归零
    预期保留: W * (1-0.95) * (1-衰减率) ≈ 0.03W
  - 声望: 负声望 (B层永久负面记录) → 社会排斥
  - 安全: 被排斥到A层 → 无法参与决策 → 无法逃脱
  - 永生资格: NO (被历史记住为"阻碍者")
  - 子孙: 背负祖辈恶名 → 声望乘数为负
```

### 3.3 合作条件推导

```
定义:
  W = 当前财富
  R(T) = 声望等效价值 (T=文明存活年数)
  alpha = 声望偏好系数
  p_d = p_detect (B层检测率 ≈ 95%)
  
合作条件: 
  alpha * R(T) + (1-alpha) * 0  >  (1-alpha) * W * (1-p_d) * (1-衰减)
  ──────────                     ────────────────────────────
  合作收益                        抵抗的期望保留财富
  
  → alpha * R(T) > (1-alpha) * W * 0.05 * 0.5
  → alpha * R(T) > (1-alpha) * W * 0.025

对于不同类型:
  成就型 (alpha=0.95, W=$10B):
    所需 R(T) > (0.05/0.95) * $10B * 0.025 = $13.2M
    R(T=$1B投资, T=1000yr) ≈ $100M >> $13.2M OK 易合作
    
  积累型 (alpha=0.2, W=$10B):
    所需 R(T) > (0.8/0.2) * $10B * 0.025 = $1.0B
    R(T=$1B投资, T=1000yr) ≈ $100M < $1.0B NO 可能抵抗
    R(T=$1B投资, T=10kyr) ≈ $200M < $1.0B NO 仍抵抗
    但考虑: 零利率下 W 每年缩水 → 10年后 W≈$4B → 所需降至$400M
    且 p_detect → 1 → 抵抗期望 → 0
    → 10-15年内被迫合作

  王朝型 (alpha=0.55, W=$10B):
    所需 R(T) > (0.45/0.55) * $10B * 0.025 = $205M
    R(T=$1B投资, T=10kyr) ≈ $200M ≈ 临界
    R(T=$1B投资, T=50kyr) ≈ $230M > $205M OK
    且: 声望继承是乘数(3.5) → 支持ABC

  权力型 (alpha=0.35, W=$10B):
    所需 R(T) > (0.65/0.35) * $10B * 0.025 = $464M
    R(T=$1B投资, T=10kyr) ≈ $200M < $464M NO 最可能抵抗
    
  但所有类型共同约束: 
    p_detect → 1 意味着抵抗的期望→0
    零利率意味着 W→0 (即使未被检测)
    两者共同迫使: 所有人最终合作
```

## 3.5 声望继承——乘数，非地板（新增）

> **原始提示词3.5全部内容——v1遗漏的关键章节**

### 3.5.1 旧世界vs ABC继承的根本差异

```
旧世界财富继承:
  继承$10亿 → 子孙最低生活水平 = $10亿支撑的奢侈
            → 能力=0也能活得好 → 退化
            → 财富是"地板"——你跌不到地板以下
            → 平庸子孙: $10亿 = 永远舒适
            → 恶劣子孙: $10亿 = 作恶的燃料

ABC声望继承:
  父母高声望 → 子孙初始被关注度 = 父母的查询热度 * 衰减系数
            → 但这只是"麦克风更大"——说的内容还是自己负责
            → 声望是"乘数"——能力 * 乘数 = 实际声望
            → 能力=0 → 实际声望=0 (没人持续关注平庸的"二代")
            → 能力=优秀 → 实际声望=优秀*乘数 → 比白手起家更耀眼
            → 能力=恶劣 → 实际声望=负*乘数 → 比普通人更糟
```

### 3.5.2 声望继承的数学

```
定义:
  R_parent = 父母的声望（年查询人次）
  R_self = 子女自身能力产生的声望（年查询人次）
  k = 衰减系数（血缘远近递减）
  
子女实际声望:
  R_child_actual = R_self + k * R_parent * f(R_self)

其中激活函数 f(R_self):
  f(R) = 1 / (1 + exp(-(R - R_threshold)/sigma))
  
  R_threshold = 能力阈值: 需要多优秀才能"激活"父母声望
  sigma = 过渡宽度
  
简化: 分段函数
  R_self > 2*R_threshold:  f → 1.0  (全部激活)
  R_self = R_threshold:    f → 0.5  (半激活)
  R_self < 0.5*R_threshold: f → 0.1 (基本休眠)
  R_self → 0:               f → 0    (完全休眠)
  R_self < 0 (恶劣):        f → -0.5~-1.0 (反向激活→恶名)

衰减系数 k (基于社会关系强度):
┌──────────────────────────────────────────────────────┐
│ 关系          k值      半衰期    说明                │
│ ─────────────────────────────────────────────────── │
│ 配偶          0.30     一生      紧密共同体           │
│ 直系子女      0.25     1代      最直接的传承          │
│ 孙辈          0.10     2代      显著衰减              │
│ 曾孙辈        0.03     3代      几乎无关联            │
│ 远亲/同姓     0.01     4代+     仅姓氏微弱关联        │
│                                                      │
│ [E] k值基于社会心理学估计, +/-30%                     │
└──────────────────────────────────────────────────────┘

能力阈值 R_threshold:
  参考: 普通人一生社会注意力 ≈ 5.4 人年
  白手起家的优秀者: ~20-50 人年 (需要显著高于平均)
  
  R_threshold ≈ 10 人年 (达到"被人注意到有一定能力"的水平)
  
  这相当于:
    → 一个小型成功的创业者
    → 一个发表过有影响力的论文的研究者
    → 一个管理过一个成功项目的组织者
```

### 3.5.3 三种子孙情景

```
情景A: 优秀子孙 (R_self = 50人年, 父母 R_parent = 200人年)
──────────────────────────────────────────────────────────
  f(50) → 1.0 (远超阈值)
  附加声望 = k=0.25 * 200 * 1.0 = 50 人年
  实际声望 = 50 + 50 = 100 人年
  
  对比白手起家同等能力者: 50 人年 → 优秀子孙 100 人年 (2x)
  "站在巨人肩膀上的巨人"——比白手起家更耀眼
  
  对比旧世界: 继承$10亿 + 自己的事业
    旧世界: 人们说"他靠父母的$10亿起家"
    ABC: B层清晰显示"他父母贡献+他自己的能力叠加"
    → ABC更公平——能力清晰可见, 不会被"富二代"标签抹杀

情景B: 平庸子孙 (R_self = 2人年, 父母 R_parent = 200人年)
──────────────────────────────────────────────────────────
  f(2) → 0.1 (远低于阈值)
  附加声望 = 0.25 * 200 * 0.1 = 5 人年
  实际声望 = 2 + 5 = 7 人年 (初始被关注然后迅速被遗忘)
  
  前6个月: "这是XX的儿子!" → 高关注
  6个月后: "哦, 他很普通" → 关注消退
  1年后: 与普通人无异
  
  对比旧世界: 继承$10亿 → 永远是"$10亿身家的人"
    ABC暴露了平庸 → 但也给了重新开始的可能 (没有财富地板)
    旧世界用$10亿掩盖平庸 → ABC用B层暴露平庸 → 更诚实的游戏

情景C: 恶劣子孙 (R_self = -20人年, 父母 R_parent = 200人年)
──────────────────────────────────────────────────────────
  f(-20) → -1.0 (反向激活)
  附加声望 = 0.25 * 200 * (-1.0) = -50 人年
  实际声望 = -20 + (-50) = -70 人年
  
  "XX这么好的父母怎么有你这样的孩子"
  → 比普通坏人更糟——加倍被唾弃
  → 父母的声望变成了子女的负担
  
  对比旧世界: $10亿可以买律师、公关、洗白
    ABC中: 无法隐藏 → B层全部记录 → 无法洗白
    → 对恶劣者: ABC比旧世界更残酷
    → 这也是设计意图: 财富不应成为恶行的保护伞
```
