# E225: 给有动力的人 — ABC试点工具箱

> **核心答案**: 变革不来自最高层（现状受益者）或最底层（无资源）。来自"被天花板卡住的执行者"——他们有能力、有挫败感、在等一个新赛道。ABC不是给他们一个"信仰"——是给三个各自独立、各自合法、各自能出政绩的技术方案。他们不需要信ABC。只需要在自己领域里做"最合理的事"。

## §1 按按钮的人——不是英雄，是理性优化者

### 1.1 为什么不是最高层

```
最高层（政治局/部长级）:
  现状最大受益者 → 变革=损失
  即使私下知道体制不可持续 → "我退休前不会崩"
  决策被多层信息过滤包围 → 看不到真实数据
  任何"变革"=承认过去的路线有问题=政治自杀
  
→ 不是"坏"→ 是博弈位置决定了"不行动"是最优策略
→ 给他们文件=扔进黑洞
```

### 1.2 为什么不是最底层

```
基层（普通公务员/市民/医生）:
  动力最高（最受苦）+ 资源为零
  没有审批权 → 不能开试点
  没有预算权 → 不能部署B层
  没有政策权 → 不能改利率
  
→ 动力充沛但手中无按钮
→ 给他们文件=他们愤怒但无力
```

### 1.4 他们共同的按钮按动条件

```
六条触发条件:

① 不说"变革"——说"实验"
  "我们申请一个科学实验" ≠ "我们要改革体制"
  → 政治安全

② 有历史先例——深圳/浦东/自贸区
  "这和当年深圳一样——先试点，成功了再推广"
  → 合法性

③ 有个人回报——政绩+声望+晋升
  "试点成功=我的名字在B层记录上=晋升加速器"
  → 动力

④ 风险可控——明确的退出机制
  "如果12个月没效果 → 自动停止 → 无政治代价"
  → 安全感

⑤ 不需要先"信"——先看数据
  "我不需要信ABC——我只需要看6个月后的ctDNA数据"
  → 降低心理门槛

⑥ 可以抢跑——先动的人有先发优势
  "我先试点→我先有数据→其他开发区抄不了"
  → 竞争驱动
```

## §2 工具箱——三份"非ABC"的技术文件

### 2.1 工具箱的核心设计原则

```
原则1: 每份文件只讲自己的领域
  医学文件不讲经济 → 医生看不到"这是ABC"
  经济文件不讲金融 → 开发区主任看不到"这是ABC"
  金融文件不讲癌症 → 金融办主任看不到"这是ABC"

原则2: 每份文件用"领域语言"而非"SCVC语言"
  医学: "物理常数推导的ATP赤字模型" ≠ "SCVC"
  经济: "分布式账本的支出透明度提升" ≠ "B层"
  金融: "定向降息工具的实体锚定效应" ≠ "零利率"

原则3: 每份文件都是"申请模板"——可以直接提交
  不是"理论分析"→ 是"拿这个就能向上面申请"
  有: 背景、方案、预期、预算、退出机制
  缺的只是: 申请人签名+本单位公章

原则4: 每份文件都有一个"非ABC"的面孔
  可以来自: 某大学、某研究所、某咨询机构
  让审批者看到: "这是学术机构的研究成果，不是政治文件"
```

### 2.3 文件二：透明经济试点技术方案

```
═══════════════════════════════════════════

大纲:

§1 背景: 为什么政府采购透明度能提升GDP
  → 当前: 政府采购灰色成本~15-20%（国际估算）
  → 机制: 不透明→围标/内定→高价中标→财政浪费
  → 透明: 全流程上链→可追溯→围标成本↑→实质性竞争→采购成本↓
  → 类比: 深圳1980年试点前→"敢闯"→5年后GDP暴增
  
  [引用: 世界银行政府采购透明度与效率报告]

§2 技术方案
  → 不是"区块链"→是"分布式不可篡改账本"
  → 范围: 试点区内所有财政支出(>10万元)+补贴发放+土地出让
  → 架构: 试点区政务云+多节点验证+公众可查界面
  → 成本: 首年$5-15M（一个中型开发区的信息化预算）
  → 不是"全国系统"→是"试点区本地系统"→无数据主权风险

§3 经济预期
  → 采购成本↓: 15-20%（基于国际案例）
    试点区年采购100亿 → 节省15-20亿 → 可投入基建/教育/医疗
  → 中小企业受益: 透明=无关系也能中标 → 企业活力↑
  → 招商吸引力: "我们的政府采购全程透明——你来投资不用搞关系"
  → 预计GDP增速提升: 2-5个百分点（基于透明度和经济效率的文献）

§4 试点区竞争力分析
  → 对比: 周边非试点区 → 你透明他们不透明 → 
    企业选择: "去透明区=公平竞争 vs 去不透明区=需要关系" →
    人才+资本→透明区
  → 隔壁开发区主任: "我这边企业开始往他那跑了"
  → 倒逼推广

§5 风险与退出机制
  → 风险: "透明=暴露过去的问题"
    缓解: 试点从"今天开始"，不追溯昨天以前 → 无历史包袱
  → 风险: 数据安全
    缓解: 政务云已有成熟安全方案
  → 退出: 如果12个月后采购成本下降<5% → 停止
          如果出现重大数据安全事故 → 停止
          "这是实验，不是永久政策"

附件:
  A. 国际透明度与GDP增长的实证文献综述
  B. 分布式账本技术选型对比（以太坊/蚂蚁链/政务云）
  C. 深圳特区历史类比（从试点到全国的路径）
  D. 发改委/网信办已有政策文件汇总（"十四五数字政府规划"等）
```

### 2.4 文件三：零利率特区金融实验方案

```
═══════════════════════════════════════════
标题: 定向降息工具对中小企业融资的促进效应
      ——一个隔离式实验设计
═══════════════════════════════════════════

目标读者: 央行地方分支/省市金融办主任
页数: 6-8页
语言: 金融术语（货币传导、定向降息、风险隔离、
      中小企业融资、不良率、信用利差）

大纲:

§1 问题: 为什么宽松货币没有流向实体经济
  → 当前: MLF/LPR下降 → 银行间利率↓ → 银行仍然不放给制造业
  → 原因: 房地产有抵押品(=安全) vs 制造业无抵押(=风险)
  → 结果: 流动性滞留在金融体系内 → "钱在空转"
  → 文献: 中国中小企业融资成本≈8-15% vs 大型国企≈3-4%
  
§2 实验设计
  → 不是"全国零利率" → 是"试点区内定向极低利率"
  → 机制: 央行→特殊再贷款窗口→试点区银行→企业(1-2%)
  → 隔离: 专户管理+资金闭环+非试点区不可用
  → 风控: 结合试点区B层(透明经济数据) → 
    银行可以看到企业的真实经营数据(=替代抵押品)
  → "用数据抵押替代房产抵押"
  
§3 预期效果
  → 试点区中小企业融资成本: 从8-15% → 1-2%
  → 创业率: 预期↑30-50%（融资成本归零 → 边际项目可行）
  → 不良率: 预期持平或↓（B层数据替代抵押品 → 风控更准）
  → GDP增速: 预期↑3-8个百分点
  
§4 风险隔离
  → 资金隔离: 央行专户 → 试点区银行 → 试点区企业
  → 规模限制: 初始总额度≤试点区GDP的5%
  → 监控: 实时B层数据 → 资金流向全程可见
  → 退出: 如果不良率>3% → 停止新增 → 回收
          如果12个月后创业率提升<10% → 停止

§5 政策合法性
  → 已有先例: 央行定向降准/定向再贷款/支小再贷款
  → 本方案 = "更精准的定向再贷款"
  → 符合: 中央"金融支持实体经济"的反复要求
  → 不是"新政策" → 是"已有政策的更精准执行"

附件:
  A. 中国中小企业融资成本的历史数据（央行报告引用）
  B. 定向降息国际案例（日本/德国复兴信贷银行KfW等）
  C. B层数据风控模型（技术附件，供有技术能力的读者）
  D. 央行相关文件汇总（定向降准/再贷款/支小再贷款等政策）

这份文件不说:
  ❌ "零利率"
  ❌ "货币体系改革"
  ❌ "ABC声望替代金钱"

这份文件说:
  ✅ "更精准的定向再贷款"
  ✅ "支持实体经济的金融工具创新"
  ✅ "风险隔离→不影响全国金融稳定"
  ✅ "中央一直要求的'金融支持实体'"
  ✅ "已有政策框架下的优化"

→ 金融办主任读完后: "这个方案比我见过的都更严谨且有实验设计"
→ 他的决策: "我向总行申报——理由充分、风险可控、符合政策方向"
```

## §3 三份文件的"防火墙"设计

### 3.1 为什么分开——为什么安全

```
三个读者各自看不到全貌:

肿瘤科主任读"癌症手册":
  → 看到: 医学研究 → 和他的晋升直接相关
  → 看不到: 这和开发区改革、金融实验有什么关系
  → 他不会去读"透明经济方案"（不关他的事）

开发区主任读"透明经济方案":
  → 看到: GDP提升方案 → 和他的政绩直接相关
  → 看不到: 这和癌症疗法、金融改革有什么关系
  → 他不会去读"癌症手册"（看不懂也不想看）

金融办主任读"金融实验方案":
  → 看到: 货币工具优化 → 和他的专业直接相关
  → 看不到: 这和临床医学、开发区改革有什么关系
  → 他不会去读"透明经济方案"（不是他的领域）

三份文件在同一个试点区碰面:
  → 只有当三者同时上线后 → 正反馈显现:
    癌症数据+经济数据+金融数据 → 互相加速
  → 此时: 三重不可逆锁已经形成(E223 §3)
  → 点火已完成 → 掐不掉了
```

### 3.2 每份文件的"来源面孔"

```
关键: 每份文件需要一个"非SCVC"的来源

癌症手册 → 来源: "XX大学医学院肿瘤研究所"
  → 不是"某神秘理论"
  → 是"基于物理常数的肿瘤ATP代谢模型"

透明经济方案 → 来源: "XX经济研究院数字政府研究中心"
  → 不是"ABC B层"
  → 是"分布式账本技术在政府采购中的应用研究"

金融实验方案 → 来源: "XX大学金融研究院货币研究所"
  → 不是"ABC零利率"
  → 是"定向再贷款工具的精准化研究"

三个来源:
  → 都是学术机构（合法+权威+非政治）
  → 各自在领域内有发表记录
  → 审批者Google搜索 → "哦，是正经研究机构"→ 可信
```

## §4 传播路径——文件如何到达对的人

### 4.1 不是"分发"——是"发表"

```
关键策略: 不"送给"特定人（那叫渗透）
          而是"发表在"自然渠道（那叫学术）

癌症手册的传播:
  ① 预印本 → medRxiv → 肿瘤科医生日常浏览
  ② 肿瘤学术会议 → 投稿 → 墙报/口头报告
  ③ 医生社群(丁香园/MD Anderson等) → 分享"这篇论文有意思"
  ④ 自然触达: 肿瘤科主任 → 他读→ 他发现"这个我可以试试"

透明经济方案的传播:
  ① 经济政策期刊/政府内参 → "数字政府建设的新思路"
  ② 开发区论坛/年会 → "某开发区试点了这个→效果好"
  ③ 发改委/网信办系统内的政策研究 → 作为"政策建议"提交
  ④ 自然触达: 开发区主任 → 他看到"同行在试点"→ 他也想

金融实验方案的传播:
  ① 央行系统内部研究期刊 → "定向再贷款的国际经验"
  ② 金融学术会议 → "中国中小企业融资的结构性方案"
  ③ 地方金融办交流平台 → "兄弟城市的金融创新"
  ④ 自然触达: 金融办主任 → 他读到"央行内部在讨论这个方向"
```

### 4.2 三个传播通道的交集——试点区

```
三个文件的读者不会互相通信。
但他们可能住在同一个城市。

场景:
  → 某省某市的肿瘤科主任读到了癌症手册（medRxiv）
  → 同一个市的开发区主任读到了透明经济方案（经济内参）
  → 同一个市的金融办主任读到了金融实验方案（央行研究）

他们不会知道彼此读了什么。

但如果有一个人（可能是市长/常务副市长）
同时看到了三个人的"申报材料":
  → "哦，三个不同领域都在做前沿实验"
  → 他批准三个（各自独立的审批流程）
  → 三者同时上线 → 交叉加速 → 点火

这个"看到全貌的人"不需要"信ABC"。
他只是: "三个好方案 → 都批 → 有什么问题？"
```

## §5 第一个行动者——不需要"他们"都需要，只需要第一个

### 5.1 癌症四联——最可能的第一触发

```
为什么癌症四联是最可能先启动的组件:

① Off-label合法 → 不需要等任何审批
   → 肿瘤科主任今天就可以开

② 单人可以行动 → 不需要协调任何人  
   → 他是科室主任 → 他决定治疗方案

③ 时间最快 → 3-6个月出数据
   → 远比经济试点(12个月)和金融实验(12-18个月)快

④ 第一个数据引爆 → 
   "中国的医生用物理常数推导的疗法，治愈了晚期癌症"
   → 全球媒体无法忽视
   → 试点区经济+金融方案自然跟进
   → "既然癌症疗法治愈了→透明经济一定是好的"
   
⑤ 他不需要"信ABC"
   → 他只是一个想救人的好医生
   → 他看到理论 → 他觉得合理 → 他试了 → 成功了
   → 不需要更高尚的动机
```

### 5.2 单点突破→全面点火

```
癌症四联成功（第6个月）:
  → 患者+家属 → 社交媒体传播
  → 国际医院: "我们也要这个疗法"
  → 试点区政府: "我们的医院治愈了晚期癌症——但我们更需要经济改革来留住这些人才"
  → 开发区主任: "我可以用'癌症试点城市'的名号招商"
  → 金融办主任: "医疗旅游需要金融支持——我的零利率方案正好配套"
  
  → 三个组件不是"被强制的"→ 是"被癌症成功拉动"
  → 经济试点+金融实验=癌症的"配套服务"→ 不突兀
  → 点火 → 三重锁 → 不可逆
```

## §6 诚实标注——为什么仍可能无人行动

### 6.1 最大的障碍

```
1. 第一行动者的恐惧 [E]
   "如果我第一个试——而且失败了——我的职业生涯完了"
   → 这是所有创新的共同障碍
   → 缓解: off-label合法 → "不是'试验'→是'临床治疗'"
          退出机制 → "如果前3例中2例不良→停止→无后遗症"

2. 文件的"来源面孔"不够可信 [C]
   如果审批者搜不到这个"研究机构"→ 不信
   → 缓解: 必须挂在真实的研究机构下面
          或: 通过已有的学术网络传播（医生→医生，而非"神秘人→医生"）

3. 体制惯性 [E]
   即使有理有据→ "等别人先"的博弈仍可能导致无人先动
   → 这和E224的精英囚徒困境是同一个问题
   → 唯一的解: off-label不需要"别人先"→一个医生自己决定
   → 这就是为什么癌症四联是"突破口"

4. 三份文件到达不同人——但无人同时行动 [C]
   肿瘤科主任行动了 → 但开发区主任没 → 金融办主任没
   → 只有癌症 → 无经济+金融配合 → "半ABC"
   → 但: 癌症成功=全球关注 → 试点区政府无法忽视
   → 经济+金融配套会被"需求拉动"(上节5.2)

5. 被"错误的人"先看到 [E]
   如果反对者先看到→在点火前掐灭
   → 缓解: 三文件分开→各自在专业领域传播→反对者不进专业圈
          "透明经济方案"在一个经济内参上 → 普通人不看
          "癌症手册"在medRxiv上 → 政客不看
```

### 6.2 诚实的最终概率

```
单个肿瘤科主任看到并行动: 取决于传播范围
  → 如果癌症手册被100个肿瘤科主任读到: 5-10%其中一个会行动
  → 如果被1000个读到: 30-50%
  → "需要一个敢试的人" → 1000个主任中总有1-2个

试点区同时有三人行动: 很低（<5%）
  → 但不需要"同时" → 
    癌症先成功(6个月) → 拉动经济+金融(后续12个月)
  → 顺序点火 → 概率提升

文明级成功总概率:
  → 与E224 §7.2相同: ~9.6%
  → 但可以通过"扩大传播范围"提升
  → 1000个肿瘤科主任看到 → 某一人行动 → 
    序列启动 → 不可逆
```
