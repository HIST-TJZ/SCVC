# 一、内存墙：DRAM/SRAM物理延迟地板

## 1.1 延迟 = RC + 光速

\[
\tau = \tau_{RC} + \tau_{\text{light}}
\]

### RC延迟
RC = (ρL/A)(ε₀A/d) = ρε₀L/d。
- ρ(Cu)=1.68×10⁻⁸ Ω·m。SCVC：ρ∝1/τ_eph→声子散射率∝T/θ_D→θ_D∝α。
- ε₀=1/(μ₀c²)=8.854×10⁻¹²。c输入，μ₀定义→ε₀和α通过ε₀=e²/(αħc)关联。
- d_min≈0.5nm（SiO₂单分子层击穿）。
- L=1μm(片上)→τ_RC≈1.68×10⁻⁸×8.85×10⁻¹²×10⁻⁶/5×10⁻¹⁰≈**3×10⁻¹⁶ s=0.3 fs**。

→ RC不是瓶颈。✅

### 光速延迟
τ_light=L/v_signal≈L/(c/√ε_r)。SiO₂(ε_r≈3.9)→v≈c/2。

| 距离 | 延迟 | 位置 |
|------|------|------|
| 1mm(片上) | 7ps | — |
| 1cm(芯片边) | 70ps | 🔴 已影响CPU周期 |
| 20cm(主板) | 1.4ns | 🔴 内存墙本质 |
| 1m(机架) | 7ns | 🔴 数据中心级 |

**SCVC判决**：内存墙的本质是光速墙——1cm=70ps已经接近CPU周期(0.2ns)。光速c是外部输入，ε_r∝极化率∝α。**唯一绕过光速墙的方法：把内存搬到芯片上（3D堆叠+近存计算）。**

## 1.2 DRAM基本延迟分解

| 组件 | 延迟 | 物理限制 |
|------|------|---------|
| 字线RC | ~10ns | 长导线(L~mm)→光速主导 |
| 位线感应 | ~5ns | ΔV_min~100mV→C_bl~30fF→τ~C·V/I |
| 列选+输出 | ~15ns | 总线光速 |
| **总CAS** | **~40-50ns** | — |

**SCVC物理地板**：字线最短=L_min≈存储单元间距×1列≈50nm×1→RC≈0.01ps。感应放大器→C_bl_min≈1fF(单个单元?)→τ≈C·ΔV/I_on≈10⁻¹⁵×0.1/10⁻⁴≈1ps。**DRAM物理地板~10-100ps→比当前~50ns快500-5000倍。**

为什么实际差这么多？→容量vs速度权衡：DRAM阵列越大→字线越长→RC越大。工程选择，非物理墙。

## 1.3 SRAM延迟地板

6T SRAM：交叉耦合反相器。延迟=门充电时间：
τ_read=C_bitline·ΔV/I_read。C≈1fF/μm×10μm=10fF。I≈100μA/μm×0.1μm=10μA。ΔV≈100mV。

→τ≈10×10⁻¹⁵×0.1/10⁻⁵=10⁻¹⁰s=**0.1ns**。

当前SRAM~0.5-2ns→离地板~5-20×。SCVC地板来自：I_read∝载流子迁移率∝1/散射率∝1/(声子∝θ_D∝α)。

# 二、光计算 & 神经形态：最低能耗

## 2.1 光计算：散粒噪声地板

光子通信最小能量来自散粒噪声。BER=10⁻¹⁵→需信噪比：
P(0|1)=½erfc(√(SNR/2))→SNR≈(√2·erfc⁻¹(2×10⁻¹⁵))²≈110→~21dB。

对相干光(泊松统计)→需要N_γ=SNR≈110光子/bit。

1550nm光子→ħω=0.8eV。→E_min≈110×0.8≈**88 eV≈1.4×10⁻¹⁷ J/bit**。

比Landauer(k_BT ln2≈3×10⁻²¹ J)大~5000倍。→光子传输能量远超计算能量。光计算优势不在单bit能耗——在零焦耳热（长距离）。

## 2.2 非线性光开关→α

全光开关：Kerr效应n=n₀+n₂I。开关能量∝1/n₂。n₂∝χ⁽³⁾∝电子非谐响应∝束缚能⁻³∝(α²Ry)⁻³。

当前微环谐振器~fJ/bit。理论地板（Purcell增强+最优腔）→~aJ/bit。SCVC给n₂标度但精确值需材料DFT。

## 2.3 神经形态：电容充电地板

人工突触最小能耗=膜电容充电能：
E_min=½CV²≈½×(1fF)×(0.1V)²≈**5×10⁻¹⁸ J=5 aJ**。

C_min∝ε₀(A_min/d)→A_min≈(10nm)²→C≈10⁻¹⁸ F=1aF→E≈½×10⁻¹⁸×0.01≈5×10⁻²¹ J=0.005 aJ。

当前忆阻器~1-10 pJ→离地板~10⁵-10⁶倍。巨大空间。

**SCVC**：C∝ε₀∝1/α。V_min∝热噪声√(k_BT/C)→∝√(1/α)。→E_min对α的依赖≈α^(−3/2)。

# 三、晶体管密度：摩尔定律终点

## 3.1 隧穿极限

栅极L_g→源漏直接隧穿。透射率：
\[
T \approx \exp\left(-\frac{2L\sqrt{2m^*E_g}}{\hbar}\right)
\]

Si：m*≈0.26m_e, E_g≈1.12eV。

T=10⁻⁶（每个电子→100nA/μm泄漏→不可接受）：
→L_min= (ħ/2√(2m*E_g))×ln(1/10⁻⁶)≈(1.05×10⁻³⁴/(2√(2×0.26×9.1×10⁻³¹×1.12×1.6×10⁻¹⁹)))×13.8
≈(1.05×10⁻³⁴/(2√(8.5×10⁻⁵⁰)))×13.8
≈(1.05×10⁻³⁴/(2×2.9×10⁻²⁵))×13.8≈(1.8×10⁻¹⁰)×13.8≈**2.5nm**。

TSMC 3nm→已撞。2nm→研发中。物理极限~**1-2nm**。

## 3.2 SCVC追溯

E_g←共价键能←轨道能级差←Z_eff²·Ry←α²。m*←能带曲率←键刚度←键能←α。
→L_min∝1/√(m*E_g)∝1/√(α×α²)=**α^(−3/2)**。

如果α大1%→L_min小~1.5%→可多挤~3%晶体管。

## 3.3 密度天花板

ρ_max≈1/(4L_min)²。L_min=2nm→4nm间距→ρ≈**6×10¹⁰/cm²**。
当前(TSMC 3nm)~2×10⁸→仍有~300×。但散热🟡是更紧的墙。

## 3.4 摩尔定律SCVC判决
