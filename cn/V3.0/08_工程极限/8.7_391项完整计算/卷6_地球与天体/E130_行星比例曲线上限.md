--------------------------------------------------------------------
§1. 行星比例的SCVC分解
--------------------------------------------------------------------

【四个SCVC锁死的核心参数】

  行星系统的所有结构特征最终追溯到四个由α和α_s锁定的物理量:

  (1) 雪线位置 r_snow:
      冰的凝结温度 T_cond ≈ 170 K（由H₂O H键能 0.20 eV 决定）
      恒星辐照: F = L/(4πr²)
      → r_snow ∝ √L ∝ M^(1.75)
      太阳: r_snow ≈ 2.7 AU（小行星带）
      红矮星 0.5M_☉: r_snow ≈ 0.8 AU
      F型 1.5M_☉: r_snow ≈ 5.5 AU

  (2) 盘面密度 Σ(r): 标准盘模型 Σ ∝ r^(-3/2)
      由α决定的盘黏度（磁旋转不稳定性依赖于电离度=依赖于α）

  (3) 隔离质量 M_iso:
      M_iso ≈ (2πr²Σ(r))^(3/2) / (3M_star)^(1/2)
      → M_iso ∝ r^(3/4)（对于 Σ ∝ r^(-3/2)）
      1 AU: M_iso ≈ 0.1 M_⊕（→ 火星大小 ✓）
      5 AU: M_iso ≈ 10 M_⊕（→ 木星核心 ✓）

  (4) 轨道间距:
      Δa_min ≈ k × a × (M_p/3M_star)^(1/3)，k≈5-10 为长期稳定性因子
      → 间距与轨道半径成正比 → 几何级数间距 → Titius-Bode

【从隔离质量到最终行星数量: 巨撞击阶段】

  隔离增长后: 内盘 ~50-100 个火星大小的胚胎
  巨撞击 ~100 Myr: 胚胎合并 → 违反间距约束的 → 碰撞/抛射
  → 最终生存的行星: 间距 ≥ 10 Hill 半径
  → 内盘 (0.4-2.7 AU): 质量 ~15 M_⊕ → 4 颗类地行星 ✓
  → 外盘 (2.7-30 AU): 质量 ~200 M_⊕ → 4 颗巨行星 ✓

§2. 比例曲线的SCVC推导
--------------------------------------------------------------------

【行星类型比例 vs 恒星质量】

  恒星质量    雪线     类地行星    气巨+冰巨   总行星    4:2:2型?
  ────────────────────────────────────────────────────────
  0.3 M_☉    0.3 AU   1-2 颗      0 颗       1-2      纯岩石
  0.5 M_☉    0.8 AU   2-4 颗      0-1 颗      2-5      纯岩石(可能有1冰巨)
  0.7 M_☉    1.4 AU   3-5 颗      1-2 颗      4-7      接近阈值
  0.9 M_☉    2.2 AU   3-5 颗      2-3 颗      5-8      可能
  **1.0 M_☉ 2.7 AU   4 颗        4 颗        8        ✅太阳系**
  1.2 M_☉    3.7 AU   4-6 颗      3-5 颗      7-11     更复杂
  1.5 M_☉    5.5 AU   5-8 颗      4-7 颗      9-15     非常复杂

  ▸ 太阳系的 4:2:2 在 1.0 M_☉ 处是**典型值**，不是极端
  ▸ 低于 ~0.7 M_☉ → 没有完整的三类型（缺冰巨或气巨）
  ▸ 高于 ~1.3 M_☉ → 行星数量增加 → 系统拥挤 → 更多轨道不稳定
  ▸ 1.0 M_☉ 恰好处在"有完整的岩石+气巨+冰巨三重结构"的**质量下限附近**

【为什么说太阳系是"下限"？— 真正的含义】

  不是行星数量最少，而是:

  1. 恒星质量的下限: ~1.0 M_☉ 是能产生"完整三类型行星系统"的最小质量
     → 再小 ~10% → 没有冰巨
     → 再小 ~30% → 没有气巨
     → 再小 ~50% → 只有 2-3 颗岩石行星（TRAPPIST-1 型）

  2. 结构复杂度的下限: 4+2+2 = 8 颗，比例 2:1:1
     → 这是SCVC物理允许的最简单"完整系统"
     → 更简单的系统 → 缺失某些行星类型

  3. 这不是巧合: 如果冰巨负责后期重轰炸 → 水输运到地球
     → 没有冰巨 → 地球可能是干的 → 生命起源更难
     → **太阳恰好有"刚好够"的恒星质量来产生冰巨**

§3. Titius-Bode — 从SCVC喂食区宽度推导
--------------------------------------------------------------------

【轨道间距的物理根源: Hill半径稳定性】

  喂食区宽度: Δa ≈ k × R_H = k × a × (M_p/3M_☉)^(1/3)

  太阳系各行星的 Hill 半径和间距:

  行星        a(AU)   M_p(M_⊕)    R_H(AU)   喂食区(AU)   到下一颗
  ──────────────────────────────────────────────────────────
  水星        0.39      0.06       0.002       0.01       0.33 ✓
  金星        0.72      0.82       0.007       0.04       0.28 ✓
  地球        1.00      1.00       0.010       0.06       0.52 ✓
  火星        1.52      0.11       0.007       0.04       1.25 ✓
  谷神星      2.77      0.0002     0.002       0.01       2.43 — (行星未形成)
  木星        5.20    317.8        0.355       2.13       4.34 ✓
  土星        9.54     95.2        0.436       2.62       9.66 ✓
  天王星     19.20     14.5        0.468       2.81      10.90 ✓
  海王星     30.10     17.1        0.776       4.66       —

  ▸ 几乎所有邻星间距 > 喂食区宽度 → 系统稳定 ✓
  ▸ 谷神星处间距 (2.43) 远大于喂食区 (0.01) → 小行星带是"未完成的胚胎"
  ▸ Titius-Bode (a_n = 0.4 + 0.3×2^n) 是间距随距离几何增长的近似

  SCVC根源:
    Δa/a ≈ 常数 × (M_p/M_star)^(1/3)
    → 在类地区域 Δa/a ≈ 0.1-0.4
    → 在巨行星区域 Δa/a ≈ 0.3-0.5
    → 这个"间距常数"由 Σ(r) 剖面设定 → 由 α（盘黏度）锁死
    → **Titius-Bode不是"巧合" — 是寡头增长+轨道稳定性的物理必然**

§4. 比例曲线的形状 — 像原子光谱吗？
--------------------------------------------------------------------

【类比的有效部分】

  原子光谱              行星系统
  ─────────────────────────────────────────────
  电子排布              行星排布
  势能: 库仑势 V∝1/r    势能: 引力 V∝1/r + 盘密度剖面
  禁戒区: Pauli不相容    禁戒区: 轨道共振重叠 → 混沌 → 抛射
  "轨道": n,l,m量子数     "轨道": a,e,i（半长轴,偏心率,倾角）
  唯一基态              多个准稳态

  ▸ 两者的共同本质: **不是所有构型都允许 — 存在"禁戒区"**

  ▸ 但根本差异:
    量子:  哈密顿量+Pauli → **唯一解**
    引力:  SCVC边界条件(盘剖面) + N体混沌 → **可行的区域, 非唯一解**

【SCVC定义的"允许区域"】

```
行星数量 N
    ↑
 15 ┤                                    ●  (F型星)
    │                              ●
 12 ┤                         ●
    │                     ●
  9 ┤                 ●
    │             ●
  8 ┤         ● ←太阳
    │     ●
  6 ┤  ●
    │ ●
  3 ┤●
    │
  0 ┼────┬────┬────┬────┬────┬────→ 恒星质量 M
    0.3  0.5  0.7  0.9  1.1  1.3  1.5  M_☉
    └─────── 禁区 ──────┘└── 可行区 ──┘
    (没有完整三类型)     (有完整三类型)
```

  ▸ **太阳(~1.0 M_☉)恰在"禁区→可行区"的边界上**
  ▸ 这是曲线最有趣的特征: 不是"太阳系特殊"，而是"太阳质量刚好跨过阈值"
  ▸ SCVC给出了这个阈值的精确位置: M_threshold ≈ 0.75-0.85 M_☉

【为什么SCVC不能给精确解？】

  N体混沌使初始条件的微小差异 → 最终构型的巨大差异。
  SCVC只能给出:
    ✓ 允许的行星数量范围
    ✓ 雪线位置 → 岩石/气巨的比例
    ✓ 最小轨道间距
    ✗ 某颗特定行星的质量
    ✗ 是否存在"热木星"（迁移是混沌的）
    ✗ 巨撞击的具体结果

  → **SCVC给的是"边界"，不是"点"**
  → 原子光谱的类比夸大了确定性的程度
  → 但在统计意义上，行星系统确实遵循SCVC预测的结构模式

§5. 诚实结论
--------------------------------------------------------------------

【SCVC锁死的】

  ✓ 雪线位置: α+α_s → 恒星光度 → r_snow ∝ M^1.75
  ✓ 盘面密度剖面: α → 黏度 → Σ ∝ r^(-3/2)
  ✓ 隔离质量标度: M_iso ∝ r^(3/4) → ~0.1 M_⊕@1AU, ~10 M_⊕@5AU
  ✓ 轨道间距标度: Δa ∝ a → 几何级数 → Titius-Bode
  ✓ 完整三类型系统的质量阈值: ~0.75-0.85 M_☉

【SCVC没锁死的】

  ✗ 具体行星数量: N体混沌+巨撞击历史不可预测
  ✗ 太阳系的4:2:2: 是典型解之一，不是唯一解
  ✗ 日食比例(P): E129已证，这是独立巧合

【太阳系的真正位置】

  ▸ **不是"下限解" — 是"刚好跨过阈值"**
  ▸ 1.0 M_☉ 是拥有完整三类型行星系统的最小质量
  ▸ 太阳系在"禁区→可行区"的边界上
  ▸ 这不是巧合 — 这是SCVC物理的必然结果: 低于此阈值的恒星没有冰巨
  ▸ 而冰巨 → 后期重轰炸 → 水输运 → 地球的海洋

  **E129+E130联合结论**:
  日食比例 ~1.03 是审美巧合，不被SCVC锁死。
  但太阳恰好有形成冰巨所需的恒星质量+恰好有一颗大卫星 —
  这两者综合起来，让地球同时拥有了:
    液态水（冰巨输运） + 稳定地轴（大卫星） + 可见日全食（距离巧合）
