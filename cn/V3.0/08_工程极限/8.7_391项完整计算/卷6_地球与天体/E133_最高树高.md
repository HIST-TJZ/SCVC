SCVC工程极限 E133：最高树高 — 木质部蒸腾+管胞内爆的双重物理墙
====================================================================

**所有推导基于SCVC常数（α=1/(4π³+π²+π), H键0.20eV, C-C键3.6eV, C-O键3.5eV）。**

--------------------------------------------------------------------
§1. 两条锁死的物理链
--------------------------------------------------------------------

【链1: 蒸腾拉力 — 水柱的张力天花板】

  树木靠蒸腾拉力将水从根拉到叶。水柱处于负压（张力）状态。
  负压上限 = 水抗拉强度。抗拉强度由H键网络决定。

  SCVC源头: α → H₂O极化率 → H键能0.20 eV/H键
  水分子配位数 ~3.5 → 内聚能密度 ≈ 3.5×0.20 eV / (30Å³) ≈ 3.7×10⁹ J/m³

  但实际极限不在"水本身断裂"——在**气穴成核**（cavitation）。
  木质部管胞通过纹孔膜（pit membrane）连接。纹孔膜上的纳米孔
  是空气进入木质部的"薄弱点"。

  气穴临界负压（air-seeding）:
    Ψ_crit = -4γ cos θ / d_pore_max

  其中:
    γ = 72.8 mN/m — 水表面张力（从H键能推导）
    θ ≈ 0° — 水在纤维素上接触角（亲水）
    d_pore_max — 纹孔膜最大孔径

  d_pore_max的SCVC根源:
    纹孔膜 = 纤维素微纤丝无规网络
    微纤丝间距由氢键网络 + 半纤维素/果胶填充决定
    最小功能孔径: ~20-50 nm（太小则水流阻力过大）
    红杉的纹孔膜孔径: ~50-100 nm（已高度优化）

  代入:
    Ψ_crit(20nm) = -4×0.0728×1/(20×10⁻⁹) ≈ -14.6 MPa
    Ψ_crit(50nm) = -4×0.0728×1/(50×10⁻⁹) ≈ -5.8 MPa
    Ψ_crit(100nm) = -4×0.0728×1/(100×10⁻⁹) ≈ -2.9 MPa

  高度约束:
    h_max = |Ψ_crit - Ψ_soil - Ψ_friction| / (ρg)
    Ψ_soil ≈ -0.5 MPa, Ψ_friction ≈ -0.5 MPa（低蒸腾/雾天）
    ρ = 1000 kg/m³, g = 9.8 m/s²

    d_pore = 100nm: h = (2.9-0.5-0.5)×10⁶/9800 ≈ 194 m
    d_pore = 50nm:  h = (5.8-1.0)×10⁶/9800 ≈ 490 m
    d_pore = 20nm:  h = (14.6-1.0)×10⁶/9800 ≈ 1390 m

  但孔径不能无限缩小: 纹孔膜也是水流通道。
  孔径缩小 → 水流阻力 ∝ 1/d⁴ → 蒸腾受限 → 光合受限 → 碳饥饿。

  **权衡最优**: d_pore ≈ 50-100 nm → h_hydraulic ≈ 150-300 m

【链2: 管胞内爆 — 细胞壁的抗压崩溃】

  木质部管胞承受负压时，管胞壁受外压→可能向内塌缩（implosion）。

  临界外压（圆柱壳屈曲）:
    P_crit_implosion ≈ E_wall × (t_wall / D_lumen)²

  SCVC来源:
    E_wall ≈ 3-10 GPa（纤维素+木质素复合，C-C/C-O键能决定刚度）
    t_wall ≈ 2-5 μm（管胞壁厚，由形成层分裂次数决定）
    D_lumen ≈ 20-40 μm（管胞内径）

    t/D ≈ 0.05-0.25

    P_crit ≈ 10×10⁹ × (0.05)² = 25 MPa → h ≈ 2550 m（最小t/D）
    P_crit ≈ 8×10⁹ × (0.1)²  = 80 MPa → h ≈ 8160 m（典型t/D）

  结论: 管胞内爆不是瓶颈——它允许的高度远超蒸腾极限。
        树木被"水柱断裂"卡死，而非"细胞压瘪"。

§2. 第三条隐藏链: 碳平衡 — 光合 vs 呼吸
--------------------------------------------------------------------

  树越高 → 更多活组织(韧皮部、形成层、边材薄壁细胞) → 更多呼吸消耗
  光合产出被呼吸吃掉 → 净碳收入趋零 → 高度无法继续增加。

  SCVC估算:
    光合净效率 ~1-3%（E17），呼吸占光合的30-60%
    总叶面积 ∝ 树冠体积 ∝ h³
    活组织呼吸 ∝ 树干体积 ∝ h × D²（D随h增大）
    → 净碳收入 ∝ h³ - 常数×h×h² = h³ - const×h³
    → 当呼吸=光合 → h_max_carbon

  粗估: 红杉叶面积指数 ~6-8, 呼吸占总光合 ~40%
  → 呼吸比例随h增加(活组织比例上升)
  → h_max_carbon ≈ 120-180 m（比水力极限更紧）

§4. 与山高的对比（E19/E64）
--------------------------------------------------------------------

  山的最高:    Olympus Mons 21.9 km（火星低g）vs 地球 ~9 km（珠峰）
  树的最高:    红杉 115 m vs SCVC ~150 m

  山高/树高 ~9000/115 ≈ 78×

  两者本质相同: 重力 vs 键能的博弈。
    山: 岩石强度(Si-O键 ~4-6 eV) vs 重力
    树: 水内聚力(H键 ~0.20 eV) vs 重力

  键能比: 4/0.2 ≈ 20×
  高度比: 78×（不是20×，因为还有几何因素）
    → 山受限于底部压强（岩石抗压 ~100 MPa）
    → 树受限于水柱张力（水抗拉 ~3-15 MPa，气穴限制）
    → 实际可用抗拉远低于理论值（缺陷导致）

  如果树木能消除气穴缺陷:
    h_max = |Ψ_cohesion|/(ρg) = 140×10⁶/9800 ≈ 14,300 m
    → 理论上树可以比山高！但碳平衡和结构会在那之前锁死。
