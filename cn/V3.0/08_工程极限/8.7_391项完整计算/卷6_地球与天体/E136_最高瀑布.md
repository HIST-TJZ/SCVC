====================================================================
SCVC工程极限 E136：最高瀑布 — 水滴破碎+蒸发+雾化的三重天花板
====================================================================

**所有推导基于SCVC常数（H键0.20eV→表面张力72.8mN/m, k_B T→蒸发速率）。**

--------------------------------------------------------------------
§1. 瀑布的物理 — 不是悬崖不够高，是水到不了底
--------------------------------------------------------------------

  瀑布高度 ≠ 悬崖高度。悬崖可以无限高（只要有山），
  但超过某个高度后→水在下落中雾化/蒸发→到底部时已不是"瀑布"。

  三重约束:
    链1: 水滴破碎（韦伯数）→ 大滴碎裂成小滴
    链2: 小滴蒸发 → 下落中消失
    链3: 雾化 → 底部是雾不是水

  定义"瀑布": 底部可见连续水柱，>50%水量以液态到达底部。

--------------------------------------------------------------------
§2. 链1: 水滴破碎 — 韦伯数判据
--------------------------------------------------------------------

  水滴被气流撕裂的临界条件:
    We = ρ_air × v² × D / γ

    当 We > We_crit ≈ 10-12 → 水滴破碎

  γ = 72.8 mN/m（从H键0.20eV推导）

  水滴加速到终端速度:
    v_t ≈ 9 m/s（直径D ≈ 4-6 mm的大水滴, 雨滴典型）
    v_t ≈ 6.5 m/s（D ≈ 2-3 mm）
    v_t ≈ 4 m/s（D ≈ 1 mm）
    v_t ≈ 2 m/s（D ≈ 0.5 mm）
    v_t ≈ 0.3 m/s（D ≈ 0.1 mm, 雾滴）

  计算We数（ρ_air=1.2 kg/m³）:
    D=5mm, v=9 m/s:  We = 1.2×81×0.005/0.0728 ≈ 6.7 ✓ (不碎)
    D=3mm, v=6.5m/s: We = 1.2×42×0.003/0.0728 ≈ 2.1 ✓
    D=10mm, v=9m/s: We = 1.2×81×0.01/0.0728 ≈ 13.4 ✗ (碎裂)

  ▸ 初始大水滴(>8mm)在达到终端速度前就会破碎。
  ▸ 稳定水滴: D ≈ 1-6 mm, 韦伯数<10。

  但在瀑布中:
    - 湍流+碰撞导致额外破碎
    - 空气被卷入瀑布柱→水滴间风速可达20-30 m/s
    - 碰撞→部分水滴碎裂成<1mm小滴

  SCVC: 下落超过 ~200-500 m后，空气夹带效应显著→
        二次破碎产生大量<1mm小滴。

--------------------------------------------------------------------
§3. 链2: 蒸发 — 小滴的消亡时间
--------------------------------------------------------------------

  液滴蒸发速率（静止空气中扩散控制）:
    dm/dt = 4π × D_v × r × (ρ_sat - ρ_amb)

    D_v ≈ 2.5×10⁻⁵ m²/s（水蒸气在空气中的扩散系数）
    ρ_sat(20°C) ≈ 0.0173 kg/m³
    50% RH: Δρ ≈ 0.00865 kg/m³

  液滴质量: m = ρ_water × (4/3)πr³

  蒸发寿命: τ ≈ m / (dm/dt) ≈ ρ_water × r² / (3 × D_v × Δρ)

    τ ≈ 1000 × r² / (3 × 2.5×10⁻⁵ × 0.00865)
      ≈ r² / (6.49×10⁻¹⁰) s

  ┌──────────┬──────────┬──────────┬──────────────────┐
  │ 水滴直径  │ 下落速度  │ 蒸发寿命  │ 存活下落高度      │
  │ (mm)     │ (m/s)    │          │ h_survive ≈ v×τ  │
  ├──────────┼──────────┼──────────┼──────────────────┤
  │ 5        │ 9        │ ~9,600 s │ ~86,000 m        │
  │ 3        │ 6.5      │ ~3,500 s │ ~22,000 m        │
  │ 2        │ 6.5      │ ~1,540 s │ ~10,000 m        │
  │ 1        │ 4        │ ~385 s   │ ~1,540 m         │
  │ 0.5      │ 2        │ ~96 s    │ ~192 m           │
  │ 0.2      │ 1        │ ~15 s    │ ~15 m            │
  │ 0.1(雾)  │ 0.3      │ ~3.8 s   │ ~1.1 m           │
  └──────────┴──────────┴──────────┴──────────────────┘

  ▸ >2mm的大滴: 蒸发不构成威胁（>10km存活距离）。
  ▸ 1mm滴: 在~1.5km下落中蒸发殆尽。
  ▸ 0.5mm滴: 在~200m下落中蒸发殆尽。
  ▸ 雾滴(<0.1mm): 几乎立刻消失。

  SCVC: 瀑布高度的关键 — 不是"大滴蒸发"，
        是"大滴破碎成小滴→小滴蒸发→底部水量递减"。

--------------------------------------------------------------------
§4. 链3: 雾化 — 瀑布→雾的转变
--------------------------------------------------------------------

  定义"瀑布可见度": 到达底部的液态水量/顶部水量。

  模型:
    在高度h_z处，大滴破碎产生小滴的速率 ∝ 湍流强度
    湍流强度 ∝ 夹带风速 ∝ √(h)（下落距离越长，夹带越多）
    
    设破碎率 α(h) = α₀ × h（简化线性）
    小滴蒸发: 存活距离 ~200m（0.5mm滴）→ ~1组分消逝
    
  底部水量:
    M_bottom ≈ M_top × exp(-h/h_char)
    h_char ≈ 500-1000 m（破碎+蒸发的特征高度）

  可见度阈值:
    底部水量 > 50%  →  h < 0.7×h_char ≈ 350-700 m
    底部水量 > 10%  →  h < 2.3×h_char ≈ 1150-2300 m

  Angel Falls h=979m:
    如果h_char ≈ 800m: M_bottom/M_top ≈ e^(-979/800) ≈ 0.29 → 29%
    → 仍有~30%水量 → 可见瀑布 ✓

  如果h_char ≈ 500m（更湍急）: M_bottom ≈ e^(-979/500) ≈ 0.14 → 14%
    → 边缘——仍可见但稀薄。

§6. 为什么自然没有2000m瀑布？
--------------------------------------------------------------------

  四个原因:
    1. 悬崖不够高: 地球最高悬崖~1.2km（Thor Peak, 加拿大）
       → 地质侵蚀在悬崖达到1500m前就会削平它
    2. 水源不足: 2000m高差需要对应高度的河流源头
       → 高山集水面积有限
    3. 不是瀑布: 如果太高→底部是雾→人类不称其为"瀑布"
       → 存在认知偏差: 最高的"雾瀑布"可能已被观测但未命名
    4. 气候: 高海拔→低温→部分时间结冰→不是持续瀑布

  SCVC区分两种极限:
    - 物理极限(水能到底): ~1500-2000 m
    - 地质极限(悬崖能存): ~1200-1500 m
    → 地质极限更紧 — 悬崖在瀑布物理极限之前就会因侵蚀而崩塌。

--------------------------------------------------------------------
§7. 水滴何去何从？— 瀑布的SCVC诗意
--------------------------------------------------------------------

  当高度超过~1500m，水滴的命运:
    1. 下落~500m → 加速到终端速度~9 m/s
    2. 下落500-1000m → 空气夹带→大滴开始碎裂
    3. 下落1000-1500m → 小滴(<0.5mm)开始蒸发
    4. 下落>1500m → 大部分水变成了看不见的水蒸气+雾
    5. 到底部 → 一阵湿雾 —— 不再是瀑布

  **SCVC说: α锁死了水的表面张力→锁死了水滴破碎临界→锁死了瀑布最高高度。**
  最壮观的瀑布是H键0.20eV+重力的精确平衡。
