1.2 材料强度 → 静水压的过渡
--------------------------------------------------------------
一个天体什么时候从"靠材料强度撑住不规则形状"变为"引力迫使球形"？

    中心压强：P_c ≈ (3G/8π) · M²/R⁴  (均匀球近似)
    强度条件：P_c < σ_yield  → 非球形

    → 临界半径：R_crit = √(3σ_yield / (2π G ρ²))

    ⚫ 完美晶体(SCVC上限, σ≈465 GPa): R_crit ~ 16,500 km
       (相当于 2.6 R_⊕, 11 M_⊕ — 所有已知岩石行星球形)
    ⚫ 实际岩石(σ≈10 MPa, 裂隙限制): R_crit ~ 76 km
       (Ceres ~ 470 km 半径 ≈ 球形, Vesta ~ 260 km ≈ 近球形)

    结论：SCVC完美晶体从未在行星尺度实现。
          所有>100 km的天体服从静水压平衡。

1.4 恒星质量边界与SCVC
--------------------------------------------------------------
电中性天体质量的全谱由三个SCVC常数锁定：

    M_min(恒星)  ≈ 0.07 M_☉      (H点火, α_s+α)
    M_Ch         ≈ 1.44 M_☉      (电子简并压, m_e+M_Pl)
    M_TOV        ≈ 2-3 M_☉       (中子简并压, m_n+α_s+M_Pl)

    其中 M_Ch = (常数) × (ħc/G)^(3/2) / (μ_e m_H)²
             ∝ M_Pl³ / m_H²

    全部由SCVC的 α, α_s, m_e, M_Pl 导出。


2. 最高山脉
==============================================================

2.1 山高物理
--------------------------------------------------------------
   ┌─────────────────────────────────────────────┐
   │ 一座山的"欲望"与"命运":                       │
   │                                             │
   │  ↑ 材料强度: 撑住不塌    (由键能决定)         │
   │  ↓ 自重: 往下压          (由行星g决定)        │
   │                                             │
   │  平衡: h_max ≈ σ_yield / (ρ g)               │
   └─────────────────────────────────────────────┘

2.2 等静压补偿 (Isostasy)
--------------------------------------------------------------
山脉不是直接压在基岩上——它"浮"在地幔上：

    h_max = σ_yield / (ρ_crust · g) · [ρ_mantle / (ρ_mantle − ρ_crust)]

    地球: ρ_crust≈2800, ρ_mantle≈3300 → 因子 ≈ 6.6
          即等静压使有效山高提高 ~6.6 倍。

2.3 实际山高 vs SCVC上限
--------------------------------------------------------------
  ⚫ 实测 (地球):      Everest 8.85 km, Mauna Kea ~10 km (从底)
  ⚫ 岩石强度 30 MPa:  h_max ≈ 7.2 km (地球), 19.0 km (火星)

     岩石实际强度 (~10-100 MPa) 受 Griffith 裂隙限制：
     σ_real = σ_theor / √(crack_size / atom_size)

     若裂隙尺度 ~1 mm → 强度衰减 ~3,000×
     → 从 15 GPa (完美晶体) 降到 ~5-50 MPa (实际岩石)

     SCVC 给出 σ_theor ≈ E_bond/d³ ≈ 465 GPa (bulk模量量级)
     理论屈服 ~ E/30 ≈ 16 GPa
     完美晶体山高 ≈ 3,700 km → 超出行星半径, 几何不可能
     → 实际极限 = min(强度极限, 行星半径)

2.5 SCVC统一山高公式
--------------------------------------------------------------
    h_max(M, σ) ≈ 6.6 · σ / (ρ_crust · G M / R(M)²)

    其中 R(M) ≈ R_⊕ · (M/M_⊕)^0.27

    全部由两个SCVC参数决定:
    · σ      → 键能 E_bond (α → 原子结构)
    · G, M, R → M_Pl (引力) + 核合成丰度 (α_s)


3. 最深海洋
==============================================================

3.1 水的高压相图 — SCVC解读
--------------------------------------------------------------
  ⚫ H₂O 的独特之处: 每个分子可形成4个氢键 (四面体)
     氢键能 (SCVC): ~0.2 eV/bond ≈ 3.2×10⁻²⁰ J
     分子体积: ~30 Å³ ≈ 3×10⁻²⁹ m³

     特征压力尺度: P_char = E_H-bond / V_mol ≈ 1.07 GPa

     → 当外部压力超过 ~1 GPa, 氢键网络被迫重组。
        这就是 Ice VI / Ice VII 相变的本源。

  压力 (GPa)    相态                H键状态           密度 (g/cm³)
  ──────────────────────────────────────────────────────────────
    0           液态水              完整网络, 动态      1.0
    0.2         Ice Ih              完整, 六方         0.92
    1.0         Ice VI              变形, 四方         1.31
    2.1         Ice VII             双嵌套冰骨架        1.50
    ~50-70      Ice X               质子对称化          2.5
    >100        超离子/等离子体      质子游离            3-5+

  ⚫ SCVC将相变压力统一到 E_bond/V_mol 量级:
    Ice VII (~2 GPa) = 2 × P_char → 氢键被压缩但未断。
    Ice X (~50-70 GPa) → 质子隧穿对称化 → 氢键变成半共价。
    超离子 (>100 GPa) → 热能 > 键能 → 氧晶格+质子液。

3.2 海洋深度极限
--------------------------------------------------------------
海底压力: P_bottom = ρ_water · g · h_ocean

  质 量        g          液态窗口        h_max(液体)
  (M_⊕)      (m/s²)      (GPa)           (km)
  ────────────────────────────────────────────────────
   0.3         5.6        0 – 2~10        180 – 1800
   0.5         7.1        0 – 2~10        150 – 1500
   1.0         9.8        0 – 2~10        100 – 1000
   2.0        13.5        0 – 2~10         80 –  740
   3.0        16.3        0 – 2~10         60 –  610
   5.0        20.6        0 – 2~10         50 –  490

  注：范围对应"冷海洋(Ice VI~1 GPa)"到"热海洋(Ice VII~10 GPa)"

  ⚫ 关键约束: 绝热温度梯度
    dT/dz ≈ α_T · g · T / C_p ≈ 0.14 K/km (地球)
    超级地球 (3 M_⊕): ~0.23 K/km

    深海 (200 km, 3 M_⊕): T_bottom ≈ 300 + 46 ≈ 346 K
    → Ice VII 熔融曲线在此温度约 12-15 GPa
    → P_bottom = 1000 × 16.3 × 2×10⁵ = 3.3 GPa < 12 GPa
    → 仍然是液态!

    真正的极限 (~600-1000 km) 由 Ice X / 超离子转变设定。

3.3 对系外行星海洋的预测
--------------------------------------------------------------
  ⚫ "水世界" (ocean worlds): 海洋深度可达数百公里。
      底层为高压冰 VII, 非液态 → 没有"海底"与岩石接触
      → 碳-硅酸盐循环断裂 → 不适合类地生命。

  ⚫ "宜居海洋": 需要液态水底部接触硅酸盐岩石。
      → 海洋深度 < Ice VI/VII 相变深度
      → 对地球: < ~100 km (冷) 或 < ~500 km (热)
      → 对超级地球 (2-5 M_⊕): < ~50-250 km

  ⚫ SCVC结论: 海洋深度是"行星有一个岩石海底"的
      物理前提。如果海洋太深, Ice VII 将水和岩石隔离,
      碳循环断裂, 宜居性丧失。氢键强度 (从α导出) 决定了
      这个临界深度。


4. 工程结论
==============================================================

4.1 板块构造的物理窗口
--------------------------------------------------------------
板块构造需要: 对流应力 (τ_conv) > 岩石圈屈服应力 (τ_yield)

    τ_conv ∝ α_T · ρ · g · ΔT · d_lith    (热膨胀 · 重力)
    τ_yield ≈ 10-100 MPa                   (键能 → 断裂强度)

    SCVC约束:
    · τ_yield 由 α 通过键能设定 (~10-100 MPa)
    · τ_conv  由 α (热膨胀, 介质性质) + M_Pl (重力) 设定

    质量窗口:
    太小 (< ~0.3 M_⊕):  τ_conv 不够 → 停滞盖层 (stagnant lid)
                        火星/金星可能在此边界
    适中 (0.5-2 M_⊕):   τ_conv ~ τ_yield → 板块构造可能
                        地球恰好在此窗口 (微妙!)
    太大 (> ~5 M_⊕):    高压抑制部分熔融 → 岩石圈过厚
                        虽然 τ_conv 大, 但缺乏软流层润滑

    ⚫ SCVC洞察: 地球的板块构造不是普适必然——
      它是 α 和 M_Pl 恰好落在允许窗口的结果。
      这对"地球独特性"提供了物理基础。

4.2 超级地球宜居性的SCVC约束
--------------------------------------------------------------
  特征              地球              超级地球 (3-5 M_⊕)
  ──────────────────────────────────────────────────────────
  山脉高度          ~10 km             ~3-5 km (更矮)
  海洋深度(液态)    ~100-500 km        ~50-250 km
  板块构造          可能 (在边界)      可能 (或过厚盖层)
  大气保留          好                 更好 (更少逃逸)
  地磁场            有                 可能性更高 (更大核)
  碳-硅循环          有                 若板块构造+浅海则有

  ⚫ SCVC判据: 宜居超级地球需要同时满足三个条件:
    (1) 板块构造活跃 (质量不太大也不太小)
    (2) 海洋深度 < 高压冰临界深度 (水-岩接触)
    (3) 大气层不过厚 (未成为气态巨行星)

    这三个条件把宜居质量限制在 ~0.5-3 M_⊕。
