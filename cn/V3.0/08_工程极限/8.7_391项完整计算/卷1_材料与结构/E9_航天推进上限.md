--------------------------------------------------------------------
§1. 化学火箭比冲上限
--------------------------------------------------------------------

【基本原理】
  I_sp = v_ex / g₀，v_ex = √(2·ΔH/m_propellant)
  ΔH从SCVC键能正向推导（C-C 3.6, C=C 6.3, C≡C 8.7, N≡N 9.8 eV）

【实际燃料的SCVC约束】

  推进剂组合           能量密度(MJ/kg)  理想I_sp(s)  实际I_sp(s)  瓶颈
  ──────────────────────────────────────────────────────────────────
  H₂ + O₂ (LOX/LH2)      13.4           528          ~452         H₂O解离@3500K
  H₂ + F₂                13.6           531          ~410-450     毒性, HF腐蚀
  RP-1 + O₂ (煤油)        5.2           330          ~350         分子量大
  Li + F₂ + H₂ (三组元)   ~20            ~640         无法实用     Li-F激渣
  Be + O₂                 23.9           700          工程不可行    BeO毒性

  ▸ H₂/O₂ 理想 I_sp = 528 s — 已接近化学火箭的工程天花板
  ▸ 当前最佳（SSME/RS-25真空）452 s → 距理想极限仅 ~15% 差距
  ▸ H₂/F₂ 和 Be/O₂ 理论更高，但毒性/腐蚀/成本使其实质上不可行

【SCVC键能极限 → 化学推进的物理天花板】

  原子H重组：H + H → H₂
    H-H键能 = 4.52 eV（从SCVC的Ry=13.606 eV和分子轨道推导）
    能量密度 = 218 MJ/kg（纯H原子质量）
    理想 I_sp = 2,128 s
    ▸ 但原子H无法储存（瞬间复合为H₂）→ 理论值，工程不可达

  SCVC最强键 N≡N 重组：N + N → N₂
    N≡N = 9.8 eV，但N原子重(14 amu) → 能量密度仅 33.8 MJ/kg
    理想 I_sp = 838 s — 高于H₂/O₂，但不如原子H

  **化学火箭绝对物理上限：I_sp ≈ 500-550 s（可储存推进剂）**
  **理论极限（不可储存）：I_sp ≈ 2,100 s（原子H，纯理论）**
  **工程现实：化学火箭送人去火星已足够（I_sp 450s → 质量比~4，可行）**

§2. 核热推进（NTR）
--------------------------------------------------------------------

【原理】
  裂变加热 H₂ → 高温排气。能量来自核而非化学键。
  SCVC：²³⁵U裂变 = 200 MeV/核 ≈ 化学反应的 ~2×10⁷ 倍能量
  → 能量无限充裕，温度被材料熔点锁死

【I_sp vs 堆芯温度（H₂工质，γ=1.4）】

  堆芯温度(K)   v_ex(m/s)   I_sp(s)   实现方式
  ─────────────────────────────────────────────
  3,000          9,343        952      石墨/HfC固体堆芯（当前技术）
  4,000         10,789      1,100      TaHfC陶瓷（材料理论极限）
  5,000         12,062      1,230      主动冷却固体堆芯
  6,000         13,213      1,347      气芯反应堆（远超固体材料）

  ▸ 核热 I_sp ≈ 950-1,100 s → 化学火箭的 ~2×
  ▸ 质量比优势：火星任务 Δv=6 km/s → NTR质量比 1.9 vs 化学的 3.8
  ▸ SCVC 力常数 k~10³ N/m → 固体材料熔点约 4000-4500 K 为硬天花板
  ▸ 气芯堆可突破固体熔点，但核燃料滞留问题尚未解决

【SCVC判定】
  NTR 的能量来自核分裂（200 MeV），远超化学键（~eV），
  但 SCVC 锁死的原子间力常数（k~10³ N/m）限定了固体材料可承受的温度。
  → 核热推进的 I_sp 上限由材料物理决定，非核物理。

§3. 聚变推进 / 电推进
--------------------------------------------------------------------

【3.1 聚变直接排气】

  D-T 聚变：D + T → α (3.5 MeV) + n (14.1 MeV)
    α粒子直接磁喷嘴排出：
      v_α = 13,000 km/s = 4.3% c
      I_sp = 1.32×10⁶ s（132万秒）
  
  D-³He 聚变：D + ³He → p (14.7 MeV) + α (3.7 MeV) — 全带电产物
    质子直接排出：
      v_p = 53,300 km/s = 17.8% c
      I_sp = 5.4×10⁶ s（540万秒）
    ▸ 全部产物带电 → 无需热转换 → 直接推力 → 极高效率

【3.2 电推进】

  I_sp = √(2η·P_spec·t_burn) / g₀（由电源比功率决定）
  
  比功率 P_spec(W/kg)  I_sp=3000s  I_sp=5000s  I_sp=10000s  I_sp=20000s
  ─────────────────────────────────────────────────────────────
  太阳能 50          0.24 mm/s²  0.14        0.07        0.04
  太阳能 200         0.97        0.58        0.29        0.15
  核电源 50          0.24        0.14        0.07        0.04
  远期太阳能 1000    4.85        2.91        1.45        0.73
  
  ▸ 高 I_sp → 低推力（功率一定时） → 长加速时间
  ▸ 太阳能电推进 I_sp 3,000-5,000 s 是当前最佳平衡点
  ▸ SCVC限制：光伏效率（E3推得~30%）→ 太阳能比功率最终上限 ~300-500 W/kg

§4. 工程结论
--------------------------------------------------------------------

【推进方式分层】

  层级   推进方式              I_sp范围      适用任务
  ────────────────────────────────────────────────────
  L1    化学火箭              300-530 s      LEO入轨、月球、火星货运
  L2    核热推进(NTR)         900-1,200 s    火星载人、外行星探测
  L3    太阳能电推进          2,000-5,000 s  小行星任务、深空货运
  L4    核电推进(NEP)         5,000-10,000 s 外太阳系、柯伊伯带
  L5    聚变推进              10⁵-10⁶ s      火星快速往返、星际前哨
  L6    聚变(D-³He)/反物质    10⁶-10⁷ s      近邻恒星任务

【关键判定】

  ▸ "化学火箭送人去火星" → 绰绰有余，已在极限的 ~85%。NASA Artemis/SpaceX Starship 用化学推进即可
  ▸ "火星1年往返" → 必须核热或电推进。化学只能做合窗口(~2.5年往返)
  ▸ "外行星载人" → 必须核推进。化学无法在合理时间内到达木星/土星
  ▸ "近邻恒星 10光年" → 必须聚变或更高级推进。SCVC物理允许，工程远超当前
  ▸ "化学火箭的 I_sp > 1000s" → SCVC禁止（键能天花板）
  ▸ "化学火箭的 I_sp > 500s 实用性" → 几乎触顶，不值得大量投资

【SCVC硬约束总结】

  约束来源              限制内容                          数值
  ───────────────────────────────────────────────────────────────
  化学键能                化学火箭 I_sp 天花板              ~530 s (工程)
  原子间力常数 k          固体材料耐温 → NTR 堆芯温度        ~4,500 K
  核结合能                核反应能量密度                    200 MeV/裂变
  D-T聚变 17.6 MeV        聚变排气速度                      4.3% c
  光伏效率 ~30%           太阳能比功率上限                   ~500 W/kg
  Tsiolkovsky方程         任何推进的 dv/v_ex                ln(m₀/m_f)
