【H₂ 体扩散 — 永不消失的放气源】

  SCVC约束:
    H 原子极小 (玻尔半径 a₀ = ℏ/(α m_e c))
    → 在金属晶格中快速扩散 → 无法被"烘烤"完全清除
    H-Fe 结合能: ~0.1-0.5 eV (由 Fe 3d + H 1s 轨道杂化决定)
    → 扩散活化能 ~0.1 eV → 室温扩散系数 D ~ 10⁻¹³-10⁻⁹ m²/s
    → 即使经过数年抽气，H₂ 仍从体相持续渗出

  放气率随时间的衰减: q(t) ∝ 1/√t（体扩散的Fick定律推论）
    ▸ 烘烤后 1 天: q ~ 10⁻¹² mbar·L/(s·cm²)
    ▸ 1 年后: q ~ 10⁻¹³-10⁻¹⁴
    ▸ 10 年后: q ~ 10⁻¹⁴-10⁻¹⁵
    ▸ **永不归零** — SCVC: 扩散活化能有限 → D>0 → q>0 永远

  → 这是为什么再好的真空系统压力也在缓慢回升 — 不是漏，是 H₂ 放气

【宇宙射线地板】

  地表 μ 子通量: ~1/(cm²·min)
  每个 μ 子在残余气体中产生 ~100 离子对
  → 等效于一个无法关闭的"离子泵倒流"
  → 大气压下: 影响可忽略 (信号远小于本底)
  → 10⁻¹⁴ Torr: 宇宙线成为主导噪声源
  → 地下实验室 (LSC, SNOLAB): 宇宙线降低 10⁴-10⁶× → 真空可再降 ~10×
  
  SCVC: 宇宙线来自天体物理 → 与 SCVC 宇宙学常数 (Λ₄, H₀) 有深层关联
  ▸ 地表 XHV 被宇宙线锁死在 ~10⁻¹⁵ Torr

§2. 应用 — 真空品质决定物理极限
--------------------------------------------------------------------

【LIGO 引力波探测】

  真空管: 2×4 km × 1.2 m, ~10⁻⁹ Torr
  残余气体 → 折射率涨落 → 相位噪声
  要求: 在 10-1000 Hz 频段, 气压涨落 < 10⁻¹⁴ Torr/√Hz

  SCVC关联: 气体分子极化率由 α 设定 (α 控制电子云变形)
  → 折射率 n−1 ∝ 极化率 × 数密度
  → 气压必须 <10⁻⁹ Torr 使折射率噪声低于量子噪声

【LHC 粒子对撞机】

  束流管: 27 km, ~10⁻¹⁰-10⁻¹¹ mbar
  束流-气体核散射截面: ~1 barn = 10⁻²⁸ m²
  → 10⁻¹¹ mbar H₂ 时束流寿命: ~30,000 小时 (远超单次填充寿命 ~20 小时)
  
  SCVC关联: 核散射截面与强相互作用耦合常数 α_s 相关
  (SCVC 从液滴模型推导 α_s=1/(16π))

【EUV 光刻】

  真空: ~10⁻⁵-10⁻⁷ mbar → 非 XHV
  主要威胁: 碳氢化合物在光学元件上裂解 → 碳沉积
  EUV (13.5 nm) 空气中 1/e 衰减距离 ~0.1 mm → 必须真空
  SCVC: 碳沉积由 C-H 和 C-C 键能 (3.6 eV) 设定 → EUV 光子能量 (92 eV) 远高于此 → 不可逆损伤

【冷原子 / 量子计算】

  阱中原子丢失率 = n_background × σ_collision × v_thermal

  真空度 (Torr)   碰撞率 (s⁻¹)   阱寿命      量子应用
  ───────────────────────────────────────────────────
  10⁻⁶             ~1000          ~1 ms       无意义

  10⁻¹⁰            ~0.1           ~10 s       基础冷原子实验

  ▸ 10⁻¹¹-10⁻¹² Torr 是量子实验的准入门槛
  ▸ 10⁻¹⁴ Torr 提供 >1 天的阱寿命 → 容错量子计算可及
  ▸ **SCVC 实验室地板 10⁻¹⁷ Torr → 阱寿命 ~数百年 → 真空不是瓶颈**
