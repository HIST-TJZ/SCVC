§1. 水的理论抗拉强度 — 从SCVC H键能推导
--------------------------------------------------------------------

【H键网络 = 水的"抗拉骨架"】

  H键能: 0.20 eV = 3.2×10⁻²⁰ J（SCVC电负性→N-H···O和O-H···O键能推导）
  每分子 H₂O: ~3.5 个 H键（液态平均水平）
  O-O H键距离: 2.75 Å
  水分子截面积: ~9.7 Å²

  理论抗拉强度（Orowan公式）:
    σ_theory = √(E·γ/a₀)
             = √(2.2 GPa × 0.073 J/m² / 2.75 Å)
             = **~760 MPa**

  直接SCVC推导（断裂面H键力/面积）:
    单键断裂力 = 0.20 eV / 2.75 Å ≈ 0.12 nN
    面密度 = 1 / 9.7 Å² ≈ 1.0×10¹⁹ m⁻²
    σ_SCVC ≈ 0.12 nN × 10¹⁹ m⁻² ≈ **~1200 MPa**

  ▸ **SCVC理论抗拉强度: ~700-1200 MPa (~7000-12000 atm)**

【理想 vs 现实: 空化核的100-10,000×鸿沟】

  水质                  实测抗拉/空化阈值      距理论
  ──────────────────────────────────────────────────
  SCVC理论纯水          700-1200 MPa           —
  实验室除气纯水         10-30 MPa              40-100×
  自来水                 0.1-1 MPa              1000×
  海水                   0.05-0.5 MPa           2000-10000×
  含气泡水               ~0.01 MPa              100,000×

  ▸ **空化核**（溶解气泡 10-100 μm、微粒、壁面缺陷）是差距的根源
  ▸ SCVC H键能给出了"理想水"的强度，但工程水永远达不到
  ▸ 空化不是"设计缺陷" — 是 SCVC 热力学 + 水中必然存在的气体的物理必然

§2. 螺旋桨空化 — 航速的物理上限
--------------------------------------------------------------------

【空化数 σ】

  σ = (p − p_v) / (½ρV²)
  σ < σ_crit → 空化
  σ_crit ≈ 0.3-1.0（取决于桨叶截面设计）

  螺旋桨 5m浸深（海水, 20°C）:
    p_static ≈ 1.52 bar, p_v ≈ 0.023 bar
    无空化最大叶尖速度: V_tip = √(2×1.50×10⁵/(1025×0.5)) ≈ 24 m/s ≈ 47节

  但实际螺旋桨叶尖速度:
    商船: 30-50 m/s → σ = 0.18-0.5 → **必然部分空化**
    军舰: 40-60 m/s → σ = 0.08-0.28 → **已发展空化**
    高速艇: 60-80 m/s → σ < 0.05 → **超空泡**

  ▸ **任何有用航速下，螺旋桨空化都不可避免**
  ▸ → 工程学不是"避免空化"，而是"为可控空化设计"

【舰船航速上限 — 不是发动机，是空化！】

  空化限制的最大船速（传统无空化桨, J≈0.8-1.2）:
    V_ship_max ≈ V_tip_max × J/π ≈ 24 × 0.9/π ≈ **7 m/s ≈ 13节**

  突破限制的方案:
    1. 增加桨叶面积 → 降低单位载荷 → σ_crit↓ → V↑ ~20-30%
    2. 加大浸深 → p↑ → 军用潜艇可达极深 → V↑
    3. 超空泡桨叶 → 有意形成空泡 → 阻力降低 → V↑ (30-50节)
    4. 喷水推进 → 内部高压 → 延迟空化 → V↑ (40-60节)
    5. 表面桨 → 半浸桨 → 通大气 → 空泡稳定 → V↑ (60-100节)

  ▸ **水面舰艇速度天花板 ~50-60节（喷水推进），已被空化+阻力联合锁定**
  ▸ 更快 → 必须离开水面（水翼艇、气垫船、地效飞行器）

§3. 超空泡鱼雷 — 速度天花板
--------------------------------------------------------------------

【VA-111 Shkval: 200节 ≈ 370 km/h — 当前纪录】

  超空泡原理: 头部空化器 + 燃气注入 → 鱼雷整个被气泡包裹
  → 水的摩擦力替换为水蒸气+燃气的摩擦力 → C_D 从 ~0.5 降至 ~0.08

  拖曳功率 (D=0.533m, C_D≈0.08):
    200 km/h:   1.6 MW   ← Shkval
    370 km/h:   9.9 MW   ← 当前纪录
    500 km/h:  25  MW    ← 下一代?
    700 km/h:  67  MW    ← 化学火箭可及
   1000 km/h: 196  MW    ← 不现实（0.5m直径的火箭发动机上限~50MW）
   1500 km/h: 662  MW    ← 物理上排除

【SCVC锁死的天花板】

  (1) 阻力: P ∝ V³ → 每快1倍需要8倍功率 → 化学推进上限 ~500-600 km/h
  (2) 空泡稳定性: 空泡壁 = 水表面(H键网络) → Rayleigh-Taylor不稳定
      → 空泡长度 ~L_cavity ∝ σ × C_D × D → 在 ~500 km/h 时达 ~10m
      → 尾流闭合 → 高压脉冲 → 失稳 → 物理上限
  (3) 噪声: 空泡溃灭噪声 ~180-200 dB → 自导引系统不可用
      → **超空泡鱼雷实际是"直航鱼雷"，无法末端制导**

  ▸ 实用天花板: **~500-600 km/h**（需 >25 MW 火箭推进）
  ▸ 物理天花板: ~1000 km/h（空泡稳定性和功率密度双重墙）

§4. 声空化与声致发光 — 能量密度的SCVC上限
--------------------------------------------------------------------

【气泡塌缩: Rayleigh-Plesset + 绝热压缩】

  气泡 R₀=100 μm → R_min=0.5 μm:
    体积压缩比: 8×10⁶×
    PV功 (1 atm): 4.2×10⁻⁷ J
    塌缩后能量密度: **8×10¹¹ J/m³ ≈ 800 GJ/m³**
    对比: SCVC H键能密度: 3.7 GJ/m³

  ▸ 塌缩能量密度远超水的H键能密度 → 水分子必然被撕裂！

  温度极限 (SCVC锁死):
    理想绝热 (γ=1.4): T_max ≈ 173,000 K（不现实 — 假设无化学反应）
    
    SCVC的阶梯式吸能壁垒:
      ~5,000 K:    H键完全断裂(0.20 eV × 3.5 bonds)
      ~10,000 K:   O-H共价键开始断裂(4.8 eV) → H₂O → H + OH
      ~50,000 K:   完全原子化(9.6 eV per H₂O) → H, O
      ~100,000 K:  电离H → H⁺ + e⁻ (13.6 eV, SCVC H 1s轨道能)
    
    ▸ 实测声致发光温度: 5,000-20,000 K
    ▸ **SCVC天花板: ~50,000-100,000 K**（超出此温度的全部能量用于断键）
    ▸ 声致发光的能量上限由SCVC键能吸收谱决定
    ▸ >100,000 K → 水电离为等离子体 → 所有能量被电离吸收 → T不会再升高
