1. 物理链 — 自修复的三步时序
==============================================================

1.1 运输 — 毛细流动 (Lucas-Washburn)
--------------------------------------------------------------
    裂纹 = 天然毛细管。修复液在表面张力驱动下吸入:

    L² = (γ cosθ / 2η) · r · t

    其中 r = 裂纹有效半径 (~宽度/2), L = 渗透深度。

    裂纹宽度 (μm)    渗透 100 μm 时间    渗透 1 mm 时间
    ─────────────────────────────────────────────────
         1             0.7 ms              67 ms
        10             0.07 ms              7 ms
       100             7 μs                 0.7 ms
    ─────────────────────────────────────────────────

    ⚫ 毛细流动极快 — μm 裂纹在亚 ms 填满!
    ⚫ SCVC: γ 和 η 由分子间力 (α) 设定 → 若 α 不同, 流速不同。

1.2 混合 — 单体-催化剂扩散接触
--------------------------------------------------------------
    单体到达裂纹后, 必须扩散到催化剂表面才能聚合。

    催化剂间距 (μm)    扩散混合时间
    ─────────────────────────────────
          1              2.5 ms
          5              62 ms
         10              0.25 s
         50              6.3 s
        100              25 s
    ─────────────────────────────────

    ⚫ 这是微胶囊系统的真正瓶颈!
    ⚫ 催化剂间距 ~10-50 μm → 混合 ~0.25-6 s
    ⚫ SCVC: D = k_B T/(6πηr) → 由 η (α) 和温度设定。

1.3 反应 — 聚合速率
--------------------------------------------------------------
    聚合活化能 ΔG‡ ≈ 0.2-0.5 eV (取决于化学体系):

    ΔG‡ (eV)     k (s⁻¹, 单分子)     t_poly
    ─────────────────────────────────────────
      0.2         2.8×10⁹             0.4 ns
      0.3         5.8×10⁷             17 ns
      0.4         1.2×10⁶             0.8 μs
      0.5         2.6×10⁴             38 μs
    ─────────────────────────────────────────

    双分子 (扩散限制): k ~ 10⁹ M⁻¹s⁻¹
    [催化剂] ~ 0.01 M → t_poly ~ 10⁻⁷ s (!!!)

    ⚫ 聚合反应本身极快 (ns-μs 理论, ~s 实际)。
    ⚫ 不是瓶颈 → 瓶颈在运输+混合。
    ⚫ SCVC: Arrhenius 指前因子 k_B T/h = 6.3 THz (E33)。


2. 微胶囊 vs 血管网络 — 谁更快？
==============================================================

2.1 微胶囊系统
--------------------------------------------------------------
    时序:
    裂纹扩展 → 胶囊破裂            (~μs, 机械)
    单体毛细吸入裂纹               (~ms, §1.1)
    单体扩散至催化剂                (~s, §1.2 — 瓶颈!)
    聚合反应                        (~s-min, §1.3)
    ─────────────────────────────────────────────────
    总愈合时间: ~秒-分钟 (μm-mm 裂纹)

    实测: White et al. (2001) → ~10 min 恢复 ~75% 强度
    → 离 SCVC 极限 (~1-10 s) 还有 ~10-100× 的工程提升空间。

2.2 血管网络系统
--------------------------------------------------------------
    修复液通过内置管道泵送 (模仿血液循环):

    Poiseuille: Q = πR⁴ΔP/(8ηL)

    管道 R=100 μm, ΔP=1 atm, L=1 mm:
    Q ≈ 4×10⁻⁶ m³/s → 填充 1 mm³ 裂纹仅需 ~0.25 ms!

    ⚫ 血管系统取消了扩散混合瓶颈 —
      修复液被直接泵送到裂纹每一处 → 秒级愈合 mm 裂纹可能!
    ⚫ 代价: 复杂的管道制造 + 持续的修复液供应。

2.3 与生物自修复的对比 — 为什么材料更快？
--------------------------------------------------------------
    ┌────────────────────────────────────────────────────────┐
    │ 生物自修复 (E145):                                        │
    │ · DNA 复制 ~8 h (基因组蓝图的硬墙)                         │
    │ · 细胞迁移 ~1 mm/天 (肌动蛋白+黏着斑周转)                  │
    │ · 蛋白质合成 ~100 s/链 (核糖体速度)                        │
    │ · 总愈合: 天-周 (皮肤), 周-月 (骨骼)                       │
    │                                                         │
    │ 材料自修复 (E150):                                        │
    │ · 无 DNA → 无细胞分裂瓶颈                                 │
    │ · 无蛋白质合成 → 化学聚合直接形成高分子                    │
    │ · 运输 = 毛细/泵送 (物理) 非细胞迁移 (生物)                │
    │ · 总愈合: 秒-分钟 (μm-mm 裂纹)                            │
    │                                                         │
    │ ⚫ 材料比生物快 10³-10⁶× 的根本原因:                       │
    │   不需要"制造新细胞" → 跳过了 DNA→RNA→蛋白质→分裂         │
    │   这条生物信息处理的漫长流水线。                           │
    │   化学自修复 = 预先储存的修复剂 + 物理运输 + 化学反应。    │
    └────────────────────────────────────────────────────────┘


3. 秒修复 — 物理是否允许？
==============================================================

3.1 可行场景
--------------------------------------------------------------
    ⚫ YES — 秒修复在物理上完全可能!

    条件:
    · 裂纹 < 100 μm (毛细流 ~ms)
    · 修复剂+催化剂已经预混或在超短扩散距离内
      → 或使用血管网络绕过扩散瓶颈
    · 快速聚合化学 (ROMP, 丙烯酸酯, 硫醇-烯)
      → ΔG‡ ≈ 0.2-0.3 eV → k ~ 10⁸-10⁹ s⁻¹

    理想系统的愈合时间:
    ┌────────────────────────────────────────────────────┐
    │ 裂纹尺度      微胶囊系统        血管网络系统          │
    ├────────────────────────────────────────────────────┤
    │ 1 μm          < 1 s            < 1 s               │
    │ 10 μm         ~1 s             < 1 s               │
    │ 100 μm        ~10 s            ~1 s                │
    │ 1 mm          ~数分钟            ~1-10 s             │
    │ 1 cm          不可能 (耗光修复剂)  ~10-100 s          │
    └────────────────────────────────────────────────────┘

3.2 SCVC 硬墙
--------------------------------------------------------------
    即使是材料自修复, 仍有不可绕过的物理墙:

    墙 1: 扩散时间 ∝ L²/D
    → 大裂纹必然慢。唯一出路: 泵送 (血管网络)。

    墙 2: 毛细驱动力的上限
    → γ 和 η 是材料固有的 (α 设定)。
    不能无限降低 η → 液体会挥发或失去结构。

    墙 3: 修复剂的有限供应
    → 微胶囊只能释放一次; 血管网络的储罐有限。
    裂纹太大 → 修复液耗尽 → 无法愈合。

    墙 4: 聚合收缩 + 界面结合
    → 聚合物体积收缩 (~5-15%) → 裂纹界面可能重新张开。
    → SCVC: 共价键形成 → 原子间距从范德华 (~3-4 Å) 变为共价 (~1.5 Å)
    → 收缩是化学键的本质, 不可避免。
    → 工程缓解: 添加膨胀剂、纳米填料。

3.3 自修复材料的 SCVC 天花板
--------------------------------------------------------------
    过程              当前最快            SCVC 天花板         差距
    ──────────────────────────────────────────────────────────────
    毛细填充 (100μm)    ~1-10 ms           ~0.7 ms              ~10×
    扩散混合 (10μm)     ~0.1-1 s           ~0.25 s              ~4×
    聚合反应            ~s-min             ~ms (快速化学)        ~10²-10³×
    总愈合 (100μm裂纹)  ~10 min             ~1-10 s              ~60-600×
    ──────────────────────────────────────────────────────────────

    ⚫ 当前自修复材料离 SCVC 极限还有 ~10-100× 的工程空间。
    ⚫ 主要差距在: 催化剂分布优化 (缩小扩散距离) +
      更快的聚合化学 (更低 ΔG‡)。
    ⚫ "秒修复"对 < 100 μm 裂纹是物理可达的工程目标!
