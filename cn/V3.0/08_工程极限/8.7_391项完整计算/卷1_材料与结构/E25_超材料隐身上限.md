# SCVC工程极限：超材料/隐身 — 负折射+隐身斗篷的带宽上限

> 所有推导基于SCVC速查表的常数（从π多项式导出，零自由参数）。
> E14已证明完美透镜和全光开关被α禁止。本计算聚焦隐身斗篷和负折射带宽。

---

## §1. 隐身斗篷的带宽极限

### 1.1 变换光学的基本要求

理想圆柱斗篷（二维，内径a，外径b）需要的材料参数：

```
r → a⁺ (内边界):
  ε_z → 0      ← 需要介电常数趋于零
  μ_r → 0      ← 需要磁导率趋于零
  μ_θ → ∞      ← 需要磁导率发散到无穷

r → b⁻ (外边界):
  ε_z → 1, μ_r → b/(b-a), μ_θ → (b-a)/b
```

**关键：内边界需要极端的材料参数（0和∞）**。这种极端值只能通过共振实现——而共振本质上是窄带的。

### 1.2 Kramers-Kronig对隐身带宽的约束

Kramers-Kronig关系将介电函数的实部和虚部绑在一起：

```
Re[ε(ω)] - 1 = (2/π) P ∫₀^∞ ω' Im[ε(ω')] / (ω'² - ω²) dω'
```

任何无源介质必须满足 Im[ε(ω)] ≥ 0 对所有ω。

**f-sum规则**为KK关系提供了全局约束：

```
∫₀^∞ ω Im[ε(ω)] dω = (π/2) ω_p²
```

这意味着"损耗预算"是固定的。要在某频段实现强色散（隐身所需），必须有损耗——要么在这个频段（降低性能），要么在其他频段（但f-sum规则限制了你能把损耗推多远）。

**隐身带宽的SCVC量化：**

对于需要介电常数变化Δε的斗篷，带宽受限于：

```
Δω/ω₀ ≈ (ω_p²/ω₀²) / (Δε × Q)

ω_p: 金属等离子体频率（由电子密度n决定，SCVC: n ≤ 10²³ cm⁻³）
ω₀: 工作频率
Q: 共振品质因数（由损耗决定）
```

各频段的KK带宽上限：

| 频段 | ω₀ (eV) | ω_p(Ag) (eV) | Δε=1 (温和) | Δε=10 (extreme) |
|------|---------|-------------|------------|-----------------|
| 可见光 (500 nm) | 2.5 | 9.0 | **~9%** | **~0.9%** |
| 近红外 (1 μm) | 1.2 | 9.0 | ~18% | ~1.8% |
| 太赫兹 | 0.01 | 9.0 | — | — |
| 微波 | 10⁻⁴-10⁻⁵ | 9.0 | — | — |

> 注：微波/THz频段，ω_p²/ω₀² >> 1，KK带宽约束不再为主要限制。此时带宽由谐振器Q值和制造公差决定。

### 1.3 共振Q值决定实际带宽

任何超材料"原子"（SRR、纳米棒等）的共振带宽为：

```
Δω/ω₀ = 1/Q_loaded

1/Q_loaded = 1/Q_ohmic + 1/Q_radiation + 1/Q_dielectric
```

**各频段的典型Q值和带宽：**

| 频段 | 特征尺寸 | 欧姆Q | 辐射Q | 加载Q | 单共振带宽 |
|------|---------|-------|-------|-------|-----------|
| **微波 (10 GHz)** | 1-10 mm | 500-5000 | 100-1000 | 80-500 | **0.2-1.2%** |
| **毫米波 (100 GHz)** | 100-500 μm | 100-500 | 50-200 | 30-100 | **1-3%** |
| **太赫兹 (1 THz)** | 10-100 μm | 20-100 | 10-50 | 7-30 | **3-15%** |
| **红外 (30 THz)** | 1-5 μm | 10-30 | 5-15 | 3-10 | **10-30%** |
| **可见光 (600 THz)** | 20-50 nm | 5-15 | 3-8 | 2-5 | **20-50%** |

> ⚠️ 上表是**单个SRR/纳米天线的共振带宽**，不是隐身斗篷的带宽！斗篷需要空间渐变的参数分布，带宽远窄。

### 1.4 SCVC损耗来源

金属中的欧姆损耗来自三个SCVC可量化的机制：

**（a）电子-声子散射（室温主导）：**

```
γ_e-ph ∝ λ × (k_B T/ℏ)

λ = 0.5-2 (SCVC速查表)
在300 K: γ_e-ph ≈ 0.02-0.04 eV（对贵金属）
```

**（b）表面散射（纳米结构主导）：**

```
γ_surf = A × v_F / d

A: 几何因子 ∼0.5-1（取决于表面粗糙度）
v_F: Fermi速度 ≈ 1.4×10⁶ m/s (Ag)
d: 特征尺寸
```

| 特征尺寸 d | γ_surf (eV) | 主导？ |
|-----------|------------|--------|
| 1 nm | 0.46 | 🔴 极大（不实用） |
| 5 nm | 0.09 | 🟡 已超过体损耗 |
| 10 nm | 0.046 | 🟡 与体损耗相当 |
| 20 nm | 0.023 | 🟢 尚可接受 |
| 50 nm | 0.009 | 🟢 体损耗主导 |
| 100 nm | 0.005 | 🟢 可忽略 |

**（c）电子-电子散射（T=0极限）：**

即使在绝对零度，Landau阻尼提供不可消除的损耗下限。对贵金属在可见光频段，T=0时总损耗可达 ~0.03-0.10 eV（由表面散射+残余e-e散射），对应极限 Q ∼ 25-80。

**SCVC锁定：γ_min > 0 永远成立。** 电-声耦合λ > 0 意味着即使理想晶体在T=0也有零點运动导致的散射。

## §2. 负折射率材料带宽

### 2.1 双负材料的频率窗口

负折射（n < 0）需要 ε < 0 和 μ < 0 同时成立：

```
ε < 0:  Drude金属在 ω < ω_p 时自然满足（宽带）
μ < 0:  磁共振附近 ω₀ < ω < ω₀√(1+F)（窄带）
──────────────────────────────────────────
n < 0:  两者的重叠区域
```

**等离子体频率约束（ε < 0的带宽）：**

```
ω_p² = ne²/(ε₀ m_e)

Ag:  n = 5.86×10²⁸ m⁻³, ω_p = 9.0 eV, λ_p = 138 nm
最大: n = 3×10²⁹ m⁻³, ω_p = 20.3 eV, λ_p = 61 nm

结论: ω_p >> ω_visible → ε < 0 不是可见光/IR的瓶颈
```

对于超材料等效等离子体频率（稀释金属线阵列）：
```
ω_p_eff² = (2πc²/a²) / ln(a/r)

a: 线间距, r: 线半径
取 a/r = 5, a = 100 nm: ω_p_eff ≈ 2πc/a × 1/√ln(a/r) ≈ 1.5 eV (近红外)
取 a/r = 2, a = 20 nm: ω_p_eff ≈ 8 eV (可见光)
```

### 2.2 磁共振带宽（μ < 0的带宽）

SRR磁响应近似为Lorentz型：

```
μ(ω) = 1 + F ω²/(ω₀² - ω² - iγ_m ω)

μ < 0 区间: ω₀ < ω < ω₀√(1+F)
分数带宽: √(1+F) - 1
```

振荡器强度F取决于SRR几何：

```
F ∝ (SRR面积 / 单元面积) × (线圈匝数)² / (LC共振)

微波SRR: F ∼ 1-5   → 分数带宽 41-145%（但受ε<0区间约束）
THz SRR:  F ∼ 0.5-1 → 分数带宽 22-41%
光学SRR:  F ∼ 0.1-0.3 → 分数带宽 5-14%
```

**SCVC约束：** 最小SRR尺寸受限于原子间距（~1 Å），但实际受限于制造能力（~10-20 nm）。在光学频段，SRR需要30-50 nm才能容纳足够的线圈匝数，此时F ∼ 0.1-0.2。

### 2.3 各频段负折射带宽总结

| 频段 | μ<0 带宽 | ε<0 上限 | 重叠带宽 | 实用BW |
|------|---------|---------|---------|--------|
| 微波 (10 GHz) | **~145%** (F=5) | >THz | ~145% | **20-50%** ✓ |
| 太赫兹 (1 THz) | **~41%** (F=1) | 9 eV | ~41% | **10-30%** ✓ |
| 近红外 (1 μm) | **~14%** (F=0.3) | 9 eV | ~14% | **5-10%** |
| 可见光 (500 nm) | **~10%** (F=0.2) | 9 eV | ~10% | **3-5%** ⚠️ |

> 实用BW考虑了制造公差（±10%几何→±20%共振频率）和相邻共振串扰。

### 2.4 能否覆盖整个可见光范围？

**不能。** 可见光范围（400-700 nm, 1.77-3.10 eV）的分数带宽为：

```
BW_visible_full = (3.10 - 1.77) / ((3.10+1.77)/2) ≈ 55%
```

单个磁共振在可见光能覆盖的最宽区间为 ~10%（F=0.2），远不够55%。

**可能的多共振方案：** 使用多个交错的SRR共振覆盖可见光——类似多结光伏的策略。但这面临：
- 共振之间的干涉和阻抗失配
- 每个共振都有损耗，叠加后总损耗相应增加
- 不同共振对应不同空间位置的"超原子"→空间均匀性丧失

**SCVC判据：** 可见光全波段的均匀负折射被SCVC锁定的α、λ和n禁止。**最乐观可见光负折射带宽：~15-20%**（约100 nm范围，例如500-600 nm）。

## §3. 损耗极限

### 3.1 负折射品质因数（FOM）

```
FOM = |Re(n)| / Im(n)

物理意义：传播距离（以波长为单位）中振幅衰减到1/e的距离
d_1/e = (λ/2π) × FOM
```

**SCVC约束的各频段极限FOM：**

| 频段 | 体损耗(eV) | 表面损耗(eV)* | 总损耗(eV) | 极限FOM |
|------|-----------|--------------|-----------|---------|
| 可见光 (2.5 eV, 50nm) | 0.02 | 0.009 | 0.029 | **86** |
| 可见光 (2.5 eV, 20nm) | 0.02 | 0.023 | 0.043 | **58** |
| 近红外 (1.2 eV, 50nm) | 0.02 | 0.009 | 0.029 | **41** |
| 太赫兹 (0.01 eV, 1μm) | 0.02 | 0.0005 | 0.020 | **0.5** |
| 微波 (10⁻⁴ eV, 10μm) | ~0.001 | ~0 | ~0.001 | **~0.1** |

> \* 表面损耗随特征尺寸增大迅速降低。微波频段结构尺寸大（mm级），表面损耗可忽略。

> 注：对微波/THz，Drude阻尼模型不完全适用（趋肤效应、反常趋肤效应）。实际微波SRR的Q ∼ 50-500，由欧姆损耗+辐射损耗+介电损耗共同决定。

### 3.2 超材料FOM的实际天花板

实验室已实现的FOM：

| 频段 | 已实现FOM | SCVC极限FOM | 差距 |
|------|----------|------------|------|
| 微波 NIM | ~20-50 | ~100-500 | 2-10× |
| THz NIM | ~5-10 | ~30-100 | 3-10× |
| 光频 NIM (IR) | ~3-5 | ~40-80 | 8-20× |
| 光频 NIM (可见) | ~1-3 | ~50-80 | 20-50× |
| 超透镜 | ~5 (λ/10分辨) | ~10-20 | 2-4× |

结论：各频段都有**5-20倍**的FOM提升空间。主要瓶颈在制造（减少表面粗糙度→降低γ_surf）和材料选择（寻找更低损耗的等离激元材料：掺杂氧化物、氮化物等）。

### 3.3 能否实现无损耗负折射？

**不能。三个不可逾越的障碍：**

1. **Kramers-Kronig关系**：任何ε(ω)的色散必然伴随非零Im[ε]——如有Re[ε]随ω变化，Im[ε]不能处处为零
2. **SCVC电子-声子耦合**：λ > 0（速查表：典型0.5-2）→ 电子必然与晶格交换能量 → γ_e-ph > 0
3. **表面散射**：任何有限尺寸的结构 → 表面 → 电子被表面散射 → γ_surf > 0

**SCVC锁定的最小损耗（T→0，完美晶体，50 nm特征）：**

```
γ_min(T=0, d=50nm) ≈ γ_surf + γ_residual ≈ 0.01-0.02 eV

FOM_max(可见) ≈ 2.5/0.01 ≈ 250 (绝对上限，不可逾越)
FOM_max(近红外) ≈ 1.2/0.01 ≈ 120
```

但实际材料永远有残余缺陷、晶界、杂质。实用FOM上限约为理论值的1/3-1/5。

### 3.4 超透镜分辨率的损耗限制

Pendry完美透镜需要 ε = μ = -1（无损耗此条件给出无限分辨率）。有限损耗时：

```
Δx_min ≈ (λ/4π) × (1/FOM) × ln(2/δ)

δ: 容忍的振幅衰减, 取 δ=0.1:
Δx_min(可见, FOM=50) ≈ 500nm/(4π) × 0.02 × 2.3 ≈ 1.8 nm ≈ λ/280
```

但这忽略了近场放大需要的厚度——透镜越厚，由于损耗积累，有效分辨率下降越多。实际超透镜分辨率 ~λ/10 到 λ/20。

**SCVC结论：** α和λ共同锁定了超透镜的分辨率上限 ~λ/10（不是Pendry无限分辨率的预测）。这在工程上仍然非常有用（超越衍射极限10倍），但"完美成像"被SCVC禁止。

## §4. 工程结论

### 4.1 哈里波特隐身斗篷——物理允许吗？

**可见光宽带隐身斗篷：被SCVC禁止。**

```
所需条件:
  ε → 0, μ_r → 0, μ_θ → ∞  (内边界)
  制造精度: <10 nm (可见光波长的 1/50)
  色散管理: ε(r,ω) 和 μ(r,ω) 的精确空间-频率分布
  
SCVC障碍:
  ① KK关系 → 极端参数只能窄带实现 → 可见光BW < 1%
  ② 表面损耗 → 50nm特征时γ_surf增大 → Q < 100
  ③ 3D纳米制造 → 需要原子级精度 → 趋近SCVC原子密度极限
  ④ 超材料"原子"的最小尺寸 ~20-50 nm（几个SRR周期）→ 
     波长500 nm时，径向方向最多放10层 → 空间分辨率严重不足
```

**判别：可见光隐身斗篷物理上不禁止（原则上存在一个解），但带宽 < 1%（约5 nm范围），制作难度逼近原子极限。** 作为实用隐身技术是死胡同。

### 4.2 雷达隐身 vs 可见光隐身

| 特性 | 雷达隐身 | 可见光隐身 |
|------|---------|-----------|
| 波长 | 3-30 cm | 400-700 nm |
| λ/d_min 比 | ~10⁶ | ~10-50 |
| 可用层数(径向) | >10³ | ~10 |
| 等离子体频率 | ω_p >> ω (轻松) | ω_p ~ 3ω (够用) |
| 磁共振Q | 50-500 | 5-15 |
| 带宽 | **10-20%** | **<1%** |
| 制造难度 | 中等（PCB/3D打印） | 极端（原子级光刻） |
| SCVC限制 | 宽松 | **严苛** |
| 实用前景 | ✅ 已演示 | ❌ 不切实际 |

**为什么雷达和可见光差距如此巨大？** 根本原因是SCVC锁定的ω_p/ω₀比。在微波频段，ω_p/ω₀ ∼ 10⁸——你有极大的"设计空间"来操控色散。在可见光频段，ω_p/ω₀ ∼ 3-5——设计空间极度压缩。

### 4.3 超材料天线/超透镜的实用前景

**超材料天线：✅ 前景广阔**

```
优势: 亚波长尺寸、可调方向图、宽带/多频
SCVC约束: 天线小型化受限于Chu极限(ka ~ 1)，但超材料可接近极限
最佳频段: 微波至THz（波长→结构尺寸比大）
实用天线: 已商用（手机天线、相控阵）
```

**超透镜：⚠️ 有前景但受限**

```
分辨率: λ/10-λ/20 (SCVC极限 ~λ/50-λ/100)
应用: 纳米光刻、生物成像、数据存储
约束: 损耗 → 透镜厚度 → 视场角 trade-off
SCVC: FOM_max ~ 50-200 → 分辨率极限 ~λ/50
```

**隐身斗篷：⚠️ 窄带可行，宽带绝望**

```
微波地毯斗篷: ✅ 已演示 (BW ~10-20%)
微波自由空间斗篷: 🟡 实验室阶段
红外斗篷: ❌ BW < 2%
可见光斗篷: ❌ BW < 1% (单色可能，宽带不行)
```

### 4.4 SCVC超材料极限总结

| 参数 | 可见光 | 近红外 | THz | 微波 |
|------|--------|--------|-----|------|
| 负折射最大带宽 | ~10% | ~14% | ~41% | ~145% |
| 隐身斗篷实用BW | **<1%** | **1-2%** | **3-5%** | **10-20%** |
| NIM最大FOM | ~80 | ~40 | ~100* | ~500* |
| 超透镜分辨率极限 | ~λ/50 | ~λ/30 | ~λ/100 | ~λ/500 |
| 实现难度 | ⬛⬛⬛⬛⬛ | ⬛⬛⬛⬛ | ⬛⬛⬛ | ⬛⬛ |

> \* 微波/THz频段的FOM受限于超材料谐振器的欧姆Q和辐射Q，而非Drude阻尼。

## 附录：SCVC推导链（超材料/隐身）

```
π → α → ℏ, m_e, n_atomic
         ↓
    ┌────┴─────┬──────────┬───────────┐
    ↓          ↓          ↓           ↓
  ω_p = f(n)  γ_e-ph=f(λ)  v_F       n_atomic
  金属等离子  电子-声子    Fermi速度   原子密度
  体频率     散射率                 
    ↓          ↓          ↓           ↓
  ε<0带宽    Q值/损耗    表面散射   最小特征尺寸
    ↓          ↓          ↓           ↓
  负折射条件  FOM上限    实际Q
    ↓          ↓          ↓
     └────────┴──────────┘
              ↓
        隐身斗篷带宽
         (KK + 共振Q)
```

所有超材料极限归约到π和原子核质量谱（后者由α_s=1/(16π)决定）。**超材料不改变物理常数，只是在SCVC设定的边界内优化工程参数。**
