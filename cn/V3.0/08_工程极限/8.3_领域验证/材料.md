## SCVC 的推导链

第二章给出 $\alpha = 1/(4\pi^3+\pi^2+\pi)$。$\alpha$ 决定电磁相互作用强度。键能、声子谱、离子半径——全部从 $\alpha$ 来。

### 石墨烯 130 GPa

$$\alpha \rightarrow \text{C-C 键能 } 3.6\text{ eV} \rightarrow \text{Morse 势 } F_{\text{max}}=aD/2 \rightarrow \text{Orowan }\sigma_{\text{th}}=\frac{n_{\text{bonds}}F_{\text{max}}}{A_{\text{plane}}} \rightarrow 130\text{ GPa}$$

### 金刚石 2000 W/mK

$$\alpha \rightarrow \text{键能} \rightarrow B \rightarrow v_s=\sqrt{B/\rho} \rightarrow \Theta_D \rightarrow \gamma\text{（Gruneisen）} \rightarrow l_{\text{mfp,max}} \rightarrow \kappa_{\text{max}}$$

### 最高配位数 CN=16

$$\alpha \rightarrow Z_{\text{eff}} \rightarrow \sigma \rightarrow r_{\text{ion}} \rightarrow r_{\text{cation}}/r_{\text{anion}} \rightarrow \text{CN}_{\text{max}}=16$$

### 表面粗糙度 0.1 nm

$$\alpha \rightarrow a_0 \rightarrow \text{原子台阶} \rightarrow 0.1\text{ nm}$$

## 如果 §2 的推导正确

- 130 GPa：C-C 键是第二周期最轻+最强共价键，被 α 锁死。碳是唯一同时满足"最轻+最强+二维"的元素。不存在更强的 2D 材料。
- 2000 W/mK：α 同时锁死声速、Gruneisen、原子质量。碳是三重最优的唯一解。
- CN=16：周期表是 α 的推论。16 是 α 允许的最大几何堆积数。不是"恰好 ThI₄"——ThI₄ 是唯一能展示这个极限的化合物。
- 0.1 nm：物质本身的离散性。不是技术问题。

**SM 能算出同样的值——但 SM 把 α 当测量值，算出来的墙没人当真。SCVC 说墙是几何的——不会移动。**
