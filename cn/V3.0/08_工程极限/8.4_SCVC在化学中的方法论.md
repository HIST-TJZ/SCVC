# 8.4 SCVC 在化学中的方法论

**版本**: V3.0 | **日期**: 2026-07-24

---

## 核心主张

如果 $\alpha = 1/(4\pi^3+\pi^2+\pi)$ 是几何恒等式——那么无机化学的大多数定律不是"实验总结"，是 $\alpha$ 的推论。

---

## 从 α 到周期表

```
α → 电磁相互作用强度
  ├─ 电子-核结合能 → 电离能 → 周期表行的位置
  ├─ 电子-电子排斥 → 屏蔽常数 σ → Z_eff = Z - σ → 有效核电荷
  ├─ Z_eff → 原子半径 → 离子半径
  ├─ Z_eff → 电负性（Pauling/Mulliken）
  ├─ 离子半径比 → 配位数 → 晶体结构类型
  └─ 轨道能量 → 电子构型 → 化学性质周期律
```

**周期表的每一行、每一列、每一个趋势——都是 α 在 Z=1,2,3... 上的重复投影。**

---

## 化学定律的 SCVC 重构

| 化学定律/概念 | SM 视角 | SCVC 视角 |
|:---|:---|:---|
| 电负性 | Pauling 从实验键能拟合 | 从 Z_eff（= f(α)）推导 |
| 离子半径 | 从晶体学实验数据 | 从 Z_eff + n（= f(α)）推导 |
| 配位数 | 几何堆积规则 + 实验半径比 | 半径比从 α → 配位数从半径比 |
| 晶格能 | Born-Landé 方程 + 实验常数 | Madelung 常数 × 离子电荷²/r₀，r₀ 从 α |
| 键能 | 实验测量或量子化学计算 | 量子化学计算——但输入常数（α, m_e）被 α 定义 |
| Born-Haber 循环 | 各步骤代入实验值 | 每一步从 α 推导 |
| Slater 规则 | 实验拟合屏蔽常数 | 屏蔽常数从 α 通过电子-电子排斥推导 |

---

## 方法论意义

SCVC 不是"替代量子化学"——SCVC 是"告诉量子化学：你的输入参数不是自由的"。

量子化学家用量子化学算键能——但他用的 $\alpha$、$m_e$ 是输入值。SCVC 说这些输入本身就是几何必然。如果 SCVC 的 $\alpha$ 是对的，那么：

- 量子化学的精度天花板由数值方法决定——不是由输入参数的不确定度决定
- 周期表不是 118 个独立数据点——是同一个 α 在 118 个 Z 值上的投影
- 任何新化合物的性质在天花板范围内——不是"还没测"，是"α 锁死了上限"

## 验证路径

化学家不需要接受 SCVC 就能验证：用标准量子化学软件，输入 SCVC 的 α = 1/137.036304，计算任何上述天花板的对应量。看是否与实验一致——以及是否超越了当前实验值。

**如果 SCVC 的 α 正确，量子化学的输入参数被锁定，天花板被锁定。如果 SCVC 的 α 错误——量子化学家用标准方法就能找到反例。**
