## 二、什么是离散唯一解的

以下环节**不是任意选择的**——特定整数的出现有群论/几何必然性，但不是 $100\%$ 严格证明：

| 环节 | 整数/公式 | 来源 |
|:---|:---|:---|
| $\alpha_s^{-1}=16\pi$ | $16 = 2\times 8$（toric 除子 × 简单根） | CP² GKM |
| $K=3/(2\pi)$ | $3=\chi(CP^2)$，$2=\dim_\mathbb{C}(CP^2)$ | 三重锁定 |
| $m_\mu/m_e = 4\pi^3\cdot(5/3)$ | $5/3$ 来自 Koide 几何 | 离散唯一 |
| $m_c/m_u=6$, $m_s/m_d=2$, $m_b/m_d=9$ | Weyl 群阶和表示维数 | 群论必然 |
| $m_H/m_W=\pi/2$ | 纯几何比 | 双路径验证 |
| $N_g=3$ | 指数定理 $=3$ | 拓扑必然 |
| $\eta_B = (\alpha/\pi)(4\pi)^{-6}$ | $(4\pi)^{-6}$ = 6 维相空间 | 几何因子 |
