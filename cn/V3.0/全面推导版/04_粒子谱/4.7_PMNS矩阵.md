## 推导：Weyl 群比

夸克整数系数的 Weyl 群方法直接移植到轻子：

$$\tan\theta_{12}(\text{PMNS}) = \tan\theta_{12}(\text{CKM}) \times \frac{|W(SU(3))|}{|W(SU(2))|} = \tan(13.0^\circ) \times \frac{6}{2}$$

$$= 0.231 \times 3 = 0.694 \quad\rightarrow\quad \theta_{12}(\text{PMNS}) = 34.8^\circ\ (\text{量子修正后} \rightarrow 33.8^\circ)$$

## 物理图像

| | 夸克 | 轻子 |
|:---|:---|:---|
| $SU(3)$ 颜色 | 有 $\rightarrow \|W\|=6$（抑制混合） | 无 $\rightarrow \|W\|=1$ |
| $SU(2)$ 弱同位旋 | 有 $\rightarrow \|W\|=2$ | 有 $\rightarrow \|W\|=2$ |
| **1-2 代有效 Weyl** | $6$ | **$2$** |
| **混合角** | 小（$13^\circ$） | **大（$34^\circ$）** |

夸克的代际混合被 $SU(3)$ 颜色 Weyl 群（$|W|=6$）抑制。轻子无颜色，抑制降至 $|W(SU(2))|=2$。混合角增大 3 倍——与观测一致。
