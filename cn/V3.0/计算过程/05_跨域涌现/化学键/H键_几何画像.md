## SCVC几何能说什么

### 1. O-H键偶极矩 (几何推导)

chi_O=3.44, chi_H=2.20 (SCVC Z_eff几何) -> dchi=1.24
电荷偏移: dq = g * dchi/(2*sqrt(chi_avg)) ~ 0.31 e
偶极矩: mu_OH = dq * d_OH ~ 0.31 * 0.96 * 4.8 = 1.45 D
实验: 水分子OH键偶极 ~ 1.51 D
偏差: -4% — 仅从chi差和键长! 这是几何推导, 零拟合。

### 2. H键能量标度 (几何估计)

水二聚体偶极-偶极能:
E_dd ~ 2 * mu1*mu2 / (4*pi*eps0 * R^3) * (角度因子)
mu_water = 1.85D, R_OO = 2.85A -> E_dd ~ 0.19 eV
实验H键: 0.20-0.25 eV
巧合接近! 但这包含了相消的误差(遗漏排斥+色散)。

### 3. 最优H键几何 (涡旋Ampère力最小化)

O-H...O角度 ~170度 (近线性)。
SCVC解释: 线性几何最大化涡旋Ampère吸引力。
H(delta+)涡旋和O孤对电子涡旋的反向环流 -> 线性排列吸引最强。
偏离线性 -> Ampère力减弱 -> Pauli排斥相对增大。

## SCVC几何不能说什么

1. 精确0.20 eV — 需要MP2/CCSD(T)量子化学
2. 色散力 (~0.05 eV贡献) — 电子关联效应
3. 温度/溶剂效应 — 液态水vs二聚体

精确值0.20 eV: RED保持 (需QC软件)
