# 一、核壳层模型与幻数

## 1. 为什么核SOC比原子SOC强~100倍？

### 1.1 数量级对比

```
原子SOC (电磁):
  V_LS_atom = (1/2m²c²)(1/r)(dV_C/dr) L·S
  dV_C/dr|_nuclear_scale = αħc/r²
  对铅(Z=82)1s轨道 (r≈a₀/82≈650 fm):
    dV_C/dr ≈ (1/137)×(197 MeV·fm)/(650 fm)²
          ≈ 1.44/(4.2×10⁵) ≈ 3.4×10⁻⁶ MeV/fm

核子SOC (强作用):
  V_LS_nuc = V_LS(0)·(1/r)(dρ/dr) L·S
  Woods-Saxon: ρ(r) = 1/(1+exp((r−R)/a))
  dρ/dr|_surface ≈ 1/(4a) (峰值在r=R)
  R≈1.2A^(1/3) fm, a≈0.5 fm

强度对比:
  V_LS_nuc(&) ≈ 20-30 MeV·fm² (Woods-Saxon拟合)
  V_LS_atom ≈ (ħ²/2m²c²)×(dV_C/dr)/r ≈ 10⁻⁴ MeV·fm²
  
  核SOC ≈ 10⁵ × 原子SOC!!

原因: α_s ≈ 0.12 ≫ α ≈ 1/137 (耦合强度差16倍)
     + 核力范围~1 fm ≪ 原子尺度~10⁵ fm (势陡度差10⁵倍)
     → 总差~10⁵倍
```

### 1.2 SCVC推导V_LS(0)

```
核子 = QCD涡旋环 (色荷环流)
涡旋环在核表面感受到Ampère力 → 环流方向-轨道耦合

SCVC: V_LS(0) ∝ α_s·ħc·(dρ/dr)|_R
      ∝ α_s·ħc/(a·R)  (a=表面厚度, R=核半径)
      
数值估计:
  α_s(QCD标度≈1GeV)≈0.3
  ħc=197 MeV·fm
  a≈0.5 fm, R≈7 fm (A=208)
  
  V_LS(0) ≈ 0.3×197/(0.5×7) ≈ 17 MeV·fm²
  
Woods-Saxon拟合值: ≈ 20-25 MeV·fm² → 偏差~20% ✅

核SOC符号: V_LS_nuc < 0 (与原子符号相反!)
  → j=ℓ+1/2 低于 j=ℓ−1/2 (核)vs (原子)
  SCVC: 涡旋环在核表面的环流方向和原子中的相反
  → QCD涡旋环 = 吸引型 → 平行排列更稳定
  → 电磁涡旋环 = 排斥型 → j=ℓ+1/2更高(更不稳定)
```

## 2. 壳修正 → 双峰

### 2.1 双峰机制

```
总能量: E(β₂) = E_LDM(β₂) + δE_shell(β₂)

液滴能 E_LDM: 平滑抛物线(-Coulomb+surface竞争)
壳修正 δE_shell: 随变形振荡!
  β₂≈0 (球形): 壳间隙大→δE大负→基态
  β₂≈0.3-0.5: 壳间隙小→δE≈0→势垒
  β₂≈0.6-0.7: 新壳间隙→δE又负→同质异能阱(II)
  β₂→∞: 断开→无壳→δE→0

双峰 = 液滴抛物线 + 壳修正振荡!

典型值 (²⁴⁰Pu):
  基态 (β₂≈0.28): E=0 (参考)
  内垒 (β₂≈0.5): E≈6 MeV
  同质异能阱 (β₂≈0.87): E≈2.7 MeV
  外垒 (β₂≈1.15): E≈5.7 MeV
  断开 (β₂→∞): E≈−200+ MeV (释放~200MeV!)
```

### 1.1 液滴模型滴线

```
单中子分离能: S_n(Z,N) = B(Z,N) − B(Z,N-1)

B(Z,N) = a_V A − a_S A^(2/3) − a_C Z²/A^(1/3) − a_A (N−Z)²/A + δ_pair

∂B/∂N ≈ a_V − (2/3)a_S·A^(−1/3) − (1/3)a_C·Z²/A^(4/3) − a_A·(1−2(N−Z)/A) + ...
       + a_A·(N−Z)²/A²

S_n=0 ⇔ ∂B/∂N=0 (连续近似)

对固定Z, 解S_n(N_max,Z)=0:
  a_A·(N_max−Z)²/A_max² ≈ a_V − (2/3)a_S/A_max^(1/3) − ...

近似: 中子过剩 δ = (N−Z)/A
S_n=0 → δ_max² ≈ (a_V/(2a_A)) → δ_max ≈ 0.32 (液滴)

实际壳修正: δ_max≈0.35-0.50 (富中子)
```
