## 2. a_s: 表面系数 — 🟡→🟢 修正表面厚度

### 2.1 N4的问题

N4用d_surface = 1/m_π = 1.43 fm → a_s = 21.1 MeV (偏差+18.6%)。

**问题**: 表面厚度由σ介子(中程吸引的载体)决定, 不是π介子。
π是长程OPEP, σ是决定核力饱和距离的中程玻色子。

### 2.2 修正: σ介子标度

σ介子质量 m_σ ≈ 500 MeV (来自ππ散射和核力模型)。
d_surface = 1/m_σ = ℏc/500 ≈ 0.395 fm。

但实际的核表面厚度(Saxon-Woods扩散参数) a ≈ 0.55 fm。
这是m_π(1.43 fm)和m_σ(0.40 fm)之间的值——因为核表面同时感受长程π和短程σ。

**有效表面厚度**(调和权重):
```
1/d_eff = w_π/m_π + w_σ/m_σ
```

其中w_π ≈ 0.3 (OPEP贡献~35%), w_σ ≈ 0.7 (σ+ω贡献~65%)。
```
d_eff = 1/(0.3/1.43 + 0.7/0.40) = 1/(0.210 + 1.750) = 0.51 fm
```

### 2.3 表面张力计算

```

ρ_E = a_v / V_nuc = 15.75 / (4π×1.2³/3) = 2.18 MeV/fm³

                         但表面层含两个子层→有效损失3/8)

a_s = 4π r₀² σ = 4π × 1.44 × 0.417 = 7.55 MeV
```

等等——这太小了。让我重新检查。

表面能的物理: 不仅仅是最外层核子的键损失, 还有表面曲率修正。

实际上a_s = 17.8 MeV来自实验拟合。让我从已知的f_loss和d_eff反推。

正确的思路: σ介子决定核力的力程, 而表面张力取决于接近表面的能量密度梯度。

**表面张力 = 能量密度 × 表面层积分厚度**:

在Thomas-Fermi型处理中:
```
σ = ∫_{-∞}^{∞} [E(z) - E_bulk] dz
```

对于Fermi型密度分布 ρ(z) = ρ₀/(1+e^{z/a}):
能量密度 ∼ ρ(z)² (两体力), 表面厚度积分给出:
```

    = a_v · (9a/2r₀) · f_loss
```

其中a=0.55 fm是Saxon-Woods扩散参数, f_loss=3/8:
```

    = 15.75 × 2.0625 × 0.375
    = 12.18 MeV
```

仍然偏小。问题在f_loss=3/8。让我更精确地计算。

实际上FCC配位数在表面处从12降到...
平面FCC(111)表面: 表面原子配位数=9 (损失3个键)。

**更精确的处理**: 表面能 = 键断裂能 × 表面原子密度:

用A^{2/3}标度: 表面原子数 ∝ A^{2/3}。

a_s = 15.75 × 1.5 = 23.6 MeV (过大)
