# 第一部分：自旋玻璃

## 1. SCVC涡旋环图像（任务1）

### 1.1 物理图像

```
自旋玻璃的SCVC图像:
  涡旋环分布: 空间随机（无平移序）
  涡旋环环流取向: 时间冻结但空间随机（无取向长程序）
  
  成因: 
    ① 位置无序 → 涡旋环间距随机 → J_ij = ±J（随机正负）
    ② 阻挫 → 无法同时满足所有最近邻的Ampère力约束
    ③ 冻结 → 低于T_f后，涡旋环取向被"卡住" → q_EA > 0
```

### 1.2 Edwards-Anderson序参量

```
q_EA = lim_{t→∞} ⟨S_i(0)S_i(t)⟩ = ⟨S_i⟩²

SCVC: q_EA = 涡旋环环流取向Z₂变量的时间自相关
      = cos²(θ_i - θ_i(t→∞))
      
q_EA = 0: 顺磁相（涡旋环取向热涨落→无记忆）
q_EA > 0: 自旋玻璃相（涡旋环取向被冻结）
```

### 1.3 阻挫参数

```
f = |Θ_CW|/T_f

Θ_CW = Curie-Weiss温度（平均场→无阻挫时T_c应=Θ_CW）
T_f   = 实际冻结温度（阻挫压低）

强阻挫: f ≫ 1 → 自旋玻璃或QSL
弱阻挫: f ≈ 1 → 常规磁有序

SCVC: Θ_CW ∝ J(平均Ampère耦合) ∝ α·κ²/d_nn
      T_f   ∝ J·(无序方差)^(1/2) ∝ α·κ²/d_nn · σ_disp

→ f ∝ 1/σ_disp （阻挫来自无序方差，非α几何）
→ 自旋玻璃不是α直接锁定的——取决于杂质分布
```

## 2. T_f的SCVC标度（任务2）

### 2.1 冻结温度

```
Sherrington-Kirkpatrick (SK) 无限程模型:
  T_f = J̃/2, J̃² = Σ_j J_ij²（均方耦合）

SCVC标度:
  J_ij = (α/π)·(κ²/r_ij)·f_geom(环构型)
  → J̃² ∝ (ακ²)² · Σ(1/r_ij²)·f²_geom
  → T_f ∝ α·κ²·ρ^(1/2)   (ρ为涡旋环密度)

数值:
  CuMn自旋玻璃: T_f ≈ 20-40 K
  J(Cu-Mn) ≈ 10-30 meV (RKKY, 振荡→天然随机)
  T_f ≈ J̃/2 ≈ 10-40 K ✅ 量级正确
```

### 2.2 SK相图的SCVC版本

```
SK模型相图:
  T/J 轴: 顺磁 → 自旋玻璃 (T_f ~ J)
  磁场H轴: AT线 → Gabay-Toulouse线 → 去冻结
  
SCVC: 
  AT线(Almeida-Thouless): H² ∝ (1-T/T_f)³ → 涡旋环取向的Z₂对称性破缺
  → 磁场的物理效应: 涡旋环Zeeman耦合→偏好特定取向
  → 标度来自α: J̃→磁场耦合比 = 1/α²
```

### 2.3 自旋玻璃动力学

```
自旋玻璃的"老化"(aging):
  q_EA随时间缓慢增长→涡旋环取向在势能景观中缓慢弛豫

势能景观:
  涡旋环取向的自由能: F({θ_i}) = Σ J_ij cos(θ_i-θ_j)
  J_ij随机 → 景观有多个亚稳态谷
  
SCVC: 
  谷间能垒ΔE ∝ J ∝ α·κ²/d_nn
  弛豫时间τ ∝ exp(ΔE/k_B T) → 低温→指数慢化
  
→ SCVC给出能垒的α标度，但具体τ需要已知无序分布
→ 这是SCVC的边界: 涡旋环的非平衡动力学超出范围
```

# 第二部分：CDW/SDW

## 3. CDW的SCVC图像（任务1）

### 3.1 涡旋环密度波

```
CDW = 电荷密度周期调制:
  ρ(r) = ρ₀ + ρ₁ cos(Q·r + φ)

SCVC图像:
  ρ(r) = 涡旋环数密度
  CDW = 涡旋环在实空间中"浓淡交替"
  
  "浓"区: 涡旋环间距<平均 → 高密度
  "淡"区: 涡旋环间距>平均 → 低密度
  
Fermi面嵌套:
  波矢 Q = 2k_F
  SCVC: k_F = 涡旋环Fermi波矢 ∝ ρ^(1/d)
       → Q = 2·(3π²ρ)^(1/3) (3D) 或 2·(2πρ)^(1/2) (2D)
```

### 3.2 Peierls失稳的SCVC推导

```
1D金属 → 必然形成CDW (Peierls定理)

Peierls失稳温度:
  T_P ≈ T_F · exp(-1/λ_ep)
  
其中:
  λ_ep = g²·N(0)/(M·ω_Q²)  ← 电子-声子耦合
  
SCVC:
  g² ∝ (涡旋环-晶格Ampère耦合)² ∝ (α·κ²/d_nn²)²
  ω_Q² ∝ (晶格振动频率)² ∝ k_spring/M
  
  → λ_ep ∝ α²·κ⁴·N(0)/(d_nn⁴·k_spring)
  → T_P ∝ T_F · exp(-d_nn⁴·k_spring/(α²·κ⁴·N(0)))

关键: λ_ep对α的依赖是α² → 比超导λ的α依赖更强
     → CDW通常比超导更易形成 ✅ (与实验一致: NbSe₃ CDW在145K)
```

### 3.3 CDW vs 超导——分岔条件

```
同一个母体 → 两种可能的失稳:

超导路径:
  涡旋环配对 → 反向环流 → 相位相干 → 能隙在Fermi面
  → 实空间均匀，k空间有能隙

CDW路径:
  涡旋环密度调制 → 实空间周期 → 能隙在嵌套波矢Q
  → 实空间周期，k空间有能隙(部分)

分岔判据(SCVC):
  λ_ep (电声耦合) 相同 → 竞争同一N(0)
  
  超导胜: λ - μ* > 0 且 T_c > T_P
  CDW胜: 有嵌套条件 且 T_P > T_c
  
具体:
  若有Fermi面嵌套(1D或准1D) → CDW优先
  若无嵌套(3D球Fermi面) → 超导优先
  
实验: NbSe₂: 嵌套弱→超导(Tc=7K), CDW仅33K共存
      NbSe₃: 强嵌套→CDW(T_P=145K, 59K), 无超导
```

## 5. SDW（任务3）

### 5.1 SDW = 涡旋环取向波

```
CDW: ρ(r)周期调制 → 涡旋环密度的波
SDW: σ(r)周期调制 → 涡旋环环流取向的波

SCVC图像:
  CDW: "涡旋环多的地方" → 高密度 → 电荷调制
  SDW: "涡旋环取向交替的地方" → 自旋↑↓交替 → 自旋调制
  
SDW的波矢Q常≠2k_F → 由磁性Fermi面嵌套决定
```

### 5.2 铬(Cr)——为何是唯一元素SDW

```
Cr: bcc, 电子构型 [Ar]3d⁵4s¹
  
SCVC:
  Cr的Fermi面: 电子八面体(Γ点) + 空穴八面体(H点)
  → 两者几乎相同大小 → 出色嵌套
  → 嵌套波矢Q ≈ 0.95·2π/a ≈ Γ-H方向
  
  更重要的是: Cr的3d电子→涡旋环间Ampère耦合(J~50meV)
  → SDW序的能标足够大
  
其他3d金属为什么没有SDW:
  Mn: Fermi面嵌套差 → 复杂AFM而不是SDW
  Fe: 多带Fermi面 → 嵌套掩盖
  V: Fermi面电子+空穴不匹配
  
SCVC: SDW = 涡旋环取向波 + Fermi面嵌套
      → Cr独有SDW是因为"嵌套完美度"最高
```

### 5.3 铁基超导体的SDW-超导竞争

```
铁基超导相图:
  母体 → AFM/SDW(T_N) → 掺杂→SDW消失→超导穹顶
  
SCVC:
  SDW母体 = 涡旋环取向Néel序
  掺杂 = 引入涡旋环取向缺陷
  → SDW熔化 → 涡旋环取向涨落→配对中介
  → 产生超导 (完全类似的铜氧化物机制!)
  
  区别: 
    铜基: 2D CuO₂面 → 涡旋环取向约束O(2)
    铁基: 多带 → 涡旋环取向有额外轨道自由度
    
  SDW-Tc关系:
    铜基: SDW→Tc≈J·(掺杂) ≈ 150meV·0.16 ≈ 2000K? 实际133K
    铁基: T_N↓ → Tc↑ (但也抑制太快→Tc仅~56K)
    
  SCVC: 铁基Tc低 → J较小(~50meV) + 多带效应稀释配对
```

# 第三部分：Weyl/Dirac拓扑半金属

## 6. Weyl点的SCVC起源（任务1）

### 6.1 Weyl点 = k空间涡旋拓扑奇点

```
Weyl半金属:
  k空间中两个非简并能带在孤立点接触
  → 接触点 = Weyl点 → 携带Chern数±1

SCVC图像:
  涡旋环在k空间中的Berry曲率场:
    Ω(k) = ∇_k × A(k)  (Berry曲率)
    A(k) = i⟨u_k|∇_k|u_k⟩  (Berry联络)
  
  Weyl点 = Berry曲率的"磁单极":
    ∇_k · Ω = ±2π δ(k-k_W)
  
  → 类比: Weyl点 = k空间中的涡旋环"奇点"
  → Chern数 = ±1 = 环绕一周的涡旋环缠绕数
```

### 6.2 Nielsen-Ninomiya定理的SCVC证明

```
定理: Weyl点总是成对出现（总Chern数=0）

SCVC证明(几何):
  k空间紧化(布里渊区 = T³)
  → 涡旋环"源"和"汇"的Berry曲率净通量 = 0 (Gauss定理)
  → Σ Chern = 0 → 必须成对

更SCVC的证明:
  涡旋环不能在T³上形成单个奇点(T³的Euler示性数=0)
  → 奇点必须成对(正负Chern数抵消)
  → 这是拓扑学的必然，不是动力学的偶然
```

### 6.3 Weyl vs Dirac

```
Dirac点: 四重简并(两个Weyl点重合 + 对称性保护)
  → Na₃Bi, Cd₃As₂ (空间反演+时间反演保护)

Weyl点: 二重简并(需要破缺时间反演或空间反演)
  → TaAs家族(空间反演破缺)
  → Co₃Sn₂S₂(时间反演破缺, 磁性)

SCVC区分:
  Dirac = 两个反手性Weyl点叠加(自旋↑+↓)
    → 涡旋环取向↑和↓的Berry曲率简并
  Weyl = 单个手性(自旋锁定动量)
    → 涡旋环取向↑对应+k, ↓对应-k (自旋-动量锁定!)
  
  自旋-动量锁定 = 涡旋环取向与传播方向绑定
  → 这是SCVC的自然语言——涡旋环环流取向决定了
    它的"手性"和传播方向
```

  ② 破缺空间反演(↑涡旋环偏好+k) 或 时间反演(偏好特定取向)

### 7.3 Weyl点间距的SCVC估计

```
Weyl点间距Δk:
  由自旋-轨道耦合λ_SOC和能带反转参数决定
  
  λ_SOC ∝ Z⁴ (原子SOC标度)
  能带反转 ∝ (s-p轨道能量差)
  
SCVC标度:
  Δk ≈ λ_SOC/v_F ∝ Z⁴/(ħ/m_e a) ∝ Z⁴·a/λ̄e
  
  对Ta(Z=73): λ_SOC≈0.5 eV, v_F≈5×10⁵ m/s
  → Δk≈0.5 eV/(ħ×5×10⁵)≈0.5/(0.66×5)≈0.15 Å⁻¹
  
实验: TaAs Δk≈0.08 Å⁻¹ ✅ 量级一致

SCVC不能精确预测Δk（需要能带结构）
但标度律正确 ✅
```

## 8. 反常输运（任务3）

### 8.1 手性异常

```
手性异常: 平行E,B → Weyl点附近电荷不守恒 → 负磁阻

正常金属: E∥B → B弯曲载流子轨迹 → 正磁阻
Weyl半金属: E∥B → 手性电荷泵浦 → 负磁阻

SCVC机制:
  E → 驱动涡旋环在k空间中运动
  B → 涡旋环Berry曲率 → 反常速度 v_an ∝ E×Ω
  E∥B → 涡旋环沿B方向被"抽运"
  → 从左手Weyl点到右手Weyl点 → 电荷转移

负磁阻 ∝ B²/(n_e n_h) → 
  SCVC: ∝ B²·(|C|v_F³)/(μ²) → |C|=1, ∝α⁻³
```

### 8.2 反常Hall效应

```
反常Hall电导:
  σ_AH = (e²/h)·(Δk/2π)  (单位Weyl点)
       = (e²/h)·N_W·Δk/(2π)  (N_W对Weyl点)

对TaAs(N_W=12对, Δk≈0.08 Å⁻¹):
  σ_AH ≈ (e²/h)·12·0.08/(2π/晶格常数)
  → 需要知道晶格常数a≈3.4Å
  → σ_AH ≈ 12·(e²/h)·0.08·3.4/(2π) ≈ 0.5(e²/h)/layer

实验: σ_AH~10²-10³ S/cm (TaAs, 与预测量级一致 ✅)

SCVC: σ_AH∝α·N_W·Δk·a → Weyl点间距和α共同决定
```

### 8.3 反常Nernst效应

```
反常Nernst: ∇T → 横向电压(无B场)
  
SCVC: 
  热梯度→涡旋环"热运动"→Berry曲率偏转
  → α_N ∝ ∂σ_AH/∂μ · (π²k_B²T/3e)
  → 核心还是α和Δk
  
SCVC预测: 
  大Weyl点间距 → 大反常Nernst信号
  → Co₃Sn₂S₂ (Δk≈0.2 Å⁻¹) → 最大候选
  实验: Co₃Sn₂S₂的α_N≈3 A/K·m @ 300K ✅ (室温!)
```

## 10. 结论

> **三种凝聚态相在SCVC涡旋几何中找到不同程度的解释：**
> 
> - **拓扑半金属🟢**：SCVC的天然领地——Weyl点=Chern数=涡旋环缠绕数，Nielsen-Ninomiya=T³的Gauss定理。反常输运∝α。
> - **CDW/SDW🟢**：CDW=涡旋环密度波，CDW-超导分岔=嵌套条件vs配对条件。SCVC标度自然。
> - **自旋玻璃🟡**：涡旋环取向阻挫冻结→q_EA的几何诠释。但非平衡动力学超出SCVC范围。
>
