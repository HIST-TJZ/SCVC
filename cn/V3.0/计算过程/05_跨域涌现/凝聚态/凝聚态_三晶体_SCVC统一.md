## 摘要

三种"晶体"在SCVC涡旋几何中找到统一语言：维格纳晶体=涡旋环Coulomb排斥→空间有序化，激子绝缘体=涡旋环-反环Coulomb吸引→配对凝聚，时间晶体=涡旋环取向的非平衡周期振荡。SCVC给出标度律和能量尺度，但精确临界值仍需量子多体计算。

# 第一部分：维格纳晶体

## 1. 涡旋环结晶化（任务1.1-1.3）

### 1.1 物理图像

```
电子涡旋环 + 低密度 + 低温 → Coulomb排斥主导
→ 涡旋环排斥彼此进入周期性排列 → 维格纳晶体

竞争:
  动能 E_K ~ ħ²/(2m_e a²)  → 量子涨落 → 破坏有序
  Coulomb E_C ~ e²/(εa)    → 排斥 → 建立有序
  
临界条件: E_C/E_K = Γ_crit  (Γ_crit = 临界比值, 非1)
```

### 1.2 SCVC标度推导

```
e²/(4πε₀) = αħc  (SCVC精细结构常数)

E_C = αħc/(εa)
E_K = ħ²/(2m_e a²)

E_C/E_K = (αħc/εa) / (ħ²/2m_e a²)
        = 2αm_e c a / (εħ)
        = 2αa / (ελ_C)          [λ_C = ħ/(m_e c) = 康普顿波长]
        = 2a / (εa_B)           [a_B = ħ/(αm_e c) = 玻尔半径]

即: E_C/E_K = 2a/(εa_B)

设临界比值 = Γ_crit:
  a_crit = (Γ_crit/2) · ε · a_B
  r_s_crit = a_crit/a_B = Γ_crit · ε/2
```

### 1.3 数值验证

```
已知实验/QMC:
  2D Wigner晶体: r_s ≈ 35-40
  3D Wigner晶体: r_s ≈ 100 (QMC)

SCVC反推Γ_crit:
  2D: Γ_crit = 2r_s/ε ≈ 2×37/1 = 74 (真空ε=1)
      对GaAs(ε≈13): Γ_crit ≈ 2×37/13 ≈ 5.7

  3D: Γ_crit ≈ 2×100/1 = 200

结论: Γ_crit不是O(1)的——结晶化需要Coulomb能远超动能。
      SCVC给出标度E_C/E_K ∝ α⁻¹a ∝ a，但Γ_crit本身需要
      量子蒙特卡洛才能确定（超出SCVC纯几何范围）。
```

### 1.4 SCVC能算的 vs 不能算的

| 物理量 | SCVC能算? | 结果 |
|:---|:--:|:---|
| E_C/E_K标度 ∝ α⁻¹·a/a_B | 🟢 能 | 标度律精确 |
| 临界密度 n_c | 🟡 半定量 | 需要Γ_crit输入 |
| 零温基态能(3D bcc) | 🟡 半定量 | Madelung常数×e²/a |
| 熔化温度 T_m | 🔴 不能 | 需要完整声子谱 |
| 涡旋环取向长程序 | 🟡 半定量 | Afv序→实验验证点 |

### 1.5 2D维格纳晶体（GaAs/AlGaAs）

```
实验平台: GaAs/AlGaAs异质结, ε≈13, m*≈0.067m_e

SCVC预测:
  E_C/E_K = 2αa/(ελ_C) = 2a/(εa_B*)  其中 a_B* = εħ²/(m*e²) ≈ 100Å

  设Γ_crit≈74（与真空2D相同）:
  a_crit ≈ (74/2)×100Å ≈ 3700Å
  n_c ≈ 1/(πa_crit²) ≈ 2.3×10⁹ cm⁻²

实验: n_c ~ 10⁹-10¹⁰ cm⁻²  ✅ 量级正确

SCVC标度: n_c ∝ 1/m*²  (a_B*∝1/m* → a_crit²∝1/m*² → n_c∝m*²)
→ 更轻的m* → 更高n_c → 更难结晶 ✅ (与实验趋势一致)
```

### 1.6 独特SCVC预测

```
① 涡旋环环流方向在维格纳晶格中有Afv长程序
   → 中子散射/μSR应能观测到反铁磁信号（即使无真实自旋）

② 声子模: 涡旋环环流集体振荡 → 与普通声子不同
   → 可能在低能激发谱中区分

③ 拓扑相变: 涡旋环晶体→涡旋环液体的转变
   → 可能存在中间"六角相"（KTHNY熔化理论）

✅ 可证伪: 如果维格纳晶体没有Afv序→涡旋环图像不完整
```

# 第二部分：激子绝缘体

## 2. 激子=涡旋环-反涡旋环对（任务1）

### 2.1 超导 vs 激子绝缘体的SCVC镜像

```
超导:                         激子绝缘体:
  e⁻涡旋环 + e⁻涡旋环              e⁻涡旋环 + h⁺反涡旋环
  → 初始排斥(同向环流)             → 初始吸引(反向环流!)
  → 需声子中介→反向→配对          → Coulomb直接配对
  → Cooper对                     → 激子
  
关键对称性:
  Cooper对: 涡旋环对(同电荷, 需中介)
  激子:     涡旋环-反涡旋环对(反电荷, 直接吸引)
  
→ 激子绝缘体是超导的"电荷共轭"版本
→ SCVC超导框架→可直接迁移！
```

### 2.2 激子结合能的SCVC闭式

```
3D激子(Bulk):
  E_b(3D) = μe⁴/(2ε²ħ²) = μ(αc)²/(2ε²)
          = Ry* = (μ/m_e)·(1/ε²)·13.6 eV

2D激子(量子阱):
  E_b(2D) = 4μe⁴/(ε²ħ²) = 4×E_b(3D) = 4Ry*
  
SCVC输入: α → e² = αħc → E_b ∝ α²
→ 激子结合能直接由精细结构常数决定 ✅
```

### 2.3 激子凝聚温度

```
弱耦合BCS限(低密度、大激子半径):
  T_c(BCS) ≈ T_F · exp(-1/|g_eff|)
  
强耦合BEC限(高密度、紧束缚激子):
  T_c(BEC) = 3.31·ħ²·n_ex^(2/3) / (k_B · m_ex)
  
SCVC判断: 激子绝缘体在BEC侧
  原因: Coulomb直接吸引 → 结合能大(E_b > T_F)
       → 激子在Tc之前就已形成 → 凝聚只是相位相干
```

### 2.4 材料验证

| 材料 | ε | μ/m_e | E_b(3D,meV) | E_b(2D,meV) | n_ex(cm⁻³) | T_BEC(K) | 实验Tc(K) | 判断 |
|:---|:--:|:--:|:--:|:--:|:--:|:--:|:--:|:---|
| **Ta₂NiSe₅** | ~5 | ~0.3 | ~16 | ~64 | ~10¹⁹ | ~110 | ~328 | 🔴 实验Tc远>BEC |
| **TiSe₂** | ~10 | ~0.5 | ~7 | ~27 | ~5×10¹⁸ | ~30 | ~200(CDW) | 🟡 CDW共存 |
| **GaAs QW** | 13 | 0.04 | 0.3 | 1.3 | 10¹⁰ | ~0.001 | — | 🟢 极低温 |
| **MoS₂ ML** | ~4 | 0.25 | 21 | 85 | 10¹² | ~0.01 | — | 🟢 2D增强明显 |

**Ta₂NiSe₅的328K远高于SCVC预测的BEC温度~110K。** 可能的原因：
1. 它不是真正的激子绝缘体——只是能隙打开（无凝聚）
2. 激子密度远高于估计（n_ex > 10²⁰ → T_BEC > 300K）
3. SCVC的BEC模型不适用于强耦合准1D体系

### 2.5 SCVC判断：Ta₂NiSe₅=328K是真激子绝缘体吗？

```
支持:
  - 结合能60meV ≈ 700K → Tc可达700K（在完美3D BEC下）
  - 准1D链→密度涨落可局部提高n_ex → 提高T_BEC

反对:
  - 结构相变与激子凝聚同时发生→可能是结构驱动的能隙
  - 无明确Goldstone模观测
  - 角分辨光电子谱(ARPES)显示的能隙与单粒子能隙难以区分

SCVC: 🔴 不确定。SCVC说Tc可达室温是物理允许的，
     但Ta₂NiSe₅的具体情况需要更多实验证据。
```

### 2.6 激子绝缘体Tc天花板

```
与超导的对比:
  超导常压Tc上限: ~133K (铜氧化物, 赝能隙截断)
  激子绝缘体Tc上限: ? (尚无明确天花板)

SCVC论证:
  超导配对需声子中介 → Tc ∝ θ_D·exp(-1/λ) → 指数压制
  激子配对Coulomb直接 → E_b ∝ α² (无指数压制!)
  → 激子绝缘体的Tc原则上可远超超导

但! BEC温度T_BEC ∝ n_ex^(2/3)/m_ex仍需足够高的激子密度
  → n_ex受限: 电子+空穴必来自激发→Mott密度
  → 存在Mott临界密度 n_M: 激子半径 > 激子间距
     a_B* · n_M^(1/3) ≈ 0.26 (Mott判据)
     n_M ≈ 1/a_B*³
  
SCVC Tc上限:
  T_BEC_max ≈ 3.31·ħ²·n_M^(2/3)/(k_B·m_ex)
           ≈ 3.31·ħ²/(k_B·m_ex·a_B*²)
           ≈ (3.31/k_B)·(ħ²/(m_ex·(εħ²/(μe²))²))
           ≈ (3.31/k_B)·(μ²e⁴/(ε²ħ²))·(1/m_ex)
           ≈ (3.31/k_B)·E_b(3D)·(μ/m_ex)

对于 μ≈m_ex/2 (电子-空穴对称):
  T_c_max ≈ (3.31/k_B)·E_b(3D)/2 ≈ E_b(3D)/(1.6k_B) ≈ 0.63·E_b(3D)/k_B

→ SCVC: Tc_max ≈ 0.6 × 激子结合能
→ 若E_b=60meV → Tc_max≈420K ✅
→ 激子绝缘体室温可行！
```

|:---|:---|

| 激子Tc有物理天花板吗？ | 🟢 Tc_max≈0.6×E_b/k_B→可达室温(~400K)。比超导上限(133K)高得多。 |
| Ta₂NiSe₅是真激子绝缘体？ | 🔴 不确定。SCVC说物理允许但实验证据不足。 |

# 第三部分：时间晶体

## 3. 时间晶体=涡旋环的非平衡振荡（任务1）

### 3.1 SCVC的平衡态/非平衡态边界

```
SCVC到目前为止: 全部平衡态（或近平衡线性响应）
  超导Tc、铁磁T_C、晶体结构、化学键...
  → 都是基态或热平衡的性质

时间晶体: 非平衡态
  需要周期驱动维持 → H(t+T)=H(t)
  需要MBL → 无序阻止热化
  
SCVC对非平衡态的核心限制:
  α锁死了所有能量标度 → 驱动频率ω_d、无序W、耦合J
  的相对比例被几何约束
```

### 3.2 能量标度的SCVC追溯

```
时间晶体的三个能量标度:

① 交换耦合 J（涡旋环间Ampère力）:
  J ~ (α/π)·(κ²/d_nn) ≈ 1-150 meV（取决于材料）
  ← 直接来自α ✅ SCVC可算

② 无序强度 W（杂质→局域场随机）:
  W ~ 晶格畸变能 ~ (键能涨落)
  ← 来自杂质涡旋环的Ampère场扰动
  ← 标度: W/J ∝ (局域应变) ← 不由α直接锁定

③ Floquet驱动 ω_d（外加微波）:
  ω_d = 2π/T_drive ← 实验可控参数
  ← 不由SCVC锁定（外部驱动）

关键问题: W/J 的临界值是否被α约束？
  MBL需要 W > W_c ≈ J  → W/J > 1
  
  SCVC: 如果杂质是天然晶格缺陷 → W ∝ 键能涨落
        → W/J ≈ (键能涨落)/(交换耦合) 
        → 两者都∝α → 比值∝O(1)
        
  → 这意味着W/J≈1是"自然点" → MBL在天然材料中可行 ✅
```

### 3.3 时间晶体的物理极限

| 极限 | SCVC推导 | 值 |
|:---|:---|:--:|
| **振荡周期下限 T_min** | J→翻转时间~ħ/J | ħ/150meV≈4×10⁻¹⁴ s (铜基) |
| **温度上限 T_max** | 热化速率>振荡速率→破坏 | k_B T ~ J → T~1700K(铜基) |
| **寿命上限 τ_max** | Floquet加热→热化 | ∝ 1/(αω_d)→几天~几年 |
| **尺度上限 N_max** | MBL在热力学极限不稳定 | 争议中，可能~10²-10³ |

### 3.4 时间晶体的寿命

```
时间晶体的"死亡"=Floquet加热→达到无限温度

加热速率(SCVC估计):
  Γ_heat ~ (α/π)·ω_d·(J/ω_d)²  (弱驱动)
         ~ (α/π)·J²/ω_d
  
对于J≈10meV, ω_d≈5GHz≈0.02meV:
  Γ_heat ≈ (1/430)×100/0.02 ≈ 12 meV/s ≈ 10¹³ K/s

这并不是热化速率——这是Floquet-Magnus展开的收敛半径估计。
实际热化时间→需要MBL→指数长寿命→exp(W/J)∼exp(10)∼10⁴周期

实验: Google Sycamore~100周期→还远远不是寿命上限
```

### 3.5 SCVC独特贡献

```
① 平衡/非平衡边界:
   SCVC的平衡态推导需要涡旋环取向处于热平衡
   → 无法处理非平衡（Floquet）的涡旋环动力学
   → 这是SCVC的方法论边界

② 能量标度追溯:
   时间晶体的所有能量标度(J,W)都追溯至α
   → 时间晶体参数空间被α约束
   → 不是所有(W/J, ω_d/J)组合都物理允许

③ 如果时间晶体有"最优工作点":
   SCVC猜测: W/J ≈ 2-3, ω_d/J ≈ 0.1-0.3
   → 这个窗口可能被几何锁定
```
