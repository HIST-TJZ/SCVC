单涡旋: BPSinstanton作用量 = π (平坦空间, n=1)
模空间: DH积分 = Σ 1/e_T(p) = 4π³+π²+π

**两者是完全不同的数学对象。**

### 2.2 模空间的物理意义

M_vortex = {涡旋在CP²×S¹上所有可能位置的集合}

- 复维数 = 3 (三个平动方向)
- toric不动点 = 涡旋位置被T²作用固定的点

- C2: 涡旋位于CP²的S²子流形上 → 2个零模方向
- F3: 涡旋位于模空间边界 → 1个零模方向

BPS涡旋解的贡献: 确认了在每个不动点附近, 涡旋剖面的局部形式,
从而确认了零模数和codim。

### 3.3 F3处的边界行为

在R=R_max处, 涡旋被截断。仅可沿边界环移动 → 1个零模 → codim=1。


**BPS涡旋解确认了零模数→确认了codim→确认了π的幂次。**
