## 说明

此文件夹收录各章节的详细推导过程。与 `全面推导版/` 的关系：

- **全面推导版**：精炼结果，适合通读理解全貌
- **计算过程/**（此处）：完整的代数步骤、中间推导、数值演算，适合独立复现

每章的计算过程文件来自 v2.0 阶段的详细推导，保留了从几何假设到数值结果的全链路。
