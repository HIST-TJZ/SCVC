====================================================================
SCVC工程极限 E134：永磁体磁场上限 — 剩磁+磁能积的绝对天花板
====================================================================

**所有推导基于SCVC常数（α=1/(4π³+π²+π), μ_B=9.274×10⁻²⁴ J/T, g≈2）。**

--------------------------------------------------------------------
§1. 永磁体的SCVC物理链
--------------------------------------------------------------------

  永磁体性能由四个参数决定，每个都追溯到α:

  M_s (饱和磁化强度):
    M_s = n × m_per_atom = n × gJμ_B × (J/atom)
    n（原子密度）← 原子半径 ← 屏蔽效应 ← α
    μ_B = eℏ/(2m_e) — ℏ和m_e都从SCVC来

  各向异性场 H_A:
    晶体场分裂能 ← 配位离子静电势 ← 电荷分布 ← α（电磁耦合）
    H_A决定了矫顽力H_c的上限

  交换耦合 J_ex:
    自旋-自旋相互作用 ← 库仑交换积分 ← α
    T_C ∝ J_ex/k_B — 决定了室温下磁性保持率

  居里温度 T_C:
    NdFeB: T_C ≈ 585 K, SmCo: T_C ≈ 1000 K
    室温剩磁保持率: B_r(T_room)/M_s(0K) ≈ 1 - (T_room/T_C)^(3/2)（近似）

--------------------------------------------------------------------
§2. 最大可能饱和磁化强度 M_s
--------------------------------------------------------------------

  M_s = n × μ_atom

  【纯3d金属的极限】
    晶体结构: bcc Fe (n=8.5×10²⁸ m⁻³), hcp Co (n=9.1×10²⁸), fcc Ni (n=9.1×10²⁸)
    Fe: 2.22 μ_B/atom → M_s = 1.76×10⁶ A/m → μ₀M_s = 2.21 T
    Co: 1.72 μ_B/atom → M_s = 1.45×10⁶ A/m → μ₀M_s = 1.82 T
    Fe₆₅Co₃₅ (Slater-Pauling峰): ~2.45 μ_B/atom
      n_FeCo ≈ 8.8×10²⁸ → M_s = 2.00×10⁶ → μ₀M_s = 2.51 T

  【4f-3d合金（稀土永磁）】
    Nd₂Fe₁₄B: 铁磁耦合, 总磁矩 = 14×2.2(Fe) + 2×3.3(Nd) ≈ 37.4 μ_B/f.u.
    单胞体积 V ≈ 0.94 nm³ → n_f.u. = 1/V = 1.06×10²⁷ m⁻³
    M_s = 37.4×9.274×10⁻²⁴×1.06×10²⁷ ≈ 3.68×10⁵ A/m/f.u. × ... 

    换个算法:
    Nd₂Fe₁₄B密度 ~7.5 g/cm³, 摩尔质量 ~1081 g/mol
    原子数密度 n ≈ (7.5/1081)×6.02×10²³×17 ≈ 7.1×10²⁸ atoms/m³
    平均磁矩 ≈ 37.4/17 ≈ 2.2 μ_B/atom
    → M_s ≈ 7.1×10²⁸×2.2×9.274×10⁻²⁴ ≈ 1.45×10⁶ A/m
    → μ₀M_s ≈ 1.82 T（实际测量 ~1.61 T，因为非完全共线）

  【SCVC绝对最大M_s（室温稳定）】
    约束1: 最高原子磁矩
      3d金属(Fe,Co): 最多 ~2.5 μ_B（Slater-Pauling峰，由能带填充锁死）
      4f稀土(Gd³⁺,Dy³⁺,Ho³⁺): Gd³⁺=7 μ_B, Dy³⁺=10 μ_B, Ho³⁺=10 μ_B
      但4f磁矩在室温下被热涨落大幅削弱（除非T_C很高）

    约束2: 最高原子密度
      最密堆积(fcc/hcp): n ≈ 9×10²⁸ m⁻³（由α→屏蔽→原子半径锁死）

    约束3: 室温保持率
      需要 T_C ≫ 300K。这要求强的交换耦合。
      3d-3d交换最强（Fe,Co: T_C~1000K），3d-4f次之，4f-4f最弱。
      → 室温永磁必须依赖3d交换。

  结论: 室温下最高M_s来自高浓度3d磁矩。
    M_s_max ≈ 2.45 μ_B × 9×10²⁸ m⁻³ × 9.274×10⁻²⁴ J/T
           ≈ 2.04×10⁶ A/m
    μ₀M_s_max ≈ 4π×10⁻⁷ × 2.04×10⁶ ≈ **2.57 T**

  这是任何材料在室温下可能达到的最高饱和磁化强度。

--------------------------------------------------------------------
§3. 到剩磁B_r — 各向异性和矫顽力的代价
--------------------------------------------------------------------

  B_r ≤ μ₀M_s（理论上限，100%剩磁=完美矩形回线）
  实际上: B_r ≈ μ₀M_s × (1 - 气孔率) × (取向度)

  NdFeB:
    μ₀M_s ≈ 1.61 T
    B_r_real ≈ 1.4 T（87% of M_s — 因气孔和取向不完美）
    理论B_r_max(NdFeB) = 1.61 T

  更高B_r的可能路径:
    Fe₆₅Co₃₅基永磁: μ₀M_s ≈ 2.51 T → B_r_max ≈ 2.5 T
    但FeCo缺乏各向异性(H_A低)→做不成永磁（矫顽力太低）

  SCVC绝对B_r天花板:
    **B_r_max ≈ 2.5-2.6 T**（需要同时实现最高M_s + 最高各向异性）

--------------------------------------------------------------------
§4. 最大磁能积 (BH)_max
--------------------------------------------------------------------

  (BH)_max ≤ B_r²/(4μ₀)（理论极限，完美矩形回线）

  ┌────────────────────┬──────────┬──────────┬──────────────┐
  │ 材料                │ B_r (T)  │ (BH)_max  │ 占SCVC天花板  │
  │                    │          │ (kJ/m³)  │              │
  ├────────────────────┼──────────┼──────────┼──────────────┤
  │ 铁氧体(SrFe₁₂O₁₉)  │ 0.4      │ 35       │ 2.7%         │
  │ Alnico             │ 0.8-1.3  │ 40-80    │ 3-6%         │
  │ SmCo₅              │ 0.9      │ 180      │ 14%          │
  │ Sm₂Co₁₇            │ 1.1      │ 240      │ 18%          │
  │ **NdFeB (商用)**    │ **1.4**  │ **474**  │ **36%**      │
  │ NdFeB (理论极限)    │ 1.61     │ 515      │ 39%          │
  │ FeCo基(如果可永磁)  │ 2.5      │ 1240     │ 95%          │
  │ **SCVC绝对天花板**  │ **2.57** │ **1313** │ **100%**     │
  └────────────────────┴──────────┴──────────┴──────────────┘

  SCVC绝对(BH)_max = (2.57)²/(4 × 4π×10⁻⁷)
                    = 6.60 / 5.027×10⁻⁶
                    = 1.313×10⁶ J/m³
                    = **1,313 kJ/m³**

§5. 为什么NdFeB远低于SCVC天花板？
--------------------------------------------------------------------

  差距不在M_s——在**各向异性**。

  永磁体需要: 高M_s + 高H_A + 高T_C。这是"不可能三角":

  ┌──────────┬──────────┬──────────┬──────────┐
  │          │ 高 M_s   │ 高 H_A   │ 高 T_C   │
  ├──────────┼──────────┼──────────┼──────────┤
  │ 3d金属   │ ✅✅✅   │ ❌       │ ✅✅     │
  │ (Fe,Co)  │ 2.2-2.5μB│ 几乎各向同性│ 1000K+  │
  ├──────────┼──────────┼──────────┼──────────┤
  │ 4f稀土   │ ✅✅     │ ✅✅✅   │ ❌       │
  │ (Nd,Sm,Dy)│ 3-10μB  │ 巨大MCA  │ 需3d耦合  │
  ├──────────┼──────────┼──────────┼──────────┤
  │ NdFeB    │ ✅✅     │ ✅✅     │ ✅       │
  │ (折中)   │ 1.61T    │ 7.5T(H_A)│ 585K     │
  └──────────┴──────────┴──────────┴──────────┘

  SCVC根源:
    3d电子: 轨道角动量被晶体场猝灭→低各向异性→矫顽力低
    4f电子: 轨道角动量未被猝灭→高各向异性→矫顽力高
    但4f-4f交换极弱→需靠3d-3d交换"拖动"
    → 所有高性能永磁都是3d-4f混合（稀土永磁）

  SCVC锁定: **没有单一元素能同时满足M_s+H_A+T_C。**
  这是α通过晶体场理论给出的硬约束。
  最高性能只能来自3d+4f的折中→NdFeB接近这个折中最优。

--------------------------------------------------------------------
§6. 无稀土永磁的上限
--------------------------------------------------------------------

  无稀土=纯3d金属（或3d+轻元素）。

  各向异性的替代来源:
    1. 形状各向异性: H_A_shape ≈ M_s/2 ≈ ~0.8 MA/m → 不够
    2. 应力各向异性: 受限于弹性极限 → 有限
    3. 表面/界面各向异性: 需要纳米结构 → 热稳定性差

  3d-金属磁性元素的H_A（磁晶各向异性场）:
    Fe (bcc): H_A ≈ 0.05 T → 不能做永磁
    Co (hcp): H_A ≈ 0.6 T → 勉强
    FeCo (bcc): H_A ≈ 0.05 T → 不能
    L1₀-FePt: H_A ≈ 10 T → 能做! 但成本极高
    L1₀-FeNi (tetrataenite): H_A ≈ 1-2 T → 有潜力但合成难

  无稀土永磁(BH)_max天花板:
    - 如果L1₀-FeNi可量产: B_r ≈ 1.0-1.5 T → (BH)_max ≈ 200-450 kJ/m³
    - 如果优化到极限: (BH)_max ≈ 300-500 kJ/m³（25-38% of SCVC绝对）
    - 永远不可能接近NdFeB的474 → 除非使用稀土

  SCVC判断:
    **无稀土永磁被物理锁死在 ~300-500 kJ/m³。**
    NdFeB的474在无稀土可达范围的边缘（仅限极端优化+稀有相）。
