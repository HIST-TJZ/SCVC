# SCVC工程极限：地热能量上限 — 地球热流+可及深度+可持续开采

> 所有推导基于SCVC速查表的常数。岩石热导率（声子传导→ℏω_D）、
> 岩石塑性温度（键能→蠕变）、Carnot效率（k_B T）共同锁定地热天花板。

---

## §1. 地球的热预算

### 1.1 热源构成

```
地球内部热源:
  ├─ 放射性衰变 (U, Th, K) : ~50% (~22 TW)
  │   → SCVC: α_s=1/(16π) 决定核结合能→衰变能
  │   → 半衰期: ²³⁸U 4.5 Gyr, ²³²Th 14 Gyr, ⁴⁰K 1.25 Gyr
  │
  └─ 残余形成热 (吸积+核形成) : ~50% (~22 TW)
      → 引力势能→热 (SCVC: G从π导出? 或独立常数)
```

### 1.2 地表热流

```
地球表面积: 5.1×10¹⁴ m² (5.1亿km²)
  海洋 (71%): ~0.101 W/m² → 36.5 TW
  大陆 (29%): ~0.065 W/m² → 9.6 TW
  ──────────────────────────────────
  全球总计:  ~0.087 W/m² → 44-47 TW
```

**44 TW 是全球地热的"自然补充率"。** 这相当于：
- 人类总用电量的 ~15倍
- 人类总能耗的 ~2.5倍
- 太阳入射功率(173,000 TW)的 ~0.026%

### 1.3 热流的SCVC起源

地球内部的热传导由声子（晶格振动）主导：

```
热导率 k = (1/3) × C_v × v_s × ℓ

C_v ∝ 原子密度 n ∼ 10²³ cm⁻³ (SCVC)
v_s ∝ √(E/ρ) ∝ √(E_bond/m_atom) (SCVC/E18)
ℓ   = 声子平均自由程 (受限于杂质+非谐散射)
     → 非谐散射来自ℏω_D ∼ 0.3-0.5 eV (SCVC)

地幔热导率: ~2-4 W/(m·K) (实验测定)
```

地球热流被SCVC锁定在~0.09 W/m²量级——这来自放射性核素的丰度（由超新星核合成→α_s）和地幔热导率（由键能→声子速度）。

## §2. 可及深度与温度

### 2.1 钻井深度约束

岩石在高温下变为塑性 → 无法维持裂缝（EGS必需）→ 无法有效换热：

```
岩石塑性转变温度 (SCVC推导):

T_plastic ≈ 0.10-0.15 × T_melt
          ≈ 0.10-0.15 × (E_bond / k_B)

Si-O键 ~4.5 eV → T_melt ~1500-2000 K
→ T_plastic ~400-600°C (673-873 K)
```

| 地温梯度 | T at 5 km | T at 10 km | 塑性极限深度 |
|----------|----------|-----------|------------|
| 正常 25°C/km | 140°C | 265°C | **~15 km** |
| 活跃 50°C/km | 265°C | 515°C | **~8 km** |
| 火山 80°C/km | 415°C | 815°C | **~5 km** |

**SCVC锁定：可及深度上限 ~5-15 km**（取决于地温梯度）。更深 → 岩石蠕变 → 井孔闭合 + 裂缝自愈合。

### 2.2 世界最深钻井

```
Kola SG-3 (俄罗斯, 1989): 12,262 m
  底部温度: ~180°C (低地温梯度 ~15°C/km)
  停止原因: 岩石塑性（非温度, 而是高压致密化）

KTB (德国, 1994): 9,101 m
  底部温度: ~265°C (27°C/km)

Chayvo (俄罗斯, 2017): 15,000 m (石油, 大斜度井)
  垂直深度: ~3,000 m, 非单纯垂深
```

## §3. 可持续开采的物理极限

### 3.1 热传导限制

地热不是"无限"的——持续抽取受限于岩石的热传导速率：

```
Q_max = k × ΔT / d

k: 岩石热导率 ~2.5 W/(m·K)
d: 裂缝间距 (EGS井间距)
ΔT: 裂缝-岩石温差
```

| EGS井间距 | 热通量 (W/m²) | 1 km²功率 (MW_th) | 100 km²功率 |
|----------|-------------|-------------------|------------|
| 100 m | 3.75 | 3.75 | 375 |
| 500 m | 0.75 | 0.75 | 75 |
| 1000 m | 0.38 | 0.38 | 38 |

**商业EGS需要~100 km²的地面面积才能产出几十MW电力。** 这是地热"能量密度低"的根本原因——SCVC锁定的岩石热导率无法改变。

### 3.2 Carnot效率上限

```
η_Carnot = 1 - T_cold / T_hot

T_cold = 20°C = 293 K
```

| 资源温度 | Carnot效率 | 实用效率 (~50% Carnot) |
|----------|-----------|----------------------|
| 150°C (常规地热) | 30.7% | **~15%** |
| 200°C | 38.1% | **~19%** |
| 250°C (冰岛) | 44.0% | **~22%** |
| 300°C | 48.9% | **~24%** |
| 400°C (干热岩上限) | 56.5% | **~28%** |

**SCVC锁定：Carnot效率由k_B T比决定。k_B由α推导。理论上限~55%，实用~15-28%。**

### 3.3 两种开采模式

**（A）可持续模式（不耗尽）：**

```
仅抽取自然热流 → 功率 = 大陆热流 × 收集效率 × 热电转换效率

大陆热流: ~10 TW_th
收集效率: ~20% (覆盖不到所有大陆)
热电效率: ~20%
─────────────────────────
可持续电力: ~0.4 TW = 400 GW

占全球电力(3 TW): ~13%
占全球总能耗(18 TW): ~2%
```

**（B）采矿模式（主动抽取 > 自然补充）：**

```
以50 TW_th速率抽取大陆热量 → 耗尽时间:

0-10 km大陆地壳热含量 ≈ 1.2×10²⁷ J
提取速率 50 TW → 寿命 ≈ 1.2×10²⁷ / (50×10¹²) / (3.15×10⁷)
                     ≈ 760 年

热电电力 = 50 × 0.20 ≈ 10 TW_electric
占全球电力: ~330%
```

**地热在采矿模式下可提供数个世纪的全球电力——但之后需要数百万年"充电"。**

## §5. 工程结论

### 5.1 地热在人类能源中的最大占比

| 模式 | 全球占比 (电力) | 全球占比 (总能耗) | 可持续？ |
|------|---------------|-----------------|---------|
| **当前 (2024)** | ~0.5% | ~0.1% | ✅ |
| **自然热流收集** | ~10-15% | ~2-3% | ✅ 永久 |
| **强化地热(EGS)** | ~30-50% | ~5-10% | ⚠️ 需管理 |
| **采矿模式上限** | **~300%** | **~50%** | ❌ 耗尽(数百年) |
| **SCVC绝对上限** | — | **~100%** (47 TW) | ❌ 技术上不可行 |

### 5.2 地热不是"无限能源"

```
储量: 巨大 (~10²⁷ J)  → 足够人类数百万年
速率: 有限 (~44 TW自然补充) → 仅够满足2.5倍总能耗
可及性: 受限 (深度+塑性+面积) → 实用远低于理论

SCVC锁定三个限制:
  ① 热导率 (~2.5 W/m·K, 来自声子速度+自由程)
  ② 塑性温度 (~400°C, 来自Si-O键能→蠕变激活能)
  ③ Carnot效率 (~15-28%, 来自k_B T比)
```

### 5.3 地热 vs 其他可再生能源

| 能源 | 全球潜力(TW_e) | SCVC天花板 | 优势 | 劣势 |
|------|--------------|-----------|------|------|
| 地热 | 0.4-10 | **~14** | 24/7基荷 | 地点受限 |
| 太阳光伏 | 20-50 | ~10,000 (E3天花板) | 无处不在 | 间歇性 |
| 风能 | 5-20 | ~100 (大气动力学) | 广泛 | 间歇性 |
| 核聚变 | >100 | 无上限 (SCVC允许) | 无限 | 未实现 |

**地热的独特价值：基荷电力。** 它是唯一不受天气/昼夜影响的可再生基荷。SCVC将其天花板设在~14 TW_电 → 足以覆盖当前全球电力，但需要全球规模的EGS开发。

### 5.4 SCVC地热极限总结

| 参数 | SCVC值 | 决定因子 | 备注 |
|------|--------|----------|------|
| 全球热流 | **~44 TW** | 放射性+残余热 | 相当于15×全球电力 |
| 可及深度 | **5-15 km** | 岩石塑性(键能→蠕变) | T>400°C岩石失稳 |
| 热导率限制 | **~0.38-3.75 W/m²** | k ∝ v_s ∝ √(E_bond/m) | 决定EGS面积需求 |
| Carnot效率 | **15-28%** | 1-T_cold/T_hot | 受k_B T约束 |
| 自然可持续电力 | **~0.4 TW** | 大陆热流×效率 | 人类电力的~13% |
| 采矿模式电力 | **~10 TW** | 可及深度×地温梯度 | 可维持数百年 |
| **SCVC绝对天花板** | **~14 TW_电** | 47 TW_th × 30% | 全地球热流的30% |

## 附录：SCVC推导链（地热）

```
π → α → ℏ, m_e → 键能 → 岩石性质
                      ↓
         ┌────────────┬──────────────┐
         ↓            ↓              ↓
    热导率(k)    蠕变温度(T)    Carnot效率
    ∝ v_s ∝      ∝ E_bond/k_B  ∝ 1-T_c/T_h
    √(E_bond/m)      ↓
         ↓       可及深度
    热补充率     ~5-15 km
    ↓              ↓
    └──────┬───────┘
           ↓
    可持续功率 = min(热流, 抽取速率)
           ↓
    自然: ~0.4 TW_e  采矿: ~10 TW_e
           ↓
    SCVC天花板: ~14 TW_e (全球47 TW_th × 30%)
```

**地热是巨大的但不是无限的。** SCVC告诉我们：自然补充率~44 TW是硬天花板，热导率和塑性温度锁死了开采速率。地热可以成为人类能源组合中重要的基荷部分(~10-30%电力)，但永远不可能像太阳能那样支撑全部需求。
