1. AAV 包装容量的物理根源
==============================================================

1.1 衣壳内腔的几何约束
--------------------------------------------------------------
    AAV 是已知最小的哺乳动物病毒之一:

    ┌──────────────────────────────────────────────────────────┐
    │ 衣壳几何参数:                                            │
    │                                                          │
    │ 外径 ≈ 25 nm (二十面体对称, T=1)                         │
    │ 衣壳蛋白壳厚度 ≈ 2.5 nm                                   │
    │ 内径 ≈ 20 nm                                              │
    │ 内腔体积 V_capsid ≈ (4π/3)×(10)³ ≈ 4190 nm³            │
    │                                                          │
    │ dsDNA 占据体积 (假设理想密堆积):                          │
    │ · DNA 视为半径 r ≈ 1 nm 的圆柱                           │
    │ · 每 bp 体积 ≈ π×(1)²×0.34 ≈ 1.07 nm³                  │
    │ · 理论最大包装: 4190/1.07 ≈ 3900 bp ≈ 3.9 kb            │
    │                                                          │
    │ 但实际包装到 ~4.7 kb → 密度超过理想密堆积!               │
    │ → DNA 在衣壳内以高度致密+有序的方式排列                   │
    │ → 这相当于 ~4.7/3.9 ≈ 120% 的理想密堆积密度              │
    └──────────────────────────────────────────────────────────┘

1.2 静电排斥 — 包装的"反抗力"
--------------------------------------------------------------
    DNA 是高度带电的分子: 每 bp 带 2 个负电荷 (磷酸基团)。

    在衣壳内, DNA 链段之间的距离被迫 < 2 nm →
    静电排斥能急剧上升:

    两条平行 DNA 段在距离 d 处的静电相互作用:
    U_elec ≈ (λ²/2πεε₀) × K₀(κd)

    λ ≈ 5.9 e⁻/nm (DNA 线性电荷密度)
    κ⁻¹ ≈ 0.8 nm (生理盐浓度下的 Debye 长度)
    K₀ ≈ 1-2 (在 d ≈ 1-2 nm 时)

    U_elec_per_length ≈ 1-3 k_B T/nm ≈ 0.03-0.08 eV/nm

    对于 4.7 kb 的 DNA (总长 ~1600 nm 轮廓长度):
    · 在衣壳内, DNA 弯曲 + 紧密排列
    · 有效相互作用长度 ~L × (堆积因子)
    · 总静电排斥能 U_total ≈ 50-200 eV

    ⚫ 这个排斥能必须由衣壳蛋白的机械强度 + 内部正电荷
      (VP1/VP2 N 端富含精氨酸, 中和 DNA 电荷) 来抗衡。
    ⚫ 增加到 5-6 kb → 静电排斥增加 ~20-30% → 接近衣壳强度极限。


2. 包装的物理天花板
==============================================================

2.1 三条物理限制线
--------------------------------------------------------------
    ┌──────────────────────────────────────────────────────────┐
    │                                                          │
    │  限制线 1: 几何体积                                       │
    │  · V_capsid ≈ 4200 nm³ → 理论最大 ~3.9 kb (理想密堆积)  │
    │  · 允许超密堆积 (内部蛋白帮助凝聚 DNA) → 可达 ~5.0 kb    │
    │  · 几何绝对天花板: ~5.5 kb (DNA占据 > 140% 衣壳体积)     │
    │                                                          │
    │  限制线 2: 静电排斥                                       │
    │  · DNA 电荷密度 → 包装力随长度指数增长                   │
    │  · 衣壳蛋白需要提供抵消力 (内部正电荷 + 机械强度)         │
    │  · ⚫ SCVC 估计: 在 ~5.0 kb 处静电排斥超过衣壳结合强度   │
    │                                                          │
    │  限制线 3: 弯曲能                                         │
    │  · DNA 持久长度 ~50 nm → 弯曲半径 < 10 nm → 弯曲能高    │
    │  · 弯曲能 ≈ κ/(2R²) per length → 在衣壳内显著            │
    │  · 更长的 DNA → 更致密 → 更小弯曲半径 → 更高弯曲能       │
    │  · 在 ~5.5 kb → 弯曲能超过衣壳可承受的构象应力           │
    ├──────────────────────────────────────────────────────────┤
    │ SCVC 综合: AAV 包装的物理天花板 ≈ 5.0-5.5 kb              │
    │ (当前 4.7 kb 已接近此上限 → 工程优化空间 ~5-15%)         │
    └──────────────────────────────────────────────────────────┘

2.2 能否工程化增大衣壳?
--------------------------------------------------------------
    ⚫ 理论可能: 使用更大的衣壳蛋白亚基 → 增大内腔
    ⚫ 实际挑战:
    · 衣壳自组装由亚基间互补界面决定 (H 键 + 范德华 + 疏水)
    · 改变亚基大小 → 界面不匹配 → 组装失败或结构不稳定
    · AAV 进化了几百万年才达到当前的优化构型
    · 工程化增大 10-20% → 需要重新设计所有亚基界面
    → 这是"蛋白质设计"的难题, 目前超出我们的能力。

    ⚫ 替代思路: 使用不同血清型或不同病毒的衣壳
    · AAV5, AAV9 等略有不同 (内腔大小相似)
    · 腺病毒 (~90 nm, ~36 kb) 或慢病毒 (~100 nm, ~8-10 kb)


3. 不同病毒载体的包装能力对比
==============================================================

3.1 从衣壳几何到包装容量的物理标度律
--------------------------------------------------------------
    ┌──────────┬──────────┬──────────┬──────────┬────────────┐
    │ 载体     │ 直径(nm) │ 内腔体积 │ 包装容量 │ 推导验证   │
    │          │          │ (nm³)    │ (kb)     │            │
    ├──────────┼──────────┼──────────┼──────────┼────────────┤
    │ AAV      │ 25       │ ~4200    │ 4.7      │ V∝kb^1.15 │
    │ 慢病毒   │ ~100     │ ~5×10⁵   │ 8-10     │ 衣壳不同   │
    │ 腺病毒   │ ~90      │ ~3×10⁵   │ 36       │ 非二十面体 │
    │ 疱疹病毒 │ ~200     │ ~4×10⁶   │ 150      │ 多层结构   │
    └──────────┴──────────┴──────────┴──────────┴────────────┘

    ⚫ 慢病毒包装容量大于 AAV 但远小于腺病毒 —
      因为慢病毒衣壳不是空的 — 内部有核衣壳蛋白 (NC)
      占据大量空间 → 实际可用体积远小于几何体积。

    ⚫ 腺病毒没有严格的二十面体对称 →
      衣壳可以更大 (更多蛋白亚基) + 内部无核衣壳蛋白
      → 包装容量大 ~8 倍。

    ⚫ SCVC 标度律: 包装容量 ∝ 内腔有效体积 ∝ 直径³ × 填充效率
      AAV 填充效率 ~120% (超密堆积)
      腺病毒填充效率 ~40% (低密度+内部蛋白占用)


4. 超越 AAV 天花板 — 工程策略
==============================================================

4.1 双 AAV 策略 (Split Gene)
--------------------------------------------------------------
    将大基因分成两半, 包装在两个 AAV 中, 共转导同一细胞:

    方案 A: 反式剪接 (trans-splicing)
    · AAV1: 启动子 + 前半基因 + 剪接供体
    · AAV2: 剪接受体 + 后半基因 + polyA
    · 在细胞内: 两个 pre-mRNA 通过剪接体连接
    · 效率: ~5-15% 的完整蛋白表达 (vs 单 AAV 的 80-100%)

    方案 B: 同源重组
    · AAV1 + AAV2 在重叠区域进行同源重组 → 完整基因
    · 效率: ~1-5% (极低, 重组是罕见事件)

    方案 C: 蛋白质反式剪接 (intein)
    · 两个半蛋白通过 intein 介导的蛋白质剪接连接
    · 效率: ~10-30%

    ⚫ SCVC 评估:
      双 AAV 在物理上完全可行, 但效率远低于单 AAV。
      对于需要高表达的治疗 (如 dystrophin 在 DMD 中),
      双 AAV 的低效率可能是限制因素。
      但"微 dystrophin" (<4 kb) 已解决 DMD 问题 —
      这是一种"删减功能域但保留核心功能"的策略。

4.2 非病毒替代 — LNP (脂质纳米颗粒)
--------------------------------------------------------------
    mRNA 疗法 (如 COVID 疫苗) 使用 LNP 递送:

    ┌──────────────────────────────────────────────────────────┐
    │ LNP 优势:                                                │
    │ · 无包装容量限制 (mRNA 可达 ~10 kb+)                     │
    │ · 无预存免疫 (非病毒)                                    │
    │ · 可重复给药 (AAV 因中和抗体不能重复)                    │
    │                                                          │
    │ LNP 劣势:                                                │
    │ · 瞬时表达 (mRNA 半衰期 ~数小时-数天)                    │
    │ · 肝脏偏向 (LNP 主要去肝脏, 除非工程化靶向)              │
    │ · 免疫原性 (LNP 本身诱导炎症)                            │
    │                                                          │
    │ ⚫ 对于需要"一次性永久纠正"的基因病: AAV 更优             │
    │ ⚫ 对于需要"定期给药"或"大基因": LNP/非病毒更优           │
    └──────────────────────────────────────────────────────────┘

4.3 CRISPR 递送的特殊考量
--------------------------------------------------------------
    CRISPR-Cas9 系统对递送的要求:
    · SpCas9 (~4.2 kb) + gRNA (~0.1 kb) ≈ 4.3 kb
    · → 刚好塞进 AAV (~4.7 kb 限制, 包括启动子+polyA!)
    · → 实际上: 启动子(0.5 kb) + Cas9(4.2 kb) + polyA(0.2 kb) ≈ 4.9 kb
    · → 超出 AAV 包装极限!

    解决方案:
    · 使用更小的 Cas 变体: SaCas9 (~3.2 kb), CjCas9 (~3.0 kb)
    · 或双 AAV 递送 Cas9
    · 或 LNP 递送 Cas9 mRNA → 绕过包装限制

E180 结论
====================================================================

  ⚫ AAV 内腔 ~4200 nm³ → DNA 理想密堆积 ~3.9 kb
  ⚫ 实际包装 4.7 kb (超密堆积 120%) → 静电排斥+弯曲能已近极限

  ⚫ 更小 Cas 变体 + 微基因策略 → 物理约束内的最优解
