【输入常数】(来自_SCVC工程常数速查表.md)
--------------------------------------------------------------
脂双层厚度 ≈ 5 nm (疏水核心 ~3 nm)
膜蛋白紧密连接: claudin, occludin, JAM, ZO-1
紧密连接链间接触: H键 + vdW — 链间距 ~0.5-1 nm
H 键去溶剂化成本 ≈ 0.2 eV/H键 (从 α → 水-膜界面能)
分子扩散系数 D_mem ∝ exp(-ΔG_partition/k_B T)
P-gp (外排泵): ATP 结合盒转运体 → ATP≈0.3 eV → 驱动主动外排
受体介导转胞吞: TfR, IR, LRP1 等 → 配体-受体结合能 ~1-2 eV
k_B T = 0.026 eV (310K)
脑内皮细胞面积 ≈ 20 m² (人脑毛细血管总表面积!)
α = 1/137.0363

1. 血脑屏障的物理结构
==============================================================

1.1 三道防线
--------------------------------------------------------------
    ┌──────────────────────────────────────────────────────────┐
    │                                                          │
    │  防线 1: 紧密连接 (Tight Junctions)                       │
    │  · 内皮细胞间无间隙 (vs 其它组织 5-50 nm 间隙)           │
    │  · Claudin-5 富集 → 同源二聚化 → 链状密封               │
    │  · 链间 H 键 (~0.2 eV/键) + vdW → 总结合 ~5-10 eV/链    │
    │  · 等效孔径 < 1 nm → 阻挡几乎所有水溶性分子              │
    │  · 跨内皮电阻 (TEER) ~1500-2000 Ω·cm² (其它组织 ~2-20)   │
    │                                                          │
    │  防线 2: 外排泵 (Efflux Pumps)                            │
    │  · P-gp (MDR1): ATP 驱动 → 识别亲脂底物 → 泵回血液      │
    │  · BCRP: 类似功能, 不同底物谱                            │
    │  · 底物结合能 ~0.5-1.0 eV → 理论可达 ~10¹⁰ 倍富集       │
    │  · 实际泵出效率 ~90-99% (单次通过)                       │
    │                                                          │
    │  防线 3: 代谢酶屏障                                       │
    │  · CYP450, MAO, COMT 等 → 在内皮细胞中降解药物            │
    │  · 不是"阻挡", 是"消灭"                                   │
    └──────────────────────────────────────────────────────────┘


2. 被动扩散的物理阈值 — 什么能穿过?
==============================================================

2.1 去溶剂化 — H键的核心代价
--------------------------------------------------------------
    分子从水环境进入脂双层的核心代价是"去溶剂化":

    每个 H 键供体/受体在水中被水分子包围 (形成 H 键):
    · 水-溶质 H 键 ≈ 0.2 eV/键
    · 进入脂双层 → 打破这些 H 键 → 无新伙伴 (脂质无 H 键供体/受体)
    · → 每个 H 键基团去溶剂化代价 ≈ 0.2 eV

    总去溶剂化能 ΔG_desolv ≈ N_HB × 0.2 eV
    分配系数 P ∝ exp(-ΔG_desolv/k_B T)

    ┌──────────────────────────────────────────────────────────┐
    │ N_HB (H键供体+受体总数)   ΔG_desolv (eV)    P (相对)    │
    │ ─────────────────────────────────────────────────────    │
    │ 0                      ≈ 0            1.0              │
    │ 2                      ≈ 0.4          2.1×10⁻⁷         │
    │ 4                      ≈ 0.8          4.4×10⁻¹⁴        │
    │ 6                      ≈ 1.2          9.1×10⁻²¹        │
    │ 8                      ≈ 1.6          1.9×10⁻²⁷        │
    │ 10                     ≈ 2.0          3.9×10⁻³⁴        │
    │                                                          │
    │ ⚫ N_HB > 8 → 通透率降至 ~10⁻²⁷ → 在生理时间尺度上      │
    │   相当于"零通透"                                          │
    │ ⚫ N_HB ≤ 5 → 仍可有可测量的被动扩散                      │
    │ ⚫ 这是 CNS 药物的"H 键上限"的物理根源!                    │
    └──────────────────────────────────────────────────────────┘

2.2 Lipinski/BBB 规则的物理验证
--------------------------------------------------------------
    ┌────────────────────┬──────────┬────────────────────────┐
    │ 经验规则           │ 数值     │ SCVC 物理推导          │
    ├────────────────────┼──────────┼────────────────────────┤
    │ MW < 400-500 Da   │ ~450 Da  │ 分子大小 → D∝1/√MW    │
    │                    │          │ + 去溶剂化表面积↑     │
    │ logP 2-5           │ 1-4      │ 过亲脂 → 困于膜中     │
    │                    │          │ 过亲水 → 无法进入膜    │
    │ HBD (H键供体) < 3  │ 0-2      │ 每个 ~0.2 eV 代价     │
    │ HBA (H键受体) < 7  │ 2-5      │ 同上 (但代价较低)     │
    │ N_HB_total < 8     │ 3-7      │ >8 → 物理上无法通过   │
    │ PSA < 60-90 Å²    │ ~70 Å²   │ 极性表面→去溶剂化↑   │
    │ 可旋转键 < 8       │ ~5       │ 构象熵 → 膜中适应↓   │
    └────────────────────┴──────────┴────────────────────────┘

    ⚫ SCVC 验证: 经验规则非常接近物理极限!
    ⚫ 这些不是"可优化的工程参数" — 它们是物理定律的直接后果。
    ⚫ 任何分子如果违反上述任一规则 → 穿透 BBB 的概率可忽略。


3. 各类分子的 BBB 穿透地图
==============================================================

3.1 小分子药物 — 在物理约束内设计
--------------------------------------------------------------
    ┌──────────────────────────────────────────────────────────┐
    │ CNS 药物设计的物理空间 (SCVC 优化指南):                    │
    │                                                          │
    │  ✅ 好:                                                   │
    │  · MW 300-450 Da → 扩散速率+去溶剂化平衡                 │
    │  · logP 2-4 → 膜分配+水溶解度平衡                        │
    │  · N_HB ≤ 5 → 去溶剂化代价可接受                         │
    │  · 刚性分子 → 低构象熵 → 更易插入膜                       │
    │  · PSA < 70 Å² → 极性面积可控                            │
    │                                                          │
    │  ❌ 差:                                                   │
    │  · MW > 500 Da → 扩散太慢                                │
    │  · logP > 5 → 困在膜中, 高血浆蛋白结合                   │
    │  · N_HB > 8 → 物理上无法通过                              │
    │  · 高度柔性分子 → 膜中构象代价大                          │
    │  · 带电基团 (除非可掩蔽) → 去溶剂化代价极高               │
    │                                                          │
    │  ⚫ 可优化参数 vs 物理墙:                                  │
    │    · logP: 可通过修饰侧链调控 ← 可工程化                  │
    │    · MW: 由药效团决定 ← 部分可工程化                      │
    │    · N_HB: 由靶点结合需求决定 ← 不可回避                  │
    │    · → 如果靶点要求 >8 个 H 键 → 该分子不适合口服 CNS 药 │
    └──────────────────────────────────────────────────────────┘

3.2 大分子 — 必须走"后门" (转胞吞)
--------------------------------------------------------------
    ┌────────────────┬──────────┬──────────────┬────────────┐
    │ 分子类型       │ 大小     │ 被动扩散?    │ 转胞吞可能?│
    ├────────────────┼──────────┼──────────────┼────────────┤
    │ 多肽 (2-10 aa) │ ~0.3-1kDa│ 部分可能     │ 受体靶向   │
    │ 小蛋白         │ 5-20 kDa │ ★☆☆☆☆        │ ★★★☆☆     │
    │ 抗体 (~150kDa) │ 150 kDa  │ ☆☆☆☆☆        │ ★★★☆☆     │
    │ 酶替代疗法     │ 50-500kDa│ ☆☆☆☆☆        │ ★★☆☆☆     │
    │ AAV (~25 nm)   │ ~4×10³kDa│ ☆☆☆☆☆       │ ★☆☆☆☆     │
    │ 脂质体/LNP     │ 50-200nm │ ☆☆☆☆☆        │ ★★☆☆☆     │
    └────────────────┴──────────┴──────────────┴────────────┘

    ⚫ 大分子必须通过受体介导转胞吞 (RMT):

    机制:
    · 配体 (如转铁蛋白) 结合内皮细胞腔面的受体 (如 TfR)
    · 受体-配体复合物内化 → 内体穿越细胞 → 脑侧释放
    · 效率受限于: 受体密度 (~10³-10⁴/细胞) + 内化速率 + 回收率

    转胞吞天花板:
    · 每次循环转运 ~1-10 个分子/受体
    · 受体总数 ~10¹²-10¹³ (整个脑内皮)
    · 最大转运速率 ~10⁴-10⁶ 分子/s (全身)
    · 对于抗体 (~150 kDa): 理论最大脑摄取 ~0.1-1% 的注射剂量
    · ⚫ 实际观察: ~0.1-0.5% → 已接近物理天花板!


4. P-gp 外排泵 — 为什么很多 CNS 候选药失败?
==============================================================

4.1 P-gp 的物理机制
--------------------------------------------------------------
    P-gp 是 ATP 结合盒 (ABC) 转运体:
    · 2 个 ATP 水解 (各 0.3 eV) → 提供 ~0.6 eV/转运周期
    · 底物结合能 ~0.5-1.0 eV (疏水+vdW+H键)
    · → 可以主动将底物从 ~nM (脑侧) 泵回 ~μM (血侧)

    P-gp 惊人的底物谱:
    · 识别范围极广 (亲脂 + 分子量 300-1500 Da + H键受体 > 2)
    · → 几乎是"亲脂分子过滤器"
    · 进化目的: 保护大脑免受环境毒素 (植物生物碱等)

4.2 P-gp 对 CNS 药物开发的物理约束
--------------------------------------------------------------
    ┌──────────────────────────────────────────────────────────┐
    │ 策略 1: 避开 P-gp 识别                                     │
    │ · 设计不被 P-gp 识别的分子 (MW < 300, 低 HBA)             │
    │ · ⚫ SCVC: 有效, 但限制化学空间                            │
    │                                                          │
    │ 策略 2: P-gp 抑制剂联合给药                                 │
    │ · 如 elacridar, tariquidar → 抑制 P-gp                    │
    │ · ⚫ SCVC: 有效增加脑摄取, 但增加全身毒性                  │
    │   (其它组织的 P-gp 也被抑制 → 化疗药等进入敏感组织)        │
    │                                                          │
    │ 策略 3: 前药策略 (掩蔽 H 键)                               │
    │ · 酯化/酰胺化极性基团 → 减少 H 键 → 增加膜渗透            │
    │ · 进入脑后 → 酯酶/酰胺酶释放活性药物                      │
    │ · ⚫ SCVC: 优雅的物理化学策略 (如 L-DOPA → 多巴胺)        │
    │                                                          │
    │ 策略 4: "特洛伊木马" (分子绑架 RMT)                        │
    │ · 药物偶联转铁蛋白或抗 TfR 抗体 → 劫持 RMT 通路          │
    │ · ⚫ SCVC: 最有前景的大分子策略                            │
    │   · 但递送效率受转胞吞天花板限制 (~0.1-1%)               │
    └──────────────────────────────────────────────────────────┘


5. 超声/微泡打开 BBB — 物理安全窗口
==============================================================

5.1 聚焦超声 + 微泡 (FUS+MB) 的物理
--------------------------------------------------------------
    微泡在超声场中振荡 → 对邻近毛细血管壁施加机械力:

    · 稳态空化 (stable cavitation): 微泡稳定振荡 → 推拉内皮细胞
    · → 紧密连接暂时分开 → 间隙 ~20-50 nm → 持续 ~4-6 小时
    · → 药物/抗体/AAV 可通过 → 治疗窗打开!

    紧密连接的 H 键 (~0.2 eV/键) + vdW → 总链间结合 ~5-10 eV
    微泡机械力 → 局部应力 → 克服链间结合 → 暂时分离

    ⚫ SCVC 计算安全窗口:
    · 需要克服的链间结合: ~5-10 eV → ~10⁻¹⁸-10⁻¹⁷ J/链
    · 微泡施加的力: ~10⁻¹²-10⁻¹⁰ N (声压 ~0.1-1 MPa × 微泡面积)
    · → 超过链间结合力 → 暂时打开
    · 但: 如果力太大 → 毛细血管破裂 → 微出血
    · 安全窗口: 声压 0.2-0.5 MPa, 频率 ~0.2-1 MHz, 脉冲 ~10 ms

E181 结论
====================================================================

  ⚫ H 键数 > 8 → 被动扩散物理上不可能 (去溶剂化 > 1.6 eV)
  ⚫ Lipinski/BBB 规则已接近物理极限 → 不是可优化的经验参数
  ⚫ MW+logP 可工程化, N_HB 由靶点决定 → 是真正的硬约束
  ⚫ P-gp 是"亲脂分子过滤器" → 避开或抑制 (但毒性)
  ⚫ 大分子必须走转胞吞 → 递送天花板 ~0.1-1% 注射剂量
  ⚫ FUS+微泡是最直接的物理开门策略 → 安全窗口窄但可行
  ⚫ CNS 药物设计 = 在物理约束的狭窄走廊中导航
