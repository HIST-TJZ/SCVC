--------------------------------------------------------------
DNA 聚合酶保真度 → 突变率 ≈ 10⁻⁹/碱基/代     (α → H键识别能)

1. 突变率 — α 的物理约束
==============================================================

1.1 聚合酶保真度
--------------------------------------------------------------
    DNA 聚合酶的错误率 ≈ 10⁻⁵/碱基 (插入错误)
    3→5 外切校对 → 降低 ~100× → 10⁻⁷
    错配修复 (MMR) → 再降 ~100× → 10⁻⁹
    → 净突变率 ≈ 10⁻⁹/碱基/细胞分裂

    ⚫ SCVC 根源:
      碱基对的 H 键能 (A=T: ~0.2 eV, G≡C: ~0.3 eV)
      → 聚合酶通过 H 键识别区分正确/错误碱基
      → α 设定电负性 → H 键强度 → 保真度
      → 10⁻⁹ 是 α=1/137 的直接物理后果

    ⚫ 癌症"突变体表型" (MMR 缺陷):
      突变率 → 10⁻⁷-10⁻⁵ → 加速 100-10,000×
      → 但 MMR 缺陷本身也是突变 → 需要时间积累!


2. 驱动突变的积累时间
==============================================================

2.1 需要多少个驱动突变?
--------------------------------------------------------------
    经典模型 (结肠癌: Vogelstein):
    APC → KRAS → SMAD4 → TP53 → ...
    需要 ≥ 4-6 个驱动突变才能完成恶性转化。

    靶基因总大小 ≈ 10⁶ bp (数百个驱动基因, 每个 ~1000 bp 关键区)
    每代驱动突变率 = 10⁻⁹ × 10⁶ = 0.001/代
    → 平均 ~1000 代产生一个驱动突变

2.2 不同组织的癌变时间
--------------------------------------------------------------
    组织          干细胞分裂率      驱动突变间隔      5 步累积时间
    ──────────────────────────────────────────────────────────────
    结肠           1/天 (~365/年)    ~3 年             ~15-20 年
    皮肤 (基底)    0.03/天 (~10/年)  ~100 年           ~500 年(!)
    骨髓 (造血)    1/天              ~3 年             ~15-20 年
    肺 (极少分裂)  极少              ~数十年            >100 年
    ──────────────────────────────────────────────────────────────

    ⚫ 但皮肤癌和肺癌确实存在 — 因为它们有"加速器":
      · 紫外线 → DNA 损伤 → 突变率 ↑ 100-1000×
      · 吸烟 → 苯并[a]芘 → DNA 加合物 → 突变率 ↑
      · 慢性炎症 → 活性氧 → DNA 损伤 → 突变率 ↑

    ⚫ 没有外部诱变剂的组织:
      癌症发病率与干细胞分裂次数完美相关 (Tomasetti-Vogelstein 2015)。
      → SCVC 直接预测这个相关性!

2.3 克隆扩增的额外时间
--------------------------------------------------------------
    每个驱动突变发生后, 突变的干细胞需扩增到可检测:

    1 → 10⁶ 细胞: log₂(10⁶) ≈ 20 次倍增
    干细胞倍增时间 ≈ 3-7 天 (in vivo)
    → 每次扩增 ≈ 2-6 个月

    5 步 → 5 × 4 个月 ≈ 1.7 年 (扩增) + 15 年 (等待突变) ≈ 17 年

    ⚫ 这与结肠癌从第一个 APC 突变到临床检测 (~15-30 年) 一致!


3. 儿童癌症为何罕见?
==============================================================

    儿童癌症需要:
    (a) 遗传易感 (生殖系突变 → 一个驱动已经就位)
    (b) 更少的驱动突变总数 (如视网膜母细胞瘤仅需 2 次打击)
    (c) 发育期间的高分裂率 (生长中的组织)

    视网膜母细胞瘤 (Rb):
    · 遗传型: 一个 Rb 等位基因已经失活 (生殖系)
    · 视网膜发育期间: 大量细胞分裂 → 第二个等位基因的
      LOH (杂合性丢失) 概率 ~10⁻⁴-10⁻⁵/代
    · 在 10⁶ 个视网膜祖细胞中 → 几乎必然有一个发生 LOH
    · → 可在 < 2 岁时发病

    ⚫ 儿童癌症 = 起步早 (遗传) + 步数少 + 窗口期短
    ⚫ 只要步数 > 3 → 几乎不可能在儿童期发生

==============================================================

====================================================================
E169 结论
====================================================================

  ⚫ 突变率 10⁻⁹/碱基/代 是 α 锁定的物理常数 — 无法降低
  ⚫ 结肠癌 ~15-20 年积累期 → 筛查的物理基础
  ⚫ 儿童癌症 = 遗传起步 + 少步数 + 发育高分裂
  ⚫ "治愈所有癌症"不可能 → "管理到老死"是物理可达目标
