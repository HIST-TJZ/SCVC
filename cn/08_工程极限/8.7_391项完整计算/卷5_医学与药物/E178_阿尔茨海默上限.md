1. 聚集的物理驱动力 — 从 α 到淀粉样蛋白
==============================================================

1.1 Aβ42 的"聚集倾向"的物理根源
--------------------------------------------------------------
    Aβ42 序列 (1-42): DAEFRHDSGYEVHHQKLVFFAEDVGSNKGAIIGLMVGGVVIA

    ⚫ 聚集驱动力分解:

    ┌──────────────────────┬──────────────┬──────────────────┐
    │ 驱动力               │ 涉及残基     │ 每个贡献 ~ΔG     │
    ├──────────────────────┼──────────────┼──────────────────┤
    │ 疏水核心 (17-21)     │ LVFFA        │ ~0.8 eV          │
    │   (埋藏面积~400 Å²) │              │ (5个疏水侧链)    │
    │ C端疏水区 (29-42)   │ GAIIGLMVGGVVIA│ ~1.0 eV         │
    │   (埋藏面积~500 Å²) │              │ (8个疏水侧链)    │
    │ 芳香π-π堆积 (F19,   │ F19-F19      │ ~0.1-0.3 eV/对   │
    │   F20, Y10)          │ F20-F20      │                  │
    │ 主链H键 (β-折叠)    │ 沿纤维轴     │ ~0.2 eV/残基     │
    │   (每层~2-3 H键)    │              │ ×~10残基=~2 eV  │
    │ 侧链H键/盐桥        │ D23-K28等    │ ~0.3 eV          │
    ├──────────────────────┼──────────────┼──────────────────┤
    │ 单体→寡聚体 ΔG     │              │ ≈ -2 到 -3 eV    │
    │ 寡聚体→原纤维 ΔG   │              │ ≈ -2 到 -4 eV    │
    │ 原纤维→成熟纤维 ΔG │              │ ≈ -5 到 -10 eV   │
    └──────────────────────┴──────────────┴──────────────────┘

    ⚫ 成熟纤维的 ΔG_total ≈ -10 到 -15 eV/单体
    ⚫ 换算为 K_eq ≈ exp(ΔG/k_B T) ≈ exp(15/0.026) ≈ 10²⁵⁰
    ⚫ → 成熟纤维的解离在动力学上几乎不可能 (在寿命内)


2. 聚集级联 — 可逆→不可逆的物理过渡
==============================================================

3. 小分子干预的物理上限
==============================================================

3.1 小分子抑制剂的最大可能亲和力
--------------------------------------------------------------
    ⚫ 小分子药物 (~200-500 Da) 对蛋白质的最大结合亲和力
    受限于其接触面积:

    最大可埋藏面积: ~300-500 Å² (小分子的"展开面")
    疏水贡献: 500 Å² × 0.02 eV/Å² ≈ 10 eV? — 太高了!

    实际限制: 溶剂化/去溶剂化平衡
    · 每个极性原子 → 去溶剂化代价 ~0.2 eV
    · 每个非极性原子 → 去溶剂化收益 ~0.02 eV/Å²
    · → 最优 logP 平衡 → ΔG_min ≈ -0.7 到 -0.8 eV

    ⚫ 对应的 K_D ≈ 10⁻¹² 到 10⁻¹³ M — 这是小分子药物的物理天花板!

    ┌──────────────────────────────────────────────────────────┐
    │                                                          │
    │  问题: -0.8 eV 足够竞争纤维的 -15 eV/单体吗?              │
    │                                                          │
    │  答案: 不 — 但不需要!                                     │
    │                                                          │
    │  · 小分子不需要"解聚纤维" — 只需要"阻止单体加入"         │
    │  · 阻止加入需要的亲和力: 仅需 ≥ 纤维末端的单体结合能      │
    │  · 纤维末端的单体结合: ΔG ≈ -2 到 -3 eV (单层)           │
    │  · 小分子亲和力天花板 -0.8 eV << -2 eV → 不可靠竞争!     │
    │                                                          │
    │  ⚫ SCVC 结论:                                            │
    │    小分子无法通过直接竞争阻止纤维延伸。                    │
    │    抗体 (～ -2 到 -3 eV 的亲和力) 可以 —                   │
    │    但需要识别构象表位, 且对纤维内部无效。                 │
    └──────────────────────────────────────────────────────────┘

3.2 抗 Aβ 抗体为什么部分有效但未治愈?
--------------------------------------------------------------
    Aducanumab, Lecanemab, Donanemab 等抗 Aβ 抗体:

    ⚫ 物理机制:
    · 抗体优先结合寡聚体和原纤维 (可及的表位)
    · ΔG_antibody ≈ -2 到 -3 eV → 比小分子强 10²-10⁵ 倍
    · 结合后 → 小胶质细胞 Fc 受体识别 → 吞噬清除
    · → 清除"可及的"Aβ 池

    ⚫ 为什么不能治愈:
    · 斑块内部的 Aβ 不可及 (抗体太大, ~150 kDa)
    · 细胞内 Aβ (高尔基体/内体中产生) → 抗体不可及
    · Tau 病理独立进展 → 即使 Aβ 清除, tau 仍在扩散
    · 神经元已经死亡 → 不可再生

    ⚫ SCVC 评估:
      抗 Aβ 抗体可以将疾病进展减缓 ~25-35% —
      但这受限于"可及性物理墙"和"tau 独立进展"。


4. Tau 的同类分析 — 为什么更难?
==============================================================

4.1 Tau 聚集的物理特征
--------------------------------------------------------------
    Tau 是微管结合蛋白, 在 AD 中过度磷酸化 → 脱离微管 → 聚集。

    ⚫ Tau 纤维比 Aβ 更稳定:
    · Tau 纤维核心 ~90 个残基/单体 (vs Aβ ~30 个)
    · 更多 H 键 + 更多疏水接触
    · ΔG_tau_fibril ≈ -20 到 -30 eV/单体
    · → 物理上更加不可逆!

    ⚫ Tau 病理可以独立于 Aβ 传播:
    · Tau 纤维可以"种子化" — 诱导正常 tau 聚集
    · 这类似于朊病毒的传播机制
    · 关键: tau 种子可以从一个神经元传到另一个 (跨突触!)
    · → 清除 Aβ 不能阻止 tau 扩散

4.2 干预 Tau 的物理窗口
--------------------------------------------------------------
    ┌──────────────────────────────────────────────────────────┐
    │ 策略 1: 阻止磷酸化 → 阻止 tau 脱离微管                    │
    │ · GSK-3β 抑制剂, CDK5 抑制剂                             │
    │ · ⚫ SCVC: 磷酸化是酶促的 → 可逆 → 物理上可行             │
    │ · 但: 这些激酶有其它底物 → 副作用                         │
    │                                                          │
    │ 策略 2: 阻止 tau 纤维种子传播                               │
    │ · 抗 tau 抗体 (如 semorinemab) → 结合细胞外 tau 种子     │
    │ · ⚫ SCVC: 细胞外 tau 种子可及 → 抗体可达                 │
    │ · 但: 细胞内 tau → 抗体不可及                             │
    │ · 大部分 tau 病理在细胞内 → 这是核心障碍                   │
    │                                                          │
    │ 策略 3: 增强 tau 降解 (自噬/蛋白酶体)                      │
    │ · mTOR 抑制剂 (雷帕霉素) → 自噬增强                       │
    │ · ⚫ SCVC: 可清除可溶性 tau, 但纤维化 tau 抗降解          │
    │ · 一旦形成纤维 → 蛋白酶体无法处理 (太大+太稳定)          │
    │                                                          │
    │ ⚫ SCVC 结论:                                              │
    │   Tau 聚集一旦开始就极难逆转。                             │
    │   干预必须极早期 — 磷酸化阶段 — 纤维形成后几乎无解。     │
    └──────────────────────────────────────────────────────────┘

E178 结论
====================================================================

  ⚫ Aβ寡聚体→原纤维→纤维→斑块: ΔG从-2 eV堆到-15 eV
  ⚫ 寡聚体阶段: 热力学可逆, 动力学极慢 → 关键干预窗口!
  ⚫ 成熟纤维: ΔG≈-15 eV/单体 → 物理上不可逆 (t₁/₂ > 宇宙年龄)
  ⚫ 小分子亲和力天花板 ≈ -0.8 eV → 无法竞争纤维延伸
  ⚫ 抗体可达 -2 到 -3 eV → 可结合可及寡聚体/原纤维 → 但非纤维内部
  ⚫ Tau 更糟: 纤维ΔG≈-30 eV, 且细胞内 + 跨突触传播
  ⚫ 干预逻辑: 必须在 -10 到 -5 年前刹车 (需要极早期诊断+预防)
