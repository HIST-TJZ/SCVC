==============================================================

    真菌病死亡 ~150 万/年 vs 细菌病死亡 ~770 万/年。
    不是真菌"不想"感染人类 — 是 37°C 对它们来说太热了。

2. 真菌蛋白质热不稳定 — SCVC 的物理根源
==============================================================

2.1 为什么真菌蛋白 Tm 比哺乳动物低 10-15°C?
--------------------------------------------------------------
    Tm = ΔH / ΔS

    ΔH (去折叠焓 — 稳定蛋白的键能):
    
    来源              哺乳动物 (每残基)      真菌 (每残基)
    ─────────────────────────────────────────────────────
    主链 H 键          ~0.25 eV              ~0.25 eV (相同)
    侧链 H 键          0.8-1.2               0.5-0.8 (少 ~30%)
    疏水核心           1.0-1.5               0.6-1.0 (少 ~35%)
    盐桥              0.3-0.5               0.1-0.3 (少 ~50%)
    ─────────────────────────────────────────────────────
    总计               ~2.3-3.5 eV/残基       ~1.5-2.4 eV/残基

    300 残基蛋白: ΔH_mammal ~700-1050 eV, ΔH_fungus ~450-720 eV

    ⚫ 真菌蛋白的稳定化能量少 ~30-40% → ΔH 更低 → Tm 更低!

2.2 为什么真菌蛋白"省了"这些稳定化?
    ⚫ 进化原因:
    · 土壤温度 25-30°C → 不需要高 Tm → 
      没有选择压力来维持高密度 H 键网络
    · 在低温下, 蛋白质需要更多柔性 (催化需要构象变化) →
      太多稳定化 = 太刚性 = 低活性 (E184 的权衡!)
    · 所以真菌选择了"柔性高, 活性高, Tm 低"的策略

    ⚫ 哺乳动物选择了相反的策略:
    · 恒温 37°C → 需要 Tm > 55°C → 
      进化压力推向高密度 H 键 + 大疏水核心 + 多盐桥
    · 代价: 蛋白质更刚性 → 但恒温提供了稳定的工作温度 →
      不需要柔性来适应温度波动

    ⚫ 这就是"同一个物理 (E184 活性-稳定性权衡)" 
      在进化上的不同答案!

2.3 37°C 下真菌蛋白的边际稳定性 — 定量
--------------------------------------------------------------
    真菌蛋白 Tm ≈ 42°C (315 K), 哺乳动物 Tm ≈ 55°C (328 K)

    在 37°C (310 K):
    真菌: ΔG(310K) = ΔH × (1 - 310/315) = ΔH × 0.016
          对于 ΔH ≈ 600 eV → ΔG ≈ 9.6 eV ≈ 0.032 eV/残基
    
    哺乳动物: ΔG(310K) = ΔH × (1 - 310/328) = ΔH × 0.055
          对于 ΔH ≈ 900 eV → ΔG ≈ 49.5 eV ≈ 0.165 eV/残基

    ⚫ 真菌蛋白的折叠稳定性: ~10 eV/蛋白
    ⚫ 哺乳动物蛋白: ~50 eV/蛋白 → 5× 更稳定!
    ⚫ 10 eV ≈ k_B T × 390 → 去折叠概率 ~exp(-390) ≈ 10⁻¹⁷⁰ 
      → 在 37°C 仍然极稳定 (单个蛋白)
    ⚫ 但! 这只是"平均" — Tm 分布有尾巴!


3. Tm 分布 — 37°C 过滤了多少种真菌?
==============================================================

3.1 真菌蛋白 Tm 的统计分布
--------------------------------------------------------------
    假设真菌蛋白 Tm 呈近正态分布:

    · 土壤真菌 (温带): μ ≈ 42°C, σ ≈ 5°C
    · 土壤真菌 (热带): μ ≈ 44°C, σ ≈ 5°C
    · 嗜热真菌 (堆肥): μ ≈ 50°C, σ ≈ 6°C
    
    ⚫ 关键: Tm 分布有尾巴 — 少数真菌的 Tm 延伸到 50°C+

    一个真菌要感染人类, 需要的不是"一个蛋白能存活"—
    是整个蛋白质组 (~6000 个蛋白) 在 37°C 下保持折叠!
    → 这相当于要求最不稳定的那个关键蛋白也在 37°C 保持功能。

    ⚫ 细菌没有这个问题 (细菌蛋白 Tm 与哺乳动物相似) → 
      细菌病的发病率是由免疫系统决定的, 不是由温度。

4. 细胞膜的额外脆弱性 — 不仅仅是蛋白质
==============================================================

4.1 真菌膜的 37°C 困境
--------------------------------------------------------------
    真菌细胞膜含麦角甾醇 (ergosterol), 而非胆固醇。
    
    膜流动性 ∝ 温度 — 太高 → 膜"漏" (离子泄漏)
    脂质相变温度 (从凝胶到液晶):
    · 真菌 (麦角甾醇): ~25-35°C
    · 哺乳动物 (胆固醇): ~15-25°C

    ⚫ 在 37°C: 真菌膜已经远高于相变温度 →
      膜过于流动 → 通透性过高 → 离子梯度泄漏!
    ⚫ 哺乳动物在 37°C: 胆固醇使膜刚化 → 仍在舒适区

    真菌在 37°C 需要:
    · 上调麦角甾醇合成 → 膜刚化
    · 上调膜转运蛋白 → 补偿泄漏
    → 这些都是额外的 ATP 成本 → 生长减慢

4.2 为什么抗真菌药可以靶向麦角甾醇?
    两性霉素 B: 结合麦角甾醇 → 形成膜孔 → 真菌死亡
    唑类 (氟康唑): 抑制麦角甾醇合成 → 膜流动性 ↑ → 37°C 时致命!

    ⚫ 这些药物之所以有效 — 恰恰是因为真菌膜已经在 37°C 的
      边缘 → 再抑制麦角甾醇 → 膜崩塌!
    ⚫ 哺乳动物细胞 (胆固醇) 不受影响 → 治疗窗口!


5. 全球变暖 — 防火墙正在被侵蚀
==============================================================

5.1 土壤升温 → 热适应 → 新致病菌涌现
--------------------------------------------------------------
    土壤温度每升高 1°C:
    · 真菌的进化压力: Tm 需要升高 ~0.5-1°C (不完全线性)
    · 持续数十年 → 土壤真菌群体的 Tm 分布向右移动

    当前全球变暖 +1.2°C → 土壤真菌 Tm 分布可能已右移 ~0.5-1°C
    预测 +2°C (2040-2060) → 右移 ~1-2°C

    ┌──────────────────────────────────────────────────────┐
    │                                                      │
    │   真菌 Tm 分布 (μ=42°C → μ=43°C → μ=44°C):            │
    │                                                      │
    │   当前 (μ=42°C): ~10% 的物种 Tm > 47°C (可耐受 37°C) │
    │   +1°C (μ=43°C): ~16% 的物种 Tm > 47°C               │
    │   +2°C (μ=44°C): ~23% 的物种 Tm > 47°C               │
    │                                                      │
    │   ⚫ +2°C 变暖 → 潜在致病真菌数量翻倍多!              │
    │   ⚫ 每多 1°C → 新增 ~5-8% 的真菌物种进入"危险区"     │
    └──────────────────────────────────────────────────────┘

5.2 耳念珠菌 (C. auris) — 防火墙穿孔的哨声
--------------------------------------------------------------
    2009 年, 耳念珠菌突然在三大洲同时出现 (日本、南亚、南美)。
    之前从未在人体中发现过。

    ⚫ 它的独特之处:
    · Tm ~48-53°C — 比大多数念珠菌更耐热
    · 耐多种抗真菌药 (唑类 + 棘白菌素)
    · 在环境表面存活数周 (医院暴发)
    · 致死率 30-60%

    ⚫ SCVC 假说: 耳念珠菌是全球变暖的"第一只金丝雀"。
    · 土壤升温 → 某种原本 Tm 偏高的环境真菌 →
      获得了在 37°C 生长的能力 →
      偶然接触到人类 (通过农业/湿地退化) →
      发现人体是一个"温暖的生态位"→ 暴发
    · 这不是"最后一次" — 是"第一次"。

5.3 每升温 1°C → 多少新真菌进入危险区?
--------------------------------------------------------------
    已知土壤真菌物种: ~10⁵-10⁶
    可感染人类的已知真菌: ~300-400 种

    假设真菌 Tm ~ N(42, 5²), 需要 Tm > 47°C 才能强致病:

    当前 (+0°C): z = (47-42)/5 = 1.0 → 尾部 ~15.9% 的物种
    · 15.9% × 10⁵ = ~16,000 种 → 但只有 ~300-400 种已知致病
    · 因为除了 Tm, 还需要: 穿透屏障 + 逃避免疫 + 获取营养

    变暖 +1°C (μ=43°C): z = (47-43)/5 = 0.8 → 尾部 ~21.2%
    · 新增: 21.2-15.9 = 5.3% → ~5,300 种新进入 Tm 范围

    变暖 +2°C (μ=44°C): z = (47-44)/5 = 0.6 → 尾部 ~27.4%
    · 新增: 27.4-15.9 = 11.5% → ~11,500 种

    ⚫ 温度条件满足的物种数大幅上升 →
      其中只要一小部分同时满足"穿透+逃逸"条件 →
      新致病真菌涌现的概率显著上升!

    ⚫ 最危险的新真菌候选 (从 Tm 和生态位推算):
    ① 热带土壤腐生真菌 (丰富的降解酶 → 可穿透组织)
    ② 昆虫病原真菌 (已进化穿透节肢动物角质层的酶 →
       哺乳动物皮肤也是角质层!)
    ③ 植物病原真菌 (在 25-30°C 致病 → 升温后跨越到 37°C)
    ④ 蝙蝠病原真菌 (白鼻综合征真菌 Pd → 
       蝙蝠体温与人类接近 → 危险!)


6. 发烧 — 免疫系统的热力学武器
==============================================================

6.1 发烧的 SCVC 基础
--------------------------------------------------------------
    发烧 (38-41°C) 不是"免疫系统的副作用" — 
    是主动的、古老的热力学防御。

    从 37°C 到 39°C (ΔT = +2°C):
    · 真菌中 Tm 在 42-47°C 的蛋白质 → 
      去折叠 ΔG 进一步降低 → 更不稳定
    · Arrhenius: 真菌酶的活性开始下降, 而非上升!

    宿主蛋白 (Tm ~55°C):
    · ΔT = +2°C → 仍在 Tm 之下 ~16°C → 完全不受影响
    · 免疫细胞 (中性粒细胞, 巨噬细胞) 在 39°C 
      实际上活性增强!

    ⚫ 发烧 = 把战场温度推到真菌的边缘, 
      而自己仍在舒适区 → 不对称战争!

6.2 发烧过滤了多少%?
--------------------------------------------------------------
    真菌 Tm 分布, 需要"在给定温度下能生长":

    37°C: 需要 Tm > 42-45°C → ~10-15% 的真菌物种
    39°C: 需要 Tm > 44-47°C → ~5-8% 的真菌物种
    41°C: 需要 Tm > 47-50°C → ~2-4% 的真菌物种

    ⚫ 39°C 发烧: 额外过滤 ~40-50% 的可感染真菌
    ⚫ 41°C 高烧: 额外过滤 ~60-80% 的可感染真菌
    ⚫ 但 41°C 对宿主自身也有风险 (神经元 >40°C 受损) →
      免疫系统在"自损"和"杀敌"之间权衡。

    ⚫ 这就是为什么退烧药 (布洛芬/对乙酰氨基酚) 
      可能延长真菌感染! — 你撤回了热力学武器。

6.3 为什么有些真菌不惧发烧?
    隐球菌 (C. neoformans):
    · Tm ~47°C → 41°C 发烧仍可存活
    · 多糖荚膜 → 物理屏障 → 减少热传导
    · 黑色素 → 吸收热量 + 抗氧化

    曲霉 (A. fumigatus):
    · Tm ~50-55°C → 在 41°C 完全不受影响
    · 可以在堆肥中生长 (>50°C!) → 人体发烧对它来说
      是"稍微暖和一点"而已

    ⚫ 这些"超级耐热真菌" → 发烧无效 → 
      只能依赖抗真菌药 + 免疫系统


7. 人体不是均匀的 37°C — 皮肤是突破口
==============================================================

    皮肤温度: 30-34°C (四肢更低)
    · 对大多数真菌来说, 这个温度完全舒适!
    · → 皮肤真菌病比全身真菌病常见得多
      (足癣、股癣、甲癣 — 全球 ~20-25% 人口!)

    呼吸道 (吸入真菌孢子):
    · 鼻腔: ~30-32°C → 孢子萌发
    · 肺部: 37°C → 免疫系统必须在真菌适应 37°C 前清除它
    · 如果免疫缺陷 → 真菌有时间上调 Hsp90 + 适应 37°C →
      肺曲霉病/隐球菌肺炎

    ⚫ 皮肤是"防火墙的漏洞" — 温度不够高
    ⚫ 肺是"防火墙的前线" — 温度够高但真菌有时间适应


8. 与细菌的对比 — 为什么细菌不怕 37°C?
==============================================================

    细菌蛋白 Tm 分布: 与哺乳动物相似 (μ ~50-55°C)
    · 细菌在土壤中面临更高的温度波动 (日晒、堆肥)
    · → 早在感染人类之前就已经进化了高 Tm
    · → 37°C 对细菌来说是"常规温度"

    细菌病的频发不是因为"细菌更多" —
    是因为"温度墙"对细菌不存在 → 
    免疫系统是唯一的防线。
    
    对真菌: 温度墙 + 免疫系统 = 双重防线 → 感染极少
    对细菌: 只有免疫系统 = 单防线 → 感染频繁

    ⚫ 这就是为什么真菌病死亡率 (150万/年) << 
      细菌病 (770万/年) 的物理根源!
