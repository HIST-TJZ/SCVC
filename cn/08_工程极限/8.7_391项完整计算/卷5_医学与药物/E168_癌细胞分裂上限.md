--------------------------------------------------------------
DNA 聚合酶速度 ≈ 50 bp/s/复制叉          (α → H键识别能 → 校对速度)

复制起点 ~30,000-50,000 个
S 期 ≈ 6-8 h                              (DNA 合成硬墙)
最短细胞周期 ≈ 12-15 h (最快癌细胞系)
端粒起始长度 ~5-15 kb，临界长度 ~2-4 kb
端粒损耗 ~50-150 bp/分裂
Hayflick 极限 ~50-70 代
α = 1/137.0363

1. DNA 复制 — 不可压缩的硬墙
==============================================================

1.1 S 期为何是 8 小时?
--------------------------------------------------------------
    ⚫ 理论下限 (所有复制叉同时工作):
      t_min = 3.2×10⁹ bp / (50 bp/s × 60,000 forks) ≈ 0.3 小时

    ⚫ 实际 S 期 ≈ 6-8 小时:
      复制起点异步激活 → 只有 ~10% 同时工作
      → t_actual ≈ 8 小时

    ⚫ 为什么不能更快? 
      · DNA 聚合酶 ~50 bp/s 是校对 (3→5 外切) 速度约束的结果
      · 更快 → 保真度 ↓ → 突变率 ↑ → 基因组崩溃
      · SCVC: H 键识别能 (~0.2 eV) + 碱基对堆叠 → 聚合酶速度的物理地板
      · 增加复制起点 → 可以 (肿瘤确实如此), 但受限于许可因子

    ⚫ S 期是癌症的物理硬墙:
      无论肿瘤多"恶性", 都不能突破 6-8 小时的 S 期。


2. 细胞周期
==============================================================

2.1 正常细胞 vs 癌细胞
--------------------------------------------------------------
    阶段       正常细胞           癌细胞 (最快)        墙
    ──────────────────────────────────────────────────────
    G1          ~10 h              ~1-2 h             需生长到足够尺寸
    S           ~8 h               ~6-8 h             DNA 聚合酶 (硬!)
    G2          ~4 h               ~2-3 h             检查点可压缩
    M           ~1 h               ~1 h               微管动力学 (硬)
    ──────────────────────────────────────────────────────
    总计         ~23 h              ~12-14 h
    ──────────────────────────────────────────────────────

    ⚫ 癌细胞的"加速" ≈ 1.7× — 主要在 G1 (绕过检查点) + G2 (压缩)
    ⚫ S 期和 M 期是物理瓶颈 → 癌细胞不可能比 ~12 h 快很多
    ⚫ 体外最快细胞系 (HeLa ~22h, CHO ~14h) 已接近此极限

    ⚫ SCVC 洞察:
      "癌细胞疯狂分裂" 的说法不完全准确。
      癌细胞比正常细胞快 ~2×, 但不是在物理上"无限快"。
      正常干细胞 (肠道隐窝 ~12-24h) 可以和癌细胞一样快 —
      癌细胞的问题是"停不下来", 而非"特别快"。


3. 端粒危机 — 干预窗口
==============================================================

3.1 端粒的倒计时
--------------------------------------------------------------
    端粒起始长度 ~10,000 bp, 临界长度 ~3,000 bp
    每次分裂损耗 ~100 bp (末端复制问题)

    最大分裂次数 = (10,000 − 3,000) / 100 = 70 代

    ⚫ 这就是 Hayflick 极限的 SCVC 根源!

3.2 从第一个癌细胞到端粒危机
--------------------------------------------------------------
    在体内, 肿瘤的净倍增时间远长于细胞周期:

    · 细胞周期: ~1-3 天 (in vivo, 不是 in vitro 的 12-24h!)
    · 净倍增时间: ~30-300 天 (大量细胞死亡 + 免疫清除)
    · 70 代 → 70 × 60 天 ≈ 11.5 年 (典型)
    · 最短可能: 70 × 14h ≈ 41 天 (零死亡, 不可能)

    ⚫ 真实的端粒危机窗口: 数年-十数年!
    ⚫ 在端粒危机 (telomeric crisis) 期间:
      · 基因组极度不稳定 → 染色体融合-桥-断裂循环
      · 少数细胞激活端粒酶 (hTERT) 或 ALT 通路 → 永生
      · 大多数细胞凋亡
    ⚫ 这是癌症进化的瓶颈事件 — 也是最大的干预窗口!

3.3 干预策略
--------------------------------------------------------------
    ┌─────────────────────────────────────────────────────────┐
    │ 窗口 1: 端粒危机前 (~数年-十数年)                        │
    │ · 肿瘤 < 1-10 mm³ → 可被免疫系统清除                     │
    │ · 尚未血管化 → 依赖扩散 → 氧限制                         │
    │ · 端粒酶尚未激活 → 基因组相对稳定                         │
    │ · 如果在此窗口检测到 → 治愈率极高                         │
    │                                                        │
    │ 窗口 2: 端粒危机中 (数月)                                 │
    │ · 基因组不稳定 → 产生新抗原 → 免疫系统可识别               │
    │ · 大多数细胞死亡 → 肿瘤可能暂时缩小                       │
    │ · 但: 少数细胞永生 → 必须在此窗口消灭所有存活者            │
    │                                                        │
    │ ⚫ SCVC: 癌症不是"一发不可收拾" —                          │
    │   在端粒酶激活之前, 肿瘤的生长受物理约束,                   │
    │   窗口期长达数年。早期筛查完全可以命中这个窗口。            │
    └─────────────────────────────────────────────────────────┘

E168 结论
====================================================================

  ⚫ 癌细胞分裂速度上限 ≈ 12-14 h/周期 (S 期 6-8 h 硬墙)
  ⚫ 比正常细胞仅快 ~2× — 癌症的问题是"不停"而非"极快"
  ⚫ 端粒危机前窗口: 数年-十数年 → 早期干预完全可能
  ⚫ 端粒酶激活是需要时间的物理瓶颈 — 不是即刻事件
