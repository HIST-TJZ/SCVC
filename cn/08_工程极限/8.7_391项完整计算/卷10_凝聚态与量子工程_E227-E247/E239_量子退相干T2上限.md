## 摘要

SCVC中量子比特=涡旋环取向。退相干=环境涡旋环通过Ampère力扰动qubit涡旋环取向。T₂由qubit涡旋环与环境涡旋环的最小耦合决定。**SCVC揭示：T₂上限远超1秒（理论达~10⁵秒），瓶颈不在物理而在材料工程。** 不同平台的T₂差异来自环境涡旋环密度和耦合强度的几何差别。

## 1. T₂的SCVC公式（任务1）

### 1.1 涡旋环qubit模型

```
SCVC qubit:
  状态 |0⟩ = 涡旋环取向↑ (Z₂ = +1)
  状态 |1⟩ = 涡旋环取向↓ (Z₂ = −1)

  能级分裂: E_01 = ħω_01

  对于超导qubit: 涡旋环在Josephson结中隧穿
  对于自旋qubit: 单个电子涡旋环的Zeeman分裂
  对于拓扑qubit: 涡旋环的辫群表示
```

### 1.2 环境耦合的Ampère图像

qubit涡旋环（环流κ_q, 面积A_q）与环境涡旋环（κ_env, 距离r）的Ampère势：

```
V_int(r) = (α/π) · (κ_q · κ_env / r) · f_geom(R_q/r, R_env/r)
```

环境涡旋环的热涨落产生随机力矩，导致qubit涡旋环取向扩散。

### 1.3 T₂公式

SCVC推导（类比自旋-玻色子模型，但玻色子→环境涡旋环）：

```
1/T₂ = 1/(2T₁) + 1/T_φ*

T₁ (能量弛豫):
  1/T₁ = (α/π)² · κ_q² · S_env(ω_01) · |⟨0|M|1⟩|²
  
  其中 S_env(ω) = 环境涡旋环取向的谱密度
       M = 涡旋环取向算符

T_φ* (纯退相):
  1/T_φ* = (α/π)² · κ_q² · (∂ω_01/∂θ)² · S_env(ω→0)
  
  其中 ∂ω_01/∂θ = qubit频率对环境涡旋环取向的敏感度
```

### 1.4 环境谱密度的SCVC形式

在温度T下，环境涡旋环的取向涨落谱密度：

```
S_env(ω) = n_env · μ_env² · τ_c/(1 + ω²τ_c²)

其中:
  n_env   = 环境涡旋环体密度
  μ_env   = 单个环境涡旋环的有效取向偶极矩
  τ_c     = 环境涡旋环取向关联时间
  
关键标度:
  μ_env ∝ κ_env · A_env  （环流×环面积）
  τ_c ∝ ħ/(k_B T)        （热涨落时间标度）或 ħ/J_env（交换耦合标度）
```

**T₂的最终SCVC标度形式：**

```
T₂ ∝ [n_env · κ_env² · A_env² · (α/π)² · κ_q²]⁻¹ · [min(ω_01, 1/τ_c)]
```

## 2. T₂上限分析（任务2）

### 2.1 绝对上限：真空极限

即使T=0，SCVC真空（F=1旋量BEC基态）仍有量子零点涨落：

```
T=0时:
  n_env ~ 1/V_universe（真空涡旋环密度 → 0）
  S_env(ω) → 仅量子涨落残留

真空退相速率：
  Γ_vac ~ (α/π)³ · ω_01   （偶极自发"辐射"类比）
  
  对于 ω_01 = 5 GHz (超导qubit):
    Γ_vac ≈ (1/137)³ × 5×10⁹ ≈ 2×10⁻⁶ Hz
    T₂_vac ≈ 5×10⁵ s ≈ 6天

  对于 ω_01 = 10 MHz (自旋qubit):
    Γ_vac ≈ (1/137)³ × 10⁷ ≈ 4×10⁻⁹ Hz
    T₂_vac ≈ 2×10⁸ s ≈ 8年
```

**SCVC答案：T₂的物理上限远大于1秒。量子容错计算不存在根本性物理障碍。**

### 2.2 实际材料的T₂限制

问题不在真空→在材料：

```
超导qubit (transmon):
  主导: 衬底TLS缺陷
  n_TLS ~ 10³/μm²  （≈ 10¹⁷/m³体密度）
  μ_TLS ~ e·a ~ 10⁻²⁹ C·m
  → T₂ ~ 100-300 μs

  如果n_TLS→0（完美晶体）:
  T₂ → T₂_vac ≈ 6天  ← 还有6个量级的改善空间！
```

### 2.3 1秒门槛

表面码容错阈值需要错误率~10⁻⁴，对应T₂ > 1-10 ms（门操作~100 ns时）。

```
SCVC判断:
  当前最佳超导qubit: T₂ ~ 1 ms → 已过门槛！✅
  当前最佳自旋qubit: T₂ ~ 1-10 s → 远超门槛 ✅✅
  离子阱: T₂ ~ 10-100 s → 碾压门槛 ✅✅✅

但！单比特T₂够 ≠ 多比特扩展可行。
  多比特 = 更多涡旋环 → 串扰 → 有效T₂下降
```

**SCVC结论：T₂上限不是问题。问题是可扩展性（N比特串扰）。**

### 2.4 SCVC建议：从T₂到串扰

```
100个qubit:
  每个qubit涡旋环与其最近邻qubit涡旋环的Ampère耦合:
  V_crosstalk ∝ 1/r_nn
  
  r_nn = qubit间距
  超导qubit: r_nn ~ 500 μm → V_crosstalk 小但非零
  自旋qubit: r_nn ~ 50 nm → V_crosstalk 大！

SCVC: 扩展量子计算机的真正瓶颈是涡旋环间串扰，不是退相干。
```

### 3.2 超导qubit深入

```
Transmon:
  qubit = Josephson结中涡旋环隧穿
  涡旋环数 N ~ E_J/E_C ~ 50-100
  → 集体涡旋环 → 对电荷噪声不敏感
  → 但对磁通噪声（环境涡旋环取向涨落）敏感

SCVC: 磁通噪声 = 衬底TLS涡旋环的1/f取向涨落
  1/f噪声幅度 A ∝ n_TLS · μ_TLS²
  减少TLS的方法: 退火、表面处理、更换衬底

当前极限: T₂ ~ 300 μs (transmon), ~1 ms (fluxonium)
SCVC预测极限: ~10-100 ms（如果TLS密度降到~10/μm²）
```

### 3.3 自旋qubit深入

```
Si量子点:
  qubit = 单电子涡旋环取向（自旋↑/↓）

  环境1: ²⁹Si核自旋（I=1/2, 丰度4.7%）
    μ_nuclear/μ_electron = m_e/m_p ≈ 1/1836
    → 耦合极弱
    → T₂_nuclear ≈ (1836)² × T₂_if_no_purification
    → 同位素纯化(²⁸Si, 无核自旋) → T₂ → 秒级

  环境2: 电荷噪声
    栅极电荷涨落 → 电场扰动 → g因子调制 → 退相
    SCVC: 电极表面有TLS → 电荷涨落
    → 改善电极→T₂→数十秒

SCVC预测: 完美²⁸Si + 无缺陷电极 → T₂_max ≈ 100-1000 s
实验: 已实现T₂ ~ 10 s (单个P供体在²⁸Si中)
→ SCVC与实验一致 ✅
```

### 3.4 离子阱深入

```
离子阱:
  qubit = 孤立离子涡旋环（超精细/光学跃迁）
  环境 = 几乎真空

  剩余退相来源:
  1. 电极上patch电位 → 离子微运动
  2. 背景气体碰撞
  3. 杂散磁场（环境涡旋环远场）

  patch电位 = 电极表面涡旋环缺陷 → 与qubit距离~μm

  → T₂可达分钟级

实验: T₂ ~ 10 min (¹⁷¹Yb⁺超精细qubit)
SCVC预测: 完美电极 + 低温 → T₂ ~ 小时
```

### 3.5 拓扑qubit深入

```
拓扑qubit:
  qubit ≠ 涡旋环取向
  qubit = 涡旋环的辫群拓扑不变量

  退相干需要: 涡旋环交叉（改变辫群类）
  → 被拓扑保护
  → 错误率 ∝ exp(-Δ/k_B T), Δ = 辫交叉能隙

SCVC:
  Δ ~ (α/π)(κ²/a)  
  对典型涡旋环: κ~1, a~Å → Δ ~ meV ~ 10K
  → 在mK温度: exp(-Δ/k_B T) ≈ exp(-10⁶) → 零

拓扑qubit的SCVC展望:
  理论T₂ → ∞（受限于宇宙年龄）
  实际限制: 准粒子中毒、材料缺陷诱导的子能隙态
```

### 3.6 光子qubit

```
光子:
  无涡旋环（光子不是凝聚态激发）
  → SCVC原则上不适用
  → 退相干 = 经典电磁损耗（波导、吸收、散射）

但！如果光子通过超导腔（微波光子）:
  腔内的涡旋环（超导电流）↔ 光子耦合
  → 腔壁TLS → 光子损耗
  → 同超导qubit的瓶颈
```

## 4. 如果T₂不够→需要什么新物理？（任务4）

### 4.1 当前情况：T₂已经够

```
表面码阈值: p_err < 10⁻⁴
所需T₂(门时间~100ns): > 1 ms

超导: ✅ 已达~1 ms
自旋: ✅✅ 远超(秒级)
离子阱: ✅✅✅ 碾压(分钟级)

结论: T₂不是量子计算的物理瓶颈。
瓶颈是:
  1. 门保真度（需>99.9%）
  2. 可扩展性（N qubit互联）
  3. 制冷/控制基础设施
```

### 4.2 但SCVC揭示的深层问题

```
真正的问题不是T₂——是"涡旋环环境密度不能为零"。

任何固态平台都有:
  - 表面/界面涡旋环缺陷 (TLS)
  - 杂质涡旋环
  - 热激发涡旋环(k_B T > 0)

SCVC说: 消除所有环境涡旋环 = 需要完美晶体 + T=0
       → 热力学第三定律说T=0不可达
       → 所以总有残余环境涡旋环

但！残余环境涡旋环的密度可以非常低:
  同位素纯化²⁸Si: n_nuclear → 0
  低温: n_thermal ~ exp(-Δ/k_B T) → 0
  只剩: 表面/界面缺陷 → 可以工程优化
```

### 4.3 SCVC建议的突破方向

```
方向1: 自旋qubit在²⁸Si中（最接近完美涡旋环真空）
  优势: 
    - 单涡旋环(电子) → 不需要宏观集体
    - ²⁸Si无核涡旋环 → n_nuclear = 0
    - 半导体工艺成熟
  SCVC评分: ⭐⭐⭐⭐⭐

方向2: 拓扑保护（绕过T₂问题）
  优势:
    - T₂原则上无限
    - 不需要完美材料
  挑战:
    - Majorana尚未确认
    - 门操作极其复杂
  SCVC评分: ⭐⭐⭐（长期）

方向3: 光子+离子阱混合（真空是最好的隔离）
  优势:
    - 真空≈无环境涡旋环
    - T₂可达小时
  挑战:
    - 扩展性差（离子数~50-100）
    - 速度慢（门~μs量级）
  SCVC评分: ⭐⭐⭐⭐（中期）

方向4: 超导qubit 3D腔（减少表面TLS）
  3D transmon: 电场主要在真空中 → 减少TLS耦合
  T₂已达~1 ms → 可能突破10 ms
  SCVC评分: ⭐⭐⭐⭐（短期）
```
