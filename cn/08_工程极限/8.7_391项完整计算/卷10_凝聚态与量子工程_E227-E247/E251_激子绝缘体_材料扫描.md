## 摘要

用SCVC激子绝缘体框架系统扫描材料：E_b=μe⁴/(2ε²ħ²)，Tc_max≈0.6×E_b/k_B。**结论：2D材料是激子绝缘体的主战场——4×结合能增强让室温激子凝聚在物理上触手可及。Top候选：单层MoS₂(Tc≈510K)、黑磷(Tc≈400K)、WS₂(Tc≈450K)。全部已有实验平台。**

## 1. 选材判据量化（任务1）

### 1.1 SCVC判据

```
3D激子结合能:
  E_b(3D) = (μ/m_e)·(1/ε²)·13.6 eV

2D激子结合能（量子限域增强）:
  E_b(2D) = 4·E_b(3D) = 4·(μ/m_e)·(1/ε²)·13.6 eV

凝聚温度（BEC极限）:
  Tc ≈ 0.6 × E_b/k_B
  
室温门槛:
  Tc=300K → E_b > 0.52 eV
  Tc=400K → E_b > 0.70 eV

2D室温条件:
  4·μ·13.6/(m_e·ε²) > 0.52
  → μ/(m_e·ε²) > 0.0096  ← 核心判据
```

### 1.2 材料四要素

| 要素 | 最优值 | 物理原因 | SCVC追溯 |
|:---|:--:|:---|:---|
| **ε↓** | <5 | 弱屏蔽→强Coulomb | ε来自涡旋环极化率→α |
| **μ↑** | >0.2 m_e | 重约化质量→深束缚 | μ来自能带曲率（超出SCVC） |
| **维度** | 2D | 4×E_b增强 | 量子限域→涡旋环约束 |
| **能隙** | 半金属~0.2 eV | 可自发产生激子 | 能隙由键能→α |

## 3. 已有实验对比（任务3）

### 3.1 声称的激子绝缘体

|:---|:---|:--:|:---|:--:|:---|

| 🟢 确认 | GaAs QW | ~1K | 激子发光+相干 | ~1K | 极低温 |

### 3.2 Ta₂NiSe₅争议的核心

```
声称Tc=328K的实验证据:
  ① ARPES: 扁平能带→高DOS
  ② 光导率: 能隙打开~180meV
  ③ 结构相变: 单斜→正交(T=328K)

质疑:
  ✗ 无Goldstone模(激子凝聚的必要信号)
  ✗ 能隙打开也可能是Peierls(纯结构)
  ✗ 激子密度n_ex未测量

SCVC: E_b~60meV→Tc~36K(T_BEC)~420K(Tc_max)
  → Tc=328K在SCVC范围内(物理可能)
  → 但需要排他性证据——能隙应同时出现在
    电荷和自旋通道（激子绝缘体的标志）
```

### 3.3 为什么2D激子绝缘体还没被声称

```
→ 因为研究重点在发光/光电子，不在凝聚态基态
→ 需要: 低温输运 + 扫描隧道谱 + Goldstone模探测
→ 实验上的"真空": TMD单层的基态相图尚未系统探索
→ 这是SCVC的机会——告诉实验去哪看
```

## 5. SCVC设计原则总结

### 5.1 激子绝缘体的"食谱"

```
SCVC激子绝缘体食谱:
  
  主料: 2D半导体 (4×E_b增强不可或缺)
  调料: 小ε (<6, 最好<5)
        大μ (>0.15 m_e)
        小E_g (<2 eV, 越小越好⸺减少激发能耗)
        
  烹饪方法:
    ① 双栅异质结 → 独立控制n和p
    ② hBN封装 → 减少无序
    ③ 低温输运 → 找凝聚相变

不支持的材料:
  ✗ 3D体材料 → ε太大(E_b∝1/ε²)
  ✗ 间接能隙 → 需声子→破坏激子
  ✗ 宽能隙(>3 eV) → 无法自发产生激子对
  ✗ 极性材料 → ε大
```

### 5.2 与超导材料搜索的对比

| | 超导 | 激子绝缘体 |
|:---|:---|:---|
| 关键参数 | λ(配对强度) | E_b(结合能) |
| 最强增强 | 高压(d_nn↓→ω_D↑) | 2D量子限域(×4) |
| 平台 | 高压/DAC | 范德华异质结 |
| 成熟度 | 百年 | 十年 |
| 最大化Tc | ~250K(高压) | ~500K(2D) |
| SCVC预测 | 🟡 部分 | 🟢 清晰 |

**激子绝缘体比超导更"SCVC友好"——E_b直接∝α²，不需要声子中介的复杂指数依赖。**

| 问题 | 答案 |

| **室温激子绝缘体最可能在？** | 🟢 **2D TMD单层(MoS₂/WS₂)** — 4×E_b增强+低ε+已有实验平台。 |

| **最大实验障碍？** | 🔴 ① 激子密度vs Mott极限 → 需要干净材料；② 凝聚信号vs能隙→需要排他性证据(Goldstone模)；③ 室温kT≈26meV→若E_b仅50meV则热解离。 |

### 6.1 为什么还没发现室温激子绝缘体

```
① 研究方向错配:
   超导→凝聚态核心，万人追逐
   激子绝缘体→小众领域，几十个组
   → 不是因为不存在，是没人认真找

② 实验难度:
   超导: 测电阻=0 → 简单直接
   激子绝缘体: 能隙≠凝聚 → 需要Goldstone模或相干证据
   → 确认门槛高

③ 材料成熟度:
   超导: 材料合成成熟→快速筛选
   2D TMD: 范德华异质结近10年才成熟
   → 才刚开始系统研究基态

SCVC判断: 
  MoS₂室温激子绝缘体可能已经存在于某些实验中——
  只是被归因为"能隙"或"测量伪影"。
  
  如果SCVC是对的，第一个发现可能来自意外观察——
  正如超导在Hg中是被意外发现的。
```
