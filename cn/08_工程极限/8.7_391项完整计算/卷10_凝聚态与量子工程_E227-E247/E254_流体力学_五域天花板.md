# 一、最小阻力形状与Strouhal涡脱落

## 1.1 Strouhal数 St ≈ 0.2：为什么是0.2？

圆柱绕流的涡脱落频率：
\[
\text{St} = \frac{fD}{U} \approx 0.21 \quad (300 < \text{Re} < 10^5)
\]

这个0.2极其稳健——Re从300变到10⁵，St几乎不变。

**它来自什么？**

冯·卡门涡街的稳定性分析：两列交错涡旋的间距比 h/l ≈ 0.281 是唯一能使涡街线性稳定的值。Strouhal数从这个几何比直接出来：

\[
\text{St} \approx \frac{1}{2\pi} \cdot \text{(分离区几何因子)} \approx 0.2
\]

**SCVC能说什么？**

St ≈ 0.2 是一个**纯几何数**——它来自涡旋列的稳定排列条件，不依赖于粘性、密度或任何物质参数。SCVC说：**所有流体在同一几何障碍物下的St相同，因为涡旋排列是一个拓扑约束，不是材料性质。**

实验验证：圆柱在水中、空气中、甘油中——St ≈ 0.21。✅

**SCVC锁定的是：涡脱落开始的Re。**
\[
\text{Re}_{\text{crit}} \approx 47
\]

这个47来自：尾流中的绝对不稳定性增长率超过对流增长率。增长率∝U/D，耗散∝ν/D² → Re_crit = UD/ν是这两个时间尺度的比值。ν → 分子碰撞 → 键能 → α。

SCVC不能说Re_crit=47（那是NS方程解的特征值），但能说：**任何流体中涡脱落的临界Re = f(ν)，且ν→α。**

## 1.2 最小阻力形状：摩擦阻力地板

流线型体的阻力系数C_D ≈ 0.04-0.05（层流边界层保持附着）。

**绝对地板**（完全层流，零压差阻力，仅表皮摩擦）：
\[
C_f = \frac{1.328}{\sqrt{\text{Re}_L}}
\]

对L=1m，U=10m/s，水(ν=10⁻⁶)：Re_L=10⁷ → C_f≈4.2×10⁻⁴。

加上形状因子（流线型≈1.1×平板）→ C_D_min ≈ **0.0005**（水中1m长物体）。

**SCVC锁定**：C_D_min ∝ 1/√Re = √(ν/UL)。ν→α。不同流体中同一形状的最小阻力比 = √(ν₁/ν₂)。

| 流体 | ν (m²/s) | C_D_min (1m,10m/s) | SCVC |
|------|---------|-------------------|------|
| 空气 | 1.5×10⁻⁵ | 0.0018 | 高ν→高阻力 |
| 水 | 1.0×10⁻⁶ | 0.0005 | 低ν→低阻力 |
| 甘油 | 1.4×10⁻³ | 0.018 | 高ν→高阻力 |

**SCVC捕获的是：不同流体中最小阻力的排序是ν的函数，ν→α。但绝对值需要物性参数。**

# 二、Rayleigh-Bénard对流

## 2.1 Ra_c = 1708：几何本征值

临界Rayleigh数：
\[
\text{Ra}_c = \frac{g\beta\Delta T L^3}{\nu\alpha_T} = 1708
\]

1708是从∇⁴w = Ra·∇²⊥θ在刚性边界水平层中的最低本征值。**这是一个几何数——不依赖流体种类。** 水、空气、汞、氦——Ra_c都是1708。

**SCVC洞察**：Ra_c=1708和α无关。因为Ra_c来自**问题的几何**（水平层、刚性边界），不是来自流体性质。SCVC在这里的角色是确认"任何流体都遵循同一几何约束"——这和SCVC"物理常数都是几何"的观点完全一致。

## 2.2 端区标度律：Nu ∝ Ra^β

湍流对流中Nusselt数（无量化热输运）：
\[
\text{Nu} \sim \text{Ra}^\beta
\]

- 经典区（Ra<10¹²）：β≈1/3（Malkus-Howard-边界层主导）
- 终极区（Ra>10¹⁴）：β→1/2（Kraichnan-混合长度，边界层消失）

**SCVC锁定**：最大可能的Nu。Nu不能超过分子扩散极限的倒数：
\[
\text{Nu}_{\text{max}} \sim \frac{\text{湍流扩散率}}{\text{分子扩散率}}
\]

湍流扩散率受限于声速×层高：D_turb < c_s·L。
分子扩散率：α_T → 声子平均自由程×声速。

→ Nu_max ∝ L/λ_mfp（宏观尺度/分子平均自由程）。

对水（λ_mfp~3Å, L~0.1m）：Nu_max ~ 3×10⁸。实验最高~10⁴-10⁵ → 还有~10³-10⁴倍空间。

**SCVC说**：Nu的物理天花板来自分子自由程→a₀→α。这是"对流能做到多强"的绝对上限。

# 三、河流网络与分形分叉

## 3.1 Horton定律：纯几何涌现

```
分叉比:    R_b = N_ω / N_{ω+1} ≈ 4
长度比:    R_l = L_{ω+1} / L_ω ≈ 2  
面积比:    R_a = A_{ω+1} / A_ω ≈ 4-5
```

这些规律在**所有**自然河流网络中出现——密西西比河、亚马逊河、你家后院的溪流。和气候、地质、植被无关。

**SCVC洞察**：Horton定律是**最优输运网络的几何必然**。一个网络要最小化总能量耗散（水流摩擦+流域维护），分叉比自然锁定在~4，长度比~2。这不需要"算"——这是图论+变分原理的数学结果。

## 3.2 Murray定律：r³和的几何根源

Murray(1926)：
\[
r_{\text{parent}}^3 = r_{\text{child1}}^3 + r_{\text{child2}}^3
\]

为什么是**立方**？来自两个竞争成本：

```
泵浦功:   W_pump ∝ Δp·Q = (8μL/πr⁴)·Q²  (Poiseuille阻力 ∝ r⁻⁴)
血液体积成本: W_vol  ∝ πr²L            (容积成本 ∝ r²)
```

总成本：W = A·r⁻⁴ + B·r²
最小化：dW/dr = −4Ar⁻⁵ + 2Br = 0 → r⁶ ∝ A/B → r³ ∝ Q

**4和2的比值决定了3。**

**SCVC锁定A和B：**
- A ∝ μ（血液粘性）→ 红细胞变形→膜力学→分子键→α
- B ∝ k（组织代谢成本）→ ATP→氧化磷酸化→质子梯度→α

**两个系数都追到α → 比例A/B锁定 → 指数3锁定。**

如果μ大一倍（糖尿病→血液粘稠），Murary定律还是r³∝Q不变——因为A和B同时变化？不，B是组织成本，和血液μ无关。所以病态下指数偏离3？

**SCVC的答案**：健康生理状态下A/B被α锁定，指数严格=3。病理偏离→指数改变→这是可验证的预言。

# 四、血液动力学

## 4.1 毛细血管直径 = 红细胞几何

毛细血管最窄处d≈5-8μm。刚好通过一个红细胞（d_RBC≈7-8μm）。

不是巧合——毛细血管不能再细了（红细胞过不去），也不能再粗了（浪费血液体积+减慢扩散）。d_cap ≈ d_RBC。

**SCVC追溯**：红细胞尺寸→血红蛋白含量→铁原子数→Fe²⁺/Fe³⁺轨道→α。红细胞的形状（双凹碟形）是膜弯曲能和表面积/体积比的几何最优解——又是一个变分问题。

## 4.2 Womersley数 = 脉动流的惯性/粘性比

\[
\alpha_W = R\sqrt{\frac{\omega}{\nu}}
\]

主动脉：α_W≈15-20（惯性主导→平推流型）
小动脉：α_W≈1-2（粘性主导→Poiseuille型）
毛细血管：α_W≈0.01（准稳态→纯粘性）

**SCVC锁定ν→α → α_W量级完全确定。** 循环系统的逐级分叉保证了α_W从~20平滑过渡到~0.01——这是Murray定律的另一个侧面。

## 4.3 心跳频率→最大心率已锁定

SCVC之前：动作电位不应期~2ms→最大心率~220bpm。

静息心率~60-70bpm→不是物理上限→是Murray型优化：心率太快→心脏充盈不足→心输出量下降；心率太慢→血压波动大。最优心率∝√(代谢率/体重的3/4次幂)→异速生长律→Kleiber定律→细胞代谢→ATP→α。

# 五、海洋波、内波、混合层

## 5.1 重力波→表面张力波的过渡：α决定

深水重力波：ω²=gk（g不是SCVC）
毛细波：ω²=σk³/ρ

过渡波长：
\[
\lambda_{\text{trans}} = 2\pi\sqrt{\frac{\sigma}{\rho g}}
\]

水：σ≈0.073 N/m, ρ=1000 kg/m³, g=9.8 m/s²
→ λ_trans≈2π√(7.3×10⁻⁵/9800)≈2π×0.00273≈**0.017m=1.7cm**

比1.7cm短的波=毛细波（表面张力主导），比1.7cm长的波=重力波。

**SCVC**：σ/ρ≈0.073/1000=7.3×10⁻⁵ m³/s²。经过单位转换，σ/ρ=键能/(分子质量)→全追α。

**SCVC给定λ_trans=1.7cm。** 这是海面上涟漪和波浪的分界线——你在任何海边看到的小于1.7cm的波纹都是毛细波（风的摩擦力直接驱动），大于1.7cm的是重力波（可以传播几百公里）。

## 5.2 最大波陡→波浪破碎

波高H和波长λ的比值不能超过1/7≈0.14（Stokes极限）。

这来自波峰处水质点加速度=g的临界条件。超过此→波峰崩塌→白浪。

**SCVC**：1/7是一个几何极限——波形的最大曲率不能超过g/σ的组合。和流体种类无关。所有海洋中的破碎波都有H/λ<1/7。✅

## 5.3 内波频率上限→Brunt-Väisälä频率

\[
N = \sqrt{-\frac{g}{\rho}\frac{d\rho}{dz}}
\]

海洋温跃层典型N≈0.01 s⁻¹（周期~10分钟）。这是分层流体中内波的最高频率。

**SCVC绕路**：dρ/dz来自温度和盐度梯度→温度来自太阳加热→太阳常数最终和核聚变截面有关→α进入。但这个链太长了。

务实：N的量级是地球物理给定的（太阳常数、地球自转、海洋深度）→SCVC给这些输入参数的量级估算，但不锁定具体值。

## 5.4 混合层深度→Monin-Obukhov尺度

海洋上层混合层深度典型~50-200m（受风和季节影响）。

风搅拌vs浮力抑制的平衡：
\[
L_{\text{MO}} = -\frac{u_*^3}{\kappa B_0}
\]

u_*（摩擦速度）←风应力←大气环流，B_0（浮力通量）←海面热通量。

这些是地球物理参数→SCVC不锁定。SCVC只能说：**混合层内湍流的最低可能混合效率由分子耗散设定**——而分子耗散→ν→α。
