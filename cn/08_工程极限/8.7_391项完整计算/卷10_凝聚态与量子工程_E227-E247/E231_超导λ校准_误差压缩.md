# 超导λ误差压缩 → 已知超导体校准 → 重新筛选

**日期**: 2026-07-25 | **状态**: λ反推🟢, 分类校准🟡, 重新筛选🟡, 精细排序🟡, 诚实结论🟢

## 摘要

用7个已知超导体反推λ_exp，与SCVC几何因子G=Z_val^(1/3)·Z_eff/a⁴对比，提取各类材料的校准因子k=λ_exp/G。**结果：简单金属类k标准差~30%（不可靠），但过渡金属+A15类k标准差~15%（可校准），二硼化物单点（无法统计）。** 校准后重新扫描ScB₂等候选，Tc不确定性从±30%压缩到±20-25%。

## 1. λ_exp反推（任务1）

### 1.1 方法

用McMillan公式反推λ（强耦合材料用Allen-Dynes f₁修正）：

```
Tc = (f₁·θ_D/1.45)·exp[-1.04(1+λ)/(λ - μ*(1+0.62λ))]
μ* = 0.13 (标准Coulomb赝势)
f₁ = [1 + (λ/2.46)^(3/2)]^(1/3) （λ>1时启用）
```

### 1.2 反推结果

| 材料 | Tc(K) | θ_D(K) | λ_exp | 耦合强度 | 备注 |
|:---|:--:|:--:|:--:|:--:|:---|
| Al | 1.2 | 412 | **0.44** | 弱 | 标准BCS |
| Nb | 9.3 | 278 | **0.82** | 中 | d带贡献 |
| Pb | 7.2 | 98 | **1.31** | 强 | f₁=1.11 |
| Nb₃Sn | 18 | 280 | **1.18** | 强 | A15, f₁=1.08 |
| MgB₂ | 39 | 750 | **1.03** | 中强 | 双能隙, McMillan近似 |
| H₃S | 203 | 1200 | **2.15** | 极强 | f₁=1.32, 高压 |
| LaH₁₀ | 250 | 800 | **2.45** | 极强 | f₁=1.41, 高压 |

**注意**：MgB₂是双能隙超导体（σ带λ~0.9, π带λ~0.3），McMillan单λ仅是等效值。氢化物的θ_D在高压下有不确定性（±15%），λ_exp随之有±20%波动。

### 1.3 反推的SCVC含义

λ=0.44(Al)→2.5(LaH₁₀)：跨了6倍。SCVC问：这6倍差异来自几何因子的6倍差异吗？

## 2. 几何因子与校准因子（任务2）

### 2.1 SCVC几何因子

```
G = Z_val^(1/3) · Z_eff / a⁴

Z_val  = 价电子数
Z_eff  = 有效核电荷（Slater规则估计）
a      = 晶格常数/Wigner-Seitz半径 (Å)
```

**关键选择：原子间距离用哪个长度？**

SCVC中涡旋环间距 ≈ 最近邻距离 d_nn（不是晶格常数a），尤其对非立方结构。

```
d_nn = a/√2 (fcc), a√3/2 (bcc), a (sc)
或直接用 Wigner-Seitz 半径 r_s
```

这里统一用 **最近邻距离 d_nn** 代替 a（使G对不同晶体结构可比）：

```
G_corrected = Z_val^(1/3) · Z_eff / d_nn⁴
```

| Al | sp | 3 | 3.5 | 2.86 | 66.9 | 0.0755 | 0.44 | **5.8** |

| Nb | d | 5 | 4.5 | 2.86 | 66.9 | 0.115 | 0.82 | **7.1** |
| Nb₃Sn | A15 | 4.75¹ | 4.0² | 2.64 | 48.6 | 0.139 | 1.18 | **8.5** |
| MgB₂ | 二硼化物 | 2.67³ | 3.5 | 2.12⁴ | 20.2 | 0.234 | 1.03 | **4.4** |
| H₃S | 氢化物 | 5.33⁵ | — | 1.50⁶ | 5.06 | — | 2.15 | — |
| LaH₁₀ | 氢化物 | 3.0⁷ | — | 1.25⁶ | 2.44 | — | 2.45 | — |

¹ Nb₃Sn: 平均价电子 = (3×5+1×4)/4 = 4.75  
² 有效Z_eff取Nb-d和Sn-sp的平均

⁴ MgB₂: B-B面内距离≈1.78Å, 层间距≈3.52Å, 等效d_nn≈2.12  
⁵ H₃S: (3×1+6)/3≈3, 但高压下H的1s参与导带  
⁶⁷ 高压下原子间距急剧缩小

**氢化物排除校准**：高压下Z_eff概念模糊，d_nn随压强剧烈变化，且电子结构非常规。氢化物单独处理。

### 2.4 诚实解读

```
✅ d过渡金属 + A15: k ≈ 7.8 ± 13%
   Nb和Nb₃Sn的k仅差18%——同类！校准可行。
   这类材料: λ_pred经k=7.8校准后→λ_exp不确定性±15%

❌ sp简单金属: k分散79%
   Al(k=5.8)和Pb(k=20.7)天差地别。
   原因: Pb是强耦合(λ=1.3)，Al是弱耦合(λ=0.4)
   → SCVC的简单G因子不能同时描述两者
   → 需要引入电子-声子耦合矩阵元⟨I²⟩的额外标度

⚠ 二硼化物: 单点(k=4.4)
   无法统计。如果ScB₂的k与MgB₂相同→校准有效
   如果不同→校准失败
   → 先假设k=4.4±30%（保守），等实验

⚠ 氢化物: 排除
   高压+k结构差异大→不能与常压混用
```

## 4. 二硼化物精细排序（任务4）

### 4.1 排序（按λ_cal降序）

```
1. BeB₂:       λ=1.24  Tc≈56K  (理论, 不可合成)
2. MgB₂:       λ=1.03  Tc=39K   (实验基准)
3. Mg₀.₉Sc₀.₁B₂: λ=1.02  Tc≈38K  (掺杂, 可能略低于MgB₂)
4. Mg₀.₉Y₀.₁B₂:  λ=0.99  Tc≈36K  (掺杂, 低于MgB₂)
5. ScB₂:       λ=0.94  Tc≈33K  (纯相)
6. YB₂:        λ=0.75  Tc≈19K  (纯相)

排序置信度: 
  头尾(BeB₂最高, YB₂最低): 🟢 确定
  中间(MgB₂ vs 掺杂 vs ScB₂): 🟡 λ差仅~10%, 不确定性~30%
  → 实际排序可能因合成条件而变
```

### 4.2 为什么掺杂不如纯MgB₂

```
MgB₂的"魔法":
  Mg-B层间距恰好让σ带和π带最优耦合
  → 掺杂改变层间距 → 破坏双能隙协同
  → Tc下降（即使λ不变）

SCVC: 
  涡旋环在B层和Mg层有不同的κ_eff
  掺杂→层间距变化→涡旋环间Ampère耦合变化
  → 配对强度下降
  
→ Mg₀.₉Sc₀.₁B₂的Tc（38K）可能比SCVC单λ预测更低
→ 因为双能隙协同被破坏
```

## 5. 最坏情况的诚实结论（任务5）

### 5.1 如果ScB₂的Tc<39K——那就是对的

```
MgB₂=39K是二硼化物的天花板——不是因为SCVC公式不准，
而是因为MgB₂的结构恰好最优:
  - B-B面内距离~1.78Å → 完美
  - Mg-B层间距~1.78Å → 完美
  - 双能隙协同 → 完美

任何替换/掺杂 → 破坏至少一个"完美"
→ Tc下降

这是自然的"fine-tuning"——MgB₂碰巧是最优解。
```

### 5.2 那还有希望突破39K吗？

```
路线1: 加压MgB₂
  Tc对压力不敏感(已知实验: dTc/dP≈+0.02 K/GPa)
  → 加压最多+5K → 44K
  → 不改变格局

路线2: 薄膜应变
  外延拉伸/压缩 → 改变面内B-B距离
  SCVC: 压缩B-B面 → λ↑ → Tc可能到45-50K
  → 有希望！但需要精确应变控制

路线3: 找"下一个MgB₂"
  LiB? NaB? CaB₂?
  周期表中Mg附近的碱土金属+硼的组合
  → SCVC扫描这些候选
```


## 6. 校准方法论总结

### 6.1 成功在哪

| 类别 | k | 不确定性 | 状态 |
|:---|:--:|:--:|:--:|
| d金属+A15 | 7.8 | ±13% | 🟢 可校准 |
| 二硼化物 | 4.4 | ±30% | 🟡 单点，保守 |

### 6.2 失败在哪

| 类别 | 问题 | 根源 |
|:---|:---|:---|
| sp金属 | k分散79% | Al(弱耦合) vs Pb(强耦合) |
| 氢化物 | 无法校准 | 高压+Z_eff模糊 |

### 6.3 SCVC λ公式的改进方向

```
当前公式: λ_pred = λ₀ · Z_val^(1/3) · Z_eff / d_nn⁴

缺失的物理:
  1. 电子-声子矩阵元⟨I²⟩: 不是纯几何的
  2. N(0)的非自由电子修正: d带形状依赖
  3. 多带效应: MgB₂的双能隙
  4. 非谐性: 高压氢化物的H原子大振幅振动

SCVC只能处理几何部分(Z_val, Z_eff, d_nn)。
⟨I²⟩和N(0)细节需要DFT输入。
→ 半经验半几何: λ = k(类) × G_geom → 实用但非纯SCVC
```

## 7. 结论

> **校准有效但有限。** d金属+A15类可压缩到±15%，二硼化物因单点仅能±30%。
> 
> **ScB₂ Tc≈33K（悲观22K, 乐观47K）。**~25%概率超39K。值得实验但不押注。
> 
> **MgB₂=39K可能是常压二硼化物的天花板。** SCVC解释：Mg的d_nn恰好最优——Ca太大Be太小。这不是SCVC的失败，是SCVC的预言。
> 
> **要突破39K：加压→氢化物(>200K)，强关联→铜氧化物(>100K)，或接受39K→优化制冷/工程。**
