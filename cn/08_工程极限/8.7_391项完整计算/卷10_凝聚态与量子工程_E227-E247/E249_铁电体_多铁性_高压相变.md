# 第一部分: 铁电体

## 1. SCVC铁电图像

### 1.1 自发极化 = 离子涡旋环的集体位移

```
顺电相: 离子涡旋环在对称位置(Ampère势阱底)
铁电相: 离子涡旋环集体位移到不对称位置(另一势阱)
```

位移驱动力: 离子涡旋环间的Ampère力 + 电子涡旋环的屏蔽效应。

### 1.2 双阱势的几何根源

```
V(x) = -½ k x² + ¼ λ x⁴  (Landau自由能)

k = Ampère力刚度(正比于离子间直接Ampère力)
λ = 电子屏蔽的非谐修正(电子涡旋环重排)
```

铁电相变条件: k<0 (软模)→有效Ampère力在对称位置为负→离子自发位移。

### 1.3 为什么BaTiO₃是铁电体?

Ti⁴⁺在TiO₆八面体中:
- 高温(立方): Ti在八面体中心→对称(顺电)
- 低温(四方): Ti偏离中心0.12 Å→极化(P_s≈26 μC/cm²)

SCVC: Ti⁴⁺涡旋环与O²⁻涡旋环的Ampère力在中心位置
由于Ti的d⁰电子构型(无能带电子屏蔽)→等效负刚度→Ti位移。

**d⁰构型 = 铁电体的必要条件(d轨道空, 不屏蔽位移)。** 这就是为什么BaTiO₃(Ti⁴⁺:d⁰)和PbTiO₃是铁电体, 而SrRuO₃(Ru⁴⁺:d⁴)不是。

# 第二部分: 多铁性

## 2. 多铁性 = 铁电+磁性共存

### 2.1 为什么罕见?

```
铁电需要: d⁰离子(空d轨道, 允许离子位移)
磁性需要: dⁿ离子(n≠0, 未配对自旋)

d⁰ vs dⁿ → 化学矛盾!
```

SCVC细化:
- 铁电位移 = 离子涡旋环的空间位移(轨道自由度)
- 磁性 = 电子涡旋环的环流方向(自旋自由度)
- 两种涡旋环自由度通常独立→耦合弱

### 2.2 BiFeO₃: 如何突破d⁰-dⁿ矛盾?

Bi³⁺的6s²孤对电子(非d电子)提供铁电位移, Fe³⁺的d⁵提供磁性。

SCVC: Bi的孤对电子涡旋环(空间不对称)→铁电极化,
Fe的d电子涡旋环(不同环流方向)→反铁磁序。
两者共享氧八面体的几何→弱磁电耦合。

### 2.3 多铁候选材料

| 材料 | 铁电机制 | 磁性机制 | T_C/T_N(K) | SCVC耦合 |
|:---|:---|:---|:--:|:--:|
| BiFeO₃ | 6s²孤对 | Fe³⁺ d⁵ | 1100/640 | 🟢 弱耦合 |
| TbMnO₃ | 螺旋自旋诱导 | Mn³⁺ d⁴ | 27/41 | 🟡 自旋-轨道 |
| YMnO₃ | 几何铁电 | Mn³⁺ d⁴ | 900/70 | 🟡 |
| CuO | 自旋诱导 | Cu²⁺ d⁹ | 230/213 | 🟡 |
| Cr₂O₃ | 线性磁电 | Cr³⁺ d³ | —/307 | 🟡 弱 |

### 2.4 强磁电耦合的SCVC判据

强磁电耦合需要涡旋环位移与涡旋环环流共享同一原子:
```
同原子dⁿ(n≠0且d≠满)→铁电位移与磁性在同一个离子上
→强耦合(但违反d⁰规则→需孤对电子或几何铁电)
```

**SCVC: 真正强的多铁性(室温+大磁电系数)至今未实现——
因为d⁰要求与dⁿ要求在同一原子上不能同时满足。
BiFeO₃是"分离型"(Bi位移, Fe磁性)→耦合弱。**

# 第三部分: 高压相变

## 3. 高压 = 涡旋环被压缩

### 3.1 SCVC高压相变判据

加压→晶格常数a减小→涡旋环间距r减小→Ampère势V(r)改变→新的V(r)极小值出现→结构相变。

```
相变压力P_c: dE_total/da|_{P=P_c} 从旧极小跳到新极小

E_total(a) = E_Ampère(a) + P·V(a)
```

### 3.2 典型相变序列

| 材料 | P=0结构 | P1相变 | P2相变 | SCVC机理 |
|:---|:---|:--:|:--:|:---|
| Si | 金刚石 | β-Sn(11GPa) | 简单六角(16GPa) | 共价→金属 |
| SiO₂ | 石英 | 柯石英(3GPa) | 斯石英(10GPa) | Si配位数4→6 |
| H₂O | 冰Ih | 冰II-IX系列 | 冰X(>60GPa) | H键对称化 |
| Fe | BCC | HCP(13GPa) | — | 磁性坍塌 |
| C | 石墨 | 金刚石(15GPa) | BC8(>1000GPa) | sp²→sp³ |

### 3.3 SCVC预测新相变

从Ampère势V(r) ∝ -Z_eff²α/r, 在高压下r减小→竞争排斥项(Pauli+核-核Coulomb)增强→V(r)变形→新极小。

```
通用序列: 低配位→高配位 (涡旋环被压→更多近邻)
         绝缘体→金属   (涡旋环重叠→能带展宽→带隙闭合)
         分子固体→原子固体→等离子体(极端)
```

### 3.4 金属氢的SCVC路径

```
H₂分子固体 → H原子固体 → 金属氢

P1(~150 GPa): H₂→H(分子解离, H涡旋环独立)
P2(~400 GPa): H→金属H(涡旋环完全重叠, 质子晶格+电子海)

SCVC: P2 = V_Ampère(H-H)在密度>0.8 mol/cm³时克服分子束缚
```

## 4. 统一视角

```
铁电体:  离子涡旋环位移 → 极化(P)

高压:    涡旋环被压缩  → Ampère势面重构 → 结构相变

全部 = 涡旋环几何在不同控制参数(温度/电场/磁场/压力)下的响应
```
