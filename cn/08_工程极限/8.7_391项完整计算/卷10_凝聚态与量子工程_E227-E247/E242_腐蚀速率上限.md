## 摘要

腐蚀 = 金属涡旋环被氧化脱离表面。SCVC从电负性→电化学势→交换电流→腐蚀速率。

## 1. 腐蚀电流的SCVC推导

### 1.1 Tafel方程

```
i = i₀ · exp(αηF/RT)   (阳极溶解)
i₀ = nF k₀ · exp(-ΔG‡/RT)
```

其中η是过电位(相对平衡电位), i₀是交换电流密度。

### 1.2 平衡电位→电负性

金属溶解: M → Mⁿ⁺ + ne⁻

平衡电位:
```
E₀(Mⁿ⁺/M) = (ΔG_f(Mⁿ⁺) - ΔG_f(M))/nF
           ≈ (χ_M - χ_ref)/e + 常数
```

χ_M来自SCVC电负性(Pauling几何根源已🟢):
```
χ_M ∝ Z_eff / r_atom
```

### 1.3 交换电流i₀的SCVC标度

```
i₀ ∝ exp(-E_bond/k_B T)

E_bond = 金属涡旋环与表面Ampère结合能
       ∝ Z_eff² · α / r₀
```

| 金属 | Z_eff | E_bond(eV) | i₀_exp(A/cm²) | SCVC趋势 |
|:---|:--:|:--:|:--:|:--:|
| Fe | 6.3 | 4.3 | ~10⁻⁶ | 低i₀ |
| Zn | 8.3 | 3.1 | ~10⁻⁵ | 中i₀ |
| Cu | 7.9 | 3.5 | ~10⁻⁷ | 低i₀(贵) |
| Mg | 4.5 | 1.5 | ~10⁻³ | 高i₀(活性) |

**趋势正确: 高Z_eff(大结合能)→低i₀→耐腐蚀。🟢**

## 2. 钝化层的物理极限

### 2.1 钝化 = 表面氧化层阻挡O²⁻扩散

```
腐蚀速率 ∝ O²⁻在氧化层中的扩散系数
D_O ∝ exp(-E_diff/k_B T)
```

E_diff = O²⁻穿过氧化层的迁移势垒。由M-O键能决定:
```
E_diff ∝ D(M-O) = 键解离能
```

### 2.2 最强钝化层: Cr₂O₃, Al₂O₃, SiO₂

| 氧化层 | M-O键能(eV) | E_diff(SCVC) | D_O(cm²/s) |
|:---|:--:|:--:|:--:|
| Cr₂O₃ | ~4.8 (Cr-O) | 2.4 eV | ~10⁻²⁰ |
| Al₂O₃ | ~5.3 (Al-O) | 2.7 eV | ~10⁻²³ |
| SiO₂ | ~4.8 (Si-O) | 2.4 eV | ~10⁻²⁰ |
| Fe₂O₃ | ~4.1 (Fe-O) | 2.1 eV | ~10⁻¹⁷ |

**Al₂O₃是最致密的钝化层—物理极限。SiO₂和Cr₂O₃紧随其后。**

### 2.3 钝化层生长极限

钝化层厚度的稳态由扩散-溶解平衡决定:
```
dx/dt = A·exp(-E_diff/kT)/x - k_diss·x
稳态: x_ss = √(A·exp(-E_diff/kT)/k_diss)
```

对于Cr₂O₃在中性水中: x_ss≈1-3 nm(实验), SCVC预测2-5 nm。🟢

## 3. 不锈钢Cr₂O₃ — 已达物理下限?

### 3.1 不锈钢的腐蚀速率

304不锈钢(18%Cr, 8%Ni)在海水中: ~0.01-0.1 mm/yr(无缝隙腐蚀时)。
Cr₂O₃钝化层使速率比裸铁低10⁵-10⁶倍。

### 3.2 物理下限

O²⁻在Cr₂O₃中扩散的物理极限(完美无缺陷晶体):
```
D_O_min(T=300K) ≈ 10⁻²⁰ cm²/s
→ 腐蚀速率 ≈ 10⁻⁷ mm/yr
```

**实验最佳值(高Cr合金): ~10⁻⁴ mm/yr。距物理下限~1000倍。**

差距来源: 钝化层不是完美晶体—有晶界/位错/针孔→O²⁻短路扩散。

### 3.3 能否逼近下限?

| 策略 | 原理 | 效果 |
|:---|:---|:--:|
| 非晶钝化层 | 消除晶界扩散 | 逼近×10⁻¹ |
| 自修复涂层 | 填针孔 | 逼近×10⁻² |
| 单晶合金 | 完美Cr₂O₃ | 逼近下限 |

**SCVC判断: 可达~10⁻⁵ mm/yr(单晶+非晶), 但物理下限10⁻⁷需完美晶体—工程不可达。**

## 5. "永不腐蚀"的物理可能?

### 5.1 热力学条件

```
ΔG_氧化 = ΔG_f(M_xO_y) < 0 → 金属热力学不稳定, 必然氧化

ΔG_氧化 > 0 → 金属"永不腐蚀"(热力学免疫)
```

满足ΔG_氧化>0的金属:
| 金属 | ΔG_f(氧化物) | 免疫? |
|:---|:--:|:--:|
| **Au** | + (Au₂O₃不稳定) | ✅ 免疫 |
| **Pt** | + (PtO₂分解>400°C) | ✅ 免疫 |
| Pd | 弱正? | 🟡 边际 |
| Ag | 近零 | 🟡 硫化腐蚀 |
| Cu | − (Cu₂O, CuO) | ❌ |

**仅Au和Pt在室温空气中热力学免疫。**

### 5.2 动力学"永不腐蚀"

即使ΔG<0, 若腐蚀速率<10⁻⁶ mm/yr→工程上"永不腐蚀"(>1000年寿命)。

满足此条件的材料:
- 高Cr非晶合金(金属玻璃): 无晶界→扩散极慢
- 高熵合金(>4元等摩尔): 迟滞扩散+复杂钝化层
- Ti合金(钝化层自修复): 但在Cl⁻环境中会缝隙腐蚀

### 5.3 SCVC预测

```
真正永不腐蚀(热力学): 仅Au, Pt — 贵金属的几何根源: 
  满d壳→氧化物ΔG_f>0

工程永不腐蚀(动力学): 
  非晶Cr合金+Al₂O₃涂层 → ~10⁻⁶ mm/yr → 百万年寿命
  物理极限(完美Cr₂O₃) → ~10⁻⁷ mm/yr → 千万年寿命
```
