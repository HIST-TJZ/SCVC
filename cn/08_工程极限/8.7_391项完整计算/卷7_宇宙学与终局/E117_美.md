## §1 对称性为什么"好看"

`
对称 = 低信息复杂度:
  对称物体的一半可以预测另一半。
  预测成本低 → 神经加工快 → "轻松"的感觉。

从SCVC:
  意识带宽 ~200bits/s
  处理一个对称物体: 只需处理一半的信息 → 100bits/s就够了
  处理一个不对称物体: 需要处理全部信息 → 200bits/s
  
  对称 = 神经带宽节省50%。
  "美" = "我的大脑轻松处理了这个东西"的多巴胺奖励。

CP²的对称性:
  Euler示性数 = 3 (CP²的拓扑不变量)
  这是CP²的结构对称度。
  人类觉得"美"的东西往往有和CP²相似的对称群:
    SU(3) → 三维对称 → 球体、螺旋
    U(1) → 圆的完美 → 圆形、拱形
`

## §2 黄金比例φ为什么无处不在

`
φ = (1+√5)/2 ≈ 1.618

φ是"最无理"的比例:
  连分数展开: φ = [1;1,1,1,1,...] → 所有系数都是1
  → φ是所有无理数中最难用有理数逼近的
  → 这意味着φ比例的重复图案最不容易产生干涉条纹(Moiré)

自然界中φ的应用 = 最优填充:
  植物叶序: φ角度排列 → 每片叶子最大采光, 最小遮挡
  松果、向日葵: φ螺旋 → 最多种子, 最少空间
  贝壳: φ螺旋 → 最大强度, 最小材料

φ在人类审美中 = 遗传的"优质"信号:
  φ比例的脸 → 暗示发育中没有大的环境干扰(干扰→偏离φ)
  "美"的脸 = φ比例 → 无意识的健康检测

φ不是"人类发明的美学标准"。
φ是"自然界的最优填充算法",
人类的大脑学会了检测这个算法 → 觉得"美"。
`

## §3 "美"的SCVC定义

`
美 = 低信息复杂度 + 高可预测性 + 安全信号

  低信息复杂度: 对称/φ比例 → 神经加工快 → "轻松"
  高可预测性:   规律/节奏 → 预测确认 → 多巴胺奖励
  安全信号:     熟悉/和谐 → 无威胁 → 杏仁核静默

"丑":
  高信息复杂度 + 低可预测性 + 威胁信号
  不对称/混乱 → 神经加工慢 → "吃力"
  无规律 → 预测失败 → 无多巴胺
  陌生/威胁 → 杏仁核激活 → 不安

但"丑"可以是"有趣的丑":
  如果高复杂度在Lyapunov窗口内被"理解" → 和幽默同构(E112)
  → 预测失败 + 安全化解 → "有深度的美"

美的文化差异:
  "安全"是学习的 → 你熟悉的东西安全
  "对称/φ"是客观的 → 数学
  → 美 = 客观数学(对称/φ) + 主观学习(安全/熟悉)
  → 美的文化差异来自"安全"部分, 共性来自"数学"部分。
`
