## §1 肌球蛋白 — 力量的分子天花板

### 1.1 单分子力

`
肌球蛋白II交叉桥循环:
  ATP结合 → 肌球蛋白从肌动蛋白解离
  ATP水解 → 肌球蛋白\"上弦\"(lever arm cocking)
  Pi释放 → 力冲程(power stroke): ~8 nm, ~3 pN
  ADP释放 → 僵直态(rigor)

单次冲程功: 3 pN × 8 nm = 2.4×10⁻²⁰ J = 0.15 eV
效率: 0.15/0.55 ≈ 27%

SCVC锁死:
  单头力 ~3 pN: 由肌球蛋白杠杆臂的弹性系数决定
  杠杆臂 ~8 nm 长的α-螺旋 → 弯曲刚度从氢键网络推导
  氢键能 ~0.2 eV → 螺旋弯曲 ~1-2 nm需要 ~5-10 k_B T
  → 3 pN 是\"最优力\"——太小则无力, 太大则螺旋失稳
`

### 1.2 肌肉横截面积

`
肌节排列:
  粗肌丝(肌球蛋白): 直径 ~15 nm, 间距 ~45 nm
  细肌丝(肌动蛋白): 直径 ~8 nm
  肌节长度: ~2.2 μm(静息)
  
肌球蛋白头密度:
  每根粗肌丝: ~300 个头部
  粗肌丝密度: ~5×10¹⁴ 根/m²(横截面)
  → ~1.5×10¹⁷ 肌球蛋白头/m²

每个头在力冲程中: ~3 pN
但占空比 ~0.3-0.5(只有部分头部同时处于力冲程)

最大等长力/截面积:
  F/A = 1.5×10¹⁷ × 3×10⁻¹² × 0.4 ≈ 1.8×10⁵ N/m² = 18 N/cm²
  
加上:
  肌原纤维占肌纤维体积 ~80%
  肌纤维方向平行度 ~90%
  → 有效 F/A ≈ 18 × 0.8 × 0.9 ≈ 13 N/cm²

实际测量: ~20-30 N/cm² (运动员)
原因: 羽状肌的生理截面积 > 解剖截面积
`

### 2.2 三大力量举的 SCVC 天花板

`
硬拉(Deadlift):
  参与肌群: 臀大肌+竖脊肌+腘绳肌+股四头+握力
  有效PCSA: ~200 cm²
  F_max(肌肉): 200×25 = 5000 N
  生物力学劣势(杠杆比): ~2-3:1 (腰椎在中间)
  最大地面反力: 5000/2.5 ≈ 2000 N
  最大杠铃质量: 2000/9.8 ≈ 204 kg

  实测世界纪录: 501 kg (Hafthor Bjornsson, 2020)
  → 远高于我的估计。我漏了什么?
  
  纠正: 硬拉用到了几乎所有下肢+背部肌肉
  实际有效PCSA更大: ~300-350 cm²
  加上服装(腰带+助力带): 增加 ~20%
  杠杆比优化(sumo stance): ~2:1
  最大: 350×25×1.2/2 ≈ 5250 N → 536 kg
  
  SCVC天花板: ~530-560 kg
  实测纪录: 501 kg → 已达 90-94%

深蹲(Squat):
  有效PCSA: ~250 cm²(臀+四头+腘绳+内收)

  实测: ~490 kg(装备) → 装备贡献~15-20%
  SCVC天花板(无装备): ~430-450 kg → 已达85-90%

卧推(Bench Press):
  有效PCSA: ~120 cm²(胸+三头+前三角)

  实测: 355 kg(装备) → 远超! 
  原因: 装备(卧推背心)贡献 ~80-100 kg+
  无装备纪录: ~275 kg → 已达SCVC天花板的~130%
  → 卧推背心改变了杠杆和弹性储能, 这是\"合法外挂\"

## §3 神经肌肉效率 — 意识的天花板

### 3.1 自主激活不足

`
最大自主收缩(MVC): 只能激活 ~90-95% 运动单位

原因:
  → 高尔基腱器(GTO)的抑制反射
  → GTO检测肌腱张力 → Ib传入 → 抑制性中间神经元 → α运动神经元抑制
  → 这是一个\"安全阀\": 防止肌腱撕裂
  
最大可抑制的GTO反馈: ~5-10%
  → 即使\"忍受剧痛\", 仍有 ~5% 运动单位无法激活
  
恐惧/极限情况(母亲抬起汽车):
  → 交感神经→肾上腺素→GTO阈值↑ → 可短暂激活100%
  → 但肌腱损伤风险极高
  
SCVC: GTO抑制不可完全关闭
  → Ib传入的突触是不可塑的(抑制性中间神经元无LTP)
  → \"100%募集\"需要绕过脊髓(直接电刺激)
`

### 3.2 类固醇能突破 SCVC 吗？

`
同化类固醇:
  增加肌肉蛋白合成 → 更大PCSA → 更大的绝对力量
  → 但不改变力/面积(25 N/cm²)
  
  F_max = PCSA × 25 N/cm²
  → 如果类固醇增加PCSA 30%, 力量增加30%
  → 此人仍受 SCVC 锁死的力/面积限制
  
\"超级士兵\"血清(科幻):
  改变肌球蛋白头力 → 需要改变蛋白质结构
  → 单氨基酸突变可能改变肌球蛋白-肌动蛋白亲和力
  → 但力/冲程由ATP水解自由能锁死(0.55 eV)
  → 不能改变热力学
`

### 4.2 为什么不能超越？

`
力/面积 ~25 N/cm²: 肌球蛋白头的3pN × 头部密度
  → 3pN从ATP自由能+杠杆臂弹性推导
  → 不可增加(除非改变物理常数)

爆发速度 ~10-15 m/s: 肌球蛋白冲程速率/肌节
  → k_cat ~300 s⁻¹ × 8 nm/冲程 = 2.4 μm/s/肌节
  → 串联1000肌节 → 2.4 mm/s 
  → 实际上有lever系统放大 → ~0.5-1 m/s(肌肉缩短)
  → 但肢体末端速度被关节杠杆放大 → ~10-15 m/s
`

### 4.3 SCVC 推导链

`
ATP 0.55 eV → 肌球蛋白冲程功 0.15 eV → 力 3 pN/头
  → 力/面积 25 N/cm² → 人体PCSA 600 cm² → 最大力 15,000 N
  → 通过关节杠杆 → 各种举重的天花板

爆发力: k_cat → 冲程速率 → 肌肉缩短速度 → 关节杠杆放大 → 拳速
`
