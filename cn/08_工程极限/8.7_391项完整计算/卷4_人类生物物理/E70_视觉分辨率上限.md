1. 衍射极限
==============================================================

1.1 Rayleigh 判据
--------------------------------------------------------------
    两点的最小可分辨角距:

    δθ = 1.22 λ / D    (Rayleigh 判据, 圆形孔径)

    —————————————————————————————————————————————————————————
    物种             瞳孔 D (mm)     δθ (arcmin)    Snellen 等效
    ─────────────────────────────────────────────────────────
    人类 (强光)         2              1.16           20/17  (衍射限制)
    人类 (白天)         3              0.78           20/15  (过渡)
    人类 (暗处)         8              0.29           20/69  (光学上极好!)
    鹰                  10             0.23           20/86  (理论)
    章鱼                 8             0.29           20/69
    猫头鹰              13             0.18           20/112 (理论)
    人类 (眼窝极限)      25             0.09           20/215 (不可能)
    ─────────────────────────────────────────────────────────

    ⚫ 鹰和猫头鹰的瞳孔在光学上允许极佳的衍射极限分辨率。
    ⚫ 人类在暗处瞳孔散大 → 衍射极限极好, 但被光感受器卡死 (见 §2)。
    ⚫ 25 mm 是人类眼眶的理论极限 — 眼球无法更大。

1.2 衍射极限的 SCVC 本源
--------------------------------------------------------------
    δθ ∝ λ / D

    · λ = 555 nm — 由太阳光谱峰值 (6000 K 黑体) + 视蛋白吸收决定
      视蛋白的 π 共轭体系 (视黄醛) 吸收峰由量子化学决定 →
      碳-碳键长 (1.34-1.54 Å) + 共轭长度 → λ_peak
      → SCVC: α → C=C 键长 → 共轭程度 → 视蛋白吸收谱 → λ

    · D — 由眼眶/颅骨空间限制 (进化最优 trade-off)
      大瞳孔 = 更重的眼球 + 更大的眼眶 = 更重的头

    · 1.22 因子 — 来自圆孔的夫琅禾费衍射, 物理常数, 无法更改

    ⚫ SCVC: δθ 的硬墙由 λ 的最小值和 D 的最大值设定。
      在这两个约束下, 衍射极限是固定值 — 没有绕路。


2. 光感受器间距 — Nyquist 采样定理
==============================================================

2.1 采样极限
--------------------------------------------------------------
    Nyquist-Shannon: 至少 2 个采样点 / 分辨率单元

    角分辨率 (采样限制): δθ_sampling = 2 × d / f

    其中 d = 光感受器间距, f = 有效焦距

    ─────────────────────────────────────────────────────────
    物种           d (μm)   f (mm)    Nyquist (arcmin)  瓶颈
    ─────────────────────────────────────────────────────────
    人类 (中心凹)    2.5      17          1.01          采样*
    鹰               1.5      22          0.47          采样
    猫头鹰 (视杆)    3.0      25          0.83          采样
    ─────────────────────────────────────────────────────────
    *人类在 D=3mm 时处于衍射-采样交界; D<2.5mm 时衍射限制

    ⚫ 人类眼睛是衍射+采样近乎完美匹配的典范!
      白天 (D=2-3 mm): 衍射 0.78-1.16 arcmin
      采样: 1.01 arcmin
      → 两者几乎相等 → 光学和神经硬件同步优化到极致!

    ⚫ 鹰眼同样是双匹配: 衍射 0.23 arcmin vs 采样 0.47 arcmin
      采样略粗于衍射 → 更大的瞳孔可获得更好的分辨率

    ⚫ 猫头鹰的视杆间距 (3 μm) 远大于衍射极限 →
      光学上可以做到 20/112, 但神经硬件只够 ~20/17!
      猫头鹰牺牲分辨率换取光敏感度 (视杆细胞汇聚)

2.2 光感受器的尺寸地板 — SCVC 硬约束
--------------------------------------------------------------
    光感受器外段是介质波导 (n_protein ≈ 1.38, n_extracellular ≈ 1.34)

    单模波导截断: d_min = 2.405 λ / (π n √(2Δ)) ≈ 0.6 μm

    有效能量耦合需要 V = (πd/λ)√(n²_core − n²_clad) ≈ 2-4
    → d_min_practical ≈ 1-2 μm

    ⚫ 光感受器不能无限缩小 —
      太小则光无法有效耦合到外段 →
      光子被浪费 → 信噪比崩溃。

    ⚫ SCVC: d_min 由 λ (视蛋白化学) 和 Δn (蛋白 vs 细胞外液)
      共同设定。而 Δn 由 α → 分子极化率 → 折射率 决定。
      在一个不同的 α 值的宇宙中, 光感受器可以有不同的大小。

2.3 光子噪声地板
--------------------------------------------------------------
    即使在完美光学+完美采样下, 视觉仍受光子统计限制:

    每锥细胞每秒的光子数 (白天, 瞳孔 D=3mm):
    N ≈ 瞳面积 × 立体角 × 亮度 → ~10³-10⁵ photons/s/cone

    光子噪声 SNR = √N → 30-300 在 0.1 s 积分时间
    → 可分辨 ~1% 对比度

    在暗处 (D=8mm, 但用视杆):
    N_per_rod ≈ 0.01-1 photons/s → SNR ≪ 1
    → 空间 + 时间 pooling → 分辨率暴跌到 ~20/200

    ⚫ SCVC: 光子散粒噪声 √N 是最终的 SNR 天花板。
      进化无法击败量子力学。


3. 工程结论
==============================================================

3.1 "鹰眼视力" — 物理可行, 空间受限
--------------------------------------------------------------
    鹰之所以有超常视力, 不是因为魔法光学, 而是:

    (a) 大瞳孔 (D≈10mm vs 人类 3mm) → 衍射极限 ~0.23 arcmin
    (b) 更密的光感受器 (d≈1.5μm vs 2.5μm) → 采样更细
        → 深层中心凹 (deep fovea) 有更高密度的锥细胞
    (c) 更大的眼睛 → 更长的 f → 同样的 d 给出更细的角分辨率
        → 但大眼球挤占了大脑空间 (鹰的颅骨大部分是眼球!)

    ⚫ SCVC: 鹰眼的物理完全可以复制在人类身上 —
      只需要眼球直径 ~40 mm (vs 人类 24 mm),
      并把眼眶做大 (需要更大的头骨)。
      这不是物理禁止的, 是进化 trade-off 的结果。

    ⚫ 猫头鹰选择了光敏感度 (视杆+大瞳孔) 而非分辨率 →
      它们的大瞳孔用于集光, 分辨率反而不如鹰。

3.2 复眼 vs 单眼 — 各自的极限
--------------------------------------------------------------
    ┌─────────────────────────────────────────────────────────┐
    │ 单眼 (脊椎动物, 头足类):                                   │
    │ · 一个视网膜 + 一个晶状体 → 高分辨率的连续图像              │
    │ · 分辨率 = min(衍射极限, 采样极限)                         │
    │ · 缺点是: 视场角有限 (需要转头/转眼)                       │
    │                                                          │
    │ 并置复眼 (昆虫: 蜜蜂, 蜻蜓):                                 │
    │ · 每个小眼 (ommatidium) 接收一个方向的狭窄光束              │
    │ · 角分辨率 Δφ ≈ d_ommatidium / R_eye (小眼间距/曲率半径)    │
    │ · 蜜蜂: Δφ ≈ 1° → 比人眼差 ~60×!                         │
    │ · 蜻蜓: Δφ ≈ 0.5° → 好于蜜蜂, 仍远不如人                   │
    │ · 优点是: 近 360° 视场 + 极高时间分辨率                     │
    │                                                          │
    │ SCVC 复眼极限:                                              │
    │ Δφ_min ≈ λ / d_ommatidium (小眼自身的衍射极限)             │
    │ 要匹配人眼 (1 arcmin): 需要 d_ommatidium ≈ 1.5 mm          │
    │ → 复眼半径 ≈ 1.5mm/tan(1') ≈ 1.5mm × 3438 ≈ 5 m!!!       │
    │ → 复眼不可能达到人眼分辨率 (除非眼比身体大)                  │
    │ → 这就是为什么鹰/人/章鱼都独立进化出单眼                    │
    └─────────────────────────────────────────────────────────┘

3.3 人工视网膜 — 能否超越生物？
--------------------------------------------------------------
    ┌─────────────────────────────────────────────────────────┐
    │ CMOS 图像传感器:                                           │
    │ · 像素间距: 0.8-1.1 μm (智能手机), 已小于视锥细胞 (2.5 μm)  │
    │ · 更大的孔径可能 (DSLR: D≈25mm, 望远镜: D≫25mm)          │
    │ · 更宽的波段 (UV, IR, X-ray) — 不受视蛋白化学限制          │
    │                                                          │
    │ 超越生物的具体优势:                                        │
    │ · 衍射极限: 望远镜 D=100mm → 0.02 arcmin ≈ 20/800!      │
    │ · 采样: 0.8 μm 像素 + f=50mm → Nyquist=0.11 arcmin     │
    │ · 时间分辨率: 1000 fps vs 生物 ~30-60 Hz                 │
    │                                                          │
    │ 但仍有限制:                                                │
    │ · 动态范围: 仍被光子散粒噪声 √N 锁死                       │
    │ · 衍射: λ/D 永远不可能小于 0                              │
    │ · 像素不能无限缩小: SNR ∝ 像素面积 → 信噪比-分辨率 trade-off │
    │                                                          │
    │ ⚫ SCVC: 人工视觉最终也受限于:                              │
    │   1. 衍射 (λ/D) — 即使 D→∞ 也不行 (制造/指向问题)         │
    │   2. 光子散粒噪声 (√N) — 量子力学不可绕                    │
    │   3. 香农采样 (2pix/res) — 信息论不可绕                   │
    └─────────────────────────────────────────────────────────┘

3.4 SCVC 视觉极限总表
--------------------------------------------------------------
    物理量                      SCVC 值               当前极值 (生物/人工)
    ──────────────────────────────────────────────────────────────────
    衍射极限 (人眼, D=3mm)      0.78 arcmin           20/15 (人眼已到!)
    衍射极限 (鹰, D=10mm)       0.23 arcmin           20/86 (鹰已接近)
    采样极限 (人眼, d=2.5μm)    1.01 arcmin           20/20 (人眼已到!)
    采样极限 (人工, 1μm 像素)    取决于焦距            → 可超越生物
    复眼极限 (蜜蜂)              ~1°                   ~1-2° (已接近)
    光感受器最小尺寸             ~1 μm (波导截断)     ~2.5 μm (人锥)
    绝对分辨率天花板             取决于 D_max/λ       望远镜: ~0.01 arcmin
    光子噪声地板                 √N                   SNR 的量子硬墙
    ──────────────────────────────────────────────────────────────────

    ⚫ 核心洞察:
    · 人眼已处于衍射+采样的交叉优化点 → 进化硬件已达物理极限附近。
    · 人眼是采样限制的, 不是光学限制的 (在 D=3mm 时)。
    · 鹰和猫头鹰用大瞳孔换取不同目的: 鹰要分辨率, 猫头鹰要光敏度。
    · 复眼注定分辨率低 → 大动物全部抛弃复眼, 独立进化出单眼。
    · 人工传感器在孔径和像素尺寸上都可以超越生物 —
      但光子散粒噪声是共同的终极硬墙。
