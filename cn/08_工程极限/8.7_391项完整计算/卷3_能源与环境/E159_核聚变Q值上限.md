## §1. D-T聚变：从SCVC到Lawson判据

### 1.1 Gamow隧穿——α的双重角色

D-T聚变的反应率由两个SCVC常数共同决定：

```
量子隧穿概率: P ∝ exp(-π × α × Z₁Z₂ × √(2m_r c²/E))

α = 1/137 → 库仑势垒穿透（电磁）
α_s = 1/(16π) → 核矩阵元（强核力）

D-T反应: 17.6 MeV (来自核结合能差 → α_s)
```

|-----------|----------|---------|-----------------|
| 1 | 49.5 | 3×10⁻²² | ❌ 太冷 |

> 隧穿概率从α直接推导。α增大1% → 隧穿概率变化~10% → 聚变功率变化~10%。**SCVC以2.22ppm精度锁定α → D-T反应率被精确锁定。**

### 1.2 Lawson三重积与Q值

能量平衡：

```
P_α + P_external = P_loss

P_α = P_fusion/5（α粒子加热，沉积在等离子体中）
P_fusion = n² × <σv> × E_fusion/4
P_loss = 3nkT/τ_E

Q ≡ P_fusion / P_external
```

推导Lawson判据：

```
nTτ_E = 12 T² / [<σv> × E_fusion × (1/5 + 1/Q)]

在T≈15 keV（最优温度），<σv>≈10⁻²² m³/s:
```

| Q值 | nTτ_E (keV·s/m³) | 含义 |
|-----|-------------------|------|
| 1 | 1.3×10²¹ | 得失相当 |
| 5 | 3.8×10²¹ | 燃烧等离子体（α加热主导） |
| **10** | **5.1×10²¹** | **ITER目标** |
| 50 | 7.0×10²¹ | 商业可行 |
| ∞ | 7.7×10²¹ | 点火（自持） |

> **Q→∞时nTτ_E收敛到有限值7.7×10²¹** — 这意味着"点火"是一个明确可达的物理阈值，而非逐渐逼近的渐近线。一旦超过 7.7×10²¹，等离子体**自持燃烧**（不需要外部加热）。

### 2.3 物理限制——Q不能无限大

| 限制 | 机制 | SCVC来源 | 约束 |
|------|------|----------|------|
| **β极限** | MHD不稳定性(Troyon) | 等离子体压力/磁压 | β_N ≤ 3-4 |
| **第一壁热流** | 偏滤器热负荷 | 材料熔化（键能~3-8 eV） | q ≤ 5-10 MW/m² |
| **中子壁负载** | 结构材料损伤 | 原子离位能~25 eV | ≤ 2-3 MW/m² |
| **氚增殖TBR** | 中子学+锂富集 | 核截面（α_s） | TBR ≥ 1.0 |
| **尺寸成本** | B²V ∝ 成本 | — | R ≤ 10-12 m 经济上限 |

**β极限的SCVC物理：**

```
β = 2μ₀nkT / B² ≤ β_crit

β_crit由MHD稳定性决定。压力梯度驱动不稳定性的阈值:
  ∇p_crit ∝ B² / (μ₀ R q²)

→ β_max ∝ 1/q²（q为安全因子, ≥2-3）
→ 对于托卡马克: β_max ≈ 5-10%
→ 对于球马克: β_max ≈ 30-40%（但B较低→Q较低）
```

### 2.4 Q的实际天花板

| 约束 | 对应Q上限 | 如何突破 |
|------|---------|----------|
| β极限 | Q不受β直接限制（功率密度在β_max内可优化） | — |

**SCVC实用天花板：Q ≈ 300-500（B=20T HTS, R=10m, 先进偏滤器）。** 远高于商业需求（Q≥50），也远超ITER的Q=10。
