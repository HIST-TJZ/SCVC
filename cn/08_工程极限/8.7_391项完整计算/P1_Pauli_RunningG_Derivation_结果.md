## §1.2 GP方程与涡旋剖面

### 1.2.1 无量纲径向GP方程

单个n=1涡旋的解ψ(r,θ) = f(r) e^{iθ}，f(r)满足：

```
f'' + f'/r - f/r² + f - f³ = 0
```

边界条件：f(0) = 0（核心），f(∞) = 1（体BEC）。

数值解（shooting method）：c₁ = f'(0) = 0.583187，有效愈合长度ξ_eff = 1.3176。

在r < ξ范围内积分得E_CORE = 2.1322：

## §1.3 两个涡旋重叠的能量

### 1.3.1 重叠构造

两个相同缠绕的涡旋在距离d处：

```
ψ(r) = f₁(r) × f₂(r) × e^{i(θ₁+θ₂)}
f₁(r) = tanh(|r − d/2|/ξ)
f₂(r) = tanh(|r + d/2|/ξ)
```

### 1.3.2 极限分析

**d = 0（完全重叠）**：等效缠绕n_eff = 2的涡旋。

由于所有能量项主导标度∝n²：
```
E(n=2) ≈ 2² × E_CORE = 4 × E_CORE = 8.5288
E_separated = 2 × E_CORE = 4.2644
ΔE_Pauli(0) = 4E_CORE − 2E_CORE = 2 × E_CORE = 4.2644
```

**乘以质量因子和缠绕范数**：
```
V_Pauli(0) = 2 × E_CORE × mf × |w|²
```

**d → ∞（完全分离）**：涡旋独立 → V_Pauli → 0（指数衰减）。

### 1.3.3 有限距离：重叠积分

两个tanh涡旋剖面的重叠积分：

```
I_overlap(d) = ∫ (1−tanh²(r₁))(1−tanh²(r₂)) d²r
             = ∫ sech²(r₁/ξ) sech²(r₂/ξ) d²r
```

当涡旋核半径~ξ时，该积分的解析结果：

```
I_overlap(d) = πξ² × 2 × sech²(d/ξ)
```

因此排斥势的完整形式：

```
┌─────────────────────────────────────────────────────────┐
│  V_Pauli(r) = 2 × E_CORE × mf × |w|² × sech²(r/ξ)    │
│                                                         │
│  同色同味：w₁ = w₂ → 全排斥                              │
│  不同色：  w_c分量正交 → V_Pauli = 0                     │
│  不同味：  w_w,w_y分量正交 → V_Pauli = 0                 │
│  反夸克：  w → −w → V_Pauli < 0（BEC亲和吸引）          │
└─────────────────────────────────────────────────────────┘
```

## §1.5 颜色依赖性的严格论证

### 1.5.1 SU(3) Cartan子代数

夸克涡旋的SU(3)颜色缠绕取值于Cartan子代数的权重格点：

```
w_color = (w_c1, w_c2) ∈ {权重 of 3}
```

对于3表示，三个颜色态的权重向量：
```
红色：  w_R = (+1/2, +1/(2√3))
绿色：  w_G = (−1/2, +1/(2√3))
蓝色：  w_B = (0,    −1/√3)
```

### 1.5.2 正交性

三个权重向量互不正交但线性无关。**关键**：两个不同颜色的夸克涡旋，其颜色缠绕向量不同 → 4D缠绕向量(w_c1, w_c2, w_w, w_y)整体不同 → 涡旋在内部空间属于不同拓扑扇区。

在BEC中，不同拓扑扇区的涡旋**不共享相同的序参量零点结构** → 重叠不导致有效缠绕数翻倍 → **无Pauli排斥**。

```
同色：ΔE_Pauli = 2E_CORE × mf × |w|² (全排斥)
异色：ΔE_Pauli = 0 (可共存)
```

这正是QCD中"颜色自由度允许三个夸克在重子中占据相同空间波函数"的SCVC版本：**三个不同颜色的夸克在BEC中处于彼此正交的拓扑扇区，可以占据同一空间区域而不产生Pauli排斥**。

# 第二部分：跑动G_STRONG(r)

## §2.1 SCVC中涡旋耦合的物理

### 2.1.1 涡旋-涡旋对数势

SCVC模拟中，两个涡旋通过BEC超流耦合：

```
V_ij(r) = −G × (w_i·w_j) × log(1 + r²/ξ²)
```

其中G = G_STRONG（强耦合）或G_EM（电磁耦合）。

### 2.1.2 为什么G应该跑动？

在量子场论中，耦合常数因虚粒子对（真空极化）而跑动。在SCVC中，真空极化对应BEC介质极化——虚涡旋-反涡旋对的产生和湮灭。

物理图像：
- **短距离（r < ξ）**：探头涡旋"看到"的是裸BEC，周围涡旋对涨落尚未形成 → 有效耦合减小
- **长距离（r > ξ）**：BEC完全愈合，所有虚涡旋对效应已包含 → 耦合达到体值G_STRONG

这就是SCVC版本的**渐近自由**。

## §2.2 BEC介质极化

### 2.2.1 极化函数

SCVC的BEC中，涡旋-反涡旋对产生的极化函数（RPA近似）：

```
Π(q) = b₀ × log(1 + 1/(q²ξ²))
```

其中：

```
b₀ = (N_c + n_f/2) / (2πρ_s)
```

N_c = 3（颜色数），n_f = 3（轻味数，低能下有效）。

数值：
```
b₀ = (3 + 1.5) / (2π × 6.5797) = 4.5 / 41.33 ≈ 0.1089
```

### 2.2.2 跑动耦合

有效耦合由RPA重求和给出：

```
G_eff(q) = G_STRONG / [1 + G_STRONG × Π(q)]
         = G_STRONG / [1 + b₀ × G_STRONG × log(1 + 1/(q²ξ²))]
```

Fourier变换到坐标空间（近似）：

```
┌──────────────────────────────────────────────────────────────┐
│  G_eff(r) = G_STRONG / [1 + b₀ × G_STRONG × log(1 + ξ²/r²)] │
│                                                              │
│  b₀ = (N_c + n_f/2) / (2πρ_s) = 0.1089                      │
│  b₀ × G_STRONG = 0.3594                                     │
└──────────────────────────────────────────────────────────────┘
```

## §2.3 渐近行为

### UV极限（r → 0）

```
log(1 + ξ²/r²) → ∞
G_eff(r) → G_STRONG / [b₀ × G_STRONG × log(ξ²/r²)]
         = 1 / [b₀ × 2log(ξ/r)]
         → 0
```

**渐近自由**。当探头距离远小于ξ时，有效耦合对数衰减至零。

对应关系：
```
α_s_SCVC(Q² ≫ ξ⁻²) ≈ 1 / [b₀ × 4π × log(Q²ξ²)]
                     = 1 / [16π × log(Q²ξ²)]
```

其中16π = 4π/b₀_SCVC? 需要验证：
4π × b₀ = 4π × 0.1089 = 1.368 ≠ 16

→ SCVC的b₀不同于微扰QCD的b₀_QCD = (33 − 2n_f)/3 ≈ 9（对n_f=3）。这是合理的：SCVC的"规范群"是拓扑的（涡旋缠绕），不是局域SU(3)。

### IR极限（r → ∞）

```
log(1 + ξ²/r²) → 0
G_eff(r) → G_STRONG = 3.30
```

**红外固定点**。耦合不趋于无穷——SCVC无Landau极点。这是SCVC区别于QCD的关键特征。

**G_STRONG = 3.30作为一个IR固定点的物理含义**：长距离处涡旋耦合由BEC超流密度唯一确定。强耦合不是"跑动到无穷"（禁闭），而是**饱和在一个有限值**。禁闭在SCVC中是拓扑效应（涡旋凝聚），而非耦合发散。
