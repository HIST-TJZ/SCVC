## §0前置. 反向博弈论 vs 机制设计 —— 参数从哪来，是全部的区别

### 0.0 机制设计已经存在了60年

2007年诺贝尔经济学奖授予Hurwicz、Maskin、Myerson，表彰他们创立了**机制设计**（Mechanism Design）。其核心思想与反向博弈论表面相似：

| | 核心问题 | 方法 |
|:---|:---|:---|
| 经典博弈论 | 给定规则 → 人会怎么玩？ | 均衡分析 |
| 机制设计 | 想要这个结果 → 应该设什么规则？ | 逆向设计激励 |
| 反向博弈论 | 物理墙在哪 → 唯一可行路径 → 不走 = 自曝 | 物理常数锁死选项 |

**表面看是同一件事。实质不是。**

### 0.1 参数从哪来——这是全部的区别

```
机制设计（Hurwicz）:
  设计者选择: 检测概率 p、惩罚力度 S、激励强度 I
  → p = 审计频率 × 审计质量 → 可以被预算削减
  → S = 法律条文 → 可以被游说修改
  → I = 补贴额度 → 可以被下届政府推翻
  → 所有参数都是人定的 → 有钱有权的人可以弯折规则

反向博弈论:
  物理墙决定: 检测概率 p、逃逸成本 C、可行路径数 N
  → p ≈ 1（B层透明 → 信息不对称被物理消除，不是"加强审计"）
  → C ≫ 收益（ATP预算崩溃、中微子不可屏蔽 → 不是"加大惩罚"）
  → N = 1（物理墙之间只有一条缝 → 不是"设计激励"，是"锁死选项"）
  → 所有参数都是物理常数锁死的 → 有钱有权的人也无法弯折
```

### 0.2 具体例子：TK-C的20%利率

```
机制设计会怎么做:
  "我们给透明企业贷款贴息，主动透明的企业享受低利率"
  → 需要财政拨款 → 需要审批 → 需要"相信政府会持续补贴"
  → 下届政府可能停止 → 企业观望 → 没有人先透明

反向博弈论怎么做:
  "透明企业的数据自动进入银行风控系统 → 利率自然降到1-2%"
  "不透明的企业 → 银行无法评估 → 利率20%，且银行会问:
   '为什么不要1%？' → 无法解释 → 不仅是贵，是直接拒贷"

  → 不需要补贴 → 不需要审批 → 不需要"相信政府"
  → 选20% = 在数学上等价于承认你在骗
  → 不需要任何人来判断 → 信息透明本身替你判断了
```

### 0.3 为什么这个区别是实质性的

```
机制设计的阿喀琉斯之踵:
  "谁来设计设计者？"（quis custodiet ipsos custodes?）
  → 设计规则的人本身不在规则内
  → 设计者可以被收买、可以被推翻、可以衰老死亡
  → 规则随设计者而变

反向博弈论的答案:
  "不需要设计者。"
  → 物理常数不会衰老、不会被收买、不需要换届
  → α = 1/(4π³+π²+π) 今天和100亿年后一样
  → 透明系统一旦上线 → p_detect≈1 是物理事实，不是政策选择
  → 不是"我相信设计这个制度的人" → 是"我验证了物理常数"
```

### 0.4 这个区别意味着什么

```
机制设计 = 规则工具
  → 规则是人写的，设计者可以被收买、被推翻

反向博弈论 = 物理本身执行规则
  → 不是"设计了一套更好的规则"
  → 是物理常数锁死了所有非合作路径的参数
  → α和Landauer极限不接受谈判
```

## §0追加. 反向博弈论——五类行为归零

反向博弈论不是在"优化策略"——是在**重新设计游戏本身**使得五类有害行为的期望值趋近于零。

`

  内幕交易、虚假宣传、隐藏排放数据
  E[收益] = 隐藏信息价值 × (1−p_detect) − 惩罚 × p_detect
  p_detect ~5-10% → E[收益] >> 0 → 泛滥

ABC世界:
  B层: 所有交易可见，所有供应链可追溯 → p_detect ≈ 1
  E[收益] = 价值 × (1−1) − 惩罚 × 1 = −惩罚 → 负期望

  例子: 公司隐藏排放
    旧世界: 被抓住概率5% → 预期成本 = 0.05 ×  =  → 值得冒险
    ABC:     B层自动记录所有排放 → 100%检测
            → 隐藏成本 = 确定的严厉制裁
            → E[信息套利] → 0
`

### 类型2: 跨期剥削 → 期望 ~0

`

  复利 → 资本指数增长 → 富者愈富
  囤积稀缺资源 → 人为稀缺 → 价格操纵

## §1. 根本原因：永生——不是气候

### 1.1 E208的遗漏

E208把ABC描述为"气候战时社会"——为了迫使100%合作而设计的透明架构。这在应用层面是正确的，但遗漏了最根本的问题：

**ABC不是为气候而生的。ABC是为永生而生的。气候只是永生文明面临的第一个测试。**

### 1.2 永生的大脑会溢出

`
人脑存储容量:
  突触: ~10¹⁵
  每突触: ~4.7 bits（约26种可区分状态）
  总容量: ~5×10¹⁵ bits ≈ 588 TB

意识记忆输入速率（E92）:
  ~100 bps → ~3.2×10⁹ bits/年

填满大脑所需时间:
  5×10¹⁵ ÷ 3.2×10⁹ ≈ 150 万年

→ 在正常寿命中永远不会填满
→ 但在永生中: 150万年后，记忆溢出
→ 没有外部存储 = 旧记忆覆盖新记忆 = 身份丢失 = 疯狂
`

`
B层 = 外部硬盘:

  10亿永生者 × 100 bps = ~0.4 EB/年
  存储成本（当前 ~/TB/年）: ~/年 → 可忽略
  
  B层不仅记录碳排放。
  B层记录每一个永生者的身份连续性。
  B是你"是谁"的外部锚点。
  
  当生物大脑的记忆满了:
    → 查询B: "我在公元50321年做了什么？"
    → B返回记录 → 你恢复了自己的连续性
    → 这是"数字永生"——不是意识上传，是记忆外挂

### 1.3 C层的真正功能：防止无限时间的疯狂

`
在有死之人的世界里:
  冲动决策的代价是有限的（你只会后悔~50年）

在永生者的世界里:
  冲动决策的代价是无限的（你会后悔永恒）
  → 每一个冲动都可能玷污你无限的未来身份
  → 没有缓冲 = 决策瘫痪 或 冲动疯狂

C层 = 决策缓冲器:
  Tier 1 (3天):    "我要离婚" → 等3天 → 可能不离婚了
  Tier 2 (30天):   "我要起诉邻居" → 等30天 → 和解了

  Tier 4 (365天):  "我要改造大气层" → 等1年 → 想清楚了

  延迟不是审查。延迟是永生者的安全机制。
  在无限时间中，3天到1年的等待不是代价——
  是保护你不做你会在永恒中后悔的事。
