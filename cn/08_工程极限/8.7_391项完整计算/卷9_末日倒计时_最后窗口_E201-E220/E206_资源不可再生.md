## §1. 煤：石炭纪窗口已被白腐真菌永久关闭

### 1.1 石炭纪的"完美风暴"（3.6-3.0亿年前）

三个条件恰好同时满足——缺一不可：

`
条件 1: 木质素刚进化出来
  C-C 键 3.6 eV → 木质素提供结构支撑 → 树能长到 30 米
  → 巨大的陆地生物量 → 巨量有机碳

条件 2: 木质素分解酶还不存在
  白腐真菌尚未进化 → 没有生物能分解木质素
  C-C 键 3.6 eV 太稳定 → 没有任何酶的活性位点能打断它
  → 死树不腐烂 → 堆积

条件 3: 广阔的缺氧沼泽
  盘古大陆形成 → 巨大低洼沼泽
  死树沉入缺氧泥潭 → 不被氧化分解
  → 埋藏 → 压力+温度 → 煤

这个窗口持续了 ~6000 万年。
在此期间形成的煤 = 人类工业革命所用的全部"容易能量"。
`

### 1.2 为什么永远不会再来？

`
石炭纪结束后（约 3 亿年前）:
  白腐真菌进化出: 漆酶（laccase）、锰过氧化物酶（MnP）
  
  这些酶终于找到了打断 C-C 键 3.6 eV 的催化路径。
  从那一刻起:
    死树 → 数周内被真菌定殖 → 数年内完全腐烂 → CO₂ 回到大气
    森林不会变成煤 → 只会变成蘑菇。

现代净煤形成率 ≈ 零:
  全球光合作用固碳: ~120 GtC/年
  呼吸+分解返回:    ~120 GtC/年
  净埋藏（泥炭）:    ~0.1-0.2 GtC/年 —— 这是泥炭，不是煤

即使刻意制造缺氧沼泽:
  泥炭积累速率: ~0.5-1 mm/年
  形成 1m 厚泥炭层: 1,000-2,000 年
  压缩成煤（10:1 体积比）: 10,000-20,000 年 → 才 1 米煤
  工业革命需要 >10m 厚的露头煤层: >100,000 年
`

`
SCVC判断:
  C-C 键 3.6 eV → 木质素的化学稳定性
  → 进化花了 6000 万年才找到分解它的酶
  → 酶一旦出现 → 进化不会倒退
  → 煤的窗口被生物学永久关闭
  
  不是"需要等几百万年"
  是"永远不会"
  除非你逆转 3 亿年的进化——这比逆转熵还难
`

## §2. 石油：现代海洋环流堵死了缺氧保存窗口

### 2.1 石油形成的苛刻条件

`
① 海洋浮游生物爆发 → 巨量有机物沉降
② 底层水缺氧 → 有机物不被氧化 → 保存
③ 快速埋藏 → 沉积物覆盖 → 温压转化 → 烃类
④ 储层+盖层 → 不逸散到地表

侏罗纪-白垩纪（2.0-0.66 亿年前）:
  多次全球缺氧事件（OAEs）→ 恰好对应主要生油层
  当时全球海洋环流缓慢 → 深海缺氧 → 有机物保存率极高
`

### 2.2 为什么不会再有？

`
现代海洋:
  温盐环流（AMOC 等）→ 极地冷水下沉 → 深层海水充分充氧
  有机物沉降途中 → 被中层水细菌分解
  保存率: <0.1% 初级生产力
  净石油形成率: ≈ 零（比人类开采速率低数个量级）

全球变暖可能造成局部缺氧:
  但规模远不及白垩纪全球缺氧事件
  即使有有机物埋藏 → 需要数千万年成熟 → 人类文明等不起
  
  → 现代海洋环流是石油形成的"永久制动"
  → 除非停止全球温盐环流（那首先是 AMOC 崩溃=人类末日）
`

## §3. 高品位矿：全都是"一次性地球事件"

### 3.1 铁：大氧化事件不会重演

`
条带状铁建造（BIF，前寒武纪 25-18 亿年前）:
  
  早期地球海洋: 富含溶解 Fe²⁺
  蓝藻开始产 O₂（大氧化事件）→ Fe²⁺ → Fe₂O₃ 沉淀
  → 硅质层与铁质层交替沉积 → BIF
  
  这是地球从无氧到有氧转变的独特产物
  → 在地球 45 亿年历史中只发生了一次
  → 所有后续高品位赤铁矿（>60% Fe）都是 BIF 风化富集
  
  现在: 海洋中几乎没有溶解 Fe²⁺（被 O₂ 氧化光了）
  → BIF 永远不会再形成
`

### 3.2 铜、锡、稀土：品位单向下降

`
热液矿床:
  需要: 岩浆侵入 + 流体循环 + 裂隙系统
  形成周期: 10⁵-10⁶ 年
  但新形成的都是低品位浸染矿 → 不会有露头高品位脉矿
  
  原因: 高品位露头脉矿需要风化剥蚀暴露 → 10⁴-10⁷ 年
        浅层高品位部分已被采尽
        剩余深层矿的品位系统性低于已采浅层矿

SCVC: 矿石品位是单向熵增过程
  → 高品位矿脉（低熵）→ 尾矿/垃圾填埋场（高熵）
  → 逆转需要至少同等的能量投入
  → 那个能量（煤）已经烧光了
`
