# SCVC工程极限：代谢率+寿命 — 一生的总代谢预算

**任务**：从SCVC ATP能量（~0.3 eV由α和键能决定）和k_B T出发，推导生物代谢率的物理上限和寿命的代谢边界。

**工程问题：**

### §1. ATP能量标度
- ATP → ADP + P_i：ΔG ~0.3 eV（~30 kJ/mol）在生理条件下
- 这个值由磷酸酐键能决定 → 磷酸酐键能由P-O键的α标度电磁力决定
- 如果α改变1%，ATP能量也会改变 → 整个生物能量学重新标度
- **SCVC锁死的ATP水解自由能？为什么是0.3 eV不是别的值？**

### §2. 代谢率上限
- 最大代谢率受限于：散热（表面积/体积比）、氧输送（扩散+循环）、底物供应
- 散热极限（热带大型动物）：~5-10 W/kg（持续）
- 短时爆发（蜂鸟、飞鼠）：~100-200 W/kg
- 由k_B T设定分子运动速度 → 代谢反应的Arrhenius温度依赖
- **温血动物的代谢率上限？散热 vs 产热的平衡点？**

### §3. 寿命的代谢边界
- 一生总代谢能量预算：~10⁶ kJ/kg（哺乳动物大致恒定）
- 每个ATP ~0.3 eV → 一生消耗 ~10²⁹ ATP/kg
- 线粒体自由基泄漏 → 氧化损伤积累 → 衰老
- **"一生总心跳"的物理上限？新陈代谢率×寿命的恒定乘积——SCVC能解释吗？**

### §4. 工程结论

- 低温生物学（冬眠/冷冻）——k_B T的Arrhenius降速效应
