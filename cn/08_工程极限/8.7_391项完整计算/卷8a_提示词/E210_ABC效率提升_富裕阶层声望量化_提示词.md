## 任务2：富裕阶层声望收益量化

### 2.1 核心问题

ABC强制归零金钱（零利率+货币重置+不可购买永久资产），但打开了声望通道。一个富豪投资$X亿在ABC公共项目上：

**声望=什么？**
- B层永久记录成就
- C层查询热度（别人查你多少次）→ 社会影响力
- 历史地位（教科书级vs被遗忘）

**需要量化：**

1. **注意力等价**
   - $1亿投资 → 每年多少人查你？
   - 假设文明存活T年 → 总查询次数
   - 每次查询=~10秒注意力 → 总"注意力人年"
   - 对比：普通人一生获得的社会注意力（家人+朋友+同事）≈ 多少人年？

2. **打工等价**
   - 一个普通人40年工作，总薪酬~$200万（按$5万/年）
   - 一个富豪的声望投资产生的社会存在感 ≈ 多少个普通人一生？
   - 用"等效打工年数"表达：你的声望 = 一个普通人打工X年的社会价值

3. **永生溢价**
   - 普通人：工作40年→退休→死→两代后被遗忘→注意力归零
   - ABC声望者：投资1次→B层永久→文明存活期间持续被查询→永续
   - 计算在T=10000年 vs T=100万年下的注意力NPV

4. **具体场景**
   - 场景A：富豪投资$10亿建DAC厂 → 声望收益（等效$？）
   - 场景B：富豪投资$100亿建全球绿色电网 → 声望收益

## 任务3.5：声望继承——乘数，非地板（新增）

### 3.5.1 旧世界vs ABC继承的根本差异

旧世界财富继承：
```
继承$10亿 → 子孙最低生活水平 = $10亿支撑的奢侈
           → 能力=0也能活得好 → 退化
           → 财富是"地板"——你跌不到地板以下
```

ABC声望继承：
```
父母高声望 → 子孙初始被关注度 = 父母的查询热度×衰减系数
           → 但这只是"麦克风更大"——说的内容还是自己负责
           → 声望是"乘数"——能力×乘数 = 实际声望
           → 能力=0 → 实际声望=0（没人持续关注平庸的"二代"）
           → 能力=优秀 → 实际声望=优秀×乘数 → 比白手起家更耀眼
```

### 3.5.2 声望继承的数学

```
定义：
  R_parent = 父母的声望（查询热度，人次/年）
  R_child = 子女自身能力产生的声望
  k = 衰减系数（血缘越远越小，配偶/子女/远亲递减）

子女实际声望 = R_child + k × R_parent × f(R_child)

其中 f(R_child):
  - 如果R_child很大 → f→1（父母声望被"激活"，全部附加）
  - 如果R_child很小 → f→0（父母声望"休眠"，没人因你是XX之子而长期关注你）
  
→ 优秀者继承全部附加声望
→ 平庸者附加声望→0
→ 恶劣者附加声望变负（"XX这么好的父母怎么有你这样的孩子"）
```

### 3.5.3 对王朝型的博弈改变

之前分析认为王朝型会因"资产不可继承"而抵抗。但新分析：

| 旧判断 | 新判断 | 原因 |
|:---|:---|:---|
| 声望不可继承 → 王朝终结 | 声望**有条件**继承 → 优秀王朝更强 | 乘数效应 |
| 子孙必须白手起家 | 子孙有"初始关注度"但不保证持续 | 需要用能力维持 |
| 王朝型会拼死抵抗 | 有能力的王朝型会**支持** | 他们的优秀子孙比旧世界更受益 |
| | 无能力的王朝型仍会抵抗 | 平庸子孙在旧世界有钱可活，ABC暴露 |

**关键反转：ABC实际上是一个"王朝过滤器"——保留优秀家族的声望传承，淘汰只靠钱的平庸家族。这对真正优秀的家族是利好。**
