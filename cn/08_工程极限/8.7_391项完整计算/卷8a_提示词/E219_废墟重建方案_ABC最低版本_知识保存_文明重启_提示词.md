## 任务1：废墟版ABC——不需要电力的最低版本

### 1.1 设计原则

```
废墟约束:
  ❌ 没有服务器 → B层不能是分布式账本
  ❌ 没有AI → 不能自动审计
  ❌ 没有互联网 → 不能全球同步
  ❌ 没有货币系统 → 不能零利率
  ❌ 能源极度有限 → 任何消耗必须值得

但ABC的核心原则不依赖技术:
  ✅ 透明 → 可以用眼睛看、用嘴说、用墙写
  ✅ 延迟 → 可以用"等7天"代替"等C层"
  ✅ 反囤积 → 可以用社区规范代替零利率
  ✅ 碰撞检测 → 可以用"三法律刻在石头上"代替算法
```

### 1.2 废墟版B层：社区公告墙

```
物理形态: 社区中心一面石墙/木板墙
功能:
  → 所有交易公开记录（谁给了谁什么）
  → 所有冲突公开记录（谁对谁做了什么）
  → 所有资源公开记录（库存有什么、用了多少）

规则:
  ① 每笔交易必须在墙上记录（或口头宣布→见证人记录）
  ② 记录不可涂改（划掉旧记录必须保留原迹→类似区块链的"不可篡改"）
  ③ 任何人可以查看墙（透明=p_detect≈你的邻居都在看）

为什么有效:
  → 小社区（<150人，Dunbar数）→ 每个人都认识每个人
  → 墙上的记录 = 你的声望 = 你的生存资格
  → 作弊被发现的概率: 极高（小社区里没有匿名）
  → 不是技术透明 → 是社会透明
```

### 1.3 废墟版C层：社区会议延迟

```
物理形态: 每周一次社区会议
功能:
  → 重大决策在会议上提出→等7天→下次会议投票
  → 所有人可以发言（类似"查询"）
  → 所有人的立场被公开记录（谁反对、谁支持）

延迟分层（废墟版）:
  Tier 1 (1天):   个人借贷、小纠纷 → 邻居调解
  Tier 2 (7天):   资源分配、规则修改 → 社区会议
  Tier 3 (30天):  驱逐成员、加入新成员 → 两次会议
  Tier 4 (90天):  改变三法律本身 → 三次会议+全部同意

为什么有效:
  → 冲动决策被缓冲（"等下次会议再说"）
  → 情绪冷却 → 理性回归
  → 社区集体记忆 → 类似B层永久记录
```

### 1.4 废墟版零利率：劳动时间记账

```
物理形态: 社区账本（纸/木板）
功能:
  → 不发行货币（没有中央银行、没有信任基础）
  → 用"劳动时间"作为交换单位
  
规则:
  ① 1小时劳动 = 1信用点（不分工作类型——医生的1小时=农民的1小时）
  ② 信用点不可生利息（零利率）
  ③ 信用点定期过期（货币重置——每年归零一定比例→防止囤积）
  ④ 基本生存需求免费（食物、水、庇护→由社区共同劳动提供）
  ⑤ 信用点只能换"超出基本需求"的东西

为什么有效:
  → 时间不可囤积（每个人每天只有24小时）
  → 零利率自动成立（时间不能"生"时间）
  → 货币重置→鼓励流通→防止积累→接近ABC经济规则
  → 不需要信任中央银行→信任"时间"这个物理常数
```

### 1.5 废墟版三法律：刻在入口石头上

```
社区入口放置一块大石，刻上:

+----------------------------------+
|                                  |
|  一、不碰撞他人                  |
|     不伤害身体，不侵害精神       |
|                                  |
|  二、不碰撞社会                  |
|     不破坏合作，不欺骗社区       |
|                                  |
|  三、不碰撞世界                  |
|     不过度索取自然，不烧化石     |
|     地球不属于任何人             |
|                                  |
|  违反者: 社区会议决定后果        |
|  记录: 姓名和事迹刻在公告墙上    |
|                                  |
+----------------------------------+

为什么三法律在废墟中比任何"法律"都好:
  → 不需要法官（社区会议=集体判断"是否碰撞"）
  → 不需要监狱（后果=公告墙记录+社区排斥+劳动补偿）
  → 碰撞检测=事前边界（不是事后惩罚）
  → 三法律足够简单→可以口口相传→不会失传
```

| **L2: 钛合金板** | 激光蚀刻钛板 | ABC核心+工程极限摘要+废墟ABC | 10万年+ | 1000份 |

### 2.3 为什么石英晶体

```
石英(SiO₂):
  → 莫氏硬度7 → 耐刮擦
  → 熔点~1700°C → 耐高温（火烧不坏）
  → 化学惰性 → 耐腐蚀
  → 不依赖磁场/电场 → 不受EMP影响
  → 不依赖数字读取 → 眼睛就能读（如果有显微镜更好）
  → 成本: ~$100/片 → 100片=$10,000 → 可以做
  → 寿命: 数百万年（只要不被故意砸碎）

和旧世界的主要区别:
  旧世界: 知识存在硬盘/云端 → 一断电就没了
  废墟: 知识刻在石头上 → 一万年后还能读
```

## 任务4：废墟ABC的博弈论验证

### 4.1 废墟版的囚徒困境

```
废墟场景（两个幸存者，交换食物vs偷食物）:

  无ABC规则:
    偷食物→一方得利→另一方死→下一次没人交换→都死
    博弈→猜疑链→霍布斯"所有人对所有人的战争"
    → 和旧世界完全一样，只是规模更小

  有废墟ABC规则（公告墙+社区会议）:
    偷食物→墙上被记录→社区知道→没人再和偷者交换→偷者饿死
    → 偷的期望值<0
    → 合作回到纳什均衡
    → 和完整ABC完全一样，只是检测靠人眼不靠算法
```

### 4.2 废墟版的E106验证

```
E106: 善意80-85%

在废墟中:
  → 小社区→Dunbar数以内→每个人认识每个人
  → 善意者自然形成核心群体
  → 不善意者（偷、骗、囤积）→被公告墙暴露→被排斥→被淘汰
  → 几代人后: 社区更接近100%善意
  → 不是因为人变好了→是因为坏行为在透明下不可存活

→ 废墟ABC = 达尔文选择器: 筛选合作者，淘汰背叛者
→ 这是完整ABC无法做的（它不能淘汰人）
→ 废墟给了ABC一个"重置"的机会
```

## 任务6：诚实标注——废墟ABC的风险

```
1. 石英板可能永远不被发现
   → 埋在废墟里→没人看到→知识丢失
   → 缓解: 多地点、多介质、地表标记

2. 废墟ABC可能退化为暴政
   → 公告墙被强者控制→"透明度"变成"告密系统"
   → 缓解: 三法律刻在石头上→"墙可以造假，石头不能"

3. 幸存社区可能选择更简单的制度
   → 酋长/军阀/宗教——比ABC更直觉
   → 缓解: ABC的优势不在于"简单"——在于"不崩溃"
     → 但第一次不崩溃要50-100年才能证明
     → 幸存者可能等不到那个时间

4. 知识保存可能引发"新宗教"
   → "这些常数是神的语言"→ABC变成教条→和E215警告的一样
   → 缓解: 石英板上刻"这些常数是可验证的——如果你有仪器，测一下"

5. 旧世界的知识可能污染重建
   → 幸存者找到经济学教科书→复利→终产者→再次崩溃
   → 缓解: 石英板上刻"经济学教科书是错的——作者不知道物理已经结束"
```
