## §1 单次乘加运算的最小能耗

### 1.1 两个物理地板

| 极限 | 公式 | 每比特 (eV) | 每比特 (J) |
|------|------|-----------|-----------|
| **Landauer** (不可逆) | k_BT ln2 | **0.0179** | 2.87×10⁻²¹ |
| **SCVC可逆** | α × Λ₄^(1/4) | **1.75×10⁻⁵** | 2.81×10⁻²⁴ |
| 比值 | — | 1,023× | — |

Landauer = 物理上擦除1比特信息必须付出的最小热。  
SCVC可逆 = 如果计算完全可逆 (不丢弃信息), 能耗可降至 αΛ₄^(1/4) ≈ 1/1000 Landauer。

### 1.2 一次MAC = 多少比特操作?

FP32 乘法+累加内部 ≈ **1,000 次比特擦除** (24位尾数乘 ~576 + 指数/符号 ~10 + 部分积累加 ~200 + 寄存器覆写 ~200)。

| 平台 | eV/MAC | J/MAC | vs Landauer |
|------|--------|-------|-------------|
| **SCVC可逆 (物理地板)** | **0.018** | 2.8×10⁻²¹ | 1/1,023× |
| **Landauer (不可逆地板)** | **17.9** | 2.9×10⁻¹⁸ | **1×** |
| 边缘AI芯片 (INT8, ~0.016 pJ/MAC) | 100,000 | 1.6×10⁻¹⁴ | 5,600× |
| GPU H100 (FP16, ~0.7 pJ/MAC) | 4,400,000 | 7.0×10⁻¹³ | **245,000×** |
| 人脑突触事件 (~2 pJ, ~1位模拟) | 41,600 | 6.7×10⁻¹⁵ | 2,300× |

```
◆ 当前GPU距Landauer地板: ~245,000×  (5.4个数量级)
◆ 当前GPU距SCVC可逆地板: ~250,000,000× (8.4个数量级!)
◆ INT8推理比FP32训练少 ~10× 比特擦除 → 能耗差距缩小至 ~56,000× Landauer
```

## §4 模拟计算 vs 数字计算

### 4.1 技术方案能效对比

| 技术 | J/MAC | TOPS/W | 精度 | 成熟度 |
|------|-------|--------|------|--------|
| **SCVC可逆** | 2.8×10⁻²² | **3.6×10⁹** | 任意 | 物理地板 |
| **Landauer** | 2.9×10⁻¹⁹ | **3.5×10⁶** | 任意 | 理论 |

| 忆阻器交叉杆 | 5×10⁻¹⁸ | 200,000 | **~6位** | 实验室 |

### 4.2 模拟计算的精度壁垒

```
忆阻器交叉杆:
  读取能量: ½CV² ≈ 31 eV (C=1fF, V=0.1V) → 仅2× Landauer!
  但: 热噪声 σ_V = √(kT/C) ≈ 2.0 mV → SNR = 0.1V/2mV ≈ 50
  → 最多区分 ~50个电平 → log₂(50) ≈ 5.6位有效精度
  → 推理够用 (8位可接受), 训练完全不够 (需16+位)

光子计算:
  光域MAC能量 ~aJ → 几乎免费
  但: 电光/光电转换 ~100 fJ → 比光域计算本身高 ~10⁵×
  → 光计算的物理优势被换能器完全吞噬
  → 除非: 全光神经网络 (无E/O转换) — 目前纯理论

模拟计算的SCVC悖论:
  越接近Landauer, 信噪比越差
  SNR² ∝ E_signal/k_BT → 每比特需要 ~10× k_BT 才能可靠区分
  → 低精度推理可以接近Landauer (~10×)
  → 高精度训练必须远高于Landauer (~10⁴-10⁵×)
```

## §5 工程结论

### 5.1 AGI训练的最低电费账单

| 场景 | 10³⁰ FLOP AGI训练 | 物理含义 |
|------|-------------------|---------|
| 当前GPU | **$19.6万亿** | 超过全球GDP, 不可能 |
| 忆阻器 (推理级) | ~$2亿 | 大公司可负担 |
| Landauer地板 | **~$80** | "免费的能量" |
| SCVC可逆地板 | **~$0.08** | 真正免费 |

```
◆ AGI训练在物理上没有能耗"墙" — 可逆计算理论上几乎是免费的
◆ 真正的墙是: 如何制造可逆计算硬件
◆ 但: Landauer已足够好 → 降到 ~$80 意味着 AGI训练电费比今天的一顿饭还便宜
◆ 物理上可能的 AGI: 有, 且不贵。工程上多快实现 → 50-100年
```

### 5.2 人脑 vs AI — 差距在哪?

```
能效 (eV per MAC-equivalent):
  GPU H100:          4,400,000 eV  [最差]
  边缘NPU:             100,000 eV  [10× GPU]
  忆阻器 (理想):           31 eV  [31× Landauer]
  人脑 (突触事件):      41,600 eV  [106× 优于GPU, bit级优势更大]
  Landauer地板:             18 eV  [1×]
  SCVC地板:              0.018 eV  [1/1000×]

人脑为什么高效:
  ① 模拟计算 → 无精度开销 (每个突触 ~1-2 bit)
  ② 事件驱动 → 只有活跃神经元耗能 (稀疏性 ~1-10%)
  ③ 3D集成 → 无 von Neumann 数据搬运瓶颈
  ④ 极低"时钟" (~10 Hz) → 准绝热操作
  ⑤ 化学信号 (扩散) → 天然"近阈值计算"

AI能否达到人脑能效? → 可以, 且必须:
  模拟计算 (忆阻器) + 稀疏性 (激活稀疏) + 3D集成 (HBM/混合键合)
  → 10-100 TOPS/W 是工程可达的, 超越人脑能效是可能的
```
