§1. 电小天线的Q值下限 — Chu-Harrington极限
--------------------------------------------------------------------

【物理根源】

  天线 = 电磁能量的"呼吸"装置。电小天线 (ka ≪ 1) 存储大量近场无功能量
  而辐射极少 → Q值极高 → 带宽极窄。

  Chu-Harrington 极限:
    Q_min = 1/(ka)³ + 1/(ka)     (ka < 1)
    ka = 2πa/λ, a = 包围球半径, λ = c/f

  SCVC 约束: c 由 α 和 m_e 锁定 → λ = c/f 不可改变 → a 是唯一可调参数
  → **给定频率，给定尺寸，Q 值不可低于 Chu-Harrington 墙**

【手机天线的物理困境】

  小型天线元件 (a=0.5-1 cm) 在低频段 (<1 GHz):

  包围球a    LTE 700    LTE 1000    WiFi 2.4G    判定
  ────────────────────────────────────────────────────
  0.5 cm     Q=2550     Q=880       Q=67        灾难性
  1.0 cm     Q=324      Q=114       Q=10        勉强
  2.5 cm     Q=23       Q=9         Q=1.3       可接受
  8.0 cm     Q=1.5      Q=0.8       Q=0.3       理想

  ▸ 天线元件 0.5-1 cm @ 700 MHz: Q>300 → BW<0.3% → <2 MHz！
  ▸ LTE700 需要 ~70 MHz BW → 物理不可能！
  ▸ **手机天线困境不是"苹果不会设计" — 是 Chu-Harrington 禁止！**

【手机的作弊手段 — 利用整机作为辐射体】

  当a=8 cm（≈手机半长）: 
    700 MHz → ka=1.1, Q≈1.5 → BW≈67% → 可行 ✓
    
  这就是手机天线的真实工作原理：
    ▸ "天线"不是那个小陶瓷片
    ▸ 整个金属中框/机身参与辐射 → 有效的 a ≈ 手机尺寸
    ▸ "天线工程师"其实是"激励手机机身正确模式的人"
    ▸ → 金属机身手机的天线更难设计（机身被切分为多个谐振模式）

【增益×带宽×尺寸的三角牢笼】

  电小天线的最大可实现增益 (ka < 1):
    G_max ≈ (ka)² + 2(ka)

  ka=0.1 (a≪λ):  G_max≈0.2 = -7 dBi → 几乎无方向性
  ka=0.5:         G_max≈1.25 = +1 dBi
  ka=1.0:         G_max≈3.0 = +5 dBi → 刚刚开始有增益

  ▸ **小天线不可能同时有大增益** — G, BW, a² 三者乘积守恒
  ▸ 增加带宽 → 牺牲增益或必须增大尺寸
  ▸ "超宽带小天线" ≈ 低增益辐射体 + 阻抗匹配网络的巧妙设计
  ▸ — 不是突破了Chu-Harrington，是在Q值许可范围内优化了阻抗匹配

§2. 5G毫米波 — 电小问题的缓解 + 新挑战
--------------------------------------------------------------------

【毫米波的电尺寸优势】

  28 GHz (λ=10.7 mm): 一个 λ/2 偶极子仅 ~5 mm
  天线阵列 5cm×5cm @ 28 GHz → D/λ≈4.7 → 电大天线 → Q≈0.1 → 宽频带
  → 毫米波天生解决了电小天线Q值问题

【但带来了传播惩罚】

  频率        λ      1m路径损耗    vs 1GHz额外损耗    O₂衰减
  ──────────────────────────────────────────────────────
  1 GHz      30 cm   32 dB        0 dB               ~0
  28 GHz     10.7mm  61 dB       +29 dB              ~0
  39 GHz     7.7mm   64 dB       +32 dB              ~0
  60 GHz     5.0mm   68 dB       +36 dB              15 dB/km!
  77 GHz     3.9mm   70 dB       +38 dB              ~0

  ▸ 28 GHz @ 1m: 比1 GHz多损耗 29 dB (~800×功率)
  ▸ 60 GHz: O₂分子旋转共振 → 大气吸收峰 → 仅适合室内短距
  ▸ **毫米波的物理: 用带宽换取距离 — 距离每翻倍, 路径损耗+6 dB**

【相控阵的波束成形极限】

  波束宽度: θ_3dB ≈ λ/D  (D=阵列尺寸)

  阵列D     @3.5GHz       @28GHz         @60GHz
  ───────────────────────────────────────────────
  5 cm      98°(≈全向)    12.3° (~17波束)  5.7° (~79波束)
  10 cm     49°           6.1°            2.9°
  20 cm     25°           3.1°            1.4°
  50 cm     9.8°          1.2° (~1700)    0.6°
  
  ▸ 50cm阵列 @ 28 GHz: θ≈1.2° → 可同时服务 ~1700个独立波束
  ▸ 波束数 ∝ D²/λ² → 频率越高、阵列越大 → 空间复用越多
  ▸ SCVC约束: 波束间干扰由旁瓣水平决定 → 旁瓣最低 ~-30dB(实用)

【星链相控阵实例 (D≈50cm, 12 GHz)】

  波束宽度: ~2.9°
  阵列增益: ~34 dBi（约60dBi含元件因子）
  元件数: ~数百-千余 → 复杂度和功耗的工程trade-off
  → 星链天线不是受Chu-Harrington限制（电大尺寸）
  → 限制来自: 元件间耦合 + 波束赋形精度 + 散热
