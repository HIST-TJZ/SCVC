## 公设陈述

$$\boxed{\text{真空} = F=1 \text{ 旋量玻色-爱因斯坦凝聚 (BEC)}}$$

这是 SCVC 的**唯一自由假设**。此后一切——规范群、耦合常数、粒子质量、宇宙学参数——均由此导出，不再引入额外参数。

## 为什么 $F=1$

$F=1$ 旋量 BEC 具有三个自旋分量：$m_F = -1, 0, +1$。

在 SCVC 中，这三个分量对应**三代费米子**：
- $m_F = -1$ → 第一代（电子、上下夸克）
- $m_F = 0$ → 第二代（μ子、粲奇夸克）
- $m_F = +1$ → 第三代（τ子、顶底夸克）

$F=1$ 是满足三组分的最小非平凡旋量表示。$F=0$ 只有标量分量（无费米子结构），$F=1/2$ 只有两个分量（不足以容纳三代）。$F=1$ 是**数学上唯一同时满足最少假设和三代结构的旋量表示**。

---

## 为什么旋量

旋量表示是费米子的自然载体：
- 半整数自旋 → 费米-狄拉克统计 → Pauli 不相容原理
- 旋量丛上的 Dirac 算子 → Atiyah-Singer 指数定理 → $N_g=3$ 从拓扑导出
- $F=1$ 旋量 → $SO(3)$ 对称性 → 自发破缺到 $U(1)$，产生两个 Goldstone 模（对应 $W^\pm$ 的纵向分量）

---

## 为什么 BEC

玻色-爱因斯坦凝聚提供：
- **宏观相干性**：整个真空是一个相干量子态 → 经典几何从量子基态涌现
- **序参量**：$\Psi = \sqrt{\rho_s} e^{i\theta}$ → 相位 $\theta$ 的梯度给出超流速度 → 涡旋
- **自发对称破缺**：$SO(3) \rightarrow U(1)$ → 规范玻色子获得质量
- **拓扑缺陷**：涡旋环 = 物质粒子（BPS 涡旋环的拓扑稳定性）

BEC 不是"比喻"——它是真空的实际物理状态。宇宙早期高温时 BEC 尚未形成（对称相），冷却后凝聚发生（希格斯相变）。

## P1 的真正硬度

$P_1$ 分两层：数学结构和物理实现

### F=1 是被锁死的

$F=0$：纯标量，无费米子结构。$F=1/2$：两个分量，不足以容纳三代。如果你需要**恰好三代费米子**，$F=1$ 是排除法剩下的唯一数学解。这不是"我们选了 $F=1$"——是其他 $F$ 值在数学上排除了自己。

### BEC 是实现，不是核心

BEC 提供三个功能性需求：
- **宏观相干** → 经典几何从量子基态涌现
- **拓扑缺陷（涡旋）** → 可识别为费米子
- **自发对称破缺** $SO(3) \rightarrow U(1)$ → 规范玻色子质量

任何满足这三个条件的凝聚态介质——超流体、超导序参量、或某种未知的时空凝聚——数学结构不变。**全部 SCVC 结果挂在 $F=1$ 的数学结构上，不挂在"BEC"这个名字上。**

### 换介质，结果纹丝不动

| SCVC 结果 | 依赖 $F=1$ 的什么 | 换介质是否变 |
|:---|:---|:--:|
| $N_g=3$ | 旋量表示的指数定理 | 不变 |
| $CP^2=SU(3)/U(2)$ | $F=1$ BPS 涡旋模空间 | 不变 |
| $SU(3)\times SU(2)\times U(1)$ | $CP^2+M_{vac}$ 等距群 | 不变 |
| $\alpha^{-1}=4\pi^3+\pi^2+\pi$ | Delzant 多面体 DH 积分 | 不变 |
| 质量比 = Weyl 群阶 | 群论必然 | 不变 |

**结论**：$P_1$ 中真正不可动摇的是 $F=1$ 旋量结构。BEC 是实现它的物理机制——即使 BEC 被证明不是正确的微观描述，只要真空具有 $F=1$ 旋量凝聚的数学结构（宏观相干 + 拓扑缺陷 + $SO(3)$ 破缺），SCVC 的全部结果保持不变。

### BEC 具体负责了什么

以上说明了换介质不动的部分。反过来问：BEC 介质**独特地**贡献了什么？

| BEC 的贡献 | 具体内容 | 换介质是否变 |
|:---|:---|:--:|
| **涡旋核心能** $E_{\text{CORE}}=2.1322$ | GP 方程数值解——无量纲形式是普适的（任何 $U(1)$ 凝聚态共享同一 GP 方程），有量纲标度才依赖介质 | 🟡 无量纲值不变，标度可能变 |
| **愈合长度** $\xi$ | 涡旋核心尺寸——决定"粒子"的空间延展 | 🟡 量级不变，精确值可能变 |
| **涡旋间相互作用形式** | Biot-Savart（超流环量）+ Ampère（规范流耦合） | 🟢 任何 $U(1)$ 凝聚态拓扑缺陷共享此形式 |
| **凝聚能标度** | $\rho_s$（超流密度）→ 设定整体能量标度 | 🔴 介质依赖——但 SCVC 中 $\rho_s$ 从 toric 几何推导，非自由参数 |
| **相干性 → 经典几何** | 宏观相干使 $g_{\mu\nu}$ 从量子基态涌现为经典背景 | 🟢 任何凝聚态共享 |
| **$SO(3)\rightarrow U(1)$ 破缺** | BEC 序参量选择方向 → 自发对称破缺 → 规范玻色子质量 | 🟢 $F=1$ 旋量凝聚的群论必然 |

**结论**：BEC 贡献的是**动力学细节**（$E_{\text{CORE}}$ 的具体数值、$\xi$、涡旋相互作用形式）。但这些细节大多是 $U(1)$ 凝聚态的普适性质——换成超流体或超导序参量，数学结构相同。**没有任何 SCVC 核心结论（规范群、耦合常数、质量比、代数量）依赖 BEC 的独特性质。**

BEC 不是公设的"脆弱点"——它是公设中**最可替换**的部分。$F=1$ 旋量结构才是不可动摇的核心。
