# E173: Universal Flu Vaccine Upper Limit

**SCVC**: Hemagglutinin (HA) stem region is conserved because its H-bond network (∝ α² energy scale) is structurally constrained. Vaccine targeting the stem → universal.

**Physical ceiling**: HA stem cannot mutate beyond ~5-10 residues without losing fusion function. SCVC: H-bond network geometry sets this constraint.

# E174: Viral Error Catastrophe Upper Limit

**SCVC**: RNA virus replication error rate ~10⁻⁴ per base (no proofreading). Genome size L → expected mutations per replication = μL. If μL > 1 → error catastrophe → population collapse.

**SCVC ceiling**: L_max ≈ 1/μ ≈ 10⁴ bases for RNA viruses without proofreading.
→ Mutagenic drugs (e.g., Ribavirin) push μ higher → lower effective L_max → population collapse.

# E175: Broad-Spectrum Antiviral Upper Limit

**SCVC**: All viruses depend on host ribosomes. Targeting conserved host factors (not viral proteins) → broad-spectrum.
Host translation machinery: ribosome structure ∝ α (electromagnetic forces hold it together). Cannot mutate.

# E176: HIV Cure Upper Limit

**SCVC**: HIV latency = provirus integrated into host genome, transcriptionally silent. "Shock and kill": latency-reversing agents → viral protein expression → immune clearance + antiretroviral.

**SCVC physical ceiling**: Latent reservoir size ~10⁶ cells. Complete clearance probability ∝ exp(-N_reservoir × p_clearance). → Requires >99.9999% clearance efficiency for cure.

# E177: Autoimmune Disease Upper Limit

**SCVC**: Autoimmunity = T/B cells recognizing self-peptides. Self-peptide-MHC binding ∝ H-bond complementarity ∝ α² energy scale.
→ Breaking tolerance requires exceeding this energy threshold → rare event → explains low incidence.

# E178: Alzheimer Upper Limit

**SCVC**: Aβ aggregation ∝ hydrophobic interactions ∝ van der Waals ∝ α².
Aggregation kinetics ∝ exp(-E_nucleation/k_B T).
Nucleation barrier ∝ (surface tension)³/(supersaturation)².
→ Physical ceiling: cannot prevent aggregation entirely, can only slow it below clinical threshold.
