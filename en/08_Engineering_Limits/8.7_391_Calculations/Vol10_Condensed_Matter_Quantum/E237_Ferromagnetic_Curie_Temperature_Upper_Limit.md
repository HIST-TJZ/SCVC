# Ferromagnetic Curie Temperature Upper Limit

**Date**: 2026-07-25 | **Status**: 🟡 Exchange coupling from vortex ring overlap

## Core Formula
```
T_C ∝ J_exchange ∝ (vortex ring overlap integral)
```

SCVC: exchange coupling J ∝ (Ampère force between electron vortex rings) ∝ α × (spin overlap).

### Upper Bound Estimate
Maximum T_C occurs when:
1. Maximum spin density (3d transition metals)
2. Maximum vortex ring overlap (shortest interatomic distance)
3. Strongest Ampère coupling (largest Z_eff)

```
T_C_max ∼ α × (ℏc/a₀) / k_B ∼ (1/137) × (27.2 eV) / (8.62×10⁻⁵ eV/K) ∼ 2300 K
```

## Honesty: T_C_max estimate is a scale argument. Quantitative T_C requires detailed band structure (Stoner criterion).
