1. VEI 标度的物理
==============================================================

1.1 VEI (Volcanic Explosivity Index) 定义
--------------------------------------------------------------
    VEI        喷出体积 (DRE)         频率             实例
    ────────────────────────────────────────────────────────────
    0-1        < 10⁴-10⁶ m³          持续              夏威夷
    2-3        10⁶-10⁸ m³            每月-每年          Stromboli
    4          10⁸-10⁹ m³            ~每年              Eyjafjallajökull 2010
    5          1-10 km³              ~10年              St. Helens 1980
    6          10-100 km³            ~100年             Pinatubo 1991, Krakatau 1883
    7          100-1000 km³          ~1000年            Tambora 1815
    8          >1000 km³             ~10,000-100,000年  Toba ~74 ka
    ────────────────────────────────────────────────────────────

1.2 岩浆房过压 — 爆发的触发器
--------------------------------------------------------------
    岩浆房压力由三个Source组成:

    (A) 浮力过剩:
        P_buoyancy = Δρ · g · z
        Δρ ≈ 250 kg/m³, z≈10 km → P_buoyancy ≈ 25 MPa

    (B) 挥发分出溶 (second boiling):
        水在硅酸岩浆中的溶解度 ~2-6 wt%
        随结晶进行, 残余熔体富集 H₂O →
        P_volatile 可达数十-数百 MPa

    (C) 热膨胀:
        新岩浆注入 → ΔT → 热膨胀 → ΔP

    ⚫ 临界过压: 当 ΔP > σ_t (岩石抗张强度) + 构造应力
      → σ_t ≈ 5-20 MPa (Griffith 裂隙理论)
      → 从 SCVC: σ_theor ≈ E_bond/d³ × 0.01 ≈ 5 GPa (完美晶体)
      → 实际岩石被裂隙衰减 ~10³× → σ_t ≈ 5-20 MPa

    ⚫ 总 ΔP_crit ≈ 30-40 MPa → 裂隙扩展 → 岩墙形成 → 喷发

1.3 最大岩浆房体积
--------------------------------------------------------------
    岩浆房在达到临界过压前能积累的最大体积:

    V_max ≈ (4π/3) × (ΔP_crit / (Δρ · g))³ × f(geometry)

    对球形岩浆房:
      ΔP_crit ≈ 35 MPa, Δρ·g ≈ 2.5 kPa/m
      → R_max ≈ 35 MPa / 2.5 kPa/m ≈ 14 km
      → V_max ≈ 11,700 km³

    实际最大value (Fish Canyon Tuff, 28 Ma):
      ~5,000 km³ DRE — 在球形Limit量级内!

    ⚫ SCVC 物理Ceiling: V_max ≈ 10,000-15,000 km³ (单次爆炸性喷发)
    ⚫ VEI 9 (>10,000 km³): 在物理上勉强可能, 但需要:
      · 极深的岩浆房 (>15 km)
      · 极其富挥发分的流纹质岩浆
      · 极长的积累时间 (>100,000 yr)
      → 地质记录中未发现, 可能是极罕见事件或物理上不可能

1.4 爆炸 vs 溢流 — SCVC 区分
--------------------------------------------------------------
    ┌─────────────────────────────────────────────────────────┐
    │ 爆炸性喷发 (Explosive):                                    │
    │ · 高 SiO₂ (>63%) → 高度聚合的硅酸盐网络                    │
    │   Si-O-Si 桥氧键 (~4-5 eV) → 高黏度 (10⁴-10¹² Pa·s)       │
    │ · 挥发分被捕获在黏稠熔体中 → 气泡无法逃逸                    │
    │ · 减压 → 气泡成核+膨胀 → 碎裂化 (fragmentation)             │
    │ · Plinian 喷发柱 → 可达 30-55 km 高度                      │
    │                                                          │
    │ 溢流式喷发 (Effusive):                                     │
    │ · 低 SiO₂ (<52%) → 较少聚合的熔体                           │
    │   → 低黏度 (10⁰-10³ Pa·s)                                 │
    │ · 挥发分可自由逃逸 → 无压力积累                             │
    │ · 岩浆从裂隙安静流出 → 熔岩流                                │
    │                                                          │
    │ ⚫ SCVC 根源: Si-O 键 vs 非桥氧的平衡 → 由 α 设定的           │
    │   轨道杂化 (sp³) 决定 Si 的四配位 → 网络形成 vs 网络修饰 →    │
    │   黏度差 10¹⁰× → 决定了地球同时有爆炸性火山和溢流式火山       │
    └─────────────────────────────────────────────────────────┘

2.2 大火成岩省 (LIPs) — 非爆炸, 是溢流
--------------------------------------------------------------
    LIP                        体积 (km³)      时间跨度         平均速率
    ──────────────────────────────────────────────────────────────────
    Siberian Traps              ~4×10⁶          ~1 Myr           4 km³/yr
    Deccan Traps                ~1.3×10⁶        ~30 kyr          43 km³/yr
    CAMP (中大西洋)             ~2×10⁶          ~600 kyr          3 km³/yr
    Columbia River              ~1.7×10⁵        ~1.5 Myr         0.1 km³/yr
    ──────────────────────────────────────────────────────────────────

    ⚫ LIPs 是玄武质 (低黏度) + 地幔柱减压熔融 → 溢流, 非爆炸。
    ⚫ Siberian Traps 总体积 ~4000× Toba, 但用了 10⁶ 年。
    ⚫ P-Tr 大灭绝 (252 Ma) 与 Siberian Traps 同时 —
      不是"炸死的", 是"烤死的" (CO₂ 温室 + SO₂ 酸雨)。

    ⚫ "单次爆发" 与 "持续溢流" 的 SCVC 物理区分:
      爆炸: 黏度 > 10⁶ Pa·s → 气泡被缚 → 碎裂化 → <1 天-数周
      溢流: 黏度 < 10² Pa·s → 气泡逃逸 → 熔岩流 → 数月-百万年
      → 爆炸的最大体积远小于溢流 (10³-10⁴ vs 10⁶ km³)

3.2 火山气溶胶与全球降温Ceiling
--------------------------------------------------------------
    SO₂ → H₂SO₄ 气溶胶 → 平流层 → 散射阳光 → 地表降温

    喷发            SO₂ (估算)     全球降温        持续时间
    ──────────────────────────────────────────────────────────
    Pinatubo 1991   ~20 Tg         ~0.5°C          1-2 年
    Tambora 1815    ~60-100 Tg     ~1-2°C           2-3 年
    Toba ~74 ka     ~100-300 Tg    ~3-5°C (估计)    数年
    ──────────────────────────────────────────────────────────

    ⚫ 物理Ceiling: 平流层气溶胶不能无限增加

    · 气溶胶粒子凝结增长 → 沉降速度 ↑
    · 当粒子 > ~1 μm → 沉降时间 ~月 (vs ~年 for 0.1 μm)
    · → 超过 100-200 Tg SO₂ 后, 额外 SO₂ 加重凝结 → 加速清除
    · → 有效光学厚度 τ_max ≈ 5-10
    · → 最大降温 ≈ 5-10°C (全球平均)

    ⚫ SCVC: 气溶胶的凝结/沉降平衡由分子碰撞 (α→范德华力)
      和气溶胶粒子尺寸分布设定。超过 τ_max ≈ 10 的注入
      几乎完全被凝结清除 → 无效 → 这是"火山冬天"的物理Ceiling。

3.3 火山 vs 核冬天 — 共同的物理Ceiling
--------------------------------------------------------------
    ┌──────────────────────────────────────────────────────────┐
    │ supervolcano (Toba级):                                         │
    │ · 气溶胶: H₂SO₄ 液滴, 强散射, 短波制冷                    │
    │ · 最大 ΔT ≈ -5 到 -10°C                                   │
    │ · 持续: 2-5 年 (气溶胶沉降)                               │
    │ · 后续: 无核冬天那种"臭氧层破坏" + "大火风暴"               │
    │                                                           │
    │ 核冬天 (假设):                                              │
    │ · 气溶胶: 碳烟 (soot) + 粉尘, 强吸收                       │
    │ · 加热平流层 → 改变环流 → "自维持"                         │
    │ · 持续: 可能 >5 年 (烟尘更难沉降)                          │
    │ · 更严重: 臭氧层破坏 + 光化学烟雾                          │
    │                                                           │
    │ ⚫ SCVC 共同硬墙:                                           │
    │ · 平流层气溶胶最大光学厚度 τ_max ≈ 5-10                    │
    │ · 凝结清除阻止 τ 无限增长                                  │
    │ · 最大地表降温 ≈ 5-15°C (取决于气溶胶种类)                  │
    │ · 这个Ceiling不能被更大的初始注入突破                        │
    └──────────────────────────────────────────────────────────┘

  ⚫ 核心洞察:
    · 单次爆炸性喷发的体积Ceiling (~10,000 km³) 由岩石强度和浮力过压共同设定。
    · VEI 9 在物理上可能勉强存在, 但地质记录中未发现 →
      可能是极罕见 (或需地球早期更高热流)。
    · LIPs 是"持续溢流"非"单次爆炸" → 总体积大 10³×, 但时间尺度长 10⁵×。
    · 平流层气溶胶的凝结清除机制提供了火山/核冬天的降温Ceiling。
    · 所有Ceiling最终都来自 SCVC 的两个锁: α (bond energy→岩石强度) + M_Pl (行星重力→浮力)。
