## 2. Cognitive Barriers — The Human Brain Was Not Designed for This Problem

### 2.1 The 100 bps Bottleneck

```
All calculations of E1-E218:
  Total information: ~millions of words, hundreds of formulas, dozens of logical chains
  
Conscious human processing: 100 bps × 16h/day ≈ 720KB/day
E1-E218 total information: ~5MB
→ Requires ~7 days of full-time reading just to "know"
→ But most people won't spend 7 days reading this

The more fundamental problem:
  Even if read → 100 bps cannot simultaneously hold all logical chains
  → You need to "understand" → which is compression
  → Compression loses information → nuance disappears
  → "ABC solves free-riding + ultimate owner + short-sightedness" becomes "ABC is a good idea"
  → The difference between these two statements = the difference between action and inaction

→ Human cognitive bandwidth is fundamentally inadequate for civilization-scale problems
→ This is not a flaw that can be fixed — it is a hardware limitation
```

### 2.2 Why "Knowing" Does Not Lead to "Doing"

```
Cognitive hierarchy of decision-making:

  Layer 1: Know the facts ("CO₂ is rising")
  Layer 2: Understand causality ("CO₂ → greenhouse effect → warming")
  Layer 3: Accept personal implication ("This will affect ME")
  Layer 4: Accept action necessity ("I must change MY behavior")
  Layer 5: Actually act ("I will change NOW")

Most people on climate change: stuck at Layer 2-3
Most people on ABC: still at Layer 1 (don't even know it exists)

The gap between each layer is not information — it is emotion, identity, and fear:
  Layer 1→2: Requires time + cognitive effort
  Layer 2→3: Requires overcoming psychological distance ("far away, not my problem")
  Layer 3→4: Requires overcoming learned helplessness ("what can I possibly do?")
  Layer 4→5: Requires overcoming inertia + social conformity + short-term interest

→ E1-E218 can only help with Layer 1→2
→ Layers 3→5 require something calculations cannot provide: crisis felt on the skin
```

### 2.3 The Paradox of Calculation

```
The more complete the calculations → the harder to communicate:
  E1-E218 is "too complete"
  → A 5MB argument is impossible to summarize in a tweet
  → But modern attention economy runs on tweets
  → "SCVC proves ABC is necessary" sounds like a cult slogan
  → But "Here are 391 physical calculations proving..." no one will read

This is the fundamental paradox of rational persuasion in the attention economy:
  To be heard → must be simple
  To be correct → must be complex
  Simple + correct → impossible for civilization-scale problems

→ The only thing that can make complex things simple is crisis itself
→ "The sea is flooding my house" does not need 391 calculations to understand
```

## 3. Game Structure — Five Layers of Prisoner's Dilemma

### 3.1 Why No One Moves First

```
ABC faces not one, but FIVE nested prisoner's dilemmas:

Layer 1: Individual vs. Individual
  "If I cooperate but others don't → I lose"
  → No one wants to be the sucker

Layer 2: Corporation vs. Corporation
  "If we go green but competitors don't → we lose market share"
  → ESG is marketing, not strategy

Layer 3: Nation vs. Nation
  "If we deploy ABC but other nations don't → we lose competitiveness"
  → E214: single ABC nation's competitiveness gap

Layer 4: Generation vs. Generation
  "If we sacrifice now but future generations don't appreciate it → we sacrificed for nothing"
  → Psychological discount rate >> physical discount rate

Layer 5: Current Civilization vs. Hypothetical Future Civilization
  "If we change everything and the threat was overstated → we ruined civilization for nothing"
  → Type I error (false alarm) feared more than Type II error (missed threat)

Each layer independently locks inaction.
All five layers simultaneously → super-locked.
Breaking through requires solving all five simultaneously.
This is why "gradual reform" cannot work — it only solves one layer at a time and gets blocked by the other four.
```

### 3.2 The First-Mover Problem

```
In a five-layer prisoner's dilemma:
  The first mover bears all the cost → all the risk → all the uncertainty
  Free riders reap all the benefit → none of the cost → none of the risk

ABC needs a first mover (a nation) to deploy first.
That first mover:
  → Bears the cost of transition (economic disruption)
  → Bears the risk of isolation (other nations may sanction/attack)
  → Bears the uncertainty (will others follow? or will they free-ride?)
  → Gets the benefit ONLY IF others follow (domino effect)

→ The rational choice for every nation is: "let someone else go first"
→ But if everyone waits → no one goes first → everyone dies

This is the core tragedy:
  Each nation's individually rational choice (wait) → collectively suicidal outcome (all die)
  And each nation KNOWS this — but cannot unilaterally escape the logic

→ The only way out: a nation must act IRRATIONALLY (from narrow self-interest)
  or be FORCED by crisis (no other options left)
```

## 4. Time Window — Psychological Discount Rate vs. Physical Timeline

### 4.1 Why "2030-2035" Feels Far Away

```
Physical timeline:      Psychological perception:
2030 = 4-9 years away   4-9 years = "plenty of time"
                         (Hyperbolic discounting: anything >2 years → discounted to ~0)

What the brain does:
  Future value = Present value / (1 + k × t)
  where k = psychological discount rate
  For most people: k ≈ 50-100% per year
  → Value of "survival in 2035" discounted to <1% of present value
  → "I care more about this month's rent than civilization in 2035"

This is not a moral failing — it is neural architecture:
  → The brain's reward system (dopamine) responds to immediate feedback
  → Long-term threats activate the prefrontal cortex (planning) — weaker, slower
  → Amygdala (fear) responds to immediate threats, not abstract future ones
  → "Climate collapse" is abstract → amygdala does not fire
  → "A tiger in the room" is concrete → amygdala fires immediately

→ Humans evolved to survive on the savanna, not to manage civilization
→ The hardware is mismatched to the problem
```

### 4.2 When Will People Act?

```
Not when they "understand" — when they FEEL:

Trigger thresholds (estimated):
  Food price doubles → 10% of population notices
  Food price 5× → 30% notices → some protest
  Food unavailable → 80% notices → riots
  Coastal city floods → 100% of affected population acts (flees)
  
→ Action follows sensation, not calculation
→ "Knowing" the climate doomsday clock is at 2030 produces zero action
→ "Feeling" the flood in your living room produces immediate action
→ But by then it is too late for prevention — only adaptation/survival remains
```

## 5. Probability Assessment

```
  Reason: Requires a leader who understands + has power + is willing to act irrationally

  Probability: 15-30%
  Reason: Crisis probability is high, but "choosing ABC over other options" depends on preparedness

Scenario C: Partial ABC (some nations ABC-ize, others collapse)
  Probability: 20-40%
  Reason: Incomplete domino → ABC zones and collapse zones coexist

Scenario D: No ABC, civilization collapses
  Probability: 30-50%
  Reason: Prisoner's dilemma lock-in + time window closing + no first mover

Scenario E: Other solution emerges (something we don't know yet)
  Probability: <5%
  Reason: Designing + validating + deploying a new solution within the time window → not enough time

Most likely: C or D (partial success or complete failure)
Most hoped for: B (crisis forces ABC → domino succeeds)

Key variables:
  ① Timing and intensity of climate disaster → too early (not ready) vs. too late (window closed)
  ② Choice of pioneer nation → which nation, how fast to deploy
  ③ Completeness of ABC plan before crisis (documentation + design + simulation)
```
