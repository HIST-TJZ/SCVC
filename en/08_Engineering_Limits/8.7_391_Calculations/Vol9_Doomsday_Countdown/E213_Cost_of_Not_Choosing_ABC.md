## 3. Ultimate Owner Formation — The Mathematics of Compound Interest

### 3.1 The Compound Interest Trap

```
Wealth concentration dynamics:

  Share(t) = Share(0) × [(1 + r_capital) / (1 + r_economy)]^t
  
  Where:
    r_capital: capital return rate (~10%/yr historically)
    r_economy: overall economic growth rate (~2%/yr)
    
  Gap: r_capital - r_economy ≈ 8%/yr
  → Wealth share of top 1% doubles approximately every 9 years
  → Starting from ~45% (current global), reaches >50% by ~2045 [C]

SCVC root:
  Compound interest is not a "policy choice" — it emerges from the time value of money
  → Capital earns returns → returns reinvested → capital grows → earns more returns
  → This is a positive feedback loop baked into the mathematics of interest
  → Without zero interest rate (ABC Layer C mechanism), this loop is unstoppable
  
  "The ultimate owner is not a person. It is a mathematical attractor.
   Under compound interest, wealth necessarily concentrates.
   The only question is: how fast, and who holds it at the end."
```

### 3.2 The Ultimate Owner's Self-Destruction

```
Paradox: The ultimate owner destroys the market that made them rich.

  Stage 1: Wealth concentrates → top 0.1% owns >50% of assets
  Stage 2: The 99.9% lose purchasing power → consumption collapses
  Stage 3: Companies lose customers → profits collapse
  Stage 4: Asset values collapse → the ultimate owner's wealth evaporates
  Stage 5: "I won the game, but the game board disintegrated."

This is the internal contradiction of capital logic:
  → To maximize wealth → must concentrate ownership
  → But concentration destroys the consumer base
  → Without consumers → there is no economy → there is no wealth
  → Capitalism's end state is self-annihilating

ABC's solution:
  → Zero interest rate → wealth cannot grow by merely "owning"
  → Currency reset → hoarding penalized
  → The "ultimate owner attractor" is mathematically removed from the system
```
