## 2. Wealthy Class Reputation Quantification — Two-Layer Attention Economics

### 2.1 Basic Model: Attention Value

```
Base unit: 1 person-hour of attention = what economic value?

Ordinary person, 10 seconds of attention:
  Advertisers pay ~$0.01 per 10-second impression
  But ABC has no advertising → this is "social attention"
  Social attention value: 10 seconds of someone thinking about you
  → Minimum wage equivalent: $10/hr → 10s = $0.028
  → Median global income equivalent: ~$6/hr → 10s = $0.017
  → Use baseline: ~$1.67/person-hour of attention

→ Base reputation value: R_base = N_people × T_attention × $1.67/hr
```

### 2.2 Decision-Maker Premium (v2 Addition)

```
Not all attention is equal.

Ordinary person 10s attention: $1.67/hr baseline
Decision-maker 10s attention: what is the value?

Reference: lobbying industry
  US federal lobbying spending: ~$4B/yr
  Number of decision-makers reached: ~10,000 (Congress + senior officials + staff)
  Implicit value per decision-maker: $4B / 10,000 = $400,000/yr
  → Per hour of decision-maker attention: $400,000 / 2000 hrs ≈ $200/hr

But lobbying is mostly wasted (most doesn't change votes).
Actual decision-changing hour: estimated ~$5,000/hr (based on bill passage probability × bill value)

→ Decision-maker attention premium: ~$5,000/person-hour
  vs. ordinary person: $1.67/person-hour
  → Premium factor: ~3,000×

Weighted attention value (assuming 1% of attention comes from decision-makers):
  V_weighted = 0.99 × $1.67 + 0.01 × $5,000 = $51.65/person-hour
  vs. original $1.67/person-hour → 31× increase
```

## 3. Reputation Inheritance — Multiplier Model

### 3.1 Basic Inheritance Formula

```
R_child = R_self + k × R_parent × f(R_self)

Where:
  R_child: descendant's starting reputation
  R_self: descendant's own achievements
  R_parent: parent's reputation legacy
  k: inheritance coefficient
  f(R_self): sigmoid activation function
  
Inheritance coefficients:
  Spouse: k = 0.30
  Children: k = 0.25
  Grandchildren: k = 0.10
  Great-grandchildren: k = 0.03
  Beyond: k → 0 (legacy becomes "historical figure")

f(R_self): sigmoid activation
  → If descendant achieves nothing (R_self ≈ 0) → f ≈ 0 → inheritance barely activates
  → If descendant achieves significantly (R_self > threshold) → f → 1 → full inheritance activates
  → Threshold: R_threshold ≈ 10 person-years of attention

Key property: inheritance is a MULTIPLIER, not a FLOOR
  → Excellent descendant + strong parent legacy → multiplicative boost
  → Mediocre descendant + strong parent legacy → weak boost (f is low)
  → Terrible descendant + strong parent legacy → no boost (f ≈ 0, may even be negative due to contrast)
```

### 3.2 Three Descendant Scenarios

```
Scenario A: Excellent Descendant
  R_self = 100 person-years, R_parent = 1000 person-years
  f(100) ≈ 1.0
  R_child = 100 + 0.25 × 1000 × 1.0 = 350 person-years
  → 3.5× boost from parent legacy
  → Capable dynasties actively SUPPORT ABC (multiplicative benefit)

Scenario B: Mediocre Descendant
  R_self = 5 person-years, R_parent = 1000 person-years
  f(5) ≈ 0.3
  R_child = 5 + 0.25 × 1000 × 0.3 = 80 person-years
  → Boost exists but modest (5 → 80)
  → Mediocre dynasties fear ABC (no floor to guarantee status)

Scenario C: Terrible Descendant
  R_self = -10 person-years (negative reputation from scandals), R_parent = 1000
  f(-10) ≈ 0
  R_child = -10 + 0.25 × 1000 × 0 ≈ -10 person-years
  → Zero inheritance benefit — possibly worse (contrast with great parent amplifies shame)
  → Terrible descendants fear ABC (exposed, no hiding)

→ Dynastic split: Capable dynasties → support ABC; Mediocre dynasties → resist ABC
→ ABC is a "dynasty quality filter," not a "dynasty destroyer"
```

### 3.3 Time Horizon and Cooperation Conditions

```
Cooperation condition: α × R(T) > (1-α) × W × 0.025

Where:
  α: weight placed on reputation vs. wealth
  R(T): total reputation value over time horizon T
  W: current wealth
  0.025: annual wealth decay rate under ABC (zero interest rate + currency reset)

As time horizon extends:
  T = 100 years:    Only achievement-types (α > 0.71) → ~20% cooperate
  T = 1,000 years:  Achievement + dynastic + accumulation (α > 0.56) → ~55% cooperate
  T = 10,000 years: Almost everyone (α > 0.52) → ~75% cooperate
  + Institutional forcing: ~94% comprehensive → ~99.7% wealth enters ABC orbit

  α threshold formula: α_min = W × 0.025 / (R(T) + W × 0.025)
  As T → ∞ or W → 0: α_min → 0 → everyone cooperates
```

## 4. Reverse Game Theory — Why the Wealthy Will Cooperate

### 4.1 The Old World Wealth Trap

```
Old world: Wealth = what you can buy

Problem:
  → Wealth decays under compound interest pressure (inflation, competition, dilution)
  → Wealth must GROW or DIE → constant reinvestment → constant risk
  → Death: wealth transfers to heirs → split → diluted
  → Within 2-3 generations: most dynastic wealth dissipated

Under ABC:
  → Zero interest rate → wealth no longer grows automatically
  → Currency reset → hoarding penalized
  → Wealth's financial meaning → approaches zero
  → But: reputation is permanent (B layer) and multiplies (inheritance)

→ The rational wealthy person's calculus:
    Pre-ABC: $10B → dies → heirs split → 2 generations → forgotten → equivalent to $0
    Post-ABC: $0 + reputation → dies → B layer permanent → queried for civilization's lifetime
    → Post-death net worth: ABC path >> Old world path
```

### 4.2 p_detect and Forced Cooperation

```
Old world: p_detect ≈ 5-10%
  → Cheating (tax evasion, corruption, monopoly) → most goes undetected
  → Expected value of cheating: positive
  → Rational choice: cheat

ABC: p_detect ≈ 95%
  → Cheating exposed almost certainly
  → Penalty: reputation destruction + social exclusion + wealth reset
  → Expected value of cheating: strongly negative
  → Rational choice: cooperate

This is NOT moral persuasion.
This is game theory with a 95% detection rate.
The wealthy are rational actors → they will respond to changed incentive structures.
```
