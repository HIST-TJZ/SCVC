## 4. The Ruler's Dilemma — Follow or Be Overthrown

### 4.1 The Non-ABC Ruler's Game Matrix

```
Non-ABC ruling elite faces a binary choice:

                    Population
                    Demand ABC     Accept Status Quo
  Ruler  ┌───────────────────┬──────────────────────┐
  Adopt  │ (Win, Win)        │ (Lose power, Win)    │
  ABC    │ Ruler becomes     │ Ruler deposed but    │
         │ ABC-era leader    │ nation transitions   │
         ├───────────────────┼──────────────────────┤
  Resist │ (Overthrown, Lose)│ (Lose, Lose)         │
  ABC    │ Population        │ Nation collapses     │
         │ revolution        │ under compound gap   │
         └───────────────────┴──────────────────────┘

Analysis:
  → If population demands ABC: resistance → overthrown (certain loss)
  → If population accepts status quo (unlikely after seeing ABC):
      resistance → slow collapse under compound gap (delayed loss)
  → Adopting ABC: ruler loses concentrated wealth but gains ABC-era leadership legitimacy
  
  → There is NO equilibrium where the ruler keeps both power and the old system
  → The only stable outcome: adopt ABC (voluntarily or after being overthrown)
  
  Key variable: information penetration
    → ABC nation's existence is visible (internet, satellites, defectors)
    → Non-ABC citizens WILL know about 9× QoL + immortality track
    → Information asymmetry favors ABC, not the resisting ruler
    → "You cannot hide a utopia next door"
```

### 4.2 The Domino Sequence

```
Phase 1: Pioneer (Years 0-3)
  → First nation deploys ABC
  → Initial chaos (transition costs) → skeptics claim "ABC failed"
  → Year 3: efficiency gains visible, talent begins flowing in

Phase 2: First Followers (Years 3-8)
  → 2-5 nations follow (those with most to lose from brain drain)
  → "If we don't, all our scientists will move there"
  → Competitive pressure, not ideological conversion

Phase 3: Avalanche (Years 8-18)
  → 10-30 more nations join
  → Non-ABC bloc shrinking → remaining nations face isolation
  → Trade partners demand ABC compatibility (Layer B transparency)
  → Carbon tariffs cripple non-ABC economies

Phase 4: Last Resistance (Years 18-28)
  → 5-10 holdout nations (authoritarian regimes, resource states)
  → Internal pressure mounting (citizens see ABC via smuggled information)
  → Either reform or collapse
  → Collapse → successor regime adopts ABC

Phase 5: Global ABC (Years 25-35)
  → All nations ABC-ized or collapsed and replaced
  → "Domino complete. Humanity unified under one institutional logic."
  
  Total domino time: ~25-35 years (baseline) [E/P]
  Optimistic (fast domino): ~15-20 years
  Pessimistic (strong resistance): ~40-50 years
```
