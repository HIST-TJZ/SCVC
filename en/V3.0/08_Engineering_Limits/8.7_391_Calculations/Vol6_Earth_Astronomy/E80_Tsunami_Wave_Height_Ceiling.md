# SCVC Engineering Limit：海啸最大波高 — 地震能量+海底地形的物理Ceiling

> 结合E78地震Limit推导。tsunami wave height由地震/滑坡/撞击能量、海洋深度和浅水放大共同决定。
> SCVC通过岩石强度（bond energy→E78）和重力（g=9.81 m/s²，非SCVC常数但被认可）锁定物理Ceiling。

## §1. 地震海啸的波高Ceiling

### 1.1 能量耦合

海啸从地震中获取的能量仅是地震释放总能量的一小部分：

```
E_tsunami = η × E_seismic
η ≈ 0.001-0.01（耦合效率，0.1-1%）

最大地震（Mw 9.5, E78推导）:
  E_seismic ≈ 1.1×10¹⁹ J (Mw 9.5, Gutenberg-Richter)
  E_tsunami ≈ 10¹⁷-10¹⁸ J
```

| Mw | E_seismic (J) | E_tsunami (J, η=0.5%) | 等效核弹 | 历史事件 |
|----|---------------|----------------------|----------|----------|
| 7.0 | 2.0×10¹⁵ | 1.0×10¹³ | 2.4 kt | 海地2010 |
| 8.0 | 6.3×10¹⁶ | 3.2×10¹⁴ | 76 kt | — |
| 8.5 | 3.5×10¹⁷ | 1.8×10¹⁵ | 0.4 Mt | — |
| 9.0 | 2.0×10¹⁸ | 1.0×10¹⁶ | 2.4 Mt | 日本2011 |
| 9.2 | 4.0×10¹⁸ | 2.0×10¹⁶ | 4.8 Mt | 阿拉斯加1964 |
| 9.5 | 1.1×10¹⁹ | 5.6×10¹⁶ | 13 Mt | 智利1960 |

### 1.2 深海波高

海啸波的能量密度（单位波前长度）：

```
E / L_front = (1/8) × ρ × g × H² × λ

H = √(8 × E_tsunami / (ρ × g × λ × L_front))

ρ = 1025 kg/m³（海水）
λ ≈ 150-300 km（海啸波长）
L_front ≈ 1000-2000 km（破裂带长度）
```

| Mw | 深海波高 (m) | Notes |
|----|-------------|------|
| 8.0 | **0.9** | 几乎感觉不到（深海） |
| 8.5 | **2.2** | 小型海啸 |
| 9.0 | **5.1** | 2011年日本~5 m深海 |
| 9.2 | **7.3** | 1964年阿拉斯加~7 m深海 |
| **9.5** | **12** | 智利1960 ~10-15 m深海 |

> 深海中tsunami wave height仅数米——这正是为什么海员常常感觉不到海啸（波长200 km，坡度<1:10,000）。

### 1.3 浅水放大（Shoaling）

当海啸进入浅水区，波速降低，能量守恒要求波高增大：

```
Green定律: H_shallow / H_deep = (v_deep / v_shallow)^(1/2)

波速: v = √(g×d)    d: 水深

水深4000m → 10m: 放大 ≈ √(√(4000g)/√(10g)) ≈ 4.5×
加上折射/聚焦效应: 额外 2-3×
总放大: ~9-14×
```

**海岸线波高 = 深海波高 × 9-14**

| Mw | 深海 (m) | 海岸线 (m) | 历史观测 |
|----|---------|-----------|----------|
| 8.0 | 0.9 | **~8** | 小海啸 |
| 8.5 | 2.2 | **~20** | Moderate海啸 |
| 9.0 | 5.1 | **~46** | 日本2011: ~40 m |
| 9.2 | 7.3 | **~65** | 阿拉斯加1964: ~67 m |
| 9.5 | 12 | **~109** | 智利1960: ~25 m（非最优几何） |

> 智利1960年Mw 9.5但波高"仅"~25 m——因为破裂Direction平行于海岸（而非垂直），能量未向海岸聚焦。

### 1.4 极端最优场景

将所有parameter推到Limit——最优几何（破裂带垂直海岸）、最大耦合效率（1%）、最短波长（150 km）、最窄波前（1000 km）+ 极端浅水放大（从5000 m到5 m）+ 海湾聚焦：

```
最优场景最大海岸线波高: ~340 m
```

**SCVC锁定的地震海啸海岸线波高Ceiling：~300-500 m。** 这是在Mw 9.5+最优几何下的物理Limit。实际历史最大约67 m（1964年阿拉斯加，有记录）。

## §2. 滑坡海啸

### 2.1 Lituya Bay 1958 —— 524 m 的记录保持者

```
岩体: 3000万 m³
坠落高度: ~900 m
位能 = mgh ≈ 7×10¹⁴ J
波高: 524 m（对岸山坡最高爬升痕迹）
```

Lituya Bay的极端波高来自**能量在狭窄峡湾中的极度集中**——波前仅~1 km。这不是开放海洋海啸，而是局部涌浪。

### 2.2 火山侧翼崩塌 —— "超级海啸"场景

**加那利群岛（La Palma, Cumbre Vieja）：**

```
崩塌体积: ~500 km³（5×10¹¹ m³）
位能 = 5×10¹¹ × 2700 × 9.81 × 6000 ≈ 8×10¹⁹ J
     ≈ Mw 10.1 地震的能量（约7倍于Mw 9.5）

耦合效率: 滑坡入水~5%（远高于地震的0.5%）
海啸能量: ~4×10¹⁸ J
深海波高（100 km波前）: ~800 m（但超过海洋深度→破碎）

实际物理限制: 波高不能超过水深
水深~4 km → 波高Ceiling ~4 km（破碎波）
```

**海岸线爬升（近源）：**
```
波高受限后 → 以破碎波形式传播
近源岛屿: 500-1000 m 爬升
区域（1000 km）: 50-100 m
远洋（5000+ km）: 10-30 m（但波长极长→广泛淹没）
```

### 2.3 SCVC滑坡Limit

最大滑坡受限于山体高度。SCVC岩石强度Ceiling：

```
h_mountain_max ≈ σ_c / (ρ×g) ≈ 200 MPa / (2700×9.81) ≈ 7.6 km

实际: Mauna Kea ~10 km（从海底计）
最大崩塌体积: ~10,000 km³（整个岛屿侧翼）
```

SCVC最大滑坡海啸能量~2×10²¹ J → 比最大地震海啸（~10¹⁸ J）大~1000倍。**但波高仍受限于海洋深度（~5 km破碎），海岸爬升Ceiling~1000-2000 m。**

## §3. 陨石撞击海啸

### 3.1 Chicxulub 级（恐龙灭绝）

```
撞击体: r=7.5 km, ρ=3000 kg/m³, v=20 km/s
动能 = ½ × (4/3)πr³ × ρ × v² ≈ 1.1×10²⁴ J
     ≈ 260,000 Gt TNT（人类所有核武库的~10⁶倍）

海啸耦合: ~2%
海啸能量: ~2×10²² J（比最大地震海啸大~200,000倍）
```

**波高不受海洋深度限制** —— 撞击直接"炸开"海洋：

```
撞击点: 海洋被推开 → 深度瞬时为零
第一波: ~4-5 km（等于海洋深度，物理Ceiling）
全球海岸: 模型Prediction ~100-300 m 爬升
距撞击点最近海岸: 可能 >1000 m（证据: 墨西哥湾周边白垩纪-古近纪沉积）
```

### 3.2 SCVC Permits的最大撞击

太阳系最大近地天体——但SCVC不禁止更大撞击（极其罕见）。10-20 km级撞击体每~1亿年发生一次。

```
最大可信撞击体: r=15 km
动能: ~8.5×10²⁴ J (Chicxulub的~8倍)
海岸爬升: ~200-500 m（全球）
近撞击点: >2000 m
```

**设计基准：** 陨石撞击海啸的回归周期（>10⁷年）远超工程结构设计lifespan（~100-1000年）→ **不需要纳入常规工程设计。** 但对核电站等超临界设施，可作为"超越设计基准"的极端情景Assessment。

## §4. Engineering Conclusions

### 4.1 沿海核电站防波堤 —— 最高设计波高

| 海啸Source | 最大爬升 (m) | 年概率 | 是否纳入设计 |
|----------|------------|--------|-------------|
| 地震 Mw 9.0（区域俯冲带） | **30-50** | ~10⁻²-10⁻³ | ✅ 设计基准 |
| 地震 Mw 9.5（最大可信地震） | **50-100** | ~10⁻⁴ | ✅ 超越设计基准 |
| 地震极端几何 | **~300** | ~10⁻⁵-10⁻⁶ | ⚠️ 讨论中 |
| 滑坡海啸（区域） | **100-500** | ~10⁻⁴-10⁻⁵ | ⚠️ 场地特定 |
| 滑坡海啸（远洋） | **10-50** | ~10⁻⁴ | ⚠️ 需Assessment |
| 陨石撞击 | **100-500** | ~10⁻⁷-10⁻⁸ | ❌ 不纳入 |

**推荐设计基准（SCVC支持）：**

```
常规沿海防护: 10-30 m（Mw 8.5-9.0）
核电站/关键设施: 30-50 m（Mw 9.0-9.2）
+ 附加干舷（考虑极端几何和滑坡）: +20-30 m
→ 总设计高度: 50-80 m
```

日本2011年福岛的设计波高~5.7 m → 实际~14 m → **低估了2.5倍。** 以SCVC物理Ceiling为参照，设计 **50-80 m防波堤** 可覆盖Mw 9.5级地震和远洋滑坡海啸。

### 4.2 海啸预警系统

| 检测手段 | 响应时间 | 精度 |
|----------|---------|------|
| 地震仪（P波检测） | **<3分钟** | 震级估计±0.3 |
| GPS地壳形变 | **<5分钟** | 直接测量断层滑移 |
| 深海压力计（DART浮标） | **10-30分钟** | 直接测tsunami wave height |
| 海岸潮位计 | **海啸到达时** | 验证 |

**SCVC限定的预警时间窗口：**

```
地震波传播: v_P ≈ 6-8 km/s → 30秒到全球任意点
海啸传播: v_tsunami ≈ √(g×4000) ≈ 200 m/s = 720 km/h

距离震中1000 km: 海啸到达~1.4小时 → 预警窗口 ~1.3小时
距离震中5000 km: 海啸到达~7小时 → 预警窗口 ~7小时
```

物理Limit：**地震P波比海啸快30-40倍 → 预警永远可能（SCVC Permits），前提是检测和通讯足够快。**

### 4.3 海啸防御的最优组合

| 措施 | 效果 | 成本 | SCVC约束 |
|------|------|------|----------|
| **防波堤** | 直接阻挡 | 极高 | 结构强度由bond energy限定（E4） |
| **红树林/海岸林** | 衰减30-50%波能 | 低 | 树木高度~20-50 m（生物力学） |

**最优策略：预警+疏散为核心（保住人命），防波堤保护关键基础设施（核电站），红树林作为低成本补充（生态双赢）。**
