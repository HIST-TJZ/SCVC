# Ferroelectrics, Multiferroics, High-Pressure Phase Transitions

**Date**: 2026-07-25 | **Status**: 🟡 SCVC vortex ring dipole alignment

## Core
Ferroelectricity = spontaneous electric polarization from off-center ion displacement.
SCVC: ion displacement = vortex ring center shift in response to internal electric fields.

### Phase Transition Temperature
```
T_C ∝ (dipole-dipole interaction energy) ∝ α × (ion displacement)²/r³
```

### Multiferroic SCVC Condition
Simultaneous ferroelectric + magnetic order requires:
1. Different vortex ring subspaces for electric and magnetic dipoles
2. Weak cross-coupling (so one order doesn't suppress the other)

BiFeO₃ satisfies: Bi³⁺ lone pair (6s²) → ferroelectric, Fe³⁺ (d⁵) → magnetic. Different orbital subspaces.
