# E170: Tumor Angiogenesis — Physical Upper Limit

## Core
Tumor growth beyond ~1-2 mm³ requires angiogenesis. This process has physical limits.

### Diffusion Limit
```
O₂ diffusion distance ~100-200 μm (Krogh cylinder model)
→ Maximum avascular tumor diameter ~1-2 mm
→ Beyond this: hypoxia → HIF-1α → VEGF → angiogenesis
```

### Angiogenesis Speed Limit
- Endothelial cell doubling time ~50 h (not compressible — same DNA polymerase limit as E168)
- Vessel maturation: ~weeks-months
- Tumor vasculature is always "one step behind" tumor growth → chronic hypoxia → necrosis

### SCVC Physical Ceiling
```
Maximum tumor growth rate = min(cell division rate, angiogenesis rate)
Cell division ceiling: ~12 h/cycle (E168)
Angiogenesis ceiling: ~50 h/endothelial cycle + vessel maturation time

→ Angiogenesis is the rate-limiting step for tumors >2 mm
→ Anti-angiogenic therapy exploits this physical bottleneck
```

### Therapeutic Window
The "angiogenic switch" (2 mm → vascularized) is a critical transition:
- Before: diffusion-limited, slow growth, accessible to immune cells
- After: rapid growth, metastasis-capable

**SCVC: Anti-angiogenic therapy targets a genuine physical bottleneck, not just a "pathway."**
