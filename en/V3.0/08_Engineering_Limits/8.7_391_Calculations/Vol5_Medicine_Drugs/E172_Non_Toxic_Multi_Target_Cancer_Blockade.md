# E172: Non-Toxic Multi-Target Cancer Blockade — Physical Strategy

## Core: The Cancer Impossible Triangle (E171 Recap)
Cancer cells face: evade T cells (low specific MHC) + suppress NK (high total MHC) + grow (time). The window is narrow and can be closed.

## Four-Line Parallel Experimental Protocol (§9.9-9.14)

### Line 1: MHC Restoration + Checkpoint Blockade (§9.9: Start Today)
- HDAC inhibitor (e.g., Vorinostat) + DNMT inhibitor (e.g., Decitabine) → restore silenced MHC-I alleles
- Anti-PD-1 + anti-CTLA-4 → release T cell brakes
- **Start today**: Both drugs are FDA-approved (for other indications). Off-label combination trial can begin immediately.

### Line 2: NK Cell Enhancement (§9.10-9.12: Animal Acceleration)
- NK cell engager bispecific antibodies
- Anti-NKG2A (Monalizumab, Phase II)
- Combined with Line 1 in animal models → parallel testing of 4-6 combination arms

### Line 3: Multi-Target Blockade (§9.13-9.14: Four-Line Parallel)
- **Target 1**: MHC-I restoration (epigenetic)
- **Target 2**: T cell activation (checkpoint inhibitors)
- **Target 3**: NK cell activation (engagers + anti-NKG2A)
- **Target 4**: Angiogenesis blockade (anti-VEGF, E170 bottleneck)
- **Target 5**: Telomere crisis exploitation (G-quadruplex stabilizers)

### SCVC Physical Rationale
Each target corresponds to a genuine physical bottleneck:
1. DNA polymerase speed (E168) → S-phase hard wall
2. Mutation accumulation time (E169) → latency window
3. Angiogenesis diffusion limit (E170) → vascular bottleneck
4. MHC-I allele physics (E171) → immune evasion trilemma

**These are not "druggable pathways" — they are physical laws. Cancer cannot evolve around them any more than it can evolve around the speed of light.**

### Non-Toxic by Design
All targets exploit differences between cancer and normal cells that are **physical** not **pharmacological**:
- Normal cells don't lose MHC-I alleles → epigenetic restoration doesn't affect them
- Normal cells aren't angiogenic → anti-VEGF doesn't affect them
- Normal cells have intact checkpoints → checkpoint inhibitors have minimal effect on naive T cells
- Normal cells don't have telomere crisis → G4 stabilizers don't affect them

**SCVC Prediction**: The combination should be cancer-specific by physical necessity, not by pharmaceutical design.
