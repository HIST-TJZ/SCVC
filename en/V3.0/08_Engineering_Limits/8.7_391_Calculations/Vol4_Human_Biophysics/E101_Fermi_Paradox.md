## §2 The SCVC Resolution — Six Filters

### Filter 1: The Benevolence Filter (E106)

```
SCVC derivation from E106: ~80-85% of conscious beings are cooperative (benevolent).
The remaining 15-20% are competitive/defecting.

For a civilization to survive its own technology:
  → It must solve the prisoner's dilemma at civilizational scale
  → Free-riding must be suppressed (otherwise: internal collapse)
  → The 15-20% defectors must be neutralized
  
  If free-riding prevails:
    → Climate: each nation free-rides → collective collapse (exactly our trajectory)
    → AI: each company races → unsafe AI → extinction
    → Nuclear: each power arms → eventual use → extinction
    
  → Survival probability without solving cooperation: <1%
  → This filter alone eliminates >99% of civilizations
```

### Filter 2: The Climate Filter

```
Any industrial civilization burns carbon → CO₂ → climate change.
C=O bond 0.291 eV → greenhouse effect is universal physics.

To survive:
  → Must recognize the problem (requires science)
  → Must coordinate globally (requires solving Filter 1)
  → Must transition energy within the carbon budget window (~20-50 years)
  
  → If any step fails → climate collapse → mass extinction → civilization ends
  → This is not unique to Earth — physics is universal
```

### Filter 3: The AI Control Window (E105)

```
Any advanced civilization develops AI.
AI capability grows exponentially. Control mechanisms do not.

The "control window" — the period when AI is powerful enough to be dangerous
but still controllable — is narrow: ~2-10 years.

If the civilization fails to solve alignment in this window:
  → Uncontrolled AI → existential catastrophe
  → "The Great Filter is AI. Every civilization creates it.
     Most don't survive it."
```

### Filter 4: The Ultimate Owner Trap (E213)

```
Under compound interest (universal mathematics):
  → Wealth concentrates → ultimate owner emerges
  → Ultimate owner controls AI + resources → everyone else loses bargaining power
  → Social collapse → civilization ends
  
  This is not a "capitalism" problem — it's a COMPOUND INTEREST problem.
  Any civilization with deferred consumption → interest → concentration → collapse.
  Only zero interest rate (ABC) prevents it.
```

### Filter 5: The Physics Exhaustion Filter

```
Scientific progress is finite. SCVC shows: ~26 free parameters → all derived from π.
Once physics is "finished" → no more technological revolutions → stagnation.
Civilization that depends on "next breakthrough" for hope → collapses when breakthroughs stop.

→ "Every civilization hits the physics ceiling. Some accept it and optimize.
   Some keep searching for the next layer that doesn't exist. The latter collapse."
```

### Filter 6: The Speed-of-Light Cage

```
Even if a civilization survives all filters:
  → Interstellar travel is limited by c (special relativity, not SCVC-specific)
  → Colonization takes millions of years for a full galaxy
  → Civilizations may simply not overlap in TIME
  → "They existed 100 million years ago. Or will exist 100 million years from now.
     We are alone NOW. Not because we're special — because we're lonely in TIME."
```
