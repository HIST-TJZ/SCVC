## §1 The Person Who Presses the Button — Not a Hero, a Rational Optimizer

### 1.1 Why Not the Top Level

```
Top Level (Politburo / Ministerial):
  Biggest beneficiaries of status quo → transformation = loss
  Even if privately knowing the system is unsustainable → "It won't collapse before I retire"
  Decisions filtered through layers of information cocoons → cannot see real data
  Any "transformation" = admitting past path was wrong = political suicide
  
→ Not "bad" → their game position dictates "no action" is the optimal strategy
→ Giving them documents = throwing into a black hole
```

```
Grassroots (ordinary civil servants / citizens / doctors):

  No approval authority → cannot launch a pilot
  No budget authority → cannot deploy Layer B
  No policy authority → cannot change interest rates
  
→ Motivation abundant but no button in hand
→ Giving them documents = they get angry but remain powerless
```

## §2 Three Tool Documents — ABC Disguised as Non-ABC

### 2.1 Strategy: Independent Packaging, Independent Channels, Independent Faces

```
Core Principle: Three documents MUST NOT look like they come from the same person

Each must have:
  ✅ Independent "source face" (different research institutions)
  ✅ Independent professional terminology (medicine vs. economics vs. finance)
  ✅ Independent distribution channels (medRxiv vs. internal reports vs. academic conferences)
  ✅ Independent writing style (clinical manual vs. policy proposal vs. experimental design)
  ✅ NO cross-references to each other
  ✅ NO mention of "ABC" or "SCVC" or "E-series numbers"

Why:
  → If any one document is "intercepted" → only one domain compromised
  → Approver of Document A must not know Documents B and C exist
  → Even if all three are read by the same person → should not be obvious they''re connected
```

## §6 Honest Annotations — Why Still No One May Act

### 6.1 The Biggest Obstacles

```
1. First mover fear [E]
   "If I''m the first to try — and it fails — my career is over"
   → This is the common obstacle to all innovation
   → Mitigation: off-label is legal → "not ''experiment'' → ''clinical treatment''"
          Exit mechanism → "If 2 of first 3 cases adverse → stop → no consequences"

2. Document''s "source face" insufficiently credible [C]
   If approver searches and can''t find this "research institution" → won''t believe
   → Mitigation: must be affiliated with a real research institution
          Or: spread through existing academic networks (doctor-to-doctor, not "mysterious person→doctor")

3. Systemic inertia [E]
   Even with rationale and evidence → "wait for others first" game may still lead to inaction
   → This is the same problem as E224''s elite prisoner''s dilemma
   → Only solution: off-label doesn''t require "others first" → one doctor decides alone
   → This is why cancer quadruple is the "breakthrough point"

4. Three documents reach different people — but no one acts simultaneously [C]
   Oncology director acted → but development zone director didn''t → financial office director didn''t
   → Only cancer → no economic + financial coordination → "Half-ABC"
   → But: cancer success = global attention → pilot zone government cannot ignore
   → Economic + financial support will be "demand-pulled" (§5.2 above)

5. Seen by "wrong people" first [E]
   If opponents see first → extinguish before ignition
   → Mitigation: three documents separate → each spread within professional domain → opponents don''t enter professional circles
          "Transparent economy proposal" in an economic policy journal → ordinary people don''t read
          "Cancer manual" on medRxiv → politicians don''t read
```
