# 8.3 Class B: Selected Engineering Limits

**Version**: V3.0 | **Date**: 2026-07-24

---

This directory contains selected Class B engineering limits — physical ceilings derived from SCVC geometric constants. These are representative samples from the full set of 128 ceilings.

Each file covers a domain: Materials, Energy & Electronics, Human Biophysics, Earth & Astrophysics.

For the complete set of all 128 ceilings, see `08_Engineering_Limits/` under the V3.0 root.
