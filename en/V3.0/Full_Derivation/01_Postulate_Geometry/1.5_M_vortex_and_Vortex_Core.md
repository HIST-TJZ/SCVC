## Delzant Theorem: Existence and Uniqueness of $M_{vortex}$

> **Delzant (1988)**: For any compact polytope $\Delta \subset \mathbb{R}^n$ satisfying the Delzant conditions, there exists a unique compact toric Kähler manifold $(M_\Delta, \omega, J)$ with $\Delta$ as its moment map image. The DH integral depends only on the combinatorial data of $\Delta$, independent of the specific metric.

### Delzant Four Conditions for the Truncated Cone Polytope $\Delta$

| Condition | Verification | Status |
|:---|:---|:--:|
| **Simple** | Each vertex has exactly 3 edges (truncated cone = 3D) | ✅ |
| **Rational** | All 6 face normals are integers (including $d_2=2$) | ✅ |
| **Smooth** | At $F_1$, edge direction determinant = 1 → $\mathbb{Z}^3$ basis | ✅ |
| **Compact** | All coordinates are bounded | ✅ |

### Key Corollaries

- **No need to solve BPS equations to construct the metric** — Delzant guarantees existence
- **No need for an explicit Kähler potential** — the DH integral requires only combinatorial data
- **$M_{vortex}$'s existence is not an assumption — it is a theorem**

## GP Equation: Vortex Core Energy $E_{\text{CORE}} = 2.1322$

SCVC vacuum = $F=1$ spinor BEC. The vortex radial order parameter $f(r)$ satisfies the dimensionless GP equation:

$$f'' + \frac{f'}{r} - \frac{f}{r^2} + f - f^3 = 0$$

**Boundary conditions**: $f(0)=0$ (vortex core), $f(\infty)=1$ (ground state recovery).

**Shooting method solution**: unique free parameter $c_1 = f'(0) = 0.5831869855$, healing length $\xi_{\text{eff}} = 1.3176$.

### Vortex Energy Functional

For an $n=1$ vortex $\psi(r,\theta) = f(r)e^{i\theta}$, the GP free energy (per unit length):

$$E_{\text{vortex}} = 2\pi \int_0^\infty r\,dr \left[ \frac{1}{2}(f')^2 + \frac{f^2}{2r^2} + \frac{1}{4}(1-f^2)^2 \right]$$

| Term | Physical Meaning | Fraction |
|:---|:---|:--:|
| $\frac{1}{2}(f')^2$ | Gradient energy of the order parameter across the core | 25.2% |
| $\frac{f^2}{2r^2}$ | Kinetic energy of superfluid circulation $\sim 1/r$ | 35.9% |
| $\frac{1}{4}(1-f^2)^2$ | Potential cost of departing from the ground state $\lvert\psi\rvert=1$ | 38.9% |

### Core vs. Tail Separation

The centrifugal term at large $r$: $f^2/(2r^2) \rightarrow 1/(2r^2)$, integral → $\pi \cdot \log(R_{\max}/R_{\min})$ — **logarithmic divergence**.

This is the classic logarithmic divergence of 2D vortices, representing long-range inter-vortex interactions (captured by pair terms in simulations). Therefore $E_{\text{CORE}}$ is defined using only the core region $r < \xi$:

| Cutoff | $E$ | Description |
|:---|:--:|:---|
| $r < 1.00\xi$ | **2.1322** | Cleanest definition: within one healing length |
| $r < 1.50\xi$ | 3.3773 | Contains some tail energy contamination |
| $r < 8.00$ (full domain) | 7.7411 | Contains logarithmically divergent tail |
