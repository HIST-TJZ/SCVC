## 1. Runaway Electrons

Runaway condition: electric field force > collisional drag force.
```
E_crit = (n_e e³ lnΛ)/(4πε₀² m_e v_th²)
```
SCVC: e²=4παħc, lnΛ≈15 (Coulomb logarithm).
→ E_crit ∝ n_e·α^(3/2)·(k_B T)^(-1)

For tokamak disruption: E_crit ≈ 0.1-1 V/m.

## 3. Fusion Lawson Criterion

n_e τ_E T > 3k_B T²/(⟨σv⟩ E_α)
SCVC: ⟨σv⟩ ∝ exp(-√(E_G/k_B T)), E_G ∝ α² (Gamow peak).
→ Lawson criterion ultimately α-dependent. If α differed, fusion conditions would shift.
