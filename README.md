## 为什么这不是"拟合"

- **0 个自由参数。** 26个SM常数从同一个几何流形（CP²×S¹）的同一个计算框架（DH/GKM局域化）正向推出。
- **精度不是调出来的。** α⁻¹=4π³+π²+π 的整数 (4,1,1) 是6不动点枚举中唯一能匹配实验的组合——改了任何一个整数，结果直接崩塌。
- **392 项工程极限互相印证。** 从超导Tc到彩虹42°，从地震M9.5到细胞10μm——全部从同一组键能推出，键能又从同一个α推出。
