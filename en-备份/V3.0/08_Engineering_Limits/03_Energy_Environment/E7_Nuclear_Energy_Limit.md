1. 聚变能量增益 Limit
==============================================================

1.1 聚变Q值（精确计算）
--------------------------------------------------------------
从质量亏损直接计算各反应Q值：

  反应               Q值 (MeV)       带电产物能量     中子能量
  ─────────────────────────────────────────────────────────────
  D + T → ⁴He + n     17.59         3.52 (α)        14.07
  D + D → ³He + n      3.27         0.82 (³He)       2.45
  D + D → T + p        4.03         3.02 (T)+p       —
  D + ³He → ⁴He + p   18.35         18.35 (全带电)    —
  p + ¹¹B → 3⁴He      8.68          8.68 (全带电)     —

注：D-He³和p-¹¹B为无中子（aneutronic）聚变。

1.2 Gamow能量与Optimal温度
--------------------------------------------------------------
Gamow穿透因子决定低能截面：σ(E) ∝ exp(−√(E_G/E))

E_G = 2μc² · (παZ₁Z₂)²       (从α直接推导)

  燃料        Z₁Z₂    E_G (MeV)    T_opt (keV)    温度 (K)
  ─────────────────────────────────────────────────────────
  D-T          1       1.175         ~14          1.6×10⁸
  D-D          1       0.979         ~13          1.5×10⁸
  D-³He        2       4.700         ~22          2.5×10⁸
  p-¹¹B        5      22.438         ~37*         4.3×10⁸

  * p-¹¹BOptimal温度实际远高于37 keV，因为轫致辐射迫使
    工作点向更高温移动（见§2.2）。热峰在~600 keV。

1.3 Lawson判据
--------------------------------------------------------------
由Power平衡推导点火条件：

    P_α + P_ext = P_loss = 3nkT/τ_E

点火定义 P_ext = 0 → P_α ≥ P_loss

    nTτ_E ≥ 12kT / (⟨σv⟩ E_α)  ≈  3×10²¹ m⁻³·keV·s   (D-T)

其中 ⟨σv⟩_DT(14 keV) ≈ 1.1×10⁻²² m³/s。

1.4 约束时间的SCVC物理极限
--------------------------------------------------------------
约束由输运决定，最乐观极限为gyro-Bohm扩散：

    D_gB = (ρ_i/a) · D_Bohm
    ρ_i = √(2m_i kT) / (eB)              (离子回旋半径)

对ITER参数 (B=5.3 T, a=2.0 m, T=14 keV)：

    ρ_i(D)      = 0.0046 m
    D_Bohm      = 165 m²/s    → τ_Bohm ≈ 0.024 s
    D_gB        = 0.38 m²/s   → τ_gB   ≈ 10.6 s
    nTτ (gB)    = 1.5×10²² m⁻³·keV·s   = 5.0× 点火阈值

结论：gyro-Bohm极限下，约束裕度约5倍点火需求。
     实际装置（ITER）受限于湍流输运，约为gyro-Bohm的
     0.1-0.3倍，因此 nTτ_ITER ≈ 5.2×10²¹ = 1.7×阈值。

1.5 轫致辐射极限与点火可行性
--------------------------------------------------------------
轫致辐射Power（NRL formulary）：

    P_brem = C_B · n_e · Σ(n_z Z²) · √T_e
    C_B = 1.69×10⁻³⁸  W·m³·eV^(-½)

对D-T等离子体 (50:50, T=14 keV)：

    P_α / P_brem ≈ 7.7   >> 1   → 点火成立 ✓

SCVC结论：α和α_s不构成对D-T点火的理论禁止。
Q>100在物理原理上完全允许，仅受工程约束。

1.6 Q的理论最大值
--------------------------------------------------------------
Q与nTτ的简化关系 (D-T, E_fus/E_α ≈ 5.03)：

    Q ≈ 5.03 · f / (1 − f)
    其中 f = (nTτ) / (nTτ)_ignition

    f = 10% (当前托卡马克)    → Q ~  0.6
    f = 50%                   → Q ~  5
    f = 90%                   → Q ~ 45
    f = 95%                   → Q ~ 100
    f = 99%                   → Q ~ 500

⚫ Q=100 要求达到点火阈值 95.2% 的约束性能。
   从gyro-Bohm给出的5×裕度来看，物理上完全可达。
   ITER目标Q=10（~67%阈值），DEMO目标Q=30-50。
   Q>100的纯聚变电站 → 需要H-mode约束增强因子 H~1.5-2。

⏺ SCVC工程判断：Q>100在物理上无禁止，是工程挑战而非
   基础物理极限。α_s=1/(16π)给出的核力强度恰好使D-T
   处于"技术上困难但并非不可能"的窗口。

2.2 无中子聚变（Aneutronic）的SCVC分析
--------------------------------------------------------------
⚫ 核心问题：高Z燃料 → 巨大轫致辐射 → Power平衡崩溃。

轫致辐射 ∝ Σ(n_z Z²) ∝ Z²。对p-¹¹B（Z_B=5）：

    Σ(n_z Z²) = n_p·1 + n_B·25 = 13n     (vs D-T: 1n)

计算各工作点的 P_fusion / P_brem：

    温度           ⟨σv⟩           P_fus/P_brem      判断
    ─────────────────────────────────────────────────────
    148 keV (共振)  1.5×10⁻²²       0.62            < 1 ✗
    300 keV         1.0×10⁻²²       0.29            < 1 ✗
    600 keV (峰值)  3.0×10⁻²²       0.61            < 1 ✗

→ 在所有温度下，P_fusion < P_brem。

即使是总聚变Power（全为带电粒子，无中子能量损失），
也永远无法超过轫致辐射损失。此即"轫致辐射灾难"
（bremsstrahlung catastrophe）。

物理上这意味着：热平衡p-¹¹B聚变等离子体不可能达到
点火或Q>1。α给出的电磁耦合强度对Z=5来说太大了。

2.3 p-¹¹B可能的规避路径（SCVC评论）
--------------------------------------------------------------
以下路径不违反SCVC，但都有各自困难：

  (a) 非热平衡分布（快质子束打硼靶）
      → 规避Maxwellian轫致辐射，但能量展宽降低有效截面
      → "beam-target" 模式始终Q<1（束流能量损失到电子）

  (b) 场反转位形（FRC） + 高能离子环
      → 维持非Maxwellian分布，α粒子直接加热离子
      → TAE Technologies方向，尚无Q>1实证

  (c) 集体效应/相干聚变
      → 凝聚态/固态密度下的相干核反应？
      → α_s约束：核力只在fm尺度有效，宏观相干极难

⏺ SCVC工程判断：p-¹¹B热平衡聚变被α（电磁）和α_s（核力）
   联合锁死在Q<1。但要说是"物理死胡同"还言之过早——
   非热平衡方案可能存在非常窄的可行窗口。但作为
   "终极目标"显然过于乐观。D-³He（Z=2, E_G=4.7 MeV）
   是更现实的无中子目标。

2.4 D-³He：中间路线
--------------------------------------------------------------
D-³He (Z₁Z₂=2, E_G=4.7 MeV)：

    P_α / P_brem 在T~50 keV时约为3-5 → 点火可能 ✓
    全带电产物 18.35 MeV → 直接电能Conversion Efficiency可达80%+
    ³He稀缺（月球表面~10 ppb，地球更少）

    工程判断：D-³He物理可行，但³He供应是主要瓶颈。
    p-¹¹B则是物理上受阻，非单纯燃料稀缺问题。


3. 裂变与嬗变
==============================================================

3.1 裂变能量密度极限
--------------------------------------------------------------
从SCVC核结合能推导的Theoretical Limit：

    ²³⁵U理论能量密度 = 200 MeV / (235 u)
                     = 8.21×10¹³ J/kg
                     = 82.1 TJ/kg
                     ≈ 1.9×10⁶ × 汽油 (44 MJ/kg)

实际工程表现：
    轻水堆 (LWR)      50 GWd/t   = 4.3 TJ/kg  (5.3%)
    快中子堆 (FR)     150 GWd/t  = 13.0 TJ/kg (15.8%)
    闭式循环 (MSR)    理论可达    ~80 TJ/kg   (~97%)

    差距来自：裂变产物毒化、包壳辐照损伤、临界质量
    稀释。但SCVC不禁止接近100%燃耗——熔盐堆+在线
    后处理可逼近理论极限。

3.2 嬗变：中子经济学
--------------------------------------------------------------
嬗变长寿命核废料需要中子。来源有三：

  (A) 临界裂变堆的过剩中子
  ─────────────────────────────────────
      ²³⁵U热中子裂变：ν = 2.43 n/fission
      维持链式反应：−1.0
      泄漏：         −0.3
      Parasitism俘获：     −0.3
      可用于嬗变：   ≈ 0.8 n/fission
      能量成本：     200/0.8 ≈ 250 MeV/n
      → 但中子来自裂变链，属于"免费副产品"
      → 净能量正 ✓

      快堆 (²³⁹Pu)：ν = 2.9 n/fission → 可用 ~1.5 n/fiss
      → 剩余中子更多，嬗变Efficiency更高 ✓

  (B) 加速器驱动次临界系统 (ADS)
  ─────────────────────────────────────
      1 GeV质子 → Pb靶散裂：~25 n/p
      束流能量成本：40 MeV/n
      市电Efficiency ~40%：100 MeV(electrical)/n
      vs 裂变产生中子：~80 MeV(fission)/n
      → ADS消耗的市电能量大于裂变产生的热Power
      → 净能量负 ✗

  (C) 聚变-裂变混合堆
  ─────────────────────────────────────
      D-T聚变产生14.1 MeV中子 → 驱动次临界裂变包层
      每个聚变中子可引发多次裂变 → 中子倍增
      → 净能量正 ✓，且可嬗变大量废料

  方案        净能量     中子利用率    技术成熟度
  ─────────────────────────────────────────────
  临界快堆    正 ✓       中           中（已有原型）
  ADS         负 ✗       高           低（MYRRHA级）
  聚变混合堆   正 ✓       极高         极低（概念阶段）

3.3 嬗变的物理极限
--------------------------------------------------------------
嬗变分两类：

  (a) 中子俘获嬗变：n + 长寿命核 → β衰变 → 短寿命/稳定
      → 每次嬗变消耗1个中子
      → 中子来自裂变 → "免费"（在临界堆中）
      →  Limit由中子经济决定，非基础物理

  (b) 光致嬗变（γ,n反应）：高能γ → 敲出中子 → 核嬗变
      → 阈值 ~6-15 MeV（由核结合能 ~8.8 MeV决定）
      → 能量Efficiency极低（γ产生Efficiency ~10% → 总Efficiency ~1-3%）
      → 物理上可能但工程上不经济

⏺ SCVC工程判断：嬗变"净能量正"的路径存在且被
   SCVC允许——只需将嬗变作为临界堆的中子利用而不是
   独立能耗过程。最经济的方案是快中子堆的"焚烧+增殖
   +嬗变"三位一体。ADS始终净能量负，但若用于处理
   无法临界焚烧的次锕系核素（Np, Am, Cm），其成本
   可以计入废物管理费用而非能量生产。


4. 工程结论
==============================================================

4.1 可控聚变的工程可行性窗口
--------------------------------------------------------------
从SCVC角度看，可控聚变的约束是工程性的而非物Rationality的：

  ┌──────────────────────────────────────────────────┐
  │  障碍层次        本质              当前状态        │
  ├──────────────────────────────────────────────────┤
  │  点火物理         已突破 (NIF 2022)   Q_sci ~ 1.5 │
  │  约束品质         gyro-Bohm内        ITER Q=10    │
  │  材料耐受         第一壁/偏滤器      DEMO级需要   │
  │  氚自持           TBR > 1.05         ITER测试     │
  │  经济性           建造成本/运维      2040s评估    │
  └──────────────────────────────────────────────────┘

  ⚫ SCVC核心结论：α_s=1/(16π)给出的核力强度使
     D-T恰好处于"可点火但需要极限工程"的窗口——
     如果α_s小20%，库仑势垒将压倒核力，聚变完全不可能；
     如果α_s大20%，核力强到常温即可聚变。
     我们恰好生活在"聚变是可能的但很难"的宇宙中。

4.2 p-¹¹B：终极目标还是死胡同？

    远期 (>2060)：p-¹¹B（仅当非热平衡方案有重大突破）

  D-³He是更现实的无中子目标——Gamow能量仅为p-¹¹B的
  1/5，轫致辐射尚在可控范围。问题不在物理，在³He。

4.3 裂变废料处理的物理极限
--------------------------------------------------------------
  ┌─────────────────────────────────────────────────────┐
  │  完全嬗变在物理上允许（临界快堆的过剩中子即可）    │
  │  工程瓶颈：分离Efficiency、靶件辐照、临界安全            │
  │  分治策略：Pu (MOX焚烧) + MA (快堆嬗变) + FP (分离储存) │
  └─────────────────────────────────────────────────────┘

  Optimal策略 = 快中子堆 + 干法后处理 + 嬗变靶件：
    · 所有Pu和MA在快谱中焚烧/嬗变
    · 裂变产物 (Sr-90, Cs-137) 分离储存 ~300年
    · 最终地质处置体积减少 ~100×
    · 全过程"净能量正"——嬗变是裂变发电的副产品

4.4 SCVC终极工程全景
--------------------------------------------------------------
从α和α_s导出的Nuclear Energy利用全景：

    D-T聚变    ←──── 可点火，工程窗口窄但存在
      │
    D-³He     ←──── 物理可行，³He供应链是瓶颈
      │
    p-¹¹B     ←──── 热平衡被α+α_s锁死，非热平衡待验证
      │
    ²³⁵U裂变   ←──── 82 TJ/kg，当前利用率~5%，可逼近100%
      │

  所有约束来自α（电磁强度）和α_s（核力强度）的特定
  数值。如果这两个常数的值有微小变化，上述结论将完全
  不同。在这个意义上，工程极限 = 宇宙常数留下的窗口。
