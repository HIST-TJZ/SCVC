## §1. 太空端：Photovoltaic阵列

### 1.1 可用Solar Energy

```
地球轨道太阳常数（1 AU）: 1361 W/m²
GEO轨道：全年99.5%时间无日食（仅春/秋分附近短暂的阴影期）
容量因子：~95%

对比：
  地面最佳地点（撒哈拉）: 峰值1000 W/m², 年均~250 W/m², 容量因子~25%
  地面平均: 峰值1000 W/m², 年均~150-200 W/m², 容量因子~15-20%
```

**太空24/7接收Solar Energy的优势因子：1361×0.95/(200×0.25) ≈ 26×**

### 1.2 PhotovoltaicEfficiency（来自E3）

| 技术 | Efficiency | Power密度 (W/m²) | 状态 |
|------|------|----------------|------|
| Single-Junction (SQ极限) | 33.1% | 450 | SCVCCeiling |
| 三结 (当前空间级) | 32% | 436 | 🟢 在轨运行 |
| 四结 (实验室) | 40% | 544 | 🟡 待空间验证 |
| Multi-Junction顶限 (E3) | **~50%** | **680** | SCVC锁定 |
| Concentration+Multi-Junction | ~55% | 748 | 需要散热系统 |

### 1.3 质量预算

| 技术 | kg/kW | kW/kg | 1 GW站质量 (吨) |
|------|-------|-------|----------------|
| 刚性面板 (当前) | 5.0 | 0.2 | 27,000 |
| 柔性卷曲 (ROSA) | 2.5 | 0.4 | 13,500 |
| 薄膜 (远景) | 1.0 | 1.0 | 5,400 |
| 超薄 (理论) | 0.2 | 5.0 | 1,100 |

**SCVC约束：** Photovoltaic的Power/质量比受限于两个因素：
1. 吸收层最小厚度（需吸收~90%光子 → ~1-3 μm）
2. 支撑结构（需抵抗太阳辐射压+热变形）

量子极限的PVPower/质量比（仅考虑活性层）：
```
薄膜厚度 ~3 μm, 密度 ~2 g/cm³
面密度 = 3×10⁻⁶ × 2000 = 6×10⁻³ kg/m²
Power密度 = 680 W/m²
极限比Power = 680 / 0.006 ≈ 113 kW/kg
```

实际结构（基板+布线+展开机构）将比Power拉低至 ~5-10 kW/kg。这是SCVC允许的Absolute Limit。

### 1.4 展开结构的物理极限

```
1 GW地面输出 ≈ 需要 1GW/0.28 ≈ 3.6 GW 太空Photovoltaic
面积 ≈ 3.6×10⁹ / 680 ≈ 5.3 km² (边长2.3 km的正方形)

挑战:
  - 5.3 km² = 530个足球场 → 需模块化组装或在轨制造
  - 热控: 60%入射能变为热 → 需同等面积散热器
  - 姿态控制: 重力梯度力矩 ≈ 10⁵ N·m → 需要主动控制
  - 空间碎片: 5.3 km²面积 × 10年 → ~数百次mm级撞击
```

SCVC不禁止大面积空间结构（轨道力学+材料强度允许），但成本是天文数字。

## §2. 微波Power传输

### 2.1 全链路Efficiency

| 环节 | Efficiency | 物理限制 |
|------|------|----------|
| Photovoltaic DC 输出 | 50% (E3 Limit) | SCVC: α²mec² → Band Gap → SQ |
| DC 电力管理 | 95% | 欧姆损耗(ℏ, 电子散射) |
| DC → RF (放大器) | 85% | 固态PAEfficiency极限 |
| 波束成形 | 90% | 旁瓣控制 |
| 大气传输 | **97-99%** | 大气窗口 (SCVC: 分子能级) |
| 整流天线 RF→DC | 85% | 肖特基二极管极限 |
| 电网接入 | 95% | — |
| **全链路总计** | **~28%** | SCVC锁定 |

**最终输出：1361 × 0.28 ≈ 380 W/m²（每m²空间阵列）。**

### 2.2 微波频率选择

| 频率 | 波长 | 大气透过率 | GEO光斑(1 km天线) | 整流天线尺寸 |
|------|------|-----------|------------------|------------|
| 2.45 GHz | 12.2 cm | **99%** (晴) | **10.7 km** | 5-10 km |
| 5.8 GHz | 5.2 cm | **97%** (晴) | **4.5 km** | 3-5 km |
| 35 GHz | 8.6 mm | 85% | 0.7 km | ~1 km |

> 衍射：θ = 1.22λ/D → GEO距离35,786 km → 光斑直径 d = 2.44λR/D

**2.45 GHz是工业和医疗频段（ISM），大气透过率最高。** 代价是巨大的地面整流天线（5-10 km²）。5.8 GHz的光斑更小，但大气衰减略大且在暴雨中衰减显著。

### 2.3 地面Power密度约束

| 约束 | 限制值 (W/m²) | 来源 |
|------|-------------|------|
| 人体安全（公众） | 5-10 | IEEE C95.1 |
| 人体安全（受控） | 10-50 | IEEE C95.1 |
| 生态安全（鸟类/昆虫） | <100 | 动物实验 |
| 整流二极管热极限 | ~1000 | 器件物理 |
| **设计目标** | **~100-200** | 工程折中 |

在100 W/m²下：1 km² 整流天线 → 100 MW。5 km² → 500 MW。10 km² → 1 GW。

**1 GW空间电站需要 ~5-10 km²的整流天线**——约等于一个中型城市机场的面积。这是土地使用的主要挑战。

### 2.4 SCVC对微波链路的约束

大气微波窗口由H₂O和O₂的转动谱线决定：

```
H₂O: 22 GHz, 183 GHz（强吸收线）
O₂:  60 GHz复合带, 118 GHz

2.45 GHz: 远离所有吸收线 → SCVC允许的最高透过率
5.8 GHz: 在H₂O线翼 → 略高但可控的损耗

SCVC锁定: 分子转动能级由键长（C-C 1.54 Å等）和转动常数决定
          → 微波大气窗口的频率位置最终由α和m_e决定
```

## §3. 工程结论

### 3.1 空间 vs 地面Photovoltaic —— SCVC比较

| 指标 | 空间Solar Energy(GEO) | 地面Photovoltaic(最佳地点) | 比值 |
|------|---------------|------------------|------|
| 年均日照 (W/m²) | 1,293 (1361×0.95) | 250 | **5.2×** |
| PVEfficiency | 50% (SCVC Limit) | 25% (商用) | **2.0×** |
| 微波/逆变损耗 | 56% | 95% | **0.59×** |
| **年均输出 (W/m²集合器)** | **~360** | **~60** | **6×** |
| 容量因子 | 95% | 20-25% | **4.2×** |

**空间Solar Energy的单位集合器面积的年发电量约为地面Photovoltaic的 ~6倍。**

但发射成本将这一优势完全抹杀：

| 成本项 | 空间Solar Energy | 地面Photovoltaic |
|--------|-----------|---------|
| 集合器製造 | ~$500/kW | ~$300/kW |
| 发射到GEO (当前) | **~$3,750/kW** | $0 |
| 发射到GEO (Starship目标) | **~$250/kW** | $0 |
| 微波发射+整流天线 | ~$500/kW | $0 |
| 土地 | $0 (太空) | ~$50/kW |
| **总计 (当前)** | **~$4,750/kW** | **~$800/kW** |
| **总计 (Starship)** | **~$1,250/kW** | **~$800/kW** |

**SCVC判据：空间Solar Energy的经济性Dependencies于发射成本。** 即使Starship将发射成本降10×，空间Solar Energy仍比地面贵~50%。需要发射成本<$50/kg且阵列质量<0.5 kg/kW才能经济Competition。

### 3.2 但是——空间Solar Energy有不可替代的价值

| 场景 | 地面Photovoltaic | 空间Solar Energy |
|------|---------|-----------|
| 电网基荷供应 | ✅ 便宜 | ❌ 太贵 |
| 极地/高纬度 | ⚠️ 冬季无法 | ✅ 全天候 |
| 偏远军事前哨 | ⚠️ 需燃料补给 | ✅ 自主供电 |
| 灾难应急 | ⚠️ 天气影响 | ✅ 不受天气影响 |
| 月球基地 | ❌ 不可能 | ✅ **天然市场** |
| 火星基地 | ⚠️ Efficiency低(590 W/m²) | ✅ 轨道中继 |

**空间Solar Energy不会取代地面Photovoltaic成为主力电源——它在SCVC中找到了自己的生态位：特殊场景（极地/军事/灾害）+ 空间（月球）。**

### 3.3 月球 —— 空间Solar Energy的天然市场

月球上的空间Solar Energy优势：

```
① 无大气 → 微波传输Lossless耗（100%透过）
② 极地"永恒光照"峰 → 100%容量因子（近乎连续光照）
③ 低重力(1/6 g) → 展开结构质量减少
④ 无生态安全顾虑 → 微波Power密度可更高
⑤ 表面到表面传输 → 距离仅10-100 km（非GEO的35,786 km）
   → 衍射光斑缩小 (100/35000)² ≈ 0.0008% 面积
   → 发射天线可极小（数米，非数千米）
⑥ 为永久阴影坑中的水冰开采提供能量
```

**月面微波输电的SCVC优势：** 传输距离仅10-100 km，衍射光斑 ∝ R²，这意味着月球上的微波输电Efficiency可比GEO-地球高10⁵-10⁶倍（以需要的天线面积计）。

### 3.4 SCVC空间Solar Energy极限总结

| 参数 | SCVC极限值 | 决定因子 | 现状 |
|------|-----------|----------|------|
| 太阳常数 | 1361 W/m² | 太阳Nuclear Fusion（SCVC宇宙学） | 固定 |
| PVEfficiency | **~50%** (Multi-Junction) | α→Band Gap (E3) | 32% |
| DC-RFEfficiency | **~90%** | 固态器件极限 | ~85% |
| 大气微波透过率 | **~99%** (2.45 GHz) | 分子转动谱线 (α) | 99% |
| 整流天线Efficiency | **~90%** | 肖特基势垒 | ~85% |
| **全链路Efficiency** | **~34%** | 以上乘积 | ~18% |
| 比Power(阵列) | **~5-10 kW/kg** | 薄膜+结构 | ~0.4 kW/kg |
| 经济可行发射成本 | **<$50/kg** | 火箭方程 | ~$1500/kg |
