### 3.3 工业原料（🔴 最硬的骨头）

#### 化肥：N≡N 键 9.8 eV 的物理硬墙

`
传统 Haber-Bosch: 
  CH₄ + H₂O → CO + 3H₂ (甲烷重整制氢)
  N₂ + 3H₂ → 2NH₃ (铁催化剂, 400-500°C, 150-300 atm)
  排放: ~2.9 吨 CO₂/吨 NH₃

绿色 Haber-Bosch:
  ① 电解水制 H₂: ~55 kWh/kg × 178 kg = 9,500 kWh
  ② 空分制 N₂: ~200 kWh
  ③ 合成 (电加热): ~800 kWh
  ④ 总计: ~10,500 kWh/吨 NH₃

全球 NH₃ 产量: ~180 Mt/年
全绿色化需要: ~1.9 PWh/年 ≈ 全球电力 6.3%

SCVC: N≡N 键 9.8 eV（最强化学键之一）
  → 任何固氮Method都必须支付这个能量代价
  → 自然界用固氮酶（FeMo辅因子，15-16个ATP/N₂）
  → 工业用 Haber-Bosch（铁催化剂，高温高压）
  → 两者都需要大量能量 —— 这是化学，不是工程选择
`

#### 塑料：C-C 键 3.6 eV 的稳定性诅咒

`
化石路线: 石脑油裂解 → 乙烯/丙烯 → 聚合

绿色替代:
  ① 生物基塑料 (PLA, PHA): 可降解但性能受限
  ② CO₂ 聚合: 利用 CO₂ 作为原料 → 需要催化剂突破
  ③ 机械回收: 最节能（不断键，只重熔）→ 应优先
  ④ 化学回收: 热解回单体 → 能量成本高

C-C 键 3.6 eV → 塑料极其稳定 → 降解极慢
→ 回收 >> 生物降解（回收不断主链键）
→ 碳捕集 + CO₂ 聚合是长期方向
`

#### 钢铁：用氢替代焦炭

`
传统高炉: Fe₂O₃ + 3CO → 2Fe + 3CO₂
          焦炭提供还原剂(C→CO) + 热量
          排放: ~1.8 吨 CO₂/吨钢

氢直接还原 (H₂-DRI):
  Fe₂O₃ + 3H₂ → 2Fe + 3H₂O
  氢来自电解水 → 需要零碳电力
  排放: ~0 (如果氢是绿色的)

SCVC: Fe-O 键能量 → 氢还原在热力学上可行
  → 技术上已在小规模示范（HYBRIT, 瑞典）
  → 瓶颈: 氢的成本 + 工业改造的投资周期
  → 高炉寿命 ~20-40 年 → 需在下次大修时替换
`

#### 水泥：化学Inevitable，不是燃料问题

`
水泥工艺排放 (CaCO₃ → CaO + CO₂):
  CaCO₃ (100 g/mol) → CaO (56 g/mol) + CO₂ (44 g/mol)
  
  每吨 CaO 释放 0.786 吨 CO₂ —— 这是化学计量，不可规避
  
  全球水泥: ~4.2 Gt/年
  工艺排放: ~3.4 GtCO₂/年 = 全球排放 ~8%
  
  → 即使燃料 100% 零碳，仍排放 3.4 GtCO₂
  → 这不是燃料问题，是 CaCO₃ 分子的化学问题

三种出路:
  ① 碳捕集（点源或 DAC）→ 唯一可规模化选项
  ② 替代胶凝材料（地质聚合物）→ 但 CaO 的化学简单性难以匹敌
  ③ 碳固化混凝土（CO₂ 注入养护）→ 可固化 ~5-10% 自身重量的 CO₂
  
SCVC: Ca-O 键能量locked / locked-in了 CaCO₃ 的稳定性
  → 水泥是化学问题，不是燃料问题
  → 碳捕集是唯一出路
`

## §4. 合成燃料 EROI：逆转燃烧的物理代价

### 4.1 Why合成燃料永远比Fossil Fuels贵？

`
合成航空煤油 (Fischer-Tropsch 路径):

  1 吨合成燃料 ≈ 857 kg C + 143 kg H
  
  能量Input:
    捕获 CO₂ (DAC): 3.1 吨 × 120 kWh/吨  =   377 kWh
    电解水制 H₂:   143 kg × 55 kWh/kg   = 7,857 kWh  
    FT 合成:                             =   500 kWh
    ─────────────────────────────────────────────────
    总Input:                                8,734 kWh/吨
  
  燃料含能: 43 MJ/kg × 1000 / 3.6       = 11,944 kWh/吨
  
  EROI = 11,944 / 8,734 = 1.37

对比:
  原油→汽油 EROI: ~10-15（历史峰值 ~100）
  合成燃料 EROI:  ~1.4（当前）→ ~2.4（热力学Ceiling）
  
  → 差 5-10 倍
  → 合成燃料永远比Fossil Fuels贵
  → 物理原因: 逆转燃烧 = 把 CO₂+H₂O 拼回烃 = 必须支付键能差价
  → 这是 C=O 键 (0.291 eV) 和 C-H 键 (3.5 eV) 之间的热力学鸿沟
`

## §7. 绿色增长 vs 去增长：SCVC的物理判断

### 7.1 脱钩的物理上限

`
历史: 能源强度改善 ~1-2%/年, GDP增长 ~3%/年
      → 净能源使用仍在增长（相对脱钩，非绝对）

物理地板:
  材料经济最低能耗: ~8 MJ/kg 重排原子 (C-C 键 3.6 eV 量级)
  全球材料消耗: ~100 Gt/年
  材料经济地板: ~22 万 TWh ≈ 全球一次能源 ~12%
  
  → 即使所有信息工作能耗为零，材料需求locked / locked-in了能源地板
  → "绝对脱钩"（增长但能耗不增）存在硬性物理Ceiling

信息经济:
  Landauer 极限: kT ln 2 ≈ 2.9×10⁻²¹ J/bit
  理论上信息 GDP 可以几乎无能耗
  但 GDP 最终要兑换为物理产品（食物、房屋、衣服）
  → 数字 GDP 的"去物质化"有上限——你不能吃 bits
`

### 7.2 体面生活的能源地板

`
全球人均一次能源: ~23,000 kWh/年
  发达国家: ~50,000 kWh/年
  发展中国家: ~5,000 kWh/年

SDG7 估计的"体面生活"最低能源: ~15,000 kWh/年
  100 亿人 × 15,000 kWh = 150,000 TWh ≈ 当前全球能源总量

SCVC判断:
  "去增长"不是Physical Necessity——是Politics选择。
  
  在物理上，体面生活的人均能源 ~15,000 kWh/年是可行的。
  100 亿人 × 15,000 kWh = 150 PWh（需要全部零碳）。
  
  但当前的全球不平等意味着:
    富人需要降: 从 50,000 → 20,000 kWh/年
    穷人需要升: 从 5,000 → 15,000 kWh/年
    
  → 这是分配问题，不是物理问题
  → 物理不要求去增长；物理要求重新分配
  → "绿色增长"在物理上是可能的——如果贫富差距被缩减
`
