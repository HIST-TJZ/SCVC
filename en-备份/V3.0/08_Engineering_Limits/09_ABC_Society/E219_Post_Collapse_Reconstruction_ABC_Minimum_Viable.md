## 1. 废墟版ABC——不需要电力的最低版本

### 1.1 设计约束

```
废墟约束:
  (X) 没有服务器 → B层不能是分布式账本
  (X) 没有AI → 不能自动审计
  (X) 没有互联网 → 不能全球同步
  (X) 没有货币系统 → 不能Zero Interest Rate(技术意义上)
  (X) 能源极度有限 → 任何消耗必须值得

但ABC的核心原则不依赖技术:
  (OK) Transparency → 可以用眼睛看、用嘴说、用墙写
  (OK) 延迟 → 可以用"等7天"代替"等C层"
  (OK) 反囤积 → 可以用社区规范代替Zero Interest Rate
  (OK) Collision Detection → 可以用"Three Laws刻在石头上"代替算法
```

### 1.2 废墟版B层：社区Bulletin Wall

```
物理形态: 社区中心一面石墙/木板墙/大地岩石

功能:
  → 所有交易公开记录（谁给了谁什么）
  → 所有冲突公开记录（谁对谁做了什么）
  → 所有资源公开记录（库存有什么、用了多少）
  → 所有人的贡献公开记录（谁修了水渠、谁照顾了病人）

规则:
  (1) 每笔交易必须在墙上记录（或口头宣布→两个见证人记录）
  (2) 记录不可涂改（划掉旧记录必须保留原迹→类似区块链"不可篡改"）
  (3) 任何人都可以查看墙（Transparency=p_detect≈你的邻居都在看）
  (4) 虚假记录→墙上也被记录→双倍惩罚

Why在小社区(<150人，Dunbar数)有效:
  → 每个人都认识每个人
  → 墙上的记录 = 你的Reputation = 你的生存资格
  → 作弊被发现的概率: 极高（小社区里没有匿名）
  → 不是技术Transparency → 是社会Transparency
  → 和完整ABC的B层逻辑完全一致——只是介质从"服务器"变成"社会记忆"

规模限制:
  >150人 → Dunbar数超限 → 无法认识所有人 → 需要书面记录
  >1000人 → 需要多层Bulletin Wall + 代表制度
  但废墟初期(<150人/社区)这个限制不存在
```

### 1.3 废墟版C层：社区会议延迟

```
物理形态: 每周一次全体社区会议（固定时间、固定地点）

功能:
  → 重大决策在会议上提出 → 等7天 → 下次会议投票
  → 所有人可以发言（类似"查询"）
  → 所有人的立场被公开记录（谁反对、谁支持、Why）

延迟分层（废墟版）:
  Tier 1 (1天):   个人借贷、小纠纷 → 邻居调解
  Tier 2 (7天):   资源分配、规则修改 → 社区会议
  Tier 3 (30天):  驱逐成员、加入新成员 → 两次会议间隔
  Tier 4 (90天):  改变Three Laws本身 → 三次会议+全体同意

Why有效:
  → 冲动决策被缓冲（"等下次会议再说"）
  → 情绪冷却 → 理性回归（7天足够多巴胺消退）
  → 社区集体记忆 = B层永久记录
  → 和完整ABC的C层逻辑完全一致——只是延迟靠日历不靠算法
```

### 1.4 废墟版Zero Interest Rate：劳动时间记账

```
物理形态: 社区账本（石板/木刻/结绳）

规则:
  (1) 1小时劳动 = 1信用点（不分工作类型——医生的1小时=农民的1小时）
  (2) 信用点不可生利息（Zero Interest Rate——借10还10，不能还11）
  (3) 信用点定期过期（每季度清零50%→防止囤积→Currency Reset废墟版）
  (4) 基本生存需求免费（食物、水、庇护→由社区共同劳动提供）
  (5) 信用点只能换"额外"的东西（更好的工具、更暖的衣服、烟酒等奢侈品）

Why"不分工作类型":
  → 废墟中每项工作都是生存必需的
  → 医生和农民同样重要
  → 区分"高技能"和"低技能"=旧世界等级制=废墟中分裂社区
  → 没有人会"不想当医生因为钱少"——因为根本没有钱

与完整ABC的类比:
  完整ABC: Zero Interest Rate(r=0) → 资本不能增值 → 无Final Owner
  废墟ABC: Zero Interest Rate(借10还10) → 劳动信用不能增值 → 无新酋长
         + Currency Reset(季度清零50%) → 不能囤积 → 人人需要持续贡献
```

### 1.5 废墟版Three Laws：刻在石头上

```
刻在社区入口的大石头上（不可移动、不可隐藏）:

  Law1: 不得伤害他人身体。
         若伤害→墙上记录→赔偿受害者→若严重→驱逐。
  
  Law2: 看见他人有生命危险，必须帮助（如果你能而不受伤）。
         若见死不救→墙上记录→等同于伤害。
  
  Law3: 不得破坏共享资源（水源、粮仓、工具、种子库）。
         若破坏→墙上记录→修复+赔偿→若严重→驱逐。

Why刻在石头上:
  → 不能改（物理形态的"不可篡改"）
  → 所有人都能看到（物理形态的"Transparency"）
  → 新成员加入时第一件事: 摸石头、读Law
  → 石头比任何服务器都长寿
```

## 4. 废墟ABC的Game TheoryVerification

### 4.1 废墟版的Prisoner's Dilemma

```
废墟场景（两个幸存者，交换食物vs偷食物）:

  无ABC规则:
    偷食物→一方得利→另一方死
    → 下一次没人交换 → 都死
    → 霍布斯"所有人对所有人的战争"

  有废墟ABC规则（Bulletin Wall+社区会议）:
    偷食物→墙上被记录→社区知道
    → 没人再和偷者交换 → 偷者被孤立
    → 偷的期望值<0
    → 合作回到Nash Equilibrium
    
  和完整ABC完全一样——只是检测靠人眼不靠算法
  p_detect在小社区(~100人)下: ~95%(每个人都认识每个人)
  → Game Theorylocked / locked-in同样有效
```

### 4.2 废墟版的E106Verification

```
E106: 善意80-85%
```
