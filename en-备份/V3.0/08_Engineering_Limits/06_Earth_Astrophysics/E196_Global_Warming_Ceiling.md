## §1. 辐射强迫与反馈 — SCVC锁死的物理链

### 1.1 CO₂的温室效应：从分子振动到全球强迫

CO₂的红外吸收来自C=O键的振动——键的劲度系数由α控制的电子密度分布决定。每分子吸收截面→大气柱浓度→辐射强迫：

```
ΔF = 5.35 × ln(C/C₀)  W/m²

C₀ = 280 ppm（工业化前）
```

| 情景 | CO₂浓度 | ΔF (W/m²) | 相当于 |
|------|---------|-----------|--------|
| 2×CO₂ | 560 ppm | **3.7** | 基准（ECS参考） |
| 4×CO₂ | 1,120 ppm | 7.4 | RCP8.5世纪末 |
| 全部化石燃料 | ~2,000 ppm | 10.5 | 最大人为排放 |
| 化石+水合物+永冻土 | ~5,000 ppm | **15.4** | Earth系统最坏 |
| 极端最坏 | ~10,000 ppm | **19.1** | 接近PETM |

### 1.2 反馈的代数 — 为什么净反馈总是负的

| 反馈 | λ (W/m²/K) | 符号 | 物理机制 |
|------|-----------|------|---------|
| **Planck（黑体T⁴）** | **-3.3** | 🔵负 | 越热→辐射越多 — Stefan-Boltzmann |
| 水汽 | +1.8 | 🔴正 | 越热→大气持水越多→更多温室效应 |
| 递减率 | -0.8 | 🔵负 | 上层对流层暖更快→更高效散热 |
| 冰反照率 | +0.3 | 🔴正 | 冰融→地表变暗→吸收更多阳光 |
| 云（净） | +0.2 | 🔴正 | 低云冷却vs高云加热→净正（不确定） |
| **净反馈 λ_net** | **-1.8** | 🔵负 | **Planck永远主导** |

```
关键：Planck反馈的幅度（-3.3 W/m²/K）压倒所有正反馈之和（+2.3 W/m²/K）。
这是气候系统的"重力"——你可以暂时往上跳（正反馈），
但最终会落回地面（T⁴辐射必须与吸收平衡）。
```

### 1.3 平衡气候敏感性（ECS）

```
ECS = ΔF(2×CO₂) / |λ_net| = 3.7 / 1.8 ≈ 2.1°C

IPCC AR6范围： 2.0-4.5°C（中Confidence Level2.5-4.0°C）
SCVC推导：    ~2.1°C（反馈参数采用中值）
```

## §2. 物理天花板 — T⁴辐射封顶

### 2.1 Stefan-Boltzmann的上升刹车

```
Planck反馈随温度增强：
λ_P(T) = -4σT_eff³

当前 T_eff ≈ 255K：λ_P ≈ -3.76 W/m²/K
+6°C (T_eff≈260K)：λ_P ≈ -4.0  W/m²/K  （+6%更强）
+10°C (T_eff≈263K)：λ_P ≈ -4.1  W/m²/K  （+10%）
+15°C (T_eff≈267K)：λ_P ≈ -4.3  W/m²/K  （+15%）
+20°C (T_eff≈271K)：λ_P ≈ -4.5  W/m²/K  （+20%）

Planck反馈随温度增强 → 在某个点，即使所有正反馈叠加也无法再推高温度
→ 这就是物理天花板
```

### 2.2 各情景的最坏升温

| 情景 | ΔF (W/m²) | λ=-1.0（保守） | λ=-1.5（中值） | λ=-2.0（乐观） |
|------|----------|-------------|-------------|-------------|
| 2×CO₂ (560 ppm) | 3.7 | 3.7°C | 2.5°C | 1.9°C |
| 全部化石燃料(~2000 ppm) | 10.5 | 10.5°C | 7.0°C | 5.3°C |
| 化石+水合物(~5000 ppm) | 15.4 | **15.4°C** | 10.3°C | 7.7°C |
| 极端(~10000 ppm) | 19.1 | **19.1°C** | 12.7°C | 9.6°C |

```
SCVC物理天花板：+15-20°C（高于工业化前）
→ 到达此温度后，T⁴辐射增量 > 所有温室效应增量
→ 温度自动封顶 — 不会走向金星（+460°C）

关键：Earth不会变成金星。水蒸气的凝结+T⁴辐射
提供了金星所没有的恒温器。但+15°C已经足够灭绝
大多数复杂生命。
```

## §3. 不可逆阈值 — 级联的Earth系统临界点

### 3.1 温度-后果矩阵

| ΔT | 触发事件 | 时间尺度 | 可逆性 |
|-----|---------|---------|--------|
| **+1.5°C** | 珊瑚礁白化（>70%丧失） | 数十年 | 部分可逆（需数十年降温） |
| **+2.0°C** | 格陵兰Ice Sheet注定融化 | 数百年 | **不可逆**（滞后数万年） |
| +2.5°C | 北极夏季海冰消失 | 数十年 | 可逆（如果降温） |
| **+3.0°C** | 亚马逊雨林→稀树草原 | 一个世纪 | 滞后、可能不可逆 |
| **+4.0°C** | 西南极Ice Sheet崩塌 | 数百年-千年 | **不可逆**（Sea Level+3-5m） |
| +5.0°C | AMOC大幅减弱/崩溃 | 数十年-世纪 | 滞后（有双稳态） |
| +6.0°C | 浅层甲烷水合物释放 | 数百年 | 自持数百年 |
| +8.0°C | 大规模灭绝条件（PETM级） | 数千年 | 恢复需10⁵年 |
| +12.0°C | 接近二叠纪-三叠纪条件 | 数十万年 | 恢复需10⁶年 |

### 3.2 级联逻辑

```
+2°C 触发格陵兰 → 不可逆（即使降温，Ice Sheet已进入正反馈融化）

+4°C 触发西南极 → Sea Level+3-5m承诺 → 沿海城市注定淹没

+5°C 触发AMOC → 欧洲变冷+热带Precipitation崩溃 → 区域灾难

+6°C 触发甲烷水合物 → 更多变暖 → 自持数百年

+8°C：多重临界点同时崩溃 → 全球生态系统重组
      → 农业系统无法适应 → 文明级危机

+15°C：T⁴辐射封顶 → 温度不再上升
       → 但Earth已进入"温室Earth"状态
       → 恢复需要数十万年
```

## §4. 工程结论

### 4.1 物理天花板 vs 政治天花板

```
巴黎协定目标：  +1.5-2.0°C（政治天花板）
当前政策轨迹：  +2.5-3.0°C
全部化石燃料：  +7-15°C（物理天花板，取决于反馈强度）

SCVC判断：
  物理天花板（+15-20°C）远高于政治天花板（+1.5-2.0°C）。
  T⁴辐射是所有正反馈的终极刹车——
  但这刹车在+15°C才踩死，
  远在任何人类文明可以承受的温度之上。
  
  "不用担心，物理会救我们"——是的，但它救的是"Earth有大气层"，
  不是"人类有文明"。
```

### 4.2 与E161碳捕集的联动

```
E161推导了碳捕集的物理 Limit（基于SCVC键能）。
如果CO₂已在下降（通过捕集+减排）：

→ +2°C以下：大部分临界点可避免（珊瑚除外）
→ +2-4°C：部分临界点已触发但或可管理
→ +4°C+：即使CO₂下降，格陵兰+西南极的融化已不可逆
                → 但降温仍可避免更高级联（AMOC、水合物）

结论：碳捕集的价值不取决于"是否已超2°C"——
      每避免0.1°C的额外升温，都减少触发更多临界点的概率。
      T⁴的刹车在+15°C才到底——我们的工作空间远比想象的大。
```

### 4.3 SCVC对气候工程的最终判断

```
三重物理真相：

1. 变暖有天花板（+15-20°C）
   → Earth不会变成金星。T⁴辐射是物理硬刹车。
   
2. 但天花板远在文明承受力之上
   → +4°C就足够触发多重不可逆崩溃
   → +8°C是PETM级灭绝条件
   
3. 速度比总量更致命
   → 生态系统能适应Geology时间尺度的变化
   → 不能适应百年尺度的变化（人类排放比二叠纪快10×）
   
SCVC的"乐观"：物理不会让Earth变成金星。
SCVC的"悲观"：物理也不在乎人类文明能否承受+4°C。
                刹车在+15°C——但我们死在+4°C。
```
