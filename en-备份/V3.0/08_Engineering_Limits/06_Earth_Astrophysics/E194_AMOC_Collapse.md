## §1 物理链: 从H键到海水下沉

### 1.1 水密度异常来源于H键

水的反常性质——4°C密度最大、热膨胀系数非线性、盐度收缩——全部源于H键网络(0.20 eV/键)的统计力学:

- **热膨胀**: 升温→H键断裂→分子间距增大→密度下降
- **盐度收缩**: 离子破坏H键网络→水分子更紧密排列→密度上升
- **4°C异常**: H键网络重排的竞争效应

### 1.2 AMOC下沉条件

海水状态方程(线性化, N. Atlantic):

\[
\rho = \rho_0 \left[1 - \alpha_T(T - T_0) + \beta_S(S - S_0)\right]
\]

| 参数 | 值 |
|------|-----|
| ρ₀ | 1027.5 kg/m³ |
| α_T (热膨胀) | \(1.5\times10^{-4}\)/°C |
| β_S (盐度收缩) | \(7.8\times10^{-4}\)/psu |

### 1.3 下沉 vs 不下沉

| 水团 | T (°C) | S (psu) | ρ (kg/m³) |
|------|--------|---------|-----------|
| 正常表层(冬季) | 0 | 34.90 | 1028.04 |
| 淡化表层 | 0 | 34.50 | 1027.72 |
| 深层水 | 2.5 | 34.95 | 1027.69 |
| **Δρ(正常-深层)** | | | **+0.345 → 下沉 ✓** |
| **Δρ(淡化-深层)** | | | **+0.025 → 不下沉 ✗** |

### 1.4 临界盐度

中性浮力条件:

\[
S_{\text{crit}} = S_{\text{deep}} - \frac{\alpha_T \cdot \Delta T}{\beta_S} = 34.95 - \frac{1.5\times10^{-4} \times 2.5}{7.8\times10^{-4}} = 34.47\text{ psu}
\]

当前表层盐度34.90 psu。需要稀释 **ΔS = 0.43 psu** 才能阻止下沉。

## §2 格陵兰融化 vs 临界点

### 2.1 临界淡水注入量

| 参数 | 值 |
|------|-----|
| 下沉区域面积 (Nordic + Labrador) | ~2×10¹² m² |
| 冬季混合深度 | ~800 m |
| 下沉水体体积 | ~1,600×10¹² m³ |
| **临界淡水总量** | **~19,700 Gt** |

### 2.2 时间线

| 情景 | 格陵兰融化(Gt/yr) | 到达下沉区(40%) | 距离临界点 |
|------|-------------------|-------------------|------------|
| 当前 (2020s) | 270 | 108 | **~183 年** |
| 2050 低排放 | 400 | 160 | ~123 年 |
| 2050 高排放 | 800 | 320 | **~62 年** |

### 2.3 正反馈加速

⚠ AMOC已减速15%(自1950年)。减速→向N.Atlantic输热减少→Evaporation减少→表层盐度恢复减缓→进一步减速。

这形成了**迟滞效应(hysteresis)**——即使恢复当前融化速率，AMOC可能不回弹到原状态。临界点的精确位置有模型不确定性，但SCVC的密度约束给出了物理下限: 至少需要~20,000 Gt淡水。

## §3 干预方案

### 3.1 人工增盐 ❌

| 指标 | 值 |
|------|-----|
| 年需盐量 | ~3.8 百万吨 |
| 年成本 | **~$189B** |
| 能量需求 | 极高(Evaporation海水产盐) |

> ❌ 每年$189B持续数十年——经济上不可持续，且大面积Evaporation池的生态代价巨大。

### 3.2 Ice Sheet反射膜 🟡

在格陵兰消融区(~5%Ice Sheet面积, ~85,000 km²)铺设反射材料:

| 指标 | 值 |
|------|-----|
| 面积 | ~85×10⁹ m² |
| 削减融化 | ~81 Gt/yr (30%) |
| 一次性成本 | **~$85B** |
| 延长临界时间 | 从62年→90年(高排放) |

> 🟡 一次性投资$85B在国际气候融资范围内(对比:全球年军费$2.2T)。但极地部署和维护的物流挑战、对生态的影响需要进一步评估。

### 3.3 与E192厄尔尼诺对比

| | AMOC | 厄尔尼诺(E192) |
|----|------|---------------|
| **干预窗口** | **~60-180年** | **~55天** |
| 物理门槛 | 中等 | 低 |
| 最可行方案 | 反射膜+减排 | 平流层气溶胶 |
| SCVC判决 | 🟡 工程墙 | 🟡 物理墙 |

> AMOC的时间窗口比厄尔尼诺宽~1000倍。瓶颈不在物理，在政治意愿和工程投资。
