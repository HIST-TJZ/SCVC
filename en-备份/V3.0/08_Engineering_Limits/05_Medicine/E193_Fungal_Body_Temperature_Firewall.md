2. FungiProtein热不稳定 — SCVC 的物理根源
==============================================================

2.1 为什么Fungi蛋白 Tm 比哺乳动物低 10-15°C?
--------------------------------------------------------------
    Tm = ΔH / ΔS

    ΔH (去折叠焓 — 稳定蛋白的键能):
    
    来源              哺乳动物 (每残基)      Fungi (每残基)
    ─────────────────────────────────────────────────────
    主链 H 键          ~0.25 eV              ~0.25 eV (相同)
    侧链 H 键          0.8-1.2               0.5-0.8 (少 ~30%)
    疏水核心           1.0-1.5               0.6-1.0 (少 ~35%)
    盐桥              0.3-0.5               0.1-0.3 (少 ~50%)
    ─────────────────────────────────────────────────────
    总计               ~2.3-3.5 eV/残基       ~1.5-2.4 eV/残基

    300 残基蛋白: ΔH_mammal ~700-1050 eV, ΔH_fungus ~450-720 eV

    ⚫ Fungi蛋白的稳定化能量少 ~30-40% → ΔH 更低 → Tm 更低!

2.2 为什么Fungi蛋白"省了"这些稳定化?
    ⚫ 进化原因:
    · 土壤温度 25-30°C → 不需要高 Tm → 
      没有选择压力来维持高密度 H 键网络
    · 在低温下, Protein需要更多柔性 (Catalysis需要构象变化) →
      太多稳定化 = 太刚性 = 低活性 (E184 的权衡!)
    · 所以Fungi选择了"柔性高, 活性高, Tm 低"的Strategy

    ⚫ 哺乳动物选择了相反的Strategy:
    · 恒温 37°C → 需要 Tm > 55°C → 
      进化压力推向高密度 H 键 + 大疏水核心 + 多盐桥
    · 代价: Protein更刚性 → 但恒温提供了稳定的工作温度 →
      不需要柔性来适应温度波动

    ⚫ 这就是"同一个物理 (E184 活性-稳定性权衡)" 
      在进化上的不同答案!

2.3 37°C 下Fungi蛋白的边际稳定性 — 定量
--------------------------------------------------------------
    Fungi蛋白 Tm ≈ 42°C (315 K), 哺乳动物 Tm ≈ 55°C (328 K)

    在 37°C (310 K):
    Fungi: ΔG(310K) = ΔH × (1 - 310/315) = ΔH × 0.016
          对于 ΔH ≈ 600 eV → ΔG ≈ 9.6 eV ≈ 0.032 eV/残基
    
    哺乳动物: ΔG(310K) = ΔH × (1 - 310/328) = ΔH × 0.055
          对于 ΔH ≈ 900 eV → ΔG ≈ 49.5 eV ≈ 0.165 eV/残基

    ⚫ Fungi蛋白的折叠稳定性: ~10 eV/蛋白
    ⚫ 哺乳动物蛋白: ~50 eV/蛋白 → 5× 更稳定!
    ⚫ 10 eV ≈ k_B T × 390 → 去折叠概率 ~exp(-390) ≈ 10⁻¹⁷⁰ 
      → 在 37°C 仍然极稳定 (单个蛋白)
    ⚫ 但! 这只是"平均" — Tm 分布有尾巴!


3. Tm 分布 — 37°C 过滤了多少种Fungi?
==============================================================

3.1 Fungi蛋白 Tm 的统计分布
--------------------------------------------------------------
    HypothesisFungi蛋白 Tm 呈近正态分布:

    · 土壤Fungi (温带): μ ≈ 42°C, σ ≈ 5°C
    · 土壤Fungi (热带): μ ≈ 44°C, σ ≈ 5°C
    · 嗜热Fungi (堆肥): μ ≈ 50°C, σ ≈ 6°C
    
    ⚫ 关键: Tm 分布有尾巴 — 少数Fungi的 Tm 延伸到 50°C+

    一个Fungi要感染人类, 需要的不是"一个蛋白能存活"—
    是整个Proteome (~6000 个蛋白) 在 37°C 下保持折叠!
    → 这相当于要求最不稳定的那个关键蛋白也在 37°C 保持功能。

4. 细胞膜的额外脆弱性 — 不仅仅是Protein
==============================================================

4.1 Fungi膜的 37°C 困境
--------------------------------------------------------------
    Fungi细胞膜含麦角甾醇 (ergosterol), 而非胆固醇。
    
    膜流动性 ∝ 温度 — 太高 → 膜"漏" (离子泄漏)
    脂质相变温度 (从凝胶到液晶):
    · Fungi (麦角甾醇): ~25-35°C
    · 哺乳动物 (胆固醇): ~15-25°C

    ⚫ 在 37°C: Fungi膜已经远高于相变温度 →
      膜过于流动 → 通透性过高 → 离子梯度泄漏!
    ⚫ 哺乳动物在 37°C: 胆固醇使膜刚化 → 仍在舒适区

    Fungi在 37°C 需要:
    · 上调麦角甾醇合成 → 膜刚化
    · 上调膜转运蛋白 → 补偿泄漏
    → 这些都是额外的 ATP 成本 → 生长减慢

4.2 为什么抗Fungi药可以靶向麦角甾醇?
    两性霉素 B: 结合麦角甾醇 → 形成膜孔 → Fungi死亡
    唑类 (氟康唑): 抑制麦角甾醇合成 → 膜流动性 ↑ → 37°C 时致命!

    ⚫ 这些Drug之所以有效 — 恰恰是因为Fungi膜已经在 37°C 的
      边缘 → 再抑制麦角甾醇 → 膜崩塌!
    ⚫ 哺乳动物细胞 (胆固醇) 不受影响 → Therapeutic Window!

    · Tm ~48-53°C — 比大多数念珠菌更耐热

    · 在环境表面存活数周 (医院暴发)

    ⚫ SCVC 假说: 耳念珠菌是全球变暖的"第一只金丝雀"。
    · 土壤升温 → 某种原本 Tm 偏高的环境Fungi →
      获得了在 37°C 生长的能力 →

5.3 每升温 1°C → 多少新Fungi进入危险区?
--------------------------------------------------------------
    已知土壤Fungi物种: ~10⁵-10⁶
    可感染人类的已知Fungi: ~300-400 种

    当前 (+0°C): z = (47-42)/5 = 1.0 → 尾部 ~15.9% 的物种
    · 15.9% × 10⁵ = ~16,000 种 → 但只有 ~300-400 种已知致病
    · 因为除了 Tm, 还需要: 穿透屏障 + 逃避免疫 + 获取营养

    · 新增: 21.2-15.9 = 5.3% → ~5,300 种新进入 Tm 范围

    · 新增: 27.4-15.9 = 11.5% → ~11,500 种

      其中只要一小部分同时满足"穿透+逃逸"条件 →
      新致病Fungi涌现的概率显著上升!

    ⚫ 最危险的新Fungi候选 (从 Tm 和生态位推算):

6. 发烧 — Immune System的热力学武器
==============================================================

6.1 发烧的 SCVC 基础
--------------------------------------------------------------
    发烧 (38-41°C) 不是"Immune System的Side Effect" — 
    是主动的、古老的热力学防御。

    从 37°C 到 39°C (ΔT = +2°C):
    · Fungi中 Tm 在 42-47°C 的Protein → 
      去折叠 ΔG 进一步降低 → 更不稳定
    · Arrhenius: FungiEnzyme的活性开始下降, 而非上升!

    宿主蛋白 (Tm ~55°C):
    · ΔT = +2°C → 仍在 Tm 之下 ~16°C → 完全不受影响
    · 免疫细胞 (Neutrophil, Macrophage) 在 39°C 
      实际上活性增强!

    ⚫ 发烧 = 把战场温度推到Fungi的边缘, 
      而自己仍在舒适区 → 不对称战争!

6.2 发烧过滤了多少%?
--------------------------------------------------------------
    Fungi Tm 分布, 需要"在给定温度下能生长":

    37°C: 需要 Tm > 42-45°C → ~10-15% 的Fungi物种
    39°C: 需要 Tm > 44-47°C → ~5-8% 的Fungi物种
    41°C: 需要 Tm > 47-50°C → ~2-4% 的Fungi物种

    ⚫ 39°C 发烧: 额外过滤 ~40-50% 的可感染Fungi
    ⚫ 41°C 高烧: 额外过滤 ~60-80% 的可感染Fungi
    ⚫ 但 41°C 对宿主自身也有风险 (Neuron >40°C 受损) →
      Immune System在"自损"和"杀敌"之间权衡。

    ⚫ 这就是为什么退烧药 (布洛芬/对乙酰氨基酚) 
      可能延长Fungal Infection! — 你撤回了热力学武器。

6.3 为什么有些Fungi不惧发烧?
    隐球菌 (C. neoformans):
    · Tm ~47°C → 41°C 发烧仍可存活
    · 多糖荚膜 → 物理屏障 → 减少热传导
    · 黑色素 → 吸收热量 + Antioxidant

    曲霉 (A. fumigatus):
    · Tm ~50-55°C → 在 41°C 完全不受影响
    · 可以在堆肥中生长 (>50°C!) → 人体发烧对它来说
      是"稍微暖和一点"而已

    ⚫ 这些"超级耐热Fungi" → 发烧无效 → 
      只能依赖抗Fungi药 + Immune System


7. 人体不是均匀的 37°C — 皮肤是Breakthrough
==============================================================

    皮肤温度: 30-34°C (四肢更低)
    · 对大多数Fungi来说, 这个温度完全舒适!
    · → 皮肤Fungi病比全身Fungi病常见得多
      (足癣、股癣、甲癣 — 全球 ~20-25% 人口!)

    呼吸道 (吸入Fungi孢子):
    · 鼻腔: ~30-32°C → 孢子萌发
    · 肺部: 37°C → Immune System必须在Fungi适应 37°C 前清除它
    · 如果免疫缺陷 → Fungi有时间上调 Hsp90 + 适应 37°C →
      肺曲霉病/隐球菌肺炎

    ⚫ 皮肤是"Firewall的漏洞" — 温度不够高
    ⚫ 肺是"Firewall的前线" — 温度够高但Fungi有时间适应


8. 与Bacteria的对比 — 为什么Bacteria不怕 37°C?
==============================================================

    Bacteria蛋白 Tm 分布: 与哺乳动物相似 (μ ~50-55°C)
    · Bacteria在土壤中面临更高的温度波动 (日晒、堆肥)
    · → 早在感染人类之前就已经进化了高 Tm
    · → 37°C 对Bacteria来说是"常规温度"

    Bacteria病的频发不是因为"Bacteria更多" —
    是因为"温度墙"对Bacteria不存在 → 
    Immune System是唯一的防线。
    
    对Fungi: 温度墙 + Immune System = 双重防线 → 感染极少
    对Bacteria: 只有Immune System = 单防线 → 感染频繁

    ⚫ 这就是为什么Fungi病死亡率 (150万/年) << 
      Bacteria病 (770万/年) 的物理根源!
