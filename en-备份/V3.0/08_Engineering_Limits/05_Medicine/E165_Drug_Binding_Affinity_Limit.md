1.3 熵惩罚
--------------------------------------------------------------
    结合必须付出的熵代价:

    来源                              能量 (eV)     本质
    ────────────────────────────────────────────────────────
    平动+转动熵丧失                   ~0.6-0.9      双分子→单分子

    Protein构象熵丧失                   ~0.1-0.3      结合界面刚化
    去溶剂化 (有利)                    −0.3 到 −1.0   释放水分子
    ────────────────────────────────────────────────────────

    ⚫ 疏水效应是"大自然的狡猾"——
      释放受限水分子 → 熵增 → 补偿一部分焓损失。
      否则所有Drug结合都会弱 ~1 eV。


2. ΔG 的物理天花板
==============================================================

2.1 热力学天花板 vs 动力学天花板
--------------------------------------------------------------
    ┌─────────────────────────────────────────────────────────┐
    │ 热力学天花板 (纯 ΔG):                                      │
    │ ΔG_theor ≈ ΔH_max − TΔS ≈ −6.3 + 0.8 = −5.5 eV          │
    │ Kd_theor ≈ e^(ΔG/RT) ≈ 10⁻⁹⁵ M                           │
    │ → 理论上 Kd 可以小到比宇宙中的原子数还小                    │
    │ → 但这种"结合"意味着 k_off 比宇宙年龄还长                   │
    │ → 在药理学上等同于不可逆共价结合                           │
    │                                                          │
    │ 动力学天花板 (实用的):                                      │
    │ k_off_min ≈ 1/τ_dosing (Drug只需在给药间隔内停留)           │
    │ τ_dosing ≈ 1 周 → k_off_min ≈ 1.7×10⁻⁶ s⁻¹               │
    │ k_on_max ≈ 10¹⁰ M⁻¹s⁻¹ (E27 扩散墙)                      │
    │ Kd_min = k_off / k_on = 1.7×10⁻¹⁶ M                      │
    │ ΔG_min ≈ −0.9 eV (−22 kcal/mol)                          │
    │                                                          │
    │ ⚫ 实用地板: Kd ≈ 10⁻¹⁶ M。                               │
    │   超过此值 → Drug"永不脱落" → 在临床上等价于共价抑制剂       │
    └─────────────────────────────────────────────────────────┘

3. Drug Design的工程Conclusion
==============================================================

3.1 生物素-链霉亲和素是天花板吗？
--------------------------------------------------------------
    ┌────────────────────────────────────────────────────────┐
    │ 答案: 是, 也不是。                                        │
    │                                                       │
    │ 不是物理学天花板:                                         │
    │ · 理论 ΔH_max ~ −6 eV → Kd 理论上可低至 10⁻⁹⁵ M          │
    │ · 更实用的动力学天花板: Kd ~ 10⁻¹⁶ M                      │
    │ · 生物素-SAv (10⁻¹⁴ M) 离实用天花板还有 ~60× 空间         │
    │                                                       │
    │ 是"自然选择"天花板:                                       │
    │ · 进化花了 40 亿年没找到比 10⁻¹⁴ M 更强的非共价结合        │
    │ · 因为更紧 = 停留更久 = 生物学上不需要                     │
    │ · 且: 结合太紧 → 无法解离 → 失去调控能力                   │
    │   (Receptor需要能"开"和"关", 不仅仅是"开")                     │
    │                                                       │
    │ 是"Drug Design"的天花板 (几乎):                                │
    │ · 对多数Drug靶点, Kd~1 nM (10⁻⁹ M) 已足够                  │
    │ · 追求 < 10⁻¹² M → 边际临床收益递减                        │
    │ · 但特定场景 (长效注射剂, Antibody-Drug偶联物,                  │
    │   诊断试剂) 确实受益于超高亲和力                            │
    └────────────────────────────────────────────────────────┘

3.2 Drug亲和力还可以优化多少？
--------------------------------------------------------------
    当前Drug        Kd (M)         离实用天花板        提升空间
    ──────────────────────────────────────────────────────────
    典型苗头化合物    10⁻⁶-10⁻³       10¹⁰-10¹³×           巨大!
    先导化合物        10⁻⁹-10⁻⁷       10⁷-10⁹×             大
    临床候选药        10⁻¹⁰-10⁻⁸      10⁶-10⁸×             中等
    已上市Drug        10⁻¹²-10⁻⁹      10⁴-10⁷×             小-中
    "完美Drug"        10⁻¹⁴           10²× (=生物素-SAv)    窄
    实用天花板        10⁻¹⁶           1×                    已到
    ─────────────────────────────────────────────────────────

    ⚫ 对大多数还在优化中的Drug, 离天花板还很远 (10⁶-10¹⁰×)。
    ⚫ 但对已经高度优化的 (如某些抗Virus药), 提升空间 ~10²-10³×。
    ⚫ 实用上: "魔弹"的 ΔG 极限 ≈ −0.9 eV ≈ −22 kcal/mol。
      这不是"不够好", 而是"在这个宇宙中不可能更好"。

3.3 为何更强的结合如此困难？
--------------------------------------------------------------
    ┌─────────────────────────────────────────────────────────┐
    │ 三道 SCVC 墙把Drug DesignLocked-In在 ~−0.9 eV:                       │
    │                                                        │
    │ 1. 熵惩罚 — 不可绕过                                      │
    │   任何双分子结合都必须丧失 ~0.7 eV 的平动/转动熵。           │
    │   只有共价结合 (单分子内) 才能避免。                         │
    │                                                        │
    │ 2. 水 — 双刃剑                                           │
    │   极性基团在水中被溶剂稳定 → 结合时断裂溶剂化层 → 能量惩罚。  │
    │   疏水基团 → 有利熵 → 但过度疏水 → 不溶性 + 非特异性结合。   │
    │                                                        │
    │ 3. Pauli 排斥 — 形状互补的极限                              │
    │   涡旋环 (电子 = 拓扑缺陷) 不能重叠 → 完美互补需要            │
    │   原子级精度的形状匹配。任何 >0.1 Å 的位置Deviation → vdW 损失。  │
    │   这在 ~20-30 个原子的大界面上要求所有原子同时完美对齐。       │
    │   → 这是一个 10²⁰ 中选一的搜索问题 → 进化花了几十亿年。       │
    └─────────────────────────────────────────────────────────┘
