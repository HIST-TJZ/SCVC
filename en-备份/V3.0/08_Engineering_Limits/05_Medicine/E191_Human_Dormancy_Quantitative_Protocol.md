1. 四种DormancyProtocol的温度-Metabolism映射
==============================================================

1.1 Arrhenius Metabolism率 vs 温度
--------------------------------------------------------------
    基础Metabolism率 (BMR) 随温度下降:

    BMR(T) / BMR(310K) = (T/310) × exp(-E_a/k_B × (1/T - 1/310))

    对 E_a = 0.4 eV (典型MetabolismEnzyme):

    ┌──────────┬──────────┬──────────┬──────────────────────────┐
    │ 温度     │ T (K)    │ BMR%     │ 备注                     │
    ├──────────┼──────────┼──────────┼──────────────────────────┤
    │ 37°C     │ 310      │ 100%     │ 正常                     │
    │ 35°C     │ 308      │ 91%      │ 熊式浅Dormancy               │
    │ 32°C     │ 305      │ 78%      │ 治疗性Hypothermia上界         │
    │ 30°C     │ 303      │ 68%      │ 心脏安全边界             │
    │ 28°C     │ 301      │ 64%      │ ⚠️ Na⁺/K⁺ 泵效率 ~50%   │
    │ 25°C     │ 298      │ 50%      │ 🔴 室颤风险极高          │
    │ 20°C     │ 293      │ 36%      │ 🔴 不能自主维持          │
    │ 15°C     │ 288      │ 25%      │ 🔴 心脏几乎停跳          │
    │ 10°C     │ 283      │ 17%      │ 🔴 需要完全体外循环      │
    │ 0°C      │ 273      │ 12%      │ 地松鼠Hibernation体温 (但人有   │
    │          │          │          │  不同的Ion Channel!)        │
    └──────────┴──────────┴──────────┴──────────────────────────┘

    ⚫ 注意: 这是"如果心脏能承受"的理论 BMR —
      实际人体安全温度被心脏锁定在 ~28°C 以上!

1.2 心脏的物理地板 — 为什么 28°C?
--------------------------------------------------------------
    Na⁺/K⁺-ATP Enzyme活化能 E_a ≈ 0.50 eV:

    k_pump(301K) / k_pump(310K) = exp(-0.50/8.617e-5 × (1/301-1/310))
    = exp(-5805 × 0.000096) = exp(-0.557) ≈ 0.57

    ⚫ 28°C 时钠泵效率降至 57%

    心肌细胞每搏:
    · 正常 Na⁺ 内流 ~10 mM/s (Action Potential上升支)
    · Na⁺/K⁺ 泵需匹配此速率
    · 泵效率 57% → Na⁺ 在胞内累积 → 膜电位去极化

    累积 ~10-30 秒 → 去极化 >15 mV → 
    触发异常自动节律 → 室颤 → 无效泵血 → 死亡

    ⚫ 这就是人类在 <28°C 时心脏停跳的物理根源 —
      不是"巧合", 是 Na⁺ 泵活化能锁定的Result。

    地松鼠为何能到 0°C?
    · 它们的心肌表达不同的 Na⁺ 通道亚型 (Na_v1.5 的低温适应性剪接)
    · 钠泵密度高于人类 ~2-3×
    · 人类可以通过Gene Therapy改变钠通道 — 但目前没有

    ⚫ 没有基因修改: 人类心脏地板 = 28°C
    ⚫ 有基因修改 (过表达 Na_v1.5 低温亚型 + Na⁺/K⁺ 泵):
      地板可能推低到 10-15°C

3. 垃圾积累 — 各类Dormancy的安全时长 (来自 E189)
==============================================================

3.1 垃圾积累速率 vs Metabolism率
--------------------------------------------------------------
    E189 给了在 37°C 下的垃圾积累时间。如果Metabolism率降到 R:

    可溶错误蛋白:
    · 产生 ∝ Transcription+Translation错误率 → ∝ Metabolism率 R
    · 降解 (UPS) ∝ Enzyme活性 → 也 ∝ Metabolism率 R
    · → 净积累 ∝ R (产生和降解同比例减慢)
    · → Toxicity阈值时间 ∝ 1/R
    · → E189: 10-20 年 (37°C) → 在 10% BMR 下 → 100-200 年

    聚集蛋白 (tau, α-syn):
    · 聚集 = 非线性 (自Catalysis)
    · 但在 lag phase: 单分子错误折叠 ∝ R
    · → lag phase 延长 ∝ 1/R
    · E189: 5-15 年 → 在 10% BMR 下 → 50-150 年

    脂褐素:
    · ∝ 氧化损伤 → ROS ∝ 呼吸链通量 → ∝ R
    · 完全不可降解 → 线性积累 ∝ R
    · E189: 30-50 年 → 在 10% BMR 下 → 300-500 年

    Mitochondria损伤:
    · ROS ∝ R (呼吸链)
    · 修复 (MitochondriaAutophagy) ∝ R
    · → 净积累 ∝ R (产生和清除同比例)
    · E189: 15-20 年 → 在 10% BMR 下 → 150-200 年

    ⚫ 关键Hypothesis: 产生和清除同比例减慢 → Toxicity阈值时间反比于Metabolism率。
    ⚫ 这个Hypothesis对大多数垃圾成立, 但对聚集蛋白 (非线性) 需要Verification。

7. Drug剂量 — 从物理到 mg
==============================================================

7.1 腺苷 A1 激动剂 (降Hypothermia调定点)
--------------------------------------------------------------
    目标: 将下丘脑体温调定点从 37°C 降至 32-35°C。

    内源性腺苷在视前区: 正常浓度 ~0.1-1 μM
    Hibernation动物: ~5-10 μM → 体温调定点降至 ~30-35°C

    Drug选择:
    · N⁶-cyclohexyladenosine (CHA): A1 选择性激动剂, K_d ≈ 1 nM
    · 目标浓度: ~10-50 nM (血浆) → ~0.3-1.5 μg/kg/h 持续输注
    · 或: 口服双嘧达莫 (抑制腺苷再摄取) → 内源性腺苷 ↑ →
      更生理性的途径

    ⚫ Side Effect: 心动过缓 (A1 在心脏) → 需要监控 + 可能起搏。
    ⚫ Physical Constraint: 腺苷-A1 结合 ΔG ≈ -1.5 eV (多个 H 键) →
      高亲和力 → 低浓度有效 → 低Toxicity。

7.2 H₂S 供体 (Mitochondria Complex IV 可逆抑制)
--------------------------------------------------------------
    目标: Metabolism率降至 10-20%。

    内源性 H₂S: ~10-100 μM (组织)
    Hibernation诱导: ~50-200 μM H₂S → Complex IV 抑制 ~50-80%

    Drug:
    · GYY4137: 缓释 H₂S 供体, Half-Life ~2-3 h
    · 目标浓度: ~50-100 μM (血浆)
    · 剂量: ~10-50 mg/kg IV 负荷 + 1-10 mg/kg/h 维持
    · 或: Na₂S (更快但更短效)

    ⚫ 关键: H₂S 的抑制是完全可逆的 — 停药后Mitochondria恢复。
    ⚫ 在小鼠中已Verification: 80 ppm H₂S 吸入 → Metabolism降至 10%,
      核心体温降至 15°C, 6 h 后完全恢复, 无神经损伤。
    ⚫ 人类数据: 仅极低剂量 (安全测试) → 未知高剂量是否安全。

8.2 唤醒过程的应激
--------------------------------------------------------------
    熊从Hibernation中醒来: 体温从 35°C 回到 37°C — 轻微。
    地松鼠从 0°C 回到 37°C: 需要 ~2-3 小时, 
    伴随大量 ROS 产生 (再灌注样损伤)。

    人类从深低温 (10-20°C) 唤醒:
    · 需要缓慢复温 (~1°C/h) → 需要 17-27 小时
    · 复温期间: Metabolism率 ↑ → ROS ↑ → 需要Antioxidant剂保护
    · Protocol: 复温前给予 N-乙酰半胱氨酸 (谷胱甘肽前体) + 
      MitoQ (Mitochondria靶向Antioxidant剂)

    ⚫ 复温损伤是深低温Dormancy的"隐性墙"—
      不是冷冻的冰晶, 但 ROS 爆发可损伤 mtDNA。

8.3 终极问题: "Dormancy 1 年" 在物理上是否等价于"年轻 1 年"?
--------------------------------------------------------------
    如果Metabolism率 10%, 垃圾积累 10%, 
    Telomere Attrition 10%, Stem Cell消耗 10% →
    Dormancy 1 年 ≈ 正常老化 0.1 年 → 是的, 你"只老了 1.2 个月"。

    但两个例外:
    ① Synapse: 长期不活跃 → 可能被修剪 (Synapse可塑性) →
       如果被修剪, 信息丢失不能靠"Metabolism率"恢复
    ② 结缔组织: 弹性蛋白的老化主要由 AGEs 和机械疲劳驱动, 
       不是Metabolism率 (AGEs 形成 ∝ 糖浓度, 在Dormancy中糖低 → 有利)

    ⚫ Synthesis: Dormancy 1 年 ≈ 老化 0.1-0.2 年 (物理老化), 
      但Synapse信息可能额外丢失 → 定期唤醒 + 学习训练
      可以对抗Synapse修剪。
