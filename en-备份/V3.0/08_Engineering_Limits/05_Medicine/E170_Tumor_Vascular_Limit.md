1. 氧扩散 — 肿瘤的无血管天花板
==============================================================

1.1 Krogh 圆柱模型
--------------------------------------------------------------
    组织中的一根毛细血管支持半径 R 的圆柱:

    R_max² = 4D_O2 × (C_cap − C_crit) / M_O2

    D_O2 ≈ 2×10⁻⁹ m²/s
    C_cap ≈ 0.1 mol/m³ (毛细血管中溶解氧)
    C_crit ≈ 0.001 mol/m³ (Mitochondria呼吸临界氧浓度)
    M_O2 ≈ 0.02 mol/m³/s (肿瘤耗氧率)

    R_max ≈ √(4×2×10⁻⁹×(0.1−0.001)/0.02) ≈ 2×10⁻⁴ m ≈ 200 μm

    ⚫ 任何细胞距离最近的毛细血管超过 ~150-200 μm → 缺氧!
    ⚫ 这是 SCVC 设定的扩散墙 — D_O2 由 α (溶剂-溶质作用) 设定。

1.2 无血管期的肿瘤最大体积
--------------------------------------------------------------
    在没有血管新生的情况下, 肿瘤作为球体从外界获取氧:

    仅能支持: R ≈ 150-200 μm (与 Krogh 一致)
    V_max_avascular ≈ 0.01-0.03 mm³ ≈ 10⁴-3×10⁴ 细胞

    ⚫ 这就是"原位癌" (carcinoma in situ) 的物理定义!
      超过此体积 → 必须诱导血管新生 → 否则中心Necrosis。
      这是肿瘤进展的必经瓶颈 — 血管开关 (angiogenic switch)。


2. 血管新生 — 永远追不上肿瘤
==============================================================

2.1 内皮Cell Division vs 肿瘤生长
--------------------------------------------------------------
    内皮Cell Cycle ≈ 24 h → 毛细血管延长 ≈ 0.1-1 mm/天
    肿瘤Cell Cycle ≈ 1-3 天 (in vivo) → 球体半径扩大 ~0.3-1 mm/倍增

    → 血管新生永远落后于肿瘤生长
    → 肿瘤核心总是缺氧/Necrosis (除非血管从表面向内生长)
    → 这是Necrosis核心 (necrotic core) 的 SCVC 物理根源!

2.2 Tumor Vasculature — 混乱且低效
--------------------------------------------------------------
    · 血管弯曲、囊状扩张、动静脉短路
    · 内皮细胞间隙大 → 高渗透 → 高间质压 (IFP)
    · 高 IFP → 压迫血管 → 灌注不均 → Drug无法到达

    ⚫ SCVC: 血管内皮细胞的连接由钙黏蛋白 (cadherin) 介导
      → VE-cadherin 二聚化 ≈ 0.3-0.5 eV
      → 肿瘤分泌 VEGF → 破坏连接 → 高渗透
      → VEGF 的有效性是 α 设定的Ligand-Receptor结合能的Result

3. Warburg 效应 — 有氧Glycolysis的物理必然
==============================================================

3.1 为什么Cancer Cell要"浪费"葡萄糖?
--------------------------------------------------------------
    Oxidative Phosphorylation: 1 葡萄糖 → 36 ATP (需要 O₂ + Mitochondria)
    有氧Glycolysis: 1 葡萄糖 → 2 ATP (不需要 O₂)

    → 看似"愚蠢", 实则精明:
    · 肿瘤核心缺氧 → 无法Oxidative Phosphorylation
    · Glycolysis提供生物合成前体 (核糖、氨基酸、脂质)
    · 快速增殖需要"建筑材料", 不只是 ATP

3.2 葡萄糖扩散 — 另一个天花板
--------------------------------------------------------------
    葡萄糖扩散系数 ≈ 5×10⁻¹⁰ m²/s (组织)
    消耗率 ≈ 0.1 mol/m³/s

    R_max_glucose ≈ √(4×5×10⁻¹⁰×(5−0.5)/0.1) ≈ 3×10⁻⁴ m ≈ 300 μm

    ⚫ 葡萄糖的扩散极限与氧相似 (~200-300 μm)
    ⚫ 肿瘤必须"疯狂吃糖" → 但糖也靠扩散 → 双重天花板
    ⚫ 这就是为什么 FDG-PET 成像能看到肿瘤 —
      它们被困在扩散范围内, 不得不高表达 GLUT1 转运体
