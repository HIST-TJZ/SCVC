§2. Clausius-Clapeyron — 大气能"装"多少水
--------------------------------------------------------------------

  SCVCDerivation汽化潜热L_v:
    H₂O在液态中平均 ~3.5 个H键/分子
    每个H键≈0.20 eV
    但汽化不完全断开所有H键（蒸汽分子无H键）+ 对抗大气做功
    → L_v ≈ 0.42 eV/分子 ≈ 2.25×10⁶ J/kg（与实测2.5×10⁶一致）

  Clausius-Clapeyron:
    de_s/dT = L_v × e_s / (R_v × T²)
    R_v = 461.5 J/(kg·K)

    饱和水汽压(近似):
    e_s(T) ≈ 6.11 × exp[ L_v/R_v × (1/273 - 1/T) ] hPa
         ≈ 6.11 × exp[ 5419 × (1/273 - 1/T) ]

  ┌──────────┬──────────┬──────────────┬────────────┐
  │ 温度      │ e_s (hPa) │ ρ_v (g/m³)   │ 相对20°C    │
  ├──────────┼──────────┼──────────────┼────────────┤
  │ 20°C     │ 23.4     │ 17.3         │ 基准        │
  │ 25°C     │ 31.7     │ 23.0         │ +33%       │
  │ 30°C     │ 42.4     │ 30.4         │ +76%       │
  │ 35°C     │ 56.2     │ 39.6         │ +129%      │
  │ 40°C     │ 73.8     │ 51.1         │ +195%      │
  │ 45°C     │ 95.9     │ 65.4         │ +278%      │
  │ 50°C     │ 123.4    │ 82.8         │ +379%      │
  └──────────┴──────────┴──────────────┴────────────┘

  SCVC灵敏度: Δe_s/e_s ≈ (L_v/R_v)/T² × ΔT = 5419/T² × ΔT
    在 300K: 5419/90000 ≈ 6.0%/K
    在 308K: 5419/94864 ≈ 5.7%/K
    → **经典的 ~6-7%/K（Clausius-Clapeyron标度律）**

§3. 大气可降水量PW — 最大水汽柱
--------------------------------------------------------------------

  PW = ∫₀^∞ ρ_v(z) dz

  极端热带气团（完全饱和, SST≈35°C）:
    PW ≈ ρ_v_surface × H_scale × shape_factor
    ρ_v_surface(35°C) ≈ 0.040 kg/m³
    H_scale ≈ 2.5-3 km（水汽标高, 由温度递减率决定）
    shape_factor ≈ 0.7（水汽随高度指数衰减）
    → PW_max ≈ 0.040 × 2700 × 0.7 ≈ 76 kg/m² = **76 mm**

  实测记录:
    热带海洋:      50-65 mm（常规）
    极端热带气团:  70-82 mm（飓风眼壁环境）
    理论饱和35°C:  ~80-85 mm

  SCVC天花板PW: **~85-100 mm**
  （需要整个对流层在极端SST下完全饱和 → 接近物理极限）

§4. 上升气流速度 — CAPE的SCVCUpper Limit
--------------------------------------------------------------------

  CAPE ≈ g × ∫ (T_parcel - T_env)/T_env dz

  CAPE决定了上升气流的动能:
    w_max = √(2 × CAPE)

  CAPE的SCVC限制:
    ΔT_max = SST_max - T_tropopause_min
    地球: SST_max ≈ 35°C = 308K, T_trop_min ≈ -80°C = 193K
    ΔT_max ≈ 115K

    湿绝热递减率由L_v设定:
    Γ_m ≈ g/c_p × (1 + L_v×q_s/(R_d×T))⁻¹
    L_v越大 → Γ_m越小 → 更大的CAPE（气块保持更热更久）

  │ 环境                  │ CAPE (J/kg)│ w_max (m/s)     │
  ├──────────────────────┼──────────┼──────────────────┤
  │ 普通雷暴              │ 1000-2000│ 45-63            │
  │ 强雷暴                │ 3000-5000│ 77-100           │
  │ 极端超级单体          │ 6000-8000│ 110-126          │
  │ SCVC理论最大(地球)    │ ~10000   │ ~141             │
  │ 声速极限(绝对)        │ —        │ ~340             │
  └──────────────────────┴──────────┴──────────────────┘

  但上升气流不是全部用于降雨——上升核心宽度有限。
  有效上升气流（在降雨柱内）: w_eff ≈ 20-50 m/s

§5. 冲洗速率 — 从水汽到雨滴的转换时间
--------------------------------------------------------------------

  水汽在上升气流中凝结 → 云滴 → 碰并 → 雨滴 → 下落。

  碰并效率: 
    云滴 ~10-50 μm, 雨滴 ~1-5 mm
    碰并由差速沉降驱动 → 大滴落得快, "收集"小滴
    收集效率 ∝ (R_big/(R_big+R_small))²（流体力学碰撞截面）

  在强对流中, 水滴碰并时间:
    τ_coalesce ≈ v_t / (g × LWC × E_coll / ρ_water)
    LWC(极端) ≈ 5-10 g/m³ → τ_coalesce ≈ 100-500 s

  下落时间:
    τ_fall ≈ H_cloud / v_t_rain
    H_cloud ≈ 3-6 km（降雨云底高度）
    v_t ≈ 7-9 m/s（大雨滴）
    τ_fall ≈ 4000/8 ≈ 500 s

  总冲洗时间: τ_residence ≈ τ_coalesce + τ_fall ≈ **600-1000 s**

§7. 为什么不更高？三重天花板交锁
--------------------------------------------------------------------

  【天花板1: 水汽供应 — PW≈100mm】
    即使大气在40°C完全饱和, 柱水汽量不超过~100mm。
    超过→需要更暖的海洋→但海洋SST受蒸发冷却限制在~35°C。

  【天花板2: 冲洗速度 — v_t≈9m/s】
    大雨滴终端速度~9m/s。更大→韦伯数>10→碎裂。
    碎裂后表面积↑→蒸发↑→反而降低净降水效率。
    SCVC: 表面张力72.8mN/m Locked-In了最大稳定雨滴尺寸。

  【天花板3: 降水效率 — ε<100%】
    部分凝结水被云砧带走（高空冰晶→蒸发）。
    部分在落到地面前蒸发（雨幕下的不饱和空气）。
    极端对流中ε≈50-70%, 不可能100%。

  三重Locked-In交汇: **~700-800 mm/h**
