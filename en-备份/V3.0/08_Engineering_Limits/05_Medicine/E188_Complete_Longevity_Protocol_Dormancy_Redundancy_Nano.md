§3. 第二层：酮体Metabolism替代葡萄糖
====================================================================

【为什么换燃料】

  传统Metabolism：
    葡萄糖 → Glycolysis + Oxidative Phosphorylation → ATP + ROS + AGEs
    → ROS 损伤 mtDNA → Mitochondria衰变
    → AGEs 在血管、皮肤、晶状体累积 → 不可逆的老化

  酮体Metabolism：
    酮体（β-羟基丁酸）→ 直接进呼吸链 → ATP + 少得多的 ROS
    → 没有糖 → 没有糖化反应 → AGEs 形成速率趋近于零
    → 不是"延缓"AGEs → 是从源头切断

【DormancyStatus的操作】

  ┌──────────────────┬──────────────────────────────────────┐
  │ 组件             │ 功能                                 │
  ├──────────────────┼──────────────────────────────────────┤
  │ 外部循环系统     │ 替代心脏 + 血液 → 送酮体 + O₂       │
  │ 酮体供应         │ 替代葡萄糖 → Mitochondria直接利用           │
  │ 微透析废物清除  │ 带走Metabolism废物（替代肾脏）              │
  │ 外部免疫哨兵     │ 工程免疫细胞巡逻 → 替代衰退的Immune System │
  └──────────────────┴──────────────────────────────────────┘

  ⚫ 细胞在低MetabolismDormancyStatus：不分裂 → 复制错误 ≈ 零。
  ⚫ Mitochondria照常工作——只是换了一种更干净的燃料。
  ⚫ 自发脱嘌呤仍在（热驱动，不可消除）→ 但修复Enzyme有 ATP 供应。

§4. 第三层：Nanorobot维护Neuron
====================================================================

  Neuron是唯一"不能换"的细胞类型。其他组织可由Stem Cell替换。
  因此Neuron是Lifespan的最终瓶颈。

【Neuron累积的垃圾】

  ┌──────────────────┬────────────────────────────────────┐
  │ 垃圾类型         │ 来源                               │
  ├──────────────────┼────────────────────────────────────┤
  │ 脂褐素           │ Autophagy最终残渣 → 溶Enzyme体消化不掉       │
  │ tau/α-Synapse核蛋白 │ 蛋白错误折叠 → 聚集 → Fibrosis        │
  │ Necrosis的Mitochondria     │ mtDNA 被 ROS 损伤 → 呼吸链崩溃      │
  │ Axon运输堵塞     │ 蛋白聚集堵在微管"高速公路"上        │
  └──────────────────┴────────────────────────────────────┘

  分裂性细胞：积累 → 分裂稀释 → 坏了 → Stem Cell替换 → 账本可清
  Neuron：    积累 → 堆着 → 80 年后脂褐素占 30% 体积 → 死亡

【Nanorobot的物理可行性（SCVC 判定）】

  ┌──────────────────┬────────────────────────────────────┐
  │ 约束             │ SCVC 判定                           │
  ├──────────────────┼────────────────────────────────────┤
  │ 最小尺寸         │ Enzyme ~3-5 nm → Nanorobot ~10-50 nm  │
  │                  │ → 物理上允许 ✅                     │
  │ 识别垃圾         │ 脂褐素/蛋白聚集有特定化学表面       │
  │                  │ → H 键+疏水识别 ← α → 可设计 ✅     │
  │ 动力来源         │ 胞内 ATP（Mitochondria不停产）→ 捕获      │
  │                  │ → 不需要外部供能 ✅                 │
  │ 单Neuron可容纳   │ 胞质 ~10⁴ μm³ → 可容 10¹⁰ 个 ✅     │
  └──────────────────┴────────────────────────────────────┘

【分工：细胞 vs Nanorobot】

  细胞自己的活（进化 20 亿年，极高效率 — 不碰）：
    ├─ Mitochondria产 ATP（酮体→呼吸链）
    ├─ DNA 修复（BER/NER 通路）
    ├─ Protein合成、折叠、运输
    └─ 维持膜电位、Synapse传递

  Nanorobot的活（细胞进化没准备 — 因为原本活不到 80 岁）：
    ├─ 清除脂褐素（识别 → 包裹 → Enzyme解 → 排出）
    ├─ 分解蛋白聚集（tau/Aβ/α-syn 纤维）
    ├─ 修复坏Mitochondria（递 mtDNA + 修复Enzyme）
    └─ 疏通Axon堵塞（微管垃圾清走）

  ⚫ Nanorobot不在"替代"任何东西 — 在补充进化缺失的维护功能。
