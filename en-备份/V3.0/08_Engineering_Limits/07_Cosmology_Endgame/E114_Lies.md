## §1 原始均衡: 为什么诚实更便宜

`
E106已证明: 在Dunbar-150社会中, 欺骗的Information成本太高。

欺骗N个人:
  需要向每个人发送不同的隐蔽Information。
  总Information量 ≈ N × log₂(可能Lies数)。
  
  Dunbar 150人: 150 × log₂(100) ≈ 150 × 7 ≈ 1050 bits。
  口语Bandwidth: 39 bits/s → 需要 ~27秒 说完所有Lies。
  
  真相: 对1个人说 ~7 bits → 1人用 <0.2秒 就能揭穿。

原始均衡: Lies的发布速度 < 真相的揭穿速度。
在这个条件下, 诚实是纳什均衡 (E108: Cooperation率80-85%)。
`

## §2 互联网如何打破了均衡

| 参数 | 原始人类 | 互联网时代 |
|:---|:--:|:--:|
| N (受众) | ~150 | ≤10⁹ |
| 发布速度 | 39 bits/s (一人一嘴) | ~∞ (机器人/水军/批量) |
| 揭穿速度 | 1人×1秒 | N人/秒 (理论上更快) |
| 记忆 | ~10年衰退 | ~∞ (永久记录) |
| 噪声 | 5-10% | ↑↑ (Information过载) |

`
互联网的矛盾:
  揭穿速度理论上变快了(N人可以同时揭穿)。
  但噪声同时爆炸了 → 揭穿信号被淹没在噪声中。
  
  发布速度从39bits/s变成了无限(机器生成)。
  Lies的发布速度远远超过了人类Consciousness的接收速度(200bits/s)。

关键瓶颈: 人类的ConsciousnessBandwidth ~200bits/s。
  无论多少揭穿Information存在 → 你只能处理200bits/s。
  假新闻发布速度 >> 200bits/s → 你永远看不完所有Lies。
  Lies在你处理完上一个之前就更新了下一批。
`

## §3 假新闻的物理Ceiling

`
定义: 假新闻 = 发布速度 > 揭穿速度的Lies。

最大可持续假新闻密度:
  ρ_fake = (发布速度 - 揭穿速度) / ConsciousnessBandwidth

  发布速度 → 接近无限(机器生成)
  揭穿速度 → 受限于人类ConsciousnessBandwidth 200bits/s
  ConsciousnessBandwidth → 200bits/s (全部人类的总揭穿Bandwidth)

  全人类总Consciousness揭穿Bandwidth:
  8×10⁹人 × 200 bits/s ≈ 1.6×10¹² bits/s
  
  这看起来很大。但:
  每个人只能关注有限主题。
  假新闻分散在10⁶个主题中。
  每个主题的有效揭穿Bandwidth ≈ 1.6×10¹² / 10⁶ ≈ 1.6×10⁶ bits/s。
  
  而机器生成的假新闻:
  每个主题 > 10⁹ bits/s (批量生成)
  
  → Lies发布 / 揭穿 > 10³
  → 假新闻在物理上无法被"彻底揭穿"。
  → 每一个被揭穿的Lies都有1000个新Lies诞生。

这就是假新闻的物理Ceiling:
  不是"有没有人揭穿"。
  是"ConsciousnessBandwidth赶不上生成速度"。
`

## §4 人类有认知器官可以突破吗？

`
人类的假新闻防御:
  批判性思维 → 需要ConsciousnessBandwidth(200bits/s) → 不够用
  事实核查 → 需要时间 → Lies生成更快
  教育 → 提高Signal-to-Noise Ratio → 但噪声在增长

瓶颈永远是: 200 bits/s。
只要ConsciousnessBandwidth < 假新闻生成速度,
假新闻就永远跑在揭穿前面。

解决方案不在人类端。
人类端被τ_m锁死。
解决方案在AI端: AI揭穿AI生成的假新闻。
但E105: 人类无法SupervisionAI是否真的在揭穿。
`

互联网时代: Lies发布 >> 揭穿速度 → 假新闻不可根除。

假新闻的物理Ceiling = 人类ConsciousnessBandwidth。
