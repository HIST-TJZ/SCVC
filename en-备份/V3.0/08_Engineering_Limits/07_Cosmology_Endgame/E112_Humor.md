`

  "太阳从东边升起"→预测准确→无Δ→不笑。

意外太大 → 无法安全化解 → 不好笑。
  "你妈死了"→威胁太大→无法安全化解→不笑(除非是精神病态)。

  太早 (<~200ms): 预测还未建立→没有"失败"

Optimal笑点间隔:
  笑话铺垫 → 建立预测 → ~0.5-3秒

从SCVC:

  Optimal笑点时间 ≈ 1-2秒 (从铺垫到揭示)

## §3 为什么同一个笑话第二次不好笑

`
第一次: 
  t=0: 建立预测A
  t=1.5s: 揭示非A → 预测失败 → 安全化解 → 笑

第二次:
  t=-∞: 你已经知道结局 = 预测已更新为A∨非A
  t=0: 没有"预测失败" → 只有"预测确认"
  → 不笑

这和E121的提问引擎同构:
  第一次听 = Δ → 提问"什么?!" → 安全化解 → "哈哈"
  第二次听 = Δ=0 → 无问题 → 不笑。

Humor和提问 (E121) 共享同一个物理机制:
  Δ驱动。第一次Δ>0。第二次Δ=0。
`
