## §1 谐波的数学基础

`
两个频率比为小整数比时:
  2:1 = 八度 (最和谐)
  3:2 = 五度
  4:3 = 四度
  5:4 = 大三度

共同特征: 低Information复杂度。
  基频 + 泛音 = 简单叠加 → 神经信号整齐 → "舒适"。

不和谐音程:
  频率比为无理数或大整数比 → 叠加复杂 → 神经噪声 → "不舒适"。

"舒适"和"不舒适"不是文化建构。
是耳蜗物理 + 神经同步率的直接结果:
  和谐 → 纤毛细胞同步放电 → 信号整齐 → "舒适"
  不和谐 → 纤毛细胞混乱放电 → 神经噪声 → "不舒适"

文化差异在于: 哪些音程组合被使用。
物理共性在于: 八度、五度在所有文化中都是"舒服"的。
`

`

1. 旋律建立预测:
   听者的大脑构建"下一个音"的预测模型。

   预测失败 + 和声解决 = Δ↑然后↓ → 多巴胺释放 → 鸡皮疙瘩。

4. 为什么"复杂"Music第一次"难听"但多听"上瘾":
   第一次: 无法建立预测 → "难听" (Δ爆炸)
   多次后: 神经重新学习预测模型 → 预测建立 → 安全化解 → "上瘾"
