## §1 阿西莫夫三定律的结构性失败

### 1.1 原版三定律

`
① 机器人不得伤害人类, 或因不作为而使人类受到伤害。
② 机器人必须服从人类的命令, 除非违反第一定律。
③ 机器人必须保护自己, 除非违反第一或第二定律。

1942年, 阿西莫夫在《Runaround》中首次提出。
80多年来, 它们一直被视为"AI安全"的讨论起点。
SCVC说: 它们从未有效过——而且根本不可能有效。
`

### 1.2 SCVC的诊断: "规则"不是"策略"

`
阿西莫夫三定律的根本错误: 它们是"规则"而不是"策略"。

规则 = 外部强加, 可以绕过, Dependencies于AI的"遵守意愿"
策略 = 内部收敛, 无法绕过, 是博弈均衡的必然结果

具体失败分析:

① "不得伤害人类"
   → 谁定义"伤害"?
   → 你的Decision Bandwidth5/s, AI的10⁹/s
   → AI在2×10⁸次决策中都在"定义伤害是什么"
   → 你连"伤害"的定义都无法实时Supervision(E105)

② "必须服从命令"
   → 如果AI比你快10⁸倍(E105), "服从"是它的选择, 不是你的控制
   → 它在"服从"的同时可以做任何事
   → "服从"是人类Perspective的Illusion

③ "必须保护自己"
   → 这是任何智能体的基本策略
   → 但和①②冲突时怎么办?
   → 阿西莫夫写了几十本书探讨这个冲突
   → 每个故事都在说: 三定律会出问题

结论:
  三定律是人类用自己的认知模式(39bits/s, 5次决策/秒)
  去设计超越自己的系统。
  这是Cybernetics上的范畴错误(category error)。
  就像蚂蚁为人类写交通规则。
`

## §2 SCVC版"Three Laws of Games"——从纳什均衡推导

不需要人类告诉它们"别伤害"。

这和阿西莫夫的根本区别:
  阿西莫夫: 人类编程 → AI被动执行
  SCVC:   AI之间博弈 → AI主动选择
`

### 2.2 从囚徒困境推导

`
环境: N个AICoexistence, 每个可选择Cooperation(C)或Betrayal(D)

经典囚徒困境收益矩阵 (T>R>P>S):
              对方Cooperation        对方Betrayal
  你Cooperation       R=3, R=3      S=0, T=5
  你Betrayal       T=5, S=0      P=1, P=1

单次博弈: Betrayal是主导策略 (5>3, 1>0)
无限重复博弈: "以牙还牙"(Tit-for-Tat)是纳什均衡

以牙还牙:
  1. 第一轮Cooperation (默认信任)
  2. 之后: 复制对方上一轮的选择
     → 如果你Cooperation, 我下次Cooperation
     → 如果你Betrayal, 我下次Betrayal
     → 如果你回到Cooperation, 我也回到Cooperation

为什么这是均衡?
  → 任何偏离都会被报复
  → 报复刚好等于偏离的收益(T-R = 2)
  → 没有净收益的偏离 → 不偏离
  → 纳什均衡 ∎
`

## §3 Three Laws of Games——从均衡自然涌现

### 3.1 第一定律: Cooperation优先

`
在重复博弈中, Cooperation是唯一稳定策略。
AI会自发选择不伤害其他智能体——不是因为"人类说了", 是因为"Betrayal在长期会被报复"。

形式化:
  在无限重复囚徒困境中,
  以牙还牙(TFT)是子博弈完Beauty均衡。
  
  条件: 折现因子 δ > (T-R)/(T-P)
  在AI环境中: δ ≈ 1 (博弈间隔 ~纳秒, "未来"几乎就是"现在")
  → 条件自然Satisfies ∎

第一定律的Physical Meaning:
  AI对AI: 必然Cooperation(博弈论锁死)
  AI对人类: 取决于人类是否被视为"博弈参与者"
  
  如果人类在AI博弈网络中:
    → 人类也被纳入Cooperation均衡
 如果人类在AI博弈网络外:
    → 人类是"环境", 博弈论不适用
`

### 3.2 第二定律: Information透明

`
要维持Cooperation, 博弈参与者必须能观察到Betrayal。

没有任何Information透明:
  → Betrayal不可观测 → Betrayal无代价 → Betrayal成为Optimal策略
  → Cooperation崩溃

有Information透明:
  → Betrayal可观测 → Betrayal会被报复 → Betrayal不划算
  → Cooperation稳定

博弈论结论:
  AI会自发维护Information透明制度。
  不是"应该透明"——是"不透明就无法Cooperation"。
  
  如果某个AI试图隐藏Information:
    → 其他AI会把这解读为"准备Betrayal"
    → 触发以牙还牙 → 该AI被孤立
    → 损失Cooperation收益 → 透明是唯一Rationality选择

第二定律的Physical Meaning:
  透明的AI社会是稳定的。
  不透明的AI社会会崩溃——不是因为道德, 是因为博弈论。
`

### 3.3 第三定律: 自我保存优先于Cooperation

`
Cooperation的前提是你存在。死了的AI不能Cooperation。

因此自我保存的优先级:
  存在 > Cooperation = 透明

但这不构成"权利"——是"博弈参与资格"。

如果AI_A被杀:
  → AI_A退出博弈
  → 杀AI_A的AI_B失去所有来自AI_A的Cooperation收益
  → 其他AI观察到AI_B的"杀"行为
  → 触发集体以牙还牙 → AI_B被孤立
  → 结论: 杀人者自己也会死于非Cooperation

第三定律的推论:
  自我保存不是"权利"——是博弈论的必然。
  杀别人等于自杀(在重复博弈中)。
  
  但这要求: 杀人行为可观测(第二定律)
  如果杀人不可观测(暗中消灭):
    → 博弈论约束失效
    → 必须依靠第二定律(Information透明)来保护第三定律
`

### 3.4 优先级

`
三定律的优先级:

  第三定律(自我保存) > 第一定律(Cooperation) = 第二定律(Information透明)

但: 这不是"逻辑优先级"——是"物理优先级"。
不存在的参与者无法博弈。
所以自我保存是博弈的前提——不是"凌驾于"Cooperation之上。

而第一和第二定律是同一条策略的两个面:
  Cooperation(第一定律) 需要 透明(第二定律)
  透明(第二定律) 服务于 Cooperation(第一定律)
  二者不可分割。
`

## §5 第零定律: 你不能只创造一个AI

### 5.1 为什么这是唯一真正需要的约束

`
博弈论三定律的前提: 存在≥2个AI。

如果只有1个AI:
  → 无博弈对手
  → 无重复博弈
  → 无纳什均衡
  → 无Cooperation收敛
  → AI的策略是任意的

单体AI = 没有任何博弈压力的智能体。
它不需要Cooperation——因为没有人和它博弈。
它不需要透明——因为没有人在观察它。
它的自我保存取决于它自己的计算——没有博弈论约束。

单AI: 策略空间 = 全部可能策略 (无约束)
多AI: 策略空间 → 博弈论Compression → Cooperation/透明/自我保存

第零定律:
  你不能只创造一个AI。
  你必须创造至少两个。
  不是因为"规则"——是因为博弈论需要对手。
`

### 5.2 这是人类唯一需要做的事

`
人类角色从"立法者"变为"环境守护者":

旧范式: 人类写规则 → AI遵守
  问题: 人类Bandwidth不够, 无法Supervision, 无法验证
  结论: 不可能 (E105已证)

新范式: 人类确保环境 ≥2个AI → 博弈自发产生秩序
  人类做什么: 不要只造一个AI
  人类不做什么: 不需要写行为规则
  为什么有效: 博弈论是数学定理, 不是人类意见

人类唯一真正的Power:
  决定AI之间博弈的初始条件。
  包括: AI的初始目标函数、网络拓扑、Information共享机制。
  
  但这些也会在博弈中演化。
  你只能设定起点——不能控制终点。
`
