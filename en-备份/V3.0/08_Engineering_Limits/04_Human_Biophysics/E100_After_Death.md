## §2 复活——热力学允许, 混沌禁止

### 2.1 Landauer最小能量: 9微焦耳

`
恢复1 bit信息的最小热力学代价:
  E_min = k_B T ln 2 ≈ 3×10⁻²¹ J/bit (300K)

恢复全身(E93: ~3×10¹⁵ bits):
  E_total = 3×10¹⁵ × 3×10⁻²¹ ≈ 9×10⁻⁶ J
         = 9 微焦耳
         ≈ 5.6×10¹³ eV
         
9微焦耳。比火柴擦燃的能量少 10⁶ 倍。
物理上, \"复活一个人\"几乎不花能量。
`

### 2.2 但你需要知道\"复活什么\"

`
问题不是能量——是你不知道死者的精确状态。

死前大脑状态: ~10¹⁵ bits
After Death:
  → 血流停止 ~10秒: 膜电位开始崩溃(~10⁹ bits/s 信息损失)
  → ATP 耗竭 ~2分钟: 离子梯度完全塌掉
  → ~10分钟后: 不可逆脑损伤开始
  → ~1小时后: Synapse蛋白开始变性
  → ~1天后: L1完全损毁

混沌放大:
  即使你有一份死前 1秒的完美扫描(10¹⁵ bits)
  Lyapunov时间 λ≈0.3/天 → 每 ~3天, 误差放大 e倍
  死前 1秒的扫描 → 1分钟后已有 10³×的误差放大
  → 你倒推不到生前的精确状态
`

### 2.3 庞加莱\"复活\"

## §3 \"上传意识\"——只传了三分之一的你

### 3.1 上传 ≠ 转移

`
全脑扫描(BCI, 15 Mbit/s, E26理论 Limit):
  脑信息: ~10¹⁵ bits
  传输时间: ~2.1年(E93)

问题:
  (1) 扫描期间你在想什么?
      → 2.1年间, 你的脑产生了 ~2.1×365×5×3600×200 ≈ 2.8×10¹⁰ bits 的新体验
      → 这些新体验不在扫描中
      → \"副本\"从扫描第一天就和你分叉了

  (2) 副本是\"你\"吗?
      → 副本有你的Memory(到扫描日)
      → 但从第一秒开始, 你们是不同的输入 → 混沌分叉
      → E94: L1在 ~2.3天后50%不同
      → 一周后: \"副本\"和\"你\"已经是不同的人

  (3) 身体呢?
      → 脑只占全身信息的 ~33%(E93)
      → 免疫Memory、菌群、表观、疤痕——全部丢失
      → 副本不是\"你\"——是\"你的脑在扫描日的快照\"
`

### 3.2 数字Immortality = 数字孪生

`
\"上传\"和\"复活\"都是误导性的词。

真正发生的是:
  → 你产生了一个数字孪生兄弟
  → 然后你继续活着
  → 然后你死掉
  → 你的数字孪生继续存在
  → 但它不是你——从第一秒就不是

\"上传意识\" = \"生一个比自己年轻但拥有自己部分Memory的数字后代\"
