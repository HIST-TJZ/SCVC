> 所有Derivation基于SCVC速查表的常数（从π多项式导出，零自由参数）。
> 高能Laser的大气传输由极化率（α→Refractive Index）、电离能（α→击穿）、衍射（ℏ→λ）共同锁定。

## §1. 大气热晕（Thermal Blooming）

### 1.1 物理Mechanism

高能Laser通过大气时，少量被吸收 → 空气局部加热 → Density降低 → Refractive Index下降 → 形成负透镜使光束扩散。这是**高能Laser大气传输的头号限制**。

```
Refractive Index变化: Δn = (dn/dT) × ΔT
温度升高:   ΔT = α_abs × I × t / (ρ × c_p)
相位畸变:   Δφ = (2π/λ) × ∫ Δn dz
```

### 1.2 临界Power

当热畸变相位达到 ~π 时（光束严重扩散），临界Power为：

```
P_crit = (λ × ρ × c_p × v_wind × D) / (2 × |dn/dT| × α_abs × R)

λ: Wavelength
ρ: 空气Density (1.225 kg/m³ 海平面)
c_p: 比热 (1005 J/kg·K)
v_wind: 横向风速
D: 发射口径
dn/dT: 空气热光系数 (~-1×10⁻⁶ K⁻¹)
α_abs: 大气吸收系数
R: 传输距离
```

**SCVC连接：** dn/dT ∝ (n-1)/T，而 n-1 ∝ N × α_pol（分子数Density × 极化率）。分子极化率由 α（精细结构常数）决定——α控制Electronics云的"柔软度"，从而控制外场下的感生偶极矩。**因此热光系数从αDerivation。**

### 1.3 各种LaserWavelength的热晕临界Power

**条件：D=1 m, 风速=5 m/s, R=10 km, 海平面**

| Laser类型 | λ (μm) | α_abs (/km) | P_crit (kW) | 
|----------|--------|-------------|-------------|
| Nd:YAG (固态) | 1.064 | 0.02 | **16** |
| COIL (化学氧碘) | 1.315 | 0.03 | **14** |
| DF (氟化氘) | 3.8 | 0.01 | **117** |
| CO₂ (气体) | 10.6 | 0.15 | **22** |

> **DFLaser(3.8 μm)有最高临界Power**——因为其Wavelength在大气窗口且吸收极低。CO₂虽是大气窗口但10.6 μm处仍有不少H₂O和CO₂吸收。

**海拔/平台效应：**

| 条件 | 1.064 μm P_crit | 提升因子 |
|------|----------------|---------|
| 海平面, 5 m/s风 | 16 kW | 1× |
| 5 kmHeight (ρ=60%, α=30%) | 33 kW | 2× |
| 机载+50 m/s扫描 | 164 kW | 10× |
| 高空+快速扫描 | **~500 kW** | **~30×** |

**口径缩放（Bradley-Hermann完整模型）：**

```
简化为单风速模型:  P_crit ∝ D
完整B-H模型:       P_crit ∝ D³/R²

D=0.3 m: P_crit ≈ 0.5 kW
D=1.0 m: P_crit ≈ 16 kW
D=1.5 m: P_crit ≈ 55 kW (实际 ~55 kW, 因为D³缩放)
D=3.0 m: P_crit ≈ 440 kW
```

**注：** B-H模型的D³缩放意味着**大口径是克服热晕的最强力手段**——比增加风速更有效。

### 1.4 克服热晕的策略

| 策略 | 效果 | SCVC约束 |
|------|------|----------|
| 大口径 | ∝ D³ | 制造/成本限制 |

**SCVC核心Conclusion：** 热晕是SCVC锁定的物理现象——空气的热光系数和吸收谱线由分子能级（来自α和m_e）决定。**无法消除，只能规避。**

## §2. 大气击穿

### 2.1 击穿Mechanism

**清洁空气击穿（光频）：**

```
E_bd(optical) ≈ 3×10⁹ V/m  (比DC Paschen击穿3×10⁶ V/m高1000倍)

原因: Optics频率下，Electronics在半个周期内获得的能量:
  ΔE ≈ (e²E²)/(2m_e ω²) < 电离能  → 需要更高Field Strength

I_bd_clean = ε₀c E²/2 ≈ 1.2×10¹⁶ W/m² ≈ 1.2×10¹² W/cm²
```

对于 D=1 m 口径：P_bd_clean ≈ **9,000 GW** → 远超热晕限制。**清洁空气击穿不是实际限制。**

**含气溶胶空气击穿（实际限制）：**

灰尘/气溶胶颗粒吸收Laser → 局部加热 → Thermoelectric子发射 → 级联电离：

```
I_bd_aerosol ≈ 10⁶-10⁸ W/cm² (取决于颗粒大小和Density)

D=1 m: P_bd_aerosol ≈ 8-800 MW
```

### 2.2 SCVC连接：多Photon电离

```
N₂ 电离能: 15.6 eV, O₂: 12.1 eV
Ry = α²m_e c²/2 = 13.606 eV (SCVC速查表)

1.064 μm Photon能量: hc/λ = 1.165 eV
需要Photon数(MPI): ⌈15.6/1.165⌉ = 14 Photon (N₂)
                 ⌈12.1/1.165⌉ = 11 Photon (O₂)

MPI速率 ∝ I^N → 极其陡峭的阈值
```

SCVC锁定了电离能（来自Ry），因此**击穿阈值的Order of Magnitude由α决定，不可改变**。

### 2.3 热晕 vs 击穿 —— 谁是真正瓶颈？

| 限制 | 典型阈值(1m,1μm) | 瓶颈？ |
|------|-----------------|--------|
| 热晕 (10 km) | **~16 kW** | 🔴 **主要瓶颈** |
| 受激拉曼散射(SRS) | ~100 kW-1 MW | 🟡 次要不稳定 |
| 气溶胶击穿 | ~8 MW | 🟢 CWLaser不触及 |
| 清洁空气击穿 | ~9,000 GW | 🟢 永远不触及 |

**Conclusion：大气传输中，热晕是压倒性的瓶颈。** 击穿从来不是限制——不等Laser强到击穿，热晕早已让光束散到无用了。

## §3. 自适应Optics的物理Limit

### 3.1 大气湍流参数

**Fried参数 r₀（大气相干长度）：**

```
r₀ = [0.423 × (2π/λ)² × sec(ζ) × ∫ C_n²(h) dh]^(-3/5)

可见光(0.5 μm)好站址: r₀ ≈ 15 cm
r₀ ∝ λ^(6/5)
```

| Wavelength | r₀ (好站址) | r₀ (一般站址) | D=1m所需促动器数 |
|------|-----------|-------------|-----------------|
| 1.064 μm | **37 cm** | 12 cm | 7-65 |
| 1.315 μm | **48 cm** | 16 cm | 4-39 |
| 3.8 μm | **171 cm** | 57 cm | 0-3 |
| 10.6 μm | **586 cm** | 195 cm | 0-0 |

> 促动器数 ≈ (D/r₀)²。r₀>D时无需AO（Diffraction Limit已天然达到）——长波红外Laser的天然优势。

**Greenwood频率（湍流Bandwidth）：**

```
f_G = 0.43 × v_wind / r₀

1.064 μm: f_G ≈ 12 Hz → 需要 ~120 Hz 控制Bandwidth
3.8 μm:   f_G ≈ 3 Hz  → 需要 ~30 Hz 控制Bandwidth
```

当前AO系统（>1 kHz）远超需求。**控制Bandwidth不是瓶颈。**

### 3.2 Strehl比的物理Limit

```
S = exp(-σ²_total)

σ²_total = σ²_fitting + σ²_bandwidth + σ²_scintillation + σ²_anisoplanatic + σ²_NCPA
```

| Error源 | σ² (典型) | 能否消除？ |
|--------|----------|-----------|
| 拟合Error(DM促动器间距有限) | 0.003 | 增加促动器数→成本↑ |
| BandwidthError | 0.0005 | 加速控制回路 |
| 闪烁(振幅起伏) | 0.01-0.05 | 需第二个DM(woofer-tweeter) |
| 非等晕性(视场外) | 0.01-0.03 | 多导星+层析 |
| 非共路Error(NCPA) | 0.005-0.02 | 精密校准 |

**理论StrehlUpper Limit：~0.98。** 实验室最好：~0.95。天文实测最好：~0.8-0.9。

**SCVC不直接约束AO性能**——湍流是大气动力学现象，不受SCVC常数限制。但湍流的最小尺度（Kolmogorov内尺度 l₀ ~1-10 mm）受空气分子平均自由程约束，而后者由分子碰撞截面（来自α）决定 → **极间接的SCVC约束**。

### 3.3 AO对高能Laser的特殊挑战

高能Laser的AO与天文AO不同：

| 挑战 | 天文AO | 高能LaserAO |
|------|--------|-----------|
| 信标 | 自然导星/Laser导星 | **目标反射**(可能很弱) |
| 热负载 | 忽略 | **镜面加热→形变** |
| 非 reciprocity | 无 | **有**(热晕致非互易) |
| Power处理 | mW | **kW-MW** |

**热晕修正的问题：** 热晕是**Nonlinear+非互易**的 → 你不能简单地用相位共轭修正热晕（因为相位畸变依赖于Strength，而形成共轭波的探测光与高能主光束经历不同的热环境）。

**SCVCConclusion：** 热晕是AO的"克星"——它既限制了可传输Power，又不完全服从AO修正。**大口径+高空平台是唯一有效的热晕对抗措施。**

## §5. 工程Conclusion

### 5.1 定向能武器的有效射程

```
地对空（海平面, 热晕限制）:
  100 kW级: ~5-15 km (反无人机/Rocket弹)
  300 kW级: ~10-30 km
  1 MW级:   ~20-50 km (反巡航导弹)
  
机载（高空, 热晕缓解）:
  100 kW级: ~20-50 km
  1 MW级:   ~50-150 km
  
天基（Vacuum, 仅衍射限制）:
  1 MW, D=3 m, λ=1 μm:
    1000 km: I ≈ 200 W/cm² → 加热破坏(分钟级)
    2000 km: I ≈ 50 W/cm²  → 缓慢加热
```

**口径是最关键的参数：** 远场Strength ∝ D⁴/R²（P ∝ D² × 衍射 ∝ D²）。

**SCVC锁定的终Limit制：** Diffraction Limit（λ/D）是SCVC波形Optics的基本Result——ℏ出现在Photon动量中。Wavelength由Laser介质能级决定（来自α和m_e）。**更短的Wavelength → 更好的衍射 → 但大气传输更差。** 最优Wavelength在1-2 μm（大气窗口+衍射合理）。

### 5.2 空间碎片Laser清除

对于近地轨道碎片（~400-1000 km），Laser烧蚀产生Thrust：

```
所需Strength: 10⁷-10⁸ W/cm² (烧蚀Propulsion)
碎片尺寸: 1-10 cm
轨道改变: Δv ~ 10-100 m/s needed for de-orbit
```

**地面站需求：**

```
D=3 m, λ=1.064 μm, R=500 km:
  光斑大小: d = 2.44×1.064×10⁻⁶×5×10⁵/3 = 0.43 m
  面积: 0.15 m²
  需要 P ≥ 0.15 × 10⁷ = 1.5 MW  (在目标上)
  
  考虑大气衰减(η=0.7) + Strehl(0.8) + 衍射(0.84):
  P_laser ≥ 1.5 / (0.7×0.8×0.84) ≈ 3.2 MW
```

**Conclusion：用~3-5 MW级地面Laser+3 m口径可实现500 km处1 cm级碎片的清除。物理可行，但工程艰巨。**

### 5.3 LaserPropulsion（光帆）

**基本物理：**

```
辐射压力: F = 2P/c (完美反射, 正入射)
Acceleration:   a = 2P/(m c) 
          = 6.67×10⁻⁹ × (P/W) / (m/kg)  [m/s²]
```

**火星快车（30天到火星，5.6×10¹⁰ m）：**

```
需要Acceleration: a = 2d/t² ≈ 0.017 m/s²

1 g 载荷: P = 2.5 kW
1 kg 载荷: P = 2.5 MW
10 kg 载荷: P = 25 MW
```

**但衍射是真正杀手：** 光帆必须始终在Laser束内。

```
D_laser = 10 m, λ = 1 μm:
  At Mars (5.6×10¹⁰ m): 光斑直径 ≈ 13.7 km!

D_laser = 1 km (Phased Array):
  At Mars: 光斑直径 ≈ 137 m → 需要 137 m 直径的光帆

D_laser = 10 km:
  光斑直径 ≈ 13.7 m → 需要 14 m 光帆（合理！）
```

**Conclusion：Laser光帆的瓶颈不是LaserPower（MW级即可），而是衍射。** 到火星需要**公里级**的发射阵列（相位锁定）以保持光束汇聚。SCVC锁定的Diffraction Limit（∝ℏ）是光帆星际旅行的根本障碍。
