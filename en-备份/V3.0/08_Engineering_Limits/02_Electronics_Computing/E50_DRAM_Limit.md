## 隧穿泄漏与保持时间

### 物理模型

直接隧穿概率 (WKB):

$$T(d) = \exp\left(-\frac{2d\sqrt{2m_e\Phi}}{\hbar}\right)$$

| 介质 | Φ (eV) | κ (m⁻¹) | 衰减长度 (nm) |
|------|--------|---------|-------------|
| SiO₂ | 3.1 | 9.03×10⁹ | 0.111 |
| HfO₂ | 2.0 | 7.25×10⁹ | 0.138 |
| ZrO₂ | 1.5 | 6.28×10⁹ | 0.159 |

### 隧穿概率 vs 厚度

| d (nm) | SiO₂ (3.1eV) | HfO₂ (2.0eV) | ZrO₂ (1.5eV) |
|--------|-------------|-------------|-------------|
| 0.5 | 1.2×10⁻⁴ | 7.1×10⁻⁴ | 1.9×10⁻³ |
| 1.0 | 1.5×10⁻⁸ | 5.1×10⁻⁷ | 3.6×10⁻⁶ |
| 2.0 | 2.1×10⁻¹⁶ | 2.6×10⁻¹³ | 1.3×10⁻¹¹ |
| 3.0 | 3.1×10⁻²⁴ | 1.3×10⁻¹⁹ | 4.5×10⁻¹⁷ |
| 5.0 | 6.7×10⁻⁴⁰ | 3.4×10⁻³² | 5.6×10⁻²⁸ |

```
每增加 0.5nm 物理厚度 → 隧穿概率下降 ~10³-10⁴×
→ 这就是为什么 DRAM 电介质不能无限缩薄
```

### DRAM漏电预算

典型DRAM单元: C=20 fF, V_DD=1.0V, 刷新=64ms, 允许100mV压降

**允许最大漏电流: < 31 fA/单元**

| d_phys (nm) | 介质 | I_leak | 保持时间 | 64ms可用? |
|------------|------|--------|---------|----------|
| 1.0 | SiO₂ | **1.46 nA** | 1.4 μs | ✗ FAIL |
| 2.0 | SiO₂ | 21 fA | **94 s** | ✓ PASS |
| 2.0 | HfO₂ | 26 fA | **77 ms** | ✓ 刚好 |
| 2.0 | ZrO₂ | 1.26 pA | 1.6 ms | ✗ FAIL |
| 3.0 | SiO₂ | 3.1×10⁻²⁵ A | ~10¹⁰ s | ✓ — 但做不到 |
| 3.0 | ZrO₂ | 45 fA | **448 s** | ✓ PASS |

```
◆ 直接隧穿: d>2-3nm物理厚度即可抑制 → 不是真正的瓶颈
◆ 真正的杀手: 陷阱辅助隧穿 (TAT) → 通过介质中Defect态的间接隧穿

TAT vs 直接隧穿 (SiO₂, 中隙陷阱 ~1.5eV):
  d=3nm: T_TAT = 4.5×10⁻¹⁷, T_direct = 3.1×10⁻²⁴ → TAT高 ~10⁷×!
  d=4nm: T_TAT = 1.6×10⁻²², T_direct = 4.6×10⁻³² → TAT高 ~10¹⁰×!
  d=5nm: T_TAT = 5.6×10⁻²⁸, T_direct = 6.7×10⁻⁴⁰ → TAT高 ~10¹²×!

→ 一旦直接隧穿被厚度抑制, TAT立即成为主导
→ TAT受限于Material质量 (DefectDensity) → 这是工艺问题, 不是Physical Wall
```

### 热离子发射 (85°C DRAM规范)

| 势垒 Φ (eV) | exp(−Φ/k_BT) at 85°C | 重要性 |
|------------|----------------------|--------|
| 0.5 | 1.3×10⁻⁷ | 陷阱能级 → 显著 |
| 1.0 | 1.2×10⁻¹⁴ | 浅陷阱 |
| 2.0 | 1.5×10⁻²⁸ | 可忽略 |
| 3.1 (SiO₂ CB offset) | **2.3×10⁻⁴⁴** | **完全可忽略** |

```
◆ 热离子发射对完整势垒 (>2eV) 完全可忽略
◆ 但Defect态 (~0.3-0.5eV) 的热激发是85°C下漏电的主因
◆ 高温加速老化测试 (85°C) 正因如此 → TAT+热离子双重加速
```

## 最小电容值

### 两层限制

| 限制 | 最小电容 | 物理Mechanism |
|------|---------|---------|
| **热噪声** (k_BT/C) | **~0.0006 fF** | V_rms=√(k_BT/C), 需6σSignal-to-Noise Ratio |
| **感知放大器** | **~0.5 fF** | 位线电容30fF, 最低感知15mV |

```
◆ 热噪声远低于实际限制 → 不是瓶颈
◆ 感知放大器才是真正的电容地板
◆ ΔV_BL = V_DD × C_cell/(C_cell+C_BL) → C_cell太小时信号被位线电容吞噬
```

## FeRAM / MRAM / RRAM — 突破电容泄漏Ceiling

### 根本差异: 能量势垒Height

所有Storage器都依赖于某种物理Status, Status保持时间由能量势垒决定:

$$\tau_{retention} \sim \tau_0 \cdot \exp(E_a/k_BT), \quad \tau_0 \sim 10^{-12}s$$

| 技术 | Storage物理量 | E_a (eV) | E_a/k_BT(85°C) | 保持时间 | SCVC来源 |
|------|-----------|---------|----------------|---------|----------|
| **DRAM** (TAT) | 电荷 | **0.3** | 10 | **0.02 ms** | Defect态 |
| **DRAM** (热离子) | 电荷 | **0.5** | 16 | **0.01 s** | 浅陷阱 |
| FeRAM (PZT) | 极化 | **1.5** | 49 | **>40年** | 偶极-偶极 ∝ α |
| FeRAM (HfO₂) | 极化 | **1.0** | 32 | **120秒** | 氧亚Lattice |
| STT-MRAM | 磁化 | **1.5** | 49 | **>40年** | SOC ∝ α² |
| RRAM (HfOₓ) | 导电丝 | **2.0** | 65 | **>10⁸年** | 键能 ∝ α |
| PCM (GST) | 相态 | **2.5** | 81 | **>10¹⁵年** | 键重排 |

```
DRAM vs FeRAM/MRAM/RRAM 的势垒差距:
  E_a(FeRAM) / E_a(DRAM) ≈ 1.5/0.3 = 5×
  保持时间比 = exp(1.2eV/k_BT) ≈ exp(39) ≈ 10¹⁷ at 85°C

→ 这就是为什么新型Storage器不需要刷新!
→ 多1eV的势垒 → 保持时间暴增 ~10¹⁴×
```

```

          代价: 写入也需要克服更高的势垒 → 写入Power Consumption更高
```

## 工程Conclusion

### DRAM终局

```
DRAM缩放的三个硬墙:

1. 隧穿墙 (直接): d_phys > 2-3nm → EOT > 0.5nm
   → 高k介质 (ZrO₂/Al₂O₃/HfO₂堆叠) 可缓解
   → 但TAT陷阱辅助隧穿在3-5nm仍是瓶颈

2. 电容墙: C_cell > ~0.5 fF
   → 当前 ~15 fF → 还有 ~30× 空间
   → 但需要极端深宽比 (>100:1) → 机械Limit

3. 感知墙: ΔV_BL > ~12 mV
   → 先进感知放大器 (偏移消除) 已接近Limit
   → 进一步降低需要全新感知架构

DRAM寿命: 还能缩放到 ~5-8nm 节点 (大约 2030-2035)
之后: 必须转向 3D-DRAM, FeRAM, 或 MRAM 混合架构
```

### 新型Storage器的SCVC优势

```
FeRAM: 保持来自铁电畴 (~1.5 eV 势垒)
  → 非易失 + DRAM级速度 → 完美"通用Storage器"候选
  → 瓶颈: 3D集成, Fatigue寿命 (~10¹²次)

MRAM: 保持来自磁各向异性 (~1.5 eV 势垒)  
  → 无限耐久 + 非易失 → 已用于 eFlash 替代
  → 瓶颈: 写入电流, Thermal Stability在 <20nm 节点

RRAM: 保持来自原子重排 (~2.0 eV 势垒)
  → 最高Density (3D crosspoint) + 非易失
  → 瓶颈:  variability, 潜行电流

SCVC核心洞察:
  DRAM是"最低势垒"的Storage器 → 最快但最"健忘"
  所有新型Storage器都用了 ~3-5× 更高的势垒
  → 多 ~1 eV → 保持时间长 ~10¹⁴× → 不再需要刷新
  → SCVC允许所有这些都是物理上可行的
  → 工程挑战不是"物理上不可能", 而是"工艺上如何做到均匀+可靠"
```
