§2. PropellerCavitation — 航速的物理Upper Limit
--------------------------------------------------------------------

【Cavitation数 σ】

  σ = (p − p_v) / (½ρV²)
  σ < σ_crit → Cavitation
  σ_crit ≈ 0.3-1.0（取决于桨叶截面设计）

  Propeller 5m浸深（海水, 20°C）:
    p_static ≈ 1.52 bar, p_v ≈ 0.023 bar
    无Cavitation最大叶尖速度: V_tip = √(2×1.50×10⁵/(1025×0.5)) ≈ 24 m/s ≈ 47节

  但实际Propeller叶尖速度:
    商船: 30-50 m/s → σ = 0.18-0.5 → **必然部分Cavitation**
    军舰: 40-60 m/s → σ = 0.08-0.28 → **已发展Cavitation**
    高速艇: 60-80 m/s → σ < 0.05 → **超空泡**

  ▸ **任何有用航速下，PropellerCavitation都不可避免**
  ▸ → 工程学不是"避免Cavitation"，而是"为可控Cavitation设计"

【Ship航速Upper Limit — 不是发动机，是Cavitation！】

  Cavitation限制的最大船速（传统无Cavitation桨, J≈0.8-1.2）:
    V_ship_max ≈ V_tip_max × J/π ≈ 24 × 0.9/π ≈ **7 m/s ≈ 13节**

  突破限制的方案:
    1. 增加桨叶面积 → 降低单位载荷 → σ_crit↓ → V↑ ~20-30%
    2. 加大浸深 → p↑ → 军用潜艇可达极深 → V↑
    3. 超空泡桨叶 → 有意形成空泡 → Drag降低 → V↑ (30-50节)
    4. 喷水Propulsion → 内部高压 → 延迟Cavitation → V↑ (40-60节)
    5. 表面桨 → 半浸桨 → 通大气 → 空泡稳定 → V↑ (60-100节)

  ▸ **水面舰艇速度Ceiling ~50-60节（喷水Propulsion），已被Cavitation+Drag联合锁定**
  ▸ 更快 → 必须离开水面（水翼艇、气垫船、地效飞行器）
