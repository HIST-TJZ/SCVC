--------------------------------------------------------------------
§1. Speed of Sound — 一切Ceiling的基准
--------------------------------------------------------------------

  Speed of Sound是大气层内飞行的标尺。每个速度门槛都是"你接近/超越了Mach 1的某种后果"。

  SCVCDerivation:
    c = √(γRT/M)

    γ = 1 + 2/f, f = 5（N₂和O₂: 3平动+2转动, 室温）
    → γ = 1.4

    R = 8.314 J/(mol·K), M = 0.029 kg/mol
    T_sl = 288 K → c = √(1.4×8.314×288/0.029) = √115,600 = **340 m/s**

    SCVC: 空气的比热比γ由分子自由度f决定。
    f = 5是因为Vibration模式被量子力学"冻结"——
    Vibration能级间隔 ↔ 化学键力常数k~10³ N/m ↔ α。
    如果α不同, γ不同, Speed of Sound不同, 所有的"Mach数Ceiling"都移动。

§2. 第一层: PropellerLimit — Mach ~0.7
--------------------------------------------------------------------

  【物理】桨尖接近Mach 1 → 局部激波 → 激波诱导分离 → 效率崩塌。

  桨尖速度: v_tip = ωR
  飞行速度: v_flight
  合成速度: v_relative = √(v_flight² + v_tip²)

  当 v_relative → c（局部音速, 随温度/压力变化）:
    → 桨叶表面出现超音速区
    → 激波→边界层分离→Thrust骤降+Drag骤升

  已知最快PropellerAircraft: Tu-95 熊式, ~Mach 0.7 (~925 km/h)
  理论Limit: Mach ~0.75-0.85（先进桨叶设计, 后掠桨尖）

  SCVC锁死:
    Propeller是旋转翼。Airfoil的临界马赫数由Airfoil厚度比决定。
    厚度比↓ → 临界Mach↑ → 但结构Strength↓ → 
    最终被Material刚度/Density比锁死 → 追溯到α（键能→弹性模量）。

    **PropellerCeiling: Mach ~0.8-0.85（绝对）**

§3. 第二层: Turbine叶片熔化 — Mach ~3.5-4.0
--------------------------------------------------------------------

  【物理】进气在压缩中升温。驻点温度 T₀ = T × (1 + 0.2M²)。
  压缩机和燃烧室进一步加热 → Turbine入口温度超过叶片MaterialLimit。

  【SR-71的精确Calculation】
    巡航Height 24 km, T_ambient ≈ 220 K
    进气驻点: T_inlet = 220 × (1 + 0.2×3.3²) = 220 × 3.178 ≈ **699 K (426°C)**
    压缩机出口: T_comp ≈ 699 × 2.0 ≈ 1400 K
    燃烧室出口: T_comb ≈ 1400 + 800 = 2200 K → 但掺混冷却 → T_turbine ≈ 1200 K

    SR-71的J58引擎用钛Alloy。钛的使用Upper Limit ~550°C（Creep限制）。
    进气已在426°C。压缩机后远超钛Limit。
    → J58使用特殊高温钛Alloy + 压缩机引气冷却。

  【SCVC绝对Ceiling（Turbine）】
    最佳Material: Ceramic基Composite MaterialCMC（SiC/SiC）
    工作温度Upper Limit: ~1500-1700 K（Oxidation+Creep限制）

    优化循环（低压缩比, 类似冲压过渡）:
      T_turbine_max ≈ 1700 K
      T_inlet_max ≈ T_turbine / (压缩加热 × 燃烧加热)
                   ≈ 1700 / (1.5 × 1.5) ≈ 756 K
      
      T_inlet = 220 × (1 + 0.2M²) → M ≈ 3.5

    加上极端冷却技术（发汗冷却, Heat Pipe）:
      T_inlet_max ≈ 1000 K → M ≈ **4.0-4.2**

  ┌──────────────────────────────────────────────────────┐
  │  TurbineCeiling: Mach ~3.5-4.0                            │
  │  SR-71 Mach 3.3 → 达成 ~83-94%                       │
  │  超越此墙 → 必须抛弃Turbine → 冲压发动机。               │
  └──────────────────────────────────────────────────────┘

§4. 第三层: N₂解离墙 — Mach ~6-9
--------------------------------------------------------------------

  【物理】冲压/超燃冲压发动机没有Turbine。但燃烧室驻点温度随M²增长。
  当T₀ > ~2500 K: O₂开始解离（O₂→2O, 5.2 eV）
  当T₀ > ~4000 K: N₂开始解离（N₂→2N, 9.8 eV）

  解离=吸收大量能量但不产生Thrust（原子在喷管中无法完全复合）。
  这就是"解离墙"——你加进去的热量被分子撕开吞噬了。

  SCVC精确Calculation:
    N≡N键能 = 9.8 eV（最强化学键, 从α_sDerivation）
    解离平衡: N₂ ⇌ 2N, K_p(T) ∝ exp(-E_diss/k_B T)

    10%解离温度(T_10%):
      O₂: ~3000-3500 K
      N₂: ~4500-5500 K

    对应的驻点Mach数（T_ambient=250K, 高空）:
      O₂解离: 1+0.2M² = 3500/250 = 14 → M ≈ **8.1**
      N₂解离: 1+0.2M² = 5000/250 = 20 → M ≈ **9.7**

    但超燃冲压的燃烧室在激波后——温度已经远高于驻点。
    实际解离墙在: **Mach 6-9**（取决于发动机设计）。

  ┌──────────────────────────────────────────────────────┐
  │  解离墙: Mach ~6-9                                    │
  │  X-15 Mach 6.7 → 撞在解离墙的起点                     │
  │  X-43A Mach 9.6 → 已经深入解离区, 燃烧效率极低         │
  │  超越此墙 → 必须接受极低Propulsion效率 → Rocket模式更优。     │
  └──────────────────────────────────────────────────────┘

§5. 第四层: 热结构Limit — Mach ~10-15
--------------------------------------------------------------------

  【物理】机身表面被气动加热"烤"。辐射平衡温度决定Material选择。

  气动加热（驻点）:
    q̇ ∝ ρ × v³（单位面积热流Density）
    T_skin⁴（辐射）= T_ambient⁴ + q̇/(εσ)
    近似: T_skin ≈ T_ambient × (1 + 0.18M²)^(1/4)

  MaterialLimit（从SCVC键能→Melting Point）:
  ┌──────────────────┬────────┬──────────┬─────────────┐
  │ Material              │ 键能eV  │ Melting Point      │ 对应MachUpper Limit  │
  ├──────────────────┼────────┼──────────┼─────────────┤
  │ 铝Alloy(A7075)     │ ~3.4   │ ~660°C   │ Mach ~2.2    │
  │ Concorde用铝      │        │          │ Mach 2.04 ✓  │
  ├──────────────────┼────────┼──────────┼─────────────┤
  │ 钛Alloy(Ti-6Al-4V) │ ~4.9   │ ~550°C*  │ Mach ~3.5    │
  │ SR-71用钛         │        │          │ Mach 3.3 ✓   │
  ├──────────────────┼────────┼──────────┼─────────────┤
  │ 不锈钢/Inconel    │ ~4.4   │ ~1000°C* │ Mach ~5-6    │
  │ X-15用Inconel X   │        │          │ Mach 6.7 ✓   │
  ├──────────────────┼────────┼──────────┼─────────────┤
  │ 铌Alloy/钼Alloy     │ ~7-8   │ ~1500°C* │ Mach ~8-10   │
  │ C/CComposite Material       │ ~6.4   │ ~2000°C* │ Mach ~10-14  │
  │ 超高温CeramicUHTC    │ ~8-10  │ ~3000°C* │ Mach ~14-18  │
  │ 主动冷却(Limit)    │ —      │ —        │ Mach ~18-22  │
  └──────────────────┴────────┴──────────┴─────────────┘
  * Creep/Oxidation有效Upper Limit, 非Melting Point

  X-15 Mach 6.7: 前缘温度 ~650°C。Inconel X勉强承受。
  Space ShuttleReentry: Mach ~25, 温度 ~1650°C → 需要Ceramic瓦。

  热结构Ceiling（无主动冷却）: **Mach ~12-15**
  热结构Ceiling（主动冷却）: **Mach ~18-22**

§6. 第五层: 等离子体黑障 — Mach ~20-25
--------------------------------------------------------------------

  【物理】T₀ > 5000-8000 K → 空气完全电离 → 等离子体。

  等离子体的后果:
    1. 电磁波Shielding → Communication完全中断（黑障）
    2. 气体不再是连续介质 → 气动Lift模型失效
    3. 电离复合释放辐射 → 热载荷进一步增加
    4. 飞行器周围形成等离子体鞘 → 无法进行气动控制

  这是"大气层内飞行"的定义边界:
    如果你被等离子体包裹, 你不是在"飞"——
    你是被电离火球裹挟着在弹道轨道上滑行。

  SCVC电离温度:
    空气第一电离能 ~12-15 eV（N₂和O₂的第一电离能）
    显著电离(T>5000K): 1+0.2M² = 5000/250 = 20 → M ≈ **9.7**
    完全电离(T>10000K): 1+0.2M² = 40 → M ≈ **14.0**

    加上激波压缩: 实际等离子体墙在 **Mach 15-25**

  在这个区域, 飞行器不再"飞"——
  AerospaceAircraftReentry(Mach 25)经历黑障 ~12分钟, 这不是"飞行", 是"受控坠落"。

  ┌──────────────────────────────────────────────────────┐
  │  等离子体墙: Mach ~20-25                              │
  │  高超音速滑翔器 Mach 15-20 → 在墙的边缘               │
  │  AerospaceAircraftReentry Mach 25 → 已穿越等离子体墙              │
  │  超越此墙 → "大气层内飞行"的定义不再适用              │
  └──────────────────────────────────────────────────────┘

§8. 客机的物理-经济交点
--------------------------------------------------------------------

  【为什么客机停在Mach 0.85？】

  不是物理上飞不了更快——是经济不允许。

  燃油能量: 航空煤油 ~43 MJ/kg
  从SCVC: C-H键能 ~4.3 eV/键, 碳氢比 ~1:2
  燃烧释放: C-C(3.6eV) + C-H(~4.3eV) → C=O(~8eV) + H-O(~5eV)
  → ΔE ≈ 产物键能 - 反应物键能 → ~43 MJ/kg

  巡航所需Power: P = D × v = (L/(L/D)) × v

  L/D随Mach数的变化:
    Mach 0.5: L/D ≈ 18-20
    Mach 0.8: L/D ≈ 18-20（最优, 跨音速Drag尚未激增）
    Mach 0.85: L/D ≈ 17-19（典型客机巡航）
    Mach 0.95: L/D ≈ 12-15（波阻开始出现）
    Mach 1.2: L/D ≈ 8-10
    Mach 2.0: L/D ≈ 6-8（Concorde ~7.5）

  每客公里油耗 ∝ v / (L/D):
    Mach 0.85: 0.85/18 ≈ 0.047
    Mach 2.0:  2.0/7.5 ≈ 0.267 → **5.7× 马赫0.85的油耗**

  Concorde票价 ~$12,000(现价) vs 经济舱 ~$800 → **15×**。
  不是因为"技术不行"——是因为物理学。
  克服波阻的代价是指数式的。

  SCVC判断:
    **超音速客机在经济上永远无法与亚音速客机竞争。**
    这不是技术问题——是波阻从Mach锥几何来,
    Mach锥几何从Speed of Sound来, Speed of Sound从γ来, γ从α来。
    只要α不变, 超音速就比亚音速贵5-10倍的燃油。

  Boom Supersonic (Overture, 目标Mach 1.7):
    声称L/D ≈ 10 → 油耗比 1.7/10=0.17 vs 0.85/18=0.047 → **3.6×**
    即使成功, 票价也是商务舱的2-3倍。利基市场, 非大众运输。

§9. Height-速度的SCVC最优曲面
--------------------------------------------------------------------

  高空 → 空气Density低 → 热流低 → 允许更高Mach。
  但高空 → Lift低 → 需要更大迎角/更大机翼 → Drag增加。

  最优巡航Height:
    h_opt ≈ 10-13 km（对流层顶, 温度最低 ~216K）
    在此Height: Drag最低 + 引擎效率最高

  不同Height的热Limit(M_max):
    ┌──────────┬──────────┬───────────────┐
    │ Height(km)  │ T_amb(K) │ M_max(钛,550°C)│
    ├──────────┼──────────┼───────────────┤
    │ 0         │ 288      │ 2.7           │
    │ 10        │ 223      │ 3.2           │
    │ 20        │ 217      │ 3.3           │
    │ 30        │ 227      │ 3.2           │
    │ 40        │ 250      │ 3.0           │
    │ 50        │ 271      │ 2.8           │
    └──────────┴──────────┴───────────────┘

  ▸ 对流层顶(~12km)给了SR-71额外的热裕度。
  ▸ 更高 → 平流层逆温 → T升高 → 热Limit反而下降。
