§1. 等Stress锥度设计 — 重力梯度精确积分
--------------------------------------------------------------------

【物理模型】

  缆绳从地表 (R=6,371 km) 延伸至地球同步轨道以外。
  在任意半径 r 处，缆绳承受重力 + 离心力的净载荷:
    g_eff(r) = GM/r² − ω²r
  在 GEO (R_GEO=42,164 km): g_eff = 0（同步轨道的定义）

  等Stress锥度方程:
    A(r) = A₀ · exp[ ∫_R^r g_eff(r′)/σ* dr′ ]
    其中 σ* = σ/ρ = 比Strength (specific strength)

【势垒积分 Φ】

  Φ = ∫_R^R_GEO (GM/r² − ω²r) dr
    = GM(1/R − 1/R_GEO) − ω²(R_GEO² − R²)/2

  引力项:   53.11 MN·m/kg
  离心项:   −4.62 MN·m/kg
  ─────────────────────
  净势垒 Φ = 48.49 MN·m/kg = 48.5 kN·m/g

  ▸ 离心力抵消了 ~9% 的引力 → 这是E65常数g近似所忽略的关键！
  ▸ 常数g近似 (E65) 给出 Φ≈350 MN·m/kg → 高估了7×！

【锥度比 = exp(Φ/σ*)】

【关键判据】

  锥度比 < 10 的阈值比Strength:
    σ*_threshold = Φ / ln(10) ≈ 21.1 MN·m/kg = 21.1 kN·m/g
  
  对于碳基Material (ρ≈1500 kg/m³):
    σ_threshold ≈ 32 GPa
    CNT 理想值 63 GPa → 超出阈值 ~2×

  ▸ CNT 达到理论Strength时，Space Elevator锥度仅 ~2.7 → 工程可行！
  ▸ CNT 带安全系数2时锥度 ~7.4 → 靠近但仍在可行区
  ▸ 石墨烯锥度 ~2.3 (SF=1) / ~5.2 (SF=2)
  ▸ 碳炔即使SF=3: 锥度 ~2.9 → 轻松！

【为什么E65说 "不可能" 而E74说 "可行"？】

  E65用了常数g近似: H_char = σ/ρg ≈ σ/ρ×9.81 → 忽略了:
    1) g随Height下降（在GEO处g≈0.22 m/s², 仅地球表面的2%）
    2) 离心力抵消（在GEO处 g_eff=0）
    3) 正确的积分应使用 g_eff(r) 而非常数 g
  → 因子差 ~7× → 决定了可能 vs 不可能的定性判断！

§2. 安全系数与缆绳总质量
--------------------------------------------------------------------

【安全系数来源】

  Defect (Griffith裂纹):    降低Strength ~2-3×（纳米纤维中DefectDensity低）
  微流星体撞击:           ~1-10 mm 坑 → 局部Stress集中 → SF ~1.2-1.5
  原子氧Corrosion (LEO):       碳Material在低轨被Corrosion → 需涂层 → 等效SF ~1.1
  热循环 (日食/日照):     膨胀-收缩 → Fatigue → SF ~1.2
  联合安全系数:           ~2-3

  → CNT (SF=2): 锥度 ~7.4 → 底部面积=顶部面积的7.4倍
  → 可制造性: 底部缆绳直径 ~1 cm → 顶部 ~2.7 cm → 制造可行！

【缆绳总质量估算】

  地表到GEO缆绳段 (~36,000 km):
    相对于等截面缆绳，锥形缆绳质量约1.5-3×（取决于σ*）
    对于CNT SF=2 (锥度7.4): 质量比 ≈ 2.0×
  
  10吨有效载荷的缆绳最小截面积:
    A₀ ≈ 10,000 kg × g / σ_material ≈ 10,000×9.81/31.5×10⁹ ≈ 3 mm²
    加上缆绳自重后: ~10-20 mm² → 直径 ~3.5-5 mm → 惊人地细！

  ▸ 但这是忽略配重、攀爬器动态载荷的情况
  ▸ 实际设计: 底部直径 ~1-5 cm（含冗余/涂层/动态载荷安全）

【GEO以远 — 配重段】

  缆绳必须延伸至GEO以外: 总长 ~100,000 km
  配重提供张力，使缆绳底部不会"松散"
  配重质量 ≈ 地表至GEO缆绳质量的 30-50%
  → 总缆绳+配重: 地表截面积的约 3-5×等截面质量
