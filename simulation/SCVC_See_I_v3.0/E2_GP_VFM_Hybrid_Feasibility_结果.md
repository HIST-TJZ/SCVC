# E2: SCVC GP-VFM混合模拟可行性 — 完整技术评估

**日期**: 2026-07-24
**状态**: 五种方案完整评估。推荐B+D混合方案。提供最小可行架构和代码修改路线图。
**依赖**: SCVC模拟v3.0, N1核子势, N2多体力, GP涡旋理论

---

## 执行摘要

SCVC模拟目前使用纯VFM（涡旋丝模型）——将粒子视为点涡旋，通过配对势相互作用。这在核尺度（~1 fm）工作良好，但在原子尺度（~1 Å = 10^5 fm）失效，因为：

| 问题 | 原因 | 影响 |
|:---|:---|:---|
| 电子量子本质 | VFM是经典的，电子需要波动力学 | 原子轨道/化学键无法正确形成 |
| 尺度跨越 | 核尺度 0.2 sim ↔ 原子尺度 ~4000 sim | 势函数在中间尺度不准确 |
| 量子零点运动 | VFM无零点能 | 基态能量/稳定性错误 |

**推荐方案**: 预计算有效势（B）+ 质量标度重定标（D）。离线一次性计算，运行时零额外开销。

## S0. 尺度分析

### 0.1 SCVC模拟的特征尺度

```
核子尺度:    1 fm      = 0.189 sim      (N1, N2 验证范围)
涡旋核心:    ξ = 0.25 sim              (GP ODE 求解)
电子Compton: 386 fm    = 72.9 sim       (电子量子尺度)
氢原子Bohr:  52900 fm  = 9993 sim       (存储值A0_SIM=4016)
```

**关键**: 核子尺度到原子尺度跨越20,000倍。VFM在核尺度精确，在原子尺度需要量子修正。

### 0.2 VFM与GP的精度/成本权衡

```
方法       | 精度          | 成本/粒子    | 总成本(N粒子)
-----------|---------------|-------------|------------
纯VFM      | 核尺度:高     | O(N)        | O(N²)
           | 原子尺度:低   |             |
纯3D GP    | 全部尺度:高   | O(N_grid³)  | O(N_iter×N_grid³)
           |               |             | ~10¹⁵ @原子尺度
GP-VFM混合 | 可调          | 取决于方案  | 取决于方案
```

**实时模拟约束** (Godot 60fps):
- 每帧预算: 16.7 ms
- GDScript吞吐: ~10⁶ ops/ms → 最大~1.6×10⁷ ops/frame
- 400粒子池: O(N²) = 1.6×10⁵ pairs → VFM本身使用~10⁶ ops (余量充足)

## S1. 方案A: GP修正的VFM有效势

### 1.1 方案

用1D GP解出的涡旋核心剖面 f(r) 替换VFM在短程的对数势。

```
V_VFM(r) = −G × (w·w) × log(1 + r²/ξ²)           [原始VFM]
V_hybrid(r) = { V_GP(r)                    r < 5ξ  [GP修正]
              { V_VFM(r)                   r ≥ 5ξ  [原始VFM]
```

### 1.2 GP有效势 V_GP(r)

从GP泛函: 对于涡旋对，有效相互作用能从序参量剖面提取:
```
V_GP(r) = E_CORE × [f²(r) − 1]²  (核心重叠能)
```

### 1.3 评估

| 指标 | 评分 | 说明 |
|:---|:--:|:---|
| 实现复杂度 | ⭐⭐ (低) | 仅修改vortex_physics.gd中的力计算 |
| 物理精度 | ⭐⭐⭐ (中) | 捕获核心量子效应，但忽略多体关联 |
| 计算开销 | ⭐⭐⭐⭐⭐ (零) | 预计算查表，运行时O(1) |
| 实时可行 | ✅ 是 | 零额外开销 |

**结论**: 简单有效，但精度有限——无法处理角度关联和电子相干。

## S2. 方案B: GP基态有效势（推荐）

### 2.1 方案

离线求解3D GP方程获取两体有效势，制成查找表供VFM使用。

```
离线阶段:
  1. 对每个关键粒子对 (e-p, e-e, p-p):
     在3D格点上解GP方程 → E_GP(r)
  2. 拟合: V_eff(r) = V_Coulomb(r) + V_exchange(r) + V_correlation(r)
  3. 输出查找表: r → V_eff(r), 分辨率0.1ξ

在线阶段:
  V(r) = lookup_table[bin(r)]   [r < r_cutoff]
  V(r) = V_VFM(r)               [r ≥ r_cutoff]
```

### 2.2 关键两体系统

| 系统 | GP输入 | 物理输出 | 模拟使用 |
|:---|:---|:---|:---|
| e⁻-p⁺ | mf_e=1, mf_p=1836, Q=∓1 | 氢原子基态势 | 所有含氢系统 |
| e⁻-e⁻ | mf_e=1, Q=−1, 交换反对称 | Pauli排斥+关联孔 | 多电子原子 |
| p⁺-p⁺ | mf_p=1836, Q=+1 | 核子间库仑排斥 | 分子/团簇 |

### 2.3 离线计算可行性

```
3D GP for e-p: 
  格点范围: r_max = 12000 sim (~1.2×Bohr半径)
  分辨率: Δr = 2 sim (~0.01Å, 足以捕获涡旋核心)
  格点数: 6000³ ≈ 2.2×10¹¹ → 不可行
  
  优化: 柱对称 → 2D (r, z): 6000×6000 = 3.6×10⁷
        迭代~100次 → 3.6×10⁹ ops
        Python+NumPy: ~10⁷ ops/s → 360s ≈ 6分钟 → 可接受

  进一步优化: 自适应网格 (近核心Δr=0.1, 远场Δr=10)
        平均格点数 ~1000×1000 = 10⁶ → 10⁸ ops → 10秒
```

**结论**: 离线2D GP完全可行（~10秒至6分钟），对模拟零运行时开销。

## S3. 方案C: Langevin量子涨落

### 3.1 方案

在VFM运动方程中加入随机力，模拟GP的量子涨落。

```
m_i dv_i/dt = F_VFM(r_ij) + F_Langevin(t)

⟨F_Langevin(t)⟩ = 0
⟨F_Langevin(t)F_Langevin(t')⟩ = γ × δ(t−t') × (ℏ/ξ_deBroglie)
```

### 3.2 根本问题

Langevin方法来自**热**涨落（经典统计力学），不是**量子**涨落。量子基态的零点运动有完全不同的谱结构:

```
经典Langevin: 白噪声, 涨落-耗散定理
量子基态:     频率相关的量子噪声, 零点能 = (1/2)ℏω for each mode
```

直接用Langevin模拟量子效应会:
- 给错基态能量（缺少零点能标度）
- 给错关联函数（量子纠缠vs经典关联）
- 在T→0时噪声应消失（但量子涨落不消失）

### 3.3 评估

| 指标 | 评分 | 说明 |
|:---|:--:|:---|
| 实现复杂度 | ⭐⭐⭐⭐ (高) | 需要有色噪声生成+量子耗散关系 |
| 物理精度 | ⭐⭐ (低) | 经典噪声≠量子涨落 |
| 计算开销 | ⭐⭐⭐ (+20%) | 每帧生成噪声 |
| 实时可行 | 🟡 勉强 | |

**结论**: 不推荐。Langevin方法本质上是经典的，不能正确复现量子基态。

## S4. 方案D: 有效Biot-Savart + 质量标度重定标

### 4.1 方案

利用m_p/m_e = 1836的质量比，为电子重定标涡旋参数。

### 4.2 物理动机

在SCVC中，涡旋核心大小ξ由BEC愈合长度决定:
```
ξ ∝ 1/√(m_c × μ)
```

对于不同质量的粒子，涡旋感受到的有效BEC参数不同:
```
电子 (轻, mf=1):      λ_deBroglie大 → "看到"更大的BEC体积
质子 (重, mf=1836):   λ_deBroglie小 → "看到"更局域的BEC
```

### 4.3 重定标公式

```
ξ_e    = ξ × √(mf_p/mf_e)   = 0.25 × √1836    = 10.71 sim
G_e    = G_STRONG / √1836   = 3.30 / 42.85    = 0.077
E_CORE_e = E_CORE / 1836    = 2.1322 / 1836    = 0.00116
ρ_s(eff) = ρ_s / 1836        = 6.5797 / 1836    = 0.00358
```

### 4.4 评估

| 指标 | 评分 | 说明 |
|:---|:--:|:---|
| 实现复杂度 | ⭐ (极低) | 仅为电子设置不同参数 |
| 物理精度 | ⭐⭐⭐ (中) | 正确标度律但忽略量子相干 |
| 计算开销 | ⭐⭐⭐⭐⭐ (零) | |
| 实时可行 | ✅ 是 | |

**物理精度说明**: 标度律正确地给出了电子的特征尺度（更大的涡旋核心，更弱的耦合），但没有波动力学（轨道量子化、干涉、隧道效应）。

## S5. 方案E: 真实GP-VFM混合

### 5.1 方案

在涡旋核心附近（|Ψ|显著偏离1的区域）求解3D GP，在远场使用VFM。

### 5.2 计算可行性

围绕单个电子的格点:
```
径向范围: r_max = 5 × ξ_e = 5 × 10.71 = 53.6 sim
格点分辨率: Δr = 0.5 sim (解析ξ_e=10.7, 约20点/core)
格点数量: (107/0.5)³ ≈ 214³ ≈ 9.8×10⁶
每次迭代: ~10⁷ ops
迭代次数: ~20 (CG/拟牛顿)
总成本/电子: ~2×10⁸ ops
```

电子数>1时，格点必须覆盖所有电子核心 → 扩展为覆盖分子的大格点。

```
氢分子 (2电子): 格点范围 ~200 sim → 400³ ≈ 6.4×10⁷ → ~10⁹ ops/frame
```

远超实时预算 (1.6×10⁷)。不可行。

### 5.3 1D简化

仅保留径向GP（球对称近似）:
```
格点数: 107/0.5 ≈ 214
每电子: ~200 ops
10电子: ~2000 ops → ✅ 实时可行
```

但球对称近似丢失了:
- 化学键的方向性
- 角度关联
- 分子轨道杂化

## S6. 推荐方案: B+D混合

### 6.1 架构

```
┌─────────────────────────────────────────────┐
│              离线阶段 (一次性)                 │
│                                              │
│  3D/2D GP求解器                               │
│    ↓                                         │
│  V_eff^ep(r), V_eff^ee(r), V_eff^pp(r)       │
│    ↓                                         │
│  查找表 (LUT) + 解析拟合                       │
│    ↓                                         │
│  电子参数重定标: ξ_e, G_e, E_CORE_e            │
└─────────────────────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────┐
│              在线阶段 (每帧)                   │
│                                              │
│  VFM粒子循环:                                 │
│    if particle.electron:                      │
│      use (ξ_e, G_e) for long-range           │
│    for each pair:                             │
│      if r < r_cutoff:                         │
│        V = LUT_lookup(r, pair_type)           │
│      else:                                    │
│        V = V_VFM_standard(r)                  │
└─────────────────────────────────────────────┘
```

### 6.2 实现细节

**查找表设计:**
```gdscript
# Pair types
enum PairType { EP, EE, PP }

# LUT: pre-computed arrays
# r_bins[i] = r_min + i * dr  (i = 0..N_bins-1)
# v_bins[type][i] = V_eff(r_bins[i])
const LUT_R_MIN = 0.01
const LUT_R_MAX = 200.0
const LUT_N_BINS = 1000
const LUT_DR = (LUT_R_MAX - LUT_R_MIN) / LUT_N_BINS

func get_effective_potential(r, pair_type):
    if r < LUT_R_MIN:
        return v_bins[pair_type][0]  # constant core
    if r > LUT_R_MAX:
        return V_VFM_standard(r)     # fallback to VFM
    var idx = int((r - LUT_R_MIN) / LUT_DR)
    return v_bins[pair_type][idx]
```

**电子参数重定标:**
```gdscript
const MF_RATIO_EP = 1836.0

# Electron-specific parameters
const XI_ELECTRON = 0.25 * sqrt(MF_RATIO_EP)    # 10.71
const G_ELECTRON  = 3.30 / sqrt(MF_RATIO_EP)    # 0.077
const E_CORE_E    = 2.1322 / MF_RATIO_EP         # 0.00116
```

### 6.3 精度评估

| 物理效应 | 是否捕获 | 机制 |
|:---|:--:|:---|
| 电子-质子库仑吸引 | ✅ | V_eff^ep包含+EM势 |
| 量子零点运动 | ✅ | V_eff隐式包含基态能量 |
| Pauli排斥 (e-e) | ✅ | V_eff^ee包含交换孔 |
| 轨道量子化 | 🟡 | 基态轨道由V_eff建模，激发态需另处理 |
| 化学键方向性 | 🟡 | V_eff是球对称的；方向性需要额外的角度依赖 |
| 隧道效应 | ❌ | VFM无法模拟量子隧道 |
| 电子关联 (多体) | 🟡 | 两体V_eff准确，三体+需N2三体力框架 |
