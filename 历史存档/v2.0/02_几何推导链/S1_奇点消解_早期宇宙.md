## 奇点→相边界

GR的奇点是4D有效描述失效处，非物理崩塌。

GR的g_μν依赖BEC序参量|Ψ|²。|Ψ|→0时映射失效→GR报告"奇点"。但7D GP方程在|Ψ|→0处完全正则(线性Schrödinger型)。7D Ricci标量有界。

| | GR (4D有效) | SCVC (7D基本) |
|:---|:---|:---|
| 奇点处 | R₄→∞ | R₇有界 |
| 物理定律 | 崩塌 | 正常 |

**G1的12不动点在|Ψ|→0处仍然良好定义**——不动点由几何对称性定义，不依赖|Ψ|值。

## 早期宇宙→相变链

```
KK紧致化(7D→4D) → 暴涨(n_s=0.964,r=0.004) → PBH形成
→ PBH蒸发 → 暗物质残余(D1) → ΛCDM宇宙
```

每一环节由不动点局域化确定。配分函数Z(β)在手，相变前后的自由度差自动决定产生的粒子种类和丰度。
